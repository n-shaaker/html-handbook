# پوشش سرفصل کوئرا کالج (دوره فرانت‌اند ۶۰۹۲)

این گزارش جزوهٔ همین مخزن را با **فهرست درس‌های** دورهٔ فرانت‌اند کوئرا می‌سنجد، نه با متن درس‌های کوئرا. متن درس پشت ورود است و در دسترس این به‌روزرسانی نبود. توضیح‌ها از روی استاندارد وب و مستندات MDN نوشته یا کامل شده‌اند و از متن کوئرا کپی نشده‌اند.

معنی وضعیت‌ها:

| وضعیت | معنی |
| --- | --- |
| پوشش‌داده‌شده | موضوع در جزوه درس دارد و مثال یا تمرین همان مهارت را می‌سازد |
| ناقص | مهارت هست، ولی یک تکهٔ مهم سرفصل فقط اشاره شده یا در صفحهٔ دیگری دیرتر آمده |
| نیست | در جزوه فصل یا درس متناظر ندارد. طبق خواست صاحب مخزن، فصل تازه ساخته نشد و فقط همین‌جا پیشنهاد شده است |

جزوه همان پوشه‌های `01` تا `13`، طرح ۱۶جلسه‌ای، و سه فایل Word تولیدشده از `content_*.py` است.

## ترتیب موضوعات

ترتیب را عوض نکردم. مسیر مطالعه‌ای که نویسنده در نمودار `README.md` ریشه و در دکمهٔ «بعدی» جزوه گذاشته، مفهومی را قبل از آموزشش به کار نمی‌گیرد.

- در `03-CSS-میانی` دکمهٔ بعدیِ درس فرم‌ها به Flexbox می‌رود، بعد Grid، بعد چیدمان سایت، بعد Media Queries. درس‌های اختیاری (شمارنده، واحد، ریاضی، Transition) زنجیرهٔ جدا هستند و جلوی Flex را نمی‌گیرند.
- DOM در جاوااسکریپت پایه (درس ۱۰) فقط از متغیر، تابع و شیء استفاده می‌کند که درس‌های ۱ تا ۹ گفته شده‌اند. `querySelectorAll` را صریحاً به بعد از حلقه موکول کرده است. درس رویداد همان‌جا شرط و حلقه ندارد. رشته، شرط و حلقه بعد از این آشنایی کوتاه می‌آیند و DOM عمیق در جاوااسکریپت میانی تکرار می‌شود. این ترتیب با سرفصل کوئرا (زبان کامل، بعد DOM) یکی نیست، ولی درس زودرس به مفهوم نخوانده تکیه نمی‌کند.
- بخش معنایی (درس ۱۳) قبل از درس اختصاصی `div` است. در آن صفحه `div` فقط به‌عنوان جایگزینِ بی‌معنا نام برده می‌شود و درس ۱۴ بلافاصله خودش `div` را یاد می‌دهد.
- آبشاری و specificity بعد از Flex و Grid است. درس‌های جلوتر هر کدام یک قانون مشخص می‌نویسند و به محاسبهٔ قدرت انتخابگر نیاز ندارند. کوئرا specificity را قبل از Flex می‌گذارد؛ هر دو ترتیب قابل تدریس‌اند و اینجا جابه‌جایی پوشه لازم نبود.
- طرح ۱۶جلسه‌ای از HTML و فرم معنایی به CSS، جعبه، Flex، Grid، پروژه، بعد جاوااسکریپت، DOM، رویداد، و در آخر شبکه می‌رسد. این ترتیب برای کلاس سالم است.

شمارهٔ پوشه با این مسیر یکی نیست: `04` تا `06` از نظر عدد قبل از `07` و `08` هستند، ولی در نمودار README بعد از Flex و Grid خوانده می‌شوند. دو جمله در README ریشه (زیر «ترتیب یادگیری» و در جمع‌بندی ممیزی) می‌گفتند شمارهٔ پوشه همان ترتیب یادگیری است. هر دو با نمودار همان فایل جور نبودند و اصلاح شدند. نمودار `سوالات-از-استاد/README.md` هم شمارهٔ پشت‌سرهم را ترتیب مطالعه معرفی می‌کرد؛ با نمودار ریشه یکی شد و جدول فایل‌ها سر جایش ماند. پوشه‌ای جابه‌جا یا شماره‌گذاری دوباره نشد تا پیوندها نشکنند.

در طرح ۱۶جلسه‌ای متن چند پیوند، شمارهٔ قدیمی ماژول را نشان می‌داد (مثلاً رستوران استاتیک را ۰۷ نوشته بود در حالی که پوشه‌اش ۰۹ است، و Fetch را ۱۰ در حالی که پوشه‌اش ۱۲ است). آدرس پیوندها همان بود؛ فقط برچسب با پوشهٔ مقصد یکی شد. ترتیب جلسه‌ها دست نخورد.

## فصل ۱۲ — پایه‌های جاوااسکریپت

پوشش‌داده‌شده بین `10-JS-پایه` و ابتدای `11-JS-میانی`: اتصال اسکریپت، خروجی، متغیر، نوع و تبدیل نوع، عملگر، شرط، `switch`، حلقه، تابع، دامنه (ادامه در میانی)، آرایه و متد و جست‌وجو و مرتب‌سازی، رشته، شیء، تاریخ میلادی و تاریخ شمسی با `toLocaleDateString("fa-IR")`.

ورودی با `prompt` و `confirm` به درس خروجی اضافه شد. قبلاً فقط `alert` بود و ورودی واقعی به فرم موکول شده بود، بدون اینکه پنجرهٔ ورودی معرفی شود. فرم HTML همچنان راه درست صفحهٔ واقعی است.

کتابخانهٔ تاریخ شمسی (مثل Jalali Moment) نیست. روش استاندارد داخل مرورگر در درس تاریخ هست. پیشنهاد در فصل ماژول‌ها آمده است.

## فصل ۱۳ — جاوااسکریپت پیشرفته

پوشش‌داده‌شده در `11` و `12`: عبارت منظم، Destructuring، `Map` و `Set`، دامنه، تابع به‌عنوان مقدار، Callback Hell، Promise، `async/await`، کلاس، getter/setter، `static` و فیلد خصوصی، وراثت.

حلقهٔ رویداد در درس Promise بود. همان بخش با پشتهٔ فراخوانی و فرق microtask و macrotask کمی بازتر شد؛ صفحهٔ جدید ساخته نشد.

## فصل ۱۴ — جاوااسکریپت در وب

پوشش‌داده‌شده: DOM (پایه و میانی)، کلاس و استایل، رویداد ماوس و صفحه‌کلید، حباب و delegation، ساخت و حذف عنصر، اسلایدر، مودال، `localStorage`.

تابع‌های `window` پراکنده‌اند (`alert`/`prompt`، `setTimeout`، `scrollTo`) و یک فهرست جدا به نام window نیست. برای سطح این جزوه همان پراکندگی کافی است. پیشنهاد جداگانه‌ای لازم ندیدم مگر اینکه بعداً یک جدول مرجع به درس زمان‌بندی اضافه شود.

## چه چیزی در این نوبت اضافه شد

هیچ فایل یا پوشهٔ درسی حذف، کوتاه، یا جابه‌جا نشد. اضافه‌ها داخل درس موجود هستند.

- HTML درس ۵: `lang` و `dir` روی یک تکهٔ متن، با تمرین.
- HTML درس ۶: محدودهٔ ۱۰۲۴ بایت برای `charset`، `script defer`، عنصر `base`.
- HTML درس ۹: ارجاع به `figure` در درس ۲۰ و تمرین نشان کارگاه.
- HTML درس ۱۲: مثال `radio` و `checkbox` با `name` و `value`.
- CSS درس ۱: استایل اولیهٔ مرورگر.
- CSS درس اندازه: استثنای `img` و `input` برای عرض و ارتفاع.
- CSS درس `display`: روند نرمال.
- CSS درس ترکیب‌کننده‌ها: اسم «انتخابگر تودرتو» برای انتخابگر نسل.
- JS درس خروجی: `prompt` و `confirm`.
- JS درس Promise: پشته و صف microtask/macrotask.
- JS درس Fetch: HTTP و REST قبل از نمونهٔ کد.

## اصلاح‌های واقعی

معنی جمله حفظ شده و فقط جایی که گفته غلط یا ناقصِ گمراه‌کننده بود عوض شده است.

1. درس معنایی می‌گفت `main` را داخل `section` نگذارید. استاندارد HTML والدهای ممنوع را `header`، `footer`، `nav`، `aside` و `article` می‌داند و `section` در این فهرست نیست. جمله اصلاح شد. الگوی رایج (section داخل main) همچنان توصیه می‌شود. به خطای پایین صفحه، `nav` و `aside` هم اضافه شد و ذکر `header`/`footer`/`article` سر جایش ماند.
2. پیوند درس `div` می‌گفت عرض و ارتفاع «فقط روی block معنا دارد». عنصر جایگزینِ درون‌خطی مثل `img` عرض می‌گیرد. متن پیوند دقیق شد و در درس اندازه، کنار جملهٔ «معمولاً اثر ندارد»، همین استثنا اضافه شد.
3. بالای درس چیدمان نوشته شده بود Media Queries «قبل» از آن مسیر است. آن درس در دکمهٔ بعدی، بعد از چیدمان می‌آید. کلمه به «بعد، برای صفحهٔ باریک» عوض شد. هر دو پیوند Flex و Grid و Media Queries سر جایشان ماندند.
4. خطای `typeof null` می‌گفت نتیجه `"null"` نیست، ولی مقدار واقعی را نمی‌گفت. اضافه شد که نتیجهٔ واقعی `"object"` است و این رفتار قدیمی زبان است. توصیهٔ `=== null` حذف نشد.
5. README ریشه می‌گفت شمارهٔ پوشه با ترتیب یادگیری یکی است، در حالی که نمودار همان فایل Flex و Grid را قبل از پوشه‌های ۰۴ تا ۰۶ می‌گذارد. جمله با نمودار یکی شد.
6. برچسب پیوندهای طرح ۱۶جلسه‌ای شمارهٔ ماژول را اشتباه نشان می‌داد. آدرس‌ها عوض نشدند.
