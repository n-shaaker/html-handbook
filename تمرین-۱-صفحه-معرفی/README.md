# تمرین ۱ — صفحه معرفی

دمو / مرجع یک صفحه معرفی شخصی با HTML و CSS.

## پیش‌نیاز

- [01 HTML مقدماتی](../01-HTML-مقدماتی/)
- [02 CSS مقدماتی](../02-CSS-مقدماتی/) (حداقل تا box model، متن، فونت)

## معیار موفقیت

1. ساختار معنایی: `header`، `nav`، `main`، `section`، `footer`
2. CSS خارجی (نه فقط اینلاین)
3. تصویر پروفایل با مسیر نسبی درست
4. لینک‌های داخلی به بخش‌های صفحه کار کنند
5. در عرض حدود ۳۶۰px خوانا باشد (حتی اگر هنوز Flex کامل نخوانده‌اید، با `max-width` و واحدهای نسبی)

## کار شما

1. یک‌بار دمو را در مرورگر ببینید.
2. **بدون کپی کامل**، صفحه معرفی خودتان را از صفر بسازید.
3. با [W3C Validator](https://validator.w3.org/) HTML را چک کنید.
