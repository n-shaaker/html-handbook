# مبحث ۵ — جمع کل و قالب‌بندی فارسی قیمت

📖 بخش مرتبط پروژه: [صفحه منوی نارنج](../../../index.html) (جمع کل سبد) — در [`js/app.js`](../../../js/app.js) تابع `formatPrice` و محاسبه `total` در `renderCart`.

> HTML و CSS آماده است (پوشه `starter`). پوشه `starter` را کنار همین پوشه کپی کنید و فقط `ex-n.js` را بنویسید. در همه تمرین‌ها **با عدد حساب کنید** و فقط موقع نمایش با `toLocaleString("fa-IR")` به متن فارسی تبدیل کنید. پاسخ نمونه در پوشه `solution` است.

---

## تمرین ۱ — قیمت‌ها از روی داده ⭐

**هدف:** نوشتن یک تابع قالب‌بندی (`formatPrice`) و استفاده از آن برای همه کارت‌ها.

**صورت مسئله:** طراح جای قیمت را در کارت‌ها خالی گذاشته (`<p class="price"></p>`) تا قیمت همیشه از `data-price` نوشته شود و هیچ‌وقت با داده اختلاف نداشته باشد.

**الزامات:**
- تابع `formatPrice(number)`: `420000` ← «۴۲۰٬۰۰۰ تومان»؛ و اگر عدد `0` بود ← «رایگان».
- برای هر `.dish`، قیمت از `dataset.price` خوانده و در `.price` همان کارت نوشته شود.

**تست‌ها:**
- کارت کوبیده ← «۴۲۰٬۰۰۰ تومان»
- کارت دوغ ← «۴۵٬۰۰۰ تومان»
- در Console: `formatPrice(0)` ← «رایگان»
- اگر در HTML `data-price` چای را `0` کنید ← کارت چای «رایگان»

## تمرین ۲ — فاکتور سفارش ⭐⭐

**هدف:** محاسبه **جمع ردیف** و **جمع کل** از آرایه‌ای از اشیا.

**صورت مسئله:** پیشخدمت فاکتور میز ۷ را می‌خواهد. سفارش میز در JS به شکل یک آرایه آماده است.

**الزامات:**
- این آرایه را در کد بگذارید:
  `[{ name: "چلوکباب کوبیده", price: 420000, qty: 2 }, { name: "سالاد شیرازی", price: 75000, qty: 1 }, { name: "دوغ محلی", price: 45000, qty: 3 }]`
- برای هر قلم یک `li` در `#invoice`: «چلوکباب کوبیده — ۲ × ۴۲۰٬۰۰۰ = ۸۴۰٬۰۰۰ تومان».
- `#count`: «تعداد اقلام: ۶» (جمع `qty`ها) و `#total`: «جمع کل: ۱٬۰۵۰٬۰۰۰ تومان».
- جمع‌ها با عدد حساب شوند (یک حلقه، دو متغیر `total` و `count`).

**تست‌ها:**
- سه ردیف؛ ردیف دوغ: «دوغ محلی — ۳ × ۴۵٬۰۰۰ = ۱۳۵٬۰۰۰ تومان»
- «تعداد اقلام: ۶»
- «جمع کل: ۱٬۰۵۰٬۰۰۰ تومان»

## تمرین ۳ — فاکتور با تخفیف، مالیات و هزینه ارسال ⭐⭐⭐

**هدف:** نوشتن یک تابع **محاسبه خالص** (فقط عدد می‌گیرد و عدد برمی‌گرداند) و جدا کردن آن از نمایش.

**صورت مسئله:** سفارش بیرون‌بر چند قاعده دارد:
- کد تخفیف `NARANJ10` (بزرگی و کوچکی حروف مهم نیست) ۱۰٪ از جمع اقلام کم می‌کند.
- مالیات ۱۰٪ مبلغ **بعد از تخفیف** است (با `Math.round`).
- هزینه ارسال ۴۰٬۰۰۰ تومان است، مگر مبلغ بعد از تخفیف ۵۰۰٬۰۰۰ تومان یا بیشتر باشد (رایگان).

**الزامات:**
- سفارش: `[{ name: "چلوکباب کوبیده", price: 420000, qty: 1 }, { name: "دوغ محلی", price: 45000, qty: 2 }]`؛ اقلام در `#items` نمایش داده شوند.
- تابع `calculateInvoice(subtotal, hasDiscount)` یک شیء `{ discount, tax, delivery, total }` برگرداند و هیچ کاری با DOM نکند.
- فرم کد تخفیف (`submit` + `preventDefault`)؛ کد با `trim().toUpperCase()` بررسی شود. کد درست ← «✔ کد تخفیف اعمال شد.» (کلاس `success`)، کد غلط ← «کد تخفیف معتبر نیست.» (کلاس `error`).
- پنج خانه جدول (`#subtotal`، `#discount`، `#tax`، `#delivery`، `#total`) با رقم فارسی؛ ارسال صفر ← «رایگان».

**تست‌ها:**
- بدون کد ← جمع اقلام ۵۱۰٬۰۰۰، تخفیف ۰، مالیات ۵۱٬۰۰۰، ارسال «رایگان»، قابل پرداخت **۵۶۱٬۰۰۰ تومان**
- کد ` naranj10 ` ← تخفیف ۵۱٬۰۰۰، مالیات ۴۵٬۹۰۰، ارسال ۴۰٬۰۰۰، قابل پرداخت **۵۴۴٬۹۰۰ تومان** (چون بعد از تخفیف زیر ۵۰۰٬۰۰۰ شد)
- کد `ABC` ← «کد تخفیف معتبر نیست.» و همان اعداد حالت بدون کد

## اشتباه‌های رایج این مبحث

- جمع زدن متن‌های فارسی («۴۲۰٬۰۰۰») به جای عدد؛ `toLocaleString` فقط در آخرین قدم.
- `parseInt("۴۲۰٬۰۰۰")` نتیجه `NaN` می‌دهد؛ عدد خام را از `data-price` بخوانید.
- گرد نکردن مالیات؛ `45900.00000001` در فاکتور زشت است.
- محاسبه مالیات قبل از تخفیف (ترتیب قاعده‌ها مهم است).
- قاطی کردن محاسبه و نمایش در یک تابع بزرگ؛ تست کردن عددها سخت می‌شود.
