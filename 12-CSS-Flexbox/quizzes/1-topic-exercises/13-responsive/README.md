# تمرین‌های مبحث «Flexbox واکنش‌گرا»

درس مربوط: [Flexbox واکنش‌گرا](../../../pages/13-responsive.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — کارت‌های منعطف بدون media query ⭐

**هدف:** فقط با `flex-wrap` و `flex: 1 1 200px` کارت‌هایی بسازید که خودشان با عرض صفحه کنار بیایند.

**صورت مسئله:**

یک آژانس مسافرتی پنج کارت تور دارد. در لپ‌تاپ چند کارت در هر ردیف، در گوشی یکی‌یکی؛
و این بار **بدون هیچ media query**.

**الزامات:**

- [ ] ظرف `.tours` فلکس با `wrap` و `gap`.
- [ ] کارت‌ها با `flex: 1 1 200px`.
- [ ] در عرض ۳۶۰ پیکسل هیچ اسکرول افقی نباشد.
- [ ] در فایل هیچ `@media` نباشد.

**خروجی مورد انتظار:**

```
لپ‌تاپ:  [ tour ] [ tour ] [ tour ] [ tour ]
         [            tour             ]
گوشی:    [ tour ]
         [ tour ]
         ...
```

## تمرین ۲ — ردیف در دسکتاپ، ستون در گوشی ⭐⭐

**هدف:** با **یک** media query، `flex-direction` را در صفحه باریک عوض کنید.

**صورت مسئله:**

بخش «درباره من» یک وبسایت شخصی یک جعبه عکس و یک متن دارد که در دسکتاپ کنار هم‌اند.
در عرض کمتر از ۶۰۰ پیکسل باید **زیر هم** بیایند و عکس تمام‌عرض شود.

**الزامات:**

- [ ] `.about` فلکس با `gap`؛ `.photo` با `flex: 0 0 200px` و `.text` با `flex: 1`.
- [ ] فقط یک `@media (max-width: 600px)`.
- [ ] در media query، `flex-direction: column` شود.
- [ ] عکس از `05-CSS-تصاویر/images/profile.jpg` با مسیر نسبی درست و `alt` مناسب باشد.

**خروجی مورد انتظار:**

```
دسکتاپ:                         گوشی:
+-----------------+-------+     +---------+
| text text text  | photo |     |  photo  |
| text text       |       |     +---------+
+-----------------+-------+     |  text   |
                                +---------+
```

## تمرین ۳ — منویی که از گوشی بیرون می‌زند ⭐⭐⭐

**هدف:** یک سربرگ غیرواکنش‌گرا را با `max-width`، `flex-wrap` و یک media query درست اصلاح کنید.

**صورت مسئله:**

سربرگ یک رستوران در گوشی از صفحه بیرون زده و کل صفحه چپ و راست تکان می‌خورد.
برنامه‌نویس قبلی یک media query هم نوشته که قرار بود منو را در گوشی زیر هم کند، ولی برعکس
در **دسکتاپ** اعمال می‌شود!

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] `width: 900px` به `max-width: 900px` تبدیل شود.
- [ ] سربرگ و منو `flex-wrap: wrap` داشته باشند.
- [ ] شرط media query به `max-width: 600px` اصلاح شود تا فقط در گوشی منو زیر هم شود.
- [ ] در عرض ۳۶۰ پیکسل هیچ اسکرول افقی نباشد.

**خروجی مورد انتظار:**

```
دسکتاپ:  [m5][m4][m3][m2][m1]   LOGO

گوشی:    LOGO
         [ m1 ]
         [ m2 ]
         ...
```

---

## اشتباه‌های رایج این مبحث

- دادن `width` ثابت بزرگ به ظرف؛ در گوشی اسکرول افقی می‌سازد. `max-width` بنویسید.
- قاطی کردن `min-width` و `max-width` در media query؛ `max-width: 600px` یعنی «۶۰۰ و کمتر».
- نوشتن چند media query برای کاری که `flex-wrap` و `flex: 1 1 200px` خودشان انجام می‌دهند.
- فراموش کردن تگ `meta viewport`؛ بدون آن گوشی صفحه را کوچک‌نمایی می‌کند و media query درست کار نمی‌کند.
