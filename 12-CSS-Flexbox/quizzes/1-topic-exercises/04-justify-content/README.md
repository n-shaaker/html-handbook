# تمرین‌های مبحث «تراز در محور اصلی (justify-content)»

درس مربوط: [تراز در محور اصلی (justify-content)](../../../pages/04-justify-content.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — لینک‌های پانویس وسط صفحه ⭐

**هدف:** با `justify-content: center` آیتم‌ها را در محور اصلی وسط بیاورید.

**صورت مسئله:**

پانویس یک سایت سه لینک «اینستاگرام، تلگرام، ایمیل» دارد که باید دقیقاً **وسط** پانویس باشند.

**الزامات:**

- [ ] یک `footer` با کلاس `social` و سه لینک بسازید.
- [ ] لینک‌ها با Flexbox و `justify-content: center` وسط بیایند.
- [ ] از `text-align` یا `margin` خودکار برای وسط‌چین استفاده نکنید.

**خروجی مورد انتظار:**

```
+----------------------------------------+
|        [mail] [telegram] [insta]       |
+----------------------------------------+
```

---

## تمرین ۲ — سربرگ: لوگو راست، منو چپ ⭐⭐

**هدف:** با `space-between` دو آیتم را به دو سر ظرف بفرستید.

**صورت مسئله:**

سربرگ «نانوایی سنگک» یک لوگو و یک منوی سه‌لینکی دارد. لوگو باید کاملاً **سمت راست**
و منو کاملاً **سمت چپ** باشد و هر فضای خالی بینشان بماند.

**الزامات:**

- [ ] `header` فلکس باشد و با `justify-content: space-between` لوگو و `nav` را دو سر بفرستد.
- [ ] لینک‌ها داخل `ul` و `li` باشند و `ul` هم فلکس باشد.
- [ ] `padding` و `margin` پیش‌فرض `ul` صفر شود و علامت لیست حذف شود.
- [ ] از `float` یا عرض ثابت استفاده نکنید.

**خروجی مورد انتظار:**

```
+----------------------------------------------+
| [c] [b] [a]                         [ LOGO ] |
+----------------------------------------------+
```

## تمرین ۳ — سه ردیف با تراز اشتباه ⭐⭐⭐

**هدف:** مقدار درست `justify-content` را برای هر کار انتخاب کنید و جهت راست‌چین را در نظر بگیرید.

**صورت مسئله:**

صفحه یک فروشگاه سه بخش دارد که هیچ‌کدام درست تراز نشده‌اند:
۱. شماره صفحه‌ها باید **وسط** باشند (برنامه‌نویس قبلی `align-items` نوشته بود!).
۲. سه ویژگی فروشگاه باید با فاصله‌های **کاملاً برابر**، حتی از لبه‌ها، پخش شوند.
۳. دکمه‌های «انصراف» و «ذخیره» باید **سمت چپ** فرم باشند.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] شماره صفحه‌ها وسط کادر باشند.
- [ ] ویژگی‌ها با فاصله برابر پخش شوند؛ فاصله از لبه‌ها هم با فاصله بین آن‌ها برابر باشد.
- [ ] دکمه‌ها سمت چپ کادر باشند (یادتان باشد صفحه راست‌چین است).
- [ ] کنار هر اصلاح یک کامنت کوتاه بنویسید که چرا مقدار قبلی غلط بود.

**خروجی مورد انتظار:**

```
|            [1][2][3][4]            |
|   [ f3 ]     [ f2 ]     [ f1 ]   |   <- فاصله‌ها برابر
| [save][cancel]                     |
```

## اشتباه‌های رایج این مبحث

- استفاده از `align-items` برای وسط‌چین افقی در ردیف؛ محور اصلی (افقی) مال `justify-content` است.
- فراموش کردن اینکه در صفحه راست‌چین `flex-start` یعنی **راست** و `flex-end` یعنی **چپ**.
- قاطی کردن `space-between` (بدون فاصله کنار لبه‌ها) با `space-around` و `space-evenly`.
- نوشتن `justify-content` روی آیتم به‌جای ظرف.
