# تمرین‌های مبحث «ترتیب نمایش (order)»

درس مربوط: [ترتیب نمایش (order)](../../../pages/08-order.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — پیشنهاد ویژه، اول ردیف ⭐

**هدف:** با یک `order` منفی، یک آیتم را بدون تغییر HTML اول ردیف بیاورید.

**صورت مسئله:**

در ردیف محصولات یک فروشگاه، «پیشنهاد ویژه امروز» آخرین آیتم HTML است،
ولی فروشنده می‌خواهد **اولین** آیتمی باشد که مشتری می‌بیند (سمت راست).

**الزامات:**

- [ ] ظرف `.products` فلکس با چهار محصول.
- [ ] محصول آخر کلاس `special` بگیرد و با `order: -1` اول بیاید.
- [ ] ترتیب HTML تغییر نکند.
- [ ] محصول ویژه رنگ متفاوت داشته باشد.

**خروجی مورد انتظار:**

```
[ 3 ] [ 2 ] [ 1 ] [ SPECIAL ]      <- ویژه سمت راست
```

---

## تمرین ۲ — سه ستون با ترتیب دلخواه ⭐⭐

**هدف:** با شماره‌های `order` ترتیب نمایش چند آیتم را کامل از نو بچینید.

**صورت مسئله:**

در HTML یک وبلاگ، اول «محتوا»، بعد «تبلیغ» و آخر «منو» آمده تا صفحه‌خوان‌ها اول محتوا را بخوانند.
ولی در صفحه باید از راست به چپ «منو، محتوا، تبلیغ» دیده شود.

**الزامات:**

- [ ] ترتیب HTML: `main`، `aside.ads`، `nav.menu` (این ترتیب را عوض نکنید).
- [ ] با `order: 1` و `2` و `3` ترتیب نمایش را «منو، محتوا، تبلیغ» کنید.
- [ ] منو و تبلیغ عرض ۱۵۰ پیکسل و محتوا عرض ۳۰۰ پیکسل داشته باشد.
- [ ] بین ستون‌ها با `gap` فاصله باشد.

**خروجی مورد انتظار:**

```
+-------+----------------+-------+
|  ads  |    content     | menu  |
+-------+----------------+-------+
```
منو سمت راست، تبلیغ سمت چپ.

## تمرین ۳ — پیام سنجاق‌شده‌ای که آخر می‌آید ⭐⭐⭐

**هدف:** بفهمید `order` مثبت آیتم را به **ته** می‌فرستد و منفی به **سر**.

**صورت مسئله:**

در صندوق پیام یک سایت، «پیام سنجاق‌شده» باید بالای همه باشد و «پیام بایگانی‌شده» پایین همه.
برنامه‌نویس قبلی به اولی `order: 1` داده (فکر کرده یعنی «اول») و به دومی `order: -1`؛ نتیجه دقیقاً برعکس شده.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] پیام سنجاق‌شده بالای همه باشد.
- [ ] پیام بایگانی‌شده پایین همه باشد.
- [ ] بقیه پیام‌ها به ترتیب HTML بمانند.
- [ ] در یک کامنت بنویسید مقدار پیش‌فرض `order` چند است.

**خروجی مورد انتظار:**

```
+------------------+
| pinned           |
| message A        |
| message B        |
| archived         |
+------------------+
```

---

## اشتباه‌های رایج این مبحث

- فکر کردن اینکه `order: 1` یعنی «اول»؛ پیش‌فرض همه صفر است، پس ۱ آیتم را به **آخر** می‌فرستد.
- استفاده از `order` برای ترتیب‌های مهم محتوایی؛ صفحه‌خوان و کلید Tab هنوز ترتیب HTML را دنبال می‌کنند.
- نوشتن `order` روی ظرف؛ این خاصیت مال آیتم‌هاست.
