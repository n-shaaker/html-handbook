# تمرین‌های مبحث «میان‌بُر flex»

درس مربوط: [میان‌بُر flex](../../../pages/10-flex-shorthand.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — چهار جعبه آمار مساوی ⭐

**هدف:** با `flex: 1` چند آیتم را دقیقاً هم‌عرض کنید.

**صورت مسئله:**

بالای پنل یک فروشگاه چهار جعبه آمار هست: «سفارش امروز، مشتری جدید، فروش، موجودی کم».
هر چهار جعبه باید دقیقاً هم‌عرض باشند و کل ردیف را پر کنند.

**الزامات:**

- [ ] ظرف `.stats` فلکس با `gap: 10px`.
- [ ] هر جعبه فقط با `flex: 1` هم‌عرض شود (بدون `width`).
- [ ] هر جعبه یک عدد درشت و یک عنوان کوچک داشته باشد.

**خروجی مورد انتظار:**

```
+--------+ +--------+ +--------+ +--------+
|  24    | |  7     | |  3.5M  | |  2     |
| label  | | label  | | label  | | label  |
+--------+ +--------+ +--------+ +--------+
```

---

## تمرین ۲ — ستون کناری ثابت، محتوای منعطف ⭐⭐

**هدف:** `flex: 0 0 220px` (ثابت) و `flex: 1` (منعطف) را کنار هم به کار ببرید.

**صورت مسئله:**

صفحه تنظیمات یک سایت یک ستون کناری ۲۲۰ پیکسلی دارد که **هرگز** نباید بزرگ یا کوچک شود،
و بخش اصلی باید بقیه عرض را بگیرد.

**الزامات:**

- [ ] `aside` با `flex: 0 0 220px`.
- [ ] `main` با `flex: 1`.
- [ ] با باریک کردن پنجره، فقط `main` باریک شود.
- [ ] در کامنت بنویسید سه عدد `0 0 220px` به ترتیب چه معنایی دارند.

**خروجی مورد انتظار:**

```
+---------------------------+---------+
|           main            |  aside  |
|     (flexible width)      | (220px) |
+---------------------------+---------+
```

## تمرین ۳ — زبانه‌های ناهم‌عرض و آیکون چاق ⭐⭐⭐

**هدف:** فرق `flex: 1`، `flex: auto` و `flex: none` را در عمل تشخیص بدهید.

**صورت مسئله:**

۱. سه زبانه «توضیحات، مشخصات فنی، نظرات کاربران» قرار بود هم‌عرض باشند، ولی زبانه با متن بلندتر پهن‌تر شده.
۲. در کادر هشدار، آیکون باید فقط اندازه خودش باشد و متن بقیه را بگیرد؛ ولی آیکون نصف کادر را گرفته.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] سه زبانه دقیقاً هم‌عرض باشند؛ سه خط طولانی را با یک `flex` کوتاه جایگزین کنید.
- [ ] آیکون هشدار با `flex: none` فقط اندازه محتوای خودش باشد.
- [ ] متن هشدار `flex: 1` بماند و بقیه عرض را بگیرد.

**خروجی مورد انتظار:**

```
[   tab 3   ][   tab 2   ][   tab 1   ]     <- هم‌عرض

+-----------------------------------+---+
| text text text ...                | ! |  <- آیکون کوچک
+-----------------------------------+---+
```

---

## اشتباه‌های رایج این مبحث

- فکر کردن اینکه `flex: 1` و `flex: auto` یکی‌اند؛ اولی basis صفر دارد (هم‌عرض) و دومی basis خودکار (به اندازه محتوا).
- دادن `flex: 1` به آیکون یا دکمه کوچک؛ آن وقت مثل بقیه بزرگ می‌شود.
- نوشتن `flex: 200px` و انتظار عرض ثابت؛ این یعنی `1 1 200px` و هنوز بزرگ و کوچک می‌شود.
