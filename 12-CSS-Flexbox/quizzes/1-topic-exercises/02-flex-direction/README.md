# تمرین‌های مبحث «جهت چیدمان (flex-direction)»

درس مربوط: [جهت چیدمان (flex-direction)](../../../pages/02-flex-direction.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — منوی کناری عمودی ⭐

**هدف:** با `flex-direction: column` آیتم‌ها را زیر هم بچینید.

**صورت مسئله:**

پنل کاربری یک سایت آموزشی یک منوی کناری باریک می‌خواهد که پنج لینکش **زیر هم** باشند.

**الزامات:**

- [ ] یک `nav` با کلاس `side` و پنج لینک داخلش بسازید.
- [ ] `nav` فلکس باشد و با `flex-direction: column` لینک‌ها زیر هم بیایند.
- [ ] عرض منو ۲۰۰ پیکسل و پس‌زمینه‌اش تیره باشد.
- [ ] هر لینک پس‌زمینه و `padding` داشته باشد تا شبیه دکمه شود.

**خروجی مورد انتظار:**

```
+----------+
| [ link ] |
| [ link ] |
| [ link ] |
| [ link ] |
| [ link ] |
+----------+
```
یک ستون باریک ۲۰۰ پیکسلی سمت راست صفحه.

## تمرین ۲ — مراحل سفارش وارونه شده ⭐⭐

**هدف:** فرق `row` با `row-reverse` و `column` با `column-reverse` را در صفحه راست‌چین تشخیص بدهید.

**صورت مسئله:**

صفحه «پیگیری سفارش» یک فروشگاه دو ایراد دارد: مرحله ۱ سمت **چپ** افتاده (باید سمت راست باشد)
و در کارت سفارش، دکمه «جزئیات» بالای تیتر آمده (باید آخر کارت باشد).

**فایل شروع:** `starter/ex-2.html` و `starter/ex-2.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] مرحله «۱. ثبت سفارش» سمت راست و مرحله ۴ سمت چپ باشد.
- [ ] در کارت، ترتیب از بالا به پایین: تیتر، توضیح، دکمه.
- [ ] فقط مقدار `flex-direction` ها را عوض کنید؛ HTML دست نخورد.

**خروجی مورد انتظار:**

```
[ 4 ] [ 3 ] [ 2 ] [ 1 ]      <- مرحله ۱ سمت راست

+--------------+
| title        |
| text         |
| [  button  ] |
+--------------+
```

## تمرین ۳ — کارت پروفایل با جهت‌های تودرتو ⭐⭐⭐

**هدف:** در یک کارت، هم چیدمان ستونی (`column`) و هم ردیفی (`row`) را تودرتو به کار ببرید.

**صورت مسئله:**

کارت پروفایل یک طراح وب باید از بالا به پایین «حرف اول اسم، نام، شغل، آمار» را نشان دهد.
سه آمار (پروژه، دنبال‌کننده، سابقه) **کنار هم** هستند و در هر آمار، عدد **بالای** عنوانش است.

**الزامات:**

- [ ] `.profile` فلکس ستونی با عرض ۲۸۰ پیکسل باشد.
- [ ] `.stats` سه آمار را در یک ردیف بچیند.
- [ ] هر `.stat` خودش فلکس ستونی باشد (عدد بالا، عنوان پایین).
- [ ] متن‌ها با `text-align: center` وسط باشند.

**خروجی مورد انتظار:**

```
+----------------------+
|        [ N ]         |
|      name            |
|      job             |
| [12 ] [340] [ 5 ]    |
| proj  foll  years    |
+----------------------+
```

## اشتباه‌های رایج این مبحث

- فکر کردن اینکه `row-reverse` در صفحه راست‌چین «از راست» شروع می‌کند؛ برعکس است، از **چپ** شروع می‌کند.
- یادتان باشد با `column` جای محور اصلی و فرعی عوض می‌شود.
- نوشتن `flex-direction` بدون `display: flex`؛ هیچ اثری ندارد.
- استفاده از `*-reverse` برای عوض کردن ترتیب محتوای مهم؛ صفحه‌خوان‌ها هنوز ترتیب HTML را می‌خوانند.
