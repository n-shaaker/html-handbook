## تمرین ۱ — نوار جست‌وجو ⭐

**هدف:** با `flex-grow: 1` یک آیتم را وادار کنید فضای خالی ردیف را پر کند.

**صورت مسئله:**

نوار جست‌وجوی یک کتاب‌فروشی یک کادر متن و یک دکمه دارد. دکمه اندازه خودش را دارد
و کادر متن باید **بقیه عرض** را بگیرد، در هر اندازه صفحه.

**الزامات:**

- [ ] یک `form` با کلاس `search`، یک `input` و یک `button`.
- [ ] `input` با `flex-grow: 1` بقیه فضا را بگیرد.
- [ ] به `input` عرض ثابت ندهید.
- [ ] بین کادر و دکمه با `gap` فاصله باشد.

**خروجی مورد انتظار:**

```
+---------------------------------------------+
| [search] [________________________________] |
+---------------------------------------------+
```

## تمرین ۲ — سه ستون با سهم ۱ و ۲ و ۱ ⭐⭐

**هدف:** با `flex-basis: 0` و `flex-grow` های مختلف، ستون‌ها را دقیقاً به نسبت دلخواه تقسیم کنید.

**صورت مسئله:**

صفحه یک خبرگزاری سه ستون دارد: «دسته‌ها»، «خبر اصلی» و «پربازدیدها».
ستون وسط باید دقیقاً **دو برابر** هر کدام از ستون‌های کناری باشد، صرف‌نظر از طول متن‌ها.

**الزامات:**

- [ ] هر سه ستون `flex-basis: 0` داشته باشند.
- [ ] ستون‌های کناری `flex-grow: 1` و ستون وسط `flex-grow: 2`.
- [ ] متن ستون‌ها طول‌های مختلف داشته باشد تا ببینید نسبت به هم نمی‌خورد.
- [ ] در یک کامنت بنویسید چرا `flex-basis: 0` لازم بود.

**خروجی مورد انتظار:**

```
+--------+----------------+--------+
|  1/4   |      2/4       |  1/4   |
+--------+----------------+--------+
```

## تمرین ۳ — لوگوی له‌شده و کارت‌های نیمه‌پر ⭐⭐⭐

**هدف:** با `flex-shrink: 0` جلوی له شدن را بگیرید و با `flex-basis` + `flex-grow` ردیف را پر کنید.

**صورت مسئله:**

در سربرگ یک سایت، وقتی پنجره باریک می‌شود، جعبه لوگو **له** می‌شود و نوشته‌اش دو خط می‌شود.
پایین صفحه هم کارت‌های ۲۰۰ پیکسلی وقتی به ردیف بعد می‌روند، یک فضای خالی زشت کنار ردیف می‌گذارند؛
مدیر می‌خواهد کارت‌ها از ۲۰۰ پیکسل شروع کنند ولی بزرگ شوند تا ردیف پر شود.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] لوگو در هیچ عرضی از ۱۴۰ پیکسل کوچک‌تر نشود (`flex-shrink: 0`).
- [ ] به‌جای `width` کارت‌ها، از `flex-basis: 200px` و `flex-grow: 1` استفاده کنید.
- [ ] در هر ردیف کارت‌ها کل عرض را پر کنند.

**خروجی مورد انتظار:**

```
[links ............] [ LOGO ]       <- لوگو همیشه یک خط و ۱۴۰ پیکسل

[   card   ] [   card   ] [   card   ]
[       card       ] [      card     ]   <- ردیف آخر هم پر است
```

## اشتباه‌های رایج این مبحث

- انتظار تقسیم دقیق با `flex-grow` تنها؛ اگر `flex-basis` صفر نباشد، طول محتوا هم اثر دارد.
- دادن `width` ثابت به آیتمی که نباید له شود و فراموش کردن `flex-shrink: 0`.
- فکر کردن اینکه `flex-grow: 2` یعنی «دو برابر عرض»؛ یعنی دو برابرِ **سهم از فضای خالی**.
- نوشتن هم‌زمان `width` و `flex-basis`؛ در Flexbox `flex-basis` برنده است و خواندن کد را سخت می‌کند.
