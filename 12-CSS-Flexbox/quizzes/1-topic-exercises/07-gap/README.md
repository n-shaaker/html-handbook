## تمرین ۱ — گروه دکمه‌ها با gap ⭐

**هدف:** فاصله بین آیتم‌ها را فقط با `gap` بسازید.

**صورت مسئله:**

نوار ابزار یک ویرایشگر متن چهار دکمه دارد که باید با فاصله ۱۰ پیکسل کنار هم باشند،
بدون اینکه کنار لبه‌های نوار فاصله اضافه بیفتد.

**الزامات:**

- [ ] ظرف `.toolbar` فلکس با چهار `button`.
- [ ] فاصله بین دکمه‌ها فقط با `gap: 10px` باشد؛ هیچ `margin` روی دکمه‌ها ننویسید.
- [ ] نوار پس‌زمینه و `padding` داشته باشد.

**خروجی مورد انتظار:**

```
+-------------------------------------+
| [B]  [I]  [U]  [save]               |   <- فاصله‌ها ۱۰ پیکسل
+-------------------------------------+
```

## تمرین ۲ — فاصله‌های margin به‌هم ریخته ⭐⭐

**هدف:** فاصله‌گذاری با `margin` را با `gap` جایگزین کنید و فرقش را در ردیف‌های wrap ببینید.

**صورت مسئله:**

کارت‌های یک وبلاگ با `margin-left` از هم فاصله گرفته‌اند. حالا آخرین کارت هر ردیف
از لبه چپ فاصله اضافه دارد و بین ردیف‌ها هیچ فاصله‌ای نیست؛ کارت‌ها به هم چسبیده‌اند.

**فایل شروع:** `starter/ex-2.html` و `starter/ex-2.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] `margin-left` کارت‌ها پاک شود.
- [ ] فاصله افقی و عمودی بین کارت‌ها با یک `gap: 20px` ساخته شود.
- [ ] لبه‌های کادر فقط همان `padding` ظرف را داشته باشند.

**خروجی مورد انتظار:**

```
+-------------------------------+
| [card]  [card]  [card]        |
|                               |   <- حالا بین ردیف‌ها هم فاصله هست
| [card]  [card]                |
+-------------------------------+
```

## تمرین ۳ — ابر برچسب و یادداشت با gap‌های جدا ⭐⭐⭐

**هدف:** `row-gap` و `column-gap` را جدا تنظیم کنید و `gap` را در ظرف ستونی هم به کار ببرید.

**صورت مسئله:**

یک کارت یادداشت داریم: تیتر، تاریخ و متن **زیر هم** با فاصله ۶ پیکسل،
و پایینش برچسب‌ها که بینشان افقی ۱۶ و عمودی ۸ پیکسل فاصله است.

**الزامات:**

- [ ] `.note` فلکس ستونی با `gap: 6px` باشد.
- [ ] `.tags` فلکس با `wrap` باشد.
- [ ] برای برچسب‌ها `row-gap: 8px` و `column-gap: 16px` جدا نوشته شود.
- [ ] `margin` تیتر و پاراگراف صفر شود تا فقط `gap` فاصله بسازد.

**خروجی مورد انتظار:**

```
+------------------------------+
| title                        |
| date                         |   <- فاصله‌ها ۶ پیکسل
| text...                      |
| [tag]    [tag]    [tag]      |   <- افقی ۱۶
| [tag]    [tag]               |   <- عمودی ۸
+------------------------------+
```

---

## اشتباه‌های رایج این مبحث

- استفاده هم‌زمان از `gap` و `margin` روی آیتم‌ها؛ فاصله‌ها دوبرابر و ناجور می‌شوند.
- انتظار اینکه `gap` کنار لبه‌های ظرف هم فاصله بگذارد؛ برای لبه‌ها `padding` ظرف لازم است.
- قاطی کردن ترتیب دو مقدار: `gap: 8px 16px` یعنی اول فاصله **ردیف‌ها** بعد فاصله **ستون‌ها**.
- نوشتن `gap` روی آیتم به‌جای ظرف.
