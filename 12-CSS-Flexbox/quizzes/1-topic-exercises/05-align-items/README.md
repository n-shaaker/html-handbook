- فقط از همین درس و درس‌های **قبلی** استفاده کنید.

## تمرین ۱ — سربرگ با وسط‌چین عمودی ⭐

**هدف:** با `align-items: center` آیتم‌های با اندازه متفاوت را عمودی وسط بیاورید.

**صورت مسئله:**

در سربرگ ۸۰ پیکسلی یک کافه، لوگو درشت است و لینک‌ها ریز. الان لینک‌ها به **بالای** سربرگ
چسبیده‌اند و ناجور به نظر می‌رسند. همه باید عمودی وسط باشند.

**الزامات:**

- [ ] سربرگ فلکس با ارتفاع ۸۰ پیکسل باشد.
- [ ] لوگو `font-size: 28px` و لینک‌ها `14px` باشند.
- [ ] لوگو و منو با `space-between` دو سر سربرگ باشند.
- [ ] همه آیتم‌ها با `align-items: center` عمودی وسط باشند.

**خروجی مورد انتظار:**

```
+---------------------------------------------+
|                                             |
|  a  b  c                       BIG LOGO     |   <- همه روی خط وسط
|                                             |
+---------------------------------------------+
```

## تمرین ۲ — پیام ۴۰۴ دقیقاً وسط کادر ⭐⭐

**هدف:** با ترکیب `justify-content` و `align-items` یک جعبه را افقی و عمودی وسط کنید.

**صورت مسئله:**

صفحه «صفحه پیدا نشد» یک کادر ۳۰۰ پیکسلی دارد و پیام خطا باید **دقیقاً وسط** آن باشد؛
هم از چپ و راست، هم از بالا و پایین.

**الزامات:**

- [ ] کادر `.box` ارتفاع ۳۰۰ پیکسل و پس‌زمینه کم‌رنگ داشته باشد.
- [ ] پیام `.message` (یک `div` با تیتر و پاراگراف) افقی و عمودی وسط باشد.
- [ ] فقط از Flexbox استفاده کنید (نه `margin-top` حدسی یا `position`).

**خروجی مورد انتظار:**

```
+------------------------------+
|                              |
|         +----------+         |
|         |   404    |         |
|         +----------+         |
|                              |
+------------------------------+
```

## تمرین ۳ — قیمت ناهم‌تراز و کارت‌های ناهم‌قد ⭐⭐⭐

**هدف:** فرق `baseline`، `center` و `stretch` را بشناسید و برای هر جا مقدار درست را بگذارید.

**صورت مسئله:**

در صفحه یک محصول دو ایراد هست:
۱. در قیمت «۲۵۰ هزار تومان»، عدد درشت است و نوشته‌های کوچک کنارش **کف‌شان** با عدد یکی نیست.
۲. سه کارت نظر مشتری‌ها متن‌های کوتاه و بلند دارند و کارت‌ها **هم‌قد نیستند**.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] کف همه نوشته‌های ردیف قیمت روی یک خط باشد (`baseline`).
- [ ] هر سه کارت نظر هم‌قد بلندترین کارت باشند.
- [ ] به کارت‌ها `height` ثابت ندهید.

**خروجی مورد انتظار:**

```
250 hezar toman  300           <- کف همه نوشته‌ها روی یک خط
___________________________

+------+ +------+ +------+
| ...  | | ...  | | ...  |
|      | | ...  | |      |
|      | | ...  | |      |    <- هر سه هم‌قد
+------+ +------+ +------+
```

## اشتباه‌های رایج این مبحث

- انتظار اثر `align-items` در ظرف بدون ارتفاع اضافه؛ وقتی ظرف هم‌قد آیتم‌هاست، جایی برای جابه‌جایی نیست.
- قاطی کردن محورها: در `flex-direction: column` کار `align-items` **افقی** است.
- دادن `height` ثابت به کارت‌ها برای هم‌قد کردن؛ `stretch` خودش این کار را می‌کند.
- استفاده از `center` برای متن‌های با اندازه مختلف؛ برای هم‌خط شدن کف نوشته‌ها `baseline` درست است.
