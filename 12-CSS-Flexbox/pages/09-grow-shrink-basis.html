۹) رشد، جمع شدن و اندازه پایه

تا اینجا ویژگی‌ها را روی ظرف می‌نوشتیم تا همهٔ آیتم‌ها با هم جابه‌جا شوند. flex-basis، flex-grow و flex-shrink روی خود آیتم نوشته می‌شوند و تعیین می‌کنند آن آیتم، بعد از چیده شدن در محور اصلی، با فضای کم یا زیاد چه کند. مرورگر اول به هر آیتم یک اندازهٔ پایه می‌دهد، بعد اگر جا اضافه ماند آن را بین آیتم‌هایی که اجازهٔ رشد دارند تقسیم می‌کند، و اگر جا کم آمد آیتم‌هایی را که اجازهٔ جمع شدن دارند کوچک می‌کند.

  • flex-basis اندازهٔ اولیهٔ آیتم را در محور اصلی مشخص می‌کند، پیش از آنکه فضای اضافه یا کمبود فضا حساب شود. مقدار auto یعنی همان عرض یا ارتفاعی که خود آیتم از محتوا یا از width گرفته است.
  • flex-grow سهم آیتم از فضای اضافه است. مقدار پیش‌فرض 0 است، یعنی آیتم بزرگ‌تر از اندازهٔ پایه‌اش نمی‌شود. اگر چند آیتم عدد بزرگ‌تر از صفر داشته باشند، فضای خالی به نسبت همان عددها بینشان تقسیم می‌شود.
  • flex-shrink سهم آیتم از جمع شدن است وقتی مجموع اندازه‌های پایه از ظرف بزرگ‌تر باشد. پیش‌فرض 1 است، یعنی آیتم‌ها اجازه دارند کوچک شوند. مقدار 0 این اجازه را می‌گیرد.

مثال ۱: flex-grow: 1 روی یک آیتم

پیش‌فرض همه flex-grow: 0 است، یعنی بزرگ نمی‌شوند. جعبه ۲ با flex-grow: 1 کل فضای خالی را برمی‌دارد:

.box-2 {
  flex-grow: 1;
}

فضای خالی به نسبت عددها تقسیم می‌شود. اینجا جعبه ۲ دو برابر جعبه ۱ و ۳ از فضای خالی سهم می‌گیرد. (دقت کنید: «فضای خالی» دو برابر می‌شود، نه لزوماً کل عرض جعبه.)

مثال ۳: flex-basis — اندازه اولیه

flex-basis مثل width است (در حالت row)، ولی مخصوص Flexbox. مقدار پیش‌فرضش auto است، یعنی «از width یا محتوای خودت استفاده کن». 

.box-1 { flex-basis: 100px; }
.box-2 { flex-basis: 200px; }
.box-3 { flex-basis: 30%; }

مثال ۴: flex-shrink — چه کسی کوچک شود؟

هر سه جعبه flex-basis: 300px دارند، یعنی جمعاً ۹۰۰ پیکسل؛ ولی ظرف فقط ۵۰۰ پیکسل است. پیش‌فرض همه flex-shrink: 1 است، پس به یک اندازه کوچک می‌شوند. جعبه ۱ را با flex-shrink: 0 از کوچک شدن معاف کرده‌ایم: 

.parent { width: 500px; }

.box { flex-basis: 300px; }

.box-1 { flex-shrink: 0; }   /* کوچک نشو */

جعبه ۱ همان ۳۰۰ پیکسل ماند و کمبود جا بین جعبه ۲ و ۳ تقسیم شد. این برای عکس پروفایل یا آیکون‌هایی که نباید له شوند خیلی کاربردی است.

مثال ۵: کاربرد واقعی — نوار جست‌وجوی فروشگاه

.search-bar { display: flex; gap: 8px; }

.search-bar input {
  flex-grow: 1;     /* بقیه فضا مال کادر جست‌وجو */
}

.search-bar .logo,
.search-bar button {
  flex-shrink: 0;   /* لوگو و دکمه له نشوند */
}
🛒 فروشگاه آبی

اشتباه رایج: فکر می‌کنیم flex-grow: 2 یعنی «دو برابر پهن‌تر». flex-grow فقط فضای اضافه را تقسیم می‌کند. اگر محتوای دو جعبه از اول اندازه متفاوتی داشته باشد، نتیجه دقیقاً دو برابر نمی‌شود. برای تقسیم دقیق، flex-basis: 0 بگذارید (درس بعد).

اشتباه رایج: به یک عکس در ردیف فلکس width: 80px می‌دهیم ولی در صفحه باریک له و بیضی می‌شود. دلیلش flex-shrink: 1 پیش‌فرض است؛ با flex-shrink: 0 مشکل حل می‌شود.

ویژگی پیش‌فرض معنی
flex-grow 0 سهم از فضای اضافه (۰ یعنی بزرگ نشو)
flex-shrink 1 سهم از کمبود جا (۰ یعنی کوچک نشو)
flex-basis auto اندازه اولیه در محور اصلی

تمرین: یک «ردیف پیام» شبیه پیام‌رسان‌ها بسازید: عکس کاربر (دایره ۵۰ پیکسلی)، متن پیام و ساعت ارسال. متن پیام باید بقیه فضا را بگیرد (flex-grow) و عکس هیچ‌وقت له نشود (flex-shrink). پنجره را باریک کنید و امتحان کنید.
