۱۴) جمع‌بندی و تمرین

تبریک! همه ابزارهای Flexbox را یاد گرفتید. این صفحه سه بخش دارد: یک چک‌لیست برای وقتی که Flexbox «کار نمی‌کند»، یک جدول مرجع از همه ویژگی‌ها، و چند تمرین که کم‌کم سخت‌تر می‌شوند.

چک‌لیست: وقتی Flexbox کار نمی‌کند

  • display: flex را روی پدر نوشته‌ام، نه روی فرزندها؟
  • آیتم‌هایی که می‌خواهم بچینم، فرزند مستقیم ظرف هستند (نه نوه)؟
  • جهت محور اصلی را می‌دانم؟ (row = افقی، column = عمودی؛ و در صفحه فارسی شروع سمت راست است)
  • برای محور اصلی justify-content و برای محور فرعی align-items نوشته‌ام؟
  • برای وسط‌چینی عمودی، ظرف ارتفاع اضافه (height یا min-height) دارد؟
  • اگر می‌خواهم آیتم‌ها به خط بعد بروند، flex-wrap: wrap نوشته‌ام؟
  • align-content را فقط با wrap و چند خط استفاده کرده‌ام؟
  • به‌جای margin روی همه آیتم‌ها، از gap روی پدر استفاده کرده‌ام؟
  • عکس‌ها و آیکون‌ها flex-shrink: 0 یا flex: none دارند تا له نشوند؟
  • برای عرض ثابت flex: 0 0 ... نوشته‌ام، نه width کنار flex: 1؟
  • با DevTools (کلیک راست ← Inspect) برچسب flex کنار ظرف را زده‌ام تا محورها و فاصله‌ها را ببینم؟

مرور با یک مثال: همه چیز در یک کارت

این کارت سفارش، نیمی از ویژگی‌های دوره را با هم دارد. سعی کنید قبل از خواندن کد، حدس بزنید هر بخش با چه ویژگی‌ای ساخته شده:

.order       { display: flex; flex-direction: column; gap: 10px; }
.order-head  { display: flex; justify-content: space-between; align-items: center; }
.order-item  { display: flex; align-items: center; gap: 10px; }
.order-item .thumb { flex: none; }
.order-item .name  { flex: 1; }
.order-foot  { display: flex; gap: 8px; }
.order-foot .pay   { margin-inline-start: auto; }

جدول مرجع: ویژگی‌های ظرف (پدر)

ویژگی مقدارهای پرکاربرد کار درس
display flex، inline-flex ساختن ظرف فلکس ۱
flex-direction row، row-reverse، column، column-reverse جهت محور اصلی ۲
flex-wrap nowrap، wrap، wrap-reverse اجازه شکستن خط ۳
flex-flow row wrap میان‌بُر جهت + شکستن خط ۳
justify-content flex-start، flex-end، center، space-between، space-around، space-evenly تراز در محور اصلی ۴
align-items stretch، flex-start، flex-end، center، baseline تراز آیتم‌ها در محور فرعی ۵
align-content stretch، flex-start، center، space-between تراز خط‌ها (فقط با wrap) ۶
gap، row-gap، column-gap 10px، 20px 10px فاصله بین آیتم‌ها و خط‌ها ۷

جدول مرجع: ویژگی‌های آیتم (فرزند)

ویژگی مقدارهای پرکاربرد کار درس
order -1، 0، 1 ترتیب نمایش ۸
flex-grow 0، 1، 2 سهم از فضای اضافه ۹
flex-shrink 1، 0 سهم از کمبود جا ۹
flex-basis auto، 200px، 30% اندازه اولیه ۹
flex 1، auto، none، 0 0 200px میان‌بُر grow + shrink + basis ۱۰
align-self مثل align-items تراز یک آیتم در محور فرعی ۱۱
margin auto، margin-inline-start: auto هل دادن یک آیتم در محور اصلی ۱۱

تمرین‌ها (از آسان به سخت)

تمرین ۱ (آسان): یک نوار «ساعت کاری» برای یک کافه بسازید با سه جعبه «شنبه تا چهارشنبه»، «پنج‌شنبه» و «جمعه» که کنار هم و با gap ۱۰ پیکسل باشند و کل گروه وسط صفحه قرار بگیرد.

تمرین ۲ (آسان): یک دکمه «افزودن به سبد» بسازید که داخلش آیکون 🛒 و متن کنار هم و عمودی وسط باشند (inline-flex و align-items). دکمه نباید تمام عرض صفحه را بگیرد.

تمرین ۳ (متوسط): سربرگ یک آموزشگاه: لوگو در شروع خط، چهار لینک کنار آن، و دکمه «ثبت‌نام» در انتهای خط (با margin خودکار). در صفحه باریک لینک‌ها به خط بعد بروند و صفحه اسکرول افقی نخورد.

تمرین ۴ (متوسط): بخش «نظر هنرجوها» با سه نظر به الگوی «عکس + متن». عکس‌ها دایره‌ای ۶۰ پیکسلی باشند و در هیچ عرضی له نشوند. نام هنرجو و تاریخ نظر در یک ردیف، دو سر خط (space-between) باشند.

تمرین ۵ (سخت): صفحه محصولات یک فروشگاه: ۸ کارت محصول که بدون media query در دسکتاپ چهارتایی و در گوشی تکی باشند. هر کارت عکس، نام، قیمت و دکمه «خرید» داشته باشد؛ همه کارت‌های یک ردیف هم‌قد باشند و دکمه‌ها در ته کارت‌ها هم‌خط بمانند، حتی اگر نام محصول‌ها کوتاه و بلند باشد.

تمرین ۶ (سخت): اسکلت کامل یک صفحه «پنل هنرجو»: سربرگ بالا، زیر آن ستون کناری با عرض ثابت ۲۲۰ پیکسل و محتوای اصلی که بقیه عرض را بگیرد، و فوتری که حتی با محتوای کم پایین صفحه بماند. با یک media query در عرض کمتر از ۶۰۰ پیکسل ستون کناری بالای محتوا بیاید. فقط از Flexbox استفاده کنید (نه float، نه position، نه Grid).

اشتباه رایج: همه چیز را با Flexbox می‌سازیم، حتی جدول‌مانندهایی که هم ردیف دارند هم ستون (مثل گالری که باید خانه‌هایش دقیقاً زیر هم باشند). Flexbox برای یک جهت است؛ برای چیدمان دوبعدی از Grid استفاده کنید. این دو با هم دشمن نیستند و در یک صفحه کنار هم کار می‌کنند.

بعد از این تمرین‌ها، سراغ کوییزهای عملی Flexbox بروید و بعد دوره آموزش Grid را شروع کنید.
