۱) آشنایی با Flexbox

قبلاً برای کنار هم چیدن جعبه‌ها از float یا inline-block استفاده می‌کردیم؛ هم کد زیادی لازم داشت و هم وسط‌چین کردن یا هم‌قد کردن ستون‌ها سخت بود. Flexbox (جعبه انعطاف‌پذیر) دقیقاً برای همین ساخته شده: چیدن چند آیتم در یک ردیف یا یک ستون، تقسیم فضای خالی بین آن‌ها و تراز کردنشان، فقط با چند خط CSS.

مثال ۱: بدون Flexbox و با Flexbox

یادآوری Block: div پیش‌فرض بلوکی است → زیر هم می‌آید. Block / Inline · display

عنصر div به‌طور پیش‌فرض display: block است. هر بلوک عرض موجود را کامل می‌گیرد و عنصر بعدی را به خط بعد می‌فرستد، برای همین سه جعبهٔ زیر، بدون هیچ چیدمان اضافه‌ای، زیر هم دیده می‌شوند نه کنار هم. 

.box {
  padding: 10px;
  /* هیچ چیدمان خاصی نداریم */
}

چیدمان را روی خود جعبه‌ها عوض نمی‌کنیم. فقط به عنصر پدر، یعنی همان عنصری که این سه جعبه فرزند مستقیم او هستند، display: flex می‌دهیم. از این لحظه پدر ظرف فلکس می‌شود و فرزندانش را در یک ردیف، از شروع خط، کنار هم می‌چیند. 

.parent {
  display: flex;
}

فرزندها کنار هم نشستند، چون ظرف حالا آن‌ها را در محور اصلی، پشت سر هم، می‌چیند. هر کدام فقط به اندازهٔ محتوای خودش پهن است، زیرا مقدار پیش‌فرض flex-grow صفر است و آیتم فضای خالی را برنمی‌دارد. این رفتار را در درس رشد و جمع‌شدن عوض می‌کنیم؛ فعلاً مهم است ببینید display: flex به‌تنهایی آیتم‌ها را هم‌عرض نمی‌کند.

مثال ۲: ظرف (Container) و آیتم (Item)

در Flexbox همیشه دو نقش داریم: عنصری که display: flex می‌گیرد ظرف فلکس است، و فرزندان مستقیم آن آیتم‌های فلکس هستند. نوه‌ها آیتم نیستند و مثل قبل رفتار می‌کنند. 

<div class="parent">          <!-- ظرف فلکس -->
  <div class="box">۱</div>    <!-- آیتم -->
  <div class="box">           <!-- آیتم -->
    <span>نوه</span>          <!-- آیتم نیست -->
  </div>
</div>

قاعده ساده: ویژگی‌هایی مثل display: flex، flex-direction، justify-content و gap روی پدر نوشته می‌شوند؛ ویژگی‌هایی مثل flex-grow، order و align-self روی فرزند.

مثال ۳: محور اصلی و محور فرعی

هر ظرف فلکس دو محور دارد: محور اصلی (main axis) جهتی است که آیتم‌ها پشت سر هم چیده می‌شوند (در حالت عادی افقی)، و محور فرعی (cross axis) عمود بر آن است (در حالت عادی عمودی). بیشتر ویژگی‌های Flexbox می‌گویند «در کدام محور» چه اتفاقی بیفتد. 

.parent {
  display: flex;
  height: 140px;   /* تا محور فرعی (عمودی) دیده شود */
}

مثال ۴: راست‌چین بودن صفحه، شروع محور را عوض می‌کند

در صفحه انگلیسی (dir="ltr") شروع محور اصلی سمت چپ است و جعبه ۱ سمت چپ می‌نشیند. صفحه ما فارسی و dir="rtl" است؛ پس شروع محور اصلی سمت راست است و جعبه ۱ سمت راست می‌آید. CSS هیچ فرقی نکرده، فقط جهت نوشتار فرق کرده: 

.parent { display: flex; }

<div class="parent" dir="rtl"> ... </div>   <!-- ۱ سمت راست -->
<div class="parent" dir="ltr"> ... </div>   <!-- 1 سمت چپ -->

برای همین در این دوره به‌جای «چپ و راست» می‌گوییم «شروع» و «پایان». مقدارهایی مثل flex-start و flex-end هم به همین شروع و پایان اشاره دارند، نه به چپ و راست.

مثال ۵: inline-flex

display: flex ظرف را مثل یک block تمام‌عرض می‌کند. اگر بخواهید خود ظرف فقط به اندازه محتوایش باشد و کنار متن بنشیند، از inline-flex استفاده کنید (مثلاً برای یک دکمه که آیکون و متن دارد): 

.badge {
  display: inline-flex;
}

سفارش شما ✓ثبت شد و به‌زودی ارسال می‌شود.

اشتباه رایج: display: flex را روی خود جعبه‌ها (فرزندها) می‌نویسیم و تعجب می‌کنیم که چرا کنار هم نمی‌آیند. display: flex همیشه روی پدر نوشته می‌شود و فرزندانش را می‌چیند، نه خودش را.

اصطلاح معنی
ظرف فلکس (flex container) عنصری که display: flex یا inline-flex دارد
آیتم فلکس (flex item) هر فرزند مستقیم ظرف فلکس
محور اصلی (main axis) جهتی که آیتم‌ها پشت سر هم چیده می‌شوند؛ پیش‌فرض: افقی، از راست در صفحه فارسی
محور فرعی (cross axis) عمود بر محور اصلی؛ پیش‌فرض: عمودی، از بالا به پایین

تمرین: یک نوار با چهار جعبه به نام‌های «قهوه»، «چای»، «کیک» و «بستنی» برای منوی یک کافه بسازید. اول بدون Flexbox ببینید چه می‌شود، بعد با display: flex کنار هم بچینیدشان. سپس روی پدر dir="ltr" بگذارید و ببینید ترتیب از کدام سمت شروع می‌شود.
