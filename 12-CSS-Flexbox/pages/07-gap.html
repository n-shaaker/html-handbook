۷) فاصله بین آیتم‌ها (gap)

تا حالا برای فاصله انداختن بین جعبه‌ها به هر کدام margin می‌دادیم. مشکل این است که margin دور همه جعبه‌ها می‌افتد، حتی کنار لبه ظرف. gap (روی پدر) فقط بین آیتم‌ها فاصله می‌گذارد؛ نه کنار لبه‌ها.

مثال ۱: فاصله با margin (روش قدیمی)

دقت کنید جعبه ۱ از لبه راست و جعبه ۴ از لبه چپ هم فاصله گرفته‌اند:

.box {
  margin: 0 10px;
}

مثال ۴: row-gap و column-gap

اگر فاصله بین خط‌ها و فاصله بین ستون‌ها را جدا بخواهید: row-gap فاصله بین ردیف‌ها (عمودی) و column-gap فاصله بین ستون‌ها (افقی) است. میان‌بُرش هم gap: ردیف ستون است: 

.parent {
  display: flex;
  flex-wrap: wrap;
  row-gap: 30px;      /* بین خط‌ها */
  column-gap: 6px;    /* بین ستون‌ها */
  /* یا خلاصه: gap: 30px 6px; */
}

مثال ۵: دکمه‌های یک فروشگاه با gap

.actions {
  display: flex;
  gap: 8px;
}
افزودن به سبد مقایسه علاقه‌مندی‌ها

اشتباه رایج: هم gap روی پدر می‌گذاریم و هم margin روی آیتم‌ها؛ فاصله‌ها دو برابر و نامرتب می‌شوند. در Flexbox برای فاصله بین آیتم‌ها gap را انتخاب کنید و margin را فقط برای موارد خاص (مثل ترفند margin: auto در درس ۱۱) نگه دارید.

اشتباه رایج: gap را روی خود آیتم‌ها می‌نویسیم و انتظار فاصله داریم، اما هیچ فاصله‌ای ساخته نمی‌شود. gap مثل justify-content ویژگی ظرف است و فقط بین آیتم‌های همان ظرف فاصله می‌گذارد.

ویژگی کار
gap: 20px فاصله ۲۰ پیکسل بین همه آیتم‌ها و همه خط‌ها
row-gap فقط فاصله بین خط‌ها (ردیف‌ها)
column-gap فقط فاصله بین آیتم‌های کنار هم
gap: 30px 6px اولی ردیف، دومی ستون

تمرین: نوار «شبکه‌های اجتماعی» پایین سایت یک آموزشگاه را با پنج لینک بسازید. یک بار با margin و یک بار با gap فاصله بدهید و تفاوت لبه‌ها را با DevTools (کلیک راست ← Inspect) ببینید.
