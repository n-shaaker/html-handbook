۱۳) Flexbox واکنش‌گرا (Responsive)

صفحه‌ای که در لپ‌تاپ قشنگ است، در گوشی هم باید خوانا باشد. خبر خوب اینکه Flexbox خودش تا حد زیادی «انعطاف‌پذیر» است: با ترکیب flex-wrap و flex-basis کارت‌ها بدون هیچ media query خودشان را با عرض صفحه تطبیق می‌دهند. هر جا هم لازم شد، یک media query ساده کار را تمام می‌کند. در این درس پنجره مرورگر را باریک و پهن کنید تا تغییرها را ببینید.

مثال ۱: مشکل — کارت‌ها در گوشی له می‌شوند

چهار کارت با flex: 1 و بدون wrap؛ در صفحه باریک هر کارت خیلی باریک و متنش ناخوانا می‌شود:

.cards {
  display: flex;
  gap: 10px;
}

.card {
  flex: 1;
}
۱ لپ‌تاپ
۲ گوشی
۳ هدفون
۴ ساعت هوشمند

مثال ۲: راه‌حل — flex-wrap + flex-basis

به هر کارت می‌گوییم «حداقل حدود ۱۸۰ پیکسل جا بگیر و اگر جا ماند بزرگ شو» (flex: 1 1 180px). هر وقت چهار کارت ۱۸۰ پیکسلی جا نشوند، آخری به خط بعد می‌رود و در گوشی همه زیر هم می‌آیند. بدون media query! 

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.card {
  flex: 1 1 180px;   /* بزرگ شو، کوچک شو، از ۱۸۰ پیکسل شروع کن */
}
۱ لپ‌تاپ
۲ گوشی
۳ هدفون
۴ ساعت هوشمند

مثال ۳: کارت‌های محصول فروشگاه

همان ترفند با کارت‌های واقعی‌تر. چون پنج کارت داریم، در بعضی عرض‌ها کارت آخر تنها در یک خط می‌ماند و پهن می‌شود؛ این رفتار طبیعی flex-grow است:

.products {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.product {
  flex: 1 1 200px;
}

اگر می‌خواهید کارت آخر پهن نشود و همه کارت‌ها دقیقاً هم‌اندازه بمانند، Grid انتخاب بهتری است؛ در دوره آموزش Grid این را می‌بینید.

مثال ۴: یک media query — ردیف در دسکتاپ، ستون در گوشی

چیدمان «محتوا + ستون کناری» در دسکتاپ کنار هم است. وقتی عرض صفحه از ۶۰۰ پیکسل کمتر شد، با یک media query جهت را column می‌کنیم تا زیر هم بیایند: 

.layout {
  display: flex;
  gap: 12px;
}

.main  { flex: 3; }
.aside { flex: 1; }

/* گوشی: زیر هم */
@media (max-width: 600px) {
  .layout {
    flex-direction: column;
  }
}

محتوای اصلی

معرفی دوره‌های تابستانی آموزشگاه: برنامه‌نویسی وب، طراحی گرافیک و زبان انگلیسی. ثبت‌نام از اول تیر شروع می‌شود.

اطلاعیه

کلاس‌ها حضوری و آنلاین برگزار می‌شوند.

مثال ۵: منویی که در گوشی زیر هم می‌آید

لازم نیست برای هر بخش یک @media جدا بنویسید. همان شرط max-width: 600px که ستون کناری را زیر محتوا برد، می‌تواند منو را هم عوض کند. در عرض زیاد، justify-content: center لینک‌ها را در یک ردیف وسط می‌چیند. زیر ۶۰۰ پیکسل، flex-direction: column محور اصلی را عمودی می‌کند تا هر لینک تمام‌عرض و زیر لینک قبلی بیاید. 

.menu {
  display: flex;
  justify-content: center;
  gap: 8px;
}

@media (max-width: 600px) {
  .menu {
    flex-direction: column;
  }
}
خانه دوره‌ها استادها ثبت‌نام

اشتباه رایج: به کارت‌ها width: 25% می‌دهیم و برای هر اندازه صفحه یک media query جدا می‌نویسیم (۵۰٪ برای تبلت، ۱۰۰٪ برای گوشی). با flex-wrap: wrap و flex: 1 1 200px بیشتر این media queryها اصلاً لازم نیست.

اشتباه رایج: <meta name="viewport" ...> را در head فراموش می‌کنیم؛ گوشی صفحه را مثل دسکتاپ کوچک‌شده نشان می‌دهد و هیچ media queryای اجرا نمی‌شود.

هدف روش
کارت‌ها خودکار به خط بعد بروند flex-wrap: wrap روی پدر + flex: 1 1 200px روی کارت
ردیف در دسکتاپ، ستون در گوشی flex-direction: column داخل @media (max-width: 600px)
کارت‌ها در گوشی از کادر بیرون نزنند عرض ثابت (width) ندهید؛ از flex-basis و max-width: 100% استفاده کنید

تمرین: صفحه «تیم ما» یک آموزشگاه را با ۶ کارت استاد بسازید که در دسکتاپ سه‌تایی، در تبلت دوتایی و در گوشی تکی باشند، فقط با flex-wrap و flex-basis (بدون media query). بعد یک سربرگ اضافه کنید که با یک media query در گوشی ستونی شود.
