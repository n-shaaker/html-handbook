۱۰) میان‌بُر flex

در عمل کمتر پیش می‌آید سه ویژگی درس قبل را جدا بنویسند. ویژگی flex روی آیتم، هر سه را در یک اعلان جمع می‌کند. ترتیب مقدارها ثابت است: اول flex-grow، بعد flex-shrink، و آخر flex-basis. اگر عددی تنها بنویسید، مشخصات CSS آن را رشد حساب می‌کند، جمع شدن را 1 می‌گذارد و پایه را 0% می‌گیرد. برای همین flex: 1 برابر است با 1 1 0%، نه با «یک واحد از عرض محتوا». 

flex: grow shrink basis;

/* مثال: */
flex: 1 1 200px;   /* grow: 1 ، shrink: 1 ، basis: 200px */

چهار میانبر اسم‌دار آن‌قدر تکرار می‌شوند که بهتر است رفتارشان را، نه فقط اسمشان را، به خاطر بسپارید. flex: 1 آیتم‌ها را هم‌اندازه می‌کند، flex: auto اول به محتوا جا می‌دهد و بعد فضای باقی‌مانده را تقسیم می‌کند، flex: none اندازه را قفل می‌کند، و flex: 0 0 200px یک عرض مشخص می‌سازد که نه رشد می‌کند و نه جمع می‌شود.

مثال ۱: flex: 1 — همه هم‌اندازه

flex: 1 در مشخصات CSS برابر است با 1 1 0%. چون اندازهٔ پایه صفر است، عرض محتوا در تقسیم اولیه حساب نمی‌شود و کل عرض ظرف به‌عنوان فضای اضافه، به سهم برابر، بین آیتم‌ها تقسیم می‌شود. برای همین همهٔ آیتم‌ها دقیقاً هم‌عرض می‌شوند، حتی اگر متن یکی کوتاه و متن دیگری بلند باشد: 

.box {
  flex: 1;
}

مثال ۲: flex: auto — بزرگ شو، ولی به اندازه محتوایت

flex: auto یعنی 1 1 auto. اول هر آیتم به اندازه محتوایش جا می‌گیرد، بعد فضای باقی‌مانده تقسیم می‌شود؛ پس آیتمی که متن بیشتری دارد، پهن‌تر می‌ماند. با مثال ۱ مقایسه کنید: 

.box {
  flex: auto;
}

مثال ۳: flex: none — دست به من نزن!

flex: none یعنی 0 0 auto: نه بزرگ می‌شود، نه کوچک. جعبه ۱ اینجا همیشه اندازه خودش را دارد و بقیه با flex: 1 فضا را تقسیم می‌کنند: 

.icon { flex: none; }
.box  { flex: 1; }

مثال ۴: flex: 0 0 200px — عرض ثابت

ستونی که همیشه دقیقاً ۲۰۰ پیکسل است؛ مثل ستون کناری (سایدبار) یک پنل مدیریت. ستون دیگر با flex: 1 بقیه را پر می‌کند: 

.sidebar { flex: 0 0 200px; }
.content { flex: 1; }
پنل آموزشگاه داشبورد دوره‌ها هنرجویان
خوش آمدید!

این ستون هر چقدر پنجره پهن یا باریک شود، فضای باقی‌مانده را می‌گیرد؛ ولی ستون کناری همیشه ۲۰۰ پیکسل است.

مثال ۵: نسبت‌ها با flex

چون flex: 2 برابر 2 1 0% است، پایهٔ همه صفر می‌ماند و فقط نسبت رشد فرق می‌کند. اینجا ستون وسط دو سهم می‌گیرد و هر ستون کناری یک سهم:

.side { flex: 1; }
.main { flex: 2; }
۱ (یک سهم)
۲ (دو سهم)
۳ (یک سهم)

اشتباه رایج: هم width: 200px و هم flex: 1 روی یک آیتم می‌نویسیم و تعجب می‌کنیم که چرا عرضش ۲۰۰ نیست. در flex: 1 مقدار basis صفر است و flex-basis بر width برتری دارد. برای عرض ثابت از flex: 0 0 200px استفاده کنید.

اشتباه رایج: flex را روی پدر می‌نویسیم (مثلاً .parent { flex: 1; }) و انتظار داریم بچه‌ها هم‌اندازه شوند. flex مال آیتم است؛ پدر display: flex می‌گیرد و هر فرزند flex: 1.

میان‌بُر برابر با کاربرد
flex: 1 1 1 0 ستون‌های کاملاً هم‌عرض
flex: auto 1 1 auto پر کردن فضا با حفظ اندازه محتوا
flex: none 0 0 auto آیکون، عکس و دکمه‌ای که نباید تغییر کند
flex: 0 0 200px — ستون با عرض ثابت
پیش‌فرض (ننوشتن) 0 1 auto به اندازه محتوا، در صورت کمبود جا کوچک می‌شود

تمرین: فوتر سایت یک کافه را با سه ستون «درباره ما»، «ساعت کاری» و «نشانی» بسازید که هم‌عرض باشند (flex: 1). بعد ستون «درباره ما» را دو برابر بقیه کنید. در آخر یک ستون لوگو با عرض ثابت ۱۲۰ پیکسل به اول ردیف اضافه کنید.
