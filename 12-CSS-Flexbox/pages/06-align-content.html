۶) تراز خط‌ها (align-content)

وقتی با flex-wrap: wrap آیتم‌ها در چند خط چیده می‌شوند و ظرف ارتفاع اضافه دارد، سؤال پیش می‌آید: خود خط‌ها کجای ظرف باشند؟ align-content (روی پدر) جواب این سؤال است. مقدارهایش شبیه justify-content است، ولی خط‌ها را در محور فرعی جابه‌جا می‌کند.

مهم: align-content فقط وقتی اثر دارد که flex-wrap: wrap باشد و آیتم‌ها واقعاً بیشتر از یک خط شوند. در ظرف تک‌خطی هیچ کاری نمی‌کند.

در همه مثال‌ها ظرف ۲۰۰ پیکسل ارتفاع دارد، پهنایش ۴۰۰ پیکسل است و هفت جعبه ۱۰۰ پیکسلی در سه خط چیده شده‌اند.

مثال ۱: stretch (پیش‌فرض)

فضای اضافه بین خط‌ها تقسیم می‌شود و هر خط کش می‌آید (برای همین بین خط‌ها فاصله افتاده):

.parent {
  display: flex;
  flex-wrap: wrap;
  align-content: stretch;
  height: 200px;
}

مثال ۴: فرق align-items و align-content

align-items: center آیتم‌ها را داخل خط خودشان وسط می‌کند؛ خط‌ها هنوز کل ارتفاع را بین خودشان تقسیم کرده‌اند. align-content: center کل خط‌ها را با هم وسط ظرف جمع می‌کند: 

.a { flex-wrap: wrap; align-items: center; }
.b { flex-wrap: wrap; align-content: center; }

مثال ۵: بدون wrap هیچ اتفاقی نمی‌افتد

  display: flex;
  /* flex-wrap ننوشته‌ایم */
  align-content: flex-end;   /* بی‌اثر */

جعبه‌ها هنوز کل ارتفاع را گرفته‌اند (کار align-items: stretch) و به پایین نرفته‌اند. اینجا باید از align-items: flex-end استفاده کرد.

اشتباه رایج: در یک ردیف تک‌خطی align-content: center می‌نویسیم تا آیتم‌ها عمودی وسط شوند و کار نمی‌کند. برای تک‌خط از align-items استفاده کنید؛ align-content مال ظرف چندخطی (با wrap) است.

ویژگی چه چیزی را جابه‌جا می‌کند؟ کی کار می‌کند؟
align-items آیتم‌ها داخل خط خودشان همیشه
align-content کل خط‌ها داخل ظرف فقط با flex-wrap: wrap و بیش از یک خط

تمرین: یک «دیوار عکس» برای یک کافه بسازید: ظرف ۳۰۰ پیکسل ارتفاع و ۱۰ مربع رنگی ۸۰ پیکسلی. align-content را یکی‌یکی روی flex-start، center، space-between و space-around بگذارید. بعد flex-wrap را بردارید و توضیح دهید چرا دیگر هیچ کدام اثر ندارد.
