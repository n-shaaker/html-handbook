۳) شکستن خط (flex-wrap)

به‌طور پیش‌فرض Flexbox همه آیتم‌ها را در یک خط نگه می‌دارد، حتی اگر جا نشوند. با flex-wrap (روی پدر) اجازه می‌دهیم آیتم‌های اضافه به خط بعد بروند؛ درست مثل کلمه‌های یک پاراگراف.

مثال ۱: nowrap (پیش‌فرض)

هشت جعبه با عرض ۱۵۰ پیکسل در ظرفی که جای همه‌شان را ندارد. Flexbox جعبه‌ها را باریک‌تر می‌کند تا در یک خط بمانند:

.parent {
  display: flex;
  flex-wrap: nowrap;
}

.box { width: 150px; }

اگر محتوای جعبه‌ها هم جا نشود (مثلاً یک کلمه بلند یا عکس)، از ظرف بیرون می‌زنند و صفحه اسکرول افقی می‌خورد.

مثال ۲: wrap

حالا هر جعبه عرض واقعی ۱۵۰ پیکسل خودش را دارد و هر وقت جا تمام شد، بقیه به خط بعد می‌روند. پنجره را باریک و پهن کنید:

.parent {
  display: flex;
  flex-wrap: wrap;
}

مثال ۳: wrap-reverse

wrap-reverse هم مثل wrap اجازه می‌دهد آیتم‌های اضافه به خط بعد بروند، اما جهت محور فرعی را برمی‌گرداند. در حالت ردیف، خط‌های بعدی به‌جای پایین، بالای خط اول ساخته می‌شوند. ترتیب آیتم‌ها در هر خط همان ترتیب شروع به پایان است؛ فقط جای خود خط‌ها عوض شده است. 

.parent {
  display: flex;
  flex-wrap: wrap-reverse;
}

wrap-reverse را وقتی لازم دارید که آخرین خط باید به لبهٔ شروع محور فرعی بچسبد، مثلاً یک ردیف برچسب که باید از پایین ظرف به بالا پر شود. در چیدمان‌های معمولی، مثل کارت و منو، wrap همان رفتاری است که خواننده انتظار دارد: خط بعد پایین خط قبل بیاید.

مثال ۴: میان‌بُر flex-flow

flex-flow میانبر دو ویژگی ظرف است: اول flex-direction و بعد flex-wrap. نوشتن flex-flow: row wrap یعنی محور اصلی افقی بماند و اگر جا کم شد آیتم‌ها به خط بعد بروند. اگر یکی از دو مقدار را ننویسید، همان یکی به مقدار اولیه‌اش برمی‌گردد؛ پس flex-flow: wrap جهت را هم به row برمی‌گرداند. 

/* این دو کد یکی هستند */
.parent {
  flex-direction: row;
  flex-wrap: wrap;
}

.parent {
  flex-flow: row wrap;
}

مثال ۵: برچسب‌های یک فروشگاه

تعداد برچسب‌ها از قبل معلوم نیست و ممکن است در یک خط جا نشوند. با flex-wrap: wrap هر برچسب به اندازهٔ متن خودش می‌ماند و هر کدام که در عرض ظرف جا نشد به خط بعد می‌رود، بدون اینکه برچسب‌ها را باریک یا از صفحه خارج کند. 

.tags {
  display: flex;
  flex-wrap: wrap;
}
کفش ورزشی کوله‌پشتی لباس کوهنوردی کیسه خواب چادر مسافرتی قمقمه چراغ‌قوه عینک آفتابی دستکش

اشتباه رایج: به آیتم‌ها width می‌دهیم و انتظار داریم به خط بعد بروند، ولی همه در یک خط فشرده می‌شوند. بدون flex-wrap: wrap روی پدر، Flexbox هیچ‌وقت خط را نمی‌شکند؛ فقط آیتم‌ها را جمع می‌کند.

مقدار رفتار
nowrap همه در یک خط؛ آیتم‌ها جمع می‌شوند یا بیرون می‌زنند (پیش‌فرض)
wrap آیتم‌های اضافه به خط بعد (پایین‌تر) می‌روند
wrap-reverse آیتم‌های اضافه به خط بالاتر می‌روند
flex-flow: row wrap میان‌بُر جهت + شکستن خط

تمرین: برای یک کتاب‌فروشی ۱۲ «کارت کتاب» با عرض ۱۸۰ پیکسل بسازید. یک بار بدون flex-wrap و یک بار با flex-wrap: wrap نتیجه را ببینید و پنجره را باریک کنید. بعد همان را با flex-flow بنویسید.
