## صورت مسئله

رستوران نارنج می‌خواهد منوی سایتش را مرتب کند. قرار است بعداً ده‌ها غذا اضافه شود، پس طراح یک **کامپوننت کارت غذا** می‌خواهد: یک ساختار HTML ثابت و یک دسته کلاس CSS که برای هر غذای جدید فقط عکس و متنش عوض شود.
شما باید این کامپوننت را بسازید و برای امتحان، سه کارت «چلوکباب کوبیده»، «چلوجوجه‌کباب» و «چلوخورش قورمه‌سبزی» را نمایش دهید.

|---|---|---|---|---|
| چلوکباب کوبیده | `koobideh.jpg` | دو سیخ کوبیده گوشت گوسفندی روی ذغال، با برنج و گوجه کبابی | ۴۲۰٬۰۰۰ | — |
| چلوجوجه‌کباب | `joojeh.jpg` | سینه مرغ خوابانده در زعفران و لیمو؛ با یا بدون استخوان | ۳۸۰٬۰۰۰ | تند |

## الزامات

1. هر کارت یک `article` است با این ترتیب: عکس، عنوان `h3`، برچسب‌ها (اگر دارد)، توضیح، قیمت.
2. همه کارت‌ها **دقیقاً یک ساختار HTML و یک کلاس اصلی** دارند (مثلاً `dish-card`). تفاوت کارت‌ها فقط در محتوا و کلاس برچسب‌هاست، نه در CSS جداگانه برای هر کارت.
3. عکس‌ها با `img` و `alt` توصیفی (نه فقط نام غذا؛ بگویید در عکس چه دیده می‌شود). عکس‌ها نسبت یکسان داشته باشند (مثلاً ۴:۳) و کش نیایند؛ عکس‌های اصلی نسبت‌های متفاوتی دارند.
4. کامپوننت سه نوع برچسب را پشتیبانی کند: «گیاهی» (سبز)، «تند» (قرمز)، «جدید» (زرد با متن تیره). هر برچسب یک کلاس پایه مشترک و یک کلاس رنگ دارد.
5. برچسب‌های هر کارت داخل یک فهرست `ul` باشند، نه چند `span` پراکنده.
6. چون «گیاهی» در این سه غذا نیست، بالای کارت‌ها یک بخش کوچک «راهنمای برچسب‌ها» بسازید که هر سه برچسب را با توضیحش نشان دهد (با `dl`، `dt`، `dd`).
7. قیمت با **رقم فارسی** و جداکننده هزارگان (`٬`) نوشته شود، به‌علاوه کلمه «تومان».
8. کارت‌ها با **Flexbox** کنار هم بنشینند، در صفحه باریک به خط بعد بروند و حداقل عرض معقولی (حدود ۲۴۰ تا ۲۸۰ پیکسل) داشته باشند.
9. همه کارت‌های یک ردیف هم‌قد باشند و **قیمت همیشه پایین کارت** بچسبد، حتی اگر توضیح یکی کوتاه‌تر است.
10. ظاهر با رنگ‌های نارنج (جدول در README اصلی پوشه quizzes) هماهنگ باشد: زمینه سفید کارت، حاشیه کرم، گوشه گرد، قیمت نارنجی و پررنگ.

## محدودیت‌ها

- بدون JavaScript، بدون `style` درون‌خطی، بدون `!important`.
- از Grid استفاده نکنید (این پروژه Flexbox است).
- ارتفاع ثابت به کارت یا بخش متن ندهید.
- از کد پروژه اصلی کپی نکنید.

## امتیازی (تا ۲ نمره)

- یک کارت چهارم برای «میرزاقاسمی» (`mirza.jpg`، گیاهی، ۱۸۵٬۰۰۰) اضافه کنید و نشان دهید هیچ خط CSS جدیدی لازم نشد.
- برای غذای تخفیف‌دار، قیمت قبلی با `del` و قیمت جدید با `ins` نمایش داده شود.

## نکته استاد

- برای اینکه قیمت پایین کارت بچسبد، خود کارت هم باید یک ظرف flex (ستونی) باشد، نه فقط ردیف کارت‌ها.
- عکس `ghormeh.jpg` تقریباً مربعی و `koobideh.jpg` خیلی پهن است؛ اگر هر دو در کارت یک‌شکل شدند، کارتان درست است.
- اگر کارت تنها در ردیف آخر کل عرض را گرفت، `flex-grow` و `flex-basis` را دوباره نگاه کنید و تصمیم بگیرید این رفتار را می‌خواهید یا نه.
