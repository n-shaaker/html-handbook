# تمرین‌ها و پروژه‌های عملی — پروژه منوی رستوران «نارنج»

پروژه منوی رستوران نارنج را در کلاس با هم ساختیم. حالا وقت آن است که نشان دهید **بدون کمک** می‌توانید تکه‌های آن را از نو بسازید.

تمرین‌ها دو بخش دارند:

1. **بخش ۱ — تمرین‌های مبحثی** (`1-topic-exercises/`): هر بلوک سازنده صفحه نارنج (سربرگ، hero، کارت، چیدمان، جدول، فرم، پرسش‌ها، پاورقی، واکنش‌گرایی) یک پوشه جدا با ۳ تمرین کوتاه (⭐ ← ⭐⭐ ← ⭐⭐⭐). هر تمرین فقط از **همان مبحث و مبحث‌های قبل‌تر** استفاده می‌کند و ۱۰ تا ۲۵ دقیقه وقت می‌گیرد.
2. **بخش ۲ — پروژه‌های ترکیبی** (`2-combined-projects/`): صفحه‌های کامل‌تری که چند مبحث بخش ۱ را **هدفمند** کنار هم می‌گذارند.

هیچ‌کدام JavaScript لازم ندارد؛ فقط HTML و CSS.

## روش کار

**برای هنرجو:**

1. مبحث‌های بخش ۱ را **به ترتیب** حل کنید. هر تمرین «هدف»، «صورت مسئله»، «الزامات» و «تست‌ها» دارد.
2. داخل همین پوشه `quizzes` یک پوشه برای خودتان بسازید و داخلش یک پوشه دیگر (مثلاً `my-work/01-header-nav/`)؛ آن‌وقت مسیر عکس‌ها از فایل HTML و CSS شما مثل پاسخ‌ها `../../../images/koobideh.jpg` می‌شود. (پاسخ‌ها یک سطح پایین‌ترند و از `../../../../images/` استفاده می‌کنند.)
3. فایل‌های `index.html` و `css/style.css` پروژه اصلی را **باز نکنید** و از رویشان کپی نکنید. رنگ‌ها در جدول پایین آمده‌اند.
4. بعد از هر تمرین، بخش «تست‌ها» را یکی‌یکی امتحان کنید: عرض موبایل (حدود ۳۷۵ پیکسل) و دسکتاپ، پیمایش فقط با Tab، و [Validator](https://validator.w3.org/#validate_by_upload).
5. بخش «اشتباه‌های رایج این مبحث» را بعد از حل بخوانید و کارتان را با آن چک کنید.
6. وقتی مباحث یک پروژه بخش ۲ را تمام کردید (جدول پایین)، سراغ آن پروژه بروید.
7. پوشه `solution` را قبل از تمام کردن کار نگاه نکنید.

**برای استاد:**

- پوشه `solution` پاسخ نمونه است و عمداً جزئیاتش با پروژه اصلی فرق دارد. هر پاسخ تمیزی که الزامات را برآورده کند قبول است.
- در پاسخ‌ها فایل CSS کنار فایل HTML است، پس مسیر عکس‌ها `../../../../images/...` است.
- کپی مستقیم از پروژه اصلی (نام کلاس‌ها و ترتیب قوانین یکسان) را نمره ندهید؛ هدف ساختن از نو است.

## نکات نمره‌دهی

- **تمرین‌های مبحثی:** هر تمرین «انجام شد / ناقص» ارزیابی می‌شود. پیشنهاد: ⭐ = ۱ امتیاز، ⭐⭐ = ۲، ⭐⭐⭐ = ۳ (هر مبحث ۶ امتیاز). ملاک: همه الزامات و تست‌ها برقرار است و Validator خطا نمی‌دهد.
- **پروژه‌های ترکیبی:** بارم هر پروژه از **۲۰** است و جدولش در برگه همان پروژه آمده.
- HTML نامعتبر یا غیرمعنایی (مثلاً `div` به‌جای `table` یا `label` جاافتاده) هر مورد **۰٫۵ تا ۱ نمره** کسر دارد.
- `img` بدون `alt` معنادار هر مورد **۰٫۵ نمره** کسر دارد.
- استفاده از `style` درون‌خطی، JavaScript یا `!important` از هر مورد **۲ نمره** کم می‌کند.
- بیش از یک media query در یک فایل CSS، یا اسکرول افقی کل صفحه در موبایل، **۱ نمره** کسر دارد.
- بخش «امتیازی» تا **۲ نمره** اضافه دارد، ولی جمع نمره از ۲۰ بیشتر نمی‌شود.
