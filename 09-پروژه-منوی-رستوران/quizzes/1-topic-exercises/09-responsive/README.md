# مبحث ۹: واکنش‌گرایی (Media Query) — تمرین‌های جداگانه

بخش مرتبط در پروژه: [پیش‌غذا](../../../index.html#starters) (Grid سه‌ستونی که در موبایل تک‌ستونی می‌شود) — و فایل [`css/style.css`](../../../css/style.css) پروژه

قانون این مبحث: **در هر فایل CSS فقط یک media query** با `max-width: 600px`. همه تغییرهای موبایل داخل همان یک بلوک.
برای تست، در DevTools (F12) حالت دستگاه (Ctrl+Shift+M) را روشن کنید و عرض را بین ۳۷۵ و ۱۰۰۰ پیکسل عوض کنید.

## تمرین ۱ — Grid سه‌ستونی در موبایل تک‌ستونی ⭐

**هدف:** تغییر تعداد ستون‌های Grid با یک media query و دانستن نقش متای `viewport`.

**صورت مسئله:** شبکه سه‌ستونی کارت‌ها در گوشی خیلی باریک می‌شود و کارت‌ها خوانا نیستند.

**الزامات:**
- `<meta name="viewport" content="width=device-width, initial-scale=1.0">` در `head` باشد.
- `.dishes-grid` در حالت عادی `repeat(3, 1fr)`.
- در `@media (max-width: 600px)` ستون‌ها `1fr` شوند.
- سه کارت ساده (عکس + تیتر) بسازید.

**تست‌ها / خروجی مورد انتظار:**
- عرض ۱۰۰۰px ← سه ستون؛ عرض ۳۷۵px ← یک ستون.
- اگر متای viewport را بردارید و در حالت دستگاه نگاه کنید، صفحه ریز و دسکتاپی دیده می‌شود (این را امتحان کنید و برگردانید).

## تمرین ۲ — سربرگ و hero در موبایل ⭐⭐

**هدف:** جمع و جور کردن چند بخش (سربرگ، hero، دکمه‌ها) در **یک** media query.

**صورت مسئله:** در گوشی، تیتر hero خیلی بزرگ است، فاصله‌ها زیاد است و دو دکمه کنار هم جا نمی‌شوند.

**الزامات:**
- سربرگ و hero مثل مبحث ۱ و ۲ (سربرگ تیره با منو، hero با عکس و دو دکمه).
- داخل یک `@media (max-width: 600px)`:
  - فاصله داخلی hero از ۹۰px به ۴۰px برسد.
  - `h1` از ۳۲px به ۲۴px برسد.
  - دکمه‌ها `display: block` شوند و تمام‌عرض زیر هم بیایند.
  - لینک‌های منو فاصله داخلی کمتری بگیرند (مثلاً ۲px و ۸px) و فونت ۱۴px.

**تست‌ها / خروجی مورد انتظار:**
- عرض ۳۷۵px ← دکمه‌ها تمام‌عرض زیر هم، تیتر کوچک‌تر، منو در حداکثر دو خط.
- عرض ۱۰۰۰px ← همان ظاهر دسکتاپ.
- فایل CSS فقط **یک** `@media` دارد.

## تمرین ۳ — صفحه کوچک کامل واکنش‌گرا ⭐⭐⭐

**هدف:** واکنش‌گرا کردن چند بخش متفاوت (عکس‌ها، جدول، فرم دوستونه) و جلوگیری از اسکرول افقی.

**صورت مسئله:** یک صفحه کوچک با بخش نوشیدنی (دو عکس + جدول) و فرم رزرو کوتاه داریم. در گوشی، عکس‌ها ریز، جدول از صفحه بیرون زده و فرم دوستونه فشرده است.

**الزامات:**
- دو عکس نوشیدنی در دسکتاپ ۴۸٪ کنار هم؛ در موبایل ۱۰۰٪ زیر هم.
- جدول داخل `div.table-wrap` با `overflow-x: auto` (این قانون **بیرون** media query است و همیشه فعال است).
- فرم در دسکتاپ دوستونه با `display: grid` و `grid-template-columns: 1fr 1fr`؛ در موبایل یک ستون.
- همه تغییرهای موبایل در **یک** media query.
- عکس‌ها هیچ‌وقت از ظرفشان بزرگ‌تر نشوند (`max-width: 100%`).

**تست‌ها / خروجی مورد انتظار:**
- عرض ۳۲۰px: کل صفحه اسکرول افقی ندارد؛ فقط خود جدول (اگر لازم باشد) افقی اسکرول می‌خورد.
- عرض ۱۰۰۰px: عکس‌ها کنار هم، فرم دوستونه.

## اشتباه‌های رایج این مبحث

- فراموش کردن متای `viewport`؛ هیچ media queryای در گوشی درست کار نمی‌کند.
- نوشتن چند media query پراکنده برای یک اندازه؛ همه را در یک بلوک جمع کنید.
- گذاشتن media query **قبل از** قانون‌های عادی؛ قانون عادی بعدی آن را بازنویسی می‌کند.
- عرض ثابت پیکسلی (مثلاً `width: 800px`) که در گوشی اسکرول افقی می‌سازد.
- `overflow: hidden` روی `body` برای پنهان کردن اسکرول افقی، به‌جای رفع علت آن.
