# مبحث ۵: جدول نوشیدنی‌ها — تمرین‌های جداگانه

بخش مرتبط در پروژه: [نوشیدنی](../../../index.html#drinks)

## تمرین ۱ — جدول معنایی ⭐

**هدف:** ساختن جدول درست با `caption`، `thead`، `tbody` و `th` با `scope`.

**صورت مسئله:** فهرست قیمت چهار نوشیدنی باید طوری نوشته شود که صفحه‌خوان هم بفهمد هر قیمت مال کدام نوشیدنی است.

| نوشیدنی | توضیح | قیمت (تومان) |
|---|---|---|
| چای سنتی | قوری دونفره، با نبات یا خرما | ۶۰٬۰۰۰ |
| دوغ محلی | با پونه و نعنا | ۴۵٬۰۰۰ |
| شربت بهارنارنج | خنک، بدون گاز | ۵۵٬۰۰۰ |
| دمنوش گل‌گاوزبان | با لیمو عمانی | ۵۰٬۰۰۰ |

**الزامات:**
- `caption` با متن «فهرست قیمت نوشیدنی‌ها».
- سرستون‌ها در `thead` با `th scope="col"`.
- اسم هر نوشیدنی در `tbody` یک `th scope="row"` باشد (نه `td`).
- CSS فقط حاشیه ساده بدهد تا ساختار دیده شود.

**تست‌ها / خروجی مورد انتظار:**
- جدول ۳ ستون و ۴ ردیف داده دارد و عنوانش بالای جدول است.
- Validator خطایی نمی‌دهد.

## تمرین ۲ — جدول خوش‌ظاهر ⭐⭐

**هدف:** استایل جدول با `border-collapse`، رنگ سرستون و ردیف‌های راه‌راه با `nth-child`.

**صورت مسئله:** همان جدول باید با ظاهر نارنج هماهنگ شود.

**الزامات:**
- `table` تمام‌عرض، زمینه سفید و `border-collapse: collapse`.
- `th` و `td`: حاشیه ۱px `#fed7aa`، فاصله داخلی ۱۰px، متن راست‌چین.
- سرستون‌ها (`thead th`): زمینه `#7c2d12` و متن سفید.
- ردیف‌های زوج `tbody` زمینه `#fff7ed` داشته باشند.
- `caption` پررنگ و به رنگ `#7c2d12`.

**تست‌ها / خروجی مورد انتظار:**
- بین خانه‌ها خط دوتایی نیست.
- ردیف ۲ و ۴ کرم‌رنگ‌اند.

## تمرین ۳ — عکس‌ها + جدول با پاورقی ⭐⭐⭐

**هدف:** کنار هم گذاشتن دو عکس با `figure`/`figcaption` و اضافه کردن `tfoot` و ردیف پیشنهادی به جدول.

**صورت مسئله:** بخش نوشیدنی نسخه کامل: بالای جدول دو عکس چای و دوغ کنار هم با یک توضیح مشترک؛ زیر جدول یک ردیف پاورقی که بگوید قیمت‌ها با مالیات است. «شربت بهارنارنج» پیشنهاد امروز است و ردیفش باید متمایز باشد.

**الزامات:**
- `figure` با دو `img` (`tea.jpg` و `doogh.jpg`) هر کدام عرض ۴۸٪، ارتفاع ۲۰۰px، `object-fit: cover` و گوشه گرد، و یک `figcaption`.
- جدول تمرین ۲ به‌اضافه `tfoot` با یک خانه `colspan="3"`: «قیمت‌ها با احتساب ۱۰٪ مالیات است.»
- ردیف بهارنارنج کلاس `today` داشته باشد: زمینه زرد کم‌رنگ و کنار اسمش یک `mark` «پیشنهاد امروز».
- قیمت‌ها داخل `data` با `value` عددی باشند (مثلاً `<data value="55000">۵۵٬۰۰۰</data>`).

**تست‌ها / خروجی مورد انتظار:**
- دو عکس هم‌اندازه کنار هم و توضیح زیرشان وسط‌چین است.
- پاورقی جدول در هر سه ستون پهن شده است.
- ردیف بهارنارنج با بقیه فرق دارد، حتی روی ردیف زوج.

## اشتباه‌های رایج این مبحث

- استفاده از جدول برای چیدمان صفحه؛ جدول فقط برای **داده جدولی** است.
- عنوان جدول با `h3` بیرون جدول به‌جای `caption`.
- نوشتن اسم ردیف با `td`؛ صفحه‌خوان نمی‌فهمد قیمت مال کدام نوشیدنی است.
- فراموش کردن `border-collapse: collapse` و دیدن حاشیه دوتایی.
- اولویت انتخابگرها: `tbody tr:nth-child(even)` از `.today` تنها قوی‌تر است؛ ردیف پیشنهادی را با `tbody tr.today` (هم‌وزن) بنویسید و **بعد از** قانون راه‌راه بگذارید.
