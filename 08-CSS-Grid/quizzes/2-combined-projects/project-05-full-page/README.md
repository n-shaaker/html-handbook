# پروژه ۵: صفحه کامل — Grid برای اسکلت، Flexbox داخل اجزا

- **سطح:** ⭐⭐⭐
- **زمان پیشنهادی:** ۱۲۰ دقیقه
- **هدف پروژه:** یک صفحه کامل و واقعی را **از صفر** بسازید و برای هر بخش ابزار درست را انتخاب کنید: Grid برای اسکلت صفحه، بنر و شبکه کارت‌ها؛ Flexbox برای سربرگ و چیدمان داخل هر کارت.

## صورت مسئله

«آموزشگاه آشپزی سفره» در شیراز یک صفحه اول می‌خواهد با این بخش‌ها:
سربرگ (لوگو، منو، دکمه ثبت‌نام)، بنر بزرگ با عکس غذا و یک جمله معرفی، فهرست دوره‌ها به‌صورت کارت
(عکس، نام، توضیح، قیمت و دکمه)، ستون کناری «اطلاعیه‌ها» و پانویس سه‌بخشی.

```
دسکتاپ:                                        گوشی (کمتر از ۷۰۰ پیکسل):
+---------------------------------------------+   +-----------+
| [signup]            [menu]        LOGO      |   |  header   |
+---------------------------------------------+   +-----------+
|            hero  (box in center)            |   |   hero    |
+----------+----------------------------------+   +-----------+
|  news    |  [card] [card] [card]            |   |   news    |
|          |  [card]                          |   +-----------+
+----------+----------------------------------+   |  courses  |
|  footer 3  |   footer 2   |   footer 1      |   +-----------+
+---------------------------------------------+   |  footer   |
                                                  +-----------+
```

برای عکس‌ها از `05-CSS-تصاویر/images/` (مثلاً `hero.jpg` و `food-1.jpg` تا `food-3.jpg`) با مسیر نسبی درست استفاده کنید.

## الزامات

1. ظرف اصلی `.page` با `grid-template-areas`: سربرگ و بنر تمام‌عرض، دوره‌ها کنار اطلاعیه‌ها (۲۵۰ پیکسل، سمت چپ)، پانویس تمام‌عرض.
2. سربرگ با **Flexbox**: همه عمودی وسط، فاصله با `gap`، و دکمه ثبت‌نام با `margin-inline-start: auto` در انتهای خط.
3. بنر با **Grid** و `place-items: center`؛ عکس پس‌زمینه با `background-size: cover`؛ متن داخل یک کادر سفید خوانا.
4. دوره‌ها با `repeat(auto-fill, minmax(220px, 1fr))`؛ تیتر بخش با `grid-column: 1 / -1` تمام‌عرض.
5. داخل هر کارت با **Flexbox** ستونی؛ ردیف قیمت و دکمه با `margin-top: auto` ته کارت و دو سر.
6. ستون اطلاعیه‌ها با `align-self: start` فقط به اندازه محتوایش باشد (کش نیاید).
7. پانویس با Grid سه ستون مساوی.
8. با **یک** media query: نقشه تک‌ستونی (اطلاعیه‌ها قبل از دوره‌ها)، پانویس تک‌ستونی، دکمه ثبت‌نام دیگر هل داده نشود.

## محدودیت‌ها

- بدون `float` و `position`.
- برای اسکلت صفحه از شماره خط استفاده نکنید؛ فقط نقشه ناحیه‌ها.
- بدون `style` درون‌خطی، JavaScript و `!important`.
- حداکثر یک media query. همه `img` ها `alt` معنادار داشته باشند.

## امتیازی (تا ۲ نمره)

- بالای فایل CSS یک جدول کوچک در کامنت بنویسید: هر بخش صفحه ← Grid یا Flex ← یک جمله دلیل.
- لینک‌ها و دکمه‌ها حالت `:hover` و `:focus-visible` واضح داشته باشند.

## نکته استاد

- قانون ساده: «یک ردیف یا یک ستون؟» ← Flexbox. «ردیف و ستون با هم؟» ← Grid.
- مسیر `url()` در CSS از جای **فایل CSS** حساب می‌شود، نه فایل HTML.
- اگر ستون اطلاعیه‌ها هم‌قد کل بخش دوره‌ها شده، پیش‌فرض `stretch` را با `align-self: start` عوض کنید.
- اول اسکلت را فقط با رنگ پس‌زمینه بسازید؛ وقتی درست بود، محتوای هر بخش را اضافه کنید.
