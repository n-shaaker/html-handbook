## صورت مسئله

«کافه نارنج» یک کافه کوچک در شیراز است و صاحبش یک صفحه ساده می‌خواهد که مشتری‌ها منوی امروز و ساعت کاری را ببینند.
طراح، شکل صفحه را روی کاغذ کشیده و برایتان فرستاده:

```
دسکتاپ:                                  موبایل (کمتر از ۷۰۰ پیکسل):
+--------------------------------------+   +------------------+
|              سربرگ (header)           |   |      سربرگ        |
+-----------+--------------------------+   +------------------+
| ستون کناری |                          |   |      محتوا        |
| (sidebar) |       محتوا (main)        |   +------------------+
|           |                          |   |    ستون کناری     |
+-----------+--------------------------+   +------------------+
|              پانویس (footer)           |   |      پانویس       |
+--------------------------------------+   +------------------+
```

(ستون کناری در صفحه راست‌چین **سمت راست** است.)

صفحه را از صفر بسازید: یک فایل `index.html` و یک فایل `style.css`.

## الزامات

1. ساختار HTML معنایی باشد: `header`، `aside`، `main` و `footer` فرزندهای مستقیم یک عنصر پدر (مثلاً `div.page`) باشند.
2. سربرگ: نام کافه (`h1`) و یک منوی کوچک با سه لینک (منو، درباره ما، تماس).
3. ستون کناری: «ساعت کاری» (شنبه تا پنجشنبه و جمعه) و نشانی کافه.
4. محتوا: تیتر «منوی امروز» و دست‌کم **۶ نوشیدنی/غذا** با اسم و قیمت. خود این لیست هم با Grid در **دو ستون** چیده شود.
5. چیدمان کل صفحه **فقط** با `grid-template-areas` و `grid-area` باشد (نه با شماره خط).
6. ستون کناری با `minmax` بین **۱۸۰ تا ۲۵۰ پیکسل** باشد و محتوا بقیه عرض را بگیرد (`fr`).
7. فاصله بین بخش‌ها فقط با `gap` باشد؛ هیچ بخشی برای فاصله گرفتن از بخش کناری `margin` نداشته باشد.
8. پانویس همیشه ته صفحه باشد، حتی وقتی محتوا کم است (راهنما: ارتفاع حداقل پدر و `grid-template-rows`).
9. در عرض کمتر از **۷۰۰ پیکسل** همه بخش‌ها زیر هم بیایند، به ترتیب: سربرگ، محتوا، ستون کناری، پانویس. لیست منو هم یک‌ستونه شود.
10. کل صفحه حداکثر ۱۱۰۰ پیکسل عرض داشته باشد و وسط صفحه بنشیند.

## محدودیت‌ها

- فقط **یک** `@media` در کل فایل CSS.
- بدون `float`، بدون `position: absolute` برای چیدمان، بدون جدول برای چیدمان.
- بدون JavaScript، بدون `style` درون‌خطی، بدون `!important`.
- ترتیب تگ‌ها در HTML را برای موبایل عوض نکنید؛ تغییر ترتیب فقط با نقشه ناحیه‌ها.

## امتیازی (تا ۲ نمره)

- قیمت هر آیتم منو با Grid یا Flexbox در **انتهای همان ردیف** (سمت چپ) بنشیند و اسم آیتم سمت راست.
- یک آیتم «پیشنهاد ویژه» در لیست منو دو ستون (تمام عرض لیست) بگیرد و در موبایل هم درست دیده شود.

## نکته استاد

- اول نقشه را با گیومه‌ها روی کاغذ بکشید؛ اگر روی کاغذ مستطیل‌ها درست باشند، در CSS هم درست است.
- در media query فقط نقشه را عوض نکنید؛ `grid-template-columns` را هم یک‌ستونه کنید (درس ۱۳، اشتباه رایج).
- برای چسباندن پانویس به پایین، ردیف وسط باید «بقیه ارتفاع» را بگیرد. کدام واحد «بقیه جا» را می‌گیرد؟
