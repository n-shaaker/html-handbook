# پروژه ۴: مجله خبری با خبر ویژه

- **سطح:** ⭐⭐⭐
- **زمان پیشنهادی:** ۹۰ دقیقه
- **هدف پروژه:** صفحه اول یک مجله را با شبکه خودکار `auto-fill` بسازید که یک خبر ویژه ۲×۲ و چند خبر عریض دارد، هیچ سوراخی در آن نمی‌ماند و در گوشی هم بیرون نمی‌زند.

## صورت مسئله

مجله آنلاین «سفره و سفر» هر هفته تعداد متفاوتی خبر دارد. سردبیر گفته:
«نمی‌خواهم برای هر تعداد خبر و هر اندازه صفحه کد جدا بنویسید. خبر ویژه باید بزرگ‌ترین باشد،
بعضی خبرها عریض‌اند، و هیچ خانه خالی وسط صفحه نماند.»

```
+-----+-----+-----------+
|  2  |  1  |           |
+-----+-----+  FEATURED |
|  wide     |   (2x2)   |
+-----+-----+-----+-----+
| ... dense fills holes |
+-----------------------+
```

## الزامات

1. `.magazine` با `repeat(auto-fill, minmax(220px, 1fr))` و `gap`؛ بدون تعداد ستون ثابت.
2. ردیف‌ها با `grid-auto-rows: minmax(220px, auto)` (شبکه ضمنی).
3. `.featured` دو ستون و دو ردیف بگیرد؛ `.wide` دو ستون.
4. با `grid-auto-flow: dense` هیچ سوراخی نماند.
5. هر `.news` خودش یک شبکه کوچک با `gap` باشد؛ برچسب `.category` با `justify-self: start` فقط اندازه متنش باشد (کش نیاید).
6. عکس‌ها `width: 100%`، ارتفاع ثابت و `object-fit: cover` داشته باشند.
7. با **یک** media query (کمتر از ۵۲۰ پیکسل) `span` ها برداشته شوند تا در شبکه تک‌ستونی، ستون اضافه ساخته نشود.

## محدودیت‌ها

- چیدمان شبکه خبرها فقط با Grid؛ بدون Flexbox، `float` و `position`.
- به هیچ خبری شماره خط ثابت (مثل `grid-column: 1 / 3`) ندهید؛ فقط `span`.
- بدون `style` درون‌خطی، JavaScript و `!important`.
- حداکثر یک media query.

## امتیازی (تا ۲ نمره)

- یک خبر «بلند» با `grid-row: span 2` اضافه کنید و نشان دهید `dense` هنوز سوراخی باقی نمی‌گذارد.
- در یک کامنت توضیح بدهید `dense` چه اثری روی ترتیب خواندن خبرها دارد و کی نباید از آن استفاده کرد.

## نکته استاد

- اگر در گوشی صفحه اسکرول افقی خورد، مقصر `span 2` در شبکه‌ای است که فقط یک ستون جا دارد؛ Grid برایش ستون ضمنی می‌سازد.
- اگر برچسب دسته تمام‌عرض شده، یادتان باشد پیش‌فرض آیتم‌های Grid `stretch` است.
- عکس‌ها را اول بدون `object-fit` ببینید تا بفهمید چرا لازم است.
