# تمرین‌های مبحث «auto-fill و auto-fit»

درس مربوط: [auto-fill و auto-fit](../../../pages/09-auto-fit-fill.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — ویترین محصولات بدون media query ⭐

**هدف:** با `repeat(auto-fill, minmax(160px, 1fr))` شبکه‌ای بسازید که خودش تعداد ستون را انتخاب کند.

**صورت مسئله:**

یک فروشگاه هفت محصول دارد. در لپ‌تاپ چند ستون، در تبلت کمتر، در گوشی یک یا دو ستون؛
و هیچ media query نمی‌خواهد.

**الزامات:**

- [ ] `grid-template-columns: repeat(auto-fill, minmax(160px, 1fr))` و `gap`.
- [ ] هفت کارت محصول.
- [ ] هیچ `@media` در فایل نباشد.
- [ ] در عرض ۳۶۰ پیکسل اسکرول افقی نباشد.

**خروجی مورد انتظار:**

```
لپ‌تاپ:  [p][p][p][p][p]
         [p][p]
گوشی:    [p][p]
         [p][p]
         ...
```

---

## تمرین ۲ — auto-fill در برابر auto-fit ⭐⭐

**هدف:** فرق `auto-fill` و `auto-fit` را وقتی آیتم‌ها کم‌اند، با چشم ببینید و توضیح بدهید.

**صورت مسئله:**

دو ردیف بسازید که هرکدام فقط **دو** کارت دارند: یکی با `auto-fill` و یکی با `auto-fit`.
روی صفحه پهن مقایسه کنید کارت‌ها کجا کش می‌آیند.

**الزامات:**

- [ ] دو ظرف `.fill` و `.fit`، هرکدام دو کارت.
- [ ] هر دو با `minmax(150px, 1fr)`؛ اولی `auto-fill`، دومی `auto-fit`.
- [ ] بالای هر ظرف یک تیتر کوچک بگذارید.
- [ ] در کامنت با یک جمله فرقشان را بنویسید.

**خروجی مورد انتظار:**

```
auto-fill:  [ a ][ b ][    ][    ][    ]   <- ستون‌های خالی می‌مانند
auto-fit:   [      a      ][      b      ] <- دو کارت کل عرض را می‌گیرند
```

---

## تمرین ۳ — سه شبکه خودکارِ خراب ⭐⭐⭐

**هدف:** خطاهای رایج `auto-fill`/`auto-fit` را درست کنید: بدون `1fr`، حداقل خیلی بزرگ، و `fr` تنها.

**صورت مسئله:**

در صفحه یک آژانس عکاسی سه شبکه هست:
۱. گالری: کنار ستون‌ها یک نوار خالی زشت می‌ماند.
۲. تیم: در گوشی کارت‌ها از صفحه بیرون می‌زنند.
۳. برچسب‌ها: اصلاً شبکه نمی‌شوند و همه زیر هم‌اند.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] گالری: ستون‌ها کش بیایند و نوار خالی نماند (`minmax(200px, 1fr)`).
- [ ] تیم: در عرض ۳۶۰ پیکسل بیرون نزند (حداقل را ۲۵۰ پیکسل کنید).
- [ ] برچسب‌ها: با `minmax(100px, 1fr)` شبکه درست شود.
- [ ] کنار هر اصلاح کامنت کوتاه بنویسید.

**خروجی مورد انتظار:**

```
گالری:   [   ][   ][   ][   ]   <- تا لبه پر
تیم:     [ member ][ member ]   (در گوشی یکی‌یکی)
برچسب:   [t][t][t][t][t][t]
```

---

## اشتباه‌های رایج این مبحث

- نوشتن `repeat(auto-fit, 1fr)`؛ نامعتبر است، چون مرورگر نمی‌داند حداقل هر ستون چقدر است.
- اندازه ثابت بدون `1fr` (مثلاً `repeat(auto-fill, 200px)`)؛ کنار شبکه نوار خالی می‌ماند.
- حداقل بزرگ‌تر از عرض گوشی در `minmax`؛ صفحه اسکرول افقی می‌خورد.
- فکر کردن اینکه `auto-fill` و `auto-fit` همیشه فرق دارند؛ فقط وقتی آیتم‌ها کم‌اند فرق دیده می‌شود.
