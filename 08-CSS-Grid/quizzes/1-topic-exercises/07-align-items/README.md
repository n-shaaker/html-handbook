# تمرین‌های مبحث «تراز آیتم‌ها داخل خانه»

درس مربوط: [تراز آیتم‌ها داخل خانه](../../../pages/07-align-items.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — آیکون‌ها وسط خانه‌ها ⭐

**هدف:** با `place-items: center` همه آیتم‌ها را وسط خانه خودشان بیاورید.

**صورت مسئله:**

صفحه «خدمات» شش آیکون کوچک دارد که هرکدام در یک خانه ۱۲۰ پیکسلی است.
آیکون‌ها الان کشیده شده‌اند و کل خانه را گرفته‌اند؛ باید کوچک و **وسط خانه** باشند.

**الزامات:**

- [ ] شبکه سه ستون، دو ردیف ۱۲۰ پیکسلی، با `gap`.
- [ ] ظرف `place-items: center` داشته باشد.
- [ ] پس‌زمینه ظرف و آیتم‌ها فرق داشته باشد تا خانه‌ها دیده شوند.

**خروجی مورد انتظار:**

```
+---------+---------+---------+
|         |         |         |
|   (i)   |   (i)   |   (i)   |
|         |         |         |
+---------+---------+---------+
```

---

## تمرین ۲ — قیمت پایین-چپ، برچسب جدید بالا-راست ⭐⭐

**هدف:** تراز همه آیتم‌ها را با `justify-items` و `align-items` و تراز یک آیتم را با `justify-self` و `align-self` تعیین کنید.

**صورت مسئله:**

در ویترین یک شیرینی‌فروشی، برچسب قیمت هر خانه باید **گوشه پایین-چپ** آن باشد.
فقط برچسب «جدید!» استثناست و باید **گوشه بالا-راست** خانه‌اش بنشیند.

**الزامات:**

- [ ] شبکه دو ستون، ردیف‌های ۱۲۰ پیکسلی.
- [ ] ظرف: `justify-items: end` و `align-items: end`.
- [ ] برچسب `.new`: `justify-self: start` و `align-self: start`.
- [ ] در کامنت بنویسید چرا در صفحه راست‌چین `end` یعنی چپ.

**خروجی مورد انتظار:**

```
+------------------+------------------+
|           [new]  |                  |
|                  |                  |
|                  | [price]          |
+------------------+------------------+
```

## تمرین ۳ — کارت‌هایی که آب رفته‌اند ⭐⭐⭐

**هدف:** بفهمید `justify-items`/`align-items` روی **همه** آیتم‌ها اثر دارد و برای یک آیتم باید `*-self` نوشت.

**صورت مسئله:**

سه کارت محصول باید هم‌عرض خانه و **هم‌قد** باشند و فقط لینک «مشاهده همه» که زیرشان تمام‌عرض است،
وسط بیاید. برنامه‌نویس برای وسط کردن همان یک لینک، روی کل شبکه تراز گذاشته
و حالا کارت‌ها باریک و ناهم‌قد شده‌اند.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] کارت‌ها کل عرض و ارتفاع خانه را بگیرند (رفتار پیش‌فرض `stretch`).
- [ ] فقط لینک «مشاهده همه» با `justify-self: center` وسط باشد.
- [ ] هیچ `width` یا `height` به کارت‌ها ندهید.

**خروجی مورد انتظار:**

```
+--------+ +--------+ +--------+
| card   | | card   | | card   |
|        | | long   | |        |   <- هم‌قد و هم‌عرض
|        | | text   | |        |
+--------+ +--------+ +--------+
          view all                <- فقط این وسط
```

---

## اشتباه‌های رایج این مبحث

- گذاشتن `justify-items: center` روی ظرف برای وسط کردن **یک** آیتم؛ همه آیتم‌ها آب می‌روند.
- فراموش کردن اینکه پیش‌فرض `stretch` است و همین آیتم‌ها را هم‌قد و هم‌عرض خانه می‌کند.
- انتظار جابه‌جایی عمودی وقتی ردیف هم‌قد محتواست؛ برای دیدن اثر `align-items` ردیف باید بلندتر باشد.
- فراموش کردن جهت راست‌چین: `start` یعنی راست و `end` یعنی چپ.
