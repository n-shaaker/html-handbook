## تمرین ۱ — منو با Flex، کارت‌ها با Grid ⭐

**هدف:** برای ردیف یک‌بعدی (منو) Flexbox و برای شبکه دوبعدی (کارت‌ها) Grid انتخاب کنید.

**صورت مسئله:**

صفحه اول یک آموزشگاه: بالای صفحه منویی با لینک‌های **طول‌های مختلف**،
و زیرش سه کارت دوره که باید **دقیقاً هم‌عرض** باشند.

**الزامات:**

- [ ] منو با `display: flex` و `gap`.
- [ ] کارت‌ها با `display: grid` و `repeat(3, 1fr)`.
- [ ] در کامنت بالای هر بخش بنویسید چرا این ابزار را انتخاب کردید.

**خروجی مورد انتظار:**

```
[contact] [about us] [courses] [home]

+--------+ +--------+ +--------+
| course | | course | | course |    <- هم‌عرض
+--------+ +--------+ +--------+
```

## تمرین ۲ — ابزار اشتباه برای هر بخش ⭐⭐

**هدف:** تشخیص بدهید کجا Flexbox و کجا Grid ابزار درست است و جایشان را عوض کنید.

**صورت مسئله:**

در صفحه یک فروشگاه:
۱. برچسب‌ها با Grid پنج‌ستونه چیده شده‌اند؛ برچسب‌های کوتاه پهن و برچسب بلند دو خط شده.
۲. کارت‌های محصول با Flexbox چیده شده‌اند؛ کارت تنهای ردیف آخر **کل عرض** را گرفته و با بقیه هم‌عرض نیست.

**فایل شروع:** `starter/ex-2.html` و `starter/ex-2.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] برچسب‌ها با Flexbox و `flex-wrap` به اندازه متنشان باشند.
- [ ] کارت‌ها با Grid و `repeat(auto-fill, minmax(200px, 1fr))` همه هم‌عرض باشند، حتی در ردیف آخر.
- [ ] `flex` اضافه از روی کارت‌ها حذف شود.

**خروجی مورد انتظار:**

```
[short] [a much longer tag] [x] [tag]

[ p ] [ p ] [ p ]
[ p ]                 <- هم‌عرض بقیه، نه تمام‌عرض
```

## تمرین ۳ — Grid بیرون، Flex داخل کارت ⭐⭐⭐

**هدف:** شبکه کارت‌ها را با Grid و چیدمان داخل هر کارت را با Flexbox بسازید.

**صورت مسئله:**

صفحه «دوره‌های آنلاین»: کارت‌ها در یک شبکه خودکار. داخل هر کارت از بالا به پایین:
تیتر، توضیح، و یک ردیف پایینی که **قیمت سمت راست** و **دکمه سمت چپ** دارد.
ردیف پایینی همه کارت‌ها باید هم‌خط، ته کارت باشد.

**الزامات:**

- [ ] `.courses` با `repeat(auto-fill, minmax(220px, 1fr))`.
- [ ] هر `.course` فلکس ستونی؛ `.course-footer` با `margin-top: auto` ته کارت.
- [ ] `.course-footer` فلکس با `justify-content: space-between` و `align-items: center`.
- [ ] دست‌کم یک کارت توضیح بلند داشته باشد.

**خروجی مورد انتظار:**

```
+---------------+ +---------------+
| title         | | title         |
| text          | | long text     |
|               | | long text     |
| [btn]   price | | [btn]   price |   <- هم‌خط
+---------------+ +---------------+
```

---

## اشتباه‌های رایج این مبحث

- استفاده از Grid برای برچسب‌ها و دکمه‌هایی که باید اندازه متنشان باشند؛ Flexbox مناسب‌تر است.
- استفاده از Flexbox با `wrap` برای کارت‌هایی که باید در ستون‌های یکسان بنشینند؛ کارت ردیف آخر کش می‌آید.
- فکر کردن اینکه باید فقط یکی را انتخاب کرد؛ ترکیب Grid بیرون و Flex داخل کاملاً رایج است.
