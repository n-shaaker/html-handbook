# تمرین‌های مبحث «جای‌گذاری آیتم‌ها با شماره خط»

درس مربوط: [جای‌گذاری آیتم‌ها با شماره خط](../../../pages/05-placement.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — تیتر تمام‌عرض ⭐

**هدف:** با `grid-column: 1 / -1` یک آیتم را از اولین تا آخرین خط بکشید.

**صورت مسئله:**

در صفحه «آلبوم عکس»، بالای شش عکس یک تیتر هست که باید **کل عرض** شبکه سه‌ستونه را بگیرد.

**الزامات:**

- [ ] شبکه سه ستون مساوی با `gap`.
- [ ] تیتر (کلاس `title`) با `grid-column: 1 / -1` تمام‌عرض شود.
- [ ] در کامنت بنویسید `-1` یعنی چه.

**خروجی مورد انتظار:**

```
+-------------------------+
|          title          |
+-------+-------+---------+
|   3   |   2   |    1    |
|   6   |   5   |    4    |
+-------+-------+---------+
```

---

## تمرین ۲ — خبر ویژه ۲×۲ ⭐⭐

**هدف:** با `span` یک آیتم را هم در ستون و هم در ردیف بزرگ کنید.

**صورت مسئله:**

صفحه اول یک خبرگزاری چهار ستون دارد. «خبر ویژه» باید دو ستون عرض و دو ردیف ارتفاع داشته باشد
و گوشه بالا-راست صفحه باشد؛ بقیه خبرها خودشان جای خالی‌ها را پر کنند.

**الزامات:**

- [ ] `grid-template-columns: repeat(4, 1fr)` و `grid-template-rows: repeat(3, 100px)`.
- [ ] خبر ویژه با `grid-column: span 2` و `grid-row: span 2`.
- [ ] هفت خبر معمولی بعد از خبر ویژه.

**خروجی مورد انتظار:**

```
+-----+-----+-----------+
|  2  |  1  |           |
+-----+-----+  FEATURED |
|  4  |  3  |           |
+-----+-----+-----+-----+
|     |  7  |  6  |  5  |
+-----+-----+-----+-----+
```

## تمرین ۳ — نقشه پارکینگ با خط‌های اشتباه ⭐⭐⭐

**هدف:** خطاهای «یکی کم/زیاد» در شماره خط‌ها و اشتباه جهت راست‌چین را درست کنید.

**صورت مسئله:**

نقشه یک پارکینگ ۴ ستون و ۳ ردیف دارد. طبق طرح:
ماشین A در ردیف اول، **ستون ۱ و ۲** را بگیرد؛ ماشین B در ستون ۳ تمام **سه ردیف** را بگیرد؛
و تابلوی «خروج» در **گوشه پایین-چپ** باشد. هیچ‌کدام سر جایش نیست.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] ماشین A دقیقاً دو خانه (ستون ۱ و ۲ ردیف اول) را بگیرد.
- [ ] ماشین B از بالا تا پایین ستون ۳ را بگیرد.
- [ ] خروج در گوشه پایین-**چپ** باشد (یادتان باشد ستون ۱ سمت راست است).
- [ ] کنار هر اصلاح کامنت کوتاه بنویسید.

**خروجی مورد انتظار:**

```
+------+------+-------------+
|      |  B   |      A      |
+------+      +------+------+
|      |      |      |      |
+------+      +------+------+
| EXIT |      |      |      |
+------+------+------+------+
```

---

## اشتباه‌های رایج این مبحث

- شمردن خانه‌ها به‌جای خط‌ها: دو ستون اول یعنی `1 / 3`، نه `1 / 2`.
- فراموش کردن اینکه در صفحه راست‌چین ستون ۱ سمت **راست** است.
- استفاده از `-1` در شبکه ضمنی (بدون `grid-template-*`)؛ `-1` فقط تا آخرین خطِ **تعریف‌شده** می‌رود.
- قاطی کردن `span 2` (دو خانه پهنا) با `2` (شروع از خط ۲).
