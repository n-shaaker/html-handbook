درس مربوط: [فاصله بین خانه‌ها (gap)](../../../pages/04-gap.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — گالری با gap ⭐

**هدف:** فاصله بین همه خانه‌ها را با یک `gap` بسازید.

**صورت مسئله:**

یک عکاس شش کار خود را در سه ستون نشان می‌دهد و بین همه کارها، افقی و عمودی، ۱۶ پیکسل فاصله می‌خواهد.

**الزامات:**

- [ ] `grid-template-columns: repeat(3, 1fr)` و `gap: 16px`.
- [ ] هیچ `margin` یا `border` برای فاصله‌گذاری روی آیتم‌ها نباشد.
- [ ] شش جعبه رنگی با ارتفاع ۱۰۰ پیکسل.

**خروجی مورد انتظار:**

```
[ 3 ]  [ 2 ]  [ 1 ]
                      <- 16px
[ 6 ]  [ 5 ]  [ 4 ]
```

---

## تمرین ۲ — قفسه کتاب: فاصله ردیف و ستون جدا ⭐⭐

**هدف:** `row-gap` و `column-gap` را جدا تنظیم کنید و فاصله لبه‌ها را با `padding` بسازید.

**صورت مسئله:**

در صفحه یک کتاب‌فروشی، کتاب‌ها مثل قفسه چیده می‌شوند: کتاب‌های هر ردیف به هم نزدیک‌اند (۱۰ پیکسل)
ولی ردیف‌ها (طبقه‌ها) از هم دورند (۳۰ پیکسل). کتاب‌ها نباید به دیواره قفسه بچسبند.

**الزامات:**

- [ ] شبکه پنج ستون مساوی با ده کتاب.
- [ ] `row-gap: 30px` و `column-gap: 10px`.
- [ ] قفسه `padding: 15px` داشته باشد (چون `gap` کنار لبه‌ها فاصله نمی‌گذارد).
- [ ] در یک کامنت همین را با `gap: 30px 10px` هم بنویسید.

**خروجی مورد انتظار:**

```
+--------------------------------+
| [b][b][b][b][b]                |
|                                |  <- 30px
| [b][b][b][b][b]                |
+--------------------------------+
```

## تمرین ۳ — فاصله‌های دوبرابر و شبکه سرریز ⭐⭐⭐

**هدف:** فاصله‌گذاری با `margin` و ستون‌های درصدی را با `gap` و `fr` جایگزین کنید.

**صورت مسئله:**

در صفحه یک فروشگاه، کارت‌ها فاصله‌های نامساوی دارند: بین کارت‌ها دوبرابر لبه‌هاست.
وقتی برنامه‌نویس `gap` را اضافه کرد، کارت‌ها از سمت چپ کادر **بیرون زدند**!

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] کارت‌ها از کادر بیرون نزنند؛ ستون‌ها را با `repeat(3, 1fr)` بنویسید.
- [ ] `margin` کارت‌ها حذف شود و فاصله فقط با `gap: 20px` باشد.
- [ ] فاصله لبه‌ها با `padding: 20px` روی ظرف ساخته شود.
- [ ] در کامنت بنویسید چرا درصد + `gap` سرریز می‌کند ولی `fr` نه.

**خروجی مورد انتظار:**

```
+-----------------------------------+
|  [card]   [card]   [card]         |   <- همه فاصله‌ها ۲۰
|  [card]   [card]   [card]         |
+-----------------------------------+
```

---

## اشتباه‌های رایج این مبحث

- استفاده هم‌زمان از `gap` و `margin` روی آیتم‌ها؛ فاصله‌ها نامساوی می‌شوند.
- ستون‌های درصدی + `gap`؛ مجموع از ۱۰۰٪ بیشتر می‌شود و شبکه بیرون می‌زند. از `fr` استفاده کنید.
- انتظار فاصله کنار لبه‌ها از `gap`؛ برای لبه‌ها `padding` ظرف لازم است.
- ترتیب دو مقدار `gap`: اول فاصله **ردیف‌ها**، بعد فاصله **ستون‌ها**.
