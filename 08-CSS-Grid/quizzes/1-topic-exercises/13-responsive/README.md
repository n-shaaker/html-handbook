# تمرین‌های مبحث «Grid واکنش‌گرا»

درس مربوط: [Grid واکنش‌گرا](../../../pages/13-responsive.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — اسکلت سایت: کنار هم در دسکتاپ، زیر هم در گوشی ⭐

**هدف:** فقط با عوض کردن `grid-template-areas` در یک media query، چیدمان صفحه را برای گوشی تغییر دهید.

**صورت مسئله:**

وبلاگ «یادداشت‌های سفر» در دسکتاپ ستون کناری دارد. در گوشی (کمتر از ۷۰۰ پیکسل) همه بخش‌ها
باید **زیر هم** باشند: سربرگ، محتوا، ستون کناری، پانویس.

**الزامات:**

- [ ] دسکتاپ: ستون‌ها `200px 1fr` و نقشه سه ردیفه.
- [ ] یک `@media (max-width: 700px)` که ستون‌ها را `1fr` و نقشه را چهار ردیف تک‌نامه کند.
- [ ] HTML و `grid-area` ها در media query عوض نشوند؛ فقط نقشه.

**خروجی مورد انتظار:**

```
دسکتاپ:                    گوشی:
+-----------------+        +---------+
|     header      |        | header  |
+-----------+-----+        +---------+
|   main    | side|        |  main   |
+-----------+-----+        +---------+
|     footer      |        |  side   |
+-----------------+        +---------+
                           | footer  |
                           +---------+
```

---

## تمرین ۲ — چهار ستون در دسکتاپ، دو ستون در گوشی ⭐⭐

**هدف:** با یک media query تعداد ستون‌های `repeat` را برای صفحه باریک کم کنید.

**صورت مسئله:**

ردیف «دسته‌بندی‌ها»ی یک فروشگاه هشت جعبه دارد: در دسکتاپ چهار ستون،
و در عرض کمتر از ۶۰۰ پیکسل **دو** ستون.

**الزامات:**

- [ ] `repeat(4, 1fr)` در حالت عادی.
- [ ] یک `@media (max-width: 600px)` با `repeat(2, 1fr)`.
- [ ] هشت جعبه با `gap`.

**خروجی مورد انتظار:**

```
دسکتاپ:  [4][3][2][1]       گوشی:  [2][1]
         [8][7][6][5]              [4][3]
                                   [6][5]
                                   [8][7]
```

---

## تمرین ۳ — صفحه محصولی که در گوشی بیرون می‌زند ⭐⭐⭐

**هدف:** ستون‌های ثابت سرریزکننده و شرط اشتباه media query را در یک صفحه واقعی پیدا و درست کنید.

**صورت مسئله:**

صفحه سفارش آنلاین یک رستوران: عکس اصلی غذا کنار توضیحات، و زیر عکس چهار عکس کوچک.
در گوشی هم عکس‌های کوچک از صفحه بیرون می‌زنند و هم عکس و توضیح هنوز کنار هم‌اند.
عجیب‌تر اینکه در **دسکتاپ** همه‌چیز زیر هم افتاده!

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] عکس‌های کوچک با `repeat(4, 1fr)` در هر عرضی جا شوند.
- [ ] شرط media query به `max-width: 700px` اصلاح شود.
- [ ] در دسکتاپ: عکس (۳۰۰ پیکسل) کنار توضیح؛ در گوشی: زیر هم.
- [ ] در عرض ۳۶۰ پیکسل اسکرول افقی نباشد.

**خروجی مورد انتظار:**

```
دسکتاپ:                              گوشی:
+---------------------+---------+    +---------+
| title, price, text  |  photo  |    |  photo  |
|                     | [][][][]|    | [][][][]|
+---------------------+---------+    +---------+
                                     |  text   |
                                     +---------+
```

---

## اشتباه‌های رایج این مبحث

- نوشتن `min-width` به‌جای `max-width`؛ تغییر گوشی در دسکتاپ اعمال می‌شود.
- ستون‌های پیکسلی ثابت (مثل `repeat(4, 120px)`) که در گوشی جا نمی‌شوند.
- تعریف دوباره همه `grid-area` ها در media query؛ فقط نقشه (`grid-template-areas`) را عوض کنید.
- نوشتن چند media query وقتی `auto-fill` با `minmax` همان کار را بدون media query انجام می‌دهد.
