۲) ستون‌ها و ردیف‌ها (fr و px و %)

با grid-template-columns تعداد و پهنای ستون‌ها را می‌گوییم و با grid-template-rows تعداد و ارتفاع ردیف‌ها را. هر مقداری که با فاصله می‌نویسید یعنی یک ستون (یا یک ردیف). پس 100px 200px یعنی دو ستون.

در کدهای این درس gap: 8px هم آمده تا جعبه‌ها به هم نچسبند. gap را در درس ۴ کامل می‌خوانیم.

مثال ۱: ستون با پیکسل (px)

پهنای هر ستون دقیقاً ثابت است، چه صفحه پهن باشد چه باریک:

.grid-px {
  display: grid;
  grid-template-columns: 150px 150px 150px;
  gap: 8px;
}

مثال ۲: ستون با درصد (%)

.grid-percent {
  display: grid;
  grid-template-columns: 50% 25% 25%;
}

اشتباه رایج: ستون‌های درصدی را با gap ترکیب می‌کنیم: 50% 25% 25% به‌علاوه دو فاصله ۸ پیکسلی می‌شود ۱۰۰٪ + ۱۶px و شبکه از ظرف بیرون می‌زند. به همین دلیل در مثال ۲ عمداً gap ننوشتیم. راه درست واحد fr است (مثال ۳).

مثال ۳: واحد fr — سهم از فضای خالی

fr مخفف fraction یعنی «سهم» است. مرورگر اول فاصله‌ها را کم می‌کند، بعد بقیه جا را بین سهم‌ها تقسیم می‌کند. 2fr 1fr 1fr یعنی کل جا ۴ سهم است: ستون اول ۲ سهم، بقیه هر کدام ۱ سهم. 

.grid-fr {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 8px;
}

مثال ۴: ترکیب پیکسل و fr — ستون کناری ثابت

ستون کناری فروشگاه همیشه ۲۰۰ پیکسل است و محتوا بقیه جا را می‌گیرد:

.grid-mix {
  display: grid;
  grid-template-columns: 200px 1fr;
  gap: 8px;
}

مثال ۵: auto — به اندازه محتوا

ستون auto به اندازه محتوایش پهن می‌شود. برای یک ردیف از منوی کافه: آیکون و قیمت به اندازه خودشان، اسم غذا بقیه جا: 

.grid-auto {
  display: grid;
  grid-template-columns: auto 1fr auto;
  gap: 8px;
}

مثال ۶: ردیف‌ها با grid-template-rows

ردیف اول ۶۰ پیکسل، ردیف دوم ۱۲۰ پیکسل. اگر ردیف تعیین نکنید، ارتفاع هر ردیف به اندازه محتوایش می‌شود:

.grid-rows {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 60px 120px;
  gap: 8px;
}

واحد معنی کی استفاده کنیم؟
px اندازه ثابت ستون کناری، آیکون، چیزهایی که نباید تغییر کنند
% درصدی از عرض ظرف کم؛ با gap مشکل سرریز دارد
fr سهم از فضای باقی‌مانده بیشتر وقت‌ها؛ بهترین انتخاب برای ستون‌های منعطف
auto به اندازه محتوا برچسب، دکمه، قیمت

اشتباه رایج: نوشتن ویرگول بین ستون‌ها: grid-template-columns: 1fr, 1fr, 1fr; این مقدار نامعتبر است و مرورگر کل خط را نادیده می‌گیرد. مقدارها فقط با فاصله از هم جدا می‌شوند.

تمرین: برای صفحه «دوره‌های آموزشگاه» یک شبکه بسازید که ستون راست ۲۵۰ پیکسل (فیلتر دوره‌ها)، ستون وسط دو سهم (لیست دوره‌ها) و ستون چپ یک سهم (سبد خرید) باشد. ردیف اول را ۸۰ پیکسل بگذارید. بعد پنجره را باریک و پهن کنید و ببینید کدام ستون تغییر اندازه می‌دهد.
