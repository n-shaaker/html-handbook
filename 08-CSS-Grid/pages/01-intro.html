۱) Grid چیست؟ (مقدمه و اصطلاحات)

Grid یعنی «شبکه» یا «جدول نامرئی». شما روی یک عنصر پدر می‌گویید چند ستون و چند ردیف داشته باشد، و فرزندهایش خودکار داخل خانه‌های این جدول می‌نشینند. شبیه جدول برنامه هفتگی آموزشگاه یا قفسه‌های یک کتابخانه.

به عنصری که display: grid می‌گیرد ظرف شبکه (grid container) می‌گوییم و به فرزندهای مستقیمش آیتم‌های شبکه (grid items). فقط فرزندهای مستقیم آیتم حساب می‌شوند، نه نوه‌ها.

مثال ۱: اولین شبکه — سه ستون مساوی

منوی کافه شش نوشیدنی دارد و باید در سه ستون هم‌اندازه بنشیند. هر دو خط را روی پدر می‌نویسیم و خود آیتم‌ها عرض جداگانه‌ای نمی‌گیرند. display: grid ظرف را شبکه می‌کند و grid-template-columns: 1fr 1fr 1fr سه ستون می‌سازد که هر کدام یک سهم از عرض ظرف را می‌گیرد. چون شش فرزند داریم و فقط سه ستون تعریف شده، مرورگر خودش ردیف دوم را می‌سازد و سه تای باقی‌مانده را در آن می‌گذارد. 

.menu {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* سه ستون هم‌اندازه */
}

مثال ۲: فقط display: grid بدون ستون

  display: grid;   /* ستون تعیین نشده */

اشتباه رایج: فقط display: grid می‌نویسیم و تعجب می‌کنیم که چرا آیتم‌ها هنوز زیر هم هستند. Grid تا وقتی grid-template-columns را ننویسید، فقط یک ستون دارد.

مثال ۳: اصطلاحات Grid روی یک شکل

این شبکه ۴ ستون و ۳ ردیف دارد. هر رنگ یکی از اصطلاحات را نشان می‌دهد (اینجا فقط رنگ خانه‌ها را عوض کرده‌ایم تا شکل را ببینید): 

.terms {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr 1fr;   /* ۴ ستون */
  grid-template-rows: 60px 60px 60px;       /* ۳ ردیف */
}

اصطلاح انگلیسی معنی
خط grid line خط‌های نامرئی بین ستون‌ها و ردیف‌ها. ۴ ستون یعنی ۵ خط عمودی. با شماره خط‌ها آیتم‌ها را جابه‌جا می‌کنیم (درس ۵).
ستون column فضای عمودی بین دو خط عمودی کنار هم (آبی در شکل).
ردیف row فضای افقی بین دو خط افقی کنار هم (سبز در شکل).
مسیر track اسم کلی برای «یک ستون» یا «یک ردیف».
خانه cell محل برخورد یک ستون و یک ردیف؛ کوچک‌ترین قسمت شبکه (نارنجی در شکل).
ناحیه area چند خانه کنار هم که یک مستطیل بسازند (بنفش در شکل). در درس ۶ به ناحیه‌ها اسم می‌دهیم.

مثال ۴: راست‌چین و چپ‌چین — خط ۱ کجاست؟

در صفحه فارسی (dir="rtl") خط ستون شماره ۱ سمت راست است و شماره‌ها به سمت چپ زیاد می‌شوند. در صفحه انگلیسی (dir="ltr") برعکس است. همان کد مثال ۱ را در یک بخش چپ‌چین ببینید: 

<div class="menu" dir="ltr">
  ...
</div>

Grid یا Flexbox؟ در یک جمله

Flexbox برای چیدن آیتم‌ها در یک جهت است (یک ردیف یا یک ستون)، ولی Grid برای چیدن در دو جهت با هم (ردیف و ستون) ساخته شده است. مقایسه کامل را در درس ۱۱ می‌بینید.

اشتباه رایج: display: grid را روی خود آیتم‌ها (فرزندها) می‌نویسیم. این ویژگی همیشه روی پدر نوشته می‌شود؛ فرزندها خودشان آیتم می‌شوند.

تمرین: یک بخش «ساعت کاری کافه» بسازید که هفت روز هفته (شنبه تا جمعه) را در یک شبکه چهارستونه نشان دهد. بعد شبکه را دوستونه کنید و ببینید آیتم‌ها چطور خودشان جابه‌جا می‌شوند. روز اول (شنبه) باید سمت راست باشد.
