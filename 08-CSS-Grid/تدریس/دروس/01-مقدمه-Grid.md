## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«صفحه admin: header، sidebar، main، footer — با Flex nested دردسرساز است. یک **شبکه دو‌بعدی** می‌خواهیم.»


اول با **مسئله** شروع کن — نه با لیست property.

«Grid یعنی «شبکه» یا «جدول نامرئی». شما روی یک عنصر پدر می‌گویید چند ستون و چند ردیف داشته باشد، و فرزندهایش خودکار داخل خانه‌های این جدول می‌نشینند. شبیه جدول برنامه هفتگی آموزشگاه یا قفسه‌های یک کتابخانه.»

«به عنصری که display: grid می‌گیرد ظرف شبکه (grid container) می‌گوییم و به فرزندهای مستقیمش آیتم‌های شبکه (grid items) . فقط فرزندهای مستقیم آیتم حساب می‌شوند، نه نوه‌ها.»

«منوی کافه شش نوشیدنی دارد و باید در سه ستون هم‌اندازه بنشیند. هر دو خط را روی پدر می‌نویسیم و خود آیتم‌ها عرض جداگانه‌ای نمی‌گیرند. display: grid ظرف را شبکه می‌کند و grid-template-columns: 1fr 1fr 1fr سه ستون می‌سازد که هر کدام یک سهم از عرض ظرف را می‌گیرد. چون شش فرزند داریم و فقط سه ستون تعریف شده، مرورگر خودش ردیف دوم را می‌سازد و سه تای باقی‌مانده را در آن می‌گذارد.»

«دقت کنید: چون صفحه راست‌چین است، آیتم ۱ در سمت راست نشسته و ردیف‌ها از راست به چپ پر می‌شوند. واحد fr را در درس بعد کامل توضیح می‌دهیم؛ فعلاً بدانید یعنی «یک سهم».»

**روی جزوه این عناوین را دنبال کنید:** *۱) Grid چیست؟ (مقدمه و اصطلاحات)* · *مثال ۱: اولین شبکه — سه ستون مساوی* · *مثال ۲: فقط display: grid بدون ستون* · *مثال ۳: اصطلاحات Grid روی یک شکل*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.menu {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* سه ستون هم‌اندازه */
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.menu-one {
  display: grid;   /* ستون تعیین نشده */
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.terms {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr 1fr;   /* ۴ ستون */
  grid-template-rows: 60px 60px 60px;       /* ۳ ردیف */
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

- جزوه `01-intro.html` را کنار live بگذارید و پارagraph به paragraph جلو بروید.

## ۵) سؤال کلاسی

- «تفاوت grid item با div معمولی داخل grid؟»  
  **پاسخ:** همان element است؛ rules **placement** و **align** grid روی item اعمال می‌شود.
- «track با cell فرق دارد؟»  
  **پاسخ:** **track** کل ستون/ردیف؛ **cell** یک خانه در تقاطع trackها.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اشتباه رایج: فقط display: grid می‌نویسیم و تعجب می‌کنیم که چرا آیتم‌ها هنوز زیر هم هستند. Grid تا وقتی grid-template-columns را ننویسید، فقط یک ستون دارد.»

«این شبکه ۴ ستون و ۳ ردیف دارد. هر رنگ یکی از اصطلاحات را نشان می‌دهد (اینجا فقط رنگ خانه‌ها را عوض کرده‌ایم تا شکل را ببینید):»

«در صفحه فارسی ( dir="rtl" ) خط ستون شماره ۱ سمت راست است و شماره‌ها به سمت چپ زیاد می‌شوند. در صفحه انگلیسی ( dir="ltr" ) برعکس است. همان کد مثال ۱ را در یک بخش چپ‌چین ببینید:»

«در همه درس‌های این دوره صفحه راست‌چین است؛ پس هر جا گفتیم «خط ۱» یعنی لبه راست شبکه.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
