## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«magazine، admin، holy grail — سه اسکلت در یک جلسه.»


اول با **مسئله** شروع کن — نه با لیست property.

«در این درس چیز تازه‌ای یاد نمی‌گیریم؛ همان ویژگی‌های درس‌های قبل را کنار هم می‌گذاریم تا پنج چیدمانی را بسازیم که تقریباً در هر سایتی پیدا می‌شوند. هر کدام را می‌توانید مستقیم در پروژه‌تان کپی و کمی تغییر دهید.»

«سربرگ و منو بالا، محتوا و ستون کناری کنار هم، پانویس پایین. ستون کناری با minmax نه خیلی باریک می‌شود و نه خیلی پهن:»

«از خانه‌های تاریخی تا باغ فین؛ برنامه سفر، هزینه‌ها و جاهایی که نباید از دست داد.»

«عکس اول «عکس منتخب» است و دو ستون و دو ردیف می‌گیرد. بقیه خودشان دورش جا می‌شوند:»

**روی جزوه این عناوین را دنبال کنید:** *۱۲) الگوهای پرکاربرد* · *مثال ۱: چیدمان کلاسیک صفحه (وبلاگ سفر)* · *مثال ۲: گالری عکس سفر با یک عکس بزرگ (۲×۲)* · *مثال ۳: داشبورد فروشگاه*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.blog {
  display: grid;
  grid-template-columns: 1fr minmax(160px, 220px);
  grid-template-areas:
    "header header"
    "nav    nav"
    "main   aside"
    "footer footer";
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 90px;
  gap: 8px;
}

.gallery .featured {
  grid-column: span 2;
  grid-row: span 2;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
}

.dashboard .chart  { grid-column: span 3; }
.dashboard .orders { grid-column: span 1; }
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## تمرین‌ها (ساده → چالشی)

### ساده
1. همان مثال Live را بدون نگاه کردن یک بار دیگر بنویسید.
2. جزوه را باز کنید و خروجی مرورگر/Console را با پیش‌بینی خودتان مقایسه کنید.

### متوسط
3. یک variation کوچک روی مثال کلاس (مقدار دیگر، یک selector دیگر، یک عنصر DOM دیگر).
4. تمرین موضوعی در [`quizzes/`](../../quizzes/README.md) همان ماژول.

### چالشی
5. mini-project انتهای درس را کامل کنید و برای یک همکلاسی توضیح دهید **چرا** این راه‌حل کار می‌کند.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«چهار کارت آمار در ردیف اول، نمودار فروش سه ستون و لیست سفارش‌ها یک ستون از ردیف دوم:»

«برچسب‌ها در ستون راست به اندازه ثابت و فیلدها در ستون چپ. چون هر label و هر input یک آیتم است، خودشان به ترتیب در دو ستون می‌نشینند. دکمه را با grid-column: 2 زیر فیلدها می‌بریم:»

«برای صفحه «سبد خرید خالی است» یا «در حال بارگذاری»، ساده‌ترین روش وسط‌چینی در هر دو جهت:»

«اشتباه رایج: در گالری مثال ۲ عکس بزرگ را span 2 می‌کنیم ولی ردیف‌ها ارتفاع ندارند ( grid-auto-rows ننوشته‌ایم). در این حالت ارتفاع ردیف‌ها به اندازه متن است و عکس «۲ ردیفی» تقریباً هم‌قد بقیه می‌شود. برای گالری همیشه grid-auto-rows بدهید.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
