## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«بنر hero باید **دو ستون** را بپوشاند — بدون جدول HTML.»


اول با **مسئله** شروع کن — نه با لیست property.

«تا اینجا آیتم‌ها خودشان به ترتیب در خانه‌ها می‌نشستند. حالا می‌خواهیم به یک آیتم بگوییم «از کدام خط شروع کن و تا کدام خط برو». این ویژگی‌ها روی خود آیتم (فرزند) نوشته می‌شوند، نه روی پدر.»

«یادآوری از درس ۱: یک شبکه ۴ ستونه ۵ خط عمودی دارد. در صفحه راست‌چین خط ۱ لبه راست است و خط ۵ لبه چپ. همه شبکه‌های این درس این‌طورند:»

«آیتم ۱ از خط ۱ تا خط ۳ می‌رود؛ یعنی دو ستون را می‌گیرد (ستون ۱ و ۲):»

«grid-column خلاصه دو ویژگی است: grid-column-start: 1; و grid-column-end: 3; . علامت / فقط این دو عدد را از هم جدا می‌کند و تقسیم نیست.»

**روی جزوه این عناوین را دنبال کنید:** *۵) جای‌گذاری آیتم‌ها با شماره خط* · *مثال ۱: grid-column: شروع / پایان* · *مثال ۲: span — «این‌قدر ستون بگیر»* · *مثال ۳: -1 یعنی «آخرین خط»*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

«بچه‌ها، جزوه را باز کنید؛ من روی همان مثال live جلو می‌روم. هر بار که property عوض می‌شود، در DevTools overlay (Flex/Grid) یا Computed styles را نگاه کنید.»

«یادآوری از درس ۱: یک شبکه ۴ ستونه ۵ خط عمودی دارد. در صفحه راست‌چین خط ۱ لبه راست است و خط ۵ لبه چپ. همه شبکه‌های این درس این‌طورند:»

«آیتم ۱ از خط ۱ تا خط ۳ می‌رود؛ یعنی دو ستون را می‌گیرد (ستون ۱ و ۲):»

اگر دانشجو گفت «حفظ کنم؟» بگو: «نه — **مسئله** را بشناسید؛ property نامش را بعداً هم از MDN پیدا می‌کنید.»

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.item-1 {
  grid-column: 1 / 3;   /* از خط ۱ تا خط ۳ */
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.item-2 { grid-column: span 2; }   /* دو ستون */
.item-5 { grid-row: span 2; }      /* دو ردیف */
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اشتباه رایج: فکر می‌کنیم grid-column: 1 / 3 یعنی «سه ستون». عددها شماره خط هستند، نه شماره ستون! از خط ۱ تا خط ۳ فقط دو ستون است. برای سه ستون باید بنویسید 1 / 4 (یا span 3 ).»

«اگر حساب شماره خط سخت است، با span فقط بگویید چند ستون یا ردیف بگیرد. آیتم از همان جایی که بود شروع می‌کند:»

«خط‌ها از آخر هم شماره دارند: -1 همیشه آخرین خط است (در راست‌چین یعنی لبه چپ). 1 / -1 یعنی «تمام عرض»، هر چند ستون که شبکه داشته باشد. برای بنر تخفیف فروشگاه عالی است:»

«با grid-row همین کار را برای ردیف‌ها می‌کنیم. آیتم ۱ در ستون ۱ (راست) است و از خط ردیف ۱ تا ۴ (سه ردیف) پایین می‌رود:»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
