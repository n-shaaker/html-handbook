## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«صفحه magazine کوچک — grid-template-areas + auto-fit.»


اول با **مسئله** شروع کن — نه با لیست property.

«به آخر دوره رسیدیم! در این صفحه یک چک‌لیست برای مرور، یک جدول مرجع از همه ویژگی‌ها، چند مثال ترکیبی و در آخر تمرین‌هایی از ساده به سخت آمده است.»

«قبل از نگاه کردن به نتیجه، روی کاغذ یک شبکه ۴×۳ بکشید و جای آیتم ۱ را حدس بزنید:»

«.quiz-grid { display: grid; grid-template-columns: repeat(4, 1fr); grid-auto-rows: 50px; gap: 6px; } .guess { grid-column: 2 / 4; /* ستون ۲ و ۳ */ grid-row: 1 / 3; /* ردیف ۱ و ۲ */ } ۱ ۲ ۳ ۴ ۵ ۶ ۷ ۸ آیتم ۱ ستون‌های ۲ و ۳ (وسط شبکه) و ردیف‌های ۱ و ۲ را گرفته؛ ستون ۱ (راست) و ستون ۴ (چپ) برای بقیه آیتم‌ها مانده و آن‌ها خودشان دورش پر شده‌اند.»

«نقشه صفحه با grid-template-areas و کارت‌های محصول داخل محتوا با auto-fill :»

**روی جزوه این عناوین را دنبال کنید:** *۱۴) تمرین جمع‌بندی* · *چک‌لیست: این‌ها را بدون نگاه کردن به جزوه بلدم؟* · *جدول مرجع: ویژگی‌های ظرف (پدر)* · *جدول مرجع: ویژگی‌های آیتم (فرزند)*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.quiz-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 50px;
  gap: 6px;
}

.guess {
  grid-column: 2 / 4;   /* ستون ۲ و ۳ */
  grid-row: 1 / 3;      /* ردیف ۱ و ۲ */
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.store {
  display: grid;
  grid-template-columns: 160px 1fr;
  grid-template-areas:
    "header  header"
    "filters products"
    "footer  footer";
  gap: 8px;
}

.products {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(120px, 1fr));
  gap: 8px;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.badge-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 100px;
  gap: 8px;
  place-items: center;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

- جزوه `14-practice.html` را کنار live بگذارید و پارagraph به paragraph جلو بروید.
