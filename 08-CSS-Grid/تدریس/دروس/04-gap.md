## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«grid کارت‌ها: margin روی هر کارت در گوشه‌ها دوبرابر دیده می‌شود.»


اول با **مسئله** شروع کن — نه با لیست property.

«ویژگی gap فاصله بین ستون‌ها و ردیف‌ها را تعیین می‌کند. روی پدر نوشته می‌شود، فقط بین آیتم‌ها فاصله می‌اندازد و هیچ‌وقت فاصله اضافه دور لبه‌های بیرونی شبکه نمی‌گذارد. (اسم قدیمی‌اش grid-gap بود که هنوز در کدهای قدیمی می‌بینید.)»

«اگر دو مقدار بنویسید، اولی فاصله بین ردیف‌ها و دومی بین ستون‌ها است:»

«همان کار مثال ۲ با دو ویژگی جدا؛ وقتی فقط یکی را لازم دارید راحت‌تر است:»

«اشتباه رایج: فاصله آیتم‌ها را با margin می‌سازیم. نتیجه: دور لبه‌های شبکه هم فاصله می‌افتد، فاصله بین دو آیتم دو برابر لبه‌ها می‌شود (۸ + ۸) و هم‌ترازی با بقیه صفحه به‌هم می‌خورد. در Grid همیشه از gap استفاده کنید.»

**روی جزوه این عناوین را دنبال کنید:** *۴) فاصله بین خانه‌ها (gap)* · *مثال ۱: بدون gap و با gap* · *مثال ۲: فاصله ردیف و ستون جدا — gap: ردیف ستون* · *مثال ۳: row-gap و column-gap*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.no-gap   { display: grid; grid-template-columns: repeat(3, 1fr); }

.with-gap {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.two-values {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 30px 8px;   /* ردیف‌ها ۳۰، ستون‌ها ۸ */
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.only-column {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  column-gap: 24px;   /* فقط بین ستون‌ها */
  row-gap: 0;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اگر دور شبکه هم فاصله می‌خواهید، آن را با padding روی خود ظرف بدهید، نه margin روی آیتم‌ها:»

«gap در Flexbox هم کار می‌کند؛ پس یک بار یاد گرفتنش برای هر دو کافی است.»

«تمرین: یک «گالری عکس سفر» با ۸ عکس (یا جعبه رنگی) در ۴ ستون بسازید. بین ردیف‌ها ۲۴ پیکسل و بین ستون‌ها ۱۲ پیکسل فاصله باشد و دور کل گالری ۱۶ پیکسل فاصله داخلی. هیچ آیتمی نباید margin داشته باشد.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
