## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«layout با نام ناحیه — header header در template-areas — بدون شمارش خط برای هر breakpoint.»


اول با **مسئله** شروع کن — نه با لیست property.

«حساب کردن شماره خط‌ها برای چیدمان کل صفحه کمی سخت است. Grid راه خیلی خواناتری هم دارد: نقشه صفحه را با اسم می‌کشیم! دو قدم دارد:»

«نقشه دقیقاً شبیه شکل نهایی است: header دو بار نوشته شده چون دو ستون را می‌گیرد. در صفحه راست‌چین، اولین اسم هر ردیف ( sidebar ) سمت راست می‌نشیند.»

«اسم‌ها دلخواه‌اند و ربطی به تگ‌های header یا main ندارند؛ فقط باید در grid-area و نقشه یکسان باشند. در grid-area اسم را بدون گیومه می‌نویسیم.»

«بدون دست زدن به HTML، ستون کناری را به سمت چپ می‌بریم. فقط ترتیب اسم‌ها و ستون‌ها عوض شده:»

**روی جزوه این عناوین را دنبال کنید:** *۶) نام‌گذاری ناحیه‌ها (template-areas)* · *مثال ۱: اسکلت کلاسیک سایت — سربرگ، ستون کناری، محتوا، پانویس* · *مثال ۲: جابه‌جا کردن ستون کناری فقط با عوض کردن نقشه* · *مثال ۳: سه ستون — منو، محتوا و تبلیغ*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 8px;
}

.page-top    { grid-area: header; }
.page-side   { grid-area: sidebar; }
.page-main   { grid-area: main; }
.page-bottom { grid-area: footer; }
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.page-left {
  grid-template-columns: 1fr 200px;
  grid-template-areas:
    "header header"
    "main   sidebar"
    "footer footer";
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.shop-page {
  display: grid;
  grid-template-columns: 150px 1fr 150px;
  grid-template-areas:
    "header header header"
    "menu   main   ads"
    "footer footer footer";
  gap: 8px;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اگر خانه‌ای قرار نیست چیزی داشته باشد، جایش یک نقطه بگذارید:»

«grid-template-areas فقط جای ناحیه‌ها را می‌گوید؛ ارتفاع ردیف‌ها را مثل قبل با grid-template-rows بدهید. اینجا ردیف وسط بقیه جا را می‌گیرد و سربرگ و پانویس به اندازه محتوایشان هستند:»

«اشتباه رایج: کشیدن ناحیه‌ای که مستطیل نیست، مثل شکل L در نقشهٔ زیر.»

«هر ناحیه باید یک مستطیل کامل باشد. اگر نباشد، مرورگر کل grid-template-areas را نادیده می‌گیرد و آیتم‌ها به ترتیب عادی می‌نشینند.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
