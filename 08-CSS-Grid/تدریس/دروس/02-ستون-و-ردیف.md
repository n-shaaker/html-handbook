## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«sidebar ۲۴۰px و main بقیه — با درصد قاطی می‌شود؛ `fr` چطور «فضای باقی‌مانده» را می‌دهد؟»


اول با **مسئله** شروع کن — نه با لیست property.

«با grid-template-columns تعداد و پهنای ستون‌ها را می‌گوییم و با grid-template-rows تعداد و ارتفاع ردیف‌ها را. هر مقداری که با فاصله می‌نویسید یعنی یک ستون (یا یک ردیف). پس 100px 200px یعنی دو ستون.»

«در کدهای این درس gap: 8px هم آمده تا جعبه‌ها به هم نچسبند. gap را در درس ۴ کامل می‌خوانیم.»

«پهنای هر ستون دقیقاً ثابت است، چه صفحه پهن باشد چه باریک:»

«سمت چپ شبکه جای خالی مانده؛ چون جمع ستون‌ها از عرض ظرف کمتر است. در موبایل هم برعکس، ممکن است از صفحه بیرون بزند.»

**روی جزوه این عناوین را دنبال کنید:** *۲) ستون‌ها و ردیف‌ها (fr و px و %)* · *مثال ۱: ستون با پیکسل ( px )* · *مثال ۲: ستون با درصد ( % )* · *مثال ۳: واحد fr — سهم از فضای خالی*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.grid-px {
  display: grid;
  grid-template-columns: 150px 150px 150px;
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.grid-percent {
  display: grid;
  grid-template-columns: 50% 25% 25%;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.grid-fr {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 8px;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## ۵) سؤال کلاسی

- «`1fr 1fr 1fr` با `33% 33% 33%` چه فرقی دارد؟»  
  **پاسخ:** **fr** فضای **باقی‌مانده** بعد از fixed و gap؛ **%** نسبت به کل container — با gap ممکن است overflow شود.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اشتباه رایج: ستون‌های درصدی را با gap ترکیب می‌کنیم: 50% 25% 25% به‌علاوه دو فاصله ۸ پیکسلی می‌شود ۱۰۰٪ + ۱۶px و شبکه از ظرف بیرون می‌زند. به همین دلیل در مثال ۲ عمداً gap ننوشتیم. راه درست واحد fr است (مثال ۳).»

«fr مخفف fraction یعنی «سهم» است. مرورگر اول فاصله‌ها را کم می‌کند، بعد بقیه جا را بین سهم‌ها تقسیم می‌کند. 2fr 1fr 1fr یعنی کل جا ۴ سهم است: ستون اول ۲ سهم، بقیه هر کدام ۱ سهم.»

«ستون کناری فروشگاه همیشه ۲۰۰ پیکسل است و محتوا بقیه جا را می‌گیرد:»

«ستون auto به اندازه محتوایش پهن می‌شود. برای یک ردیف از منوی کافه: آیکون و قیمت به اندازه خودشان، اسم غذا بقیه جا:»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
