## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«فقط ۲ ستون تعریف کردیم ولی ۷ item داریم — ردیف‌های اضافه از کجا می‌آیند؟»


اول با **مسئله** شروع کن — نه با لیست property.

«ستون‌ها و ردیف‌هایی که خودمان با grid-template-... می‌نویسیم شبکه صریح (explicit) هستند. اگر آیتم‌ها از خانه‌های این شبکه بیشتر باشند، مرورگر خودش ردیف (یا ستون) تازه می‌سازد. به این ردیف‌های خودکار شبکه ضمنی (implicit) می‌گوییم. در این درس یاد می‌گیریم اندازه و جهت آن‌ها را کنترل کنیم.»

«فقط دو ردیف ۷۰ پیکسلی نوشته‌ایم، ولی ۸ آیتم داریم. ردیف سوم خودکار ساخته شده و ارتفاعش فقط به اندازه متن است:»

«اشتباه رایج: برای لیست محصولاتی که تعدادش از دیتابیس می‌آید، grid-template-rows می‌نویسیم. وقتی محصول‌ها زیاد شوند، ردیف‌های جدید ارتفاع ما را نمی‌گیرند (مثل آیتم ۷ و ۸). وقتی تعداد ردیف را نمی‌دانید از grid-auto-rows استفاده کنید.»

«بهتر از عدد ثابت، grid-auto-rows: minmax(70px, auto); است: حداقل ۷۰ پیکسل، ولی اگر متن کارت زیاد شد بلندتر می‌شود.»

**روی جزوه این عناوین را دنبال کنید:** *۱۰) شبکه ضمنی (grid-auto)* · *مثال ۱: ردیف اضافه‌ای که خودمان ننوشتیم* · *مثال ۲: grid-auto-rows — اندازه همه ردیف‌های خودکار* · *مثال ۳: grid-auto-flow: column — پر کردن ستونی*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

«فقط دو ردیف ۷۰ پیکسلی نوشته‌ایم، ولی ۸ آیتم داریم. ردیف سوم خودکار ساخته شده و ارتفاعش فقط به اندازه متن است:»

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.explicit {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 70px 70px;   /* فقط دو ردیف */
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.auto-rows {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 70px;   /* هر ردیفی که ساخته شود */
  gap: 8px;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.flow-column {
  display: grid;
  grid-template-rows: repeat(2, 60px);   /* دو ردیف */
  grid-auto-flow: column;                /* ستونی پر شود */
  grid-auto-columns: 100px;              /* هر ستون تازه ۱۰۰ پیکسل */
  gap: 8px;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«حالت پیش‌فرض row است: آیتم‌ها ردیف به ردیف پر می‌شوند. با column ستون به ستون پر می‌شوند و ستون‌های تازه ساخته می‌شوند؛ اندازه آن ستون‌ها را grid-auto-columns تعیین می‌کند:»

«به ترتیب شماره‌ها دقت کنید: ۱ و ۲ زیر هم در ستون راست، بعد ۳ و ۴ در ستون بعدی، و همین‌طور به سمت چپ.»

«وقتی بعضی آیتم‌ها دو ستون می‌گیرند و در ادامه ردیف جا نمی‌شوند، به ردیف بعد می‌روند و یک خانه خالی (سوراخ) جا می‌گذارند. با dense مرورگر آیتم‌های کوچک بعدی را برمی‌گرداند تا سوراخ‌ها را پر کند:»

«بدون dense (به خانه‌های خالی دقت کنید):»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
