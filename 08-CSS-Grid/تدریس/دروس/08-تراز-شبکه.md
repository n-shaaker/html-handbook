## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«grid کوچک‌تر از container است — کل بلوک بالا چسبیده.»


اول با **مسئله** شروع کن — نه با لیست property.

«در درس قبل هر آیتم را داخل خانه خودش جابه‌جا کردیم ( -items ). حالا فرض کنید کل شبکه (همه ستون‌ها و ردیف‌ها با هم) از ظرفش کوچک‌تر است؛ مثلاً ستون‌ها پیکسلی هستند و جا اضافه مانده. با justify-content و align-content کل شبکه را داخل ظرف جابه‌جا می‌کنیم.»

«در همهٔ مثال‌های این درس شبکه از ظرف کوچک‌تر است تا جای خالی دیده شود: سه ستون ۹۰ پیکسلی و دو ردیف ۵۰ پیکسلی، داخل ظرفی با ارتفاع ۲۲۰ پیکسل. اگر ستون‌ها را با 1fr تا آخر ظرف کشیده بودیم، فضای خالی افقی نمی‌ماند و justify-content چیزی برای جابه‌جا کردن نداشت.»

«شبکه به گوشه بالا- راست ظرف می‌چسبد (چون صفحه راست‌چین است) و بقیه ظرف خالی می‌ماند:»

«برای اینکه جا کم‌تر بگیرد، در این مثال ظرف‌ها کوتاه‌اند و فقط یک ردیف دارند.»

**روی جزوه این عناوین را دنبال کنید:** *۸) تراز کل شبکه داخل ظرف* · *مثال ۱: حالت پیش‌فرض — start* · *مثال ۲: جابه‌جایی افقی — justify-content* · *مثال ۳: جابه‌جایی عمودی — align-content*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 90px);
  grid-template-rows: repeat(2, 50px);
  gap: 8px;
  height: 220px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.jc-center  { justify-content: center; }
.jc-end     { justify-content: end; }             /* چپ */
.jc-between { justify-content: space-between; }   /* ستون‌ها تا لبه‌ها پخش شوند */
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.ac-center  { align-content: center; }
.ac-end     { align-content: end; }              /* پایین */
.ac-between { align-content: space-between; }
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«place-content: center خلاصه align-content و justify-content است. مثلاً صفحه‌کلید عددی یک دستگاه کارت‌خوان فروشگاه وسط صفحه:»

«اشتباه رایج: روی شبکه‌ای با ستون‌های 1fr می‌نویسیم justify-content: center و هیچ اتفاقی نمی‌افتد. ستون‌های fr همه جای خالی را می‌خورند، پس جای اضافه‌ای برای جابه‌جایی نمی‌ماند. -content فقط وقتی کار می‌کند که ستون‌ها (یا ردیف‌ها) اندازه ثابت داشته باشند و جا اضافه بیاید.»

«اشتباه رایج: align-content روی ظرفی که ارتفاع ندارد. ظرف بدون height دقیقاً به اندازه ردیف‌هاست و جای خالی عمودی ندارد.»

«تمرین: یک «دکمه‌های انتخاب صندلی» برای سالن کوچک یک آموزشگاه بسازید: ۴ ستون ۶۰ پیکسلی و ۳ ردیف ۶۰ پیکسلی، داخل ظرفی با ارتفاع ۳۰۰ پیکسل و عرض کامل. کل صندلی‌ها را وسط ظرف بیاورید و بعد space-evenly را امتحان کنید.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
