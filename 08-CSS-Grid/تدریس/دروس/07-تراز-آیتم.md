## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«cell بلند است و دکمه کوچک **بالا** چسبیده — stretch پیش‌فرض دردسرساز.»


اول با **مسئله** شروع کن — نه با لیست property.

«هر آیتم داخل خانه‌ای می‌نشیند که از برخورد یک ستون و یک ردیف ساخته شده است. اگر خود آیتم از آن خانه کوچک‌تر باشد، می‌توان گفت در کدام لبه یا در وسط خانه قرار بگیرد. دو خانواده ویژگی این کار را می‌کنند و اسمشان جهت را مشخص می‌کند.»

«مقدار پیش‌فرض stretch است: آیتم در جهتی که اندازه‌اش auto باشد کش می‌آید تا خانه را پر کند. start آیتم را به لبهٔ شروع می‌چسباند، center آن را وسط خانه می‌گذارد و end آن را به لبهٔ پایان می‌برد. در صفحهٔ راست‌چین، شروع افقی سمت راست است و پایان سمت چپ. این جهت برای محور عمودی عوض نمی‌شود: شروع بالا است و پایان پایین.»

«در همه مثال‌ها هر ردیف ۹۰ پیکسل ارتفاع دارد و هر ستون یک‌سوم عرض است؛ پس آیتم‌ها از خانه‌شان کوچک‌ترند و جابه‌جایی‌شان دیده می‌شود.»

«بدون هیچ‌کدام از ویژگی‌های تراز، مقدار پیش‌فرض stretch اعمال می‌شود. آیتم‌هایی که ارتفاع جداگانه ندارند تمام ارتفاع ردیف را می‌گیرند، برای همین کارت‌های یک ردیف هم‌قد دیده می‌شوند:»

**روی جزوه این عناوین را دنبال کنید:** *۷) تراز آیتم‌ها داخل خانه* · *مثال ۱: حالت پیش‌فرض — stretch* · *مثال ۲: تراز افقی همه آیتم‌ها — justify-items* · *مثال ۳: تراز عمودی همه آیتم‌ها — align-items*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 90px;
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.justify-start  { justify-items: start; }   /* راست */
.justify-center { justify-items: center; }
.justify-end    { justify-items: end; }     /* چپ */
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.align-start  { align-items: start; }    /* بالا */
.align-center { align-items: center; }
.align-end    { align-items: end; }      /* پایین */
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«grid-auto-rows را هم در درس ۱۰ می‌خوانیم؛ فعلاً یعنی «ارتفاع هر ردیف ۹۰ پیکسل».»

«place-items میانبر دو ویژگی پدر است. مقدار اول به align-items می‌رود (عمودی) و مقدار دوم به justify-items (افقی). اگر فقط یک مقدار بنویسید، همان مقدار برای هر دو جهت به کار می‌رود. پس place-items: center آیتم را هم افقی و هم عمودی وسط خانه‌اش می‌گذارد، به شرطی که خانه از خود آیتم بزرگ‌تر باشد.»

«اگر دو مقدار بنویسید، اولی برای align (عمودی) و دومی برای justify (افقی) است: place-items: end start; یعنی پایین و راست.»

«این دو روی خود آیتم نوشته می‌شوند و فقط همان آیتم را جابه‌جا می‌کنند، حتی اگر پدر چیز دیگری گفته باشد:»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
