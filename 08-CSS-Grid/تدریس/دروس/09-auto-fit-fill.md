## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«تعداد کارت‌ها هر هفته عوض می‌شود — ستون‌ها خودکار جمع/پخش شوند.»


اول با **مسئله** شروع کن — نه با لیست property.

«تا حالا تعداد ستون‌ها را خودمان می‌گفتیم: repeat(4, 1fr) . ولی در گوشی ۴ ستون خیلی باریک می‌شود! اگر به‌جای عدد بنویسیم auto-fill یا auto-fit ، مرورگر خودش حساب می‌کند چند ستون جا می‌شود . نتیجه: شبکه واکنش‌گرا بدون حتی یک media query .»

«در این درس حتماً پنجره مرورگر را باریک و پهن کنید تا تغییر تعداد ستون‌ها را ببینید.»

«هر ستون دقیقاً ۱۵۰ پیکسل؛ مرورگر هر چندتا که جا شود می‌سازد. ولی سمت چپ کمی جای خالی می‌ماند:»

«با minmax می‌گوییم «هر ستون حداقل ۲۰۰ پیکسل، ولی اگر جا ماند همه با هم پهن شوید». حالا جای خالی هم نمی‌ماند. این یک خط را برای کارت‌های محصول تقریباً همه سایت‌ها می‌بینید:»

**روی جزوه این عناوین را دنبال کنید:** *۹) auto-fill و auto-fit* · *مثال ۱: repeat(auto-fill, 150px)* · *مثال ۲: فرمول طلایی — repeat(auto-fill, minmax(200px, 1fr))* · *مثال ۳: فرق auto-fill و auto-fit (وقتی آیتم کم است)*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

«در این درس حتماً پنجره مرورگر را باریک و پهن کنید تا تغییر تعداد ستون‌ها را ببینید.»

«هر ستون دقیقاً ۱۵۰ پیکسل؛ مرورگر هر چندتا که جا شود می‌سازد. ولی سمت چپ کمی جای خالی می‌ماند:»

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.fixed-cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, 150px);
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.products {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 12px;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.fill { grid-template-columns: repeat(auto-fill, minmax(120px, 1fr)); }
.fit  { grid-template-columns: repeat(auto-fit,  minmax(120px, 1fr)); }
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«تا وقتی آیتم‌ها زیادند، این دو هیچ فرقی ندارند. فرق وقتی پیدا می‌شود که آیتم‌ها کمتر از ستون‌های جاشده باشند. هر دو شبکه زیر فقط ۲ آیتم دارند:»

«auto-fill: ستون‌های خالی سر جایشان می‌مانند»

«auto-fit: ستون‌های خالی جمع می‌شوند و آیتم‌ها کل عرض را می‌گیرند»

«گالری زیر همان الگو را روی کارت واقعی می‌گذارد: عکس بالا و متن پایین. چون ستون‌ها با repeat(auto-fill, minmax(180px, 1fr)) ساخته شده‌اند، هر ستون دست‌کم ۱۸۰ پیکسل است و اگر جا بماند پهن‌تر می‌شود. در صفحهٔ پهن چند ستون کنار هم می‌آیند و وقتی عرض ظرف برای ستون دوم کافی نباشد، کارت‌ها در یک ستون زیر هم قرار می‌گیرند. برای این تغییر به media query نیازی نیست.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
