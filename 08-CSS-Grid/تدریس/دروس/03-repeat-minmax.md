## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«گالری ۱۲ عکس — ستون‌ها **حداقل** ۱۸۰px و بیشتر نشوند.»


اول با **مسئله** شروع کن — نه با لیست property.

«نوشتن 1fr 1fr 1fr 1fr 1fr 1fr هم خسته‌کننده است و هم احتمال اشتباه دارد. تابع repeat() تکرار را برای ما می‌نویسد، و تابع minmax() به یک ستون یا ردیف کمترین و بیشترین اندازه می‌دهد.»

«repeat(4, 1fr) همان چهار بار نوشتن 1fr است: چهار ستون که هر کدام یک سهم برابر از عرض ظرف می‌گیرند. عدد اول تعداد تکرار است و مقدار دوم اندازهٔ هر ستون. برای ویترین فروشگاه، این یعنی کارت‌ها در هر ردیف هم‌عرض می‌مانند و ردیف بعد خودش ساخته می‌شود.»

«داخل repeat می‌شود چند اندازه نوشت؛ کل الگو تکرار می‌شود. اینجا «ستون باریک، ستون پهن» دو بار تکرار شده:»

«ستون کناری آموزشگاه نباید از ۱۵۰ پیکسل باریک‌تر شود (متن می‌شکند) و نه از ۲۵۰ پیکسل پهن‌تر (جای محتوا را می‌گیرد). پنجره را باریک و پهن کنید:»

**روی جزوه این عناوین را دنبال کنید:** *۳) repeat() و minmax()* · *مثال ۱: repeat(تعداد, اندازه)* · *مثال ۲: تکرار یک الگو* · *مثال ۳: repeat کنار اندازه‌های دیگر*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.shop {
  display: grid;
  grid-template-columns: repeat(4, 1fr);   /* همان 1fr 1fr 1fr 1fr */
  gap: 8px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.pattern {
  display: grid;
  grid-template-columns: repeat(2, 80px 1fr);   /* 80px 1fr 80px 1fr */
  gap: 8px;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.mixed {
  display: grid;
  grid-template-columns: 200px repeat(3, 1fr);   /* یک ستون ثابت + سه ستون مساوی */
  gap: 8px;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اگر به ردیف ارتفاع ثابت بدهید و متن زیاد شود، متن بیرون می‌زند. با minmax(80px, auto) ردیف حداقل ۸۰ پیکسل است ولی اگر لازم بود بلندتر می‌شود:»

«هر سه کارت هم‌قد شدند، چون همه در یک ردیف هستند و ردیف به اندازه بلندترین کارت رشد کرد.»

«اشتباه رایج: جا انداختن ویرگول داخل repeat : repeat(3 1fr) . در repeat و minmax ویرگول لازم است (برخلاف خود grid-template-columns که ویرگول نمی‌خواهد). بدون ویرگول کل خط نامعتبر است و شبکه یک‌ستونه می‌ماند.»

«اشتباه رایج: نوشتن fr به‌عنوان کمترین مقدار: minmax(1fr, 200px) . مقدار اول minmax نمی‌تواند fr باشد؛ fr فقط در جای «بیشترین» معنی دارد.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
