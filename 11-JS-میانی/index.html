آموزش JavaScript — سطح میانی

ادامه دوره پایه، مثال به مثال، با تمرین‌های کاربردی

پیش‌نیاز: قبل از شروع این دوره، درس‌های دوره پایه JavaScript (متغیر، نوع داده، تابع، شیء، رویداد، رشته، عدد، شرط و حلقه) را بخوانید. مثل دوره پایه، کد هر مثال در فایل JavaScript خارجی است و از اسکریپت داخلی و رویداد اینلاین (مثل onclick) استفاده نشده است. خروجی console.log هر مثال در جعبه سیاه «Console» زیر همان مثال نمایش داده می‌شود.

  2. متدهای آرایه (Array Methods)

  5. تاریخ و زمان (Dates)
  6. ریاضی و عدد تصادفی (Math & Random)
  7. محدوده دسترسی (Scope)
  8. بالا بردن و حالت سخت‌گیرانه (Hoisting & Strict Mode)
  9. توابع پیکانی (Arrow Functions)
  10. کلمه کلیدی this
  11. تجزیه و پخش (Destructuring، Spread و Rest)
  12. قالب JSON
  13. مدیریت خطا (Try...Catch)
  14. DOM: انتخاب عنصرها
  15. DOM: تغییر محتوا، ویژگی و ظاهر
  16. DOM: رویدادها به صورت عمیق‌تر
  17. DOM: ساختن و حذف عنصرها
  18. فرم‌ها و اعتبارسنجی (Forms & Validation)
  19. اشکال‌زدایی پایه (DevTools)
  20. اسلایدر عکس (Image Slider)
  21. الگوهای رایج UI (مودال، تب، منو، …)
  22. پروژه جمع‌بندی: فهرست کارها (Todo List)

بعد از این دوره: کلاس‌ها، Closure، برنامه‌نویسی ناهمگام (Promise و async/await)، Fetch API، ذخیره‌سازی و ... در دوره JavaScript سطح پیشرفته ادامه پیدا می‌کند.
