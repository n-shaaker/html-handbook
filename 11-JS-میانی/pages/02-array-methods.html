۲) متدهای آرایه (Array Methods)

خواندن عضو با شماره کافی نیست؛ اغلب باید عضوی را به ابتدا یا انتها اضافه کنید، از وسط حذف کنید یا از آرایه یک متن بسازید. متدهای آرایه همین کارها را انجام می‌دهند. بعضی‌ها همان آرایه را عوض می‌کنند و بعضی یک آرایه یا رشتهٔ تازه برمی‌گردانند و اصل را دست نمی‌زنند. قبل از استفاده باید بدانید نتیجه را کجا می‌گیرید و آیا فهرست قبلی هنوز سر جایش است یا نه.

متدکارآرایه اصلی تغییر می‌کند؟
push(x)اضافه به آخربله
pop()حذف از آخر (و برگرداندن آن)بله
unshift(x)اضافه به اولبله
shift()حذف از اول (و برگرداندن آن)بله
splice(i, n, ...)حذف/اضافه از وسط (عضوهای حذف‌شده را برمی‌گرداند)بله
slice(start, end)کپی یک بخشخیر
concat(arr)چسباندن دو آرایهخیر
join(sep)تبدیل به رشتهخیر
reverse()برعکس کردن ترتیببله

push، pop، unshift، shift

const list = ["ب", "پ"];
list.push("ت");       // ["ب","پ","ت"]
list.unshift("الف");  // ["الف","ب","پ","ت"]
console.log(list);

const last = list.pop();      // "ت" را حذف می‌کند و برمی‌گرداند
const first = list.shift();   // "الف" را حذف می‌کند و برمی‌گرداند
console.log(last, first);
console.log(list);            // ["ب","پ"]





push مقدار را به انتهای آرایه اضافه می‌کند و unshift آن را در ابتدا می‌گذارد؛ با اضافه شدن به ابتدا، شمارهٔ بقیهٔ عضو‌ها یکی جلو می‌رود. pop آخرین عضو را هم حذف می‌کند و هم به‌عنوان نتیجه برمی‌گرداند. shift همین کار را با عضو اول انجام می‌دهد. اگر فقط آرایه را چاپ کنید عضو حذف‌شده را نمی‌بینید؛ باید مقدار برگشتی را در متغیر نگه دارید.



splice — حذف و اضافه از وسط



const nums = [1, 2, 3, 4, 5];
const removed = nums.splice(1, 2);   // از شماره 1، دو عضو حذف کن
console.log(removed);                // [2, 3] — عضوهای حذف‌شده
console.log(nums);                   // [1, 4, 5]

nums.splice(1, 0, "x", "y");  // از شماره 1، صفر حذف، x و y اضافه
console.log(nums);            // [1, "x", "y", 4, 5]










آرگومان اول splice شمارهٔ شروع است و آرگومان دوم تعداد عضوی که باید حذف شود. عضوهای حذف‌شده در یک آرایهٔ تازه برمی‌گردند و از آرایهٔ اصلی کم می‌شوند. اگر تعداد حذف صفر باشد و بعد از آن مقدارهای تازه بیایند، چیزی پاک نمی‌شود و همان مقدارها از آن شماره به بعد درج می‌شوند.



slice، concat، join



const letters = ["a", "b", "c", "d", "e"];
console.log(letters.slice(1, 3));            // ["b","c"] - اصلی دست نمی‌خورد
console.log(letters.concat(["f", "g"]));
console.log(letters.join(" - "));
console.log(letters);










slice(1, 3) از شمارهٔ ۱ تا قبل از شمارهٔ ۳ را در آرایهٔ جدید کپی می‌کند و letters را عوض نمی‌کند. concat عضوهای آرایهٔ دوم را به کپی آرایهٔ اول می‌چسباند. join عضو‌ها را با جداکننده‌ای که می‌دهید به یک رشته تبدیل می‌کند. چاپ آخر نشان می‌دهد آرایهٔ اصلی هنوز پنج حرف اول است.



مثال زنده: صف انتظار



const queue = [];

function render() {
  view.textContent = "صف: " + queue.join("، ");
}

addBtn.addEventListener("click", function () {
  let name = nameInput.value.trim();
  if (name === "") {
    name = "مهمان";
  }
  queue.push(name);
  nameInput.value = "";
  render();
});

nextBtn.addEventListener("click", function () {
  if (queue.length === 0) {
    info.textContent = "صف خالی است.";
  } else {
    const person = queue.shift();
    info.textContent = `نوبت ${person} است.`;
  }
  render();
});









صف خالی است.







صف یک آرایهٔ خالی است. نام کادر اگر بعد از trim خالی باشد، به‌جای آن «مهمان» گذاشته می‌شود و با push به انتهای صف می‌رود. دکمهٔ نفر بعدی با shift کسی را که زودتر آمده از ابتدای صف برمی‌دارد. join نام‌های باقی‌مانده را برای نمایش به یک متن تبدیل می‌کند. اگر صف خالی باشد، shift صدا زده نمی‌شود تا پیام «نوبت undefined» ساخته نشود.



slice (بدون p) کپی می‌گیرد و اصلی را تغییر نمی‌دهد؛ splice (با p) آرایه اصلی را تغییر می‌دهد. این دو را با هم اشتباه نگیرید.



اشتباه رایج: نوشتن arr = arr.push(5). خروجی push «طول جدید آرایه» است نه خود آرایه؛ پس arr عدد می‌شود!



تمرین: آرایه ["شنبه", "یکشنبه", "دوشنبه"] را بسازید، «جمعه» را به آخر و «پنجشنبه» را قبل از جمعه اضافه کنید (با push و splice) و نتیجه را با join و «، » چاپ کنید.
