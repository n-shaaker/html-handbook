۲۱) الگوهای رایج UI

بیشتر سایت‌ها چند الگوی تکراری دارند: سوالات متداول، تب، پنجره پاپ‌آپ، پیام کوتاه، منوی موبایل، جستجوی فوری و دکمه برگشت به بالا. در این درس هر کدام را با یک مثال زنده و کد کوتاه می‌بینید.

۱) آکاردئون / FAQ

با کلیک روی سؤال، فقط همان جواب باز می‌شود. ایده: کلاس is-open را روی آیتم عوض کنید.

برای سفارش‌های بالای ۵۰۰ هزار تومان رایگان است؛ در غیر این صورت ۴۵ هزار تومان.
معمولاً ۲ تا ۴ روز کاری در شهرهای بزرگ.
تا ۷ روز پس از تحویل، در صورت سالم بودن کالا.
btn.addEventListener("click", () => {
  const item = btn.closest(".accordion-item");
  item.classList.toggle("is-open");
});

۲) تب‌ها (Tabs)

چند بخش محتوا، یک فضا. تب فعال با aria-selected مشخص می‌شود.

این محصول برای استفاده روزمره طراحی شده و گارانتی ۱۲ ماهه دارد.
وزن: ۳۲۰ گرم · رنگ: سرمه‌ای · جنس: پلاستیک مقاوم
«کیفیت خوبی داشت.» — سارا · «ارسال سریع بود.» — علی 
tab.addEventListener("click", () => {
  // همه تب‌ها را خاموش کن، فقط همین را روشن کن
  // پنل متناظر را با aria-controls پیدا کن
});

۳) مودال (پنجره پاپ‌آپ)

برای تأیید حذف، ورود، یا پیام مهم. با کلیک بیرون یا کلید Escape بسته شود.

حذف حساب؟

این کار برگشت‌پذیر نیست. مطمئن هستید؟

function openModal() {
  backdrop.classList.add("is-open");
  document.body.classList.add("modal-open"); // اسکرول صفحه قفل شود
}

document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") closeModal();
});

۴) توست (پیام کوتاه گوشه صفحه)

بعد از ذخیره یا خطا، یک پیام چندثانیه‌ای نشان دهید و بعد حذفش کنید.

function showToast(message) {
  const el = document.createElement("div");
  el.className = "toast";
  el.textContent = message;
  stack.append(el);
  setTimeout(() => el.remove(), 2800);
}

۵) منوی همبرگری (موبایل)

در عرض کم، لینک‌ها پشت دکمه «منو» پنهان می‌شوند. کلاس is-open منو را باز می‌کند.

فروشگاه نمونه
خانه محصولات درباره تماس

پنجره را باریک کنید تا دکمه منو دیده شود؛ در عرض بزرگ لینک‌ها کنار هم می‌آیند.

menuToggle.addEventListener("click", () => {
  const open = siteNav.classList.toggle("is-open");
  menuToggle.setAttribute("aria-expanded", open);
});

۶) فیلتر زنده (جستجوی لیست)

با هر حرفی که کاربر تایپ می‌کند، آیتم‌های نامرتبط مخفی می‌شوند. پایه بسیاری از جستجوهای ساده سایت است.

  • چای ایرانی ممتاز
  • کباب کوبیده
  • فسنجان خانگی
  • دوغ محلی
  • بستنی سنتی
  • سالاد شیرازی

موردی پیدا نشد.

filterInput.addEventListener("input", () => {
  const q = filterInput.value.trim().toLowerCase();
  items.forEach((li) => {
    li.classList.toggle("is-hidden", !li.textContent.toLowerCase().includes(q));
  });
});

۷) دکمه برگشت به بالا

بعد از اسکرول زیاد ظاهر می‌شود و با کلیک نرم به ابتدای صفحه می‌رود.

صفحه را پایین بکشید تا دکمه آبی گوشه ظاهر شود.

window.addEventListener("scroll", () => {
  backTop.classList.toggle("is-visible", window.scrollY > 400);
});

backTop.addEventListener("click", () => {
  window.scrollTo({ top: 0, behavior: "smooth" });
});

جمع‌بندی

الگو ایده JS
آکاردئون کلیک → کلاس باز/بسته
تب کلیک → پنل فعال + aria-selected
مودال نمایش لایه + Escape / کلیک بیرون
توست createElement + setTimeout برای حذف
منوی موبایل classList.toggle("is-open")
فیلتر زنده رویداد input + مقایسه متن
برگشت بالا رویداد scroll + scrollTo

تمرین: ۱) در آکاردئون اجازه دهید چند آیتم هم‌زمان باز بمانند. ۲) به مودال یک فیلد ایمیل و دکمه «ارسال» اضافه کنید که بعد از کلیک توست نشان دهد و مودال را ببندد. ۳) فیلتر را طوری عوض کنید که هم نام محصول و هم دسته‌بندی (data-cat) را جستجو کند.
