۱۲) قالب JSON

JSON (جِی‌سان) یک قالب متنی برای ذخیره و جابه‌جایی داده است. سرورها معمولاً داده را به شکل JSON می‌فرستند. ظاهرش شبیه شیء JavaScript است ولی چند قانون سخت‌تر دارد.

{
  "name": "سارا",
  "age": 25,
  "skills": ["HTML", "CSS", "JS"],
  "isStudent": true,
  "address": { "city": "تهران" }
}
قانون JSONدرستغلط
کلیدها حتماً با گیومه دوتایی"name": 1name: 1
رشته‌ها فقط با گیومه دوتایی"سارا"'سارا'
بدون کامای آخر[1, 2][1, 2,]
تابع، undefined، NaN و توضیح (comment) ممنوعnullfunction، undefined، //

مقدارهای مجاز در JSON فقط این‌ها هستند: رشته، عدد، true/false، null، آرایه و شیء.

JSON.stringify — شیء به متن

const user = { name: "علی", age: 30, skills: ["JS", "React"] };

const text = JSON.stringify(user);
console.log(text);
console.log(typeof text);

console.log(JSON.stringify(user, null, 2));   // مرتب و خوانا با ۲ فاصله

JSON.stringify شیء را به متن JSON تبدیل می‌کند. نتیجه از نوع رشته است، حتی اگر شبیه شیء به نظر برسد. آرگومان دوم برای فیلتر کردن ویژگی‌هاست و اینجا null یعنی همهٔ ویژگی‌های قابل‌تبدیل بمانند. آرگومان سوم، اگر عدد باشد، متن را با همان تعداد فاصله توگذاری می‌کند تا خواندن فایل راحت‌تر شود.






JSON.parse — متن به شیء



const json = '{"title":"کتاب JS","price":250000,"tags":["آموزش","برنامه‌نویسی"]}';

const book = JSON.parse(json);
console.log(book.title);     // کتاب JS
console.log(book.tags[1]);   // برنامه‌نویسی
console.log(typeof book);    // object



JSON.parse متن JSON را به مقدار JavaScript برمی‌گرداند. بعد از تبدیل، book.title یک ویژگی واقعی است و book.tags آرایه. اگر متن قانون JSON را نقض کند، این تابع خطا می‌دهد و اجرا همان‌جا متوقف می‌شود، مگر اینکه خطا را با try بگیرید.










چه چیزهایی در stringify گم یا عوض می‌شوند؟



const order = {
  id: 15,
  note: undefined,                       // حذف می‌شود
  print: function () { return "..."; },  // حذف می‌شود
  createdAt: new Date("2026-03-21T08:30:00Z"),  // به رشته تبدیل می‌شود
  discount: NaN                          // null می‌شود
};

const saved = JSON.stringify(order);
console.log(saved);
// {"id":15,"createdAt":"2026-03-21T08:30:00.000Z","discount":null}

const restored = JSON.parse(saved);
console.log(typeof restored.createdAt);  // string ← دیگر Date نیست!
console.log(new Date(restored.createdAt).getFullYear());   // 2026 ← دوباره Date ساختیم



تابع‌ها و مقدار undefined در JSON جایی ندارند و هنگام تبدیل حذف می‌شوند. تاریخ به رشتهٔ استاندارد زمان تبدیل می‌شود و بعد از parse دیگر شیء Date نیست، مگر اینکه خودتان دوباره new Date بسازید. NaN به null تبدیل می‌شود. این تفاوت‌ها وقتی مهم می‌شوند که داده را ذخیره کنید و بعد انتظار نوع اولیه را داشته باشید.










بعد از JSON.parse تاریخ‌ها به شکل رشته برمی‌گردند (مثل "2026-03-21T08:30:00.000Z" که همیشه به وقت UTC است)؛ اگر لازم دارید، دوباره با new Date(...) به Date تبدیلشان کنید.



مثال زنده: بررسی‌کننده JSON



const editor = document.getElementById("json-editor");
const checkBtn = document.getElementById("json-btn");
const output = document.getElementById("json-out");

checkBtn.addEventListener("click", () => {
  try {
    const data = JSON.parse(editor.value);
    output.textContent = "✔ JSON درست است:\n" + JSON.stringify(data, null, 2);
  } catch (err) {
    output.textContent = "✖ خطا: " + err.message;
  }
});



با کلیک، متن داخل ویرایشگر به JSON.parse داده می‌شود. اگر متن معتبر باشد، دوباره با stringify مرتب می‌شود تا کاربر ساختار را ببیند. اگر گیومه، کاما یا نوع مقدار غلط باشد، parse خطا پرتاب می‌کند و شاخهٔ catch فقط پیام خطا را نشان می‌دهد تا بقیهٔ صفحه از کار نیفتد.















برای امتحان، یکی از قانون‌های جدول را بشکنید: گیومه دور name را بردارید، به جای " از ' استفاده کنید یا بعد از آخرین عضو کاما بگذارید و دوباره «بررسی» را بزنید. JSON.parse با متن نامعتبر خطای SyntaxError می‌دهد؛ برای همین همیشه آن را داخل try...catch (درس بعد) می‌نویسیم.



کاربرد مهم دیگر: ذخیره آرایه و شیء در localStorage که فقط متن قبول می‌کند (در دوره پیشرفته).



اشتباه رایج: دادن شیء به JSON.parse یا فراموش کردن parse. JSON.parse ورودی متنی می‌گیرد و JSON.stringify خروجی متنی می‌دهد؛ مثلاً text.name روی رشته JSON مقدار undefined می‌دهد تا وقتی آن را parse نکرده‌اید.



تمرین: آرایه‌ای از ۳ شیء محصول (name، price، inStock) بسازید، با JSON.stringify(products, null, 2) به متن خوانا تبدیل و چاپ کنید، نوع (typeof) و طول متن را چاپ کنید، سپس با parse به آرایه برگردانید و نام محصول دوم را چاپ کنید. در آخر متن '{name: "کتاب"}' را parse کنید و خطا را با try...catch بگیرید و پیامش را نشان دهید.
