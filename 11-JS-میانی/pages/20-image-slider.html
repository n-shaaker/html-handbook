۲۰) اسلایدر عکس

اسلایدر چند تصویر را یکی‌یکی نشان می‌دهد. با دکمه جلو/عقب، نقطه‌ها، و در صورت تمایل پخش خودکار جابه‌جا می‌شود. این درس آرایه، اندیس، DOM، رویداد و setInterval را کنار هم می‌گذارد.

ایدهٔ کلی

  1. لیست اسلایدها را در یک آرایه نگه می‌داریم (آدرس عکس + توضیح).
  2. یک متغیر index می‌گوید الان کدام اسلاید دیده می‌شود.
  3. تابع showSlide همان اسلاید را روی img و متن توضیح می‌گذارد.
  4. دکمه‌ها فقط index را عوض می‌کنند و دوباره showSlide را صدا می‌زنند.

نسخه زنده

۱ / ۴

اسلاید ۱ — غذای اول

۱) داده اسلایدها

const slides = [
  { src: "../images/slide-1.jpg", caption: "اسلاید ۱ — غذای اول" },
  { src: "../images/slide-2.jpg", caption: "اسلاید ۲ — غذای دوم" },
  { src: "../images/slide-3.jpg", caption: "اسلاید ۳ — غذای سوم" },
  { src: "../images/slide-4.jpg", caption: "اسلاید ۴ — تصویر هیرو" },
];

let index = 0;

۲) نمایش یک اسلاید

function showSlide(i) {
  // اگر از ۰ کمتر یا از طول بیشتر شد، دور بزند
  index = (i + slides.length) % slides.length;
  const slide = slides[index];

  img.src = slide.src;
  img.alt = slide.caption;
  caption.textContent = slide.caption;
  counter.textContent = `${index + 1} / ${slides.length}`;
}

عملگر % (باقی‌مانده) باعث می‌شود بعد از آخرین اسلاید دوباره به اول برگردید و قبل از اولی به آخر بروید.

۳) دکمه‌ها و نقطه‌ها

prevBtn.addEventListener("click", () => showSlide(index - 1));
nextBtn.addEventListener("click", () => showSlide(index + 1));

// هر نقطه یک دکمه است که مستقیم به همان اندیس می‌رود
dot.addEventListener("click", () => showSlide(n));

۴) پخش خودکار با setInterval

let timerId = null;

function startAutoplay() {
  timerId = setInterval(() => showSlide(index + 1), 3000); // هر ۳ ثانیه
}

function stopAutoplay() {
  clearInterval(timerId);
  timerId = null;
}

خطای متداول: چند بار پشت‌سرهم setInterval را بدون clearInterval صدا بزنید؛ چند تایمر همزمان می‌مانند و اسلاید تند تند عوض می‌شود.

جمع‌بندی

  • آرایه = لیست اسلایدها
  • index = اسلاید فعلی
  • showSlide = یک جا برای به‌روز کردن DOM
  • رویداد کلیک = عوض کردن اندیس
  • setInterval / clearInterval = پخش و توقف خودکار

تمرین: ۱) یک اسلاید پنجم اضافه کنید. ۲) با کلیدهای جهت‌دار صفحه‌کلید (ArrowLeft / ArrowRight) جلو و عقب بروید. ۳) وقتی ماوس روی اسلایدر است پخش خودکار را متوقف کنید.
