۵) تاریخ و زمان (Dates)

با new Date() یک شیء تاریخ ساخته می‌شود. این شیء در اصل فقط یک لحظه از زمان را نگه می‌دارد: تعداد میلی‌ثانیه‌ها از ۱ ژانویه ۱۹۷۰ به وقت جهانی UTC. وقتی آن را چاپ می‌کنیم، مرورگر همان لحظه را با تقویم میلادی و منطقهٔ زمانی کامپیوتر کاربر نشان می‌دهد. چند شکل برای ساختن تاریخ وجود دارد و در شکل عددی، شمارهٔ ماه از صفر شروع می‌شود. اگر این دو را قاطی کنید، تاریخ یک ماه یا چند ساعت جابه‌جا می‌شود.

const now = new Date();
console.log(now);          // تاریخ و ساعت همین الان

const exam = new Date(2026, 0, 15, 10, 30);   // سال، ماه، روز، ساعت، دقیقه
console.log(exam);         // Thu Jan 15 2026 10:30:00 ... ← ماه 0 یعنی ژانویه!

const d2 = new Date("2026-03-21");         // فقط تاریخ ← نیمه‌شب UTC
console.log(d2);           // در ایران: Sat Mar 21 2026 03:30:00 GMT+0330

const d3 = new Date("2026-03-21T00:00");   // تاریخ + ساعت (بدون Z) ← وقت محلی
console.log(d3);           // Sat Mar 21 2026 00:00:00 GMT+0330

const overflow = new Date(2026, 12, 1);    // ماه 12 وجود ندارد ← می‌رود سال بعد
console.log(overflow);     // Fri Jan 01 2027 ...

new Date() بدون آرگومان، لحظهٔ فعلی را می‌سازد. در شکل عددی، آرگومان‌ها به ترتیب سال، ماه، روز، ساعت و دقیقه‌اند و ماه از صفر است؛ پس 0 ژانویه است نه ماه اول تقویم انسانی اگر از یک بشمارید. رشتهٔ "2026-03-21" به‌عنوان نیمه‌شب UTC خوانده می‌شود و در منطقهٔ ایران چند ساعت جلوتر دیده می‌شود. اگر ساعت را هم در رشته بنویسید و Z نگذارید، همان ساعت به‌وقت محلی تفسیر می‌شود. ماه 12 وجود ندارد و JavaScript به‌جای خطا، تاریخ را به سال بعد سرریز می‌کند.






خروجی‌های بالا برای کامپیوتری با منطقه زمانی ایران (UTC+3:30) نوشته شده‌اند؛ اگر ساعت سیستم شما روی منطقه دیگری باشد، ساعت چاپ‌شده فرق می‌کند. نکته مهم: رشته‌ای مثل "2026-03-21" (فقط تاریخ) به وقت UTC خوانده می‌شود، ولی new Date(2026, 2, 21) و "2026-03-21T00:00" به وقت محلی.



گرفتن بخش‌های تاریخ





متدخروجی


getFullYear()سال میلادی (۴ رقمی)


getMonth()ماه میلادی: ۰ تا ۱۱ (۰ = ژانویه، ۱۱ = دسامبر)


getDate()روز ماه: ۱ تا ۳۱


getDay()روز هفته: ۰ (یکشنبه) تا ۶ (شنبه)


getHours() / getMinutes() / getSeconds()ساعت / دقیقه / ثانیه


getTime()میلی‌ثانیه از ۱ ژانویه ۱۹۷۰ (UTC)





const today = new Date();
const weekDays = ["یکشنبه", "دوشنبه", "سه‌شنبه", "چهارشنبه", "پنجشنبه", "جمعه", "شنبه"];

console.log("سال:", today.getFullYear());
console.log("ماه:", today.getMonth() + 1);          // +1 برای نمایش به انسان
console.log("روز:", today.getDate());
console.log("روز هفته:", weekDays[today.getDay()]);

const hh = String(today.getHours()).padStart(2, "0");
const mm = String(today.getMinutes()).padStart(2, "0");
console.log("ساعت:", hh + ":" + mm);               // مثلاً 09:05 نه 9:5



getFullYear سال چهاررقمی میلادی را می‌دهد. getMonth ماه را از صفر می‌شمارد، پس برای نمایش به انسان یک واحد به آن اضافه می‌شود. getDate روز ماه است و getDay شمارهٔ روز هفته از یکشنبه. ساعت و دقیقه عددند؛ padStart آن‌ها را به متن دو رقمی تبدیل می‌کند تا ۹ و ۵ به‌شکل ۰۹:۰۵ دیده شوند.










همه این متدها بخش‌های تاریخ میلادی را برمی‌گردانند. getDay() هفته را از یکشنبه شروع می‌کند (عدد ۰)، نه از شنبه؛ برای همین آرایه weekDays را از یکشنبه نوشتیم.



تاریخ شمسی با toLocaleDateString



JavaScript تقویم شمسی جداگانه ندارد؛ ولی متدهای toLocaleDateString و toLocaleTimeString با زبان "fa-IR" همان لحظه را در تقویم هجری شمسی و با رقم‌های فارسی نمایش می‌دهند. خروجی این متدها یک رشته است، نه عدد.



const nowruz = new Date(2026, 2, 21);   // 21 مارس 2026 (ماه 2 = مارس)

console.log(nowruz.toLocaleDateString("fa-IR"));          // ۱۴۰۵/۱/۱
console.log(nowruz.getMonth());                            // 2 ← هنوز ماه میلادی!

const date = new Date();
console.log(date.toLocaleDateString("fa-IR"));             // تاریخ شمسی امروز
console.log(date.toLocaleTimeString("fa-IR"));             // ساعت با رقم فارسی



toLocaleDateString("fa-IR") همان لحظه را با تقویم و رقم فارسی نشان می‌دهد؛ برای ۲۱ مارس ۲۰۲۶ خروجی شمسی می‌شود. getMonth همچنان ماه میلادی ذخیره‌شده را برمی‌گرداند و با این نمایش فارسی عوض نمی‌شود. toLocaleTimeString فقط بخش ساعت را با همان زبان قالب‌بندی می‌کند.










اگر به عدد ماه یا سال شمسی برای محاسبه نیاز دارید، از getMonth() استفاده نکنید؛ چون همیشه ماه میلادی را می‌دهد.



فاصله بین دو تاریخ



اگر دو شیء Date را از هم کم کنیم، تفاضل به میلی‌ثانیه به دست می‌آید. برای تبدیل به روز، بر تعداد میلی‌ثانیه‌های یک روز تقسیم می‌کنیم.



const termStart = new Date(2026, 0, 1);    // 1 ژانویه 2026، وقت محلی
const nowruzDay = new Date(2026, 2, 21);   // 21 مارس 2026، وقت محلی
const diffMs = nowruzDay - termStart;              // تفاضل به میلی‌ثانیه
const DAY_MS = 1000 * 60 * 60 * 24;                // میلی‌ثانیه‌های یک روز
const days = Math.round(diffMs / DAY_MS);          // گرد کردن برای اطمینان
console.log(`${days} روز فاصله`);                  // 79 روز فاصله



اگر دو شیء تاریخ را از هم کم کنید، نتیجه اختلاف آن‌ها به میلی‌ثانیه است، نه به روز. تقسیم بر تعداد میلی‌ثانیهٔ یک شبانه‌روز این اختلاف را به روز تبدیل می‌کند. Math.round خطای کوچک اعشاری ناشی از تغییر ساعت محلی را به نزدیک‌ترین روز می‌برد. هر دو تاریخ با شکل عددی و وقت محلی ساخته شده‌اند تا مقایسه از یک مبدأ باشد.










در کشورهایی که ساعت تابستانی دارند، بعضی روزها ۲۳ یا ۲۵ ساعت‌اند و نتیجه تقسیم ممکن است مثلاً 78.958 شود؛ برای همین با Math.round گرد می‌کنیم.



مثال زنده ۱: ساعت دیجیتال



const clock = document.getElementById("clock");
const dateText = document.getElementById("date-text");

function updateClock() {
  const now = new Date();
  clock.textContent = now.toLocaleTimeString("fa-IR");
  dateText.textContent = now.toLocaleDateString("fa-IR");
}

updateClock();
setInterval(updateClock, 1000);   // هر ۱۰۰۰ میلی‌ثانیه (۱ ثانیه) دوباره اجرا کن



updateClock هر بار یک Date تازه می‌سازد و ساعت و تاریخ را با قالب فارسی در صفحه می‌نویسد. صدا زدن مستقیم تابع، صفحه را همان اول پر می‌کند تا یک ثانیه منتظر نمانید. setInterval همان تابع را هر ۱۰۰۰ میلی‌ثانیه دوباره اجرا می‌کند. این تابع در درس زمان‌بندی کامل‌تر می‌آید؛ اینجا فقط برای تازه نگه داشتن ساعت لازم است.











مثال زنده ۲: شمارش معکوس تا یک رویداد



تاریخ رویداد (مثلاً امتحان پایان‌ترم یا نوروز) را انتخاب کنید. مقدار <input type="date"> یک رشته مثل "2027-03-21" است؛ به آخرش "T00:00" اضافه می‌کنیم تا مثل d3 در بالا به وقت محلی خوانده شود.



const eventInput = document.getElementById("event-date");
const countdown = document.getElementById("countdown");

function updateCountdown() {
  if (eventInput.value === "") {
    countdown.textContent = "یک تاریخ انتخاب کنید.";
    return;
  }
  const target = new Date(eventInput.value + "T00:00");
  const diff = target - new Date();

  if (diff <= 0) {
    countdown.textContent = "این تاریخ گذشته است.";
    return;
  }
  const days = Math.floor(diff / (1000 * 60 * 60 * 24));
  const hours = Math.floor(diff / (1000 * 60 * 60)) % 24;
  const minutes = Math.floor(diff / (1000 * 60)) % 60;
  const seconds = Math.floor(diff / 1000) % 60;
  countdown.textContent = `${days} روز و ${hours} ساعت و ${minutes} دقیقه و ${seconds} ثانیه مانده`;
}

// مقدار اولیه کادر: نوروز سال بعد
eventInput.value = (new Date().getFullYear() + 1) + "-03-21";

eventInput.addEventListener("input", updateCountdown);
updateCountdown();
setInterval(updateCountdown, 1000);



اگر کادر تاریخ خالی باشد، تابع پیام راهنما می‌نویسد و با return بیرون می‌آید. مقدار کادر تاریخ فقط بخش روز است؛ چسباندن T00:00 آن را نیمه‌شب محلی می‌کند. اختلاف این لحظه با الان اگر صفر یا منفی باشد، تاریخ گذشته است. در غیر این صورت همان میلی‌ثانیه‌ها به روز، ساعت و دقیقه شکسته می‌شوند. باقیماندهٔ تقسیم با % جلوی این را می‌گیرد که مثلاً ساعت، کل روزها را هم داخل خودش نشان دهد.












اشتباه رایج: فراموش کردن اینکه getMonth() و پارامتر ماه در new Date(y, m, d) از صفر شروع می‌شوند؛ برای نمایش + 1 و برای ساختن تاریخ - 1 لازم است. new Date(2026, 3, 21) یعنی ۲۱ آوریل، نه مارس.



اشتباه رایج: ساختن رشته تاریخ با toISOString() برای کادر تاریخ. این متد ساعت را به UTC می‌برد؛ در ایران new Date(2026, 2, 21).toISOString() می‌شود "2026-03-20T20:30:00.000Z"، یعنی یک روز قبل! تاریخ محلی را با getFullYear، getMonth و getDate بسازید.



تمرین: برنامه‌ای بنویسید که تاریخ تولد کاربر را با <input type="date"> بگیرد و (الف) سن او را به سال کامل، (ب) تعداد روزهای مانده تا تولد بعدی‌اش و (ج) تاریخ تولدش را به شمسی (با toLocaleDateString("fa-IR")) در صفحه نشان دهد. راهنما: اگر تولد امسال گذشته است، تولد سال بعد را حساب کنید.
