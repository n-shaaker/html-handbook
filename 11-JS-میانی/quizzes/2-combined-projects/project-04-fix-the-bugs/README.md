## صورت مسئله

همکار تازه‌کارتان قبل از رفتن به مرخصی، برنامه «کارهای امروز» را نوشته و رفته است. برنامه باید فهرست کارها را نشان دهد، با دکمه‌ها فیلتر و مرتب کند، خلاصه‌ای از کارها نمایش دهد و بتواند کارها را از یک متن JSON وارد کند. ولی وقتی صفحه را باز می‌کنید... هیچ چیز کار نمی‌کند!

در کد `starter/app.js` **دقیقاً ۸ باگ** وجود دارد. همه به مباحث همین دوره مربوط‌اند. HTML و CSS سالم‌اند.

### گزارش‌هایی که از کاربران رسیده

1. صفحه کاملاً خالی است و فهرستی نمایش داده نمی‌شود.
2. (بعد از اینکه صفحه بالا آمد) بالای صفحه نوشته «undefined: ۲ از ۵ انجام شده».
3. بعد از اولین کلیک (مثلاً تیک زدن یک کار)، ترتیب کارها با ترتیب داده اصلی فرق می‌کند، در حالی که کسی دکمه مرتب‌سازی را نزده! دکمه «ترتیب اصلی» هم ترتیب را برنمی‌گرداند.
4. زیر فهرست نوشته «کوتاه‌ترین کار: ۱۲۰ دقیقه | طولانی‌ترین کار: ۵ دقیقه».
5. دکمه‌های «همه / مانده / انجام‌شده» هیچ کاری نمی‌کنند.
6. وقتی متن اشتباهی در کادر JSON می‌چسبانیم و «وارد کن» را می‌زنیم، هیچ پیامی نمی‌آید.

(بعضی گزارش‌ها بیش از یک باگ پشتشان است.)

## الزامات

1. هر ۸ باگ را در کد پیدا و **با کمترین تغییر لازم** اصلاح کنید. بازنویسی کامل برنامه قابل قبول نیست.
2. کنار `app.js` یک فایل `bugs-list.md` بسازید و برای هر باگ بنویسید: **باگ چه بود** (شماره خط در فایل اصلی starter و کد)، **چرا** اتفاق می‌افتاد، **چطور** درستش کردید.
3. بعد از اصلاح، این آزمون‌ها باید درست باشند:

   | عمل | نتیجه مورد انتظار |
   |---|---|
   | باز کردن صفحه | ۵ کار به ترتیب داده اصلی؛ بالای صفحه «کارهای امروز: ۲ از ۵ انجام شده \| مهم‌ترین کار: مرور کد همکار» |
   | متن زیر فهرست | «کوتاه‌ترین کار: ۵ دقیقه \| طولانی‌ترین کار: ۱۲۰ دقیقه» |
   | کلیک «مانده» | فقط ۳ کار انجام‌نشده؛ دکمه «مانده» حالت فعال (`aria-pressed="true"`) |
   | کلیک «مرتب بر اساس اولویت» و بعد «ترتیب اصلی» | اول «مرور کد همکار» بالا می‌آید؛ بعد دوباره ترتیب داده اصلی |
   | تیک زدن «نوشتن گزارش هفتگی» | خلاصه بالا «۳ از ۵ انجام شده» شود |
   | وارد کردن `[{title: "x"}]` | پیام خطای فارسی در `#import-msg` و برنامه همچنان کار کند |
   | وارد کردن `{"title":"x"}` | پیام خطای فارسی (آرایه نیست)، برنامه نشکند |
   | وارد کردن `[{"id":10,"title":"خرید نان","priority":1,"minutes":10,"done":false}]` | «۱ کار وارد شد.» و فهرست فقط همین کار را نشان دهد |

4. Console در هیچ‌کدام از این مراحل خطای قرمز نشان ندهد.

## محدودیت‌ها

- فایل‌های `index.html` و `style.css` را تغییر ندهید.
- `var` در کد نهایی نباشد.
- `innerHTML` با داده کاربر و رویداد اینلاین اضافه نکنید.
- ساختار کلی برنامه (state + `render()`) را نگه دارید.

## امتیازی (حداکثر ۲ نمره اضافه)

- بعد از وارد کردن موفق JSON، کادر متن خالی شود و فیلتر به «همه» برگردد (دکمه «همه» هم فعال شود).

## نکته استاد

- از بالای Console شروع کنید: اولین خطای قرمز را بخوانید، روی نام فایل و شماره خط کنارش کلیک کنید و فقط همان را درست کنید. یک خطای اجرایی، اجرای بقیه کد را متوقف می‌کند؛ پس بعضی باگ‌ها تا اصلاح باگ قبلی خودشان را نشان نمی‌دهند.
- همه باگ‌ها «خطای قرمز» نمی‌دهند؛ بعضی فقط نتیجه غلط تولید می‌کنند. آزمون‌های جدول را یکی‌یکی امتحان کنید.
- برای هر متد آرایه از خودتان بپرسید: «این متد چه چیزی **برمی‌گرداند** و آیا آرایه اصلی را **تغییر می‌دهد**؟»
