# مبحث ۱۲: قالب JSON — تمرین‌های جداگانه

درس مرتبط: [۱۲) قالب JSON](../../../pages/12-json.html)

ابزارهای این مبحث: `JSON.stringify` و `JSON.parse`. خروجی در **Console** است.

## تمرین ۱ — رفت و برگشت ⭐

**هدف:** تبدیل شیء به متن JSON و برگرداندن آن به شیء.

**صورت مسئله:** اطلاعات یک کتاب باید به صورت متن برای سرور فرستاده شود و جواب سرور دوباره شیء شود.

**الزامات:**
- شیء `book` با `title`، `author`، `pages` و `available` بسازید.
- با `JSON.stringify` آن را متن کنید و متن و `typeof` آن را چاپ کنید.
- با `JSON.parse` دوباره شیء بسازید و `title` آن را چاپ کنید.
- نشان دهید نتیجه parse یک **شیء جدید** است (`copy === book` برابر `false`).

**تست‌ها / خروجی مورد انتظار:**
```
{"title":"شازده کوچولو","author":"اگزوپری","pages":96,"available":true}
نوع: string
عنوان از روی JSON: شازده کوچولو
همان شیء است؟ false
```

## تمرین ۲ — JSON خوانا و چیزهایی که جا می‌مانند ⭐⭐

**هدف:** چاپ JSON با تورفتگی و شناختن مقدارهایی که JSON نگه نمی‌دارد.

**صورت مسئله:** یک شیء تنظیمات، متد `sayHi`، ویژگی `undefined` و یک `Date` دارد. می‌خواهیم ببینیم بعد از JSON چه می‌ماند.

**الزامات:**
- با `JSON.stringify(obj, null, 2)` نسخه خوانا (با تورفتگی) چاپ کنید.
- نشان دهید متد و ویژگی `undefined` در خروجی **نیستند**.
- بعد از parse، نوع `createdAt` را چاپ کنید (رشته شده، نه Date).
- با `new Date(...)` دوباره از آن رشته تاریخ بسازید و سالش را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
{
  "theme": "dark",
  "createdAt": "2026-03-21T08:30:00.000Z"
}
sayHi بعد از JSON هست؟ false
نوع createdAt بعد از parse: string
سال: 2026
```

## تمرین ۳ — کارهای ذخیره‌شده ⭐⭐⭐

**هدف:** خواندن آرایه از متن JSON، کار با آن و ساختن دوباره متن JSON.

**صورت مسئله:** فهرست کارهای یک کاربر به صورت متن JSON رسیده:
`'[{"title":"خرید نان","done":true},{"title":"تمرین JS","done":false},{"title":"ورزش","done":false}]'`

**الزامات:**
- متن را با `JSON.parse` به آرایه تبدیل کنید.
- تعداد کارهای انجام‌شده را با `filter` بشمارید.
- یک کار تازه `{ title: "زنگ به مادربزرگ", done: false }` اضافه کنید.
- کار «تمرین JS» را انجام‌شده کنید (با `find`).
- آرایه را دوباره به JSON تبدیل و چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
تعداد کارها: 3 | انجام‌شده: 1
بعد از تغییرات: 4 کار، 2 انجام‌شده
[{"title":"خرید نان","done":true},{"title":"تمرین JS","done":true},{"title":"ورزش","done":false},{"title":"زنگ به مادربزرگ","done":false}]
```

## اشتباه‌های رایج این مبحث

- در JSON کلیدها و رشته‌ها حتماً با **دابل کوتیشن** (`"`) هستند؛ `{name: 'علی'}` JSON معتبر نیست.
- `JSON.parse` روی شیء (نه متن) معنی ندارد؛ ورودی‌اش باید **رشته** باشد.
- تابع‌ها و `undefined` در `stringify` حذف می‌شوند و `Date` به رشته تبدیل می‌شود.
- ویرگول اضافه آخر (`[1, 2,]`) در JSON خطاست.
- متن JSON خراب، `SyntaxError` می‌دهد؛ مدیریتش را در درس بعد (try/catch) یاد می‌گیریم.
