# مبحث ۵: تاریخ و زمان — تمرین‌های جداگانه

درس مرتبط: [۵) تاریخ و زمان (Dates)](../../../pages/05-dates.html)

ابزارهای این مبحث: `new Date(...)`، `getFullYear`، `getMonth`، `getDate`، `getDay`، `getHours`، `getMinutes`، `toLocaleDateString("fa-IR")`، تفریق دو تاریخ و `padStart`. خروجی در **Console** است.

## تمرین ۱ — امروز چندم است؟ ⭐

**هدف:** خواندن بخش‌های تاریخ امروز با متدهای `get...`.

**صورت مسئله:** یک ویجت کوچک می‌خواهد تاریخ امروز را به چند شکل نشان دهد.

**الزامات:**
- با `new Date()` تاریخ امروز را بسازید.
- سال، ماه میلادی (یادتان باشد `getMonth` از ۰ شروع می‌شود) و روز ماه را چاپ کنید.
- اسم روز هفته را از آرایه `["یکشنبه", "دوشنبه", ..., "شنبه"]` و `getDay()` بخوانید.
- تاریخ شمسی را با `toLocaleDateString("fa-IR")` چاپ کنید.

**تست‌ها / خروجی مورد انتظار:** (به تاریخ امروز بستگی دارد؛ شکل خروجی این است)
```
سال: 2026
ماه: 10
روز: 26
روز هفته: دوشنبه
تاریخ شمسی: ۱۴۰۵/۸/۴
```

## تمرین ۲ — چند روز مانده؟ ⭐⭐

**هدف:** محاسبه فاصله دو تاریخ به روز با تفریق و `Math.round`.

**صورت مسئله:** دانش‌آموزان می‌خواهند بدانند از اول ژانویه تا نوروز و از امروز تا نوروز سال بعد چند روز است.

**الزامات:**
- ثابت `DAY_MS` (تعداد میلی‌ثانیه‌های یک روز) را تعریف کنید.
- تابع `daysBetween(start, end)` تعداد روزهای بین دو تاریخ را برگرداند.
- با تاریخ‌های ثابت امتحان کنید (جدول تست‌ها).
- تعداد روزهای مانده تا ۲۱ مارس سال بعد را از امروز چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
daysBetween(1 ژانویه 2026، 21 مارس 2026) → 79
daysBetween(20 مه 2026، 1 ژوئن 2026) → 12
تا نوروز سال بعد: ... روز   (به امروز بستگی دارد)
```

## تمرین ۳ — ساعت و روز اضافه ⭐⭐⭐

**هدف:** ساختن تاریخ جدید از تاریخ قبلی (سرریز روز) و قالب‌بندی ساعت با `padStart`.

**صورت مسئله:** سامانه کتابخانه کتاب را برای چند روز امانت می‌دهد و باید تاریخ برگشت و ساعت تحویل را درست نشان دهد.

**الزامات:**
- تابع `addDays(date, n)` یک **تاریخ جدید** برگرداند که `n` روز بعد است (تاریخ ورودی عوض نشود). از `new Date(سال، ماه، روز + n)` استفاده کنید.
- تابع `formatDate(date)` خروجی `سال/ماه/روز` میلادی بدهد (مثل `2026/2/2`).
- تابع `formatTime(date)` ساعت و دقیقه را دو رقمی کند (مثل `09:05`).
- تابع `weekDayName(date)` اسم فارسی روز هفته را برگرداند.

**تست‌ها / خروجی مورد انتظار:**
```
امانت: 2026/1/30 — برگشت (3 روز بعد): 2026/2/2
تاریخ امانت عوض نشد: 2026/1/30
ساعت تحویل: 09:05
نوروز 2026 چه روزی است؟ شنبه
```

## اشتباه‌های رایج این مبحث

- `getMonth()` از **۰** شروع می‌شود (ژانویه = ۰)؛ موقع چاپ `+ 1` و موقع ساختن `- 1` لازم است.
- `getDay()` روز هفته است (۰ = یکشنبه) و `getDate()` روز ماه؛ این دو را قاطی نکنید.
- `new Date("2026-03-21")` به وقت UTC ساخته می‌شود و ممکن است یک روز جابه‌جا شود؛ `"T00:00"` اضافه کنید یا از `new Date(2026, 2, 21)` استفاده کنید.
- تفریق دو تاریخ **میلی‌ثانیه** می‌دهد، نه روز.
- `getHours()` عدد است؛ برای `09` باید اول با `String(...)` متنش کنید و بعد `padStart(2, "0")`.
