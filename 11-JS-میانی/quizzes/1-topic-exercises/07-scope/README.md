# مبحث ۷: محدوده دسترسی (Scope) — تمرین‌های جداگانه

درس مرتبط: [۷) محدوده دسترسی (Scope)](../../../pages/07-scope.html)

در این مبحث می‌بینیم هر متغیر **کجا** دیده می‌شود: سراسری (global)، داخل تابع، یا داخل بلوک `{ }`. خروجی در **Console** است.

## تمرین ۱ — کی کجا دیده می‌شود؟ ⭐

**هدف:** تشخیص متغیر سراسری، متغیر تابعی و متغیر بلوکی.

**صورت مسئله:** یک سایت فروشگاهی اسم سایت را سراسری نگه می‌دارد، ولی پیام خوش‌آمد و تخفیف فقط داخل تابع و بلوک ساخته می‌شوند.

**الزامات:**
- `const siteName = "فروشگاه نارنج"` را بیرون از همه تابع‌ها تعریف کنید.
- تابع `welcome()` یک متغیر محلی `message` بسازد که از `siteName` استفاده کند و آن را چاپ کند.
- داخل یک `if` متغیر `discount` را با `let` بسازید و همان‌جا چاپش کنید.
- بیرون از تابع و بلوک، با `typeof` نشان دهید `message` و `discount` آنجا وجود ندارند (اسمشان را مستقیم صدا نزنید، خطا می‌دهد).

**تست‌ها / خروجی مورد انتظار:**
```
به فروشگاه نارنج خوش آمدید
تخفیف امروز: 15 درصد
بیرون از تابع، message: undefined
بیرون از بلوک، discount: undefined
siteName همه جا دیده می‌شود: فروشگاه نارنج
```

## تمرین ۲ — سایه‌انداختن (Shadowing) ⭐⭐

**هدف:** فهمیدن اینکه پارامتر یا متغیر هم‌نام داخل تابع، متغیر بیرونی را تغییر نمی‌دهد.

**صورت مسئله:** در یک بازی، `score` سراسری امتیاز بازیکن است. یک تابع فقط «پیش‌نمایش» امتیاز با جایزه را می‌دهد و نباید امتیاز اصلی را عوض کند؛ تابع دیگر واقعاً امتیاز اضافه می‌کند.

**الزامات:**
- `let score = 10` سراسری.
- تابع `previewBonus(score)` (پارامتر هم‌نام) مقدار `score + 5` را **برگرداند**.
- تابع `addBonus()` (بدون پارامتر) به `score` سراسری ۵ اضافه کند.
- بعد از هر صدا زدن، مقدار `score` سراسری را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
پیش‌نمایش: 15
امتیاز واقعی بعد از پیش‌نمایش: 10
امتیاز واقعی بعد از addBonus: 15
```

## تمرین ۳ — هزینه ارسال (رفع باگ محدوده) ⭐⭐⭐

**هدف:** جای درست تعریف متغیر را انتخاب کنید تا هم بیرون بلوک در دسترس باشد و هم بی‌جهت سراسری نشود.

**صورت مسئله:** همکارتان این کد را نوشته و خطای `cost is not defined` می‌گیرد:

```js
function getShippingCost(total) {
  if (total >= 500000) {
    let cost = 0;
  } else {
    let cost = 40000;
  }
  return cost;
}
```

**الزامات:**
- باگ را با تعریف `let cost;` در جای درست (داخل تابع، بیرون از `if`) رفع کنید؛ `cost` نباید سراسری شود.
- آرایه `cartPrices = [120000, 85000, 40000]` را با حلقه `for` جمع بزنید؛ متغیر جمع (`total`) بیرون حلقه و قیمت هر کالا داخل حلقه تعریف شود.
- با `typeof i` نشان دهید متغیر حلقه بعد از حلقه وجود ندارد.
- هزینه ارسال سبد و دو مبلغ آزمایشی را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
جمع سبد: 245000
بعد از حلقه، i: undefined
هزینه ارسال سبد: 40000
هزینه ارسال برای 600000: 0
هزینه ارسال برای 500000: 0
```

## اشتباه‌های رایج این مبحث

- متغیری که با `let` یا `const` داخل `{ }` ساخته شود، بیرون آن بلوک **وجود ندارد**.
- مقداردهی بدون `let`/`const` (مثل `total = 0`) یک متغیر سراسری ناخواسته می‌سازد.
- پارامتر هم‌نام با متغیر بیرونی، آن را **پنهان** می‌کند؛ تغییرش روی بیرونی اثری ندارد.
- `var` محدوده بلوکی ندارد و از `if` و `for` بیرون می‌زند؛ از آن استفاده نکنید.
- همه چیز را سراسری نکنید؛ متغیر را در **کوچک‌ترین** محدوده‌ای که لازم است تعریف کنید.
