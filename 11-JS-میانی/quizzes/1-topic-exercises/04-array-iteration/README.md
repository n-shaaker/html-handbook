# مبحث ۴: پیمایش آرایه — تمرین‌های جداگانه

درس مرتبط: [۴) پیمایش آرایه (forEach، map، filter، reduce)](../../../pages/04-array-iteration.html)

متدهای این مبحث: `forEach`، `map`، `filter`، `reduce`، `every`، `some`. تابع‌ها را با `function` بنویسید (تابع پیکانی در درس ۹ می‌آید). خروجی در **Console** است.

## تمرین ۱ — دمای هفته ⭐

**هدف:** چاپ هر عضو با `forEach` و ساختن آرایه جدید با `map`.

**صورت مسئله:** دمای پنج روز به سانتی‌گراد `[12, 15, 9, 20, 18]` است. برای یک دوست خارجی باید فارنهایت هم گزارش شود.

**الزامات:**
- با `forEach` و پارامتر دوم (اندیس)، برای هر روز یک خط چاپ کنید.
- با `map` آرایه `fahrenheit` را بسازید (فرمول: `c * 9 / 5 + 32`).
- آرایه اصلی `celsius` نباید عوض شود.

**تست‌ها / خروجی مورد انتظار:**
```
روز 1: 12 درجه
روز 2: 15 درجه
روز 3: 9 درجه
روز 4: 20 درجه
روز 5: 18 درجه
فارنهایت: 53.6,59,48.2,68,64.4
سانتی‌گراد: 12,15,9,20,18
```

## تمرین ۲ — صورت‌حساب رستوران ⭐⭐

**هدف:** جمع زدن با `reduce` (با مقدار اولیه) و جدا کردن با `filter`.

**صورت مسئله:** سفارش یک میز: ۲ کوبیده (۴۲۰٬۰۰۰)، ۳ دوغ (۴۵٬۰۰۰) و ۱ سالاد شیرازی (۷۵٬۰۰۰).

**الزامات:**
- آرایه `order` با اشیای `{ name, price, qty }` بسازید.
- جمع کل صورت‌حساب (`price * qty`) را با `reduce` و مقدار اولیه `0` حساب کنید.
- تعداد کل اقلام (جمع `qty`) را هم با `reduce` حساب کنید.
- با `filter` غذاهای ۱۰۰ هزار تومان به بالا را جدا و اسمشان را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
جمع کل: 1050000 تومان
تعداد اقلام: 6
گران‌ها: کوبیده
```

## تمرین ۳ — گزارش کلاس ⭐⭐⭐

**هدف:** زنجیره `filter` + `map` و پرسش‌های بله/خیر با `every` و `some`.

**صورت مسئله:** نمره‌ها: سارا ۱۸، علی ۱۲، رضا ۹، مریم ۱۶. مدیر مدرسه یک گزارش کوتاه می‌خواهد.

**الزامات:**
- با `every` بررسی کنید همه قبول (۱۰ به بالا) شده‌اند یا نه.
- با `some` بررسی کنید کسی ۱۷ یا بیشتر گرفته یا نه.
- با `filter` و بعد `map` اسم قبول‌شده‌ها را به‌دست آورید.
- میانگین قبول‌شده‌ها را با `reduce` حساب و با `toFixed(2)` چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
همه قبول شدند؟ false
کسی 17 به بالا دارد؟ true
قبول‌شده‌ها: سارا، علی، مریم
میانگین قبول‌شده‌ها: 15.33
```

## اشتباه‌های رایج این مبحث

- `forEach` چیزی برنمی‌گرداند؛ برای ساختن آرایه جدید از `map` استفاده کنید.
- فراموش کردن `return` داخل تابعِ `map` یا `filter` (نتیجه پر از `undefined` یا خالی می‌شود).
- `reduce` بدون مقدار اولیه، روی آرایه اشیا جواب عجیب و روی آرایه خالی خطا می‌دهد؛ همیشه مقدار اولیه (`0`) بدهید.
- `filter` همیشه آرایه برمی‌گرداند، حتی اگر فقط یک عضو پیدا شود.
- `every` روی آرایه خالی `true` می‌دهد؛ حواستان باشد.
