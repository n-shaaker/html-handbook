# مبحث ۱۴: DOM — انتخاب عنصرها — تمرین‌های جداگانه

درس مرتبط: [۱۴) DOM: انتخاب عنصرها](../../../pages/14-dom-selecting.html)

ابزارهای این مبحث: `getElementById`، `querySelector`، `querySelectorAll` و خواندن `textContent`. تغییر دادن صفحه درس بعد است؛ پس در این مبحث فقط **انتخاب کنید و نتیجه را در Console چاپ کنید**. HTML هر تمرین را در `solution/ex-n.html` ببینید (می‌توانید همان HTML را بردارید و فقط JS را خودتان بنویسید).

## تمرین ۱ — منوی کافه ⭐

**هدف:** انتخاب با id، کلاس و تگ.

**صورت مسئله:** صفحه یک کافه یک تیتر با `id="page-title"`، یک پاراگراف با کلاس `intro` و یک فهرست `ul#menu` با ۴ آیتم دارد.

**الزامات:**
- تیتر را با `getElementById` بگیرید و متنش را چاپ کنید.
- پاراگراف را با `querySelector(".intro")` بگیرید و متنش را چاپ کنید.
- تعداد آیتم‌های فهرست را با `querySelectorAll("#menu li")` چاپ کنید.
- متن اولین آیتم را با `querySelector` چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
عنوان: منوی کافه
معرفی: هر روز از ساعت ۸ صبح باز هستیم.
تعداد آیتم‌ها: 4
اولین آیتم: اسپرسو
```

## تمرین ۲ — جمع قیمت‌های ویترین ⭐⭐

**هدف:** پیمایش نتیجه `querySelectorAll` با `forEach` و تبدیل متن به عدد.

**صورت مسئله:** ویترین کافه ۴ آیتم دارد. هر آیتم `li.item` است با `span.name` و `span.price`؛ آیتم ناموجود کلاس `sold-out` هم دارد.

**الزامات:**
- همه `.price`ها را بگیرید و با `Number(...)` جمع بزنید.
- تعداد آیتم‌های موجود را با انتخابگر `.item:not(.sold-out)` بشمارید.
- اسم آیتم‌های ناموجود را با انتخابگر `.sold-out .name` بخوانید.
- نتیجه‌ها را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
جمع قیمت‌ها: 265000
تعداد موجودها: 3
ناموجود: کیک شکلاتی
```

## تمرین ۳ — انتخابگرهای ترکیبی و null ⭐⭐⭐

**هدف:** انتخابگر تودرتو (`#id .class tag`) و مدیریت حالتی که عنصری پیدا نمی‌شود (`null`).

**صورت مسئله:** صفحه منو دو بخش `#starters` و `#desserts` دارد که هر کدام چند `article.dish` با `h3` دارند. بخش نوشیدنی هنوز ساخته نشده.

**الزامات:**
- اسم پیش‌غذاها را با `querySelectorAll("#starters .dish h3")` جمع کنید و با «، » چاپ کنید.
- تعداد کل غذاها (`.dish`) را چاپ کنید.
- اولین دسر را با یک `querySelector` بخوانید.
- تابع `getText(selector)` بنویسید که اگر عنصر پیدا نشد (`null`) متن «پیدا نشد» و اگر پیدا شد `textContent` آن را برگرداند.
- `getText` را برای `#drinks h2` و `#starters h2` امتحان کنید.

**تست‌ها / خروجی مورد انتظار:**
```
پیش‌غذاها: میرزاقاسمی، سالاد شیرازی
تعداد کل غذاها: 4
اولین دسر: فالوده
getText("#drinks h2") → پیدا نشد
getText("#starters h2") → پیش‌غذا
```

## اشتباه‌های رایج این مبحث

- نوشتن `#` در `getElementById("#title")`؛ آنجا فقط اسم id را بنویسید. در `querySelector` اما `#` و `.` لازم است.
- `querySelector` فقط **اولین** عنصر را می‌دهد؛ برای همه از `querySelectorAll` استفاده کنید.
- خواندن `.textContent` از نتیجه `null` (عنصر پیدا نشده) خطای `Cannot read properties of null` می‌دهد؛ اول بررسی کنید.
- اجرای اسکریپت قبل از ساخته شدن HTML؛ `defer` را فراموش نکنید.
- `textContent` همیشه **رشته** است؛ برای جمع زدن، اول `Number(...)` کنید.
