# مبحث ۹: توابع پیکانی — تمرین‌های جداگانه

درس مرتبط: [۹) توابع پیکانی (Arrow Functions)](../../../pages/09-arrow-functions.html)

از این مبحث به بعد، برای callbackهای کوتاه از تابع پیکانی استفاده کنید. خروجی در **Console** است.

## تمرین ۱ — تبدیل به پیکانی ⭐

**هدف:** نوشتن تابع پیکانی کوتاه با `return` ضمنی، یک پارامتر و برگرداندن شیء.

**صورت مسئله:** این چهار تابع را به پیکانی تبدیل کنید و کوتاه‌ترین شکل درست را بنویسید:

```js
function square(n) { return n * n; }
function isAdult(age) { return age >= 18; }
function fullName(first, last) { return first + " " + last; }
function makeProduct(name, price) { return { name: name, price: price }; }
```

**الزامات:**
- هر چهار تابع با `const` و `=>` نوشته شوند.
- برای یک پارامتر پرانتز لازم نیست؛ برای دو پارامتر لازم است.
- `makeProduct` شیء را داخل **پرانتز** برگرداند: `=> ({ ... })`.
- هر تابع را یک بار امتحان کنید.

**تست‌ها / خروجی مورد انتظار:**
```
square(7) → 49
isAdult(15) → false
fullName("سارا", "احمدی") → سارا احمدی
makeProduct("کیبورد", 1500000) → { name: "کیبورد", price: 1500000 }
```

## تمرین ۲ — پیکانی در متدهای آرایه ⭐⭐

**هدف:** نوشتن callbackهای `filter`، `map`، `reduce` و `sort` با تابع پیکانی.

**صورت مسئله:** فروشگاه لوازم‌التحریر این کالاها را دارد:
دفتر ۴۵٬۰۰۰ (موجود)، خودکار ۱۵٬۰۰۰ (موجود)، کیف ۶۵۰٬۰۰۰ (ناموجود)، ماشین‌حساب ۳۲۰٬۰۰۰ (موجود).

**الزامات:**
- آرایه `products` با اشیای `{ name, price, inStock }`.
- اسم کالاهای موجود را با `filter` و `map` (پیکانی، یک خطی) به‌دست آورید.
- جمع قیمت کالاهای موجود را با `reduce` حساب کنید.
- یک کپی را بر اساس قیمت صعودی مرتب کنید و اسم‌ها را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
موجودها: دفتر، خودکار، ماشین‌حساب
جمع قیمت موجودها: 380000
از ارزان به گران: خودکار، دفتر، ماشین‌حساب، کیف
```

## تمرین ۳ — ماشین‌حساب انعام ⭐⭐⭐

**هدف:** تابع پیکانی با پارامتر پیش‌فرض، بدنه چندخطی با `{ }` و ترکیب چند تابع پیکانی.

**صورت مسئله:** یک کافه می‌خواهد برای چند صورت‌حساب، انعام و مبلغ نهایی را حساب کند و با ارقام فارسی نشان دهد.

**الزامات:**
- `calcTip = (bill, percent = 10) => ...` مبلغ انعام را گرد‌شده برگرداند.
- `formatToman = n => ...` عدد را با `toLocaleString("fa-IR")` و کلمه «تومان» برگرداند.
- `billSummary` یک تابع پیکانی **چندخطی** (با `{ }` و `return`) باشد که برای یک مبلغ، متن «مبلغ … + انعام … = …» بسازد.
- روی آرایه `[180000, 250000, 95000]` با `map` خلاصه‌ها را بسازید و با `forEach` چاپ کنید.
- انعام ۱۵ درصد را هم برای ۲۰۰٬۰۰۰ تومان امتحان کنید.

**تست‌ها / خروجی مورد انتظار:**
```
مبلغ ۱۸۰٬۰۰۰ تومان + انعام ۱۸٬۰۰۰ تومان = ۱۹۸٬۰۰۰ تومان
مبلغ ۲۵۰٬۰۰۰ تومان + انعام ۲۵٬۰۰۰ تومان = ۲۷۵٬۰۰۰ تومان
مبلغ ۹۵٬۰۰۰ تومان + انعام ۹٬۵۰۰ تومان = ۱۰۴٬۵۰۰ تومان
انعام ۱۵ درصد برای ۲۰۰٬۰۰۰: ۳۰٬۰۰۰ تومان
```

## اشتباه‌های رایج این مبحث

- با `{ }` در بدنه، `return` ضمنی از بین می‌رود؛ باید خودتان `return` بنویسید.
- `=> { name: "x" }` شیء برنمی‌گرداند؛ شیء را در پرانتز بگذارید: `=> ({ name: "x" })`.
- تابع پیکانی در `const` قبل از تعریف قابل صدا زدن نیست (درس ۸).
- تابع پیکانی `this` خودش را ندارد؛ برای متد شیء مناسب نیست (درس ۱۰).
- برای خوانایی، پیکانی را برای کارهای کوتاه به کار ببرید؛ تابع طولانی را اسم‌دار و جدا بنویسید.
