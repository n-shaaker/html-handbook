# مبحث ۱۰: کلمه کلیدی this — تمرین‌های جداگانه

درس مرتبط: [۱۰) کلمه کلیدی this](../../../pages/10-this.html)

`this` داخل متد شیء، به **همان شیئی** اشاره می‌کند که متد را صدا زده. خروجی در **Console** است.

## تمرین ۱ — ماشین من ⭐

**هدف:** نوشتن متد شیء که با `this` ویژگی‌های همان شیء را می‌خواند و تغییر می‌دهد.

**صورت مسئله:** برای یک بازی ماشین‌سواری، شیء `car` با برند و سرعت لازم است.

**الزامات:**
- شیء `car` با `brand: "پراید"` و `speed: 0`.
- متد `describe` (با `function`) متن «پراید با سرعت 0 کیلومتر» را برگرداند.
- متد `accelerate(amount)` سرعت را با `this.speed` زیاد کند.
- متد `brake()` سرعت را صفر کند.

**تست‌ها / خروجی مورد انتظار:**
```
پراید با سرعت 0 کیلومتر
پراید با سرعت 60 کیلومتر
پراید با سرعت 0 کیلومتر
```
(به ترتیب: اول، بعد از `accelerate(40)` و `accelerate(20)`، بعد از `brake()`)

## تمرین ۲ — معلم و شاگردها (پیکانی یا معمولی؟) ⭐⭐

**هدف:** انتخاب درست بین تابع معمولی و پیکانی برای متد و برای callback داخل متد.

**صورت مسئله:** این شیء کار نمی‌کند و `undefined` چاپ می‌کند:

```js
const classroom = {
  teacher: "خانم رضایی",
  students: ["سارا", "علی", "مریم"],
  intro: () => "معلم: " + this.teacher
};
```

**الزامات:**
- `intro` را به تابع معمولی تبدیل کنید تا اسم معلم را درست برگرداند.
- متد `list()` با `forEach` برای هر شاگرد چاپ کند «سارا شاگرد خانم رضایی است».
- callback داخل `forEach` **پیکانی** باشد تا `this` همان `classroom` بماند.
- در یک کامنت توضیح دهید چرا متد نباید پیکانی باشد ولی callback داخلش می‌تواند.

**تست‌ها / خروجی مورد انتظار:**
```
معلم: خانم رضایی
سارا شاگرد خانم رضایی است
علی شاگرد خانم رضایی است
مریم شاگرد خانم رضایی است
```

## تمرین ۳ — حساب بانکی و bind ⭐⭐⭐

**هدف:** دیدن گم شدن `this` وقتی متد جدا از شیء صدا زده می‌شود و درست کردنش با `bind`.

**صورت مسئله:** حساب بانکی مریم یک متد `deposit` دارد. برنامه‌نویس دیگری این متد را در یک متغیر گذاشته تا بعداً صدا بزند و حساب درست شارژ نمی‌شود.

**الزامات:**
- شیء `account` با `owner: "مریم"`، `balance: 100000` و متد `deposit(amount)` که موجودی جدید را برگرداند، و متد `report()`.
- `account.deposit(50000)` را مستقیم صدا بزنید.
- `const lostDeposit = account.deposit;` بسازید و در کامنت بنویسید چرا صدا زدنش کار نمی‌کند (`this` دیگر `account` نیست).
- با `bind` نسخه `safeDeposit` را بسازید و با آن ۲۵٬۰۰۰ واریز کنید.
- گزارش نهایی را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
موجودی بعد از واریز مستقیم: 150000
موجودی بعد از واریز با bind: 175000
حساب مریم: 175000 تومان
```

## اشتباه‌های رایج این مبحث

- نوشتن متد شیء به شکل پیکانی؛ پیکانی `this` خودش را ندارد و `this.name` را `undefined` می‌دهد.
- برعکس: callback داخل متد را با `function` نوشتن، که `this` را گم می‌کند. آنجا پیکانی بهتر است.
- جدا کردن متد از شیء (`const f = obj.method`) یا دادنش به جای دیگر، `this` را از بین می‌برد؛ `bind` لازم است.
- `this` به **جای تعریف** بستگی ندارد؛ به **شکل صدا زدن** بستگی دارد (`obj.method()`).
- فراموش کردن `this.` و نوشتن اسم ویژگی به تنهایی (`speed` به‌جای `this.speed`).
