# مبحث ۲: متدهای آرایه — تمرین‌های جداگانه

درس مرتبط: [۲) متدهای آرایه (Array Methods)](../../../pages/02-array-methods.html)

فقط از متدهای همین درس (`push`، `pop`، `shift`، `unshift`، `splice`، `slice`، `concat`، `join`) و درس قبل استفاده کنید. خروجی در **Console** است.

## تمرین ۱ — صف نانوایی ⭐

**هدف:** اضافه و کم کردن از اول و آخر آرایه با `push`، `shift` و `pop`.

**صورت مسئله:** در صف نانوایی «علی» و «سارا» ایستاده‌اند. «رضا» و «مریم» می‌رسند، نفر اول نان می‌گیرد و می‌رود، و نفر آخر خسته می‌شود و صف را ترک می‌کند.

**الزامات:**
- «رضا» و «مریم» را با **یک** `push` به آخر صف اضافه کنید.
- با `join("، ")` صف را چاپ کنید.
- با `shift` نفر اول را بردارید و اسمش را چاپ کنید (از مقدار برگشتی `shift` استفاده کنید).
- با `pop` نفر آخر را بردارید و اسمش را چاپ کنید.
- صف نهایی و تعدادش را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
صف: علی، سارا، رضا، مریم
نان گرفت: علی
از صف رفت: مریم
صف نهایی: سارا، رضا (2 نفر)
```

## تمرین ۲ — برنامه کلاسی ⭐⭐

**هدف:** فرق `splice` (آرایه را عوض می‌کند) با `slice` (کپی برمی‌گرداند).

**صورت مسئله:** برنامه امروز `["ریاضی", "فیزیک", "شیمی", "زبان", "ورزش"]` است. معلم شیمی نیامده و به‌جایش «ادبیات» و «هنر» گذاشته‌اند.

**الزامات:**
- با **یک** `splice`، «شیمی» را حذف و «ادبیات» و «هنر» را جایش بگذارید.
- درس حذف‌شده را از مقدار برگشتی `splice` چاپ کنید.
- برنامه جدید را چاپ کنید.
- با `slice` سه زنگ اول را جدا کنید و نشان دهید آرایه اصلی هنوز ۶ عضو دارد.

**تست‌ها / خروجی مورد انتظار:**
```
حذف شد: شیمی
برنامه جدید: ریاضی، فیزیک، ادبیات، هنر، زبان، ورزش
سه زنگ اول: ریاضی، فیزیک، ادبیات
تعداد درس‌های امروز هنوز: 6
```

## تمرین ۳ — فهرست مهمان‌های جشن ⭐⭐⭐

**هدف:** ترکیب `concat`، `unshift` و `splice` داخل تابع، با استفاده از مقدار برگشتی آن‌ها.

**صورت مسئله:** مادر و پدر هر کدام فهرست مهمان جدا دارند. باید فهرست‌ها یکی شوند، پدربزرگ اول فهرست بیاید و یک نفر که نمی‌تواند بیاید حذف شود.

**الزامات:**
- `momGuests = ["خاله مینا", "عمو رضا"]` و `dadGuests = ["دایی حسن", "عمه زری"]`.
- با `concat` فهرست `allGuests` را از این دو و `["مادربزرگ"]` بسازید؛ فهرست‌های اصلی نباید عوض شوند.
- تابع `addFirst(list, name)` با `unshift` مهمان را اول فهرست بگذارد و **تعداد جدید** را برگرداند.
- تابع `cancelGuest(list, index)` با `splice` مهمان آن اندیس را حذف کند و **اسمش** را برگرداند.
- «پدربزرگ» را اضافه و مهمان اندیس ۳ را لغو کنید و نتیجه‌ها را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
همه مهمان‌ها: خاله مینا، عمو رضا، دایی حسن، عمه زری، مادربزرگ
فهرست مادر هنوز 2 نفر است
تعداد بعد از اضافه شدن پدربزرگ: 6
لغو شد: دایی حسن
فهرست نهایی: پدربزرگ، خاله مینا، عمو رضا، عمه زری، مادربزرگ
```

## اشتباه‌های رایج این مبحث

- `splice` آرایه اصلی را **تغییر می‌دهد**؛ `slice` فقط کپی می‌گیرد.
- `slice(0, 3)` عضو اندیس ۳ را شامل **نمی‌شود**.
- `push` و `unshift` طول جدید را برمی‌گردانند، نه خود آرایه را.
- `splice` همیشه یک **آرایه** از حذف‌شده‌ها برمی‌گرداند (`["شیمی"]`)، نه یک رشته.
- `concat` آرایه جدید می‌سازد؛ اگر نتیجه‌اش را در متغیری نگذارید، گم می‌شود.
