## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«آرایه یک فهرست مرتب از مقدارهاست که همه در یک متغیر نگه داشته می‌شوند. وقتی چند دادهٔ هم‌نوع دارید، مثل نام میوه‌ها یا نمرهٔ چند دانش‌آموز، ساختن متغیر جدا برای هر کدام هم نام‌گذاری را شلوغ می‌کند و هم پیمایش را سخت. در آرایه هر مقدار یک شماره دارد و شماره از صفر شروع می‌شود. ترتیب عضو‌ها بخشی از معنی داده است: عضو اول با عضو دوم یکی نیست.»

«شماره‌گذاری (index) آرایه از صفر شروع می‌شود؛ پس شماره آخرین عضو همیشه length - 1 است.»

«کروشه‌ها آرایه را می‌سازند و عضو‌ها با کاما جدا می‌شوند. fruits[0] اولین عضو است، نه عضوی که انسان معمولاً «شمارهٔ ۱» می‌نامد. length تعداد عضو‌ها را می‌دهد و ویژگی است، نه متد. آخرین عضو را هم می‌توان با length - 1 خواند و هم با at(-1) که از انتها می‌شمارد. شمارهٔ منفی داخل کروشه، برخلاف at ، از انتها حساب نمی‌شود و undefined برمی‌گرداند.»

«نوشتن مقدار تازه در یک شمارهٔ موجود، همان عضو را عوض می‌کند. اگر شماره برابر length باشد، عضو جدیدی به انتها اضافه می‌شود، چون آن خانه هنوز خالی است. خود متغیر همچنان با const به همان آرایه اشاره می‌کند؛ آنچه عوض شده محتوای داخل فهرست است.»

**روی جزوه این عناوین را دنبال کنید:** *۱) آرایه‌ها (Arrays)* · *تغییر و اضافه کردن* · *آرایه می‌تواند هر نوعی داشته باشد* · *پیمایش با for و for...of*

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const fruits = ["سیب", "موز", "پرتقال"];

console.log(fruits);
console.log(fruits[0]);          // اولین عضو (شماره صفر)
console.log(fruits.length);      // تعداد عضوها
console.log(fruits[fruits.length - 1]);   // آخرین عضو
console.log(fruits.at(-1));               // آخرین عضو (روش جدیدتر و کوتاه‌تر)
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
fruits[1] = "انگور";            // تغییر عضو شماره 1
fruits[fruits.length] = "کیوی"; // اضافه به آخر (روش ساده‌ترش push است)
console.log(fruits);
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const mixed = [10, "متن", true, null, { name: "علی" }, [1, 2]];
console.log(mixed.length);
console.log(mixed[4].name);
console.log(mixed[5][1]);     // آرایه داخل آرایه
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«fruits با const تعریف شده ولی باز هم توانستیم عضوهایش را عوض کنیم. const فقط جلوی انتساب دوباره (مثل fruits = [] ) را می‌گیرد، نه تغییر محتوای آرایه.»

«عضو آرایه می‌تواند عدد، متن، بولین، null ، شیء یا حتی آرایهٔ دیگر باشد. mixed[4] شیء است، پس .name ویژگی آن شیء را می‌خواند. mixed[5] خودش آرایه است و [1] عضو دوم همان آرایهٔ داخلی را می‌دهد. آرایهٔ تو در تو وقتی به کار می‌آید که یک عضو، خودش چند مقدار مرتب داشته باشد.»

«حلقهٔ for با شماره کار می‌کند و هم شاخص و هم مقدار را در اختیار شما می‌گذارد. شرط i < colors.length باعث می‌شود آخرین عضو خوانده شود و یک خانه بعد از پایان آرایه خوانده نشود. for...of شماره نمی‌سازد و در هر دور خود مقدار را در متغیر می‌ریزد. اگر فقط مقدار لازم است، شکل دوم خواناتر است؛ اگر باید عضو را عوض کنید یا شماره را نشان دهید، به شاخص نیاز دارید.»

«typeof برای آرایه رشتهٔ "object" برمی‌گرداند، چون آرایه در این زبان نوعی شیء است. این خروجی آرایه را از شیء معمولی جدا نمی‌کند. Array.isArray مخصوص همین تشخیص است و فقط وقتی true می‌شود که مقدار واقعاً آرایه باشد.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
