## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«با new Date() یک شیء تاریخ ساخته می‌شود. این شیء در اصل فقط یک لحظه از زمان را نگه می‌دارد: تعداد میلی‌ثانیه‌ها از ۱ ژانویه ۱۹۷۰ به وقت جهانی UTC. وقتی آن را چاپ می‌کنیم، مرورگر همان لحظه را با تقویم میلادی و منطقهٔ زمانی کامپیوتر کاربر نشان می‌دهد. چند شکل برای ساختن تاریخ وجود دارد و در شکل عددی، شمارهٔ ماه از صفر شروع می‌شود. اگر این دو را قاطی کنید، تاریخ یک ماه یا چند ساعت جابه‌جا می‌شود.»

«const now = new Date(); console.log(now); // تاریخ و ساعت همین الان const exam = new Date(2026, 0, 15, 10, 30); // سال، ماه، روز، ساعت، دقیقه console.log(exam); // Thu Jan 15 2026 10:30:00 ... ← ماه 0 یعنی ژانویه! const d2 = new Date("2026-03-21"); // فقط تاریخ ← نیمه‌شب UTC console.log(d2); // در ایران: Sat Mar 21 2026 03:30:00 GMT+0330 const d3 = new Date("2026-03-21T00:00"); // تاریخ + ساعت (بدون Z) ← وقت محلی console.log(d3); // Sat Mar 21 2026 00:00:00 GMT+0330 const overflow = new Date(2026, 12, 1); // ماه 12 وجود ندارد ← می‌رود سال بعد console.log(overflow); // Fri Jan 01 2027 ... new Date() بدون آرگومان، لحظهٔ فعلی را می‌سازد. در شکل عددی، آرگومان‌ها به ترتیب سال، ماه، روز، ساعت و دقیقه‌اند و ماه از صفر است؛ پس 0 ژانویه است نه ماه اول تقویم انسانی اگر از یک بشمارید. رشتهٔ "2026-03-21" به‌عنوان نیمه‌شب UTC خوانده می‌شود و در منطقهٔ ایران چند ساعت جلوتر دیده می‌شود. اگر ساعت را هم در رشته بنویسید و Z نگذارید، همان ساعت به‌وقت محلی تفسیر می‌شود. ماه 12 وجود ندارد و JavaScript به‌جای خطا، تاریخ را به سال بعد سرریز می‌کند.»

«خروجی‌های بالا برای کامپیوتری با منطقه زمانی ایران (UTC+3:30) نوشته شده‌اند؛ اگر ساعت سیستم شما روی منطقه دیگری باشد، ساعت چاپ‌شده فرق می‌کند. نکته مهم: رشته‌ای مثل "2026-03-21" (فقط تاریخ) به وقت UTC خوانده می‌شود، ولی new Date(2026, 2, 21) و "2026-03-21T00:00" به وقت محلی .»

«const today = new Date(); const weekDays = ["یکشنبه", "دوشنبه", "سه‌شنبه", "چهارشنبه", "پنجشنبه", "جمعه", "شنبه"]; console.log("سال:", today.getFullYear()); console.log("ماه:", today.getMonth() + 1); // +1 برای نمایش به انسان console.log("روز:", today.getDate()); console.log("روز هفته:", weekDays[today.getDay()]); const hh = String(today.getHours()).padStart(2, "0"); const mm = String(today.getMinutes()).padStart(2, "0"); console.log("ساعت:", hh + ":" + mm); // مثلاً 09:05 نه 9:5 getFullYear سال چهاررقمی میلادی را می‌دهد. getMonth ماه را از صفر می‌شمارد، پس برای نمایش به انسان یک واحد به آن اضافه می‌شود. getDate روز ماه است و getDay شمارهٔ روز هفته از یکشنبه. ساعت و دقیقه عددند؛ padStart آن‌ها را به متن دو رقمی تبدیل می‌کند تا ۹ و ۵ به‌شکل ۰۹:۰۵ دیده شوند.»

**روی جزوه این عناوین را دنبال کنید:** *۵) تاریخ و زمان (Dates)* · *گرفتن بخش‌های تاریخ* · *تاریخ شمسی با toLocaleDateString* · *فاصله بین دو تاریخ*

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const now = new Date();
console.log(now);          // تاریخ و ساعت همین الان

const exam = new Date(2026, 0, 15, 10, 30);   // سال، ماه، روز، ساعت، دقیقه
console.log(exam);         // Thu Jan 15 2026 10:30:00 ... ← ماه 0 یعنی ژانویه!

const d2 = new Date("2026-03-21");         // فقط تاریخ ← نیمه‌شب UTC
console.log(d2);           // در ایران: Sat Mar 21 2026 03:30:00 GMT+0330

const d3 = new Date("2026-03-21T00:00");   // تاریخ + ساعت (بدون Z) ← وقت محلی
console.log(d3);           // Sat Mar 21 2026 00:00:00 GMT+0330

const overflow = new Date(2026, 12, 1);    // ماه 12 وجود ندارد ← می‌رود سال بعد
console.log(overflow);     // Fri Jan 01 2027 ...
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const today = new Date();
const weekDays = ["یکشنبه", "دوشنبه", "سه‌شنبه", "چهارشنبه", "پنجشنبه", "جمعه", "شنبه"];

console.log("سال:", today.getFullYear());
console.log("ماه:", today.getMonth() + 1);          // +1 برای نمایش به انسان
console.log("روز:", today.getDate());
console.log("روز هفته:", weekDays[today.getDay()]);

const hh = String(today.getHours()).padStart(2, "0");
const mm = String(today.getMinutes()).padStart(2, "0");
console.log("ساعت:", hh + ":" + mm);               // مثلاً 09:05 نه 9:5
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const nowruz = new Date(2026, 2, 21);   // 21 مارس 2026 (ماه 2 = مارس)

console.log(nowruz.toLocaleDateString("fa-IR"));          // ۱۴۰۵/۱/۱
console.log(nowruz.getMonth());                            // 2 ← هنوز ماه میلادی!

const date = new Date();
console.log(date.toLocaleDateString("fa-IR"));             // تاریخ شمسی امروز
console.log(date.toLocaleTimeString("fa-IR"));             // ساعت با رقم فارسی
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
