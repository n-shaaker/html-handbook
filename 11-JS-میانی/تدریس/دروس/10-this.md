## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«this یک کلمه کلیدی است که داخل تابع معمولی به «شیئی که تابع را صدا زده» اشاره می‌کند. مقدارش به این بستگی ندارد که تابع کجا نوشته شده ، بلکه به این بستگی دارد که چطور صدا زده شده . قانون ساده: در obj.method() هر چه قبل از نقطه است، this می‌شود.»

«const user = { name: "سارا", greet: function () { return "سلام، من " + this.name + " هستم"; } }; console.log(user.greet()); greet تابع معمولی است و با شکل user.greet() صدا زده می‌شود. چیزی که قبل از نقطه است user است، پس داخل تابع this همان شیء است و this.name مقدار «سارا» را می‌خواند. اگر پرانتز را فراموش کنید، تابع اجرا نمی‌شود و متن سلام ساخته نمی‌شود.»

«تابع پیکانی this خودش را ندارد const user2 = { name: "علی", normal: function () { return this.name; }, arrow: () => this.name // this اینجا مال بیرون است، نه user2 }; console.log("normal:", user2.normal()); // normal: علی console.log("arrow:", user2.arrow()); // arrow: ← خالی! چرا خالی؟ آکولاد شیء ( { } ) محدوده جدید نمی‌سازد ؛ پس this تابع پیکانی همان this بیرون از شیء است که در این صفحه window است. window.name یک ویژگی آماده مرورگر است که معمولاً رشته خالی است؛ برای همین چیزی چاپ نشد. (در ماژول یا حالت strict، this بیرونی undefined است و همین کد خطای TypeError می‌دهد.)»

«const shop = { name: "کتاب‌فروشی دانش", welcome: function () { return "به " + this.name + " خوش آمدید"; } }; console.log(shop.welcome()); // ✔ به کتاب‌فروشی دانش خوش آمدید const welcomeFn = shop.welcome; // فقط خود تابع کپی شد، نه shop console.log(welcomeFn()); // ✖ به خوش آمدید ← this دیگر shop نیست const fixed = shop.welcome.bind(shop); // bind: this را برای همیشه shop کن console.log(fixed()); // ✔ به کتاب‌فروشی دانش خوش آمدید وقتی متد را در متغیر دیگری می‌ریزید، فقط خود تابع کپی می‌شود و ارتباطش با shop قطع می‌شود. صدا زدن welcomeFn() دیگر «قبل از نقطه» ندارد، پس this شیء فروشگاه نیست. bind(shop) تابع تازه‌ای می‌سازد که this آن همیشه shop است، حتی اگر آن را بدون نقطه صدا بزنید.»

**روی جزوه این عناوین را دنبال کنید:** *۱۰) کلمه کلیدی this* · *this در متد شیء* · *تابع پیکانی this خودش را ندارد* · *جدا کردن متد از شیء — this گم می‌شود*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const user = {
  name: "سارا",
  greet: function () {
    return "سلام، من " + this.name + " هستم";
  }
};

console.log(user.greet());
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const user2 = {
  name: "علی",
  normal: function () { return this.name; },
  arrow: () => this.name        // this اینجا مال بیرون است، نه user2
};

console.log("normal:", user2.normal());   // normal: علی
console.log("arrow:", user2.arrow());     // arrow:  ← خالی!
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const shop = {
  name: "کتاب‌فروشی دانش",
  welcome: function () {
    return "به " + this.name + " خوش آمدید";
  }
};

console.log(shop.welcome());     // ✔ به کتاب‌فروشی دانش خوش آمدید

const welcomeFn = shop.welcome;  // فقط خود تابع کپی شد، نه shop
console.log(welcomeFn());        // ✖ به  خوش آمدید ← this دیگر shop نیست

const fixed = shop.welcome.bind(shop);   // bind: this را برای همیشه shop کن
console.log(fixed());            // ✔ به کتاب‌فروشی دانش خوش آمدید
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
