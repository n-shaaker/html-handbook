## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«به‌جای نوشتن حلقه برای هر کاری که باید روی همهٔ عضوهای یک فهرست انجام شود، می‌توانید تابعی بدهید و از متد بخواهید آن تابع را روی تک‌تک عضوها اجرا کند. تفاوت متدها در خروجی است: بعضی فقط کار جانبی انجام می‌دهند، بعضی آرایهٔ تازه می‌سازند و بعضی همهٔ عضو‌ها را به یک مقدار جمع می‌کنند. آرایهٔ اصلی در map و filter و reduce دست نمی‌خورد، مگر اینکه خودتان داخل تابع آن را عوض کنید.»

«forEach برای هر عضو تابع را صدا می‌زند. پارامتر اول خود عضو است و پارامتر دوم، اگر بنویسید، شمارهٔ همان عضو است. این متد آرایهٔ تازه برنمی‌گرداند؛ اگر چیزی return کنید نادیده گرفته می‌شود. از آن وقتی استفاده می‌کنید که فقط می‌خواهید برای هر عضو کاری مثل چاپ یا به‌روزرسانی صفحه انجام دهید.»

«map به تعداد عضوهای آرایهٔ اصلی، عضو جدید می‌سازد و آن‌ها را در آرایهٔ دیگری می‌ریزد. تابع باید مقدار تازه را return کند. ضرب در 1.1 ده درصد به قیمت اضافه می‌کند، ولی بعضی حاصل‌ها به‌خاطر ذخیرهٔ دودویی اعشار دقیقاً همان عددی که روی کاغذ انتظار دارید نیستند. Math.round همان نتیجه را به عدد صحیح نزدیک گرد می‌کند. چاپ prices نشان می‌دهد فهرست اولیه عوض نشده است.»

«عددهای اعشاری در کامپیوتر (و همه زبان‌های برنامه‌نویسی) به شکل دودویی ذخیره می‌شوند و بعضی‌شان دقیق نیستند؛ مثلاً 0.1 + 0.2 می‌شود 0.30000000000000004 . برای قیمت، نتیجه را گرد کنید ( Math.round ) یا برای نمایش از toFixed استفاده کنید.»

**روی جزوه این عناوین را دنبال کنید:** *۴) پیمایش آرایه (forEach، map، filter، reduce)* · *forEach* · *map — تبدیل* · *filter — فیلتر کردن*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const fruits = ["سیب", "موز", "انار"];
fruits.forEach(function (fruit, index) {
  console.log(index + 1 + ". " + fruit);
});
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const prices = [100, 250, 80];
const withTax = prices.map(function (p) {
  return p * 1.1;            // ۱۰٪ مالیات
});
console.log(withTax);        // [110.00000000000001, 275, 88] ‼
console.log(prices);         // اصلی دست نخورده

const rounded = prices.map(function (p) {
  return Math.round(p * 1.1);
});
console.log(rounded);        // [110, 275, 88]
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const ages = [12, 25, 17, 40, 8, 19];
const adults = ages.filter(function (age) {
  return age >= 18;
});
console.log(adults);
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«filter فقط عضوهایی را در آرایهٔ جدید نگه می‌دارد که تابع برایشان true برگرداند. سن‌های کمتر از ۱۸ حذف می‌شوند، ولی از آرایهٔ ages کم نمی‌شوند. اگر هیچ عضوی شرط را نداشته باشد، نتیجه آرایهٔ خالی است، نه undefined .»

«مراحل اجرای reduce روی [120, 45, 300] : sum اول ۰ است؛ بعد ۰+۱۲۰=۱۲۰، بعد ۱۲۰+۴۵=۱۶۵، و در آخر ۱۶۵+۳۰۰=۴۶۵ برگردانده می‌شود.»

«در reduce پارامتر اول تابع، جمع جاری است و پارامتر دوم عضو فعلی. عدد 0 بعد از تابع، مقدار شروع sum است؛ بدون آن، اولین عضو به‌جای شروع استفاده می‌شود و اگر آرایه خالی باشد خطا می‌گیرید. در سبد خرید، هر دور قیمت را در تعداد ضرب می‌کند و به جمع اضافه می‌کند تا در پایان فقط یک عدد بماند.»

«some همین که یک عضو شرط را داشته باشد true می‌شود و لازم نیست بقیه را تا آخر نشان دهد. every فقط وقتی true است که همهٔ عضو‌ها شرط را داشته باشند؛ اولین مورد مخالف، نتیجه را false می‌کند. هر دو به‌جای آرایه، یک بولین برمی‌گردانند.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
