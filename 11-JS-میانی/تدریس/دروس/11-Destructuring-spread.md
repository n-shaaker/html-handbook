## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«تجزیه (Destructuring) یعنی عضوهای یک آرایه یا ویژگی‌های یک شیء را همان موقع خواندن، در متغیرهای جدا بریزید. پخش (Spread) با سه نقطه یک فهرست یا شیء را باز می‌کند تا داخل فهرست یا شیء دیگری کپی شود. Rest برعکس عمل می‌کند و بقیهٔ مقدارها را در یک آرایه یا شیء جمع می‌کند. این سه شکل کد را کوتاه‌تر می‌کنند، به شرطی که معلوم باشد کدام بخش واقعاً کپی شده و کدام هنوز به دادهٔ اصلی وصل است.»

«با Destructuring می‌توان عضوهای آرایه یا شیء را در یک خط داخل چند متغیر ریخت.»

«کروشهٔ سمت چپ، عضوهای آرایه را به ترتیب در متغیرهای جدید می‌ریزد. first عضو شمارهٔ صفر است و second عضو بعدی. عضوهایی که متغیر نگیرند نادیده گرفته می‌شوند و خود آرایه عوض نمی‌شود. در خط جابه‌جایی، سمت راست اول آرایهٔ تازه‌ای از مقدارهای فعلی b و a می‌سازد و بعد همان مقدارها در متغیرهای قبلی ریخته می‌شوند.»

«آکولاد سمت چپ ویژگی‌ها را با همان نام بیرون می‌کشد. city: town ویژگی city را در متغیری به نام town می‌ریزد. اگر ویژگی job در شیء نباشد، مقدار پیش‌فرض «نامشخص» استفاده می‌شود. ویژگی‌هایی که در این خط نیامده‌اند، مثل بقیهٔ اطلاعات کاربر، سر جایشان در شیء می‌مانند.»

**روی جزوه این عناوین را دنبال کنید:** *۱۱) تجزیه و پخش (Destructuring، Spread و Rest)* · *Destructuring آرایه* · *Destructuring شیء* · *در پارامتر تابع*

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const colors = ["قرمز", "سبز", "آبی"];

const [first, second] = colors;
console.log(first, second);

let a = 1, b = 2;
[a, b] = [b, a];                // جابه‌جا کردن دو متغیر!
console.log(a, b);
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const user = { name: "سارا", age: 25, city: "شیراز" };

const { name, age } = user;
console.log(name, age);

const { city: town, job = "نامشخص" } = user;   // تغییر نام و مقدار پیش‌فرض
console.log(town, job);
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function showUser({ name, age }) {
  console.log(`${name} - ${age} ساله`);
}
showUser({ name: "علی", age: 30, city: "تبریز" });   // علی - 30 ساله
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«به‌جای گرفتن کل شیء و بعد خواندن user.name ، خود پارامتر را تجزیه کرده‌ایم. موقع صدا زدن، ویژگی‌های هم‌نام از شیء آرگومان در name و age قرار می‌گیرند. ویژگی city چون در پارامتر نیست خوانده نمی‌شود، ولی فرستادنش خطا نیست.»

«سه نقطه عضوهای یک آرایه را داخل آرایهٔ دیگر باز می‌کند، نه اینکه خود آرایه را به‌صورت یک عضو تودرتو بگذارد. copy فهرست تازه‌ای است؛ push روی آن، a1 را بلندتر نمی‌کند. در شیء تنظیمات، ویژگی‌های base کپی می‌شوند و theme بعدی مقدار قبلی همان کلید را عوض می‌کند. newCart عضوهای سبد قبلی را به اضافهٔ یک کالای جدید دارد، ولی cart هنوز یک عضو است. این کپی برای شیءهای داخل آرایه سطحی است و در بخش بعد دیده می‌شود.»

«orderCopy شیء تازه‌ای در لایهٔ اول است، پس عوض کردن id روی سفارش اصلی اثر ندارد. ویژگی customer هنوز به همان شیء درونی اشاره می‌کند؛ به همین دلیل عوض کردن نام مشتری در کپی، نام را در اصل هم عوض می‌کند. در deepCopy شیء مشتری جدا ساخته شده است و تغییر بعدی دیگر به سفارش اصلی نمی‌رسد.»

«Spread فقط لایه اول را کپی می‌کند. اگر داخل شیء یا آرایه، شیء یا آرایه دیگری باشد، کپی و اصلی هنوز به همان شیء داخلی اشاره می‌کنند. برای کپی کامل، شیء داخلی را هم جداگانه با Spread کپی کنید (مثل deepCopy بالا).»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
