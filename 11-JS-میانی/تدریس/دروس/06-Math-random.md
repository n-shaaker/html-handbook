## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«شیء Math مجموعه‌ای از تابع‌ها و عددهای ریاضی آماده است. لازم نیست آن را با new بسازید؛ متدها را مستقیم روی خود Math صدا می‌زنید. از گرد کردن و جذر تا ساختن عدد تصادفی برای بازی یا نمونه، این شیء همان کاری را می‌کند که اگر بخواهید خودتان با حلقه بنویسید طولانی و خطاپذیر است. عدد تصادفی این شیء برای آموزش و بازی مناسب است، نه برای رمز و توکن امنیتی.»

«console.log(Math.round(4.5), Math.floor(4.9), Math.ceil(4.1)); // 5 4 5 console.log(Math.sqrt(144), Math.abs(-3.5)); // 12 3.5 console.log(Math.max(12, 45, 7), Math.min(12, 45, 7)); // 45 7 const r = 5; const area = (Math.PI * r ** 2).toFixed(2); // ** یعنی توان console.log("مساحت دایره:", area, typeof area); // 78.54 string ← toFixed رشته برمی‌گرداند // کاربرد واقعی: گرد کردن قیمت به نزدیک‌ترین هزار تومان const price = 123456; console.log(Math.round(price / 1000) * 1000); // 123000 // تعداد صفحه‌های لازم برای ۴۳ محصول، ۱۰ تا در هر صفحه console.log(Math.ceil(43 / 10)); // 5 round به نزدیک‌ترین عدد صحیح می‌رود، floor به سمت پایین و ceil به سمت بالا. sqrt جذر می‌گیرد و abs علامت منفی را برمی‌دارد. max و min بین عددهایی که جدا جدا به آن‌ها می‌دهید بزرگ‌ترین و کوچک‌ترین را برمی‌گردانند؛ اگر همان عددها داخل یک آرایه باشند، این دو متد خودبه‌خود عضوهای آرایه را یکی‌یکی نمی‌خوانند. toFixed مساحت را برای نمایش گرد می‌کند ولی رشته برمی‌گرداند. گرد کردن قیمت، عدد را به هزار تقسیم می‌کند، گرد می‌کند و دوباره در هزار ضرب می‌کند. ceil برای تعداد صفحه لازم است تا باقیماندهٔ کمتر از یک صفحه هم یک صفحهٔ کامل حساب شود.»

«Math.round نیمه را به سمت بالا (به سمت مثبت بی‌نهایت) گرد می‌کند: Math.round(4.5) می‌شود 5 ولی Math.round(-4.5) می‌شود -4 . Math.floor و Math.trunc هم برای عددهای منفی فرق دارند: Math.floor(-4.7) برابر -5 و Math.trunc(-4.7) برابر -4 است.»

«// عدد تصادفی صحیح بین min و max (هر دو شامل) function randomInt(min, max) { return Math.floor(Math.random() * (max - min + 1)) + min; } console.log(randomInt(1, 6)); // تاس console.log(randomInt(1, 100)); Math.random عددی اعشاری از صفر تا کمتر از یک می‌دهد. ضرب در max - min + 1 این بازه را به اندازهٔ تعداد عددهای صحیح مطلوب کش می‌دهد. floor اعشار را حذف می‌کند تا به عدد صحیح برسید و جمع با min بازه را از نقطهٔ شروع جابه‌جا می‌کند. + 1 داخل پرانتز باعث می‌شود خود max هم شانس برابر داشته باشد. بدون آن، سقف بازه هرگز دیده نمی‌شود.»

**روی جزوه این عناوین را دنبال کنید:** *۶) ریاضی و عدد تصادفی (Math & Random)* · *عدد صحیح تصادفی در یک بازه* · *مثال زنده: تاس و انتخاب تصادفی*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
console.log(Math.round(4.5), Math.floor(4.9), Math.ceil(4.1));   // 5 4 5
console.log(Math.sqrt(144), Math.abs(-3.5));                       // 12 3.5
console.log(Math.max(12, 45, 7), Math.min(12, 45, 7));             // 45 7

const r = 5;
const area = (Math.PI * r ** 2).toFixed(2);     // ** یعنی توان
console.log("مساحت دایره:", area, typeof area); // 78.54 string ← toFixed رشته برمی‌گرداند

// کاربرد واقعی: گرد کردن قیمت به نزدیک‌ترین هزار تومان
const price = 123456;
console.log(Math.round(price / 1000) * 1000);   // 123000

// تعداد صفحه‌های لازم برای ۴۳ محصول، ۱۰ تا در هر صفحه
console.log(Math.ceil(43 / 10));                // 5
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
// عدد تصادفی صحیح بین min و max (هر دو شامل)
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

console.log(randomInt(1, 6));     // تاس
console.log(randomInt(1, 100));
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const faces = ["⚀", "⚁", "⚂", "⚃", "⚄", "⚅"];

diceBtn.addEventListener("click", function () {
  const n = randomInt(1, 6);
  dice.textContent = faces[n - 1] + " " + n;   // شماره عضو آرایه از 0 است
});

quoteBtn.addEventListener("click", function () {
  const i = randomInt(0, quotes.length - 1);   // عضو تصادفی آرایه
  quote.textContent = quotes[i];
});
```
