## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«تابع پیکانی شکل کوتاه‌تری برای نوشتن تابع است و در متدهایی مثل map و filter زیاد دیده می‌شود. کار اصلی‌اش همان اجرای یک بلوک کد و برگرداندن مقدار است. تفاوت مهمش با تابع معمولی در دو جا ظاهر می‌شود: اگر بدنه فقط یک عبارت باشد می‌توان آکولاد و return را حذف کرد، و this خودش را جداگانه نمی‌سازد. مورد دوم را در درس this می‌بینید؛ اینجا اول شکل نوشتن را یاد بگیرید.»

«// تابع معمولی const add1 = function (a, b) { return a + b; }; // تابع پیکانی const add2 = (a, b) => { return a + b; }; // کوتاه‌تر: اگر فقط یک return دارد، { } و return حذف می‌شوند const add3 = (a, b) => a + b; console.log(add1(2, 3), add2(2, 3), add3(2, 3)); هر سه ثابت یک تابع جمع هستند. add1 شکل معمولی است. add2 همان بدنه را بعد از فلش => نوشته است. add3 چون فقط یک عبارت برمی‌گرداند، آکولاد و return را حذف کرده و خود a + b مقدار خروجی است. هر سه را با آرگومان‌های ۲ و ۳ صدا می‌زنیم و نتیجه یکی است.»

«قوانین کوتاه‌نویسی حالت نوشتن بدون پارامتر () => "سلام" یک پارامتر x => x * 2 (پرانتز اختیاری) چند پارامتر (a, b) => a + b چند خط (a) => { const r = a * 2; return r; } برگرداندن شیء () => ({ name: "علی" }) (داخل پرانتز) const hello = () => "سلام!"; const double = x => x * 2; const makeUser = (name, age) => ({ name: name, age: age }); console.log(hello()); console.log(double(21)); console.log(makeUser("مریم", 25)); اگر پارامترها صفر تا باشند پرانتز خالی لازم است. اگر دقیقاً یک پارامتر باشد می‌توان پرانتز را برداشت. برای برگرداندن شیء در شکل کوتاه، دور آکولاد شیء یک پرانتز اضافه می‌گذارند؛ وگرنه زبان آکولاد را بدنهٔ تابع حساب می‌کند نه شیء. hello متن ثابت برمی‌گرداند و double ورودی را دو برابر می‌کند.»

«بهترین جا: همراه با map، filter و ... const nums = [1, 2, 3, 4, 5, 6]; // قبل const evens1 = nums.filter(function (n) { return n % 2 === 0; }); // بعد const evens2 = nums.filter(n => n % 2 === 0); const squares = nums.map(n => n * n); const total = nums.reduce((sum, n) => sum + n, 0); console.log(evens2, squares, total); // [2,4,6] [1,4,9,16,25,36] 21 // مثال واقعی: نام محصولات موجود زیر ۲ میلیون تومان const products = [ { name: "کیبورد", price: 1500000, inStock: true }, { name: "مانیتور", price: 9800000, inStock: true }, { name: "ماوس", price: 600000, inStock: false } ]; const affordable = products .filter(p => p.inStock && p.price < 2000000) .map(p => p.name); console.log(affordable); // ["کیبورد"] وقتی تابع فقط یک پارامتر دارد و یک عبارت برمی‌گرداند، فلش جای function و return را می‌گیرد.»

**روی جزوه این عناوین را دنبال کنید:** *۹) توابع پیکانی (Arrow Functions)* · *قوانین کوتاه‌نویسی* · *بهترین جا: همراه با map، filter و ...* · *در رویدادها*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
// تابع معمولی
const add1 = function (a, b) {
  return a + b;
};

// تابع پیکانی
const add2 = (a, b) => {
  return a + b;
};

// کوتاه‌تر: اگر فقط یک return دارد، { } و return حذف می‌شوند
const add3 = (a, b) => a + b;

console.log(add1(2, 3), add2(2, 3), add3(2, 3));
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const hello = () => "سلام!";
const double = x => x * 2;
const makeUser = (name, age) => ({ name: name, age: age });

console.log(hello());
console.log(double(21));
console.log(makeUser("مریم", 25));
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const nums = [1, 2, 3, 4, 5, 6];

// قبل
const evens1 = nums.filter(function (n) { return n % 2 === 0; });

// بعد
const evens2 = nums.filter(n => n % 2 === 0);
const squares = nums.map(n => n * n);
const total = nums.reduce((sum, n) => sum + n, 0);

console.log(evens2, squares, total);   // [2,4,6] [1,4,9,16,25,36] 21

// مثال واقعی: نام محصولات موجود زیر ۲ میلیون تومان
const products = [
  { name: "کیبورد", price: 1500000, inStock: true },
  { name: "مانیتور", price: 9800000, inStock: true },
  { name: "ماوس", price: 600000, inStock: false }
];
const affordable = products
  .filter(p => p.inStock && p.price < 2000000)
  .map(p => p.name);
console.log(affordable);               // ["کیبورد"]
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
