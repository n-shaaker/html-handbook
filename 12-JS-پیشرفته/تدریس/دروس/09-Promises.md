## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«Promise شیئی است که نتیجهٔ یک کار ناهمگام را نگه می‌دارد؛ کاری که همین لحظه تمام نمی‌شود، مثل انتظار یا درخواست شبکه. به‌جای دادن نتیجهٔ مستقیم، شیء وعده می‌دهد که بعداً یا مقدار موفق را تحویل می‌دهد یا دلیل شکست را. تا آن لحظه، برنامه می‌تواند به خط‌های بعدی برسد و هر وقت نتیجه آماده شد با then یا catch به آن واکنش نشان دهد. یک Promise در هر لحظه یکی از این سه حالت را دارد:»

«function orderPizza(type) { return new Promise((resolve, reject) => { log(`سفارش ${type} ثبت شد...`); setTimeout(() => { if (type === "آناناس") { reject(new Error("این پیتزا را نداریم!")); } else { resolve(`پیتزا ${type} آماده است 🍕`); } }, 1200); }); } orderPizza("پپرونی") .then(message => log("✔", message)) .catch(error => log("✖", error.message)) .finally(() => log("— پایان سفارش —")); سازندهٔ Promise تابعی می‌گیرد که resolve و reject را در اختیارش می‌گذارد. اگر نوع پیتزا قابل‌قبول باشد، resolve نتیجهٔ موفق را می‌فرستد و then آن را می‌گیرد. نوع غیرمجاز reject می‌شود و به catch می‌رود. finally در هر دو حالت اجرا می‌شود و برای کاری است که باید آخر سر انجام شود.»

«متد کی اجرا می‌شود .then(fn) وقتی Promise موفق شد؛ fn مقدار resolve را می‌گیرد .catch(fn) وقتی Promise (یا هر then قبلی) خطا داد .finally(fn) در هر صورت، آخر کار زنجیره then — خداحافظی با Callback Hell // بعد از ms میلی‌ثانیه، با value موفق می‌شود function wait(ms, value) { return new Promise(resolve => { setTimeout(() => resolve(value), ms); }); } wait(500, 1) .then(n => { log("مرحله اول:", n); return wait(500, n + 1); }) .then(n => { log("مرحله دوم:", n); return wait(500, n + 1); }) .then(n => { log("مرحله سوم:", n); }) .catch(err => log("خطا:", err)); wait بعد از مدت مشخص با یک مقدار resolve می‌شود. هر then می‌تواند Promise تازه‌ای برگرداند تا مرحلهٔ بعد منتظر همان بماند. اگر یکی از مرحله‌ها خطا بدهد، زنجیره به catch می‌رود و then های بعدی اجرا نمی‌شوند.»

«هر then یک Promise جدید برمی‌گرداند؛ برای همین می‌شود آن‌ها را پشت سر هم نوشت. اگر داخل then یک Promise را return کنید، then بعدی منتظر تمام شدن آن می‌ماند. یک catch در آخر، خطای همه مرحله‌ها را می‌گیرد.»

**روی جزوه این عناوین را دنبال کنید:** *۹) وعده‌ها (Promises)* · *ساختن و مصرف Promise* · *زنجیره then — خداحافظی با Callback Hell* · *ترتیب اجرا: کد همگام، microtask و تایمر*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function orderPizza(type) {
  return new Promise((resolve, reject) => {
    log(`سفارش ${type} ثبت شد...`);
    setTimeout(() => {
      if (type === "آناناس") {
        reject(new Error("این پیتزا را نداریم!"));
      } else {
        resolve(`پیتزا ${type} آماده است 🍕`);
      }
    }, 1200);
  });
}

orderPizza("پپرونی")
  .then(message => log("✔", message))
  .catch(error => log("✖", error.message))
  .finally(() => log("— پایان سفارش —"));
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
// بعد از ms میلی‌ثانیه، با value موفق می‌شود
function wait(ms, value) {
  return new Promise(resolve => {
    setTimeout(() => resolve(value), ms);
  });
}

wait(500, 1)
  .then(n => { log("مرحله اول:", n); return wait(500, n + 1); })
  .then(n => { log("مرحله دوم:", n); return wait(500, n + 1); })
  .then(n => { log("مرحله سوم:", n); })
  .catch(err => log("خطا:", err));
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
log("1: همگام");
setTimeout(() => log("4: setTimeout با تأخیر 0"), 0);
Promise.resolve().then(() => log("3: then (microtask)"));
log("2: همگام");
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
