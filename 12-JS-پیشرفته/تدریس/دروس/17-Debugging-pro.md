## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«خطا فقط یک جملهٔ قرمز نیست. کنسول نوع مشکل، محل آن در فایل و مقدار متغیرها را نشان می‌دهد، اگر بدانید هر دستور کنسول چه چیزی را برجسته می‌کند. این درس ابزارهای دیدن خروجی و خواندن پیام خطا را جدا می‌کند تا وقتی برنامه می‌ایستد، از روی پیام به همان خط برسید.»

«const users = [ { name: "سارا", age: 25, city: "شیراز" }, { name: "علی", age: 32, city: "تبریز" } ]; console.table(users); console.group("اطلاعات سفارش"); console.log("شماره: 1024"); console.warn("موجودی کم است"); console.groupEnd(); console.time("حلقه"); for (let i = 0; i < 1_000_000; i++) {} console.timeEnd("حلقه"); همین کد هنگام باز شدن صفحه اجرا شده است؛ Console مرورگر (F12) را باز کنید تا جدول و گروه‌بندی واقعی را ببینید. جعبه زیر فقط نسخه ساده‌شده خروجی را نشان می‌دهد (عدد زمان حلقه در هر اجرا و هر سیستم فرق می‌کند):»

«نقطه توقف (Breakpoint) و دستور debugger F12 را بزنید و به زبانه Sources بروید. فایل JS را باز کنید و روی شماره یک خط کلیک کنید تا نقطه آبی (Breakpoint) ظاهر شود. کاری کنید که آن خط اجرا شود (مثلاً کلیک روی دکمه). اجرا همان‌جا متوقف می‌شود. مقدار متغیرها را با بردن ماوس روی آن‌ها یا در پنل Scope ببینید. با دکمه‌های Step Over (F10) و Step Into (F11) خط‌به‌خط جلو بروید. function calculateTotal(items) { let total = 0; for (const item of items) { debugger; // اگر DevTools باز باشد، اجرا اینجا متوقف می‌شود total += item.price * item.qty; } return total; } اجرای calculateTotal (اول F12 را باز کنید)»

«وقتی تابع با ورودی نامعتبر روبه‌رو می‌شود، بهتر است به جای برگرداندن یک مقدار عجیب، با throw خطا «پرتاب» کند. کدی که تابع را صدا می‌زند با try...catch خطا را می‌گیرد و پیام مناسب نشان می‌دهد. نوع خطا ( TypeError ، RangeError ، ...) هم کمک می‌کند بفهمیم مشکل از کجاست.»

**روی جزوه این عناوین را دنبال کنید:** *۱۷) اشکال‌زدایی و نکات حرفه‌ای (Debugging & Best Practices)* · *ابزارهای Console* · *نقطه توقف (Breakpoint) و دستور debugger* · *مدیریت خطا: throw و try...catch*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const users = [
  { name: "سارا", age: 25, city: "شیراز" },
  { name: "علی", age: 32, city: "تبریز" }
];

console.table(users);

console.group("اطلاعات سفارش");
console.log("شماره: 1024");
console.warn("موجودی کم است");
console.groupEnd();

console.time("حلقه");
for (let i = 0; i < 1_000_000; i++) {}
console.timeEnd("حلقه");
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function calculateTotal(items) {
  let total = 0;
  for (const item of items) {
    debugger;               // اگر DevTools باز باشد، اجرا اینجا متوقف می‌شود
    total += item.price * item.qty;
  }
  return total;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function parsePrice(text) {
  const n = Number(text);
  if (text.trim() === "" || Number.isNaN(n)) {
    throw new TypeError(`«${text}» عدد نیست`);
  }
  if (n < 0) throw new RangeError("قیمت نمی‌تواند منفی باشد");
  return n;
}

for (const input of ["250000", "abc", "-5"]) {
  try {
    console.log("✔", parsePrice(input));
  } catch (err) {
    console.log("✖", err.name + ":", err.message);
  }
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
