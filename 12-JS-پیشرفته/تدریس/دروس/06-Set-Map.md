## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«آرایه برای فهرست مرتب خوب است، ولی برای «هر مقدار فقط یک بار» یا «جست‌وجوی سریع با کلید» ابزار دقیق‌تری هست. Set مجموعهٔ مقدارهای یکتاست و Map زوج‌های کلید و مقدار را نگه می‌دارد. کلید Map برخلاف شیء معمولی لازم نیست رشته باشد.»

«Set مثل آرایه است، ولی هر مقدار فقط یک بار در آن می‌آید.»

«const tags = new Set(["js", "css", "js", "html", "css"]); console.log(tags); // Set(3) {"js", "css", "html"} console.log(tags.size); // 3 ← Set به جای length، size دارد tags.add("react"); tags.add("js"); // تکراری؛ اضافه نمی‌شود console.log(tags.has("css")); // true tags.delete("html"); console.log(tags); // Set(3) {"js", "css", "react"} for (const t of tags) console.log("-", t); Set مقدار تکراری را نگه نمی‌دارد، حتی اگر در آرایهٔ اولیه چند بار آمده باشد. به‌جای length ویژگی size دارد. add اگر مقدار از قبل باشد کاری نمی‌کند. has وجود را با true یا false می‌گوید و delete همان مقدار را برمی‌دارد. پیمایش با for...of مقدارها را به ترتیبی که اولین بار اضافه شده‌اند می‌دهد.»

«کاربرد معروف: حذف تکراری‌ها از آرایه const numbers = [1, 2, 2, 3, 3, 3, 4]; const unique = [...new Set(numbers)]; // Set ← حذف تکراری، [...] ← دوباره آرایه console.log(unique); // [1, 2, 3, 4] ساختن Set از آرایه، تکرارها را حذف می‌کند. سه نقطه آن مجموعه را دوباره به آرایه تبدیل می‌کند تا متدهای آرایه در دسترس باشند. ترتیب اولین دیده‌شدن هر عدد حفظ می‌شود. اگر به آرایه نیاز ندارید، می‌توانید همان Set را نگه دارید.»

**روی جزوه این عناوین را دنبال کنید:** *۶) مجموعه و نگاشت (Set و Map)* · *Set — مجموعه‌ای از مقدارهای یکتا* · *کاربرد معروف: حذف تکراری‌ها از آرایه* · *Map — کلید و مقدار با هر نوع کلید*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const tags = new Set(["js", "css", "js", "html", "css"]);
console.log(tags);              // Set(3) {"js", "css", "html"}
console.log(tags.size);         // 3  ← Set به جای length، size دارد

tags.add("react");
tags.add("js");                 // تکراری؛ اضافه نمی‌شود
console.log(tags.has("css"));   // true
tags.delete("html");
console.log(tags);              // Set(3) {"js", "css", "react"}

for (const t of tags) console.log("-", t);
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const numbers = [1, 2, 2, 3, 3, 3, 4];
const unique = [...new Set(numbers)];   // Set ← حذف تکراری، [...] ← دوباره آرایه
console.log(unique);                    // [1, 2, 3, 4]
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const prices = new Map();
prices.set("سیب", 45000);
prices.set("موز", 80000);
prices.set("انار", 60000);

console.log(prices.get("موز"));      // 80000
console.log(prices.has("کیوی"));     // false
console.log(prices.size);            // 3

prices.forEach((value, key) => {     // ترتیب پارامترها: اول مقدار، بعد کلید
  console.log(`${key}: ${value.toLocaleString("en-US")} تومان`);
});

const fromObject = new Map(Object.entries({ a: 1, b: 2 }));   // شیء ← Map
console.log(fromObject);             // Map(2) {"a" => 1, "b" => 2}
console.log(Object.fromEntries(fromObject));                  // Map ← شیء: {a: 1, b: 2}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
