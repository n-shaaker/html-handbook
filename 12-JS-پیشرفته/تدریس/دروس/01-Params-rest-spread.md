## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«تابع فقط یک فهرست ثابت از ورودی‌ها نیست. می‌توانید برای پارامتری که نیامده مقدار پیش‌فرض بگذارید، تعداد ورودی را از قبل ندانید، خود یک تابع را به‌عنوان ورودی بگیرید، یا از یک تابع، تابع تازه‌ای بسازید که بخشی از داده را به یاد داشته باشد. این درس همین حالت‌ها را جدا نشان می‌دهد.»

«اگر آرگومانی فرستاده نشود (یا دقیقاً undefined فرستاده شود)، پارامتر مقدار پیش‌فرضش را می‌گیرد.»

«function greet(name = "مهمان", greeting = "سلام") { return `${greeting} ${name}!`; } console.log(greet("سارا", "درود")); // درود سارا! console.log(greet("علی")); // سلام علی! console.log(greet()); // سلام مهمان! console.log(greet(undefined, "صبح بخیر")); // صبح بخیر مهمان! console.log(greet(null)); // سلام null! ← null یعنی «مقدار دارد» اگر آرگومان را نفرستید یا صریحاً undefined بفرستید، مقدار پیش‌فرض جایگزین می‌شود. فرستادن null پیش‌فرض را فعال نمی‌کند، چون null یک مقدار واقعی است و در خروجی دیده می‌شود. آرگومان دوم را می‌توانید جدا بدهید و اولی را undefined بگذارید تا فقط همان اولی پیش‌فرض بگیرد.»

«مقدار پیش‌فرض فقط جای undefined را می‌گیرد؛ null ، 0 و "" مقدار حساب می‌شوند و پیش‌فرض اعمال نمی‌شود.»

**روی جزوه این عناوین را دنبال کنید:** *۱) توابع پیشرفته (پارامترها و توابع مرتبه بالا)* · *مقدار پیش‌فرض پارامتر* · *پارامتر Rest و شیء arguments* · *تابع به عنوان مقدار*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function greet(name = "مهمان", greeting = "سلام") {
  return `${greeting} ${name}!`;
}

console.log(greet("سارا", "درود"));          // درود سارا!
console.log(greet("علی"));                   // سلام علی!
console.log(greet());                        // سلام مهمان!
console.log(greet(undefined, "صبح بخیر"));   // صبح بخیر مهمان!
console.log(greet(null));                    // سلام null!  ← null یعنی «مقدار دارد»
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function average(...nums) {           // Rest: همه آرگومان‌ها در آرایه nums
  if (nums.length === 0) return 0;
  return nums.reduce((s, n) => s + n, 0) / nums.length;
}
console.log(average(10, 20, 30));     // 20

const scores = [17, 19, 15];
console.log(average(...scores));      // 17  ← Spread: مثل average(17, 19, 15)

function oldStyle() {
  console.log(arguments.length, arguments[0]);   // روش قدیمی؛ در تابع پیکانی وجود ندارد
}
oldStyle("a", "b", "c");              // 3 a
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function calculate(a, b, operation) {   // operation یک تابع است
  return operation(a, b);
}

const add = (x, y) => x + y;
const multiply = (x, y) => x * y;

console.log(calculate(4, 5, add));                // 9
console.log(calculate(4, 5, multiply));           // 20
console.log(calculate(4, 5, (x, y) => x ** y));   // 1024  ← تابع بی‌نام همان‌جا
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
