## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«async/await همان Promise را با شکلی می‌نویسد که از بالا به پایین خوانده می‌شود. async تابع را طوری علامت می‌زند که همیشه یک Promise برگرداند. await داخل همان تابع می‌ایستد تا Promise تمام شود و مقدارش را به شما بدهد. بقیهٔ برنامه در این فاصله متوقف نمی‌شود؛ فقط ادامهٔ همان تابع عقب می‌افتد. خطا را هم با try/catch می‌گیرید، شبیه کد همگام.»

«// با then function showUserThen() { getUser(1) .then(user => log("then:", user.name)) .catch(err => log(err.message)); } // با async/await async function showUserAwait() { try { const user = await getUser(1); log("await:", user.name); } catch (err) { log(err.message); } } هر دو تابع همان getUser(1) را می‌خوانند. شکل then ادامهٔ کار را داخل callback می‌گذارد و خطا را با catch می‌گیرد. شکل await همان انتظار را مثل یک خط معمولی می‌نویسد و خطا را با try/catch می‌گیرد. await فقط داخل تابع async مجاز است و تا آماده شدن Promise، بقیهٔ همان تابع را عقب می‌اندازد.»

«const wait = ms => new Promise(r => setTimeout(r, ms)); async function makeTea() { log("۱. آب را جوش می‌آوریم..."); await wait(1000); log("۲. چای را دم می‌کنیم..."); await wait(1000); log("۳. چای را می‌ریزیم ☕"); return "چای آماده است"; } makeTea().then(result => log("نتیجه:", result)); log("(این خط منتظر چای نمی‌ماند)"); // ترتیب خروجی: // ۱. آب را جوش می‌آوریم... ← بخش همگام makeTea تا اولین await // (این خط منتظر چای نمی‌ماند) // ۲. چای را دم می‌کنیم... ← ۱ ثانیه بعد // ۳. چای را می‌ریزیم ☕ ← ۲ ثانیه بعد // نتیجه: چای آماده است هر await wait(1000) ادامهٔ makeTea را حدود یک ثانیه متوقف می‌کند، ولی خط بعد از صدا زدن makeTea() منتظر چای نمی‌ماند. بخش قبل از اولین await همان لحظه اجرا می‌شود. return داخل تابع async به Promise تبدیل می‌شود و then متن نهایی را می‌گیرد.»

«await فقط همان تابع async را متوقف می‌کند، نه کل برنامه. تابع async تا اولین await به صورت همگام اجرا می‌شود؛ بعد کنترل به کدی که آن را صدا زده برمی‌گردد. مقداری هم که با return برمی‌گرداند، در قالب یک Promise تحویل داده می‌شود؛ برای همین از .then (یا await) برای گرفتن «چای آماده است» استفاده کردیم.»

**روی جزوه این عناوین را دنبال کنید:** *۱۰) async و await* · *مقایسه then با await* · *مثال: چند مرحله پشت سر هم* · *مدیریت خطا با try...catch*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
// با then
function showUserThen() {
  getUser(1)
    .then(user => log("then:", user.name))
    .catch(err => log(err.message));
}

// با async/await
async function showUserAwait() {
  try {
    const user = await getUser(1);
    log("await:", user.name);
  } catch (err) {
    log(err.message);
  }
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const wait = ms => new Promise(r => setTimeout(r, ms));

async function makeTea() {
  log("۱. آب را جوش می‌آوریم...");
  await wait(1000);
  log("۲. چای را دم می‌کنیم...");
  await wait(1000);
  log("۳. چای را می‌ریزیم ☕");
  return "چای آماده است";
}

makeTea().then(result => log("نتیجه:", result));
log("(این خط منتظر چای نمی‌ماند)");

// ترتیب خروجی:
// ۱. آب را جوش می‌آوریم...      ← بخش همگام makeTea تا اولین await
// (این خط منتظر چای نمی‌ماند)
// ۲. چای را دم می‌کنیم...        ← ۱ ثانیه بعد
// ۳. چای را می‌ریزیم ☕          ← ۲ ثانیه بعد
// نتیجه: چای آماده است
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function getUser(id) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (id > 0) resolve({ id, name: "کاربر " + id });
      else reject(new Error("شناسه نامعتبر است"));
    }, 700);
  });
}

async function loadUser(id) {
  try {
    log(`در حال دریافت کاربر ${id}...`);
    const user = await getUser(id);
    log("✔", user);
  } catch (err) {
    log("✖", err.message);
  } finally {
    log("— تمام —");
  }
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
