## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«بعضی کارها نباید همین لحظه یا فقط یک بار انجام شوند: صبر کردن، تکرار هر ثانیه، یا محدود کردن تعداد اجرای یک رویداد شلوغ. تابع‌های زمان‌بندی، تابع شما را به صف مرورگر می‌سپارند و اجرای خط‌های بعدی را متوقف نمی‌کنند. شناسه‌ای که برمی‌گردانند برای لغو همان زمان‌بندی لازم است.»

«log("۱. شروع"); setTimeout(() => { log("۳. بعد از ۱.۵ ثانیه"); }, 1500); log("۲. این خط منتظر نمی‌ماند!"); setTimeout تابع را همین حالا اجرا نمی‌کند؛ آن را برای حدود ۱۵۰۰ میلی‌ثانیهٔ بعد در صف می‌گذارد و ادامهٔ برنامه را متوقف نمی‌کند. به همین دلیل پیام دوم قبل از پیام سوم چاپ می‌شود. زمان داده‌شده حداقل انتظار است، نه ضمانت دقیق، چون اگر برنامه مشغول باشد اجرا کمی دیرتر شروع می‌شود.»

«در این مثال‌ها از تابع log به جای console.log استفاده شده چون خروجی بعد از چند ثانیه می‌آید. کار هر دو یکی است.»

«JavaScript برای setTimeout صبر نمی‌کند؛ کار را «زمان‌بندی» می‌کند و سراغ خط بعد می‌رود. این اولین آشنایی ما با کد ناهمگام (Asynchronous) است. حتی setTimeout(fn, 0) هم بعد از تمام شدن کدهای همگام فعلی اجرا می‌شود (جزئیات در درس ۹، بخش «ترتیب اجرا»).»

**روی جزوه این عناوین را دنبال کنید:** *۷) زمان‌بندی (setTimeout، setInterval و debounce)* · *setTimeout* · *مثال زنده: کرنومتر با setInterval* · *مثال زنده: پیام موقت (Toast) با setTimeout*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
log("۱. شروع");

setTimeout(() => {
  log("۳. بعد از ۱.۵ ثانیه");
}, 1500);

log("۲. این خط منتظر نمی‌ماند!");
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let seconds = 0;
let timerId = null;

startBtn.addEventListener("click", () => {
  if (timerId !== null) return;          // جلوی چند بار شروع شدن را بگیر
  timerId = setInterval(() => {
    seconds++;
    display.textContent = format(seconds);
  }, 1000);
});

stopBtn.addEventListener("click", () => {
  clearInterval(timerId);
  timerId = null;
});

resetBtn.addEventListener("click", () => {
  clearInterval(timerId);
  timerId = null;
  seconds = 0;
  display.textContent = format(0);
});

function format(s) {
  const m = String(Math.floor(s / 60)).padStart(2, "0");
  const r = String(s % 60).padStart(2, "0");
  return `${m}:${r}`;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let hideId = null;

toastBtn.addEventListener("click", () => {
  toast.classList.remove("hidden");
  clearTimeout(hideId);       // اگر پیام قبلی هنوز باز است، تایمر قبلی را لغو کن
  hideId = setTimeout(() => toast.classList.add("hidden"), 2000);
});
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
