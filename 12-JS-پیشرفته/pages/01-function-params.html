۱) توابع پیشرفته (پارامترها و توابع مرتبه بالا)

تابع فقط یک فهرست ثابت از ورودی‌ها نیست. می‌توانید برای پارامتری که نیامده مقدار پیش‌فرض بگذارید، تعداد ورودی را از قبل ندانید، خود یک تابع را به‌عنوان ورودی بگیرید، یا از یک تابع، تابع تازه‌ای بسازید که بخشی از داده را به یاد داشته باشد. این درس همین حالت‌ها را جدا نشان می‌دهد.

مقدار پیش‌فرض پارامتر

اگر آرگومانی فرستاده نشود (یا دقیقاً undefined فرستاده شود)، پارامتر مقدار پیش‌فرضش را می‌گیرد.

function greet(name = "مهمان", greeting = "سلام") {
  return `${greeting} ${name}!`;
}

console.log(greet("سارا", "درود"));          // درود سارا!
console.log(greet("علی"));                   // سلام علی!
console.log(greet());                        // سلام مهمان!
console.log(greet(undefined, "صبح بخیر"));   // صبح بخیر مهمان!
console.log(greet(null));                    // سلام null!  ← null یعنی «مقدار دارد»

اگر آرگومان را نفرستید یا صریحاً undefined بفرستید، مقدار پیش‌فرض جایگزین می‌شود. فرستادن null پیش‌فرض را فعال نمی‌کند، چون null یک مقدار واقعی است و در خروجی دیده می‌شود. آرگومان دوم را می‌توانید جدا بدهید و اولی را undefined بگذارید تا فقط همان اولی پیش‌فرض بگیرد.






مقدار پیش‌فرض فقط جای undefined را می‌گیرد؛ null، 0 و "" مقدار حساب می‌شوند و پیش‌فرض اعمال نمی‌شود.



پارامتر Rest و شیء arguments



سه نقطه در تعریف تابع (...nums) یعنی Rest: «بقیه آرگومان‌ها را در یک آرایه واقعی جمع کن». همین سه نقطه در صدا زدن تابع (average(...scores)) یعنی Spread: «آرایه را باز کن و عضوهایش را جدا جدا بفرست».



function average(...nums) {           // Rest: همه آرگومان‌ها در آرایه nums
  if (nums.length === 0) return 0;
  return nums.reduce((s, n) => s + n, 0) / nums.length;
}
console.log(average(10, 20, 30));     // 20

const scores = [17, 19, 15];
console.log(average(...scores));      // 17  ← Spread: مثل average(17, 19, 15)

function oldStyle() {
  console.log(arguments.length, arguments[0]);   // روش قدیمی؛ در تابع پیکانی وجود ندارد
}
oldStyle("a", "b", "c");              // 3 a



Rest همهٔ آرگومان‌ها را در آرایهٔ nums می‌ریزد. اگر هیچ عددی نیاید، تابع صفر برمی‌گرداند تا تقسیم بر صفر رخ ندهد. در غیر این صورت جمع را بر تعداد تقسیم می‌کند. سه نقطه موقع صدا زدن، عضوهای آرایهٔ scores را به‌صورت آرگومان جدا می‌فرستد. شیء arguments روش قدیمی‌تر دیدن آرگومان‌هاست و در تابع پیکانی وجود ندارد.










arguments شبه‌آرایه است (متدهایی مثل map و reduce را ندارد) و در تابع پیکانی تعریف نشده است. در کد جدید همیشه از پارامتر Rest استفاده کنید. پارامتر Rest باید آخرین پارامتر باشد: function f(first, ...others).



تابع به عنوان مقدار



در JavaScript تابع هم یک «مقدار» است: می‌شود آن را در متغیر گذاشت، به تابع دیگر داد یا از تابع برگرداند. به تابعی که تابع دیگری را بگیرد یا برگرداند تابع مرتبه بالا (Higher-Order Function) می‌گویند.



function calculate(a, b, operation) {   // operation یک تابع است
  return operation(a, b);
}

const add = (x, y) => x + y;
const multiply = (x, y) => x * y;

console.log(calculate(4, 5, add));                // 9
console.log(calculate(4, 5, multiply));           // 20
console.log(calculate(4, 5, (x, y) => x ** y));   // 1024  ← تابع بی‌نام همان‌جا



پارامتر operation خود یک تابع است. calculate عددها را به آن تابع می‌دهد و نتیجهٔ برگشتی را برمی‌گرداند. می‌توانید تابعی را که از قبل در متغیر است بفرستید، یا همان‌جا یک تابع بی‌نام بنویسید. خود calculate نمی‌داند جمع است یا توان؛ این تصمیم با تابعی است که شما می‌فرستید.










map، filter، forEach و addEventListener همه توابع مرتبه بالا هستند؛ چون یک تابع ورودی می‌گیرند.



تابعی که تابع برمی‌گرداند



این الگو مثل «کارخانه تابع» است: یک بار تنظیمات را می‌دهیم و تابعی آماده می‌گیریم. مثال کاربردی: ساختن تابع محاسبه قیمت با درصد تخفیف‌های مختلف.



function makeMultiplier(factor) {
  return function (n) {
    return n * factor;
  };
}

const double = makeMultiplier(2);
const triple = makeMultiplier(3);
console.log(double(10), triple(10));      // 20 30

function makeDiscount(percent) {
  return price => price - (price * percent) / 100;
}

const studentPrice = makeDiscount(20);    // ۲۰٪ تخفیف دانشجویی
const vipPrice = makeDiscount(35);        // ۳۵٪ تخفیف مشتری ویژه
console.log(studentPrice(500000), vipPrice(500000));   // 400000 325000



makeMultiplier یک تابع تازه برمی‌گرداند که factor را به یاد دارد. هر بار صدا زدن makeMultiplier یک تابع جدا با ضریب خودش می‌سازد، به همین دلیل double و triple مستقل‌اند. makeDiscount همین الگو را برای کم کردن درصد از قیمت به کار می‌برد.










IIFE — تابعی که بلافاصله اجرا می‌شود



(function () {
  const secret = "فقط این‌جا دیده می‌شود";
  console.log(secret);
})();



پرانتز بیرونی تابع را تعریف می‌کند و پرانتز آخر همان لحظه آن را اجرا می‌کند. اسمی برای بعد باقی نمی‌ماند. secret فقط داخل همین اجرا وجود دارد و بیرون از پرانتزها دیده نمی‌شود. این شکل وقتی به کار می‌آید که یک کار را یک بار انجام دهید و نخواهید متغیرهایش با بقیهٔ فایل قاطی شود.










IIFE در کدهای قدیمی برای جلوگیری از ساختن متغیر سراسری زیاد دیده می‌شود. امروزه معمولاً همین کار را با ماژول‌ها (درس ۱۲) یا یک بلوک { } همراه با let/const انجام می‌دهیم.



اشتباه رایج: گذاشتن پارامتر پیش‌فرض قبل از پارامتر اجباری: function f(a = 1, b). این کد خطا نمی‌دهد، ولی برای استفاده از پیش‌فرض a باید f(undefined, 5) بنویسید که خوانا نیست. پارامترهای پیش‌فرض را آخر بگذارید.



اشتباه رایج: فرستادن نتیجه تابع به جای خود تابع: calculate(4, 5, add(4, 5)). این‌جا add همان لحظه اجرا می‌شود و عدد 9 (نه یک تابع) فرستاده می‌شود؛ درستش calculate(4, 5, add) است.



تمرین:

۱) تابع repeat(n, action) بنویسید که تابع action را n بار اجرا کند و شماره دور (از ۱ تا n) را به آن بدهد؛ مثلاً repeat(3, i => console.log("دور " + i)) سه خط «دور 1» تا «دور 3» چاپ کند.

۲) تابع makeGreeting(prefix) بنویسید که تابعی برگرداند؛ آن تابع اسم بگیرد و prefix + " " + name را برگرداند؛ مثلاً makeGreeting("سلام")("سارا") مقدار "سلام سارا" بدهد.

۳) تابع sumAll(...nums) بنویسید که هر تعداد عدد بگیرد و جمعشان را برگرداند و آن را یک بار با آرایه [5, 10, 15] و Spread صدا بزنید.
