۶) مجموعه و نگاشت (Set و Map)

آرایه برای فهرست مرتب خوب است، ولی برای «هر مقدار فقط یک بار» یا «جست‌وجوی سریع با کلید» ابزار دقیق‌تری هست. Set مجموعهٔ مقدارهای یکتاست و Map زوج‌های کلید و مقدار را نگه می‌دارد. کلید Map برخلاف شیء معمولی لازم نیست رشته باشد.

Set — مجموعه‌ای از مقدارهای یکتا

Set مثل آرایه است، ولی هر مقدار فقط یک بار در آن می‌آید.

const tags = new Set(["js", "css", "js", "html", "css"]);
console.log(tags);              // Set(3) {"js", "css", "html"}
console.log(tags.size);         // 3  ← Set به جای length، size دارد

tags.add("react");
tags.add("js");                 // تکراری؛ اضافه نمی‌شود
console.log(tags.has("css"));   // true
tags.delete("html");
console.log(tags);              // Set(3) {"js", "css", "react"}

for (const t of tags) console.log("-", t);

Set مقدار تکراری را نگه نمی‌دارد، حتی اگر در آرایهٔ اولیه چند بار آمده باشد. به‌جای length ویژگی size دارد. add اگر مقدار از قبل باشد کاری نمی‌کند. has وجود را با true یا false می‌گوید و delete همان مقدار را برمی‌دارد. پیمایش با for...of مقدارها را به ترتیبی که اولین بار اضافه شده‌اند می‌دهد.






کاربرد معروف: حذف تکراری‌ها از آرایه



const numbers = [1, 2, 2, 3, 3, 3, 4];
const unique = [...new Set(numbers)];   // Set ← حذف تکراری، [...] ← دوباره آرایه
console.log(unique);                    // [1, 2, 3, 4]



ساختن Set از آرایه، تکرارها را حذف می‌کند. سه نقطه آن مجموعه را دوباره به آرایه تبدیل می‌کند تا متدهای آرایه در دسترس باشند. ترتیب اولین دیده‌شدن هر عدد حفظ می‌شود. اگر به آرایه نیاز ندارید، می‌توانید همان Set را نگه دارید.










Set برای مقایسه از === استفاده می‌کند؛ پس دو شیء با محتوای یکسان ({id: 1} و {id: 1}) دو عضو جدا حساب می‌شوند. همچنین has در Set بسیار سریع‌تر از includes در آرایه‌های بزرگ است.



Map — کلید و مقدار با هر نوع کلید



Map شبیه شیء است، ولی کلید می‌تواند هر چیزی باشد (عدد، شیء، ...)، ترتیب اضافه شدن حفظ می‌شود و size دارد.



const prices = new Map();
prices.set("سیب", 45000);
prices.set("موز", 80000);
prices.set("انار", 60000);

console.log(prices.get("موز"));      // 80000
console.log(prices.has("کیوی"));     // false
console.log(prices.size);            // 3

prices.forEach((value, key) => {     // ترتیب پارامترها: اول مقدار، بعد کلید
  console.log(`${key}: ${value.toLocaleString("en-US")} تومان`);
});

const fromObject = new Map(Object.entries({ a: 1, b: 2 }));   // شیء ← Map
console.log(fromObject);             // Map(2) {"a" => 1, "b" => 2}
console.log(Object.fromEntries(fromObject));                  // Map ← شیء: {a: 1, b: 2}



Map زوج کلید و مقدار را نگه می‌دارد و کلید می‌تواند هر مقداری باشد، نه فقط رشته. set مقدار را می‌گذارد، get آن را می‌خواند و اگر کلید نباشد undefined می‌دهد. در forEach ترتیب پارامترها اول مقدار و بعد کلید است. در دو خط آخر، Object.entries یک شیء را به زوج‌های کلید و مقدار تبدیل می‌کند تا از آن Map ساخته شود و Object.fromEntries Map را دوباره به شیء برمی‌گرداند. این رفت‌وبرگشت وقتی کلیدها رشته باشند نتیجهٔ قابل‌استفاده می‌دهد.

مثال زنده: شمارش کلمات با Map



countBtn.addEventListener("click", () => {
  const text = textInput.value.trim();
  if (text === "") {                       // "".split(...) آرایه [""] می‌دهد، نه آرایه خالی
    output.textContent = "اول چند کلمه بنویسید.";
    return;
  }
  const words = text.split(/\s+/);
  const counts = new Map();
  for (const w of words) {
    counts.set(w, (counts.get(w) || 0) + 1);
  }
  const sorted = [...counts].sort((a, b) => b[1] - a[1]);
  output.textContent = sorted.map(([w, c]) => `${w}: ${c}`).join("\n");
});



متن خالی را جدا بررسی کرده‌ایم، چون split روی رشتهٔ خالی یک آرایه با یک رشتهٔ خالی می‌سازد و آن را یک کلمه حساب می‌کند. هر کلمه کلید Map است. اگر کلمه تازه باشد get مقدار undefined می‌دهد و || 0 شمارش را از صفر شروع می‌کند. مرتب‌سازی روی آرایهٔ زوج‌ها، پرتکرارترین کلمه را اول می‌آورد.













اشتباه رایج: استفاده از براکت برای Map: map["key"] = 1. این یک ویژگی معمولی می‌سازد نه عضو Map؛ size تغییر نمی‌کند و get آن را پیدا نمی‌کند. از set و get استفاده کنید.



اشتباه رایج: ذخیره مستقیم Map یا Set با JSON.stringify. نتیجه "{}" است و داده از بین می‌رود! اول به آرایه تبدیل کنید: JSON.stringify([...map]) و موقع خواندن: new Map(JSON.parse(text)) (این روش در پروژه نهایی درس ۱۸ استفاده شده است).



تمرین:

۱) علاقه‌مندی‌های دو نفر در دو آرایه است: ["فوتبال", "کتاب", "فیلم"] و ["کتاب", "شنا", "فیلم"]. با Set علاقه‌مندی‌های مشترک را پیدا کنید (راهنما: آرایه دوم را به Set تبدیل کنید و روی آرایه اول filter و has بزنید). خروجی مورد انتظار: ["کتاب", "فیلم"].

۲) با یک Map، تعداد دانشجویان هر شهر را از آرایه [{ name: "سارا", city: "شیراز" }, { name: "علی", city: "تبریز" }, { name: "مریم", city: "شیراز" }] بشمارید.
