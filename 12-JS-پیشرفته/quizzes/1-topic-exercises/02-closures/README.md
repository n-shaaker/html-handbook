## تمرین ۱ — شمارنده لایک ⭐

**هدف:** ساختن تابعی که یک تابع برمی‌گرداند و متغیر بیرونی‌اش را **به خاطر می‌سپارد**.

**صورت مسئله:** زیر دو پست وبلاگ دکمه «👍 لایک» هست. هر پست باید شمارنده **جداگانه** خودش را داشته باشد، بدون این‌که متغیر سراسری `let likes1, likes2` بسازیم.

**الزامات:**
- تابع `createCounter()` یک متغیر `count = 0` بسازد و تابعی برگرداند که هر بار `count` را یکی زیاد کند و برگرداند.
- برای هر پست یک شمارنده جدا ساخته شود: `const post1Likes = createCounter();`
- با کلیک روی دکمه هر پست، عدد کنار همان دکمه (با رقم فارسی) به‌روز شود.
- متغیر `count` از بیرون تابع قابل دسترسی نباشد.

**تست‌ها:**
- ۳ کلیک روی لایک پست ۱ ← پست ۱: «۳»، پست ۲: «۰»
- بعد از آن ۱ کلیک روی پست ۲ ← پست ۱: «۳»، پست ۲: «۱»
- در Console: `count` ← خطای `count is not defined`

## تمرین ۲ — کیف پول خصوصی ⭐⭐

**هدف:** برگرداندن **چند تابع** که همه به یک متغیر خصوصی مشترک دسترسی دارند.

**صورت مسئله:** یک کیف پول ساده برای بوفه مدرسه بسازید. موجودی نباید مستقیم قابل تغییر باشد؛ فقط با «واریز» و «برداشت».

**الزامات:**
- `createWallet(initialBalance)` شیئی با سه تابع `deposit(amount)`، `withdraw(amount)` و `getBalance()` برگرداند.
- مقدار صفر یا منفی پذیرفته نشود؛ پیام «مبلغ باید بیشتر از صفر باشد.»
- برداشت بیشتر از موجودی انجام نشود؛ پیام «موجودی کافی نیست.»
- یک کادر عدد و دو دکمه «واریز» و «برداشت»؛ موجودی بعد از هر کار نمایش داده شود.

**تست‌ها:**
- `createWallet(50000)` و واریز `20000` ← «موجودی: ۷۰٬۰۰۰ تومان»
- برداشت `100000` ← «موجودی کافی نیست.» (موجودی همان ۷۰٬۰۰۰ می‌ماند)
- واریز `-5` ← «مبلغ باید بیشتر از صفر باشد.»
- در Console: `wallet.balance` ← `undefined`

## تمرین ۳ — قفل رمز با تعداد تلاش محدود ⭐⭐⭐

**هدف:** نگه داشتن **وضعیت** (تعداد تلاش‌ها) داخل closure و تصمیم‌گیری بر اساس آن.

**صورت مسئله:** گاوصندوق دیجیتال یک فروشگاه فقط ۳ بار اجازه وارد کردن رمز اشتباه می‌دهد و بعد قفل می‌شود.

**الزامات:**
- `createPinChecker(correctPin, maxAttempts)` تابعی برگرداند که یک رمز بگیرد و یک پیام برگرداند.
- رمز درست ← «✔ درِ گاوصندوق باز شد.»
- رمز اشتباه ← «رمز اشتباه است. n تلاش دیگر دارید.» (n با رقم فارسی)
- بعد از تمام شدن تلاش‌ها ← «⛔ گاوصندوق قفل شد.» و دکمه بررسی غیرفعال شود؛ حتی رمز درست هم دیگر پذیرفته نشود.
- فرم با `submit` و `preventDefault` کار کند.

**تست‌ها** (رمز درست: `1234`، حداکثر ۳ تلاش):
- `1111` ← «رمز اشتباه است. ۲ تلاش دیگر دارید.»
- `1234` ← «✔ درِ گاوصندوق باز شد.»
- (صفحه تازه) `1` و `2` و `3` ← بعد از سومی «⛔ گاوصندوق قفل شد.»؛ بعد `1234` ← باز هم «⛔ گاوصندوق قفل شد.»

## اشتباه‌های رایج این مبحث

- تعریف `let count = 0` **بیرون** از `createCounter`؛ آن‌وقت همه شمارنده‌ها یک عدد مشترک دارند.
- برگرداندن نتیجه تابع به جای خود تابع: `return increment()` به جای `return increment`.
- صدا زدن `createCounter()` داخل listener کلیک؛ هر کلیک یک شمارنده تازه با صفر می‌سازد.
- انتظار این‌که `wallet.balance` موجودی را نشان دهد؛ متغیر داخل closure ویژگی شیء نیست.
