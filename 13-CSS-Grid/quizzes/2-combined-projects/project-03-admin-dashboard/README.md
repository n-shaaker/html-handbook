- **سطح:** ⭐⭐
- **زمان پیشنهادی:** ۷۵ دقیقه
- **هدف پروژه:** اسکلت یک پنل مدیریت را با `grid-template-areas` بسازید و داخلش کارت‌های آمار چهارستونه و یک پنل نمودار بزرگ ۲×۲ بچینید؛ همه در گوشی تک‌ستونی شوند.

## صورت مسئله

فروشگاه اینترنتی کتاب «ورق» یک پنل مدیریت ساده می‌خواهد. طرح دسکتاپ:

```
+---------------------------------------------+
|                    top                      |
+-----------------------------------+---------+
|  [stat] [stat] [stat] [stat]      |  side   |
|                                   |  menu   |
|  +---------+ +-----------------+  |         |
|  | orders  | |                 |  |         |
|  +---------+ |   chart (2x2)   |  |         |
|  | notes   | |                 |  |         |
|  +---------+ +-----------------+  |         |
+-----------------------------------+---------+
|                   bottom                    |
+---------------------------------------------+
```

## الزامات

1. `.dashboard` با `grid-template-areas` سه ردیف دارد: `top` تمام‌عرض، `side` (۲۰۰ پیکسل) کنار `main`، و `bottom` تمام‌عرض. کل صفحه دست‌کم `100vh` باشد و ردیف وسط با `1fr` کش بیاید.
2. منوی کناری با `display: grid` و `gap` لینک‌ها را زیر هم بچیند و با `align-content: start` بالای ستون بمانند.
3. `.stats` با `repeat(4, 1fr)` و `gap`.
4. `.panels` سه ستون مساوی با `grid-auto-rows: minmax(140px, auto)`.
5. پنل `.chart` با `span` دو ستون و دو ردیف بگیرد.
6. با **یک** media query (کمتر از ۷۰۰ پیکسل): نقشه تک‌ستونی، آمار دوستونه، پنل‌ها تک‌ستونی و نمودار دیگر span نداشته باشد.

## محدودیت‌ها

- چیدمان فقط با Grid؛ بدون `float`، `position` و Flexbox.
- بدون `height` ثابت برای پنل‌ها.
- بدون `style` درون‌خطی، JavaScript و `!important`.
- حداکثر یک media query.

## امتیازی (تا ۲ نمره)

- لینک فعال و `:hover`/`:focus-visible` لینک‌های منو ظاهر متفاوت داشته باشند.
- در دسکتاپ، کارت‌های آمار را با `repeat(auto-fit, minmax(160px, 1fr))` بسازید و توضیح بدهید چرا دیگر در media query لازم نیستند.

## نکته استاد

- اگر ردیف وسط کش نمی‌آید و فوتر وسط صفحه است، `grid-template-rows: auto 1fr auto` و `min-height: 100vh` را چک کنید.
- اگر در گوشی نمودار باز هم دو ستون می‌گیرد و صفحه بیرون می‌زند، `span` را در media query با `auto` خنثی کنید.
- قبل از نوشتن CSS، نقشه ناحیه‌ها را روی کاغذ بکشید؛ نصف کار همین است.
