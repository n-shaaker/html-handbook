# تمرین‌های مبحث «نام‌گذاری ناحیه‌ها (template-areas)»

درس مربوط: [نام‌گذاری ناحیه‌ها (template-areas)](../../../pages/06-template-areas.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — اسکلت کلاسیک سایت ⭐

**هدف:** با `grid-template-areas` و `grid-area` اسکلت سربرگ، ستون کناری، محتوا و پانویس را بسازید.

**صورت مسئله:**

یک وبلاگ ساده اسکلت کلاسیک می‌خواهد: سربرگ و پانویس تمام‌عرض، و بین آن‌ها ستون کناری (۲۰۰ پیکسل، سمت راست)
کنار محتوای اصلی.

**الزامات:**

- [ ] ظرف `.page` با `grid-template-columns: 200px 1fr`.
- [ ] نقشه با سه رشته: `"header header"`، `"sidebar main"`، `"footer footer"`.
- [ ] هر بخش با `grid-area` به نامش وصل شود.
- [ ] از شماره خط استفاده نکنید.

**خروجی مورد انتظار:**

```
+---------------------------+
|          header           |
+-----------------+---------+
|      main       | sidebar |
+-----------------+---------+
|          footer           |
+---------------------------+
```

---

## تمرین ۲ — سه ستون با خانه خالی ⭐⭐

**هدف:** در نقشه ناحیه‌ها ستون سوم اضافه کنید و با `.` یک خانه را خالی بگذارید.

**صورت مسئله:**

سایت یک مجله سه ستون دارد: منو (راست)، محتوا (وسط)، تبلیغ (چپ). سربرگ تمام‌عرض است.
پانویس فقط زیر **منو و محتوا** است و زیر ستون تبلیغ باید **خالی** بماند.

**الزامات:**

- [ ] `grid-template-columns: 150px 1fr 150px`.
- [ ] نقشه سه ردیف، هر ردیف سه نام؛ خانه خالی با `.`.
- [ ] نام‌ها: `header`، `menu`، `main`، `ads`، `footer`.
- [ ] ستون‌های نقشه را با فاصله تراز کنید تا خوانا باشد.

**خروجی مورد انتظار:**

```
+------------------------------+
|            header            |
+------+--------------+--------+
| ads  |     main     |  menu  |
+------+--------------+--------+
|      |        footer         |
+------+-----------------------+
```

---

## تمرین ۳ — نقشه خراب ناحیه‌ها ⭐⭐⭐

**هدف:** قانون‌های نقشه ناحیه را بشناسید: تعداد نام برابر در هر ردیف، ناحیه مستطیلی، نام بدون گیومه در `grid-area`.

**صورت مسئله:**

صفحه یک فروشگاه قرار بود این شکل باشد: سربرگ تمام‌عرض؛ ستون کناری سمت راست در دو ردیف وسط؛
محتوا در دو ستون دیگرِ همان دو ردیف؛ پانویس تمام‌عرض. ولی کل نقشه نادیده گرفته شده و
همه بخش‌ها زیر هم آمده‌اند.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] هر ردیف نقشه دقیقاً سه نام داشته باشد.
- [ ] ناحیه `sidebar` مستطیل باشد (فقط ستون راست، ردیف ۲ و ۳).
- [ ] نام `grid-area` محتوا با نام نقشه یکی باشد.
- [ ] `grid-area` پانویس بدون گیومه نوشته شود.
- [ ] کنار هر اصلاح یک کامنت بنویسید.

**خروجی مورد انتظار:**

```
+------------------------------+
|            header            |
+--------------------+---------+
|                    |         |
|        main        | sidebar |
|                    |         |
+--------------------+---------+
|            footer            |
+------------------------------+
```

---

## اشتباه‌های رایج این مبحث

- تعداد نام نابرابر در ردیف‌های نقشه؛ کل `grid-template-areas` نامعتبر و نادیده گرفته می‌شود.
- ناحیه غیرمستطیلی (مثلاً شکل L)؛ مجاز نیست.
- نوشتن نام داخل گیومه در `grid-area`؛ گیومه فقط در خود نقشه است.
- یکی نبودن نام در نقشه و در `grid-area` (مثلاً `content` و `main`).
