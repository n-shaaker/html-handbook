# تمرین‌های مبحث «الگوهای پرکاربرد»

درس مربوط: [الگوهای پرکاربرد](../../../pages/12-patterns.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — کادر ورود وسط صفحه ⭐

**هدف:** با `display: grid` و `place-items: center` یک کادر را وسط کل صفحه بیاورید.

**صورت مسئله:**

صفحه ورود یک سایت فقط یک کادر کوچک دارد که باید **دقیقاً وسط** پنجره باشد، افقی و عمودی.

**الزامات:**

- [ ] `body` با `margin: 0`.
- [ ] ظرف `.screen` با `min-height: 100vh`، `display: grid` و `place-items: center`.
- [ ] کادر `.login` با عرض ۲۸۰ پیکسل، شامل تیتر، دو `input` با `label` و یک دکمه.

**خروجی مورد انتظار:**

```
+---------------------------------+
|                                 |
|          +-----------+          |
|          |  login    |          |
|          +-----------+          |
|                                 |
+---------------------------------+
```

## تمرین ۲ — فرم دوستونه ⭐⭐

**هدف:** برچسب‌ها و فیلدهای فرم را در دو ستون `150px 1fr` بچینید و دکمه را با `grid-column` زیر فیلدها بفرستید.

**صورت مسئله:**

فرم «ثبت‌نام در همایش» سه فیلد دارد. برچسب‌ها در ستون راست (۱۵۰ پیکسل)
و فیلدها در ستون چپ (بقیه عرض) کنار برچسبشان باشند. دکمه ارسال زیر **فیلدها** باشد، نه زیر برچسب‌ها.

**الزامات:**

- [ ] `form` با `grid-template-columns: 150px 1fr` و `gap`.
- [ ] هر `label` با `for` به `input` خودش وصل باشد.
- [ ] دکمه با `grid-column: 2` در ستون دوم.
- [ ] برچسب‌ها با `align-self: center` (یا `align-items`) عمودی وسط ردیف باشند.

**خروجی مورد انتظار:**

```
+--------------------------+---------+
| [_______________]        |  name   |
| [_______________]        |  email  |
| [_______________]        |  phone  |
| [send]                   |         |
+--------------------------+---------+
```

## تمرین ۳ — گالری غذا با یک عکس بزرگ ⭐⭐⭐

**هدف:** یک گالری با عکس بزرگ ۲×۲ بسازید که عکس‌ها خانه‌شان را بدون کشیدگی پر کنند.

**صورت مسئله:**

صفحه یک رستوران گالری غذا می‌خواهد: چهار ستون، ردیف‌های ۱۲۰ پیکسلی، و عکس «غذای روز»
که دو ستون و دو ردیف بگیرد. عکس‌ها نباید کشیده یا له شوند.

**الزامات:**

- [ ] `repeat(4, 1fr)` و `grid-auto-rows: 120px` و `gap`.
- [ ] عکس بزرگ کلاس `big` با `grid-column: span 2` و `grid-row: span 2`.
- [ ] همه `img` ها `width: 100%`، `height: 100%` و `object-fit: cover`.
- [ ] عکس‌ها از `05-CSS-تصاویر/images/` با مسیر نسبی درست، و هر `img` یک `alt` دقیق.

**خروجی مورد انتظار:**

```
+-----+-----+-----------+
|  2  |  1  |           |
+-----+-----+    BIG    |
|  4  |  3  |           |
+-----+-----+-----------+
```

---

## اشتباه‌های رایج این مبحث

- وسط کردن با `margin-top` حدسی؛ `place-items: center` روی یک ظرف با `min-height` کافی است.
- در فرم دوستونه، فراموش کردن `grid-column: 2` برای دکمه؛ دکمه زیر برچسب‌ها می‌افتد.
- عکس بدون `object-fit: cover` در خانه‌های ثابت؛ عکس کشیده یا له می‌شود.
- نوشتن مسیر عکس از دید پوشه اشتباه؛ مسیر نسبی از جای **فایل HTML** حساب می‌شود.
