# تمرین‌های مبحث «repeat() و minmax()»

درس مربوط: [repeat() و minmax()](../../../pages/03-repeat-minmax.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — چهار ستون با repeat ⭐

**هدف:** به‌جای تکرار دستی `1fr`، با `repeat(4, 1fr)` چهار ستون بسازید.

**صورت مسئله:**

یک فروشگاه لوازم‌التحریر هشت محصول دارد و می‌خواهد آن‌ها را **چهارتا چهارتا** نشان دهد.

**الزامات:**

- [ ] ظرف `.products` با `grid-template-columns: repeat(4, 1fr)`.
- [ ] هشت محصول در دو ردیف.
- [ ] فاصله با `border` سفید (هنوز `gap` نخوانده‌ایم).

**خروجی مورد انتظار:**

```
| 4 | 3 | 2 | 1 |
| 8 | 7 | 6 | 5 |
```

---

## تمرین ۲ — کارت‌هایی که از ۱۵۰ پیکسل کوچک‌تر نمی‌شوند ⭐⭐

**هدف:** با `minmax()` برای ستون‌ها حداقل عرض و برای ردیف‌ها حداقل ارتفاع بگذارید.

**صورت مسئله:**

سه کارت معرفی استاد کنار هم هستند. ستون‌ها نباید از ۱۵۰ پیکسل باریک‌تر شوند. هر ردیف هم دست‌کم
۱۰۰ پیکسل ارتفاع دارد، ولی اگر متن یک کارت بلند بود، ردیف باید **بلندتر** شود.

**الزامات:**

- [ ] `grid-template-columns: repeat(3, minmax(150px, 1fr))`.
- [ ] `grid-template-rows: repeat(2, minmax(100px, auto))`.
- [ ] دست‌کم یکی از کارت‌ها متن بلند داشته باشد تا بزرگ شدن ردیف دیده شود.
- [ ] در یک کامنت بنویسید در عرض خیلی باریک چه اتفاقی می‌افتد (راه‌حلش در درس ۹ است).

**خروجی مورد انتظار:**

```
+-------+-------+-------+
|       | long  |       |   <- این ردیف بلندتر شده
|       | text  |       |
+-------+-------+-------+
|       |       |       |   <- حداقل 100px
+-------+-------+-------+
```

## تمرین ۳ — repeat و minmax نوشته‌شده به‌شکل غلط ⭐⭐⭐

**هدف:** ترتیب درست آرگومان‌های `repeat` و `minmax` و الگوی تکراری `repeat(2, 120px 1fr)` را تمرین کنید.

**صورت مسئله:**

صفحه مشخصات یک گوشی دو بخش دارد: ۱. سه عکس که باید سه ستون مساوی باشند.
۲. جدول مشخصات که در هر ردیف دو جفت «عنوان: مقدار» دارد (عنوان ۱۲۰ پیکسل، مقدار بقیه).
هیچ‌کدام کار نمی‌کند و همه‌چیز زیر هم است.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] سه عکس در سه ستون مساوی با `repeat` درست.
- [ ] جدول مشخصات چهار ستون داشته باشد: `120px 1fr 120px 1fr` که با `repeat(2, 120px 1fr)` نوشته شود.
- [ ] در کامنت بنویسید چرا `minmax(1fr, 120px)` غلط است.

**خروجی مورد انتظار:**

```
[ photo ][ photo ][ photo ]

+------+--------+------+--------+
| val  | label  | val  | label  |
| val  | label  | val  | label  |
+------+--------+------+--------+
```

---

## اشتباه‌های رایج این مبحث

- جابه‌جا نوشتن آرگومان‌ها: `repeat(1fr, 3)` غلط است؛ اول **تعداد** بعد **اندازه**.
- گذاشتن `fr` به‌عنوان حداقل در `minmax`؛ مقدار اول باید اندازه مشخص مثل `150px` باشد.
- فراموش کردن اینکه `minmax(150px, 1fr)` با تعداد ثابت ستون، در گوشی اسکرول افقی می‌سازد.
- استفاده از ارتفاع ثابت برای ردیف‌های پرمتن؛ `minmax(100px, auto)` اجازه بزرگ شدن می‌دهد.
