# تمرین‌های مبحث «تراز کل شبکه داخل ظرف»

درس مربوط: [تراز کل شبکه داخل ظرف](../../../pages/08-align-content.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

## تمرین ۱ — صفحه‌کلید عددی وسط کادر ⭐

**هدف:** با `justify-content: center` یک شبکه با ستون‌های ثابت را افقی وسط ظرف بیاورید.

**صورت مسئله:**

صفحه‌کلید عددی یک دستگاه کارت‌خوان سه ستون ۷۰ پیکسلی دارد. کادرش تمام‌عرض است
و صفحه‌کلید الان به سمت راست چسبیده؛ باید **وسط** کادر باشد.

**الزامات:**

- [ ] `grid-template-columns: repeat(3, 70px)` (ستون ثابت، نه `fr`).
- [ ] دوازده دکمه با `gap: 6px`.
- [ ] کل شبکه با `justify-content: center` وسط کادر بیاید.

**خروجی مورد انتظار:**

```
+--------------------------------------+
|            [3] [2] [1]               |
|            [6] [5] [4]               |
|            [9] [8] [7]               |
|            [#] [0] [*]               |
+--------------------------------------+
```

## تمرین ۲ — بازی حافظه، وسطِ وسط ⭐⭐

**هدف:** با `place-content: center` کل شبکه را هم افقی و هم عمودی وسط ظرف بیاورید.

**صورت مسئله:**

یک بازی حافظه کوچک نُه کارت ۸۰ پیکسلی دارد. صفحه بازی ۴۰۰ پیکسل ارتفاع دارد
و شبکه کارت‌ها باید دقیقاً **وسط** صفحه بازی باشد.

**الزامات:**

- [ ] ظرف `height: 400px`.
- [ ] ستون‌ها و ردیف‌ها با `repeat(3, 80px)`.
- [ ] با یک خط `place-content: center` شبکه وسط شود.
- [ ] در کامنت بنویسید `place-content` میان‌بُر کدام دو خاصیت است.

**خروجی مورد انتظار:**

```
+-----------------------------+
|                             |
|        [?] [?] [?]          |
|        [?] [?] [?]          |
|        [?] [?] [?]          |
|                             |
+-----------------------------+
```

## تمرین ۳ — justify-content بی‌اثر ⭐⭐⭐

**هدف:** بفهمید `justify-content` و `align-content` فقط وقتی اثر دارند که شبکه از ظرف **کوچک‌تر** باشد.

**صورت مسئله:**

نقشه صندلی‌های یک کلاس: چهار ستون صندلی که باید با فاصله‌های **برابر** در عرض کلاس پخش شوند،
و دو ردیف که اولی بالای کلاس و دومی پایین کلاس (۳۰۰ پیکسل) بچسبد. هیچ‌کدام اثری ندارد.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] ستون‌ها ثابت ۸۰ پیکسل شوند تا جای خالی برای پخش شدن بماند.
- [ ] ستون‌ها با `justify-content: space-evenly` پخش شوند.
- [ ] ردیف‌ها با `align-content: space-between` به بالا و پایین بچسبند.
- [ ] در کامنت بنویسید چرا با `1fr`، `justify-content` اثری نداشت.

**خروجی مورد انتظار:**

```
+------------------------------------+
|   [s]    [s]    [s]    [s]         |
|                                    |
|                                    |
|   [s]    [s]    [s]    [s]         |
+------------------------------------+
```

---

## اشتباه‌های رایج این مبحث

- انتظار اثر `justify-content` با ستون‌های `fr`؛ `fr` همه فضا را می‌گیرد و جای خالی نمی‌ماند.
- قاطی کردن `align-items` (آیتم داخل خانه) با `align-content` (کل شبکه داخل ظرف).
- فراموش کردن ارتفاع ظرف؛ بدون ارتفاع اضافه، `align-content` اثری ندارد.
