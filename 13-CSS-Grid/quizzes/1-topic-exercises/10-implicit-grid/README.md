# تمرین‌های مبحث «شبکه ضمنی (grid-auto)»

درس مربوط: [شبکه ضمنی (grid-auto)](../../../pages/10-implicit-grid.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — ردیف‌هایی که خودشان ساخته می‌شوند ⭐

**هدف:** با `grid-auto-rows` ارتفاع همه ردیف‌های ضمنی را یکجا تعیین کنید.

**صورت مسئله:**

تعداد پست‌های یک وبلاگ هر هفته بیشتر می‌شود و نمی‌دانیم چند ردیف لازم است. فقط ستون‌ها را
تعریف کنید و کاری کنید **هر ردیف**، هر چند تا که ساخته شود، ۱۲۰ پیکسل باشد.

**الزامات:**

- [ ] `grid-template-columns: repeat(3, 1fr)` و **بدون** `grid-template-rows`.
- [ ] `grid-auto-rows: 120px`.
- [ ] دست‌کم نُه پست.

**خروجی مورد انتظار:**

```
| p | p | p |   120px
| p | p | p |   120px
| p | p | p |   120px   <- همه ردیف‌ها ضمنی‌اند
```

---

## تمرین ۲ — فهرست مخاطبان ستون‌به‌ستون ⭐⭐

**هدف:** با `grid-auto-flow: column` و `grid-auto-columns` شبکه را ستونی پر کنید.

**صورت مسئله:**

دفترچه تلفن یک شرکت باید اسم‌ها را **از بالا به پایین** پر کند: چهار اسم در هر ستون،
و هر چند ستون که لازم شد، خودش ساخته شود (هر ستون ۱۵۰ پیکسل).

**الزامات:**

- [ ] `grid-template-rows: repeat(4, auto)`.
- [ ] `grid-auto-flow: column`.
- [ ] `grid-auto-columns: 150px`.
- [ ] ده مخاطب.

**خروجی مورد انتظار:**

```
|  9  |  5  |  1  |
| 10  |  6  |  2  |
|     |  7  |  3  |
|     |  8  |  4  |
```

## تمرین ۳ — گالری سوراخ‌سوراخ ⭐⭐⭐

**هدف:** ردیف‌های ضمنی له‌شده را با `grid-auto-rows` و سوراخ‌ها را با `grid-auto-flow: dense` درست کنید.

**صورت مسئله:**

در گالری یک فروشگاه گیاه، عکس‌های «عریض» دو ستون می‌گیرند. دو ایراد هست:
فقط ردیف اول ۱۰۰ پیکسل است و بقیه ردیف‌ها **کوتاه و له** شده‌اند؛ و کنار عکس‌های عریض **خانه خالی** مانده.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] همه ردیف‌ها، حتی ردیف‌های ضمنی، ۱۰۰ پیکسل باشند.
- [ ] خانه‌های خالی با `grid-auto-flow: dense` پر شوند.
- [ ] در کامنت بنویسید `dense` چه چیزی را عوض می‌کند (ترتیب نمایش!).

**خروجی مورد انتظار:**

```
قبل:                      بعد:
| p | p |  wide  |       | p | p |  wide  |
|   |  wide  | p |       | p |  wide  | p |
| p |   |  wide  |       |  wide  | p | p |
```

---

## اشتباه‌های رایج این مبحث

- نوشتن `grid-template-rows` با یک مقدار و انتظار اثر روی همه ردیف‌ها؛ برای ردیف‌های ضمنی `grid-auto-rows` لازم است.
- فراموش کردن اینکه با `grid-auto-flow: column` باید تعداد **ردیف‌ها** را مشخص کنید.
- استفاده از `dense` برای محتوایی که ترتیبش مهم است (مثل مراحل یا اخبار به ترتیب زمان).
