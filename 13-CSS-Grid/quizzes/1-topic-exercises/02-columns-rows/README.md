# تمرین‌های مبحث «ستون‌ها و ردیف‌ها»

درس مربوط: [ستون‌ها و ردیف‌ها](../../../pages/02-columns-rows.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — ستون کناری ۲۰۰ پیکسلی ⭐

**هدف:** یک ستون ثابت پیکسلی را کنار یک ستون `1fr` بگذارید.

**صورت مسئله:**

وبلاگ آشپزی «سفره» یک ستون کناری ۲۰۰ پیکسلی برای دسته‌ها و یک ستون اصلی برای دستور غذا می‌خواهد
که بقیه عرض صفحه را بگیرد.

**الزامات:**

- [ ] ظرف `.page` با `grid-template-columns: 200px 1fr`.
- [ ] ستون کناری `aside` و ستون اصلی `main` باشد.
- [ ] با تغییر عرض پنجره فقط ستون اصلی باریک و پهن شود.

**خروجی مورد انتظار:**

```
+------------------------------+---------+
|            main (1fr)        |  200px  |
+------------------------------+---------+
```

---

## تمرین ۲ — برنامه کلاس‌های هفته ⭐⭐

**هدف:** ستون‌ها و ردیف‌ها را با اندازه‌های مختلف (`px` و `fr`) با هم تعریف کنید.

**صورت مسئله:**

یک آموزشگاه موسیقی جدول برنامه می‌خواهد: ستون اول نام روز (۱۰۰ پیکسل) و سه ستون مساوی برای
ساعت‌های ۸، ۱۰ و ۱۲. ردیف عنوان‌ها کوتاه (۴۰ پیکسل) و ردیف روزها بلندتر (۶۰ پیکسل) باشند.

**الزامات:**

- [ ] `grid-template-columns: 100px 1fr 1fr 1fr`.
- [ ] `grid-template-rows: 40px 60px 60px 60px` (هنوز `repeat` را نخوانده‌ایم).
- [ ] ردیف اول عنوان‌ها با رنگ متفاوت باشد.
- [ ] هیچ تگ `table` استفاده نشود؛ ۱۶ `div` کافی است.

**خروجی مورد انتظار:**

```
+------+------+------+-------+
|  12  |  10  |   8  |  day  |   <- 40px
+------+------+------+-------+
|      |      |      |  sat  |   <- 60px
|      |      |      |  sun  |
|      |      |      |  mon  |
+------+------+------+-------+
```

## تمرین ۳ — ستون‌هایی که جا نمی‌شوند ⭐⭐⭐

**هدف:** خطاهای رایج در `grid-template-columns` و `grid-template-rows` را پیدا و درست کنید.

**صورت مسئله:**

صفحه اول یک سایت خبری قرار بود سه ستون با نسبت **۱ به ۲ به ۱** داشته باشد که کل عرض را پر کنند،
و هر دو ردیف ۱۲۰ پیکسل ارتفاع داشته باشند. ولی: ستون‌ها کنار هم نیستند،
و بعد از درست شدن هم، در گوشی از صفحه بیرون می‌زنند و فقط ردیف اول ۱۲۰ پیکسل است.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] اشتباه تایپی نام خاصیت را پیدا و درست کنید.
- [ ] ستون‌ها نسبت ۱ به ۲ به ۱ داشته باشند و کل عرض را پر کنند (`fr`).
- [ ] هر دو ردیف ۱۲۰ پیکسل باشند.
- [ ] کنار هر اصلاح کامنت کوتاه بگذارید.

**خروجی مورد انتظار:**

```
+------+------------+------+
|  3   |     2      |  1   |   120px
+------+------------+------+
|  6   |     5      |  4   |   120px
+------+------------+------+
```

---

## اشتباه‌های رایج این مبحث

- غلط تایپی در نام خاصیت (`grid-template-column` بدون s)؛ مرورگر بی‌صدا آن را نادیده می‌گیرد.
- استفاده از پیکسل ثابت برای همه ستون‌ها؛ در گوشی از صفحه بیرون می‌زند. `fr` بقیه فضا را تقسیم می‌کند.
- انتظار اینکه یک مقدار در `grid-template-rows` برای همه ردیف‌ها تکرار شود؛ فقط ردیف اول را می‌سازد.
- قاطی کردن `%` و `fr`: درصد از کل عرض حساب می‌شود، ولی `fr` از فضای **باقی‌مانده**.
