۱۱) Grid یا Flexbox؟

Flexbox و Grid هر دو چیدمان را به CSS می‌سپارند، اما مسئله‌ای که حل می‌کنند یکی نیست. اگر آیتم‌ها باید در یک جهت پشت سر هم بنشینند و اندازهٔ هر کدام از محتوایش بیاید، Flexbox مستقیم‌تر است. اگر صفحه را از قبل به ردیف و ستون تقسیم کرده‌اید و می‌خواهید خانه‌های ردیف‌های مختلف زیر هم بمانند، Grid همان نقشه را نگه می‌دارد.

  • Flexbox از محتوا به بیرون کار می‌کند. آیتم‌ها در یک جهت کنار هم می‌نشینند و هر کدام، مگر اینکه flex خلافش را بگوید، به اندازهٔ محتوای خودش جا می‌گیرد.
  • Grid از نقشه به داخل کار می‌کند. اول ستون‌ها و ردیف‌ها را می‌کشید و بعد آیتم‌ها در خانه‌ها می‌نشینند، برای همین لبهٔ ستون‌ها در ردیف‌های بعدی هم همان‌جا می‌ماند.

اگر Flexbox را هنوز نخوانده‌اید، مقایسهٔ این صفحه را بعد از آموزش Flexbox راحت‌تر می‌فهمید، چون مثال‌ها به flex و flex-wrap تکیه دارند.

مثال ۱: یک چیدمان، دو روش — سه کارت هم‌اندازه

/* با Flexbox */
.cards-flex { display: flex; gap: 10px; }
.cards-flex .card { flex: 1; }

/* با Grid */
.cards-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

در این مثال هر دو روش سه کارت هم‌عرض می‌سازند، چون در Flexbox به هر کارت flex: 1 داده‌ایم و در Grid سه ستون 1fr داریم. هم‌عرض شدن اینجا نتیجهٔ آن تنظیم‌هاست، نه شباهت ذاتی دو مدل. برای یک ردیف ساده که لازم نیست ستون‌ها در ردیف بعد هم تراز بمانند، هر کدام را که خواندن کدانش ساده‌تر است می‌توانید انتخاب کنید.

مثال ۲: فرق اصلی — وقتی آیتم‌ها به ردیف بعد می‌روند

۵ محصول داریم و در هر ردیف ۳ تا جا می‌شود. در Flexbox هر ردیف جدا حساب می‌شود، پس دو آیتم آخر پهن می‌شوند تا ردیف را پر کنند. در Grid ستون‌ها ثابت‌اند و ردیف آخر هم با بقیه هم‌تراز می‌ماند: 

/* Flexbox */
.wrap-flex { display: flex; flex-wrap: wrap; gap: 10px; }
.wrap-flex .card { flex: 1 1 30%; }

/* Grid */
.wrap-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

مثال ۳: جایی که Flexbox بهتر است — منوی بالای سایت

لینک‌های منو طول‌های متفاوتی دارند و باید به اندازه متن خودشان باشند. با Flexbox ساده و طبیعی است؛ با repeat(4, 1fr) همه هم‌عرض و عجیب می‌شوند: 

.nav-flex { display: flex; gap: 6px; }

.nav-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 6px;
}

مثال ۴: ترکیب هر دو — صفحه با Grid، داخل کارت با Flexbox

در عمل بیشتر وقت‌ها هر دو را با هم استفاده می‌کنیم: Grid برای چیدن کارت‌ها در صفحه، و Flexbox برای چیدن محتوای داخل هر کارت. اینجا دکمه «سفارش» همیشه ته کارت است، حتی اگر متن کارت‌ها کوتاه و بلند باشد: 

/* بیرون: Grid */
.menu-cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
  gap: 12px;
}

/* داخل هر کارت: Flexbox ستونی */
.menu-card {
  display: flex;
  flex-direction: column;
}

.menu-card .order {
  margin-top: auto;   /* دکمه به ته کارت هل داده شود */
}

اشتباه رایج: فکر می‌کنیم باید یکی را «برای همیشه» انتخاب کنیم. Grid جایگزین Flexbox نیست؛ این دو مکمل هم هستند و یک صفحه خوب معمولاً هر دو را دارد. سؤال درست این است: «این بخش یک‌بعدی است یا دوبعدی؟»

تمرین: صفحه «دوره‌های آموزشگاه» بسازید: کارت دوره‌ها با Grid چیده شوند، داخل هر کارت با Flexbox عنوان بالا، توضیح وسط و ردیف «قیمت + دکمه ثبت‌نام» ته کارت باشد (قیمت سمت راست و دکمه سمت چپ همان ردیف).
