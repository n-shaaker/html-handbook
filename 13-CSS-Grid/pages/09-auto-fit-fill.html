۹) auto-fill و auto-fit

تا حالا تعداد ستون‌ها را خودمان می‌گفتیم: repeat(4, 1fr). ولی در گوشی ۴ ستون خیلی باریک می‌شود! اگر به‌جای عدد بنویسیم auto-fill یا auto-fit، مرورگر خودش حساب می‌کند چند ستون جا می‌شود. نتیجه: شبکه واکنش‌گرا بدون حتی یک media query.

در این درس حتماً پنجره مرورگر را باریک و پهن کنید تا تغییر تعداد ستون‌ها را ببینید.

مثال ۱: repeat(auto-fill, 150px)

هر ستون دقیقاً ۱۵۰ پیکسل؛ مرورگر هر چندتا که جا شود می‌سازد. ولی سمت چپ کمی جای خالی می‌ماند:

.fixed-cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, 150px);
  gap: 8px;
}

مثال ۲: فرمول طلایی — repeat(auto-fill, minmax(200px, 1fr))

با minmax می‌گوییم «هر ستون حداقل ۲۰۰ پیکسل، ولی اگر جا ماند همه با هم پهن شوید». حالا جای خالی هم نمی‌ماند. این یک خط را برای کارت‌های محصول تقریباً همه سایت‌ها می‌بینید: 

.products {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 12px;
}

مثال ۳: فرق auto-fill و auto-fit (وقتی آیتم کم است)

تا وقتی آیتم‌ها زیادند، این دو هیچ فرقی ندارند. فرق وقتی پیدا می‌شود که آیتم‌ها کمتر از ستون‌های جاشده باشند. هر دو شبکه زیر فقط ۲ آیتم دارند: 

.fill { grid-template-columns: repeat(auto-fill, minmax(120px, 1fr)); }
.fit  { grid-template-columns: repeat(auto-fit,  minmax(120px, 1fr)); }

کلمه یادآوری ساده کی؟
auto-fill «خانه‌ها را پر کن؛ اگر آیتم کم بود خانه خالی بماند» وقتی می‌خواهید کارت‌ها همیشه هم‌اندازه بمانند (مثلاً ۲ محصول بیش از حد پهن نشوند)
auto-fit «آیتم‌ها را جا بده؛ خانه خالی را حذف کن» وقتی می‌خواهید آیتم‌های کم، کل عرض را بگیرند

مثال ۴: گالری عکس سفر

گالری زیر همان الگو را روی کارت واقعی می‌گذارد: عکس بالا و متن پایین. چون ستون‌ها با repeat(auto-fill, minmax(180px, 1fr)) ساخته شده‌اند، هر ستون دست‌کم ۱۸۰ پیکسل است و اگر جا بماند پهن‌تر می‌شود. در صفحهٔ پهن چند ستون کنار هم می‌آیند و وقتی عرض ظرف برای ستون دوم کافی نباشد، کارت‌ها در یک ستون زیر هم قرار می‌گیرند. برای این تغییر به media query نیازی نیست. 

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
  gap: 12px;
}

.photo-card .photo {
  height: 100px;           /* جای عکس */
  border-radius: 6px 6px 0 0;
}

جزیره هرمز

در پروژه واقعی به‌جای div.photo یک img با width: 100% و object-fit: cover بگذارید (درس‌های تصاویر در CSS).

اشتباه رایج: نوشتن repeat(auto-fill, 1fr). مرورگر باید بداند هر ستون حداقل چقدر است تا بشمارد چندتا جا می‌شود؛ با 1fr تنها نمی‌تواند حساب کند و کل خط نامعتبر می‌شود. همیشه یک اندازه ثابت بدهید: 150px یا minmax(150px, 1fr).

اشتباه رایج: حداقل خیلی بزرگ: minmax(400px, 1fr). در گوشی‌ای که ۳۶۰ پیکسل عرض دارد، حتی یک ستون هم جا نمی‌شود و کارت از صفحه بیرون می‌زند. برای کارت‌ها حداقلی بین ۱۵۰ تا ۲۵۰ پیکسل معمولاً مناسب است.

تمرین: صفحه «اساتید آموزشگاه» را با ۷ کارت (عکس، اسم، تخصص) بسازید که با repeat(auto-fill, minmax(...)) واکنش‌گرا باشد. بعد ۵ کارت را پاک کنید و auto-fill را با auto-fit عوض کنید و فرق را در یک کامنت CSS بنویسید.
