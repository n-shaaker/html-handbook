۱۴) تمرین جمع‌بندی

به آخر دوره رسیدیم! در این صفحه یک چک‌لیست برای مرور، یک جدول مرجع از همه ویژگی‌ها، چند مثال ترکیبی و در آخر تمرین‌هایی از ساده به سخت آمده است.

چک‌لیست: این‌ها را بدون نگاه کردن به جزوه بلدم؟

  • می‌دانم display: grid روی پدر نوشته می‌شود و فقط فرزندهای مستقیم آیتم هستند.
  • با grid-template-columns و واحدهای px، fr و auto ستون می‌سازم.
  • در repeat() و minmax() ویرگول می‌گذارم، ولی بین ستون‌ها نه.
  • برای فاصله از gap استفاده می‌کنم، نه margin.
  • می‌دانم grid-column: 1 / 3 یعنی دو ستون و 1 / -1 یعنی تمام عرض.
  • می‌دانم در صفحه راست‌چین خط ۱ سمت راست است.
  • با grid-template-areas نقشه صفحه می‌کشم و می‌دانم هر ناحیه باید مستطیل باشد.
  • فرق -items (داخل خانه) و -content (کل شبکه) را می‌دانم.
  • با repeat(auto-fill, minmax(200px, 1fr)) کارت واکنش‌گرا بدون media query می‌سازم.
  • برای تعداد نامعلوم آیتم grid-auto-rows می‌نویسم.
  • می‌دانم کجا Grid و کجا Flexbox بهتر است و چطور با هم ترکیبشان کنم.
  • با یک media query نقشه صفحه را برای موبایل یک‌ستونه می‌کنم.

جدول مرجع: ویژگی‌های ظرف (پدر)

ویژگی نمونه کار درس
display grid ساختن ظرف شبکه ۱
grid-template-columns 200px 1fr تعداد و پهنای ستون‌ها ۲
grid-template-rows 80px auto تعداد و ارتفاع ردیف‌ها ۲
repeat() / minmax() repeat(3, minmax(100px, 1fr)) تکرار / کمترین و بیشترین اندازه ۳
gap، row-gap، column-gap 16px یا 20px 10px فاصله بین خانه‌ها ۴
grid-template-areas "header header" "side main" نقشه ناحیه‌ها با اسم ۶
justify-items، align-items، place-items center تراز همه آیتم‌ها داخل خانه‌شان ۷
justify-content، align-content، place-content space-between تراز کل شبکه داخل ظرف ۸
auto-fill / auto-fit repeat(auto-fill, minmax(200px, 1fr)) تعداد ستون خودکار ۹
grid-auto-rows، grid-auto-columns minmax(100px, auto) اندازه ردیف/ستون‌های خودکار ۱۰
grid-auto-flow row، column، dense جهت پر شدن خانه‌ها ۱۰

جدول مرجع: ویژگی‌های آیتم (فرزند)

ویژگی نمونه کار درس
grid-column 1 / 3، span 2، 1 / -1 از کدام خط ستون تا کدام خط ۵
grid-row 1 / 3، span 2 از کدام خط ردیف تا کدام خط ۵
grid-area main اسم آیتم برای نقشه ۶
justify-self، align-self، place-self end تراز فقط همین آیتم ۷

مثال ۱: «حدس بزنید» — این آیتم کجا می‌نشیند؟

قبل از نگاه کردن به نتیجه، روی کاغذ یک شبکه ۴×۳ بکشید و جای آیتم ۱ را حدس بزنید:

.quiz-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 50px;
  gap: 6px;
}

.guess {
  grid-column: 2 / 4;   /* ستون ۲ و ۳ */
  grid-row: 1 / 3;      /* ردیف ۱ و ۲ */
}

آیتم ۱ ستون‌های ۲ و ۳ (وسط شبکه) و ردیف‌های ۱ و ۲ را گرفته؛ ستون ۱ (راست) و ستون ۴ (چپ) برای بقیه آیتم‌ها مانده و آن‌ها خودشان دورش پر شده‌اند.

مثال ۲: صفحه کامل یک فروشگاه کوچک

نقشه صفحه با grid-template-areas و کارت‌های محصول داخل محتوا با auto-fill:

.store {
  display: grid;
  grid-template-columns: 160px 1fr;
  grid-template-areas:
    "header  header"
    "filters products"
    "footer  footer";
  gap: 8px;
}

.products {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(120px, 1fr));
  gap: 8px;
}

.badge-grid {

  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 100px;
  gap: 8px;
  place-items: center;

اشتباه رایج: ترکیب auto-fill با آیتمی که grid-column: span 2 دارد. در گوشی که فقط یک ستون جا می‌شود، مرورگر به‌خاطر آن آیتم یک ستون اضافه می‌سازد و صفحه افقی اسکرول می‌خورد. راه ساده: در media query موبایل، span را به auto برگردانید (grid-column: auto;).

تمرین‌ها (از ساده به سخت)

تمرین ۱ ⭐: منوی نوشیدنی‌های یک کافه با ۹ آیتم را در یک شبکه سه‌ستونه با فاصله ۱۲ پیکسل بچینید. هر آیتم اسم و قیمت داشته باشد.

تمرین ۲ ⭐: جدول «برنامه هفتگی کلاس‌ها»: یک ستون ۸۰ پیکسلی برای ساعت و ۵ ستون مساوی برای روزها (با repeat). ردیف عنوان روزها تمام‌رنگی باشد.

تمرین ۳ ⭐⭐: صفحه «محصولات فروشگاه» با بنر تمام‌عرض (1 / -1)، یک محصول ویژه ۲×۲ و ۸ محصول معمولی در شبکه ۴ ستونه با grid-auto-rows: 120px.

تمرین ۴ ⭐⭐: گالری عکس سفر با repeat(auto-fill, minmax(180px, 1fr)). هر کارت عکس، اسم شهر و تاریخ سفر داشته باشد و با Flexbox دکمه «جزئیات» ته کارت بنشیند.

تمرین ۵ ⭐⭐⭐: اسکلت کامل سایت یک آموزشگاه با grid-template-areas: سربرگ، منو، محتوا، ستون کناری و پانویس. داخل محتوا یک فرم ثبت‌نام دوستونه (برچسب/فیلد) باشد. در عرض کمتر از ۷۰۰ پیکسل همه بخش‌ها و فرم یک‌ستونه شوند (فقط یک media query).

تمرین ۶ ⭐⭐⭐: داشبورد مدیریت یک کافه: ۴ کارت آمار، نمودار فروش (۳ ستون)، لیست سفارش‌ها (۱ ستون و ۲ ردیف) و جدول موجودی انبار (تمام‌عرض). در موبایل کارت‌های آمار دوتایی و بقیه بخش‌ها تمام‌عرض شوند.
