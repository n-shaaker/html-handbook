۱۰) شبکه ضمنی (grid-auto)

ستون‌ها و ردیف‌هایی که خودمان با grid-template-... می‌نویسیم شبکه صریح (explicit) هستند. اگر آیتم‌ها از خانه‌های این شبکه بیشتر باشند، مرورگر خودش ردیف (یا ستون) تازه می‌سازد. به این ردیف‌های خودکار شبکه ضمنی (implicit) می‌گوییم. در این درس یاد می‌گیریم اندازه و جهت آن‌ها را کنترل کنیم.

مثال ۱: ردیف اضافه‌ای که خودمان ننوشتیم

فقط دو ردیف ۷۰ پیکسلی نوشته‌ایم، ولی ۸ آیتم داریم. ردیف سوم خودکار ساخته شده و ارتفاعش فقط به اندازه متن است:

.explicit {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 70px 70px;   /* فقط دو ردیف */
  gap: 8px;
}

اشتباه رایج: برای لیست محصولاتی که تعدادش از دیتابیس می‌آید، grid-template-rows می‌نویسیم. وقتی محصول‌ها زیاد شوند، ردیف‌های جدید ارتفاع ما را نمی‌گیرند (مثل آیتم ۷ و ۸). وقتی تعداد ردیف را نمی‌دانید از grid-auto-rows استفاده کنید.

مثال ۲: grid-auto-rows — اندازه همه ردیف‌های خودکار

.auto-rows {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 70px;   /* هر ردیفی که ساخته شود */
  gap: 8px;
}

بهتر از عدد ثابت، grid-auto-rows: minmax(70px, auto); است: حداقل ۷۰ پیکسل، ولی اگر متن کارت زیاد شد بلندتر می‌شود.

مثال ۳: grid-auto-flow: column — پر کردن ستونی

حالت پیش‌فرض row است: آیتم‌ها ردیف به ردیف پر می‌شوند. با column ستون به ستون پر می‌شوند و ستون‌های تازه ساخته می‌شوند؛ اندازه آن ستون‌ها را grid-auto-columns تعیین می‌کند: 

.flow-column {
  display: grid;
  grid-template-rows: repeat(2, 60px);   /* دو ردیف */
  grid-auto-flow: column;                /* ستونی پر شود */
  grid-auto-columns: 100px;              /* هر ستون تازه ۱۰۰ پیکسل */
  gap: 8px;
}

مثال ۴: سوراخ‌های شبکه و grid-auto-flow: dense

وقتی بعضی آیتم‌ها دو ستون می‌گیرند و در ادامه ردیف جا نمی‌شوند، به ردیف بعد می‌روند و یک خانه خالی (سوراخ) جا می‌گذارند. با dense مرورگر آیتم‌های کوچک بعدی را برمی‌گرداند تا سوراخ‌ها را پر کند: 

.wide { grid-column: span 2; }

.holes { grid-auto-flow: row; }     /* پیش‌فرض */
.dense { grid-auto-flow: dense; }   /* پر کردن سوراخ‌ها */

اشتباه رایج: استفاده از dense برای محتوایی که ترتیبش مهم است (مثل مراحل ثبت‌نام یا اخبار به ترتیب تاریخ). dense ترتیب دیداری را به‌هم می‌زند؛ فقط برای چیزهایی مثل گالری عکس که ترتیب مهم نیست مناسب است.

ویژگی کار
grid-auto-rows ارتفاع ردیف‌هایی که خودکار ساخته می‌شوند
grid-auto-columns پهنای ستون‌هایی که خودکار ساخته می‌شوند
grid-auto-flow: row پر کردن ردیف به ردیف (پیش‌فرض)
grid-auto-flow: column پر کردن ستون به ستون
grid-auto-flow: dense پر کردن خانه‌های خالی با آیتم‌های بعدی

تمرین: یک «دیوار عکس» برای صفحه اینستاگرام یک کافه بسازید: ۴ ستون، grid-auto-rows: 120px، ۱۲ عکس که سه‌تایشان span 2 ستون هستند. یک بار بدون dense و یک بار با آن نگاه کنید و تعداد خانه‌های خالی را بشمارید.
