۶) نام‌گذاری ناحیه‌ها (template-areas)

حساب کردن شماره خط‌ها برای چیدمان کل صفحه کمی سخت است. Grid راه خیلی خواناتری هم دارد: نقشه صفحه را با اسم می‌کشیم! دو قدم دارد:

  1. روی هر آیتم با grid-area یک اسم می‌گذاریم (مثلاً header).
  2. روی پدر با grid-template-areas نقشه را می‌نویسیم: هر جفت گیومه "..." یک ردیف است و هر اسم یک خانه.

مثال ۱: اسکلت کلاسیک سایت — سربرگ، ستون کناری، محتوا، پانویس

.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 8px;
}

.page-top    { grid-area: header; }
.page-side   { grid-area: sidebar; }
.page-main   { grid-area: main; }
.page-bottom { grid-area: footer; }
۱. سربرگ: کافه نارنج
۲. ستون کناری: ساعت کاری
۳. محتوا: منوی امروز و معرفی کافه
۴. پانویس: نشانی و تلفن

نقشه دقیقاً شبیه شکل نهایی است: header دو بار نوشته شده چون دو ستون را می‌گیرد. در صفحه راست‌چین، اولین اسم هر ردیف (sidebar) سمت راست می‌نشیند.

اسم‌ها دلخواه‌اند و ربطی به تگ‌های header یا main ندارند؛ فقط باید در grid-area و نقشه یکسان باشند. در grid-area اسم را بدون گیومه می‌نویسیم.

مثال ۲: جابه‌جا کردن ستون کناری فقط با عوض کردن نقشه

بدون دست زدن به HTML، ستون کناری را به سمت چپ می‌بریم. فقط ترتیب اسم‌ها و ستون‌ها عوض شده:

.page-left {
  grid-template-columns: 1fr 200px;
  grid-template-areas:
    "header header"
    "main   sidebar"
    "footer footer";
}
۱. سربرگ
۲. ستون کناری (حالا چپ)
۳. محتوا
۴. پانویس

مثال ۳: سه ستون — منو، محتوا و تبلیغ

.shop-page {
  display: grid;
  grid-template-columns: 150px 1fr 150px;
  grid-template-areas:
    "header header header"
    "menu   main   ads"
    "footer footer footer";
  gap: 8px;
}
۱. سربرگ فروشگاه
۲. منو
۳. محصولات
۴. تبلیغ
۵. پانویس

مثال ۴: خانه خالی با نقطه (.)

اگر خانه‌ای قرار نیست چیزی داشته باشد، جایش یک نقطه بگذارید:

.with-empty {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-areas:
    "logo  .     login"
    "main  main  main";
  gap: 8px;
}
۱. لوگو
۲. ورود
۳. محتوا

مثال ۵: ارتفاع ردیف‌ها کنار نقشه

grid-template-areas فقط جای ناحیه‌ها را می‌گوید؛ ارتفاع ردیف‌ها را مثل قبل با grid-template-rows بدهید. اینجا ردیف وسط بقیه جا را می‌گیرد و سربرگ و پانویس به اندازه محتوایشان هستند: 

.tall-page {
  height: 300px;
  grid-template-rows: auto 1fr auto;
}
۱. سربرگ (auto)
۲. ستون کناری
۳. محتوا (1fr = بقیه ارتفاع)
۴. پانویس (auto)

اشتباه رایج: کشیدن ناحیه‌ای که مستطیل نیست، مثل شکل L در نقشهٔ زیر. 

/* اشتباه: main شکل L ساخته */
grid-template-areas:
  "main main"
  "main side";

هر ناحیه باید یک مستطیل کامل باشد. اگر نباشد، مرورگر کل grid-template-areas را نادیده می‌گیرد و آیتم‌ها به ترتیب عادی می‌نشینند.

اشتباه رایج: تعداد اسم‌ها در ردیف‌ها برابر نیست؛ مثلاً ردیف اول ۲ اسم و ردیف دوم ۳ اسم دارد. همه ردیف‌ها باید به تعداد ستون‌ها اسم داشته باشند (برای خانه خالی از . استفاده کنید). غلط املایی در اسم‌ها هم (مثلاً sidbar) همین‌قدر دردسر دارد.

ویژگی روی کار
grid-area: main; آیتم اسم گذاشتن روی آیتم
grid-template-areas پدر کشیدن نقشه؛ هر "..." یک ردیف
. داخل نقشه خانه خالی

تمرین: اسکلت صفحه یک «آموزشگاه زبان» را با grid-template-areas بسازید: سربرگ تمام‌عرض، منوی دوره‌ها سمت راست، محتوا وسط، بخش «اخبار» سمت چپ و پانویس تمام‌عرض. بعد فقط با تغییر نقشه، بخش اخبار را زیر محتوا ببرید.
