۵) جای‌گذاری آیتم‌ها با شماره خط

تا اینجا آیتم‌ها خودشان به ترتیب در خانه‌ها می‌نشستند. حالا می‌خواهیم به یک آیتم بگوییم «از کدام خط شروع کن و تا کدام خط برو». این ویژگی‌ها روی خود آیتم (فرزند) نوشته می‌شوند، نه روی پدر.

یادآوری از درس ۱: یک شبکه ۴ ستونه ۵ خط عمودی دارد. در صفحه راست‌چین خط ۱ لبه راست است و خط ۵ لبه چپ. همه شبکه‌های این درس این‌طورند: 

.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 8px;
}

مثال ۱: grid-column: شروع / پایان

آیتم ۱ از خط ۱ تا خط ۳ می‌رود؛ یعنی دو ستون را می‌گیرد (ستون ۱ و ۲):

.item-1 {
  grid-column: 1 / 3;   /* از خط ۱ تا خط ۳ */
}

grid-column خلاصه دو ویژگی است: grid-column-start: 1; و grid-column-end: 3;. علامت / فقط این دو عدد را از هم جدا می‌کند و تقسیم نیست.

اشتباه رایج: فکر می‌کنیم grid-column: 1 / 3 یعنی «سه ستون». عددها شماره خط هستند، نه شماره ستون! از خط ۱ تا خط ۳ فقط دو ستون است. برای سه ستون باید بنویسید 1 / 4 (یا span 3).

مثال ۲: span — «این‌قدر ستون بگیر»

اگر حساب شماره خط سخت است، با span فقط بگویید چند ستون یا ردیف بگیرد. آیتم از همان جایی که بود شروع می‌کند:

.item-2 { grid-column: span 2; }   /* دو ستون */
.item-5 { grid-row: span 2; }      /* دو ردیف */

مثال ۳: -1 یعنی «آخرین خط»

خط‌ها از آخر هم شماره دارند: -1 همیشه آخرین خط است (در راست‌چین یعنی لبه چپ). 1 / -1 یعنی «تمام عرض»، هر چند ستون که شبکه داشته باشد. برای بنر تخفیف فروشگاه عالی است: 

.banner {
  grid-column: 1 / -1;   /* از اولین خط تا آخرین خط */
}
۱. بنر: حراج پاییزه فروشگاه — ۳۰٪ تخفیف (1 / -1)

مثال ۴: grid-row — ستون کناری بلند

با grid-row همین کار را برای ردیف‌ها می‌کنیم. آیتم ۱ در ستون ۱ (راست) است و از خط ردیف ۱ تا ۴ (سه ردیف) پایین می‌رود:

.side {
  grid-column: 1;      /* فقط ستون اول */
  grid-row: 1 / 4;     /* سه ردیف */
}

مثال ۵: فرستادن یک آیتم به خانه دلخواه

آیتم ۶ در HTML آخر است، ولی می‌خواهیم «پیشنهاد امروز» کافه در گوشه بالا-چپ (ستون ۴، ردیف ۱) دیده شود. بقیه آیتم‌ها خودشان کنار می‌روند:

۶. پیشنهاد امروز ⭐

جابه‌جایی با CSS فقط ظاهر را عوض می‌کند. صفحه‌خوان‌ها و کلید Tab هنوز به ترتیب HTML حرکت می‌کنند؛ پس ترتیب مهم محتوا را در خود HTML درست بنویسید.

کد معنی
grid-column: 2 / 4 از خط ۲ تا خط ۴ (دو ستون)
grid-column: span 3 سه ستون، از جای فعلی
grid-column: 1 / -1 تمام عرض
grid-row: 1 / 3 از خط ردیف ۱ تا ۳ (دو ردیف)
grid-column: 3 فقط در ستون ۳ (یک ستون)

اشتباه رایج: در صفحه راست‌چین انتظار داریم grid-column: 1 آیتم را سمت چپ ببرد (چون در آموزش‌های انگلیسی این‌طور دیده‌ایم). در dir="rtl" خط ۱ سمت راست است.

تمرین: صفحه اول یک فروشگاه را با شبکه ۴ ستونه بسازید: یک بنر تمام‌عرض در ردیف اول، یک محصول «ویژه» که ۲ ستون و ۲ ردیف بگیرد و ۶ محصول معمولی. فقط با grid-column و grid-row (یک‌بار با شماره خط و یک‌بار با span).
