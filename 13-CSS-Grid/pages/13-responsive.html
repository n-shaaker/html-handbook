۱۳) Grid واکنش‌گرا

بزرگ‌ترین هدیه Grid برای طراحی واکنش‌گرا این است که کل چیدمان صفحه با عوض کردن یکی دو خط تغییر می‌کند. HTML دست نمی‌خورد؛ فقط در یک media query نقشه شبکه را عوض می‌کنیم.

همه مثال‌های این صفحه با یک media query کار می‌کنند: @media (max-width: 700px). پنجره مرورگر را باریک‌تر از ۷۰۰ پیکسل کنید (یا در DevTools حالت موبایل را بزنید) تا تغییرها را ببینید. فراموش نکنید که تگ <meta name="viewport" ...> در head باشد، وگرنه گوشی صفحه را کوچک‌شده نشان می‌دهد و media query درست کار نمی‌کند.

مثال ۱: اسکلت سایت — در موبایل همه زیر هم

در دسکتاپ سه ستون؛ در موبایل فقط نقشه و ستون‌ها عوض می‌شوند و همه بخش‌ها زیر هم می‌آیند:

.site {
  display: grid;
  grid-template-columns: 180px 1fr 180px;
  grid-template-areas:
    "header header header"
    "menu   main   ads"
    "footer footer footer";
  gap: 8px;
}

@media (max-width: 700px) {
  .site {
    grid-template-columns: 1fr;   /* فقط یک ستون */
    grid-template-areas:
      "header"
      "main"
      "menu"
      "ads"
      "footer";
  }
}

دقت کنید: در موبایل «محتوا» قبل از «منو» آمده تا کاربر گوشی اول مطلب اصلی را ببیند. این جابه‌جایی را فقط با ترتیب اسم‌ها در نقشه انجام دادیم.

مثال ۲: ردیف کارت‌ها — ۴ ستون در دسکتاپ، ۲ ستون در موبایل

.features {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 8px;
}

/* داخل همان media query بالا */
.features { grid-template-columns: repeat(2, 1fr); }

مثال ۳: گالری بدون media query (یادآوری درس ۹)

اگر تنها چیزی که باید با عرض صفحه عوض شود تعداد ستون‌هاست، media query لازم نیست. repeat(auto-fill, minmax(150px, 1fr)) خودش می‌شمارد چند ستونِ دست‌کم ۱۵۰ پیکسلی در عرض فعلی جا می‌شود و بقیهٔ فضا را بین همان ستون‌ها تقسیم می‌کند. با باریک شدن پنجره، تعداد ستون‌ها کم می‌شود بدون اینکه HTML یا یک شرط جدا عوض شود. 

.trips {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
  gap: 8px;
}

۲. قهوه‌ساز دستی فرانسه

ظرفیت ۴ فنجان، بدنه شیشه‌ای و فیلتر استیل. مناسب برای خانه و کافه‌های کوچک.

قیمت: ۸۹۰ هزار تومان

اشتباه رایج: در media query فقط grid-template-areas را یک‌ستونه می‌کنیم و grid-template-columns را فراموش می‌کنیم. شبکه هنوز سه ستون 180px 1fr 180px دارد؛ همه ناحیه‌ها در ستون اول (۱۸۰ پیکسل) فشرده می‌شوند و بقیه عرض خالی می‌ماند. هر دو را با هم عوض کنید.

اشتباه رایج: برای هر عرض یک media query جدا می‌نویسیم (۳۲۰، ۳۷۵، ۴۱۴، ۷۶۸، ...). معمولاً یک نقطه شکست کافی است، و برای کارت‌ها auto-fill و minmax کار را بدون media query انجام می‌دهند.

تمرین: صفحه «منوی کافه» با سه ناحیه بسازید: دسته‌بندی‌ها (راست)، لیست غذاها (وسط) و سبد سفارش (چپ). در عرض کمتر از ۷۰۰ پیکسل ترتیب این باشد: سبد سفارش بالا، بعد لیست غذاها و دسته‌بندی‌ها پایین. فقط یک media query مجاز است.
