۱۲) الگوهای پرکاربرد

در این درس چیز تازه‌ای یاد نمی‌گیریم؛ همان ویژگی‌های درس‌های قبل را کنار هم می‌گذاریم تا پنج چیدمانی را بسازیم که تقریباً در هر سایتی پیدا می‌شوند. هر کدام را می‌توانید مستقیم در پروژه‌تان کپی و کمی تغییر دهید.

مثال ۱: چیدمان کلاسیک صفحه (وبلاگ سفر)

سربرگ و منو بالا، محتوا و ستون کناری کنار هم، پانویس پایین. ستون کناری با minmax نه خیلی باریک می‌شود و نه خیلی پهن:

.blog {
  display: grid;
  grid-template-columns: 1fr minmax(160px, 220px);
  grid-template-areas:
    "header header"
    "nav    nav"
    "main   aside"
    "footer footer";
  gap: 8px;
}

مثال ۲: گالری عکس سفر با یک عکس بزرگ (۲×۲)

عکس اول «عکس منتخب» است و دو ستون و دو ردیف می‌گیرد. بقیه خودشان دورش جا می‌شوند:

.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 90px;
  gap: 8px;
}

.gallery .featured {
  grid-column: span 2;
  grid-row: span 2;
}

مثال ۳: داشبورد فروشگاه

چهار کارت آمار در ردیف اول، نمودار فروش سه ستون و لیست سفارش‌ها یک ستون از ردیف دوم:

.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
}

.dashboard .chart  { grid-column: span 3; }
.dashboard .orders { grid-column: span 1; }

مثال ۴: فرم با برچسب و فیلد در دو ستون

برچسب‌ها در ستون راست به اندازه ثابت و فیلدها در ستون چپ. چون هر label و هر input یک آیتم است، خودشان به ترتیب در دو ستون می‌نشینند. دکمه را با grid-column: 2 زیر فیلدها می‌بریم: 

.signup {
  display: grid;
  grid-template-columns: 120px 1fr;
  gap: 10px;
  align-items: center;   /* برچسب‌ها وسط ارتفاع فیلد */
}

.signup button {
  grid-column: 2;
  justify-self: start;   /* دکمه تمام‌عرض نشود */
}

مثال ۵: وسط کردن با place-items

برای صفحه «سبد خرید خالی است» یا «در حال بارگذاری»، ساده‌ترین روش وسط‌چینی در هر دو جهت:

.empty-cart {
  display: grid;
  place-items: center;
  min-height: 180px;
}
🛒 سبد خرید شما خالی است

اشتباه رایج: در گالری مثال ۲ عکس بزرگ را span 2 می‌کنیم ولی ردیف‌ها ارتفاع ندارند (grid-auto-rows ننوشته‌ایم). در این حالت ارتفاع ردیف‌ها به اندازه متن است و عکس «۲ ردیفی» تقریباً هم‌قد بقیه می‌شود. برای گالری همیشه grid-auto-rows بدهید.

اشتباه رایج: در فرم دوستونه هر label و input را داخل یک div می‌گذاریم. آن وقت هر div یک آیتم می‌شود و برچسب و فیلد دیگر در دو ستون شبکه نیستند. برای این الگو، برچسب و فیلد باید فرزند مستقیم فرم باشند.

تمرین: صفحه «پنل مدیریت آموزشگاه» بسازید: سربرگ، منوی کناری و محتوا با grid-template-areas؛ داخل محتوا ۳ کارت آمار (تعداد هنرجو، دوره فعال، کلاس امروز) و زیر آن یک فرم دوستونه «افزودن هنرجو».
