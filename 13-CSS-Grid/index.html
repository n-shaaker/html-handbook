آموزش CSS Grid — چیدمان شبکه‌ای

مثال به مثال، از اولین شبکه ساده تا چیدمان کامل یک سایت واکنش‌گرا

پیش‌نیاز: قبل از شروع این دوره، درس‌های دوره CSS سطح میانی (به‌خصوص display، مدل جعبه‌ای، واحدها و چیدمان سایت) را بخوانید. پیشنهاد می‌کنیم اول آموزش Flexbox را تمام کنید؛ بعضی ویژگی‌ها مثل gap، justify-content و align-items در هر دو مشترک‌اند و با دانستن Flexbox، Grid خیلی راحت‌تر جا می‌افتد. مثل دوره‌های قبل، ظاهر هر مثال از فایل‌های CSS خارجی می‌آید و از CSS داخلی و اینلاین استفاده نشده است.
