آموزش CSS — سطح میانی

ادامه دوره مقدماتی، مثال به مثال، از چیدمان پایه تا ساخت اسکلت یک سایت واقعی

پیش‌نیاز: قبل از شروع این دوره، درس‌های دوره مقدماتی CSS (رنگ، پس‌زمینه، حاشیه، مدل جعبه‌ای، متن، فونت، لینک، فهرست و جدول) را بخوانید. مثل دوره مقدماتی، ظاهر هر مثال از فایل‌های CSS خارجی می‌آید و از CSS داخلی و اینلاین استفاده نشده است.

فهرست درس‌ها
  1. نمایش (Display)
  2. حداکثر عرض (Max-width)
  3. موقعیت (Position)
  4. ترتیب لایه‌ها (Z-index)
  5. سرریز (Overflow)
  6. شناور کردن (Float و Clear)
  7. Inline-block
  8. وسط‌چین و تراز (Align)
  9. ترکیب‌کننده‌ها (Combinators)
  10. شبه‌کلاس‌ها (Pseudo-classes)
  11. شبه‌عنصرها (Pseudo-elements)
  12. شفافیت (Opacity)
  13. نوار منو (Navigation Bar)
  14. منوی کشویی (Dropdowns)
  15. انتخابگرهای ویژگی (Attribute Selectors)
  16. فرم‌ها (Forms)
  17. شمارنده‌ها (Counters)
  18. واحدها (Units)
  19. توابع ریاضی (Math Functions)
  20. چیدمان سایت (Website Layout)
  21. تمرین جمع‌بندی

مباحث «اولویت قوانین (Specificity)» و «!important» در مجموعه آبشاری بودن CSS و مبحث «گالری تصاویر» در مجموعه تصاویر در CSS آمده‌اند.

بعد از این دوره: چیدمان صفحه را مفصل در آموزش Flexbox و آموزش CSS Grid یاد می‌گیرید.
