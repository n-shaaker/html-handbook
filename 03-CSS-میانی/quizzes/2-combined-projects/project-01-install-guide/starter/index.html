راهنمای نصب VS Code در ویندوز

این راهنما برای هنرجویان ترم اول است. نصب کامل حدود ده دقیقه طول می‌کشد.

  1. دانلود فایل نصب

    فایل نصب را از سایت رسمی ویرایشگر دانلود کنید.

    به سایت رسمی VS Code بروید و روی دکمه آبی «Download for Windows» کلیک کنید.

    اگر نمی‌دانید ویندوزتان ۳۲ یا ۶۴ بیتی است، کلیدهای Win + Pause را بزنید.

  2. اجرای فایل نصب

    فایل دانلودشده را اجرا کنید و این مراحل را بروید:

    1. قوانین استفاده را بخوانید و گزینه «I accept» را انتخاب کنید.
    2. مسیر نصب را تغییر ندهید و «Next» بزنید.
    3. تیک گزینه «Add to PATH» را حتماً بزنید.

    اگر تیک «Add to PATH» را نزنید، بعداً از ترمینال نمی‌توانید ویرایشگر را باز کنید.

  3. اولین اجرا

    ویرایشگر را باز کنید و ظاهرش را تنظیم کنید.

    1. از صفحه خوش‌آمد، یک پوسته (Theme) روشن یا تیره انتخاب کنید.
    2. با Ctrl + + اندازه متن را بزرگ‌تر کنید.

  4. نصب افزونه Live Server

    این افزونه صفحه شما را با هر بار ذخیره، خودکار در مرورگر تازه می‌کند.

    با Ctrl + Shift + X بخش افزونه‌ها را باز کنید، «Live Server» را جستجو و نصب کنید.

    بعد از نصب، روی فایل HTML راست‌کلیک کنید و «Open with Live Server» را بزنید.

اگر در هر قدم به مشکل خوردید، از قسمت پشتیبانی سایت آموزشگاه پیام بدهید.
