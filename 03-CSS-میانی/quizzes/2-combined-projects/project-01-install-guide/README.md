## صورت مسئله

پشتیبانی یک آموزشگاه برنامه‌نویسی هر ترم ده‌ها بار به هنرجوها توضیح می‌دهد چطور ویرایشگر VS Code را نصب کنند. مدیر آموزشگاه یک صفحه راهنما نوشته (`starter/index.html`) ولی صفحه فعلاً هیچ CSS ندارد و خواندنش سخت است.
مدیر گفته: «شماره قدم‌ها را دستی ننویسید؛ هر ترم قدمی اضافه یا کم می‌کنیم و نمی‌خواهیم هر بار همه شماره‌ها را عوض کنیم.»

فایل `starter/index.html` را در پوشه کار خودتان کپی کنید و فقط فایل `style.css` را بنویسید.

## الزامات

1. محتوای صفحه حداکثر `45rem` عرض داشته باشد و وسط صفحه باشد؛ اندازه همه فونت‌ها با `rem` نوشته شود.
2. شماره‌های پیش‌فرض هر دو فهرست (`ol`) خاموش شود.
3. قبل از تیتر هر قدم (`h2` داخل `.steps > li`) با شمارنده و `::before` متن «قدم ۱»، «قدم ۲» و ... بیاید، داخل یک برچسب رنگی گرد.
4. زیرقدم‌ها (فهرست داخل یک قدم) به شکل «۲.۱»، «۲.۲» شماره بخورند (با `counters()` یا ترکیب دو شمارنده) و اعداد فارسی باشند.
5. هر قدم اصلی (فقط فرزند مستقیم `.steps`) یک خط رنگی سمت راست و فاصله داخلی داشته باشد؛ آخرین قدم با `:last-child` رنگ خط متفاوت (سبز، «پایان») بگیرد.
6. اولین پاراگراف بعد از تیتر هر قدم (`h2 + p`) کمی درشت‌تر و پررنگ‌تر باشد (خلاصه قدم).
7. پاراگراف‌های `.tip` با `::before` کلمه «نکته:» و پس‌زمینه زرد ملایم، و `.warning` کلمه «هشدار:» و پس‌زمینه قرمز ملایم بگیرند. `padding` این جعبه‌ها با `em` باشد.
8. کلیدهای کیبورد (`kbd`) مثل دکمه کوچک دیده شوند: حاشیه، گوشه گرد و `padding` با `em`.

## محدودیت‌ها

- به HTML **هیچ کلاس، id یا تگ تازه‌ای** اضافه نکنید و هیچ عددی را دستی ننویسید.
- بدون Flexbox و Grid (لازم نیست).
- بدون JavaScript، بدون `style` درون‌خطی و بدون `!important`.

## امتیازی (تا ۲ نمره)

- لینک‌هایی که در تب جدید باز می‌شوند (`target="_blank"`) با انتخابگر ویژگی یک «↗» بگیرند.
- با `::selection` رنگ انتخاب متن را هم‌رنگ برچسب قدم‌ها کنید.

## نکته استاد

- اگر همه قدم‌ها «قدم ۱» شدند، `counter-reset` را روی همان عنصری گذاشته‌اید که `counter-increment` دارد. ریست روی `ol`، افزایش روی `li`.
- برای اینکه زیرقدم‌ها با شمارنده قدم‌ها قاطی نشوند، از دو نام شمارنده جدا استفاده کنید یا انتخابگر را با `>` دقیق کنید.
- اول صفحه را بدون CSS ببینید و بشمارید چند نوع عنصر دارید؛ بعد برای هر نوع یک بخش با کامنت در CSS بسازید.
