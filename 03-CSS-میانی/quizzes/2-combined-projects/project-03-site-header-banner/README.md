## صورت مسئله

آژانس گردشگری «سفرینو» سایت تازه‌ای می‌خواهد. طراح فقط بالای صفحه اول را کشیده و از شما خواسته آن را با HTML و CSS بسازید:

- یک **سربرگ** تیره با لوگو و منوی «خانه، تورها ▾، هتل‌ها، وبلاگ، تماس». زیر «تورها» یک زیرمنو با «تورهای داخلی»، «تورهای خارجی»، «طبیعت‌گردی»، «تورهای یک‌روزه».
- زیر سربرگ یک **بنر** بزرگ با عکس طبیعت (`images/bg.jpg` همین دوره)، یک لایه تیره روی عکس، تیتر «سفر بعدی‌ات را همین‌جا پیدا کن»، یک جمله و دکمه «مشاهده تورها».
- در گوشه بالا-چپ بنر یک **نشان** «۲۰٪ تخفیف تورهای بهاری».
- زیر بنر چند پاراگراف محتوا تا صفحه اسکرول بخورد.

مدیر آژانس گفته: «زیرمنو هیچ‌وقت نباید زیر بنر یا نشان تخفیف برود، و منو هنگام اسکرول بالای صفحه بماند.»

یک `index.html` و یک `style.css` بسازید.

## الزامات

1. سربرگ معنایی: `header` شامل لوگو (لینک) و `nav` با `aria-label`؛ آیتم‌ها در `ul`/`li`. منو افقی (Flexbox ساده مثل درس ۱۳ یا `inline-block`).
2. سربرگ با `position: sticky`، `top: 0` و `z-index` بالا (مثلاً `100`).
3. زیرمنو در حالت عادی `display: none`؛ با `:hover` **و** `:focus-within` روی آیتم «تورها» باز شود، با `position: absolute` درست زیر آیتم و هم‌تراز با لبه راست آن.
4. بنر `position: relative` و `min-height: 420px` داشته باشد و عکس با `background-image`، `background-size: cover` و `background-position: center` بیاید.
5. لایه تیره بنر با `::before` ساخته شود (`content: ""`، `position: absolute` روی کل بنر، `background-color` با `rgba`) — **بدون** `div` اضافه.
6. متن بنر روی لایه تیره باشد (`position: relative` و `z-index` بالاتر از `::before`) و افقی وسط‌چین.
7. نشان تخفیف `position: absolute` در گوشه بالا-چپ بنر، روی لایه تیره.
8. دکمه «مشاهده تورها» با `:hover` کمی شفاف شود (`opacity: 0.85`) و `:focus-visible` واضح داشته باشد.

## محدودیت‌ها

- بدون JavaScript، بدون `style` درون‌خطی و بدون `!important`.
- لایه تیره فقط با شبه‌عنصر؛ برای پس‌زمینه نیمه‌شفاف از `opacity` روی جعبه متن استفاده نکنید (متن کم‌رنگ می‌شود؛ مبحث ۱۲).
- `z-index`ها عددهای مرتب و کم باشند (مثلاً ۱، ۲، ۱۰، ۱۰۰)، نه ۹۹۹۹.
- ارتفاع ثابت (`height`) به سربرگ ندهید.

## امتیازی (تا ۲ نمره)

- یک `::after` زیر لینک فعال منو (خط کوتاه رنگی) به جای تغییر رنگ پس‌زمینه.
- تیتر بنر با `clamp()` واکنش‌گرا شود.

## نکته استاد

- چهار لایه دارید: عکس پس‌زمینه بنر، `::before` تیره، متن و نشان، و بالاتر از همه سربرگ و زیرمنو. قبل از کد، این ترتیب را روی کاغذ بنویسید.
- اگر متن بنر زیر لایه تیره رفت، یادتان باشد `z-index` بدون `position` کار نمی‌کند.
- زیرمنو را با Tab امتحان کنید، نه فقط با ماوس.
