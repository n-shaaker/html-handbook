اطلاعیه: ثبت‌نام دوره‌های ترم پاییز تا پایان مهر ادامه دارد.

برنامه‌نویسی را قدم‌به‌قدم یاد بگیرید

در کدآموز، هر دوره با پروژه واقعی تمام می‌شود. از ساختن اولین صفحه HTML شروع می‌کنید و در پایان، یک سایت کامل و واکنش‌گرا تحویل می‌دهید.

چرا کدآموز؟

کلاس‌ها کم‌جمعیت هستند تا مدرس فرصت کند کد هر هنرجو را ببیند. تمرین‌ها هر هفته بازبینی می‌شوند و اشکال‌ها در جلسه بعد با هم رفع می‌شوند.

بعد از پایان دوره هم تا سه ماه می‌توانید سؤال‌هایتان را در گروه پشتیبانی بپرسید.

مسیر پیشنهادی

اگر تازه شروع کرده‌اید، اول HTML و CSS مقدماتی، بعد CSS میانی و در آخر JavaScript را بگذرانید. این ترتیب کمک می‌کند هر مبحث روی پایه محکمی بنشیند.

برای کسانی که قبلاً کمی کدنویسی کرده‌اند، جلسه تعیین سطح رایگان داریم.

ساعت کار دفتر

شنبه تا چهارشنبه از ساعت ۹ تا ۱۸ و پنجشنبه‌ها از ۹ تا ۱۳ پاسخ‌گوی شما هستیم.

برای مشاوره حضوری لطفاً از قبل وقت بگیرید تا زمان انتظار نداشته باشید.
