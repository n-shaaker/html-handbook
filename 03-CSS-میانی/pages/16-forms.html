۱۶) فرم‌ها (Forms)

کنترل‌های فرم در HTML کار جمع‌آوری داده را انجام می‌دهند و ظاهر پیش‌فرضشان را خود مرورگر می‌سازد: کادر کوچک، فونت سیستم، و حاشیه ساده. CSS اندازه، فاصله داخلی، رنگ حاشیه و حالت فوکوس را عوض می‌کند تا پر کردن فرم روشن‌تر شود. برای جدا کردن انواع input از انتخابگر ویژگی درس ۱۵ استفاده می‌کنیم، چون نام تگ همه آن‌ها input است و تفاوتشان در ویژگی type است. بسیاری از کنترل‌های فرم، فونت عنصر والد را به ارث نمی‌برند. برای همین font-family: inherit قلم داخل کادر را با قلم بقیه صفحه یکی می‌کند. اگر به کادر width: 100% و padding بدهید، در حالت پیش‌فرض content-box عرض از پدر بیرون می‌زند. box-sizing: border-box padding و border را داخل همان صددرصد نگه می‌دارد.

عنصرهای فرم فونت صفحه را به ارث نمی‌برند؛ برای همین در همه مثال‌ها font-family: inherit گذاشته‌ایم تا متن داخل کادرها هم با فونت سایت (اینجا Tahoma) نمایش داده شود.

مثال ۱: کادر متن تمام‌عرض

input[type="text"] {
  width: 100%;
  padding: 12px 16px;
  margin: 8px 0;
  box-sizing: border-box;   /* padding از عرض بیرون نزند */
  font-family: inherit;
}

مثال ۲: سبک‌های مختلف حاشیه

.f-border  { border: 2px solid #1a5fb4; border-radius: 4px; }
.f-bottom  { border: none; border-bottom: 2px solid #e8590c; }
.f-filled  { border: none; background-color: #3f51b5; color: white; }

مثال ۳: حالت focus

کاربر باید همیشه ببیند الان در کدام کادر تایپ می‌کند. اگر outline پیش‌فرض را برمی‌دارید، حتماً یک نشانه واضح جایگزین بگذارید:

input:focus {
  outline: none;                                   /* فقط چون جایگزین داریم */
  border-color: #0b6e4f;
  box-shadow: 0 0 0 3px rgba(11, 110, 79, 0.35);   /* حلقه سبز واضح */
}

مثال ۴: کادر جستجو با آیکون

در صفحه راست‌چین متن از راست شروع می‌شود؛ پس آیکون را سمت راست می‌گذاریم و همان سمت padding اضافه می‌دهیم:

.search {
  background-image: url("search-icon.svg");  /* در این صفحه، آیکون به شکل SVG داخل خود CSS نوشته شده */
  background-position: right 14px center;
  background-repeat: no-repeat;
  padding-right: 42px;   /* جا برای آیکون */
  border-radius: 20px;
}

مثال ۵: textarea و select

textarea {
  height: 120px;
  resize: vertical;   /* کاربر فقط بتواند ارتفاع را تغییر دهد، نه عرض را */
}

select {
  padding: 10px;
  border-radius: 4px;
}

مثال ۶: دکمه‌ها

.submit {
  background-color: #0b6e4f;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 4px;
  font-family: inherit;
  cursor: pointer;    /* نشانگر دست */
}

.submit:hover { background-color: #08533b; }

مثال ۷: یک فرم کامل ثبت‌نام

هر کادر یک label دارد که با for به id کادر وصل شده؛ با کلیک روی برچسب، کادر فعال می‌شود و صفحه‌خوان‌ها هم می‌فهمند هر کادر برای چیست. کادرهایی که required دارند و اشتباه پر شده‌اند، بعد از تایپ کاربر با :user-invalid قرمز می‌شوند: 

.signup label {
  display: block;          /* برچسب بالای کادر، در خط جدا */
  font-size: 14px;
}

.signup input:user-invalid {
  border-color: #c92a2a;   /* فقط بعد از اینکه کاربر چیزی وارد کرد */
}

ساخت حساب کاربری

اشتباه رایج: دادن width: 100% و padding بدون box-sizing: border-box؛ کادر از فرم بیرون می‌زند.

اشتباه رایج: استفاده از placeholder به‌جای label. متن placeholder با شروع تایپ ناپدید می‌شود، رنگش معمولاً کم‌رنگ و کم‌خواناست و همه صفحه‌خوان‌ها آن را نمی‌خوانند. placeholder فقط برای «نمونه ورودی» است، نه نام کادر.

برای هم‌رنگ کردن چک‌باکس و رادیو با رنگ سایت، یک خط کافی است: accent-color: #0b6e4f;

تمرین: یک فرم «تماس با ما» بسازید با نام، ایمیل، موضوع (select)، پیام (textarea) و دکمه ارسال. همه کادرها label داشته باشند و حالت :focus واضح باشد.
