۲۱) Media Queries و واکنش‌گرایی

Media Query یعنی «اگر عرض صفحه (یا شرط دیگری) برقرار بود، این قوانین CSS را اعمال کن». با آن یک صفحه را برای موبایل و دسکتاپ هم‌زمان طراحی می‌کنید. بدون این، سایت روی گوشی کامل نیست. 

/* از عرض ۷۰۰ پیکسل به پایین */
@media (max-width: 700px) {
  .cards { grid-template-columns: 1fr; }
}

مثال ۱: تغییر ظاهر با عرض صفحه

@media (max-width: 700px) {
  .cards { grid-template-columns: 1fr; }
}
مفهومیعنی چه؟
@media (max-width: …)عرض viewport کمتر یا مساوی آن مقدار.
@media (min-width: …)عرض بیشتر یا مساوی (رویکرد mobile-first).
viewportمتا HTML ضروری: width=device-width, initial-scale=1.0

پیشنهاد: یک رویکرد را انتخاب کنید (موبایل‌اول با min-width یا دسکتاپ‌اول با max-width) و ثابت بمانید.

اشتباه رایج: CSS واکنش‌گرا بدون متا viewport.

تمرین: ردیف ۳ ستونه بسازید که زیر ۶۰۰px تک‌ستون شود و در DevTools موبایل چک کنید.
