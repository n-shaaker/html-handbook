۷) Inline-block

inline-block رفتار دو حالت قبلی را با هم ترکیب می‌کند. مثل inline، عنصر در همان خط کنار بقیه می‌نشیند و خط را نمی‌شکند. مثل block، width، height و padding هر چهار طرف روی آن اثر واقعی دارند و جعبه را بزرگ می‌کنند. این مقدار برای برچسب، دکمه و نشان مناسب است. برای ردیف کارت‌ها، Flexbox فاصله و هم‌قد کردن را ساده‌تر کنترل می‌کند.

مثال ۱: مقایسه سه حالت

.s {
  width: 100px;
  height: 50px;
  padding: 10px;
}

.a { display: inline; }        /* width و height اثر ندارد؛ padding بالا/پایین روی خط‌های دیگر می‌افتد */
.b { display: inline-block; }  /* کنار هم + اندازه دارد */
.c { display: block; }         /* اندازه دارد ولی خط جدید */

inline: متن جعبه جعبه ادامه متن

inline-block: متن جعبه جعبه ادامه متن

block: متن جعبه جعبه ادامه متن

مثال ۲: برچسب‌های مهارت (tag)

.tag {
  display: inline-block;
  padding: 4px 12px;
  margin: 4px;
  border-radius: 20px;
}
طراحی وب فتوشاپ تایپ سریع زبان انگلیسی کار تیمی

مثال ۳: دکمه‌های منو

.menu a {
  display: inline-block;
  padding: 10px 20px;
}
خانه آموزش‌ها وبلاگ تماس

مثال ۴: کارت‌های محصول کنار هم بدون float

.product {
  display: inline-block;
  width: 150px;
  vertical-align: top;   /* بالای کارت‌ها هم‌تراز شود */
}

اشتباه رایج: بین عنصرهای inline-block یک فاصله کوچک ناخواسته (حدود ۴ پیکسل) دیده می‌شود؛ این به‌خاطر فاصله (space/enter) بین تگ‌ها در HTML است، نه CSS. در مثال ۳، اگر دقت کنید، بین پس‌زمینه سبز لینک‌ها هنگام hover یک شکاف باریک هست. حذف فاصله‌ها از HTML کد را ناخوانا می‌کند؛ راه حل تمیز این است که پدر را display: flex کنید و فاصله را با gap بدهید.

اشتباه رایج: فراموش کردن vertical-align: top؛ عنصرهای inline-block به‌طور پیش‌فرض روی «خط پایه» متن تراز می‌شوند و اگر محتوای یکی بیشتر باشد، بقیه پایین می‌افتند.

inline-block برای برچسب، دکمه و نشان (badge) هنوز عالی است. ولی برای ردیف کارت‌ها و منوها امروزه Flexbox ساده‌تر است: فاصله ناخواسته ندارد، هم‌ترازی آسان است و کارت‌ها هم‌قد می‌شوند.

تمرین: سه کارت «سرویس» (طراحی، برنامه‌نویسی، پشتیبانی) با inline-block و عرض ۲۰۰ پیکسل کنار هم بسازید.
