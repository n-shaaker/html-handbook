۲۲) Transition پایه

transition تغییر یک ویژگی را نرم می‌کند. بدون آن ظاهر «پرش» دارد. 

.btn {
  background: #1a5fb4;
  transition: background-color 0.25s ease, transform 0.25s ease;
}
.btn:hover {
  background: #0b6e4f;
  transform: translateY(-2px);
}

مثال ۱: دکمه

مثال ۲: عرض و رنگ جعبه

بخشتوضیح
ویژگیcolor، opacity، transform یا با احتیاط all
مدت0.3s یا 300ms
timingease، linear، ease-in-out

برای عملکرد بهتر، transform و opacity را ترجیح دهید.

تمرین: لینکی با transition روی رنگ و border-bottom در ۰٫۲s بسازید.
