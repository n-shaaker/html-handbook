۲۴) Animation و keyframes

animation و @keyframes برای حرکت تکرارشونده یا ورود عنصرند. برای جونیور کم استفاده کنید؛ یک پالس روی CTA کافی است. 

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.08); }
}
.cta { animation: pulse 1.4s ease-in-out infinite; }
