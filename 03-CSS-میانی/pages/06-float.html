۶) شناور کردن (Float و Clear)

float عنصر را به سمت راست یا چپ فیزیکی هل می‌دهد و می‌گذارد متن دور آن بپیچد؛ مثل عکس کنار ستون روزنامه. مقدار right و left با جهت صفحه عوض نمی‌شود: در صفحه فارسی هم float: right تصویر را به لبه راست می‌برد. کاربرد مناسب امروزی float همین پیچیدن متن دور تصویر است. ساختن ستون و منو با float روش قدیمی است و در کدهای قدیمی دیده می‌شود؛ برای چیدمان تازه از Flexbox و Grid استفاده می‌کنیم. عنصر شناور از جریان عادی ارتفاع پدر خارج می‌شود. اگر همه فرزندان شناور باشند، ارتفاع پدر ممکن است صفر شود، مگر اینکه پدر با display: flow-root یا روش مشابه، شناورها را در بر بگیرد.

مثال ۱: عکس کنار متن

.news-img {
  float: right;        /* عکس برود سمت راست */
  width: 140px;
  margin-left: 12px;   /* فاصله عکس تا متن */
}

این یک متن خبری نمونه است. چون عکس float: right دارد، متن به‌جای اینکه زیر عکس برود، کنار آن قرار می‌گیرد و دورش می‌چرخد. وقتی متن از ارتفاع عکس بیشتر شود، خط‌های بعدی در کل عرض ادامه پیدا می‌کنند. این روش برای مقاله‌ها و وبلاگ‌ها بسیار رایج است. متن بیشتر برای دیدن چرخیدن خط‌ها دور تصویر و ادامه آن در پایین.

مثال ۲: جعبه‌های کنار هم — روش قدیمی (float) و روش امروزی (flex)

این روش را در کدهای قدیمی زیاد می‌بینید؛ برای همین باید بشناسیدش. پدر حتماً باید flow-root شود (مثال ۴):

.clearfix { display: flow-root; }  /* پدر جمع نشود */

.item {
  float: right;
  width: 30%;
  margin-left: 3%;   /* ۳ × (۳۰٪ + ۳٪) = ۹۹٪؛ اگر بیشتر از ۱۰۰٪ شود، ستون آخر به خط بعد می‌افتد */
}

مثال ۳: clear — دیگر کنار نیا!

اگر بخواهیم عنصری زیر عنصرهای شناور بیاید (نه کنارشان)، از clear استفاده می‌کنیم:

.with-clear {
  clear: both;   /* نه شناورِ راست کنارم باشد، نه شناورِ چپ */
}

مثال ۴: مشکل «پدر جمع‌شده» و راه حل

عنصر شناور از جریان عادی صفحه بیرون می‌رود؛ پس وقتی همه فرزندان شناور باشند، پدر آن‌ها را «نمی‌بیند»، ارتفاعش صفر می‌شود و حاشیه‌اش جمع می‌شود. راه حل امروزی:

.parent {
  display: flow-root;   /* یا: overflow: auto; */
}

در کدهای قدیمی به‌جای آن «clearfix» با شبه‌عنصر می‌بینید که همین کار را می‌کند: 

.parent::after { content: ""; display: block; clear: both; }

برای چیدمان ستونی، منو و ردیف کارت‌ها از Flexbox و Grid استفاده کنید؛ float فقط برای «عکس کنار متن» (مثل مقاله و خبر) هنوز بهترین گزینه است.

اشتباه رایج: فراموش کردن margin سمت متن؛ در صفحه راست‌چین، عکسی که float: right دارد باید margin-left بگیرد (و عکسی که float: left دارد، margin-right)، وگرنه متن به عکس می‌چسبد.

تمرین: یک پاراگراف درباره شهرتان بنویسید و یک عکس با float: left و فاصله مناسب کنارش بگذارید. سپس یک تیتر بعد از آن بگذارید که با clear حتماً زیر عکس بیاید.
