۸) وسط‌چین و تراز (Align)

وسط‌چین کردن در CSS یک دستور واحد نیست. اول باید مشخص کنید چه چیزی را وسط می‌کنید و در کدام جهت. text-align محتوای داخل جعبه را افقی تراز می‌کند؛ متن و عنصرهای inline. خود جعبه بلوکی را جابه‌جا نمی‌کند. margin با مقدار auto در چپ و راست، جعبه بلوکی را افقی وسط می‌آورد، به شرطی که عرض جعبه از عرض والد کمتر باشد و فضای خالی برای تقسیم بماند. وسط کردن عمودی در جریان عادی صفحه با همین دو ویژگی به دست نمی‌آید. برای یک خط کوتاه می‌توان ارتفاع خط را برابر ارتفاع جعبه گذاشت. برای وسط کردن در هر دو جهت، Flexbox، Grid یا ترکیب position و transform به کار می‌آید.

مثال ۱: وسط کردن متن — text-align

.title { text-align: center; }

این متن وسط‌چین است

مثال ۲: وسط کردن یک جعبه — margin: auto

margin: auto فضای خالی افقی را بین دو طرف جعبه تقسیم می‌کند. این فضا فقط وقتی وجود دارد که عرض جعبه از عرض والد کمتر باشد. عنصر بلوکی بدون width یا max-width از قبل همه عرض را گرفته است؛ در آن حالت auto چیزی برای تقسیم ندارد و جعبه تکان نمی‌خورد. 

.center-box {
  width: 50%;
  margin: 0 auto;
}
من وسط هستم

مثال ۳: وسط کردن تصویر

تصویر inline است و margin: auto روی آن کار نمی‌کند؛ پس اول باید block شود (راه دیگر: text-align: center روی پدرش):

.center-img {
  display: block;
  margin: 0 auto;
  width: 200px;
}

مثال ۴: وسط عمودی با padding

.pad-center {
  padding: 40px 0;     /* بالا و پایین برابر */
  text-align: center;
}
با padding برابر، عمودی هم وسط هستم

مثال ۵: وسط عمودی یک خط با line-height

.line-center {
  height: 80px;
  line-height: 80px;   /* برابر با height */
  text-align: center;
}
یک خط، وسطِ وسط

اشتباه رایج: استفاده از این روش برای متن چندخطی؛ هر خط ۸۰ پیکسل ارتفاع می‌گیرد و متن از جعبه بیرون می‌زند. این ترفند فقط برای یک خط کوتاه (مثل متن دکمه یا نشان) مناسب است.

مثال ۶: وسط کامل با position و transform

.parent { position: relative; height: 150px; }

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);  /* نصف اندازه خودش برگردد */
}
دقیقاً وسط

مثال ۷: ساده‌ترین روش امروزی — Flexbox

.flex-center {
  display: flex;
  justify-content: center;  /* افقی */
  align-items: center;      /* عمودی */
  height: 150px;
}
وسط با Flexbox

مثال ۸: کوتاه‌ترین روش — Grid

برای وسط کردن یک فرزند در هر دو جهت (مثلاً محتوای یک پنجره مودال یا صفحه «در حال بارگذاری»):

.grid-center {
  display: grid;
  place-items: center;   /* افقی و عمودی با هم */
  height: 150px;
}
وسط با Grid
می‌خواهم ... روش پیشنهادی
متن یا عنصرهای inline را افقی وسط کنم text-align: center روی پدر
یک جعبه block با عرض مشخص را افقی وسط کنم margin: 0 auto
هر چیزی را افقی و عمودی وسط کنم Flexbox یا Grid روی پدر
عنصری را روی عنصر دیگر وسط کنم (مثل آیکون پخش روی ویدیو) position: absolute + transform

اشتباه رایج: text-align: center را روی یک div می‌گذاریم و انتظار داریم خود div وسط برود. text-align فقط محتوای داخل را تراز می‌کند؛ برای خود جعبه از margin: auto استفاده کنید.

اشتباه رایج: انتظار وسط عمودی از margin: auto یا vertical-align: middle روی یک div معمولی. margin: auto در جریان عادی فقط افقی کار می‌کند و vertical-align فقط روی عنصرهای inline، inline-block و سلول جدول اثر دارد.

تمرین: یک «بنر» به ارتفاع ۲۰۰ پیکسل بسازید که یک تیتر و یک دکمه دقیقاً وسط آن باشند.
