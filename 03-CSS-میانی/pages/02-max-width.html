۲) حداکثر عرض (Max-width)

width عرض را روی یک اندازه مشخص قفل می‌کند. اگر پنجره از آن عرض باریک‌تر شود، جعبه کوچک نمی‌شود و صفحه اسکرول افقی می‌گیرد. max-width فقط سقف عرض را تعیین می‌کند: جعبه تا آن اندازه پهن می‌شود و اگر فضای والد کمتر باشد، هم‌عرض فضای موجود می‌ماند. برای ستون متن و کارت، معمولاً max-width رفتار مناسب‌تری در موبایل دارد، چون عرض ثابت در صفحه باریک بیرون می‌زند.

مثال ۱: مقایسه width و max-width

.fixed { width: 600px; }      /* همیشه ۶۰۰ پیکسل */
.fluid { max-width: 600px; }  /* حداکثر ۶۰۰ پیکسل */
width: 600px — پنجره مرورگر را باریک کنید؛ از جعبه بیرون می‌زنم!
max-width: 600px — من خودم را با پنجره کوچک می‌کنم.

برای دیدن تفاوت، پنجره مرورگر را کوچک کنید یا صفحه را در حالت موبایل باز کنید (کلید F12 و سپس آیکون گوشی).

مثال ۲: وسط‌چین کردن محتوا

ترکیب max-width با margin: auto یک الگوی بسیار رایج برای وسط صفحه آوردن محتواست:

.article {
  max-width: 400px;
  margin: 0 auto;   /* چپ و راست خودکار = وسط */
}
یک مقاله کوتاه

این جعبه هیچ‌وقت از ۴۰۰ پیکسل پهن‌تر نمی‌شود و همیشه وسط می‌ماند. متن‌های بلند با عرض کم راحت‌تر خوانده می‌شوند.

مثال ۳: تصویری که هیچ‌وقت بیرون نمی‌زند

این سه خط تقریباً در همه سایت‌ها هست؛ جعبه آبی ۶۰٪ عرض را دارد و تصویر هرگز از آن بیرون نمی‌زند:

img {
  max-width: 100%;  /* بزرگ‌تر از ظرفش نشود */
  height: auto;     /* نسبت تصویر حفظ شود */
  display: block;   /* فاصله ریز زیر تصویر (به‌خاطر inline بودن) حذف شود */
}

مثال ۴: min-width و max-height

.btn       { min-width: 120px; }  /* دکمه حداقل ۱۲۰ پیکسل باشد */
.short-box { max-height: 70px; overflow: auto; }
این جعبه حداکثر ۷۰ پیکسل ارتفاع دارد. اگر متن بیشتر شود، اسکرول ظاهر می‌شود. خط دوم متن. خط سوم متن. خط چهارم متن. خط پنجم متن. خط ششم متن.

اگر min-width و max-width با هم تناقض داشته باشند (مثلاً min-width: 300px و max-width: 200px)، همیشه min-width برنده است. همین قاعده برای min-height و max-height هم برقرار است.

برای متن‌های طولانی (مقاله، وبلاگ) عرضی حدود ۶۰ تا ۷۵ حرف در هر خط خواناتر است؛ یعنی چیزی مثل max-width: 700px برای ستون متن، حتی در مانیتورهای خیلی پهن.

اشتباه رایج: دادن width ثابت و بزرگ به کل صفحه (مثلاً width: 1200px). در موبایل اسکرول افقی ایجاد می‌شود. به‌جایش از max-width استفاده کنید.

تمرین: یک کارت معرفی بسازید با max-width: 350px و margin: 20px auto و یک تصویر داخلش با max-width: 100%.
