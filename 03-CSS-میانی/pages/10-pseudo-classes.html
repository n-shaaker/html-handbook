۱۰) شبه‌کلاس‌ها (Pseudo-classes)

شبه‌کلاس حالتی از عنصر را انتخاب می‌کند که در HTML به‌صورت کلاس نوشته نشده است. مرورگر آن حالت را از تعامل کاربر یا از جایگاه عنصر در میان خواهر و برادرها تشخیص می‌دهد. شبه‌کلاس با یک دونقطه به انتخابگر می‌چسبد و بین آن‌ها نباید فاصله باشد: a:hover یعنی خود لینک وقتی ماوس روی آن است. اگر فاصله بگذارید (a :hover)، معنی عوض می‌شود و مرورگر به دنبال عنصر hoverشده داخل لینک می‌گردد. 

selector:pseudo-class {
  property: value;
}

مثال ۱: :hover و :active — دکمه زنده

.btn:hover  { background-color: #0b6e4f; }  /* ماوس روی دکمه */
.btn:active { transform: scale(0.95); }     /* لحظه کلیک */

مثال ۲: :focus — کادری که فعال است

input:focus {
  border-color: #1a5fb4;
  background-color: #e8f4fd;
  outline: 3px solid #a5d8ff;   /* حلقه فوکوس واضح؛ هرگز بدون جایگزین حذفش نکنید */
}

:focus-visible نسخه هوشمند :focus است: حلقه فوکوس را فقط وقتی نشان می‌دهد که کاربر با کیبورد (کلید Tab) حرکت می‌کند، نه وقتی با ماوس روی دکمه کلیک می‌کند. برای دکمه‌ها و لینک‌ها معمولاً :focus-visible انتخاب بهتری است. در همین جزوه، با Tab زدن روی لینک‌ها کادر نارنجی را می‌بینید.

مثال ۳: :first-child و :last-child

li:first-child { color: green; font-weight: bold; }
li:last-child  { color: red; }

مثال ۴: :nth-child() — انتخاب با شماره

:nth-child() عنصر را با شماره جایگاهش بین همه فرزندان والد انتخاب می‌کند، نه فقط بین عنصرهای هم‌نوع. شمارش از ۱ شروع می‌شود. odd جایگاه‌های فرد را می‌گیرد و even جایگاه‌های زوج را. 3n یعنی هر سومین جایگاه: ۳، ۶، ۹. اگر قبل از li عنصر دیگری باشد، شماره li با شماره «سومین آیتم فهرست» یکی نخواهد بود. در آن حالت :nth-of-type() فقط بین عنصرهای همان نوع می‌شمارد. 

li:nth-child(odd)  { background: #f1f3f5; }  /* فردها: ۱، ۳، ۵ */
li:nth-child(3n)   { color: #c92a2a; }      /* هر سومی: ۳، ۶، ۹ */
li:nth-child(2)    { font-weight: bold; }   /* فقط دومی */

مثال ۵: :not() — همه به‌جز ...

.tabs a:not(.active) {

مثال ۶: نمایش پیام با hover روی والد

در گوشی ماوس وجود ندارد و کاربر کیبورد هم hover ندارد؛ پس همیشه کنار :hover یک حالت :focus هم بگذارید:

.hint p        { display: none; }
.hint:hover p,
.hint:focus p  { display: block; }  /* با ماوس یا با Tab، پیام ظاهر شود */
ماوس را اینجا بیاور (یا با Tab به اینجا بیا)

سلام! من پیام مخفی هستم.

مثال ۷: :checked — چک‌باکس انتخاب‌شده

input:checked + label {
  color: green;
  text-decoration: line-through;
}


اشتباه رایج: گذاشتن فاصله قبل از دونقطه: a :hover اشتباه است؛ درستش a:hover است (بدون فاصله). با فاصله، معنی عوض می‌شود: «هر عنصرِ hover شده‌ای که داخل a است».

ترتیب درست حالت‌های لینک

برای لینک‌ها چهار حالت داریم و ترتیب نوشتنشان مهم است، چون قانونی که دیرتر بیاید برنده می‌شود. اگر :hover را قبل از :visited بنویسید، لینک‌های بازدیدشده دیگر رنگ hover نمی‌گیرند. 

a:link    { color: #1a5fb4; }   /* لینک دیده‌نشده */
a:visited { color: #6741d9; }   /* لینک بازدیدشده */
a:hover   { color: #0b6e4f; }   /* ماوس روی لینک */
a:active  { color: #c92a2a; }   /* لحظه کلیک */

برای به خاطر سپردن ترتیب: LoVe HAte (Link، Visited، Hover، Active).

اشتباه رایج: :first-child یعنی «عنصری که اولین فرزند پدرش است»، نه «اولین li». اگر قبل از اولین li یک تگ دیگر (مثلاً h4) باشد، li:first-child هیچ چیزی را انتخاب نمی‌کند؛ در این حالت از li:first-of-type استفاده کنید.

تمرین: یک جدول بسازید که ردیف‌های زوجش رنگی باشد (:nth-child(even)) و ردیف زیر ماوس پررنگ شود (:hover).
