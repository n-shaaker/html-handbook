۳) موقعیت (Position)

ویژگی position مشخص می‌کند مرورگر جای عنصر را نسبت به چه مرجعی حساب کند: جای عادی خودش در صفحه، یک عنصر والد، یا پنجره مرورگر. بعد از انتخاب نوع موقعیت، با top، right، bottom و left فاصله از لبه‌های همان مرجع را می‌دهیم. در حالت پیش‌فرض که static است، این چهار ویژگی اثری ندارند؛ چون عنصر هنوز در جریان عادی صفحه نشسته و قرار نیست از جایش جدا شود. مقدارهای left و right سمت فیزیکی را می‌گویند و با dir="rtl" جابه‌جا نمی‌شوند.

مقدار به زبان ساده
static حالت پیش‌فرض. عنصر در جریان عادی صفحه می‌ماند و top، right، bottom، left و z-index روی آن اثر ندارند.
relative عنصر نسبت به جایی که در جریان عادی داشته جابه‌جا می‌شود. جای اولیه‌اش خالی می‌ماند، پس عنصرهای بعدی تکان نمی‌خورند.
absolute عنصر از جریان صفحه خارج می‌شود و جایش برای بقیه خالی نمی‌ماند. مرجع آن نزدیک‌ترین جد است که position آن static نباشد. اگر چنین جدی نباشد، مرجع صفحه است.
fixed عنصر نسبت به پنجره مرورگر ثابت می‌ماند و با اسکرول صفحه حرکت نمی‌کند. از جریان صفحه خارج می‌شود، پس روی محتوای زیر خودش قرار می‌گیرد.
sticky تا پیش از رسیدن به آستانه، مثل relative در جریان صفحه می‌ماند. بعد از اسکرول، داخل محدوده والدش به لبه تعیین‌شده (مثلاً top: 0) می‌چسبد. بدون top یا bottom چسبیدن شروع نمی‌شود.

مثال ۱: relative — کمی جابه‌جا کن

.moved {
  position: relative;
  top: 15px;
  right: 40px;   /* ۴۰ پیکسل از سمت راست فاصله بگیرد (یعنی به چپ برود) */
}

در صفحه راست‌چین هم right: 40px یعنی «۴۰ پیکسل از لبه راستِ جای اصلی فاصله بگیر»؛ پس جعبه به سمت چپ می‌رود. جهت صفحه (dir="rtl") معنی left و right را عوض نمی‌کند.

مثال ۲: absolute — برچسب روی گوشه کارت محصول

الگوی پرکاربرد در فروشگاه‌ها: پدر را relative می‌کنیم و فرزند را absolute.

.card {
  position: relative;   /* مرجع برای فرزند */
}

.badge {
  position: absolute;
  top: -10px;
  left: -10px;
}

مثال ۳: sticky — سرتیتری که می‌چسبد

همین روش برای «هدر چسبان» سایت‌ها (header { position: sticky; top: 0; }) هم استفاده می‌شود. داخل جعبه زیر اسکرول کنید:

.sticky-title {
  position: sticky;
  top: 0;
}

مثال ۴: fixed — دکمه «بالای صفحه»

دکمه گرد گوشه پایین سمت چپ صفحه را ببینید؛ هر چقدر اسکرول کنید سر جایش می‌ماند.

.to-top {
  position: fixed;
  bottom: 20px;
  left: 20px;
}
↑

اشتباه رایج: absolute دادن به فرزند بدون relative کردن پدر. در این حالت مرجعِ عنصر یک جدّ دورتر یا (اگر هیچ جدّی position نداشته باشد) کل صفحه می‌شود و برچسب جای عجیبی می‌رود.

اشتباه رایج: «sticky کار نمی‌کند!» معمولاً یکی از این سه دلیل را دارد: ۱) top (یا bottom) تعیین نشده؛ ۲) یکی از اجداد عنصر overflow: hidden یا auto دارد و چسبیدن داخل همان جعبه اتفاق می‌افتد؛ ۳) پدر عنصر هم‌قد خود عنصر است و جایی برای چسبیدن نمی‌ماند.

عنصری که fixed است روی محتوا می‌افتد؛ اگر یک هدر را fixed کنید، باید به body به اندازه ارتفاع هدر padding-top بدهید تا اول صفحه زیرش پنهان نشود. sticky این مشکل را ندارد، چون جای خودش را در صفحه نگه می‌دارد.

تمرین: یک عکس پروفایل بسازید و با absolute یک دایره سبز کوچک (نشانه «آنلاین») روی گوشه پایین آن بگذارید.
