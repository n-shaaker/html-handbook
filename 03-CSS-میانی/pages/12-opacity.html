۱۲) شفافیت (Opacity)

opacity میزان مات بودن کل عنصر را تعیین می‌کند. مقدار 1 کاملاً مات است و مقدار 0 کاملاً نامرئی. بین این دو، مثلاً 0.5 یا 50%، عنصر نیمه‌شفاف دیده می‌شود. این ویژگی روی خود عنصر و همه فرزندانش با هم اثر می‌گذارد. فرزند نمی‌تواند با opacity: 1 از شفافیت پدر خارج شود، چون شفافیت‌ها در هم ضرب می‌شوند. عنصری با opacity: 0 دیده نمی‌شود، ولی هنوز جا دارد و می‌توان روی آن کلیک کرد. برای حذف از چیدمان باید از display: none استفاده کرد. اگر فقط پس‌زمینه باید شفاف باشد و متن خوانا بماند، به‌جای opacity از رنگ rgba یا شکل جدید rgb(… / …) استفاده کنید.

مثال ۱: درجه‌های مختلف شفافیت

.o1 { opacity: 0.2; }
.o2 { opacity: 0.5; }
.o3 { opacity: 0.8; }
.o4 { opacity: 1; }

مثال ۲: واضح شدن با hover (گالری محصولات)

.gallery img {
  opacity: 0.5;
  transition: opacity 0.3s;   /* تغییر نرم */
}

.gallery img:hover {
  opacity: 1;
}

مثال ۳: دکمه غیرفعال (مثلاً «افزودن به سبد» برای کالای ناموجود)

.btn:disabled {
  opacity: 0.4;
  cursor: not-allowed;
}

مثال ۴: opacity یا rgba؟ (مهم)

opacity کل عنصر را همراه با متن داخلش کم‌رنگ می‌کند. اگر فقط پس‌زمینه باید شفاف شود، از rgba استفاده کنید: 

.box-op   { background: rgb(26, 95, 180); opacity: 0.4; }      /* متن هم کم‌رنگ شد */
.box-rgba { background: rgba(26, 95, 180, 0.4); }               /* فقط پس‌زمینه */
با opacity — متن هم کم‌رنگ است
با rgba — متن کاملاً واضح است

در CSS امروزی همین را می‌توانید کوتاه‌تر هم بنویسید: rgb(26 95 180 / 40%) (بدون ویرگول و با / برای شفافیت).

اشتباه رایج: نوشتن عدد بزرگ‌تر از ۱ مثل opacity: 50. مقدار درست 0.5 یا به شکل درصد 50% است.

اشتباه رایج: فکر کنیم می‌شود فرزند یک عنصر کم‌رنگ را با opacity: 1 دوباره پررنگ کرد. نمی‌شود؛ opacity روی کل عنصر و همه فرزندانش با هم اعمال می‌شود. راه حل همان rgba برای پس‌زمینه است.

عنصری که opacity: 0 دارد دیده نمی‌شود ولی هنوز جا دارد و کلیک‌پذیر است. برای پنهان کردن واقعی از display: none یا visibility: hidden استفاده کنید. همچنین برای دکمه غیرفعال، فقط کم‌رنگ کردن کافی نیست؛ ویژگی disabled در HTML لازم است تا واقعاً کلیک نشود.

تمرین: یک کارت با تصویر پس‌زمینه بسازید که روی آن یک نوار متن با rgba(0, 0, 0, 0.6) قرار بگیرد.
