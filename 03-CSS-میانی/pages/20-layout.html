۲۰) چیدمان سایت (Website Layout)

مسیر درست چیدمان: Flexbox · Grid · قبلش: Media Queries

چیدمان سایت یعنی مشخص کردن جای بخش‌های تکرارشونده صفحه: سربرگ، منو، محتوای اصلی، ستون کناری و پانویس. این بخش‌ها را با عنصرهای معنایی HTML می‌سازیم تا ساختار صفحه برای مرورگر و صفحه‌خوان روشن باشد، و اندازه و کنار هم نشستنشان را با CSS تعیین می‌کنیم. header معمولاً نام و نشانه سایت را دارد، nav لینک صفحه‌ها را، main مطلب اصلی را، aside مطلب جانبی را و footer اطلاعات پایانی را. در هر صفحه فقط یک main مجاز است. برای کنار هم گذاشتن ستون‌ها، روش پایدار امروزی Flexbox یا Grid است. Float را در این درس فقط می‌بینید تا چیدمان‌های قدیمی را بشناسید.

بخش تگ پیشنهادی کار
سربرگ header لوگو و نام سایت
منو nav لینک صفحه‌ها
محتوا main (فقط یکی در هر صفحه)، داخلش article و section مطالب اصلی
ستون کناری aside مطالب جانبی، تبلیغ، دسته‌بندی
پانویس footer کپی‌رایت، راه‌های تماس

در هر صفحه فقط یک main مجاز است. چون این صفحه آموزشی چند نمونه سایت را با هم نشان می‌دهد، در مثال‌های زیر به‌جای main از article با کلاس l-main استفاده شده؛ در سایت خودتان همان main را بنویسید.

مثال ۱: چیدمان ساده یک‌ستونه (مثل وبلاگ)

header, nav, main, footer { padding: 16px; }
header { background: #1a3a5c; color: white; text-align: center; }
nav    { background: #333; }
footer { background: #ddd; text-align: center; }

مثال ۲: محتوا + ستون کناری (با Flexbox)

پدرِ دو ستون flex می‌شود؛ ستون‌ها خودکار کنار هم و هم‌قد می‌نشینند. در صفحه راست‌چین، اولین فرزند (محتوا) سمت راست قرار می‌گیرد:

.row  { display: flex; }
main  { width: 70%; }
aside { width: 30%; }

مثال ۳: سه ستون برابر با Grid (بخش خدمات)

Grid برای ردیف کارت‌ها عالی است: تعداد ستون و فاصله را یک‌جا روی پدر تعیین می‌کنید. واحد fr یعنی «یک سهم از فضای باقی‌مانده»:

.grid-3 {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* سه ستون مساوی */
  gap: 12px;
}

مثال ۴: همان سه ستون با float (روش قدیمی)

قبل از Flexbox و Grid، ستون‌ها را این‌طور می‌ساختند. کد بیشتری لازم دارد، ستون‌ها هم‌قد نمی‌شوند و پدر باید flow-root شود:

.row-float { display: flow-root; }   /* پدر جمع نشود */

.column {
  float: right;
  width: 33.33%;
  padding: 15px;
}

تفاوت را ببینید: در مثال ۳ هر سه کارت هم‌قدند، ولی اینجا ارتفاع هر ستون به اندازه متن خودش است.

مثال ۵: Flexbox با flex: 1

Flexbox بعداً مفصل آموزش داده می‌شود؛ فعلاً فقط ببینید بدون حساب درصد، ستون‌ها چطور فضا را بین خودشان تقسیم می‌کنند:

.row-flex {
  display: flex;
  gap: 12px;
}

.row-flex > div {
  flex: 1;   /* همه ستون‌ها هم‌اندازه */
}

ستون ۳

در موبایل چه کنیم؟

ستون‌های کنار هم در گوشی خیلی باریک می‌شوند. با Media Query می‌گوییم «اگر عرض صفحه کم بود، ستون‌ها زیر هم بیایند». جزئیات را در درس‌های طراحی واکنش‌گرا (Responsive) یاد می‌گیریم؛ فعلاً شکل کلی‌اش را ببینید (پنجره را باریک کنید تا مثال‌های ۲ و ۳ و ۵ این صفحه زیر هم بیایند): 

@media (max-width: 600px) {
  .row, .row-flex   { flex-direction: column; }        /* ستون‌ها زیر هم */
  main, aside       { width: 100%; }
  .grid-3           { grid-template-columns: 1fr; }    /* یک ستون */
}

اشتباه رایج: در روش float یا عرض‌های درصدی، جمع عرض ستون‌ها بیشتر از ۱۰۰٪ می‌شود (مثلاً 70% + 30% به‌علاوه margin یا padding بدون border-box) و ستون آخر به خط بعد می‌افتد. با box-sizing: border-box و حساب دقیق (یا calc) حل می‌شود؛ و در Flexbox و Grid با gap و fr اصلاً پیش نمی‌آید.

تمرین: اسکلت یک سایت «رستوران» بسازید: هدر با نام رستوران، منو، محتوا (۷۰٪) با معرفی غذاها، ستون کناری (۳۰٪) با ساعت کاری، و فوتر. ستون‌ها را با Flexbox کنار هم بچینید و بخش «غذاهای ویژه» را با Grid سه‌ستونه بسازید.
