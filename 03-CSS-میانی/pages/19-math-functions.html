۱۹) توابع ریاضی (Math Functions)

تابع‌های ریاضی CSS اجازه می‌دهند طول را همان‌جا که می‌نویسیم حساب کنیم و واحدهای مختلف را در یک مقدار مخلوط کنیم؛ مثلاً درصدی از عرض پدر را منهای چند پیکسل ثابت. calc() یک عبارت با جمع، تفریق، ضرب و تقسیم را حساب می‌کند. دور علامت‌های + و - باید فاصله باشد، وگرنه مرورگر عبارت را نامعتبر می‌خواند. min() از بین چند مقدار، کوچک‌ترین را برمی‌گزیند و max() بزرگ‌ترین را. clamp(کمینه, دلخواه, بیشینه) مقدار دلخواه را بین یک کف و یک سقف نگه می‌دارد: اگر دلخواه از کمینه کوچک‌تر شود، کمینه اعمال می‌شود و اگر از بیشینه بزرگ‌تر شود، بیشینه.

تابع به زبان ساده
calc() یک محاسبه انجام بده (+ − × ÷)
min() از بین چند مقدار، کوچک‌ترین را بردار
max() از بین چند مقدار، بزرگ‌ترین را بردار
clamp(کمینه, دلخواه, بیشینه) مقدار دلخواه را بین یک حداقل و حداکثر نگه دار

مثال ۱: calc() — عرض منهای یک مقدار ثابت

.layout  { display: flex; }               /* دو ستون کنار هم */
.sidebar { width: 120px; }
.main    { width: calc(100% - 120px); }   /* بقیه جا */
ستون کناری ۱۲۰px
ستون اصلی: calc(100% - 120px)

اشتباه رایج: دور + و - در calc حتماً باید فاصله باشد: calc(100%-120px) کار نمی‌کند (چون -120px یک عدد منفی خوانده می‌شود). برای * و / فاصله الزامی نیست، ولی برای خوانایی بهتر است بگذارید.

در calc ضرب و تقسیم باید با «عدد بدون واحد» باشد: calc(100% / 3) درست است، ولی calc(100% / 3px) نامعتبر است.

مثال ۲: calc() — سه ستون با فاصله دقیق

.cols {
  display: flex;
  gap: 20px;                        /* دو فاصله ۲۰ پیکسلی بین سه ستون */
}

.col {
  width: calc((100% - 40px) / 3);   /* دو فاصله کم شود، بقیه تقسیم بر ۳ */
}

در عمل، با Flexbox می‌توانید به‌جای این حساب فقط flex: 1 بنویسید (درس ۲۰). calc وقتی لازم است که عرض دقیق بخواهید؛ مثلاً هر کارت دقیقاً یک‌سوم ردیف باشد حتی اگر تعداد کارت‌های ردیف آخر کمتر باشد.

مثال ۳: min() — حداکثر عرض بدون max-width

min(90%, 400px) هر دو مقدار را حساب می‌کند و کوچک‌تر را برمی‌گزیند. در صفحه پهن، ۴۰۰ پیکسل کوچک‌تر از ۹۰ درصد است، پس عرض ۴۰۰ می‌ماند. در صفحه باریک، ۹۰ درصد کوچک‌تر می‌شود و همان اعمال می‌شود. نتیجه شبیه ترکیب width: 90% و max-width: 400px است: یک سقف پیکسلی، با جمع شدن در عرض کم. 

.card-min {
  width: min(90%, 400px);   /* هر کدام کوچک‌تر بود */
  margin: 0 auto;
}
در صفحه بزرگ ۴۰۰px، در موبایل ۹۰٪

مثال ۴: max() — حداقل اندازه

.note-max { font-size: max(14px, 1.2vw); }   /* هیچ‌وقت کمتر از ۱۴px نشود */

نام تابع‌ها از دید ریاضی است، نه از دید «حداکثر عرض طراحی». min() کوچک‌ترین عدد را برمی‌دارد، پس در عمل سقف اندازه را می‌سازد. max() بزرگ‌ترین عدد را برمی‌دارد، پس اندازه از کف تعیین‌شده پایین‌تر نمی‌رود. در این مثال، max(14px, 1.2vw) یعنی اگر ۱٫۲ درصد عرض پنجره از ۱۴ پیکسل کوچک‌تر شد، همان ۱۴ پیکسل استفاده شود تا متن ناخوانا ریز نشود.

این متن در صفحه کوچک هم خوانا می‌ماند.

مثال ۵: clamp() — فونت واکنش‌گرا

.clamp-title {
  font-size: clamp(18px, 5vw, 40px);
  /* حداقل 18px، معمولاً 5vw، حداکثر 40px */
}

پنجره را بزرگ و کوچک کنید

clamp() یکی از کاربردی‌ترین ابزارهای CSS مدرن است؛ با یک خط، فونت در موبایل و دسکتاپ هر دو مناسب می‌شود. برای اینکه فونت با زوم مرورگر هم بزرگ شود، در مقدار وسط rem را با vw جمع کنید: clamp(1.125rem, 1rem + 2vw, 2.5rem). داخل clamp، min و max نیازی به نوشتن calc نیست.

اشتباه رایج: جابه‌جا نوشتن ترتیب آرگومان‌های clamp. ترتیب همیشه «کمینه، مقدار دلخواه، بیشینه» است؛ اگر کمینه از بیشینه بزرگ‌تر باشد، همیشه کمینه برنده می‌شود و مقدار هرگز تغییر نمی‌کند.

تمرین: یک تیتر بسازید که با clamp(20px, 4vw, 48px) اندازه‌اش تغییر کند و یک جعبه با width: calc(100% - 40px).
