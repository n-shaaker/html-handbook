۵) سرریز (Overflow)

سرریز وقتی رخ می‌دهد که محتوا از جعبه بزرگ‌تر باشد؛ مثلاً متن بلند در جعبه‌ای با height یا max-height محدود. ویژگی overflow می‌گوید با قسمت اضافه چه شود. visible مقدار پیش‌فرض است و اضافه را بیرون جعبه نشان می‌دهد. hidden اضافه را می‌برد و پنهان می‌کند. scroll نوار اسکرول را حتی اگر محتوا جا شود نشان می‌دهد. auto فقط وقتی محتوا واقعاً جا نشود نوار اسکرول می‌آورد و معمولاً انتخاب مناسب‌تری است. اگر ارتفاع جعبه آزاد باشد و با محتوا بزرگ شود، سرریز عمودی پیش نمی‌آید و overflow اثری برای بریدن متن ندارد.

مثال ۱: چهار مقدار اصلی

.box { height: 90px; }

.v { overflow: visible; }  /* پیش‌فرض: بیرون می‌زند */
.h { overflow: hidden; }   /* اضافه بریده و پنهان می‌شود */
.s { overflow: scroll; }   /* همیشه اسکرول دارد */
.a { overflow: auto; }     /* فقط اگر لازم بود اسکرول می‌آید */
visible متن زیادی که در این جعبه کوچک جا نمی‌شود و از پایین آن بیرون می‌زند و روی بقیه می‌افتد.
hidden متن زیادی که در این جعبه کوچک جا نمی‌شود و قسمت اضافه‌اش بریده می‌شود و دیده نمی‌شود.
scroll متن زیادی که در این جعبه کوچک جا نمی‌شود؛ برای همین نوار اسکرول داریم تا بقیه را ببینیم.
auto متن زیادی که در این جعبه کوچک جا نمی‌شود؛ اسکرول فقط وقتی ظاهر می‌شود که لازم باشد.

مثال ۲: فقط اسکرول افقی با overflow-x

برای جدول‌ها یا ردیف کارت‌ها و برچسب‌های پهن در موبایل خیلی کاربردی است (در این مثال، ردیف برچسب‌ها direction: ltr دارد تا از چپ شروع شود):

.row {
  overflow-x: auto;     /* اسکرول افقی */
  white-space: nowrap;  /* آیتم‌ها به خط بعد نروند */
}

مثال ۳: سه‌نقطه برای متن طولانی

وقتی عنوان کارت باید در یک خط بماند، متن اضافه را با سه‌نقطه نشان می‌دهیم. white-space: nowrap جلوی رفتن به خط بعد را می‌گیرد، overflow: hidden بخش بیرون‌زده را پنهان می‌کند و text-overflow: ellipsis به‌جای آن سه‌نقطه می‌گذارد. اگر عرض جعبه محدود نباشد، متن جایی برای بریده شدن ندارد و سه‌نقطه ظاهر نمی‌شود. 

.ellipsis {
  width: 250px;
  white-space: nowrap;      /* در یک خط بماند */
  overflow: hidden;         /* اضافه پنهان شود */
  text-overflow: ellipsis;  /* به‌جایش ... بیاید */
}

آموزش کامل طراحی سایت با HTML و CSS از صفر تا صد همراه با پروژه عملی

هر سه ویژگی لازم است: بدون white-space: nowrap متن به خط بعد می‌رود و بدون overflow: hidden بیرون می‌زند؛ در هر دو حالت سه‌نقطه ظاهر نمی‌شود. عنصر هم باید عرض محدود داشته باشد (block یا inline-block با width). در متن فارسی سه‌نقطه به‌درستی در سمت چپ (انتهای جمله) می‌آید.

اشتباه رایج: استفاده از overflow: scroll وقتی محتوا کم است؛ نوار اسکرول خالی و زشت دیده می‌شود. معمولاً auto انتخاب بهتری است.

اشتباه رایج: گذاشتن overflow: hidden روی پدر یک منوی کشویی یا برچسب absolute؛ هر چیزی که از لبه پدر بیرون بزند بریده می‌شود و منو «ناپدید» به نظر می‌رسد. همچنین overflow بدون height یا max-height معمولاً اثری ندارد، چون جعبه هم‌قد محتوایش بزرگ می‌شود.

تمرین: یک جعبه «قوانین سایت» با ارتفاع ۱۵۰ پیکسل بسازید که متن بلندش با overflow: auto اسکرول شود.
