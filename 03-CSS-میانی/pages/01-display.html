۱) نمایش (Display)

ویژگی display تعیین می‌کند مرورگر برای یک عنصر چه نوع جعبه بسازد و آن جعبه در کنار عنصرهای دیگر چطور جا بگیرد. هر تگ HTML یک مقدار پیش‌فرض دارد. بیشتر تگ‌ها یا block هستند، یعنی از خط تازه شروع می‌شوند و تمام عرض در دسترس را می‌گیرند، یا inline هستند، یعنی در همان خط کنار متن می‌نشینند و فقط به اندازه محتوایشان جا می‌گیرند. با عوض کردن display ظاهر و جای جعبه عوض می‌شود، ولی معنی تگ در HTML همان می‌ماند؛ مثلاً یک لینک که display: block گرفته هنوز لینک است.

مثال ۱: تفاوت block و inline

block (بلوکی) inline (درون‌خطی)
همیشه از خط جدید شروع می‌شود و کل عرض را می‌گیرد. کنار بقیه در همان خط می‌نشیند و فقط به اندازه محتوایش جا می‌گیرد.
div، p، h1 تا h6، ul، form span، a، strong، em، label
width، height و margin بالا/پایین اثر دارند. width و height اثر ندارند؛ margin و padding بالا/پایین جای خط را تغییر نمی‌دهند.

img، input و button هم درون‌خطی هستند، ولی از نوع «جایگزین‌شونده» (replaced)؛ یعنی برخلاف span، می‌شود به آن‌ها width و height داد. رفتارشان شبیه inline-block است.

من یک div هستم (block)
من هم div هستم؛ زیر قبلی آمدم
من span هستم من هم span هستم؛ کنار قبلی نشستم

مثال ۲: منوی افقی با display: inline

آیتم‌های فهرست (li) به‌طور پیش‌فرض block هستند (دقیق‌تر: list-item) و زیر هم می‌آیند. با inline کردنشان کنار هم قرار می‌گیرند:

.menu-inline {
  margin: 0;
  padding: 0;          /* فاصله پیش‌فرض فهرست حذف شود */
}

.menu-inline li {
  display: inline;
  margin-left: 16px;   /* در صفحه راست‌چین، فاصله با آیتم بعدی (سمت چپ) */
}

مثال ۳: block کردن یک عنصر inline

برعکس هم ممکن است. اینجا هر span مثل یک خط کامل رفتار می‌کند:

.span-block span {
  display: block;
}

نام: سارا شهر: شیراز رشته: طراحی وب

مثال ۴: پنهان کردن با display: none و visibility: hidden

display: none عنصر را از چیدمان صفحه حذف می‌کند: نه دیده می‌شود، نه جا اشغال می‌کند، و معمولاً صفحه‌خوان هم آن را نمی‌خواند. visibility: hidden عنصر را نامرئی می‌کند، ولی جعبه خالی‌اش سر جایش می‌ماند و عنصرهای بعدی را هل می‌دهد. این دو وقتی به کار می‌آیند که بخواهید بخشی را موقتاً پنهان کنید؛ مثلاً یک پیام یا یک آیتم منو. برای پنهان کردن واقعی، none مناسب است. برای حفظ فاصله، hidden. 

.hide-none   { display: none; }       /* کاملاً حذف؛ جایش هم خالی نمی‌ماند */
.hide-hidden { visibility: hidden; }  /* نامرئی؛ ولی جایش خالی می‌ماند */

display ظاهر عنصر را عوض می‌کند، نه نوع تگ را. یعنی a با display: block هنوز یک لینک است؛ فقط مثل block جا می‌گیرد.

مقدارهای مهم دیگر display

مقدار کاربرد
inline-block کنار بقیه در یک خط، ولی با عرض و ارتفاع؛ در درس ۷ می‌بینیم.
flex چیدن فرزندان در یک ردیف یا ستون با کنترل فاصله و تراز؛ روش امروزی ساخت منو و ردیف کارت‌ها.
grid چیدمان دوبعدی (سطر و ستون)؛ مناسب اسکلت صفحه و گالری.
none عنصر کاملاً از صفحه حذف می‌شود (برای منوی کشویی، پنجره مودال و ...).

اشتباه رایج: دادن width و height به یک عنصر inline (مثل span یا a). روی inline اثری ندارد؛ اول باید آن را block یا inline-block کنید.

اشتباه رایج: فکر کنیم visibility: hidden و opacity: 0 عنصر را حذف می‌کنند. هر دو جای عنصر را نگه می‌دارند؛ عنصری که opacity: 0 دارد حتی هنوز کلیک‌پذیر است. برای حذف واقعی از display: none استفاده کنید.

تمرین: یک فهرست سه‌تایی از غذاهای مورد علاقه‌تان بسازید و با display: inline آن را افقی کنید. سپس با display: none یکی از آیتم‌ها را پنهان کنید.
