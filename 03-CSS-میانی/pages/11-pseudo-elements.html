۱۱) شبه‌عنصرها (Pseudo-elements)

شبه‌عنصر بخشی از عنصر را جداگانه سبک می‌دهد، یا یک جعبه تازه قبل یا بعد از محتوا می‌سازد، بدون اینکه در HTML تگ تازه‌ای اضافه شود. شبه‌عنصر با دو دونقطه نوشته می‌شود: ::before، ::after، ::first-letter، ::first-line، ::marker و ::selection. ::before و ::after فقط وقتی چیزی نشان می‌دهند که ویژگی content داشته باشند. حتی جعبه تزئینی خالی هم به content: "" نیاز دارد. متنی که با content ساخته می‌شود جزو HTML نیست: انتخاب و کپی کردنش مثل متن واقعی صفحه نیست و بعضی صفحه‌خوان‌ها آن را نمی‌خوانند. پس برای اطلاعات ضروری، همان متن را در HTML بنویسید و از شبه‌عنصر برای تزئین استفاده کنید.

فرق ساده: شبه‌کلاس (:hover) = یک حالت. شبه‌عنصر (::before) = یک بخش. در کدهای قدیمی نسخه تک‌دونقطه (:before، :after) را هم می‌بینید که هنوز کار می‌کند، ولی شکل استاندارد امروزی همان :: است.

مثال ۱: ::first-letter — حرف اول بزرگ

p::first-letter {
  font-size: 40px;
  color: #c92a2a;
  font-weight: bold;
}

Once upon a time, there was a little web page that wanted to look beautiful...

در متن فارسی، چون حروف به هم می‌چسبند، ::first-letter ممکن است اتصال حرف اول را بشکند؛ برای همین مثال انگلیسی است.

مثال ۲: ::first-line — خط اول متفاوت

p::first-line {
  color: #1a5fb4;
  font-weight: bold;
}

فقط خط اول این پاراگراف آبی و پررنگ است. اگر پنجره را کوچک یا بزرگ کنید، می‌بینید که همیشه همان خط اول (هر چقدر که جا شود) تغییر می‌کند و بقیه متن عادی می‌ماند. این حالت برای شروع مقاله‌ها زیباست.

مثال ۳: ::before و ::after — ساختن محتوای تازه

این دو حتماً به content نیاز دارند (حتی اگر خالی باشد: content: "").

.done::before   { content: "✔ "; color: green; }
.price::after   { content: " تومان"; color: #888; }
.required::after { content: " *"; color: red; }

نام و نام خانوادگی

محتوایی که با content ساخته می‌شود جزو HTML نیست: کاربر نمی‌تواند آن را انتخاب و کپی کند و بعضی صفحه‌خوان‌ها (نرم‌افزار نابینایان) آن را نمی‌خوانند. پس فقط برای تزئین و علامت‌های کمکی از آن استفاده کنید؛ مثلاً برای فیلد اجباری، علاوه بر ستاره، ویژگی required را هم در HTML بگذارید.

مثال ۴: نقل قول تزئینی با ::before

.quote::before {
  content: "«";
  font-size: 50px;
  color: #ced4da;
}
دانستن کافی نیست، باید به کار ببریم.

مثال ۵: خط تزئینی زیر تیتر بخش‌های سایت با ::after

.fancy::after {
  content: "";          /* خالی، فقط یک جعبه */
  display: block;
  width: 60px;
  height: 4px;
  background: orange;
  margin-top: 6px;
}

خدمات ما

مثال ۶: ::selection و ::marker

p::selection { background: #ffd43b; color: black; }  /* متن انتخاب‌شده */
li::marker   { color: #e8590c; font-size: 20px; }    /* علامت فهرست */

روی ::selection و ::marker فقط چند ویژگی محدود (مثل رنگ، پس‌زمینه و فونت) کار می‌کند؛ مثلاً نمی‌شود به آن‌ها padding داد.

این متن را با ماوس انتخاب (select) کنید تا رنگ زرد را ببینید.

  • علامت این فهرست نارنجی است
  • با ::marker تغییر کرده

اشتباه رایج: نوشتن ::before بدون content. در این حالت هیچ چیزی نمایش داده نمی‌شود.

اشتباه رایج: استفاده از ::before و ::after روی img و input. این عنصرها محتوای داخلی ندارند و شبه‌عنصر رویشان ساخته نمی‌شود؛ شبه‌عنصر را روی پدرشان (مثلاً label یا یک div) بگذارید.

تمرین: برای لینک‌هایی که کلاس external دارند، با ::after یک علامت ↗ اضافه کنید.
