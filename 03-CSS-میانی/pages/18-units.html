۱۸) واحدها (Units) — اختیاری

هر جا در CSS طول می‌نویسیم، بعد از عدد باید واحد بیاید؛ مثل 20px. بدون واحد، آن تعریف نامعتبر است و مرورگر نادیده‌اش می‌گیرد. دو استثنا مهم وجود دارد: عدد 0، که صفر در هر واحدی همان صفر است، و ویژگی‌هایی که از اول عدد بدون واحد می‌خواهند؛ مثل opacity، z-index و line-height وقتی به‌صورت ضریب نوشته شود. واحدها دو دسته‌اند. واحد مطلق، مثل px، به اندازه عنصرهای اطراف وابسته نیست. واحد نسبی نسبت به مرجع دیگری حساب می‌شود: درصد نسبت به پدر، em نسبت به قلم، rem نسبت به قلم ریشه، و vw و vh نسبت به اندازه پنجره. یک px در CSS همیشه یک پیکسل فیزیکی صفحه نیست. در نمایشگرهای پرتراکم، مرورگر یک پیکسل CSS را با چند پیکسل دستگاه رسم می‌کند تا اندازه دیده‌شده منطقی بماند.

واحد نوع نسبت به ...
px مطلق پیکسل CSS؛ پرکاربردترین واحد (در گوشی‌های با صفحه پرتراکم، هر px چند پیکسل واقعی صفحه است)
cm، mm، in، pt مطلق بیشتر برای چاپ؛ در صفحه نمایش کم استفاده می‌شوند
% نسبی اندازه پدر (برای width، عرض پدر؛ برای font-size، فونت پدر)
em نسبی در font-size: اندازه فونت پدر؛ در بقیه ویژگی‌ها (padding، margin، ...): اندازه فونت خود عنصر
rem نسبی اندازه فونت ریشه (تگ html؛ معمولاً 16px)
vw / vh نسبی ۱٪ عرض / ارتفاع پنجره مرورگر
dvh نسبی ۱٪ ارتفاع «واقعی» پنجره در موبایل (با در نظر گرفتن نوار آدرس که باز و بسته می‌شود)

مثال ۱: px — اندازه ثابت

.px12 { font-size: 12px; }
.px20 { font-size: 20px; }
.px32 { font-size: 32px; }
12px 20px 32px

مثال ۳: em در برابر rem

em «زنجیره‌ای» است: هر سطح، نسبت به پدرش بزرگ می‌شود. rem همیشه نسبت به ریشه است و قابل پیش‌بینی‌تر است. 

.parent { font-size: 20px; }

.em  { font-size: 1.5em; }   /* 1.5 × 20 = 30px */
.rem { font-size: 1.5rem; }  /* 1.5 × 16 = 24px (بدون توجه به پدر) */

با 1.5em

مثال ۴: em برای padding دکمه

اگر padding با em باشد، با بزرگ شدن فونت، دکمه هم متناسب بزرگ می‌شود:

.btn { padding: 0.5em 1em; }

مثال ۵: vw و vh — نسبت به پنجره

vh یک‌صدم ارتفاع پنجره مرورگر است و vw یک‌صدم عرض همان پنجره. height: 30vh یعنی جعبه همیشه حدود ۳۰ درصد ارتفاع پنجره‌ای باشد که الان باز است، نه ۳۰ درصد پدرش. font-size: 5vw هم اندازه قلم را به عرض پنجره وصل می‌کند. این اندازه با تنظیم درشت‌نمایی قلم مرورگر بزرگ نمی‌شود و در صفحه‌های خیلی پهن بیش از حد درشت می‌شود؛ برای همین در عمل آن را با clamp() محدود می‌کنند. 

.hero {
  height: 30vh;               /* ۳۰٪ ارتفاع پنجره */
  display: flex;              /* متن وسط بنر (درس ۸) */
  justify-content: center;
  align-items: center;
}

.vw-title { font-size: 5vw; } /* با عرض پنجره بزرگ و کوچک می‌شود */
پنجره را تغییر اندازه دهید

فونت فقط با vw با زوم مرورگر بزرگ نمی‌شود و در موبایل خیلی ریز و در مانیتور بزرگ خیلی درشت می‌شود. راه درست، محدود کردن آن با clamp() است که در درس بعد می‌بینیم.

قاعده ساده برای شروع: فونت‌ها با rem، فاصله‌های کوچک و حاشیه‌ها با px، عرض‌ها با % یا max-width. دلیل rem برای فونت: اگر کاربر کم‌بینا اندازه فونت پیش‌فرض مرورگرش را بزرگ کند، متن‌های rem همراهش بزرگ می‌شوند، ولی متن‌های px ثابت می‌مانند.

اشتباه رایج: فاصله بین عدد و واحد: 20 px اشتباه است؛ درستش 20px است. همچنین جا انداختن واحد: width: 20 نامعتبر است و مرورگر کل آن خط را نادیده می‌گیرد (فقط 0 بدون واحد مجاز است).

اشتباه رایج: استفاده از em برای فونت در عنصرهای تودرتو؛ مثلاً اگر li { font-size: 1.2em; } باشد، هر فهرست داخل فهرست دیگر ۱٫۲ برابر بزرگ‌تر از قبلی می‌شود. برای فونت، rem امن‌تر است.

تمرین: یک نوار «مهارت‌های من» با سه مهارت و درصد عرض متفاوت بسازید.
