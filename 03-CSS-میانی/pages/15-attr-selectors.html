۱۵) انتخابگرهای ویژگی (Attribute Selectors)

انتخابگر ویژگی، عنصر را بر اساس ویژگی‌های نوشته‌شده در HTML انتخاب می‌کند؛ مثل type، href یا target. این انتخابگر داخل کروشه نوشته می‌شود. [target] یعنی ویژگی وجود دارد، حتی اگر مقدارش هر چه باشد. [type="text"] یعنی مقدار دقیقاً برابر text است. علامت ^= یعنی مقدار با این رشته شروع می‌شود، $= یعنی با آن تمام می‌شود، و *= یعنی آن رشته هر جای مقدار آمده باشد. ~= به دنبال یک کلمه کامل، جدا شده با فاصله، می‌گردد. |= برای مقدارهایی مثل کد زبان است: یا دقیقاً همان مقدار، یا همان مقدار با یک خط تیره بعدش، مثل fa و fa-IR. این انتخابگرها وقتی مفیدند که نخواهید برای هر حالت یک کلاس تازه در HTML اضافه کنید و اطلاعات از قبل در ویژگی‌ها وجود داشته باشد.

انتخابگر یعنی عنصرهایی که ...
[target] ویژگی target دارند (مقدارش مهم نیست)
[type="text"] مقدار ویژگی‌شان دقیقاً text است
[href^="https"] مقدارشان با https شروع می‌شود
[href$=".pdf"] مقدارشان با ‎.pdf تمام می‌شود
[class*="btn"] مقدارشان کلمه btn را جایی داخلش دارد
[title~="new"] در مقدارشان کلمه جداگانه new هست (بین کلمه‌ها فاصله باشد)
[lang|="fa"] مقدارشان دقیقاً fa است یا با fa- شروع می‌شود (مثل fa-IR)

انتخابگر ویژگی را می‌شود با تگ و کلاس ترکیب کرد (a.btn[target="_blank"]). اگر بعد از مقدار حرف i بگذارید، بزرگی و کوچکی حروف مهم نیست: a[href$=".pdf" i] هم .pdf را می‌گیرد و هم .PDF را.

مثال ۱: لینک‌هایی که در تب جدید باز می‌شوند

ویژگی target="_blank" یعنی لینک در تب تازه باز شود و صفحه فعلی سر جایش بماند. با انتخابگر [target="_blank"] فقط همین لینک‌ها را پیدا می‌کنیم و با ::after یک علامت به انتهای متنشان اضافه می‌کنیم تا کاربر قبل از کلیک بداند به تب دیگری می‌رود. 

a[target="_blank"]::after {
  content: " ↗";
}

لینک داخلی

مستندات MDN (تب جدید)

مثال ۲: ظاهر متفاوت برای هر نوع input

input[type="text"]     { border: 2px solid #1a5fb4; }
input[type="password"] { border: 2px solid #c92a2a; }
input[type="email"]    { border: 2px solid #2b8a3e; }

مثال ۳: آیکون بر اساس نوع فایل

a[href$=".pdf"]::before { content: "📄 "; }
a[href$=".zip"]::before { content: "🗜️ "; }
a[href^="mailto:"]::before { content: "✉️ "; }

دو لینک اول فقط نمونه‌اند و در این جزوه فایلی دانلود نمی‌کنند؛ آیکون‌ها فقط از روی پسوند انتهای href اضافه شده‌اند.

نکته کاربردی: کنار نام لینک دانلود، نوع فایل را هم بنویسید (مثل «PDF») تا کاربر قبل از کلیک بداند چه چیزی دریافت می‌کند؛ آیکونی که CSS اضافه می‌کند برای صفحه‌خوان‌ها همیشه خوانده نمی‌شود.

مثال ۴: *= و ~=

[class*="btn"]  { padding: 6px 14px; border-radius: 4px; }  /* btn-red، btn-green، ... */
[title~="new"]  { outline: 2px dashed orange; }
btn-red btn-green btn-blue

فقط عکس اول کادر نارنجی دارد، چون در title آن کلمه جداگانه new آمده است.

اشتباه رایج: [class*="btn"] هر کلاسی را که حروف btn جایی داخلش باشد می‌گیرد؛ مثلاً submit-btn-wrapper یا dd-btn را هم. اگر منظورتان کلاس‌هایی است که با btn- شروع می‌شوند، دقیق‌تر بنویسید: [class^="btn-"] (و اگر فقط یک کلاس مشخص می‌خواهید، همان .btn ساده‌تر و بهتر است).

اشتباه رایج: جا انداختن علامت نقل قول برای مقدارهایی که فاصله، نقطه یا علامت دارند؛ [href$=.pdf] نامعتبر است و کل قانون نادیده گرفته می‌شود. عادت کنید همیشه مقدار را داخل " " بنویسید: [href$=".pdf"].

تمرین: همه inputهایی که required دارند را با input[required] انتخاب کنید و حاشیه نارنجی بدهید.
