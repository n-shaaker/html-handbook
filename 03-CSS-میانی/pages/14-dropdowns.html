۱۴) منوی کشویی (Dropdowns)

منوی کشویی فهرستی است که در حالت عادی پنهان است و با تعامل کاربر زیر یک دکمه یا لینک باز می‌شود. ساختن آن چهار رفتار را کنار هم می‌گذارد که در درس‌های قبلی آمده‌اند. ظرف منو position: relative می‌گیرد تا مرجع جای منوی باز باشد. خود فهرست بازشونده اول display: none است و هنگام باز شدن display: block می‌شود. همان فهرست position: absolute دارد تا از جریان صفحه خارج شود و روی محتوای زیرش بنشیند، نه اینکه بقیه صفحه را به پایین هل بدهد. z-index آن را بالای محتوای معمولی نگه می‌دارد. باز شدن هم با :hover برای ماوس و با :focus-within برای صفحه‌کلید انجام می‌شود، تا کاربری که با Tab حرکت می‌کند هم بتواند به لینک‌های داخل منو برسد.

مثال ۱: منوی «دسته‌بندی‌ها» در یک فروشگاه

<div class="dropdown">
  <button type="button">دسته‌بندی‌ها ▾</button>
  <div class="dropdown-content">
    <a href="books.html">کتاب</a>
    <a href="stationery.html">لوازم تحریر</a>
    <a href="games.html">بازی</a>
  </div>
</div>
.dropdown {
  position: relative;      /* مرجع برای منوی بازشونده */
  display: inline-block;   /* هم‌عرض دکمه شود، نه کل خط */
}

.dropdown-content {
  display: none;           /* اول پنهان */
  position: absolute;      /* زیر دکمه، روی بقیه محتوا */
  right: 0;                /* در صفحه راست‌چین، از لبه راست دکمه باز شود */
  min-width: 160px;
  background-color: white;
  box-shadow: 0 8px 16px rgba(0, 0, 0, 0.2);
  z-index: 10;
}

.dropdown-content a {
  display: block;          /* هر لینک یک ردیف کامل و قابل کلیک */
  padding: 10px 14px;
}

.dropdown:hover .dropdown-content,
.dropdown:focus-within .dropdown-content {
  display: block;          /* با ماوس یا با Tab ظاهر شود */
}
کتاب لوازم تحریر بازی

:focus-within یعنی «وقتی خود عنصر یا یکی از فرزندانش فوکوس دارد». با آن، کاربری که با کلید Tab روی دکمه می‌رود هم منو را می‌بیند و می‌تواند بین لینک‌ها حرکت کند. منویی که فقط با :hover باز شود، برای کاربران کیبورد غیرقابل استفاده است.

مثال ۲: منوی کشویی داخل نوار منو

همان سه کلاس، این بار روی یکی از liهای نوار منوی درس ۱۳:

.bar > li { display: inline-block; }

.bar > li.dropdown { position: relative; }

.bar > li:hover > a,
.bar > li:focus-within > a {
  background-color: #0f2740;   /* آیتم والد هم پررنگ بماند */
}

مثال ۳: کارت اطلاعات با hover روی تصویر پروفایل

Dropdown فقط برای لینک نیست؛ هر محتوایی را می‌شود این‌طور نمایش داد. tabindex="0" باعث می‌شود با Tab هم بشود به آن رسید:

.profile:hover .info,
.profile:focus-within .info {
  display: block;
}
سارا محمدی

طراح وب — شیراز

جهت باز شدن منو را با right: 0 یا left: 0 روی .dropdown-content تعیین می‌کنید. در سایت راست‌چین معمولاً right: 0 درست است (منو از لبه راست دکمه به سمت چپ باز می‌شود). ولی برای دکمه‌ای که در انتهای چپ نوار است (مثل «حساب کاربری»)، left: 0 بگذارید تا منو از صفحه بیرون نزند.

اشتباه رایج: فراموش کردن z-index؛ منوی باز شده زیر محتوای بعدی صفحه پنهان می‌شود.

اشتباه رایج: overflow: hidden روی نوار منو یا یکی از پدرها؛ منوی کشویی که از لبه پدر بیرون می‌زند بریده و ناپدید می‌شود. همچنین اگر بین دکمه و منو فاصله (margin-top) بگذارید، تا ماوس از آن فاصله رد شود hover قطع می‌شود و منو بسته می‌شود.

تمرین: یک دکمه «حساب کاربری ▾» در انتهای چپ یک نوار منو بسازید که با hover و با Tab گزینه‌های «پروفایل»، «سفارش‌های من» و «خروج» را نشان دهد و منو از لبه چپ دکمه باز شود.
