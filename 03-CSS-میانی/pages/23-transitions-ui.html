۲۳) Transition در UI (منو و فوکوس)

در UI واقعی transition را روی لینک منو، فوکوس کیبورد و منوی کشویی می‌گذارید.

مثال ۱: لینک منو + focus-visible

خانه منو تماس 
.nav-link {
  border-bottom: 2px solid transparent;
  transition: color 0.2s, border-color 0.2s;
}
.nav-link:hover,
.nav-link:focus-visible {
  color: #0b6e4f;
  border-color: #0b6e4f;
}

مثال ۲: دراپ‌داون نرم

پیش‌غذا غذای اصلی دسر

با opacity + visibility + transform منو نرم باز می‌شود. برای a11y کامل بعداً JS لازم است.

اشتباه: transition روی display کار نمی‌کند.

تمرین: کارت محصول با hover و translateY ملایم بسازید.
