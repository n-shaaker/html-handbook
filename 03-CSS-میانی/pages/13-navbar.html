۱۳) نوار منو (Navigation Bar)

بعداً قوی‌تر: منوی حرفه‌ای را با Flexbox بسازید. اینجا با display آشنا می‌شوید.

نوار منو در HTML یک فهرست از لینک‌هاست. آن را با ul و li می‌سازیم و داخل nav می‌گذاریم تا مرورگر و صفحه‌خوان بفهمند این بخش برای رفتن بین صفحه‌هاست. فهرست به‌طور پیش‌فرض علامت گلوله و فاصله داخلی دارد و آیتم‌هایش زیر هم می‌آیند. برای ساختن منو، اول این ظاهر پیش‌فرض را برمی‌داریم و بعد با display تصمیم می‌گیریم آیتم‌ها عمودی بمانند یا در یک ردیف کنار هم بنشینند. کلاس active صفحه فعلی را نشان می‌دهد. ویژگی aria-current="page" همان اطلاع را به صفحه‌خوان می‌دهد، چون کلاس CSS به‌تنهایی برای نرم‌افزار خواندن صفحه معنی خاصی ندارد. ساختار HTML همه مثال‌های این درس یکی است: 

<nav aria-label="منوی اصلی">
  <ul>
    <li><a class="active" href="index.html" aria-current="page">خانه</a></li>
    <li><a href="news.html">اخبار</a></li>
    <li><a href="contact.html">تماس</a></li>
    <li><a href="about.html">درباره ما</a></li>
  </ul>
</nav>

قدم اول: حذف ظاهر پیش‌فرض فهرست

ul {
  list-style-type: none;  /* بدون نقطه */
  margin: 0;
  padding: 0;             /* فاصله پیش‌فرض (در صفحه راست‌چین، سمت راست) حذف شود */
}

مثال ۱: منوی عمودی (کناری)

ul { width: 200px; background-color: #f1f1f1; }

li a {
  display: block;          /* کل ردیف قابل کلیک شود */
  padding: 8px 16px;
  text-decoration: none;
  color: #000;
}

li a:hover   { background-color: #555; color: white; }
li a.active  { background-color: #0b6e4f; color: white; }

مثال ۲: منوی افقی با inline-block

اگر دقت کنید، بین آیتم‌ها شکاف باریکی هست؛ این همان فاصله ناخواسته inline-block است (درس ۷). مثال ۴ راه حل امروزی را نشان می‌دهد.

مثال ۳: منوی افقی با float و یک آیتم در سمت مقابل (روش قدیمی)

این روش را در قالب‌های قدیمی زیاد می‌بینید؛ بدانید چطور کار می‌کند، ولی برای پروژه جدید از مثال ۴ استفاده کنید.

ul { overflow: hidden; }       /* پدر جمع نشود */
li { float: right; }
li.left { float: left; }        /* «ورود» به سمت دیگر برود */

اشتباه رایج: overflow: hidden روی منو، هر زیرمنوی کشویی را هم می‌بُرد (درس ۱۴)؛ این یکی از دلایلی است که روش float برای منو کنار گذاشته شده.

مثال ۴: نوار منوی فروشگاه با Flexbox (روش امروزی)

لوگو در سمت راست، لینک‌ها کنارش و سبد خرید با نشان تعداد در سمت چپ. margin-right: auto روی آیتم آخر، همه فضای خالی را سمت راستش می‌گذارد و آن را به انتهای چپ نوار هل می‌دهد. 

.shop-nav {
  display: flex;
  align-items: center;     /* هم‌ترازی عمودی لوگو و لینک‌ها */
  gap: 4px;                /* فاصله بدون مشکل inline-block */
  flex-wrap: wrap;         /* در صفحه باریک به خط بعد برود */
}

.shop-nav .cart {
  margin-right: auto;      /* در صفحه راست‌چین، به انتهای چپ نوار برود */
}

.cart-count {
  padding: 0 7px;
  border-radius: 10px;     /* نشان گرد کنار متن */
  background-color: #e8590c;
  font-size: 12px;
}

برای اینکه منو هنگام اسکرول بالای صفحه بماند (هدر چسبان)، کافی است به نوار position: sticky، top: 0 و z-index: 100 بدهید (درس‌های ۳ و ۴).

مثال ۵: منوی تب‌مانند با خط زیر

خط زیر تب را با border-bottom می‌سازیم. اگر این خط فقط هنگام hover ظاهر شود، ارتفاع لینک یک‌باره زیاد می‌شود و منو می‌پرد. برای جلوگیری از آن پرش، از اول حاشیه‌ای به همان ضخامت و با رنگ transparent می‌گذاریم و در hover فقط رنگش را عوض می‌کنیم. جا از قبل رزرو شده و بقیه آیتم‌ها تکان نمی‌خورند. 

li a {
  border-bottom: 3px solid transparent;  /* از اول جای خط را نگه دارد تا هنگام hover چیزی تکان نخورد */
}

li a:hover,
li a.active {
  border-bottom-color: #e8590c;
  color: #e8590c;
}

مثال ۶: منوی دکمه‌ای (گرد)

اگر به‌جای نوار یکپارچه، هر لینک باید مثل دکمه جدا دیده شود، به خود لینک حاشیه و border-radius بزرگ می‌دهیم. وقتی شعاع گردی از نصف ارتفاع لینک بیشتر باشد، دو سر لینک نیم‌دایره می‌شوند و شکل کپسول به دست می‌آید. inline-block روی li هم آیتم‌ها را در یک ردیف کنار هم می‌نشاند. 

li { display: inline-block; }

li a {
  display: block;
  padding: 8px 20px;
  border: 1px solid #1a5fb4;
  border-radius: 20px;     /* گوشه‌های کاملاً گرد */
  margin-left: 6px;
}

li a.active { background-color: #1a5fb4; color: white; }

کلاس active نشان می‌دهد کاربر الان در کدام صفحه است. در هر صفحه، آن کلاس را روی لینک همان صفحه بگذارید و ویژگی aria-current="page" را هم اضافه کنید تا صفحه‌خوان‌ها هم صفحه فعلی را اعلام کنند.

اشتباه رایج: padding را به li می‌دهیم به‌جای a. در این صورت فقط روی خود متن می‌شود کلیک کرد، نه کل دکمه.

اشتباه رایج: فقط برای :hover استایل می‌نویسیم. کاربری که با کیبورد (Tab) حرکت می‌کند hover ندارد؛ همان استایل را برای :focus-visible هم بنویسید: li a:hover, li a:focus-visible { ... }

تمرین: برای صفحه معرفی‌تان یک منوی افقی با Flexbox و چهار لینک بسازید که لینک فعال رنگ متفاوتی داشته باشد و یک دکمه «تماس با من» در انتهای دیگر نوار قرار بگیرد.
