۲۵) تمرین جمع‌بندی: ظاهر دادن به صفحه معرفی شخصی

در این تمرین، صفحه معرفی جلسه‌های HTML را با CSS خارجی کامل می‌کنید. بخش اول ظاهر پایه را می‌سازد: فونت، رنگ، تصویر، لینک و جدول. بخش دوم رفتارهای این دوره را به همان صفحه اضافه می‌کند: منوی چسبان، زیرمنو، چیدمان دو ستونه، فرم و اندازه واکنش‌گرا. هر مرحله را جدا در مرورگر ببینید و در پایان، صفحه را فقط با کلید Tab طی کنید تا حلقه فوکوس هیچ لینک و دکمه‌ای پنهان نماند.

بخش اول: مباحث دوره مقدماتی

  1. یک پوشه css بسازید و فایل‌های CSS را داخلش بگذارید (مثل همین پروژه).
  2. با تگ link فایل‌ها را به صفحه HTML وصل کنید.
  3. برای body فونت Tahoma، رنگ پس‌زمینه روشن و line-height: 1.8 بگذارید.
  4. به h1 و h2 رنگ و یک border-bottom بدهید.
  5. عکس پروفایل را با border-radius: 50% دایره‌ای کنید.
  6. لینک‌ها را بدون خط زیر و با رنگ متفاوت در حالت :hover بنویسید.
  7. جدول پروژه‌ها را با border-collapse و ردیف‌های راه‌راه مرتب کنید.

بخش دوم: مباحث این دوره (درس‌های ۱ تا ۲۰)

  1. محتوای صفحه را با max-width: 900px و margin: 0 auto وسط صفحه بیاورید.
  2. یک منوی افقی داخل nav بالای صفحه بسازید (ul + display: flex)، لینک فعال را با کلاس active مشخص کنید و منو را با position: sticky بالای صفحه نگه دارید.
  3. یکی از آیتم‌های منو را کشویی کنید (مثلاً «نمونه‌کارها ▾») و مطمئن شوید با :focus-within از کیبورد هم باز می‌شود.
  4. بخش «مهارت‌ها» را با برچسب‌های inline-block و یک نوار پیشرفت درصدی بسازید.
  5. چیدمان دو ستونه بسازید: محتوا ۷۰٪ و ستون کناری ۳۰٪ (با display: flex).
  6. روی عکس پروفایل با position: absolute یک نشان کوچک «آنلاین» بگذارید.
  7. یک فرم «تماس با من» با label برای هر کادر، کادرهای تمام‌عرض، حالت :focus واضح و دکمه رنگی بسازید.
  8. تیتر اصلی را با clamp() واکنش‌گرا کنید.
  9. با ::after یک خط تزئینی زیر تیترهای h2 بکشید.
  10. یک دکمه «بالای صفحه» با position: fixed اضافه کنید.
  11. در پایان، کل صفحه را فقط با کلید Tab پیمایش کنید: همه لینک‌ها و دکمه‌ها باید حلقه فوکوس واضح داشته باشند.

یک شروع نمونه برای فایل CSS

body {
  font-family: Tahoma, Arial, sans-serif;
  background-color: #f7f9fc;
  color: #222;
  line-height: 1.8;
  margin: 0;
}

.wrapper {
  max-width: 900px;
  margin: 0 auto;
  padding: 0 16px;
}

/* منو */
.menu {
  display: flex;
  flex-wrap: wrap;
  list-style-type: none;
  margin: 0;
  padding: 0;
  background-color: #1a3a5c;
}

.site-nav {
  position: sticky;   /* منو هنگام اسکرول بالای صفحه بماند */
  top: 0;
  z-index: 100;
}

.menu a {
  display: block;
  color: white;
  padding: 12px 16px;
  text-decoration: none;
}

.menu a:hover,
.menu a:focus-visible,
.menu a.active { background-color: #0b6e4f; }

/* تیتر */
h1 { font-size: clamp(24px, 5vw, 44px); }

h2::after {
  content: "";
  display: block;
  width: 50px;
  height: 3px;
  background-color: #0b6e4f;
  margin-top: 6px;
}

/* دو ستون */
.row   { display: flex; gap: 20px; }
main   { flex: 7; }   /* حدود ۷۰٪ */
aside  { flex: 3; }   /* حدود ۳۰٪ */

/* عکس پروفایل با نشان آنلاین */
.avatar-box { position: relative; display: inline-block; }

.avatar-box img {
  width: 160px;
  height: 160px;
  border-radius: 50%;
  object-fit: cover;
}

.online {
  position: absolute;
  bottom: 10px;
  left: 10px;
  width: 22px;
  height: 22px;
  background-color: #2b8a3e;
  border: 3px solid white;
  border-radius: 50%;
}

/* موبایل: ستون‌ها زیر هم */
@media (max-width: 600px) {
  .row { flex-direction: column; }
}

برای مرور مباحث «اولویت قوانین (Specificity)» و «!important» به مجموعه آبشاری بودن CSS سر بزنید.
