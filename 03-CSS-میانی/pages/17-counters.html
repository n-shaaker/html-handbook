۱۷) شمارنده‌ها (Counters)

شمارنده CSS متغیری عددی است که مرورگر خودش آن را کم و زیاد می‌کند و ما فقط نام و محل نمایشش را تعیین می‌کنیم. ساختن شماره سه مرحله دارد. counter-reset را روی عنصر والد می‌نویسیم تا شمارنده‌ای با یک نام ساخته شود و معمولاً از صفر شروع کند. counter-increment را روی هر آیتمی می‌نویسیم که باید شماره بگیرد؛ هر بار که مرورگر به آن عنصر می‌رسد یکی به شمارنده اضافه می‌کند، پس اولین آیتم عدد ۱ را نشان می‌دهد. برای نمایش عدد، در ::before یا ::after می‌نویسیم content: counter(نام). تابع counter() مقدار فعلی را به متن تبدیل می‌کند. اگر reset و increment هر دو روی یک عنصر باشند، مرورگر اول reset را انجام می‌دهد و بعد increment را؛ برای همین معمولاً reset را روی پدر می‌گذاریم تا هر فرزند فقط یکی اضافه کند.

دستور کار
counter-reset: نام; شمارنده را می‌سازد و روی صفر می‌گذارد (روی پدر)؛ با counter-reset: نام 4; از ۴ شروع می‌شود
counter-increment: نام; هر بار یکی اضافه می‌کند (روی هر آیتم)؛ پس اولین آیتم شماره ۱ می‌گیرد
content: counter(نام); عدد را نمایش می‌دهد (داخل ::before)

مثال ۱: شماره‌گذاری خودکار تیترها

در یک صفحه واقعی شمارنده را روی body یا ظرف مقاله می‌سازیم (در این نمونه روی ظرف مثال):

body { counter-reset: section; }

h4::before {
  counter-increment: section;
  content: "بخش " counter(section) ": ";
}

مثال ۲: مراحل یک دستور پخت (دایره‌های شماره‌دار)

چون ترتیب مراحل مهم است، در HTML از ol استفاده می‌کنیم و فقط شماره پیش‌فرض را با list-style-type: none برمی‌داریم:

.steps { counter-reset: step; list-style-type: none; padding: 0; }

.steps li { counter-increment: step; }

.steps li::before {
  content: counter(step);
  display: inline-block;
  width: 28px;
  height: 28px;
  line-height: 28px;    /* عدد وسط عمودی دایره */
  border-radius: 50%;
  background: #e8590c;
  color: white;
  text-align: center;
  margin-left: 10px;    /* فاصله دایره تا متن (در صفحه راست‌چین، سمت چپ دایره) */
}

مثال ۳: شماره‌گذاری تودرتو (۱.۱، ۱.۲، ...)

برای شماره دوتکه، دو شمارنده جدا لازم است. شمارنده main روی کل کتاب صفر می‌شود و هر فصل یکی به آن اضافه می‌کند. شمارنده sub روی خود فصل صفر می‌شود تا هر فصل از ۱٫۱ شروع کند، نه اینکه شماره زیربخش در فصل بعد ادامه پیدا کند. در content می‌توان چند مقدار را کنار هم نوشت: متن ثابت، counter(main)، یک نقطه، و counter(sub). 

.book          { counter-reset: main; }
.chapter       { counter-reset: sub; }
.chapter h4::before { counter-increment: main; content: counter(main) ". "; }
.chapter p::before  { counter-increment: sub;  content: counter(main) "." counter(sub) " "; }

مدل جعبه‌ای

برای فهرست‌های تودرتو با عمق نامعلوم، تابع counters() (با s) همه سطح‌ها را خودش کنار هم می‌گذارد: content: counters(item, ".") " "; که خروجی‌اش مثل 1.2.3 است.

مثال ۴: شمارش با اعداد فارسی

شمارنده‌ها به‌طور پیش‌فرض با رقم‌های لاتین (1، 2، 3) نمایش داده می‌شوند (مثل مثال‌های بالا). با نوشتن سبک persian به‌عنوان آرگومان دوم، رقم‌ها فارسی می‌شوند: 

.fa-num li::before {
  content: counter(item, persian) "- ";   /* ۱- ، ۲- ، ۳- */
}

اشتباه رایج: گذاشتن counter-reset روی خود آیتم‌ها به‌جای پدر؛ در این حالت همه آیتم‌ها شماره ۱ می‌گیرند.

اشتباه رایج: نوشتن counter-increment روی عنصری که display: none دارد؛ عنصر پنهان شمرده نمی‌شود. همچنین نام شمارنده در هر سه دستور باید دقیقاً یکی باشد (step با steps فرق دارد).

تمرین: یک صفحه «سؤالات متداول» بسازید که سؤال‌ها خودکار با «سؤال ۱:»، «سؤال ۲:» و ... شماره بخورند.
