## ۱) شروع کلاس؛ مسئله واقعی سایت

«بچه‌ها، پایین صفحه «درباره ما» یک ردیف **مهارت** می‌خواهیم: طراحی وب، فتوشاپ، تایپ، زبان، کار تیمی. هر کدام یک قرص کوچک با padding و گوشه گرد، همه در یک خط، و اگر جا کم شد بروند خط بعد.

دیروز برای عکس مقاله از `float` استفاده کردیم. اینجا عکس نیست و متنی دور چیزی نمی‌پیچد. اگر هر برچسب را `float: right` کنیم، باید دوباره حواسمان به پدر جمع‌شده و `clear` باشد. برای پنج تا کلمه‌ی کوتاه، float ابزار اشتباهی است.

ابزار نزدیک‌تر، `display` است. یادتان هست روی `span` معمولی `width` و `height` اثر مورد انتظار را نداشت؟»

فایل زنده (پیشنهاد: `تدریس/live/07-inline-block.html`):

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — inline-block</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      padding: 1.5rem;
      background: #f8fafc;
      line-height: 1.7;
    }
    .tag {
      width: 120px;
      height: 40px;
      padding: 4px 12px;
      background: #e0f2fe;
      border-radius: 20px;
    }
  </style>
</head>
<body>
  <p>
    مهارت‌ها:
    <span class="tag">طراحی وب</span>
    <span class="tag">فتوشاپ</span>
    <span class="tag">تایپ سریع</span>
  </p>
</body>
</html>
```

**در مرورگر:** هر سه `span` در متن نشسته‌اند، ولی عرض ۱۲۰ و ارتفاع ۴۰ دیده نمی‌شود. padding چپ و راست کمی فضا می‌دهد؛ padding بالا و پایین ممکن است روی خط‌های مجاور بریزد، بدون اینکه جعبه را آن‌طور که برای یک دکمه انتظار داریم بزرگ کند. این همان inline است.

«پس مسئله سایت این است: عنصر در **همان خط** بماند، خط را نشکند، و در عین حال مثل block بشود به آن اندازه و padding داد.»

### سؤال کلاسی

- «اگر به‌جای `span` از `div` خالی استفاده کنیم، بدون تغییر `display`، برچسب‌ها کنار هم می‌آیند؟»  
  **پاسخ:** `div` به‌صورت پیش‌فرض block است و هر کدام خط تازه می‌گیرد.

## ۲) سه مقدار کنار هم — inline، inline-block، block

«`inline-block` رفتار دو حالت قبلی را با هم ترکیب می‌کند.

- مثل **inline**: در همان خط کنار بقیه می‌نشیند و خط را به‌خاطر خودش نمی‌شکند.  
- مثل **block**: `width`، `height` و padding هر چهار طرف روی آن اثر واقعی دارند و جعبه را بزرگ می‌کنند.

جزوه هر سه را با یک کلاس اندازه مقایسه می‌کند. همان را زنده بساز تا تفاوت حدس نباشد.»

```html
<p>inline: متن <span class="s a">جعبه</span> <span class="s a">جعبه</span> ادامه متن</p>
<p>inline-block: متن <span class="s b">جعبه</span> <span class="s b">جعبه</span> ادامه متن</p>
<p>block: متن <span class="s c">جعبه</span> <span class="s c">جعبه</span> ادامه متن</p>
```

```css
.s {
  width: 100px;
  height: 50px;
  padding: 10px;
  background: #fde68a;
  border: 1px solid #b45309;
}

.a { display: inline; }
.b { display: inline-block; }
.c { display: block; }
```

**در مرورگر:** ردیف اول جعبه‌ها به اندازه متن «جعبه» می‌مانند؛ ۱۰۰ در ۵۰ اعمال نمی‌شود. ردیف دوم دو جعبه ۱۰۰×۵۰ در همان خط، بین کلمات. ردیف سوم هر جعبه تمام عرض را می‌گیرد و جمله را تکه‌تکه می‌کند.

«این سه خط را در صفحه جزوه [`07-inline-block.html`](../../pages/07-inline-block.html) هم ببینید. قانون را از حفظ نخوانید؛ با چشم بگویید کدام ردیف اندازه دارد و کدام ردیف خط را شکسته.»

حالا همان `.tag` ابتدای کلاس را درست کن:

```css
.tag {
  display: inline-block;
  padding: 4px 12px;
  margin: 4px;
  background: #e0f2fe;
  border-radius: 20px;
}
```

«برای برچسب مهارت، `width` ثابت لازم نیست. متن کوتاه و بلند هر کدام به اندازه خودشان جا می‌گیرند، padding افقی قرص را پهن می‌کند، و `inline-block` اجازه می‌دهد padding عمودی واقعاً به ارتفاع قرص اضافه شود. `border-radius: 20px` گوشه را گرد می‌کند. این مثال ۲ جزوه است.»

**در مرورگر:** پنج برچسب در یک یا دو خط، با فاصله ۴ پیکسل از `margin`. اگر پنجره را باریک کنی، برچسب بعدی به خط بعد می‌رود، بدون clear و بدون float.

### سؤال کلاسی

- «روی `.tag` اگر `display` را برنداریم و فقط `width: 120px` بگذاریم، عرض ثابت می‌شود؟»  
  **پاسخ:** فقط وقتی `display` برابر `inline-block` (یا block) باشد. روی inline پیش‌فرض `span`، آن عرض اعمال نمی‌شود.

- «چرا اینجا `float` نگذاشتیم؟»  
  **پاسخ:** نمی‌خواهیم عنصر از جریان خارج شود و متن دورش بپیچد. می‌خواهیم در خط بماند و جعبه اندازه داشته باشد.

### اشتباهات رایج

- `display: block` روی برچسب، به امید اینکه «اندازه کار کند». اندازه کار می‌کند و هر برچسب یک خط کامل می‌شود.  
- `height` ثابت روی برچسبی که متنش ممکن است دو کلمه شود. اگر متن نیاید داخل ارتفاع، سرریز می‌شود. برای قرص مهارت، ارتفاع را به padding و خط بسپار.

## ۳) دکمه‌های منو — ناحیه کلیک بزرگ در همان ردیف

«لینک داخل منو به‌صورت پیش‌فرض inline است. اگر فقط رنگ پس‌زمینه بدهی، ناحیه کلیک به اندازه خود کلمات است و padding بالا و پایین رفتار دلخواه دکمه را ندارد.

`inline-block` لینک را به دکمه نواری تبدیل می‌کند: هنوز کنار لینک بعدی می‌نشیند، ولی `padding: 10px 20px` هر چهار طرف را واقعی می‌کند.»

```html
<nav class="menu">
  <a href="#home">خانه</a>
  <a href="#learn">آموزش‌ها</a>
  <a href="#blog">وبلاگ</a>
  <a href="#contact">تماس</a>
</nav>
```

```css
.menu a {
  display: inline-block;
  padding: 10px 20px;
  background: #166534;
  color: #fff;
  text-decoration: none;
}

.menu a:hover {
  background: #14532d;
}
```

**در مرورگر:** چهار دکمه سبز در یک ردیف. نشانگر را روی فاصله بین دکمه‌ها ببر. یک شکاف باریک هست که سبز نیست و hover هم نمی‌گیرد. جزوه در مثال ۳ همین شکاف را گفته. علتش را بخش بعد باز می‌کنیم؛ الان فقط ببینند و اسم بگذارند: «فاصله بین inline-blockها».

«`:hover` را کامل درس شبه‌کلاس‌ها توضیح می‌دهد. اینجا فقط کافی است پس‌زمینه عوض شود تا ناحیه کلیک دیده شود.»

### سؤال کلاسی

- «اگر `padding` را زیاد کنیم و عرض صفحه کم باشد، چه می‌شود؟»  
  **پاسخ:** لینک‌هایی که جا نشوند به خط بعد می‌روند. منو نمی‌شکند به معنی خراب شدن صفحه؛ فقط می‌پیچد. برای منوی حرفه‌ای که همیشه یک ردیف بماند، بعداً flex و در صورت نیاز منوی جمع‌شونده می‌آید.

### انتقال

«آن شکاف باریک بین سبزها باگ padding نیست. از HTML می‌آید.»

## ۴) فاصله چندپیکسلی — کاراکتر فاصله بین تگ‌ها

«بین عنصرهای inline و inline-block، فاصله‌ها و خط‌جدیدهای فایل HTML مثل فاصله بین کلمه‌های یک جمله حساب می‌شوند. مرورگر حدود چند پیکسل (اغلب نزدیک ۴ پیکسل، بسته به اندازه قلم) بین دو جعبه خالی می‌گذارد.

CSS مقصر نیست. این کد:

```html
<a href="#">خانه</a>
<a href="#">آموزش‌ها</a>
```

بین `</a>` و `<a>` بعدی یک newline دارد. همان newline یک فاصله متنی است.»

زنده ثابت کن. اول منو را در **یک خط**، بدون هیچ فاصله‌ای بین تگ‌ها، ذخیره کن:

```html
<nav class="menu"><a href="#home">خانه</a><a href="#learn">آموزش‌ها</a><a href="#blog">وبلاگ</a><a href="#contact">تماس</a></nav>
```

**در مرورگر:** شکاف باریک بین پس‌زمینه‌ها می‌رود. بعد فایل را دوباره خوانا کن و newline را برگردان تا شکاف برگردد.

«جزوه صریح می‌گوید: حذف فاصله‌ها از HTML کد را ناخوانا می‌کند. این راه حل کلاس ما نیست. راه تمیز این است که پدر را `display: flex` کنیم و فاصله را خودمان با `gap` بدهیم. Flex را این جلسه عمیق نمی‌خوانیم؛ فقط همین تعویض را ببینید تا بدانید شکاف، سرنوشت inline-block است و درمانش چسباندن تگ‌ها به هم نیست.»

```css
.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 0;
}

.menu a {
  display: block;
  padding: 10px 20px;
  background: #166534;
  color: #fff;
  text-decoration: none;
}
```

**در مرورگر:** با `gap: 0` دکمه‌ها به هم چسبیده‌اند و newline داخل HTML دیگر شکاف نمی‌سازد. اگر طراحی بین دکمه‌ها ۸ پیکسل هوا بخواهد:

```css
.menu {
  gap: 8px;
}
```

«این ۸ پیکسل تصمیم توست، نه کاراکتر نامرئی فایل. برای منو، از همین‌جا flex را به‌عنوان روش ترجیحی معرفی کن. `inline-block` را برای جایی نگه دار که واقعاً تکه‌ای از جمله است: نشان کنار اسم، برچسب داخل پاراگراف.»

### سؤال کلاسی

- «شکاف بین دو `inline-block` را با `margin: 0` حذف می‌کنیم؟»  
  **پاسخ:** اگر آن شکاف از فاصله HTML باشد، `margin: 0` فقط حاشیه خود CSS را صفر می‌کند. فاصله متنی سر جایش می‌ماند.

- «چرا چسباندن همه تگ‌ها در یک خط را به‌عنوان استاندارد پروژه قبول نمی‌کنیم؟»  
  **پاسخ:** خواندن و ویرایش HTML سخت می‌شود، و با هر خط‌جدید اتفاقی شکاف برمی‌گردد. `flex` و `gap` فاصله را صریح می‌کنند.

### اشتباهات رایج

- منفی کردن `margin` (مثلاً `-4px`) برای «خوردن» فاصله HTML. با عوض شدن `font-size` پدر، عرض آن فاصله عوض می‌شود و عدد جادویی دیگر جور نیست.  
- `font-size: 0` روی پدر و برگرداندن فونت روی فرزند. کار می‌کند و کد را معمایی می‌کند. برای منو و ردیف، flex را نشان بده.

## ۵) کارت‌ها کنار هم و `vertical-align`

«مثال ۴ جزوه سه محصول را بدون float کنار هم گذاشته. این الگو را باید بشناسی، چون در قالب‌های قدیمی هست. برای ردیف کارت فروشگاه، باز هم flex ساده‌تر است؛ ولی علت کج شدن کارت‌ها را همین‌جا ببین.»

```html
<div class="shop">
  <div class="product"><strong>قهوه</strong><br>۸۰ هزار تومان</div>
  <div class="product"><strong>چای سبز</strong><br>۴۵ هزار تومان<br>(پرفروش)</div>
  <div class="product"><strong>کیک</strong><br>۶۰ هزار تومان</div>
</div>
```

اول عمداً بدون `vertical-align`:

```css
.product {
  display: inline-block;
  width: 150px;
  margin: 4px;
  padding: 8px;
  background: #fff;
  border: 1px solid #cbd5e1;
}
```

**در مرورگر:** کارت چای که سه خط است، بقیه را با خودش پایین می‌کشد. لبه‌های بالا هم‌تراز نیستند. پیش‌فرض `vertical-align` برای inline-block برابر `baseline` است: جعبه روی خط پایه متن می‌نشیند، نه روی سقف کارت.

«یک کلمه اضافه کن:»

```css
.product {
  display: inline-block;
  width: 150px;
  vertical-align: top;
  margin: 4px;
  padding: 8px;
  background: #fff;
  border: 1px solid #cbd5e1;
}
```

**در مرورگر:** لبه بالای هر سه کارت در یک راستا. ارتفاع‌ها هنوز برابر نیستند؛ چای بلندتر است. `vertical-align: top` هم‌قد نمی‌کند، فقط شروع کارت‌ها را بالا می‌چیند.

«اگر بخواهیم کف کارت‌ها هم یکی شود، inline-block این را رایگان نمی‌دهد. در flex، کش آمدن آیتم‌ها در محور متقاطع همان کار را می‌کند. امروز فقط اشاره کن و کارت‌ها را top-aligned رها کن. درس Flex جای هم‌قد کردن است.»

شکاف بین کارت‌ها را هم نشان بده: newline بین `</div>` و `<div>` بعدی. بگو این همان پدیده منو است، این‌بار بین کارت ۱۵۰ پیکسلی.

### سؤال کلاسی

- «`vertical-align: middle` روی یک `div` با `display: block` چه می‌کند؟»  
  **پاسخ:** در جریان بلوکی عادی اثری ندارد. `vertical-align` برای inline، inline-block و سلول جدول است. وسط‌چین جعبه block درس بعد است.

- «چرا کارت چای بلندتر است ولی عرض هر سه یکی است؟»  
  **پاسخ:** `width: 150px` عرض را قفل کرده. ارتفاع را محتوا تعیین می‌کند، چون `height` ننوشته‌ایم.

### اشتباهات رایج

- فرض اینکه inline-blockها مثل ستون‌های جدول خودبه‌خود هم‌قد می‌شوند.  
- `vertical-align: top` را روی پدر گذاشتن. این ویژگی روی خود جعبه‌های inline-block اثر دارد، نه به‌عنوان دستور «بچه‌ها را بچین» روی پدر.

## ۶) کِی inline-block، کِی flex

این جدول را روی تخته نگه دار:

| کار در سایت | انتخاب این جلسه |
|-------------|-----------------|
| برچسب داخل جمله یا ردیف مهارت | `inline-block` |
| نشان (badge) کنار عنوان | `inline-block` |
| دکمه تکی یا چند دکمه کوتاه | `inline-block` هنوز روشن و کافی است |
| منویی که شکاف و فاصله‌اش باید دقیق باشد | `display: flex` و `gap` |
| ردیف کارت محصول با ارتفاع‌های مختلف | flex؛ inline-block را فقط برای شناخت الگو |

«inline-block منسوخ نشده. برای قرص و نشان هنوز انتخاب خوبی است، چون آن عنصر جزئی از خط متن است. جایی که داری یک **ردیف از جعبه‌ها** می‌سازی و فاصله و هم‌ترازی برایت مهم است، پدر را flex کن. درس float را تکرار نکن: float مال پیچیدن متن دور تصویر بود.»

## ۷) پروژه جلسه — سه کارت سرویس

تمرین جزوه: سه کارت «سرویس» (طراحی، برنامه‌نویسی، پشتیبانی) با inline-block و عرض ۲۰۰ پیکسل. اول دقیقاً همان را بساز تا دانشجو ابزار درس را به کار ببرد. بعد همان پدر را flex کن و تفاوت شکاف را نشان بده.

### مرحله ۱ — خواسته جزوه

```html
<section class="services" aria-label="سرویس‌ها">
  <article class="service">
    <h2>طراحی</h2>
    <p>رابط ساده برای صفحه معرفی محصول.</p>
  </article>
  <article class="service">
    <h2>برنامه‌نویسی</h2>
    <p>پیاده‌سازی همان طرح با HTML و CSS.</p>
    <p>شامل یک دور اصلاح.</p>
  </article>
  <article class="service">
    <h2>پشتیبانی</h2>
    <p>پاسخ به پرسش‌های بعد از تحویل.</p>
  </article>
</section>
```

```css
.service {
  display: inline-block;
  width: 200px;
  vertical-align: top;
  margin: 8px;
  padding: 12px 14px;
  background: #fff;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}

.service h2 {
  margin: 0 0 8px;
  font-size: 1.1rem;
}

.service p {
  margin: 0 0 8px;
}
```

**در مرورگر:** کارت برنامه‌نویسی بلندتر است و لبه بالاها، به‌خاطر `vertical-align: top`، جفت‌اند. بین کارت‌ها هم `margin` هست و هم یک شکاف اضافه از newline. با DevTools عرض یکی از فاصله‌ها را نشان بده.

دانشجو را وادار کن قبل از مرحله ۲ پیش‌بینی کند: «اگر `vertical-align: top` را حذف کنم، کارت کوتاه نسبت به کارت بلند کجا می‌نشیند؟» حذف کن، ببینند، برگردان.

### مرحله ۲ — همان HTML با flex

```css
.services {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.service {
  display: block;
  width: 200px;
  margin: 0;
}
```

**در مرورگر:** newline دیگر شکاف اضافه نمی‌سازد. فاصله فقط ۱۶ پیکسل `gap` است. `vertical-align` را بردار؛ در flex لازم نیست. اگر `align-items` را پیش‌فرض رها کنی، کارت‌ها در ردیف کش می‌آیند و هم‌قد به نظر می‌رسند. بگو: «این رفتار را درس Flex باز می‌کند؛ امروز شاهدش باشید.»

«نسخه‌ای که تحویل تمرین جزوه است، مرحله ۱ است: inline-block، عرض ۲۰۰، `vertical-align: top`. مرحله ۲ را در کنارش نگه دار تا انتخاب ابزار را بلد باشند.»

### سؤال حین پروژه

- «چرا عرض را ۲۰۰ پیکسل دادیم نه `width: auto`؟»  
  **پاسخ:** خواسته تمرین کارت هم‌عرض است. بدون عرض، هر کارت به اندازه متنش جمع می‌شود و ردیف نامنظم می‌شود.

## ۸) جمع‌بندی مدرس و سؤالات پایانی

۱. `inline-block` کدام رفتار inline و کدام رفتار block را با هم دارد؟  
   **پاسخ راهنما:** در همان خط می‌ماند؛ `width`، `height` و padding چهار طرف روی اندازه جعبه اثر دارند.

۲. فاصله باریک بین دکمه‌های منو، با اینکه `margin` صفر است، از کجاست؟  
   **پاسخ راهنما:** از فاصله یا newline بین تگ‌ها در HTML. درمان خوانا برای ردیف: `display: flex` و `gap` روی پدر.

۳. سه کارت با محتوای نابرابر، لبه‌های بالایشان یکی نیست. کدام ویژگی روی خود inline-block این را درست می‌کند، و کدام کار را انجام نمی‌دهد؟  
   **پاسخ راهنما:** `vertical-align: top` شروع را هم‌تراز می‌کند. ارتفاع‌ها را برابر نمی‌کند.

**پیام پایانی:**

«هر وقت خواستی به یک تکه از خط، جعبه واقعی بدهی، `inline-block` سر جایش است. هر وقت دیدی بین آن جعبه‌ها شکاف مرموز است، اول HTML را نگاه کن، بعد برای ردیف‌های جدی پدر را flex کن. float را برای این کار برنگردان.»

## تمرین‌ها (ساده → چالشی)

### ساده

۱. سه `span` با متن «جدید»، «حراج»، «تمام‌شد» بساز. با `inline-block` و padding به آن‌ها شکل نشان بده.  
۲. همان سه مقدار `display` جزوه (`inline`، `inline-block`، `block`) را با `width: 100px` روی یک جمله تکرار کن و در یک خط بنویس کدام عرض را نشان داد.

### متوسط

۳. منوی چهار لینکی جزوه را با `inline-block` بساز، شکاف newline را در مرورگر نشان بده، بعد پدر را `flex` با `gap: 0` کن.  
۴. سه کارت محصول با عرض ۱۵۰ پیکسل: یکی را بدون `vertical-align` رها کن و یکی را با `top`. تفاوت را با یک جمله توضیح بده.

### چالشی

۵. سه کارت سرویس ۲۰۰ پیکسلی تمرین جزوه را کامل کن (مرحله ۱ پروژه). سپس فقط CSS پدر را به flex و `gap: 16px` عوض کن، بدون دست زدن به متن HTML.  
۶. یک جمله بساز که وسطش یک نشان قیمت با `inline-block` باشد. بعد نشان بده که اگر همان نشان `float` شود، بقیه جمله دور آن می‌پیچد و دیگر «یک کلمه از جمله» نیست.
