## ۱) شروع کلاس — دیالوگ

«بچه‌ها، فرض کنید روی کارت محصول می‌خواهید برچسب **«جدید»** گوشهٔ بالا بنشیند:

```css
.badge { top: -10px; left: -10px; }
```

اما badge **پایین صفحه** یا اصلاً جابه‌جا نمی‌شود.

یا می‌خواهید دکمه **«برو بالا»** همیشه گوشهٔ viewport باشد — با scroll حرکت نکند.

`top` / `left` **کافی نیست** — اول باید `position` را انتخاب کنیم. مرورگر می‌پرسد: **نسبت به چه مرجعی**؟

امروز [`03-position.html`](../../pages/03-position.html) — بدون invent مقادیر غیراستاندارد.»

---

## ۲) جدول position — speak through

| مقدار | خلاصه |
|--------|--------|
| `static` | پیش‌فرض — `top/left/z-index` **بی‌اثر** |
| `relative` | جابه‌جایی نسبت **جای عادی** — slot اولیه خالی می‌ماند |
| `absolute` | خارج از flow — مرجع: نزدیک‌ترین ancestor غیر static |
| `fixed` | مرجع viewport — scroll نمی‌خورد |
| `sticky` | hybrid — نیاز `top`/`bottom` — داخل والد scroll |

«`left`/`right` **فیزیکی** هستند — `dir=rtl` معنی‌شان را swap **نمی‌کند** (tip جزوه).»

## ۳) Live — relative (.moved)

```html
<div class="demo-pos">
  <div class="box">جعبه معمولی</div>
  <div class="box moved">relative</div>
  <div class="box">بعدی</div>
</div>
```

```css
.demo-pos .box {
  background-color: #e7f5ff;
  border: 1px solid #1a5fb4;
  padding: 8px;
  margin-bottom: 6px;
  width: 260px;
}

.demo-pos .moved {
  position: relative;
  top: 15px;
  right: 40px;
  background-color: #ffe3e3;
  border-color: #c92a2a;
}
```

**در مرورگر:** جعبه قرمز پایین‌تر و به چپ — **جعبه سوم** جای slot اول moved را **خالی نگه نداشته** — relative slot را حفظ می‌کند.

### سؤال کلاسی

«`top: 15px` یعنی؟»  
**پاسخ:** ۱۵px پایین‌تر از جای عادی.

«بدون `position: relative` روی `.moved`?»  
**پاسخ:** `top` بی‌اثر — static.

## ۴) Live — absolute badge

«الگوی فروشگاه: parent `relative`, child `absolute`.»

```css
.demo-pos .card {
  position: relative;
  display: inline-block;
  width: 220px;
  background: white;
  border: 1px solid #cfd8e3;
  border-radius: 8px;
  padding: 14px;
  margin: 12px 0 0 20px;
}

.demo-pos .badge {
  position: absolute;
  top: -10px;
  left: -10px;
  background-color: #2b8a3e;
  color: white;
  font-size: 12px;
  padding: 2px 10px;
  border-radius: 12px;
}

.demo-pos .badge.sale {
  background-color: #e8590c;
}
```

```html
<div class="card">
  <span class="badge">جدید</span>
  <strong>دوره CSS</strong>
  <p>توضیح کوتاه…</p>
</div>
```

**در مرورگر:** badge روی گوشه — بدون relative parent مرجع **بالاتر** یا viewport بود.

### سؤال کلاسی

«اگر `.card` relative نباشد؟»  
**پاسخ:** absolute تا ancestor positioned یا viewport.

## ۵) Live — sticky

```css
.demo-pos .scroll-area {
  height: 170px;
  overflow: auto;
  border: 1px solid #adb5bd;
  padding: 0 10px;
}

.demo-pos .sticky-title {
  position: sticky;
  top: 0;
  margin: 0;
  background-color: #1a3a5c;
  color: white;
  padding: 4px 8px;
}
```

HTML با پاراگراف‌های بلند داخل `.scroll-area`.

**در مرورگر:** scroll — title می‌چسبد.

«بدون `top: 0` sticky کار نمی‌کند — جزوه.»

---

## ۶) Live — fixed (.to-top)

```css
.to-top {
  position: fixed;
  bottom: 20px;
  left: 20px;
  width: 44px;
  height: 44px;
  line-height: 44px;
  text-align: center;
  background-color: #0b6e4f;
  color: white;
  text-decoration: none;
  border-radius: 50%;
}
```

```html
<a class="to-top" href="#top">↑</a>
```

**scroll صفحه** — دکمه ثابت.

«fixed از flow خارج — روی محتوا می‌افتد — z-index در درس بعد.»

## ۷) اشتباهات

| غلط | درست |
|-----|------|
| `top` بدون position | relative/absolute/... |
| absolute بدون relative parent | عمداً بد — یا bug |
| sticky بدون overflow context فکر | sticky در ancestor scroll |
| فکر RTL = swap left/right physics | tip جزوه |

## ۸) پروژه mini — دو card + badge

دو `.card` — یکی `badge` سبز «جدید»، یکی `.sale` نارنجی.

## ۹) جمع‌بندی

1. مرجع absolute?  
   **پاسخ:** nearest positioned ancestor.

2. relative flow?  
   **پاسخ:** بله — slot حفظ.

3. fixed vs sticky?  
   **پاسخ:** fixed viewport؛ sticky در scroll container والد.

---

## تمرین‌ها (ساده → چالشی)

### ساده
1. `.moved` — `top:0` — observe.  
2. badge `left` vs `right` — position on card.

### متوسط
3. sticky بدون top — broken.  
4. draw containing block for absolute badge.

### چالشی
5. card + absolute badge + **بدون** overflow hidden — badge outside card visible?  
6. چرا modal overlay often `fixed` full viewport?
