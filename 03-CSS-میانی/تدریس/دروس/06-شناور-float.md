## ۱) شروع کلاس؛ مسئله واقعی سایت

اول کلاس این‌طور شروع کن. هنوز اسم ویژگی را نگو:

«بچه‌ها، یک **صفحه خبر** باز کنید. بالای مطلب یک عکس است و متن خبر از کنار عکس شروع می‌شود. خط‌های اول کوتاه‌اند، چون دور عکس می‌پیچند. وقتی متن از ارتفاع عکس رد شد، خط‌های بعدی دوباره تمام عرض ستون را می‌گیرند.

این همان صفحه‌ای است که در روزنامه می‌بینید: عکس یک گوشه، حروف دور آن.

سؤال: اگر فقط یک `img` و یک `p` پشت سر هم در HTML بگذاریم، مرورگر چه می‌کند؟»

این فایل را زنده باز کن (پیشنهاد: `تدریس/live/06-float.html`):

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — شناور</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      padding: 1.5rem;
      background: #f8fafc;
      line-height: 1.8;
    }
    .news {
      max-width: 40rem;
      background: #fff;
      padding: 1rem;
      border: 1px solid #e2e8f0;
    }
    .news-img {
      width: 140px;
      height: 100px;
      object-fit: cover;
      background: #cbd5e1;
    }
  </style>
</head>
<body>
  <article class="news">
    <img class="news-img" src="../images/bg.jpg" alt="تصویر خبر">
    <p>
      این یک متن خبری نمونه است. عکس و متن هر کدام بلوک خودشان را گرفته‌اند.
      متن زیر عکس آمده، نه کنار آن. برای مقاله این چیدمان جا را هدر می‌دهد.
      چند جمله دیگر هم می‌نویسیم تا ارتفاع متن از ارتفاع عکس بیشتر شود و
      ادامه مطلب را در عرض کامل ستون ببینیم.
    </p>
  </article>
</body>
</html>
```

اگر تصویر جزوه در دسترس نیست، یک `div` با پس‌زمینه خاکستری و همان عرض و ارتفاع را جای `img` بگذار تا کلاس معطل فایل نشود.

بعد بگو:

«عکس بالا است، پاراگراف پایین. هیچ‌کدام دور دیگری نپیچیده. `img` در جریان عادی صفحه نشسته و خط بعد از خودش شروع شده.

ما می‌خواهیم عکس برود گوشه راست جعبه خبر و متن از سمت دیگرش شروع شود. این کارِ چیدمان کل سایت نیست. این کارِ **متن دور یک شکل** است.»

**در مرورگر:** بدون float، تصویر و پاراگراف زیر هم. این «قبل» درس است. هنوز `display: flex` را به‌عنوان راه‌حل این مسئله پیشنهاد نکن؛ flex متن را دور شکل نامنظم نمی‌پیچاند، ردیف می‌سازد.

### سؤال کلاسی

- «اگر عرض پنجره را کم کنیم، آیا متن خودش کنار عکس می‌آید؟»  
  **پاسخ:** تا وقتی عکس در جریان بلوکی عادی باشد، کم کردن عرض فقط هر دو را باریک‌تر می‌کند. کنار هم آمدن خودکار نیست.

## ۲) `float` — عکس را به گوشه ببر تا متن دورش بپیچد

«ویژگی‌ای که این کار را می‌کند `float` است. مقدارهای همین درس: `right` و `left`.

`float: right` عنصر را به **لبه راست فیزیکی** هل می‌دهد. `float: left` به لبه چپ فیزیکی.

این دو مقدار با جهت صفحه عوض نمی‌شوند. در صفحه فارسی (`dir="rtl"`) هم `float: right` تصویر را به لبه راست می‌برد، نه به «سمت شروع متن».»

Live Coding — فقط همین را به `.news-img` اضافه کن:

```css
.news-img {
  float: right;
  width: 140px;
  height: 100px;
  object-fit: cover;
  background: #cbd5e1;
}
```

«به مرورگر گفتیم: این عکس را از جریان عادی ارتفاع خط بردار، بچسبان به راست، و بگذار خط‌های پاراگراف در فضای باقی‌مانده بنشینند.»

**در مرورگر:** متن کنار عکس شروع می‌شود. اگر پاراگراف بلندتر از ۱۴۰×۱۰۰ باشد، خط‌های پایین دوباره تمام عرض `.news` را می‌گیرند. این را با کم و زیاد کردن جمله نشان بده. جزوه همین را در مثال ۱ صفحه [`06-float.html`](../../pages/06-float.html) دارد.

بلافاصله `left` را هم عوض کن و برگردان:

```css
.news-img {
  float: left;
}
```

«حالا عکس چپ است و متن از سمت دیگرِ عکس کنارش می‌آید. برای خبر فارسی معمولاً `float: right` طبیعی‌تر است، چون چشم از راست شروع می‌کند و عکس همان گوشه است. هر دو را ببینند.»

### سؤال کلاسی

- «`float` روی خود پاراگراف بگذاریم یا روی عکس؟»  
  **پاسخ:** روی شکلی که باید گوشه برود (اینجا تصویر). متن دور آن می‌پیچد.

- «آیا `float: right` در صفحه راست‌چین به لبه چپ می‌رود؟»  
  **پاسخ:** `right` همیشه لبه راست فیزیکی است. جهت صفحه آن را برنمی‌گرداند.

### اشتباهات رایج

- `float` را روی هر دو، هم عکس و هم پاراگراف، گذاشتن. پاراگراف هم از جریان خارج می‌شود و دیگر «دور عکس» نمی‌پیچد.  
- فراموش کردن `width` روی تصویر شناور. بدون عرض مشخص، بعضی تصاویر ذاتیِ خیلی پهن کل خط را می‌گیرند و جایی برای پیچیدن متن نمی‌ماند.

### انتقال

«متن کنار عکس آمد، ولی به لبه عکس چسبیده. فاصله را جدا درست می‌کنیم.»

## ۳) فاصله عکس تا متن — حاشیه سمت متن

«جزوه یک اشتباه رایج را صریح گفته: اگر حاشیه سمت متن را فراموش کنیم، حروف به عکس می‌چسبند.

در این صفحه راست‌چین، عکسی که `float: right` دارد باید از سمت چپش فاصله بگیرد، چون متن آن سمت نشسته. عکسی که `float: left` دارد باید از سمت راستش فاصله بگیرد.»

`float` را برگردان به `right` و حاشیه را اضافه کن:

```css
.news-img {
  float: right;
  width: 140px;
  margin-left: 12px;
  margin-bottom: 8px;
}
```

«`margin-left: 12px` همان فاصله جزوه است: بین عکس راست و متن. `margin-bottom` برای وقتی است که خط‌ها از زیر عکس رد می‌شوند و نباید به لبه پایین عکس بچسبند.»

**در مرورگر:** ۱۲ پیکسل هوای خالی بین عکس و حروف. DevTools را باز کن، حاشیه را ۰ کن تا چسبیدن را ببینند، بعد ۱۲ را برگردان.

حالا آزمایش جهت:

```css
.news-img {
  float: left;
  margin-left: 0;
  margin-right: 12px;
}
```

«لبه عوض شد؛ سمت حاشیه هم باید عوض شود. اگر `float: left` باشد و هنوز `margin-left` مانده باشد، فاصله می‌افتد سمت دیواره چپ، نه بین عکس و متن.»

| عکس | کجا می‌نشیند | حاشیه فاصله تا متن |
|-----|----------------|---------------------|
| `float: right` | لبه راست | `margin-left` |
| `float: left` | لبه چپ | `margin-right` |

### سؤال کلاسی

- «در همین فایل `dir="rtl"`، برای `float: right` کدام `margin` متن را از عکس جدا می‌کند؟»  
  **پاسخ:** `margin-left`.

### اشتباهات رایج

- `margin-right` روی عکسِ `float: right` در صفحه فارسی. فاصله به لبه بیرونی صفحه می‌رود و متن همچنان می‌چسبد.  
- فقط `margin` کلی `10px` بدون نگاه کردن به اینکه متن کدام سمت عکس است.

برای ادامه درس، کد خبر را به حالت راست برگردان:

```css
.news-img {
  float: right;
  width: 140px;
  margin-left: 12px;
  margin-bottom: 8px;
}
```

## ۴) `clear` — این یکی زیر شناورها بیاید

«مقاله فقط یک پاراگراف نیست. بعد از خبر یک تیتر بخش بعد داریم: «نظر خوانندگان». اگر آن تیتر هم در جریان عادی باشد، ممکن است کنار فضای خالی شناور بنشیند، نه زیر عکس.»

HTML را گسترش بده:

```html
<article class="news">
  <img class="news-img" src="../images/bg.jpg" alt="تصویر خبر">
  <p>
    متن خبر دور عکس می‌پیچد. این پاراگراف را کوتاه نگه دار
    تا هنوز به زیر عکس نرسیده باشد.
  </p>
  <h2 class="next">نظر خوانندگان</h2>
  <p>این بخش باید از سر خط، زیر عکس، شروع شود.</p>
</article>
```

**در مرورگر:** اگر پاراگراف اول کوتاه باشد، `h2` ممکن است هنوز در کنار عکس جا شود. این همان «کنار آمدن ناخواسته» است.

«وقتی می‌خواهیم عنصری **زیر** شناورها بیاید، نه کنارشان، به خودش `clear` می‌دهیم.

`clear: both` یعنی: نه شناور راست کنار من باشد، نه شناور چپ. از زیر هر دو شروع کن.»

```css
.next {
  clear: both;
}
```

**در مرورگر:** تیتر می‌پرد زیر عکس، حتی اگر کنار عکس هنوز جا باشد. مثال ۳ جزوه همین تضاد را با دو پاراگراف نشان می‌دهد: یکی بدون `clear` کنار جعبه‌ها، یکی با `clear: both` زیر آن‌ها.

اگر وقت شد، نسخه جزوه را هم زنده کن تا `clear` فقط به تیتر مقاله محدود نماند:

```html
<div class="tag-float">شناور ۱</div>
<div class="tag-float">شناور ۲</div>
<p class="no-clear">بدون clear: من کنار جعبه‌ها چسبیدم.</p>
<div class="tag-float">شناور ۳</div>
<div class="tag-float">شناور ۴</div>
<p class="with-clear">با clear: both — من زیر جعبه‌ها آمدم.</p>
```

```css
.tag-float {
  float: right;
  width: 6rem;
  margin: 0 0 0.5rem 0.5rem;
  padding: 0.4rem;
  background: #dbeafe;
}
.with-clear {
  clear: both;
}
```

### سؤال کلاسی

- «`clear` را روی عکس می‌گذاریم یا روی عنصری که باید پایین بیاید؟»  
  **پاسخ:** روی عنصری که باید زیر شناورها شروع شود (تیتر، بخش بعد، پاراگراف «با clear»).

- «`clear: both` همان پاک کردن `float` خودِ عنصر است؟»  
  **پاسخ:** `clear` نمی‌گوید «شناور نباش». می‌گوید «کنار شناورهای قبلی ننشین».

### انتقال

«تیتر پایین آمد. یک باگ معروف مانده: گاهی جعبه پدر، دور فرزندان شناور جمع می‌شود و پس‌زمینه‌اش ناپدید به نظر می‌رسد.»

## ۵) پدر جمع‌شده — شناور از حساب ارتفاع خارج می‌شود

«عنصر شناور از جریان عادی صفحه بیرون می‌رود. پدر، ارتفاع را از فرزندانِ داخل جریان حساب می‌کند. اگر همه فرزندان شناور باشند، پدر آن‌ها را در حساب ارتفاع «نمی‌بیند» و ممکن است ارتفاعش صفر شود. حاشیه و پس‌زمینه پدر جمع می‌شود و انگار محتوا بیرون جعبه ریخته.»

این را جدا از مقاله نشان بده تا دانشجو قاطی نکند. دو پدر کنار هم، مطابق مثال ۴ جزوه:

```html
<p><strong>بدون راه‌حل:</strong></p>
<div class="parent-bad">
  <div class="item">فرزند شناور</div>
</div>

<p><strong>با display: flow-root:</strong></p>
<div class="parent-good">
  <div class="item">فرزند شناور</div>
</div>
```

```css
.item {
  float: right;
  width: 8rem;
  padding: 0.6rem;
  background: #bfdbfe;
}

.parent-bad {
  background: #fee2e2;
  border: 2px dashed #b91c1c;
}

.parent-good {
  display: flow-root;
  background: #dcfce7;
  border: 2px solid #15803d;
}
```

**در مرورگر:** پدر قرمز تقریباً فقط یک خط حاشیه است؛ جعبه آبی شناور از آن بیرون زده. پدر سبز دور فرزند را گرفته، چون `display: flow-root` یک ظرف قالب‌بندی تازه می‌سازد و شناورها را داخل خودش نگه می‌دارد.

«راه حل امروزی جزوه همین است:

```css
.parent {
  display: flow-root;
}
```

جزوه `overflow: auto` را هم به‌عنوان راه مشابه نام برده. `overflow` غیر از `visible` هم اغلب شناورها را در بر می‌گیرد، ولی ممکن است نوار اسکرول ناخواسته بیاورد. اگر هدف فقط «در بر گرفتن شناور» است، `flow-root` روشن‌تر است. درس سرریز را یادشان بیاور: `overflow` اول برای برش و اسکرول بود، نه برای وصله کردن float.»

### سؤال کلاسی

- «اگر داخل پدر یک پاراگراف غیرشناور هم باشد، آیا ارتفاع لزوماً صفر است؟»  
  **پاسخ:** همان پاراگراف به ارتفاع پدر کمک می‌کند. باگ وقتی تیز می‌شود که فرزندان مؤثر، شناور باشند و محتوای داخل جریان تمام شود.

- «چرا پس‌زمینه `.parent-bad` دیده نمی‌شود؟»  
  **پاسخ:** ارتفاع محاسبه‌شده پدر تقریباً صفر است؛ پس‌زمینه روی ارتفاع صفر چیزی برای رنگ کردن ندارد. خودِ `.item` هنوز روی صفحه هست.

### اشتباهات رایج

- اضافه کردن `height` ثابت به پدر تا «جمع نشود». با یک خط متن بیشتر، محتوا می‌برد بیرون. دربرگیری شناور را با `flow-root` حل کن، نه با ارتفاع جادویی.  
- فکر کردن که `clear` روی پدر، ارتفاع پدر را درست می‌کند. `clear` مال فرزندِ بعدی است، نه دکمه جادویی روی خود پدر.

## ۶) clearfix قدیمی — همان کار با شبه‌عنصر

«در کدهای قدیمی، قبل از `flow-root`، این الگو را زیاد می‌بینید. لازم نیست امروز پروژه‌ات را با آن بنویسی، ولی باید بتوانی بخوانی‌اش.»

```css
.parent::after {
  content: "";
  display: block;
  clear: both;
}
```

«`::after` یک جعبه خالی آخرِ پدر می‌سازد. `content: ""` یعنی داخلش متنی نیست، ولی جعبه وجود دارد. `display: block` و `clear: both` یعنی این جعبه خالی زیر همه شناورها می‌نشیند. چون این جعبه فرزند پدر است و داخل جریان است، پدر مجبور می‌شود تا زیر آن کش بیاید. در عمل ارتفاع پدر دور شناورها بسته می‌شود.

جزوه همین یک خط را دارد. درس بعد از شبه‌کلاس‌ها، شبه‌عنصر `::before` و `::after` را جدا باز می‌کنیم. امروز فقط بدان این سه اعلام با هم یعنی clearfix.»

اگر `flow-root` را از `.parent-good` برداری و این قانون را بگذاری، نتیجه سبز باید برگردد. هر دو راه را یک بار عوض کن تا دانشجو ببیند هدف یکی است.

«برای کد تازه همان `display: flow-root` را بنویس. clearfix را برای خواندن قالب‌های قدیمی نگه دار.»

### سؤال کلاسی

- «اگر `content` را در `::after` ننویسیم چه می‌شود؟»  
  **پاسخ:** شبه‌عنصر ساخته نمی‌شود (مقدار پیش‌فرض `content` برابر `none` است) و `clear` هم اجرا نمی‌شود.

---

## ۷) ستون‌های کنار هم — کد قدیمی را بشناس، با آن سایت نساز

«مثال ۲ جزوه سه جعبه را با float کنار هم چیده. این را در سایت‌های قدیمی زیاد می‌بینید. باید بتوانید بخوانید. برای چیدمان تازه استفاده نکنید.»

```css
.clearfix {
  display: flow-root;
}

.item {
  float: right;
  width: 30%;
  margin-left: 3%;
}
```

«حساب جزوه را با هم انجام بده: هر ستون ۳۰٪ است و حاشیه چپ ۳٪. سه بار (۳۰ + ۳) می‌شود ۹۹٪. اگر جمع از ۱۰۰٪ بیشتر شود، ستون آخر به خط بعد می‌افتد. پدر هم باید `flow-root` باشد وگرنه پس‌زمینه‌اش جمع می‌شود.

همین کار را امروز با Flexbox می‌نویسند، بدون حساب درصد و بدون جمع شدن پدر. ستون‌ها هم می‌توانند هم‌قد شوند. این کد را فقط نشان بده؛ درس Flex جداست:»

```css
.flex-row {
  display: flex;
  gap: 3%;
}

.flex-row .item {
  flex: 1;
  float: none;
  width: auto;
  margin: 0;
}
```

**در مرورگر:** هر دو ردیف را زیر هم بگذار. در ردیف flex، متن بیشتر در یک ستون، ستون‌های دیگر را هم‌قد می‌کند. در ردیف float این هم‌قدی خودکار نیست.

«پس نقشه ذهنی امروز:

- **متن دور عکس، مقاله، نقل‌قول کنار تصویر** → `float` هنوز کار درست است.  
- **منو، ردیف کارت، ستون صفحه، فوتر** → Flexbox یا Grid، در ماژول‌های بعدی. float را آنجا «تعمیر» نکنید.»

این جمله را روی تخته بگذار و تا آخر کلاس پاک نکن.

### اشتباهات رایج

- ساختن نوار بالای سایت با `float: right` روی هر `li`. با یک آیتم بیشتر، یا با ترجمه طولانی، ردیف می‌شکند و clearfix به معما تبدیل می‌شود.  
- مخلوط کردن `float` و `flex` روی همان عنصر. اگر پدر `display: flex` است، `float` فرزندان در آن قالب اثر چیدمان flex را ندارد.

## ۸) پروژه جلسه — خبر کوتاه شهر

دیگر مثال تازه نزن. همان مقاله را کامل کن تا هر سه ابزار در یک صفحه باشند: `float`، حاشیه سمت متن، `clear`، و پدرِ `flow-root`.

### Live Coding مرحله‌به‌مرحله

۱) HTML:

```html
<article class="story">
  <h1>بازار محلی جمعه</h1>
  <img class="story-img" src="../images/bg.jpg" alt="غرفه بازار">
  <p>
    هر جمعه بازار کنار رودخانه شلوغ می‌شود. غرفه‌ها از اول صبح بازند
    و بوی نان تازه تا آخر خیابان می‌آید. این پاراگراف باید دور عکس بپیچد
    و بعد از ارتفاع تصویر، در عرض کامل ستون ادامه پیدا کند.
  </p>
  <p>
    جمله دوم هنوز بخشی از خود خبر است و لازم نیست زیر عکس قفل شود،
    مگر اینکه از عکس بلندتر شده باشد.
  </p>
  <h2 class="comments-title">نظر خوانندگان</h2>
  <p>این بخش همیشه زیر تصویر شروع می‌شود، حتی اگر خبر کوتاه باشد.</p>
</article>
```

۲) CSS:

```css
.story {
  display: flow-root;
  max-width: 40rem;
  margin-inline: auto;
  padding: 1rem 1.25rem;
  background: #fff;
  border: 1px solid #e2e8f0;
}

.story-img {
  float: right;
  width: 160px;
  height: 110px;
  object-fit: cover;
  margin-left: 12px;
  margin-bottom: 8px;
}

.comments-title {
  clear: both;
  margin-top: 1.5rem;
}
```

«ببینید چه کردیم:

- پدر `flow-root` است تا اگر متن کوتاه شد، پس‌زمینه سفید دور عکس جمع نشود.  
- عکس `float: right` با عرض مشخص و `margin-left` برای فاصله در صفحه فارسی.  
- تیتر نظرات `clear: both` دارد تا هرگز کنار عکس ننشیند.  
- عرض مقاله با `max-width` سقف دارد؛ این را از درس حداکثر عرض دارید. float جایگزین آن نیست.»

**در مرورگر:** یک بار پاراگراف اول را تا یک جمله کوتاه کن تا جمع‌نشدن پدر را امتحان کنی. یک بار متن را بلند کن تا پیچیدن زیر عکس را ببینی. عرض پنجره را تا حدود ۳۶۰ پیکسل کم کن: عکس ۱۶۰ پیکسلی کنار متن باریک هنوز کار می‌کند، ولی اگر متن ناخوانا شد، این محدودیت float برای ستون کل صفحه است. برای آن چیدمان سراغ flex می‌رویم، در ماژول خودش، نه وسط این پروژه.

### سؤال حین پروژه

- «اگر `clear` را از تیتر برداریم و متن خبر را یک خط کنیم، تیتر کجا می‌رود؟»  
  **پاسخ:** در فضای کنار عکس، اگر جا باشد.

## ۹) جمع‌بندی مدرس و سؤالات پایانی

قبل از تمرین، این سه سؤال را بپرس:

۱. برای عکس کنار متن یک مقاله، امروز از چه ویژگی‌ای استفاده می‌کنیم، و منوی افقی سایت را با چه ابزاری تازه نمی‌سازیم؟  
   **پاسخ راهنما:** `float` برای پیچیدن متن دور تصویر. منو و ستون صفحه را با float تازه نمی‌سازیم؛ Flexbox و Grid در درس‌های بعدی‌اند.

۲. در صفحه راست‌چین، عکس `float: right` چه حاشیه‌ای می‌خواهد تا متن به آن نچسبد؟  
   **پاسخ:** `margin-left` (سمت متن).

۳. ارتفاع پدر صفر شده و فقط فرزندان `float` دارند. دو راهی که جزوه گفته چیست؟  
   **پاسخ:** `display: flow-root` روی پدر (راه امروزی). در کد قدیمی: `::after` با `content: ""` و `display: block` و `clear: both`. راه‌حل مشابه دیگر: `overflow: auto`.

**پیام پایانی:**

«هدف این جلسه ساختن قالب سه‌ستونه با درصد و clearfix نبود. هدف این بود که یک خبر را طوری بچینی که عکس گوشه باشد، متن دورش بپیچد، بخش بعدی زیر عکس بیاید، و جعبه پدر از هم نپاشد. هر جا دیدی چند جعبه هم‌عرض کنار هم می‌خواهی، float را کنار بگذار.»

## تمرین‌ها (ساده → چالشی)

### ساده

۱. یک پاراگراف درباره شهرت بنویس و یک عکس (یا جعبه رنگی ۱۴۰ پیکسلی) با `float: left` کنارش بگذار. فاصله مناسب سمت متن را خودت انتخاب کن.  
۲. بعد از همان پاراگراف یک تیتر بگذار که با `clear: both` حتماً زیر عکس بیاید. این همان تمرین جزوه است.

### متوسط

۳. پدر را عمداً بدون `flow-root` رها کن و فقط فرزند شناور داخلش بگذار تا پس‌زمینه جمع شود. بعد `display: flow-root` را اضافه کن و قبل/بعد را در مرورگر کنار هم توضیح بده.  
۴. همان پدر را به‌جای `flow-root` با clearfix زیر درست کن:

```css
.parent::after {
  content: "";
  display: block;
  clear: both;
}
```

### چالشی

۵. مقاله پروژه جلسه را با دو تصویر بساز: اولی `float: right`، دومی `float: left`، هر کدام با حاشیه سمت متن خودش. یک `h2` میانی با `clear: both` بخش را بشکند.  
۶. سه ستون ۳۰٪ با float را یک بار بساز (فقط برای دیدن حساب ۹۹٪ و `flow-root`)، بعد همان HTML را با `display: flex` و `gap` بچین و در دو جمله بنویس چرا برای ستون صفحه دومی را نگه می‌داری. عمق flex را وارد حل نکن؛ فقط ردیف را نشان بده.
