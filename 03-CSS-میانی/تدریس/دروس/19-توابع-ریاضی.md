## 2) math

«`clamp(min, preferred, max)` — `min()`, `max()`, `calc()` — فاصله در calc لازم.»

```css
.hero-title { font-size: clamp(1.25rem, 2.5vw + 0.5rem, 2.25rem); }
.sidebar { width: min(16rem, 100%); }
.gap { margin-inline: calc(1rem + 2vw); }
```
