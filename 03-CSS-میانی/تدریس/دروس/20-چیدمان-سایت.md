## ۱) شروع کلاس — مسئله اول (دیالوگ)

«بچه‌ها، سایت شخصی با `<div id="top">`, `<div class="left">`, `<div class="right">` — CSS کار می‌کند ولی:

- صفحه‌خوان نمی‌فهمد کجا **محتوای اصلی** است  
- SEO و keyboard skip-link سخت  
- هر refactor HTML classهای جادویی را می‌شکند

**Layout مدرن** = HTML **معنایی** + CSS **Flex/Grid** (نه table، نه float برای shell — float در [`06-float`](../../pages/06-float.html) فقط تاریخچه).

امروز سه سطح: **وبلاگ یک‌ستونه** → **main+aside با flex** → **grid-template-areas** — مطابق [`20-layout.html`](../../pages/20-layout.html) و [`layout.css`](../../css/demos/layout.css).»

## ۲) landmarks — یک `main` در هر صفحه

| بخش | تگ | نقش |
|-----|-----|-----|
| سربرگ | `header` | لوگو، عنوان |
| منو | `nav` | لینک‌ها |
| محتوا | **`main`** (یکی!) | مطلب اصلی |
| کناری | `aside` | دسته، تبلیغ |
| پا | `footer` | کپی‌رایت |

«در جزوه آموزشی چند نمونه کنار هم است — از `article.l-main` استفاده شده؛ **در سایت واقعی `main`**.»

### سؤال کلاسی

«دو `<main>` در یک صفحه?»  
**پاسخ:** نامعتبر برای accessibility — فقط یک main.

## ۳) Live Coding مرحله ۱ — وبلاگ یک‌ستونه

```css
header, nav, main, footer {
  padding: 16px;
}
header {
  background: #1a3a5c;
  color: white;
  text-align: center;
}
nav {
  background: #333;
}
nav a {
  display: inline-block;
  color: white;
  text-decoration: none;
  padding: 10px 16px;
}
footer {
  background: #ddd;
  text-align: center;
}
```

**در مرورگر:** demo `.site.one-col` — موبایل-friendly بدون media query.

## ۴) Live Coding مرحله ۲ — flex 70/30

```css
.row {
  display: flex;
}
main {
  width: 70%;
}
aside {
  width: 30%;
}
```

«RTL: اولین flex item سمت **شروع** — در فارسی main راست.

**محدودیت:** `width: 70%` روی موبایل بدون wrap — درس ۲۱ stack می‌کند.»

**نمایش:** demo فروشگاه کتاب در جزوه.

## ۵) Live Coding مرحله ۳ — grid سه ستون خدمات

```css
.grid-3 {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
```

«`fr` = سهم فضای باقی‌مانده — کارت‌های هم‌قد.»

---

## ۶) Live Coding مرحله ۴ — shell `.page` با areas

```css
.page {
  display: grid;
  gap: 1rem;
  max-width: 72rem;
  margin-inline: auto;
  padding: 1rem;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  grid-template-columns: minmax(0, 16rem) minmax(0, 1fr);
}
.page-header { grid-area: head; }
.page-sidebar { grid-area: side; }
.page-main { grid-area: main; }
.page-footer { grid-area: foot; }
```

«**`minmax(0, 1fr)`** — بدون آن محتوای wide در main grid را overflow می‌کند.

**DOM order vs visual:** می‌توانید main قبل aside در HTML برای screen reader و grid area جای sidebar را عوض کنید (درس پیشرفته).»

**در مرورگر:** demo grid shell جزوه (اگر present) — resize.

## ۷) container pattern

```css
.site-container {
  width: 100%;
  max-width: 72rem;
  margin-inline: auto;
  padding-inline: 1rem;
}
```

«محتوا وسط، نفس در موبایل — همان margin auto درس ۹.»

---

## ۸) اشتباهات رایج

- div soup بدون main/nav landmarks.  
- sidebar `width: 16rem` fixed بدون media — موبایل overflow.  
- `1fr` بدون minmax(0) — classic grid overflow bug.  
- float برای کل صفحه layout (legacy).

## ۱۰) جمع‌بندی

1. چرا semantic tags?  
   **پاسخ:** a11y، SEO، نگهداری.

2. flex vs grid برای shell?  
   **پاسخ:** grid برای 2D areas؛ flex برای row ساده.

3. minmax(0,1fr)?  
   **پاسخ:** allow column shrink — prevent overflow.

**پیام:** «Layout shell آماده — فردا **media queries** stack موبایل.»
