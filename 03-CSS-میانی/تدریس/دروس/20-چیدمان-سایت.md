# سناریوی تدریس درس ۲۰: چیدمان سایت (Website Layout)

**صفحه جزوه:** [`pages/20-layout.html`](../../pages/20-layout.html)  
**پیش‌نیاز مفهومی:** [Flexbox](../../../07-CSS-Flexbox/index.html) و [Grid](../../../08-CSS-Grid/index.html) — این جلسه **جای آن دو ماژول نیست** · تگ‌های معنایی HTML · `box-sizing` · درس‌های position و float همین ماژول فقط برای مقایسه  
**مدت پیشنهادی:** حدود ۱۰۰ دقیقه  
**جایگاه در مسیر:** درس **اصلی**. بعد از فرم‌ها، اول ماژول Flexbox و بعد Grid را خوانده‌اند و حالا اسکلت یک سایت واقعی را با همان ابزارها سر هم می‌کنند.  
**هدف جلسه:** دانشجو بخش‌های تکرارشونده صفحه (سربرگ، منو، محتوا، ستون کناری، پانویس) را با HTML معنایی نام‌گذاری کند، یک ستون و دو ستون و ردیف کارت را با **کمترین** CSS لازم کنار هم ببیند، float را به‌عنوان روش قدیمی بشناسد، و بداند واکنش‌گرا کردن ستون‌ها درس ۲۱ است. الگوریتم Flex و Grid را دوباره تدریس نکن.

**چرخه ثابت تدریس:**

## ۱) شروع کلاس؛ نیاز روی سایت

«بچه‌ها، تا اینجا قطعه ساخته‌ایم: منو، فرم، کارت، نشان روی عکس. امروز سؤال این است که **یک صفحه کامل** این قطعه‌ها را کجا می‌گذارد.

یک فروشگاه کتاب را باز کنید، حتی روی تخته. بالا نام فروشگاه است. زیرش لینک‌ها. وسط فهرست کتاب‌ها. کنارش دسته‌بندی. پایین کپی‌رایت. اگر این‌ها را پنج تا `div` بدون اسم بنویسیم، صفحه ممکن است شبیه همان فروشگاه شود، ولی مرورگر و کسی که ماه بعد کد را باز می‌کند نمی‌فهمد کدام بخش «مطلب اصلی» است.

چیدمان سایت یعنی دو تصمیم جدا:

۱. **HTML:** این تکه‌ها چه نقشی دارند.  
۲. **CSS:** چقدر جا می‌گیرند و کنار هم می‌نشینند یا زیر هم.

امروز تصمیم دوم را با همان Flex و Grid که در ماژول ۰۷ و ۰۸ دیده‌اید می‌نویسیم. اگر چیزی از آن دو ماژول یادتان نیست، خط‌ها را مثل دستور آماده استفاده کنید و بعد از کلاس برگردید به همان ماژول. اینجا `justify-content` و `grid-template-areas` را از نو درس نمی‌دهم.»

صفحه خالی را باز کن و فقط متن بریز، بدون تگ معنایی:

```html
<div>فروشگاه کتاب</div>
<div>خانه | کتاب‌ها | تماس</div>
<div>کتاب‌های جدید…</div>
<div>دسته‌بندی: رمان، علمی، کودک</div>
<div>© فروشگاه کتاب</div>
```

**در مرورگر:** پنج بلوک زیر هم، همه مثل هم. «ظاهر را هنوز CSS می‌دهد، ولی نقش‌ها گم‌اند. از همین‌جا تگ را عوض می‌کنیم، نه اینکه با کلاس‌هایی مثل `.div1` نقشه بکشیم.»

## ۲) نقشه بخش‌ها

روی برد این جدول جزوه را بنویس و برای هر ردیف یک جمله «روی سایت چه کاری می‌کند» بگو:

| بخش | تگ | روی سایت |
|------|------|----------|
| سربرگ | `header` | نام و نشانه؛ اغلب بالای هر صفحه تکرار می‌شود |
| منو | `nav` | لینک صفحه‌ها. منو را داخل `header` هم می‌گذارند؛ هر دو ساختار دیده می‌شود |
| محتوا | `main` | مطلبی که این صفحه برایش باز شده. در هر صفحه **فقط یک** `main` |
| نوشته مستقل | `article` | یک مطلب که به‌تنهایی هم معنی دارد، مثل پست وبلاگ |
| گروه موضوعی | `section` | بخشی با عنوان، مثل «خدمات ما» |
| ستون کناری | `aside` | چیزی مرتبط ولی نه متن اصلی: دسته، تبلیغ، ساعت کاری |
| پانویس | `footer` | کپی‌رایت، تماس، لینک‌های تکراری پایین |

«`div` ممنوع نیست. `div` یعنی «این تکه‌ها را برای چیدمان گروه‌بندی کردم» وقتی نقش بهتری نداریم. مثلاً پدرِ دو ستون گاهی `div` است، چون خودش نه محتواست و نه ستون کناری؛ فقط ردیف است.

قانونی که در جزوه هست و باید بلند گفته شود: در هر صفحه فقط **یک** `main`. این صفحه جزوه چند نمونه سایت را هم‌زمان نشان می‌دهد، برای همین داخل مثال‌های جزوه به‌جای `main` از `article` با کلاس استفاده شده تا چند `main` در یک صفحه آموزشی ننشیند. در سایت خود دانشجو، و در فایل زنده ما، `main` را واقعی می‌نویسیم.»

### سؤال کلاسی

- «ساعت کاری رستوران در کنار معرفی غذاها کدام تگ است؟»  
  **پاسخ:** `aside`. معرفی غذاها داخل `main`.

- «چرا کل صفحه را `main` نگذاریم؟»  
  **پاسخ:** سربرگ و پانویس و منو، محتوای یکتای این صفحه نیستند. `main` باید همان بخشی باشد که با رفتن به صفحه دیگر عوض می‌شود.

### اشتباهات رایج

- چند `main` چون چند تا `section` داریم. sectionها **داخل** همان یک `main` می‌نشینند.  
- گذاشتن تنها متن صفحه داخل `aside` و خالی گذاشتن `main`. ستون کناری، اصلی نیست.

## ۳) مثال ۱ — وبلاگ یک‌ستونه

نیاز: «یادداشت‌های یک برنامه‌نویس» فقط یک ستون متن می‌خواهد. در موبایل هم همین شکل درست است. پیچیدگی دو ستونه را به زور اضافه نکن.

HTML:

```html
<body>
  <header class="site-header">
    <p class="brand">یادداشت‌های یک برنامه‌نویس</p>
  </header>
  <nav class="site-nav" aria-label="منوی اصلی">
    <a href="#">خانه</a>
    <a href="#">مطالب</a>
    <a href="#">درباره من</a>
  </nav>
  <main class="site-main">
    <article>
      <h1>چرا نام‌گذاری بخش‌ها مهم است</h1>
      <p>متن مطلب در یک ستون خوانده می‌شود.</p>
    </article>
    <article>
      <h2>یادداشت دوم</h2>
      <p>مطلب بعدی همان ستون.</p>
    </article>
  </main>
  <footer class="site-footer">© ۱۴۰۵ — یادداشت‌ها</footer>
</body>
```

CSS، عمداً بدون Flex و Grid:

```css
body {
  margin: 0;
  font-family: Tahoma, sans-serif;
  line-height: 1.7;
  color: #1e293b;
  background: #f8fafc;
}

.site-header {
  background: #1a3a5c;
  color: white;
  text-align: center;
  padding: 16px;
}

.site-nav {
  background: #333;
  padding: 10px 16px;
}

.site-nav a {
  color: white;
  margin-left: 12px;
}

.site-main {
  width: 100%;
  max-width: 42rem;
  margin: 0 auto;
  padding: 16px;
  background: white;
}

.site-footer {
  background: #e2e8f0;
  text-align: center;
  padding: 16px;
}
```

«منو را این‌بار با فاصله ساده بین لینک‌ها گذاشتم تا چیدمان صفحه گم نشود. اگر کسی منوی افقی درس ۱۳ را بلد است، همان `ul` با Flex را می‌تواند بیاورد؛ امروز ساختن navbar جدید هدف نیست.

`max-width` روی `main` همان الگوی کارت مقدماتی است: در صفحه پهن خط متن از حد خواندن طولانی‌تر نمی‌شود، در صفحه باریک `width: 100%` همراه پدر جمع می‌شود.»

**در مرورگر:** ستون سفید وسط، سربرگ و پاصفحه تمام‌عرض. عرض را کمی کم کن؛ متن نباید اسکرول افقی بسازد.

### سؤال کلاسی

- «اگر `max-width` را برداریم و فقط `width: 700px` بگذاریم، در گوشی چه می‌شود؟»  
  **پاسخ:** ستون از صفحه باریک‌تر از ۷۰۰px بیرون می‌زند.

## ۴) مثال ۲ — محتوا و ستون کناری

نیاز فروشگاه کتاب: فهرست کتاب پهن‌تر است، دسته‌بندی باریک‌تر، هر دو کنار هم، و در صفحه راست‌چین محتوا سمت راست دیده شود.

«پدرِ دو ستون یک `div` است با کلاس `row`. نقش معنایی ندارد؛ فقط ردیف چیدمان است. داخلش `main` و `aside` هستند.»

```html
<div class="row">
  <main>
    <h2>کتاب‌های جدید</h2>
    <p>اینجا محتوای اصلی است و حدود ۷۰٪ عرض را می‌گیرد.</p>
  </main>
  <aside>
    <h2>دسته‌بندی</h2>
    <p>رمان، علمی، کودک</p>
  </aside>
</div>
```

```css
.row {
  display: flex;
}

.row main {
  width: 70%;
  padding: 16px;
  background: white;
}

.row aside {
  width: 30%;
  padding: 16px;
  background: #ecfeff;
}
```

«در صفحه راست‌چین، اولین فرزند سمت راست می‌نشیند. پس `main` را در HTML قبل از `aside` نوشته‌ایم و بدون `order` محتوا راست است و ستون کناری چپ.

`display: flex` را امروز باز نمی‌کنم. نمی‌پرسیم محور اصلی کدام است و `flex-direction` پیش‌فرض چیست؛ آن درس ۰۷ است. اینجا فقط نتیجه را می‌بینیم: دو جعبه کنار هم، و اگر متن یکی بلندتر باشد ارتفاع ردیف با بلندتر هماهنگ می‌شود.

درصدها را با padding قاطی نکن. اگر `box-sizing: content-box` باشد، `width: 70%` به‌علاوه padding از ۷۰٪ بزرگ‌تر است و جمع ۷۰ و ۳۰ از ردیف سرریز می‌کند. بالای فایل زنده این را بگذار:»

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

**در مرورگر:** دو ستون. یک پاراگراف بلند فقط داخل `main` اضافه کن تا اختلاف ارتفاع محتوا دیده شود و ردیف همچنان یک‌تکه بماند.

عمداً یک‌بار خراب کن:

```css
.row main { width: 70%; padding: 16px; } /* box-sizing را بردار */
.row aside { width: 30%; margin-right: 16px; }
```

«ستون دوم می‌افتد خط بعد، یا اسکرول افقی می‌آید. جزوه همین را اشتباه رایج نامیده: جمع عرض‌ها به‌علاوه margin یا padding بدون `border-box`. با Flex و Grid و `gap` این مدل حساب کمتر لازم می‌شود. `gap` را اگر در ۰۷ دیده‌اند این‌طور عوض کن:»

```css
.row {
  display: flex;
  gap: 16px;
}
.row main { width: 70%; }
.row aside { width: 30%; }
```

«حتی با `gap`، جمع ۷۰٪ و ۳۰٪ و ۱۶px از ۱۰۰٪ بیشتر است. یا درصدها را کمی کمتر بگیر، یا در درس اختیاری `calc`، یا — راه تمیزتر بعد از Flex — به‌جای درصد از `flex` استفاده کن که بخش بعد فقط نشانش می‌دهیم.»

### سؤال کلاسی

- «اگر در HTML اول `aside` را بنویسیم چه می‌شود؟»  
  **پاسخ:** در راست‌چین، ستون کناری می‌رود سمت راست. ترتیب منبع برای این چیدمان مهم است. برای صفحه‌خوان هم بهتر است محتوای اصلی زودتر بیاید؛ پس `main` را اول نگه دار.

### مرز با ماژول ۰۷

اگر کسی پرسید «چرا `align-items` ننوشتیم؟»: «پیش‌فرض کش آمدن ارتفاع است. اگر خواستید ستون کوتاه به بالا بچسبد، همان ویژگی را در جزوه Flexbox پیدا کنید. امروز اضافه نمی‌کنیم.»

## ۵) مثال ۳ — سه کارت خدمات با Grid

نیاز: بخش «خدمات» صفحه شرکت، سه کارت هم‌عرض با فاصله یکسان. این کار Grid است، نه سه تا `float`.

```html
<section class="services" aria-labelledby="services-title">
  <h2 id="services-title">خدمات</h2>
  <div class="grid-3">
    <article>
      <h3>طراحی</h3>
      <p>رابط کاربری</p>
    </article>
    <article>
      <h3>برنامه‌نویسی</h3>
      <p>ساخت سایت. این متن را عمداً بلندتر می‌نویسیم تا ارتفاع کارت‌ها مقایسه شود.</p>
    </article>
    <article>
      <h3>پشتیبانی</h3>
      <p>همراهی بعد از تحویل</p>
    </article>
  </div>
</section>
```

```css
.grid-3 {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

.grid-3 article {
  background: #f1f5f9;
  padding: 12px;
  border-radius: 8px;
}
```

«`1fr` یعنی یک سهم از فضای باقی‌مانده. `repeat(3, 1fr)` یعنی سه سهم مساوی. `gap` فاصله را می‌سازد بدون اینکه به عرض ستون‌ها اضافه شود؛ همان درد درصد و margin این‌جا پیش نمی‌آید.

کارت با متن بلندتر، بقیه را هم قد می‌کند. این را نشان بده و نگه‌دار، چون بخش float دقیقاً همین را ندارد.

`grid-template-areas`، `minmax`، و جای‌گذاری با شماره خط را باز نکن. بگو: ماژول ۰۸. اگر کلاس هنوز Grid را تمام نکرده، این چهار خط را کپی مجاز بدان و تمرین سه‌ستونه را بعد از آن ماژول تحویل بگیر.»

### سؤال کلاسی

- «فاصله بین کارت‌ها را با `margin` روی هر article بدهیم چه فرقی با `gap` دارد؟»  
  **پاسخ:** margin به لبه بیرونی هم می‌چسبد و حساب عرض را به‌هم می‌ریزد. `gap` فقط بین ستون‌ها و ردیف‌هاست.

## ۶) مثال ۴ — همان سه ستون با float، فقط برای شناخت

«قبل از Flex و Grid ستون را این‌طور می‌ساختند. لازم است کد قدیمی را بشناسی تا وقتی در پروژه‌ای دیدی، بفهمی چرا پدر جمع شده یا چرا ستون‌ها قدشان یکی نیست. برای سایت جدید از این روش شروع نکن.»

```css
.row-float {
  display: flow-root; /* پدر دور floatها جمع شود */
}

.row-float .column {
  float: right;
  width: 33.33%;
  padding: 15px;
  box-sizing: border-box;
}
```

HTML سه `div.column` داخل `.row-float`.

**در مرورگر:** کنار مثال Grid بگذار. «آنجا هر سه کارت هم‌قدند. اینجا ارتفاع هر ستون به اندازه متن خودش است. پس‌زمینه ستون کوتاه تمام ردیف را نمی‌پوشاند.

`flow-root` را اگر در درس float گفته‌ای یادآوری کن: بدون آن، پدر ارتفاعش را از floatها نمی‌گیرد و رنگ پس‌زمینه پدر کوتاه می‌ماند. وارد clearfixهای قدیمی با `::after` نشو مگر کسی کد قدیمی آورده باشد.»

یک‌بار `box-sizing` را از `.column` بردار تا با padding، جمع از ۱۰۰٪ بیشتر شود و ستون سوم بیفتد پایین. بعد برگردان.

«جزوه همین را گفته: در float یا درصد خام، ۷۰ به‌علاوه ۳۰ به‌علاوه padding، ستون آخر را به خط بعد می‌اندازد. در Grid با `fr` و `gap` این حساب را خودت انجام نمی‌دهی.»

### سؤال کلاسی

- «برای بخش خدمات یک سایت جدید float می‌نویسیم یا Grid؟»  
  **پاسخ:** Grid. float را برای خواندن کد قدیمی نگه دار.

## ۷) یک نگاه به flex: 1 — بدون درس جدید

مثال ۵ جزوه را فقط به‌عنوان جایگزین درصد نشان بده:

```css
.row-flex {
  display: flex;
  gap: 12px;
}

.row-flex > div {
  flex: 1;
  padding: 12px;
}
```

«`flex: 1` یعنی فضای اضافه را مساوی تقسیم کن. دیگر لازم نیست بنویسی ۳۳٫۳۳٪. اگر بخواهی محتوا حدود سه‌برابر ستون کناری باشد، در تمرین خبرگزاری جزوه می‌نویسند `flex: 3` و `flex: 1`. معنی دقیق این عددها، رشد و جمع‌شدن، درس Flexbox است. اینجا فقط ببینید که بدون جمع کردن درصد هم می‌شود ردیف ساخت و ستون‌ها هم‌قد می‌شوند.»

اگر کلاس ماژول ۰۷ را خوب بلد است، سی ثانیه بگو `flex: 1` کوتاه‌شده `flex-grow` / `flex-shrink` / `flex-basis` است و رد شو. تخته را از فرمول پر نکن.

---

## ۸) موبایل؛ فقط پل به درس ۲۱

عرض را به حدود ۳۶۰px برسان.

«سه کارت و دو ستون له شدند. متن داخل ۳۰٪ ناخوانا است. این صفحه هنوز واکنش‌گرا نیست.

درس بعد با media query می‌گوییم: در عرض کم، ستون‌ها زیر هم. شکل کلی‌اش در جزوه این است و با `max-width` نوشته شده، یعنی «از این عرض به پایین قانون را عوض کن»:»

```css
@media (max-width: 600px) {
  .row,
  .row-flex {
    flex-direction: column;
  }

  .row main,
  .row aside {
    width: 100%;
  }

  .grid-3 {
    grid-template-columns: 1fr;
  }
}
```

«این قطعه را امروز اگر وقت شد بچسبان تا له شدن تمام شود، ولی رویکرد کلاس ما در درس ۲۱ **موبایل‌اول** است: اول سبک یک ستون، بعد با `min-width` ستون‌ها را کنار هم می‌آوریم. هر دو به یک نتیجه می‌رسند. در جزوه این صفحه `max-width` را می‌بینید تا کد نمونه را بشناسید؛ در پروژه درس بعد همان چیدمان را با `min-width` می‌نویسیم و به یک روش وفادار می‌مانیم.

`flex-direction` را هم عمیق نکن. یک جمله: جهت ردیف عوض می‌شود و فرزندان زیر هم می‌آیند. جزئیات محور، ماژول ۰۷.»

**در مرورگر:** اگر قطعه را نوشتی، از ۶۰۱px به ۵۹۹px رد شو تا پرش چیدمان دیده شود. اگر ننوشتی، فقط له شدن را نشان بده و بگو جلسه بعد درستش می‌کنیم. ترجیح با نشان دادن کوتاه است تا نیاز درس ۲۱ ساختگی نباشد.

## ۹) پروژه ترکیبی — اسکلت رستوران

دیگر الگوی تازه نده. جزوه همین را خواسته. دانشجو همراه تو تایپ می‌کند؛ تو فقط اگر گیر کرد راهنمایی کن.

نقشه را قبل از کد با صدای بلند بگو:

- `header`: نام رستوران  
- `nav`: سه لینک  
- `main`: معرفی غذاها  
- داخل main یک `section` برای غذاهای ویژه با سه کارت Grid  
- `aside`: ساعت کاری  
- `div.row` دور `main` و `aside`  
- `footer`: آدرس و تلفن  

```html
<header class="site-header"><p class="brand">رستوران نارون</p></header>
<nav class="site-nav" aria-label="منوی رستوران">
  <a href="#">خانه</a>
  <a href="#">غذاها</a>
  <a href="#">تماس</a>
</nav>
<div class="row">
  <main>
    <h1>غذاهای امروز</h1>
    <p>معرفی کوتاه رستوران.</p>
    <section class="specials" aria-labelledby="sp-title">
      <h2 id="sp-title">غذاهای ویژه</h2>
      <div class="grid-3">
        <article><h3>کوفته</h3><p>با سبزی تازه.</p></article>
        <article><h3>ماهی</h3><p>با برنج و سبزی. توضیح این کارت را بلندتر بگذار.</p></article>
        <article><h3>دسر</h3><p>بستنی زعفرانی.</p></article>
      </div>
    </section>
  </main>
  <aside>
    <h2>ساعت کاری</h2>
    <p>هر روز ۱۲ تا ۲۳</p>
  </aside>
</div>
<footer class="site-footer">خیابان مثال — ۰۲۱۰۰۰۰۰۰۰</footer>
```

CSS را از تکه‌های همین جلسه جمع کن: `border-box`، سربرگ، `row` با flex و عرض ۷۰/۳۰ **یا** `flex: 3` و `flex: 1`، `grid-3`، footer. یکی را انتخاب کن و وسط پروژه عوض نکن. اگر کلاس Flex را تمام کرده، `flex` تمیزتر است؛ اگر نه، همان ۷۰ و ۳۰ جزوه با `border-box` و بدون margin اضافه.

**چک قبل از تمام شدن جلسه:**

- فقط یک `main`  
- در عرض حدود ۱۰۰۰px، محتوا راست و ساعت کاری چپ (در `dir="rtl"`)  
- سه کارت ویژه هم‌قد  
- اسکرول افقی نداریم  
- هنوز قول نده در ۳۲۰px زیبا است؛ بگو درس ۲۱

## ۱۰) جمع‌بندی مدرس و سؤالات پایانی

1. پنج بخش رایج صفحه را با تگ نام ببر.  
   **پاسخ:** `header`، `nav`، `main`، `aside`، `footer`. داخل محتوا `article` و `section`.

2. چرا در سایت واقعی یک `main` کافی است؟  
   **پاسخ:** صفحه یک مطلب اصلی دارد. بخش‌های داخلی‌اش `section` و `article` هستند.

3. برای سه کارت هم‌عرض و هم‌قد از چه ابزاری استفاده می‌کنیم و عمقش کجاست؟  
   **پاسخ:** Grid با `repeat(3, 1fr)` و `gap`. جزئیات در ماژول ۰۸. float را برای این کار جدید انتخاب نمی‌کنیم.

4. اگر ۷۰٪ و ۳۰٪ در عمل ستون آخر را پایین می‌اندازد، اولین چیزی که چک می‌کنی چیست؟  
   **پاسخ:** padding یا margin اضافه، و `box-sizing`.

**پیام پایانی:**

«چیدمان سایت حفظ کردن `display: flex` نیست. اول نقشه را با تگ معنایی می‌کشی، بعد با ابزاری که در Flex و Grid یاد گرفته‌ای کنار هم می‌گذاری، و float را فقط وقتی می‌خوانی که با کد قدیمی طرف باشی. صفحه را هنوز برای گوشی تمام نکرده‌ایم؛ جلسه بعد همان رستوران را mobile-first جمع می‌کنیم.»

## تمرین‌ها (ساده → چالشی)

پوشه [`quizzes/1-topic-exercises/20-layout`](../../quizzes/1-topic-exercises/20-layout/README.md). هر فایل CSS آن تمرین‌ها حداکثر یک media query دارد؛ در کلاس بگو رویکرد ترجیحی ما در درس ۲۱ mobile-first است، ولی اگر تمرین را با همان یک `@media (max-width)` جزوه حل کردند قبول است به شرطی که در یک فایل دو سبک را قاطی نکنند.

### ساده
1. وبلاگ «یادداشت‌های یک برنامه‌نویس»: `header`، `nav` با سه لینک، `main` با دو `article`، `footer`. عرض `main` حداکثر حدود ۷۰۰px و وسط صفحه. سربرگ و پانویس تمام‌عرض.

### متوسط
2. خبرگزاری: `div.page` با `display: flex`، `main` با `flex: 3` و `aside` با `flex: 1`، `gap`. یک media query که زیر حدود ۷۰۰px جهت را ستونی کند. در دسکتاپ خبر سمت راست بماند.

### چالشی
3. صفحه «باغبان»: سربرگ و منو، بنر کوتاه، بخش خدمات با `grid-template-columns: repeat(3, 1fr)`، پانویس با تلفن. در عرض کم خدمات یک‌ستونه شود. ساختار معنایی کامل، فقط یک `main`.  
4. اسکلت رستوران همین جلسه را بدون نگاه به جزوه دوباره بنویس و کنارش پنج خط توضیح بده چرا خدمات را Grid کردی و ستون ساعت کاری را Flex.
