## ۱) شروع کلاس؛ نیاز روی سایت

«دو جلسه اختیاری قبل، حرکت به **کار کاربر** وصل بود. ماوس می‌رفت روی دکمه، رنگ راه می‌افتاد. ماوس که می‌رفت، حرکت تمام می‌شد. آن transition است.

امروز دو نیاز دیگر:

۱. دکمه‌ای که حتی بدون hover هم یک‌بار آرام توجه را جلب کند، مثلاً «ثبت‌نام» در اول صفحه. اگر این کار را تند و دائمی بکنی، کاربر خسته می‌شود. جزوه می‌گوید یک پالس کافی است، نه رقصیدن کل صفحه.  
۲. برچسب «جدید» کنار یک دوره که **یک‌بار** از کناری وارد شود و بعد بایستد. این دیگر hover نیست؛ به محض دیده شدن باید اجرا شود.

هر دو را با `animation` و `@keyframes` می‌نویسیم. keyframes یعنی خودت چند ایستگاه تعریف می‌کنی و مرورگر بینشان را پر می‌کند.»

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — animation</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      padding: 2rem;
      background: #f8fafc;
    }
  </style>
</head>
<body>
  <a class="cta" href="#signup">ثبت‌نام</a>
</body>
</html>
```

«هنوز حرکت ندارد. اول ایستگاه‌ها را می‌نویسیم، بعد به دکمه وصل می‌کنیم. اگر فقط `@keyframes` بنویسی و به هیچ عنصری وصل نکنی، هیچ‌چیز تکان نمی‌خورد.»

### سؤال کلاسی

- «تغییر رنگ hover را با animation می‌نویسیم یا transition؟»  
  **پاسخ:** transition. آن تغییر به حالت hover وصل است و با رفتن ماوس باید برگردد. animation برای وقتی است که فیلمنامه را خودت از صفر تا صد تعریف می‌کنی، اغلب بدون اینکه کاربر روی عنصر بماند.

## ۲) فیلمنامه پالس

نام انیمیشن را خودت انتخاب می‌کنی. در جزوه `pulse` است. در فایل زنده اگر چند دمو داری اسم را خاص کن تا با دموی جزوه قاطی نشود؛ برای کلاس همان `pulse` روشن است.

```css
@keyframes pulse {
  0%, 100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.08);
  }
}
```

«۰٪ شروع است، ۵۰٪ وسط زمان، ۱۰۰٪ پایان. می‌توانی به‌جای ۰ و ۱۰۰ بنویسی `from` و `to`. اینجا هم اول و هم آخر مقیاس ۱ است و وسط ۸ درصد بزرگ‌تر. چون اول و آخر یکی است، اگر انیمیشن تکرار شود پرش بین دورها کمتر دیده می‌شود.

عددها درصدِ **زمان** انیمیشن‌اند، نه درصد اندازه. اندازه را داخل ایستگاه می‌نویسی (`scale`).

حالا وصل کن:»

```css
.cta {
  display: inline-block;
  padding: 12px 18px;
  background: #0b6e4f;
  color: white;
  text-decoration: none;
  border-radius: 8px;
  animation: pulse 1.4s ease-in-out infinite;
}
```

کوتاه‌شده `animation` به ترتیب رایج:

| بخش | مقدار این دکمه | معنی |
|------|-----------------|------|
| نام | `pulse` | کدام `@keyframes` |
| مدت | `1.4s` | یک دور چقدر طول بکشد |
| timing | `ease-in-out` | ریتم داخل همان دور |
| تعداد | `infinite` | تمام نشود |

«شکل بلندش را یک‌بار روی برد بنویس تا ترتیب کوتاه‌شده حفظی نباشد:

```css
animation-name: pulse;
animation-duration: 1.4s;
animation-timing-function: ease-in-out;
animation-iteration-count: infinite;
```

اگر مدت را فراموش کنی، پیش‌فرض `0s` است و هیچ حرکتی نمی‌بینی. این باگ بی‌صدا است. اولین چیزی که چک می‌کنی: اسم keyframes دقیقاً همان نام `animation` باشد، و مدت صفر نباشد.»

**در مرورگر:** دکمه آرام بزرگ و کوچک می‌شود. `1.08` را موقتاً `1.4` کن تا اغراق دیده شود، بعد برگردان. «۱٫۴ برابر برای دعوت به عمل، داد زدن است. ۸ درصد هم اگر بی‌نهایت تکرار شود زیاد است؛ پایین‌تر درباره‌اش حرف می‌زنیم.»

جزوه در keyframes واقعی دمو، `opacity` را هم کمی کم و زیاد کرده. اگر خواستی همان را نشان بده:

```css
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.08); opacity: 0.85; }
}
```

یک جمله: چشمک تند نساز. کم کردن opacity تا ۰٫۸۵ یعنی کمی عقب رفتن، نه خاموش و روشن شدن.

### سؤال کلاسی

- «اگر `infinite` را برداریم چند بار اجرا می‌شود؟»  
  **پاسخ:** یک‌بار. پیش‌فرض `animation-iteration-count` برابر ۱ است.

## ۳) این پالس را کجا بگذاریم و کجا نگذاریم

«یک دکمه اصلی در اول صفحه، آن هم اگر واقعاً باید دیده شود. نه هر کارت محصول، نه هر تیتر، نه آیکون شبکه‌های اجتماعی در پاصفحه.

اگر همه‌چیز حرکت کند، هیچ‌چیز مهم نیست و بعضی کاربرها، به‌خصوص با حساسیت به حرکت، حالشان بد می‌شود. برای همین بخش reduced motion این درس اختیاری نیست؛ بخشی از خود انیمیشن است.

جایگزین آرام‌تر برای «توجه» گاهی همان transition روی hover است که جلسه قبل ساختی، بدون هیچ حرکتِ خودبه‌خود. اگر در طراحی تردید داری، پالس را حذف کن. صفحه خراب نمی‌شود.»

عمداً یک نسخه بد بساز و سریع پاک کن: سه جعبه با `infinite` و مدت `0.3s` و `scale(1.3)`. «این همان اشتباه جزوه است: چند انیمیشن بی‌وقفه روی صفحه. حس اتمام کار نمی‌دهد.»

## ۴) ورود یک‌باره — برچسب «جدید»

نیاز: کنار نام دوره، برچسب یک‌بار از کمی آن‌طرف‌تر وارد شود و بماند. نباید بی‌نهایت تکرار شود.

در صفحه راست‌چین، «از سمت بیرون آمدن» را با `translateX` کم آزمایش کن. مقدار مثبت و منفی را زنده عوض کن تا جهت با `dir="rtl"` همان چیزی شود که می‌خواهی ببینی؛ حفظ کردن علامت مثبت به‌تنهایی دانشجو را گیج می‌کند. جزوه برای دمو از `translateX(20px)` به صفر رفته است.

```html
<p class="course">
  CSS میانی
  <span class="badge">جدید</span>
</p>
```

```css
@keyframes slide-in {
  from {
    transform: translateX(20px);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

.badge {
  display: inline-block;
  margin-right: 8px;
  padding: 2px 8px;
  background: #1a5fb4;
  color: white;
  border-radius: 999px;
  font-size: 0.85rem;
  animation: slide-in 0.6s ease-out both;
}
```

«`from` و `to` همان ۰٪ و ۱۰۰٪ هستند. مدت ۰٫۶ ثانیه، یک‌بار، `ease-out` یعنی با سرعت بیاید و آرام بایستد.

کلمه `both` مقدار `animation-fill-mode` است. بدون آن، قبل از شروع انیمیشن عنصر با opacity خودش (۱) دیده می‌شود و در یک فریم می‌پرد روی ۰، بعد وارد می‌شود. با `backwards` یا `both`، حالت ایستگاه اول در زمان تأخیر و قبل از شروع هم اعمال می‌شود. `forwards` حالت ایستگاه آخر را بعد از تمام شدن نگه می‌دارد. `both` هر دو را می‌گوید.

برای این برچسب، چون آخر انیمیشن همان `translateX(0)` و opacity برابر ۱ است و با استایل عادی یکی است، `forwards` حیاتی به نظر نمی‌رسد؛ ولی `backwards` جلوی آن پرش فریم اول را می‌گیرد. `both` را بگذار و یک‌بار حذف کن تا اگر پرش دیدی برش گردانی.

`infinite` این‌جا ممنوع است. برچسب «جدید» که هر ۰٫۶ ثانیه دوباره غیب شود، خواندن عنوان را خراب می‌کند.»

**در مرورگر:** رفرش کن. برچسب یک‌بار می‌آید و می‌ایستد. رفرش دوباره. این آزمایش باید آرام باشد؛ اگر دانشجو ندید، رفرش را تکرار کن نه اینکه مدت را ۳ ثانیه کنی.

### سؤال کلاسی

- «فرق این slide با transition روی hover چیست؟»  
  **پاسخ:** این یکی با بار شدن صفحه خودش شروع می‌شود و به ماندن ماوس وابسته نیست. یک‌بار اجرا می‌شود و تمام.

## ۵) کنترل‌هایی که واقعاً استفاده می‌کنی

همه ویژگی‌ها را فهرست نکن. این چهار تا را روی همان برچسب آزمایش کن و برگردان:

**تعداد**

```css
animation-iteration-count: 3;
```

«سه بار وارد می‌شود. برای برچسب، ۱ درست است. برای پالس، `infinite` بود. عدد را از روی نیاز بگذار نه از روی دمو.»

**جهت**

```css
animation-direction: alternate;
```

«یک دور رفت، دور بعد برگشت. روی پالس، چون خود keyframes از ۱ به ۱٫۰۸ و دوباره به ۱ می‌رود، `alternate` اغلب لازم نیست و حرکت را نامتقارن می‌کند. نشان بده و بردار.»

**تأخیر**

```css
animation-delay: 0.4s;
```

«اگر چند برچسب با هم وارد شوند، تأخیر کوتاه باعث می‌شود هم‌زمان داد نزنند. با تأخیر، اهمیت `both` بیشتر می‌شود وگرنه در آن ۰٫۴ ثانیه برچسب کامل دیده می‌شود و بعد ناگهان انیمیشن از opacity صفر شروع می‌کند.»

**توقف**

```css
.cta:hover {
  animation-play-state: paused;
}
```

«با رفتن ماوس روی دکمه، پالس می‌ایستد تا متن را راحت‌تر بخوانند یا کلیک کنند. اختیاری است. اگر استفاده کردی، بگو این حالت pause است نه transition.»

`animation: none` یعنی هیچ فیلمنامه‌ای نیست. برای خاموش کردن در reduced motion از همین استفاده می‌کنیم.

وارد `steps()` و انیمیشن فریم‌به‌فریم نشو. برای این سطح لازم نیست.

## ۶) prefers-reduced-motion — بخشی از تحویل، نه نکته حاشیه

«بعضی کاربرها در سیستم‌عامل گفته‌اند حرکت کم شود: سرگیجه، حواس‌پرتی، یا صرفاً ترجیح. CSS می‌تواند این را بشنود.

اگر انیمیشن را ساخته‌ای و این شرط را ننوشته‌ای، کار را تمام نکن.»

```css
@media (prefers-reduced-motion: reduce) {
  .cta,
  .badge {
    animation: none;
  }
}
```

«دکمه سر جایش می‌ماند، سبز و خوانا. برچسب «جدید» همان لحظه اول دیده می‌شود، بدون لغزش. اطلاعات حذف نشده؛ فقط حرکت حذف شده.

در DevTools می‌شود این رسانه را شبیه‌سازی کرد: منوی فرمان، «Emulate CSS prefers-reduced-motion». اگر پیدا نکردی، توضیح بده که در سیستم واقعی با روشن بودن کاهش حرکت، این بلوک برنده است. پالس باید بایستد.

transitionهای کوتاه hover را در این درس مجبور نیستی همه را حذف کنی؛ تمرکز روی `infinite` و ورودهای متحرک است. اگر همان فایل درس ۲۳ را ادامه می‌دهی، می‌توانی transition را هم `none` کنی. یک سیاست در کل فایل کافی است.»

**در مرورگر:** شبیه‌سازی را روشن و خاموش کن. این باید آخرین آزمایش زنده باشد تا در ذهن بماند.

### اشتباهات رایج

- اسم `@keyframes` با اسم داخل `animation` یکی نیست → سکوت، بدون حرکت.  
- مدت نوشته نشده → `0s`.  
- `infinite` روی چیزی که باید یک‌بار بیاید.  
- مقیاس‌های بزرگ (بیشتر از حدود ۱٫۱) روی دکمه متنی.  
- انیمیشن روی `width` و `margin` که چیدمان صفحه را در هر فریم تکان می‌دهد. مثل transition، `transform` و `opacity` را ترجیح بده.  
- ننوشتن `prefers-reduced-motion` چون «فقط یک پالس است». همان یک پالس هم اگر کاربر کاهش حرکت خواسته باید خاموش شود.

## ۷) پروژه ترکیبی — دعوت به عمل و برچسب

یک تکه صفحه دوره، نه گالری افکت:

```html
<section class="hero">
  <h1>ثبت‌نام دوره بهار</h1>
  <p>ظرفیت این کلاس <span class="badge">جدید</span> محدود است.</p>
  <a class="cta" href="#form">ثبت‌نام</a>
</section>
```

از همان `pulse` و `slide-in` بالا استفاده کن. علاوه بر آن:

- فقط **یک** عنصر `infinite` داشته باشد: همان `.cta`.  
- برچسب یک‌بار با `both` وارد شود.  
- مدت پالس حدود ۱٫۴s و مقیاس حداکثر حدود ۱٫۰۸.  
- بلوک `prefers-reduced-motion` هر دو را `animation: none` کند.  
- یک hover ساده با transition روی رنگ لینک مجاز است، به شرطی که با انیمیشن بی‌وقفه قاطی توضیح داده شود: «این یکی هنوز transition است.»

**چک:** رفرش برای ورود برچسب؛ ده ثانیه صبر برای اینکه پالس آزاردهنده نشده؛ شبیه‌سازی reduced motion برای ایستادن هر دو.

اگر دانشجو خواست پس‌زمینه هیرو هم آرام رنگ عوض کند، نپذیر. یک حرکت تکراری در صفحه کافی است.

## ۸) جمع‌بندی مدرس و سؤالات پایانی

1. transition به چه وصل است و animation به چه؟  
   **پاسخ:** transition به عوض شدن یک ویژگی بین دو حالت (مثل hover و عادی). animation به فیلمنامه‌ای که در `@keyframes` نوشته‌ای و خودش زمان‌بندی دارد.

2. `infinite` را روی کدام قطعه این جلسه گذاشتیم و روی کدام نذاشتیم؟  
   **پاسخ:** روی پالس دکمه دعوت به عمل. روی برچسب «جدید» نه؛ آن یک‌بار وارد می‌شود.

3. `both` چه کمکی به ورود برچسب می‌کند؟  
   **پاسخ:** حالت ایستگاه اول را قبل از شروع (و حالت آخر را بعد از پایان) نگه می‌دارد تا فریم اول نپرد.

4. اگر کاربر کاهش حرکت را روشن کرده باشد چه می‌نویسی؟  
   **پاسخ:** داخل `@media (prefers-reduced-motion: reduce)` مقدار `animation: none` روی همان عنصرها.

**پیام پایانی:**

«انیمیشن ابزار کم‌مصرف است. یک فیلمنامه کوتاه با `transform` و `opacity`، یک دکمه که اگر لازم است آرام تکرار شود، یک ورود که تکرار نشود، و یک شرط که اگر کاربر حرکت نمی‌خواهد همه را خاموش کند. بیشتر از این، در این دوره لازم نیست.»

جزوه: برچسب «جدید» با یک‌بار slide-in.

### ساده
1. دکمه «ثبت‌نام» با `@keyframes pulse` مطابق جزوه: مقیاس ۱ و ۱٫۰۸، مدت حدود `1.4s`، `ease-in-out`، `infinite`.  
2. همان دکمه را بدون `infinite` هم یک‌بار نشان بده و در یک جمله فرق را بنویس.

### متوسط
3. برچسب «جدید» با `from` / `to`، opacity و translate، مدت زیر ۱ ثانیه، `animation-fill-mode` طوری که پرش فریم اول نباشد. تکرار نشود.  
4. روی پالس، `animation-play-state: paused` هنگام hover.

### چالشی
5. هر دو قطعه در یک بخش معرفی دوره، به‌علاوه `@media (prefers-reduced-motion: reduce)` که هر دو انیمیشن را حذف کند. در DevTools یا با توضیح شبیه‌سازی نشان بده حرکت می‌ایستد و متن می‌ماند.  
6. توضیح بده چرا برای عوض شدن رنگ یک لینک در hover، به‌جای keyframes از transition استفاده می‌کنی.
