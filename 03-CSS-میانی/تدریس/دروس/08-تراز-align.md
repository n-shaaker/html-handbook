## ۱) شروع کلاس؛ مسئله واقعی سایت

«بچه‌ها، بالای صفحه یک **هیرو** داریم. یک تیتر کوتاه، یک جمله معرفی، و زیرش یک ستون متن که نباید تمام عرض مانیتور را بگیرد، چون خط خیلی بلند ناخوانا می‌شود.

طراح گفته: تیتر وسط باشد، و آن ستون باریک هم وسط صفحه باشد.

خیلی از دانشجوها هر دو خواسته را با یک خط حل می‌کنند:

```css
.hero {
  text-align: center;
}
```

تیتر وسط می‌آید. ستون متن هم اگر تمام عرض پدر را گرفته باشد، جعبه‌اش تکان نمی‌خورد؛ فقط کلمه‌های داخلش وسط‌چین می‌شوند. این دو تا خواسته، دو تا ابزارند.»

فایل زنده (پیشنهاد: `تدریس/live/08-align.html`):

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — تراز</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      margin: 0;
      background: #f1f5f9;
      line-height: 1.7;
    }
    .hero {
      background: #1e293b;
      color: #f8fafc;
      padding: 2rem 1rem;
    }
    .hero h1 { margin: 0 0 0.5rem; }
    .narrow {
      background: #fff;
      color: #0f172a;
      padding: 1rem;
    }
  </style>
</head>
<body>
  <header class="hero">
    <h1>آموزش طراحی وب</h1>
    <p>یک جمله معرفی، خوانا و کوتاه.</p>
  </header>
  <div class="narrow">
    <p>
      این ستون باید باریک بماند و وسط صفحه بنشیند.
      اگر فقط متن را وسط کنیم، خود جعبه همچنان از لبه تا لبه است.
    </p>
  </div>
</body>
</html>
```

**در مرورگر:** تیتر سمت شروع خط است (در فارسی، راست). جعبه سفید تمام عرض را گرفته. هنوز هیچ تراز افقی‌ای ننوشته‌ایم. بگو: «اول مشخص کنید چه چیزی را وسط می‌کنید.»

دو سؤال را روی تخته بنویس و تا آخر جلسه پاک نکن:

۱. محتوای داخل جعبه (حروف، لینک، تصویر inline) را افقی کجا بگذارم؟  
۲. خود جعبه block را در پدر کجا بگذارم؟

### سؤال کلاسی

- «وسط‌چین در CSS یک ویژگی واحد به نام `align: center` دارد؟»  
  **پاسخ:** بسته به هدف، `text-align`، `margin` با `auto`، یا بعدها Flex و Grid. اسم ابزار از روی «چه چیزی» می‌آید.

## ۲) `text-align` — حروف و عنصرهای inline داخل جعبه

«`text-align` محتوای داخل جعبه را افقی تراز می‌کند: متن، و عنصرهایی که در خط نشسته‌اند. خود جعبه بلوکی را در پدر جابه‌جا نمی‌کند.»

```css
.hero {
  text-align: center;
}
```

**در مرورگر:** `h1` و پاراگراف معرفی وسط ناحیه تیره قرار می‌گیرند. جعبه `.narrow` هنوز تمام عرض است. اگر داخل `.narrow` هم `text-align: center` بگذاری، فقط جمله‌های داخل سفید وسط می‌شوند؛ لبه‌های سفید از لبه صفحه جدا نمی‌شوند.

مقادیر را سریع نشان بده:

```css
.hero { text-align: start; }   /* در فارسی: راست */
.hero { text-align: end; }     /* در فارسی: چپ */
.hero { text-align: center; }
```

«`start` و `end` به جهت صفحه نگاه می‌کنند. `left` و `right` فیزیکی‌اند و با `dir` عوض نمی‌شوند. برای متن فارسی، اگر منظورت «سمت شروع خواندن» است، `start` روشن‌تر از `right` است. برای هیرو، خواسته طراح `center` است؛ برگردان به `center`.»

یک `span` نشان را هم داخل تیتر بگذار تا دانشجو ببیند inline هم با همین ویژگی می‌رود وسط، چون جزئی از خط است:

```html
<h1>آموزش طراحی وب <span class="badge">جدید</span></h1>
```

```css
.badge {
  display: inline-block;
  padding: 0.1rem 0.5rem;
  background: #f59e0b;
  color: #1e293b;
  border-radius: 999px;
  font-size: 0.75rem;
}
```

**در مرورگر:** نشان همراه تیتر وسط خط است. این همان inline-block درس قبل است که حالا داخل محتوای وسط‌چین نشسته.

### سؤال کلاسی

- «`text-align: center` را روی `.narrow` گذاشتیم و عرض جعبه سفید عوض نشد. چرا؟»  
  **پاسخ:** این ویژگی محتوای داخل را تراز می‌کند. عرض جعبه block هنوز مال جریان عادی است: تمام عرض در دسترس پدر.

### اشتباهات رایج

- انتظار اینکه `text-align: center` روی یک `div`، خود آن `div` را به وسط صفحه ببرد.  
- وسط کردن دکمه block تمام‌عرض با `text-align` روی پدر، در حالی که خود دکمه `width: 100%` است. متن دکمه وسط می‌شود؛ دکمه از قبل تمام عرض را گرفته.

### انتقال

«تیتر درست شد. حالا خود ستون سفید باید از عرض صفحه کوتاه‌تر شود و در فضای خالی وسط بایستد.»

## ۳) `margin: auto` — خود جعبه block را افقی وسط کن

«`margin: auto` فضای خالی افقی را بین دو طرف جعبه تقسیم می‌کند. این فضا فقط وقتی وجود دارد که عرض جعبه از عرض والد کمتر باشد.

عنصر بلوکی بدون `width` یا `max-width` از قبل همه عرض را گرفته. در آن حالت `auto` چیزی برای تقسیم ندارد و جعبه تکان نمی‌خورد.»

اول این را عمداً خراب کن تا جمله بالا دیده شود:

```css
.narrow {
  margin: 0 auto;
  background: #fff;
  color: #0f172a;
  padding: 1rem;
}
```

**در مرورگر:** هیچ جابه‌جایی افقی نیست. در DevTools عرض `.narrow` را نشان بده؛ برابر عرض پدر است. حاشیه auto به صفر محاسبه شده.

بعد سقف عرض را از درس حداکثر عرض بیاور:

```css
.narrow {
  width: 50%;
  margin: 0 auto;
  background: #fff;
  color: #0f172a;
  padding: 1rem;
}
```

**در مرورگر:** جعبه نصف عرض پدر است و دو طرفش فضای مساوی. این مثال ۲ جزوه است. `margin: 0 auto` یعنی حاشیه بالا و پایین صفر، چپ و راست auto.

«روی صفحه خیلی پهن، ۵۰٪ ممکن است هنوز خط را بلند کند. الگوی خواناتر برای ستون متن:»

```css
.narrow {
  width: 100%;
  max-width: 36rem;
  margin: 0 auto;
  box-sizing: border-box;
}
```

«`width: 100%` روی موبایل ستون را به پدر می‌چسباند. `max-width` روی دسکتاپ نمی‌گذارد از حدود ۳۶rem پهن‌تر شود. فضای اضافه دو طرف با `auto` نصف می‌شود. `box-sizing: border-box` را یادآوری کن تا padding جزو همان عرض بماند و جعبه از پدر نزند بیرون.»

یک بار `max-width` را بردار و فقط `width: 100%` بگذار تا دانشجو ببیند auto بی‌اثر می‌شود. بعد برگردان.

### سؤال کلاسی

- «جعبه `width: 100%` و `margin: 0 auto` دارد و وسط نمی‌آید. کدام شرط جزوه برقرار نیست؟»  
  **پاسخ:** عرض از پدر کمتر نیست؛ فضای خالی افقی برای تقسیم نمانده.

- «`margin-top: auto` در همین جریان عادی، جعبه را به کف پدر می‌چسباند؟»  
  **پاسخ:** در جریان عادی صفحه، auto برای حاشیه عمودی این وسط‌کردن را انجام نمی‌دهد. جزوه می‌گوید `margin: auto` اینجا افقی کار می‌کند.

### اشتباهات رایج

- فقط `margin: auto` بدون کم کردن عرض.  
- `text-align: center` روی پدرِ `.narrow` به امید جابه‌جا شدن خود ستون. اگر داخل ستون پاراگراف باشد، متن وسط می‌شود و جعبه سر جایش می‌ماند.  
- فراموش کردن `box-sizing` وقتی هم `width: 100%` داری و هم padding زیاد؛ ممکن است اسکرول افقی بگیری و فکر کنی `auto` خراب است.

## ۴) تصویر — inline است، پس اول نوع جعبه‌اش را مشخص کن

«تصویر به‌صورت پیش‌فرض inline است. `margin: auto` روی آن، مثل یک block با عرض معلوم، دو طرف را باز نمی‌کند. جزوه دو راه داده.»

راه اول، خود تصویر را block کن و عرض بده:

```html
<img class="center-img" src="../images/bg.jpg" alt="تصویر نمونه وسط‌چین">
```

```css
.center-img {
  display: block;
  width: 200px;
  height: 120px;
  object-fit: cover;
  margin: 0 auto;
}
```

**در مرورگر:** تصویر ۲۰۰ پیکسلی وسط پدر. بدون `display: block` همین `margin: 0 auto` را امتحان کن تا بی‌اثری را ببینند، بعد block را برگردان.

راه دوم، پدر را `text-align: center` کن و تصویر inline بماند:

```css
.figure { text-align: center; }
.center-img {
  display: inline;
  width: 200px;
  margin: 0;
}
```

«این‌جا خودِ جعبه block را وسط نکرده‌ای. تصویر را مثل یک کلمه، با تراز متن پدر، وسط خط گذاشته‌ای. هر دو راه در جزوه معتبرند. برای یک تصویر تنها در ستون، `display: block` و `margin: 0 auto` پیش‌بینی‌پذیرتر است، چون دیگر به `text-align` پاراگراف‌های همسایه وابسته نیست.»

اگر تصویر را داخل `.narrow` می‌گذاری، پدر از قبل وسط صفحه است. تصویر block با `margin: 0 auto` وسط همان ستون وسط می‌شود. این دو لایه را با هم قاطی نکن: اول ستون در صفحه، بعد تصویر در ستون.

### سؤال کلاسی

- «عکس `float: right` از درس قبل را می‌شود با `margin: auto` هم وسط کرد؟»  
  **پاسخ:** float عنصر را به یک لبه می‌برد تا متن دورش بپیچد. وسط کردن تصویر تنها، float نمی‌خواهد. float را خاموش کن، بعد block و auto.

### اشتباهات رایج

- `margin: 0 auto` روی `img` بدون `display: block` و بدون عرض کمتر از پدر.  
- `text-align: center` روی خود `img`. تراز را به پدر بده، یا خود عکس را block کن.

## ۵) عمودی — padding برابر، و ترفند یک‌خطی `line-height`

«وسط کردن عمودی در جریان عادی با `text-align` و `margin: auto` به دست نمی‌آید. جزوه دو تقریب نشان می‌دهد و هر دو را محدود معرفی می‌کند.»

### padding بالا و پایین برابر

```css
.pad-center {
  padding: 40px 0;
  text-align: center;
  background: #e2e8f0;
}
```

```html
<div class="pad-center">با padding برابر، بالا و پایین هوا یکسان است</div>
```

**در مرورگر:** متن یک خط، ۴۰ پیکسل هوا بالا و ۴۰ پیکسل پایین. این وسط‌دیدن از مساوی گذاشتن فضا می‌آید، نه از سنتر کردن داخل یک ارتفاع ثابت. اگر جمله دو خط شود، باز هم padding بالا و پایین برابر است و جعبه بلندتر می‌شود. برای یک نقل‌قول کوتاه در هیرو این الگو کافی و سالم است.

### یک خط داخل ارتفاع ثابت

```css
.line-center {
  height: 80px;
  line-height: 80px;
  text-align: center;
  background: #dbeafe;
}
```

```html
<div class="line-center">یک خط، وسطِ وسط</div>
```

**در مرورگر:** آن یک خط در نوار ۸۰ پیکسلی عمودی وسط دیده می‌شود، چون ارتفاع خط با ارتفاع جعبه یکی است. افقی را هنوز `text-align` داده.

حالا متن را دو خط کن:

```html
<div class="line-center">خط اول<br>خط دوم</div>
```

**در مرورگر:** هر خط می‌خواهد ۸۰ پیکسل ارتفاع خط داشته باشد. متن از جعبه می‌زند بیرون. جزوه همین را اشتباه رایج نامیده: این ترفند فقط برای یک خط کوتاه است؛ متن دکمه، نشان، یک کلمه در نوار. برای پاراگراف چندخطی از آن استفاده نکن.

`vertical-align: middle` را روی `.line-center` که یک `div` بلوکی است امتحان کن.

**در مرورگر:** تغییری نمی‌بینی. جزوه می‌گوید `vertical-align` روی div معمولی در جریان block اثر ندارد؛ جایش inline، inline-block و سلول جدول است. درس قبل روی کارت‌های inline-block از آن استفاده کردیم. اینجا جعبه block را با آن وسط نکن.

### سؤال کلاسی

- «بنر ۲۰۰ پیکسلی با سه خط متن. `line-height: 200px` مناسب است؟»  
  **پاسخ:** هر خط به اندازه کل ارتفاع کش می‌آید و متن بیرون می‌زند. برای چند خط، padding برابر یا روش بخش بعد.

### اشتباهات رایج

- قفل کردن `height` و `line-height` روی تیتری که در موبایل دو خط می‌شود.  
- انتظار وسط عمودی از `margin: auto` در همین مقاله معمولی.

## ۶) وسط هر دو جهت — سه روش جزوه، بدون عمق اضافه

«وقتی یک فرزند باید هم افقی و هم عمودی وسط یک قاب با ارتفاع مشخص باشد (پخش روی ویدیو، پیام «در حال بارگذاری»، بنر)، جریان عادی را رها می‌کنیم. جزوه سه روش دارد. امروز کد را ببینید و کاربرد را به هم وصل کنید. Flex و Grid را در ماژول خودشان باز می‌کنیم؛ position را هم قبلاً داشته‌اید.»

### روی هم افتادن: `position` و `transform`

```css
.pos-parent {
  position: relative;
  height: 150px;
  background: #e2e8f0;
}

.pos-child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  background: #fff;
  padding: 0.5rem 1rem;
}
```

«`top` و `left` پنجاه درصد، گوشه بالای-چپ فرزند را به مرکز پدر می‌برد. `translate(-50%, -50%)` فرزند را به اندازه نصف عرض و نصف ارتفاع **خودش** برمی‌گرداند تا مرکزش روی مرکز پدر بنشیند. این روش برای چیزی است که روی عنصر دیگر قرار می‌گیرد، مثل دکمه پخش روی تصویر. از جریان خارج می‌شود؛ پدر باید ارتفاع جدا داشته باشد وگرنه جمع می‌شود.»

**در مرورگر:** یک جمله کوتاه دقیقاً وسط قاب ۱۵۰ پیکسلی. متن را بلندتر کن تا ببینی جعبه سفید هنوز از مرکز خودش سنتر است.

### Flexbox — روش ساده‌تر برای قاب

```css
.flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 150px;
  background: #dcfce7;
}
```

«`justify-content` در ردیف، محور افقی را وسط می‌کند. `align-items` محور عمودی را. فرزند در جریان flex می‌ماند. نام ویژگی‌ها را امروز حفظ اجباری نکن؛ ببینید که یک پدر با ارتفاع، فرزند را در هر دو جهت وسط کرده.»

### Grid — یک خط برای همان کار

```css
.grid-center {
  display: grid;
  place-items: center;
  height: 150px;
  background: #ede9fe;
}
```

«`place-items: center` یعنی هر دو جهت. جزوه این را برای یک فرزند، مثل محتوای یک پنجره یا صفحه انتظار، کوتاه‌ترین روش نامیده. عمق Grid مال بعد است.»

جدول جزوه را روی تخته کپی کن:

| می‌خواهم ... | روش |
|--------------|------|
| متن یا inline را افقی وسط کنم | `text-align: center` روی پدر |
| جعبه block با عرض مشخص را افقی وسط کنم | `margin: 0 auto` |
| هر چیزی را افقی و عمودی وسط یک قاب کنم | Flex یا Grid روی پدر |
| عنصری را روی عنصر دیگر وسط کنم | `position: absolute` و `transform` |

### سؤال کلاسی

- «هیروی اول کلاس فقط تیتر و یک جمله بود، بدون قاب با ارتفاع ثابت. کدام ردیف جدول کافی است؟»  
  **پاسخ:** ردیف اول، `text-align: center`. لازم نیست برای یک تیتر، absolute بنویسی.

### اشتباهات رایج

- `position: absolute` برای وسط کردن ستون متن مقاله. متن از جریان خارج می‌شود و بقیه صفحه زیرش می‌آید.  
- کپی کردن Flex وسط‌چین روی پاراگراف طولانی مقاله، در حالی که فقط خوانایی خط با `max-width` و `margin: auto` لازم بوده.

## ۷) پروژه جلسه — بنر ۲۰۰ پیکسل با تیتر و دکمه وسط

تمرین جزوه: بنری به ارتفاع ۲۰۰ پیکسل که تیتر و دکمه دقیقاً وسط آن باشند. این هر دو جهت است، پس از جدول، ردیف Flex (یا Grid) را انتخاب کن. کنارش یک ستون معرفی با `max-width` و `margin: auto` بگذار تا هر دو مسئله اول کلاس در یک صفحه جمع شود.

```html
<section class="banner">
  <div class="banner-inner">
    <h1>کلاس‌های پاییز</h1>
    <a class="btn" href="#signup">ثبت‌نام</a>
  </div>
</section>

<article class="narrow">
  <h2>برنامه هفته</h2>
  <p>
    جلسه‌ها عصرها برگزار می‌شود. این متن باید در ستونی باریک و وسط صفحه خوانده شود،
    نه به شکل یک خطِ تمام‌عرض.
  </p>
</article>
```

```css
.banner {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
  background: #1e293b;
  color: #f8fafc;
  text-align: center;
}

.banner-inner h1 { margin: 0 0 0.75rem; }

.btn {
  display: inline-block;
  padding: 0.5rem 1.25rem;
  background: #f59e0b;
  color: #1e293b;
  text-decoration: none;
  border-radius: 6px;
}

.narrow {
  width: 100%;
  max-width: 36rem;
  margin: 1.5rem auto;
  padding: 1rem 1.25rem;
  background: #fff;
  box-sizing: border-box;
}
```

«ببینید تقسیم کار را:

- بنر ارتفاع ثابت دارد و دو چیز را در هر دو جهت می‌خواهد → flex روی پدر. `text-align: center` متن داخل گروه را وسط خط نگه می‌دارد.  
- دکمه `inline-block` است تا padding واقعی داشته باشد؛ وسط شدنش مال پدر است.  
- مقاله زیر بنر جعبه block است → `max-width` به‌علاوه `margin: 1.5rem auto`. حاشیه عمودی این‌جا عدد ثابت است.»

**در مرورگر:** ارتفاع را در DevTools از ۲۰۰ به ۱۲۰ کم کن؛ تیتر و دکمه باید هنوز وسط قاب بمانند. بعد `align-items` را بردار تا به بالا بچسبند و دوباره برگردان. عرض را باریک کن؛ `.narrow` باید تا ۱۰۰٪ پدر جمع شود و اسکرول افقی نسازد.

اگر کسی بنر را با `line-height: 200px` ساخت، دکمه و تیتر با هم یک خط نمی‌مانند. همان ضدالگو را ده ثانیه نشان بده و به flex برگرد.

نسخه Grid را به‌عنوان جایگزین هم‌ارز، فقط روی `.banner`، یک بار عوض کن:

```css
.banner {
  display: grid;
  place-items: center;
  height: 200px;
}
```

بگو هر دو قابل قبول‌اند. در این کلاس یکی را تا آخر پروژه نگه دارید. پیشنهاد مدرس: flex، چون مثال ۷ جزوه همان را برای این کار نشان داده، و Grid را مثال ۸ کنارش گذاشته.

### سؤال حین پروژه

- «اگر ارتفاع بنر را حذف کنیم، `align-items: center` هنوز فاصله عمودی می‌سازد؟»  
  **پاسخ:** بدون ارتفاع (یا بدون فضای اضافه در محور)، چیزی برای وسط کردن عمودی نمی‌ماند و بنر به اندازه محتوا جمع می‌شود.

## ۸) جمع‌بندی مدرس و سؤالات پایانی

۱. تیتر و جمله داخل هیرو باید وسط شوند. کدام ویژگی، و روی کدام عنصر؟  
   **پاسخ راهنما:** `text-align: center` روی پدر (خود هیرو).

۲. یک `div` با `max-width: 36rem` باید وسط صفحه باشد. چه می‌نویسیم، و چرا بدون `max-width` یا `width` تکان نمی‌خورد؟  
   **پاسخ راهنما:** `margin: 0 auto` یا `margin-inline: auto`. بدون عرض کمتر از پدر، فضای خالی افقی برای `auto` نیست.

۳. چرا `line-height` برابر `height` برای متن چندخط بنر مناسب نیست، و به‌جایش روی بنر ۲۰۰ پیکسلی چه نوع نمایشی می‌گذاریم؟  
   **پاسخ راهنما:** هر خط به اندازه کل ارتفاع کش می‌آید. برای تیتر و دکمه وسط قاب: `display: flex` با `justify-content` و `align-items`، یا Grid با `place-items: center`.

**پیام پایانی:**

«قبل از تایپ کردن، یک جمله بگو: متن داخل را وسط می‌کنم، یا خود جعبه را، یا هر دو جهت را داخل یک قاب. ابزار از همان جمله درمی‌آید.»

## تمرین‌ها (ساده → چالشی)

### ساده

۱. یک پاراگراف با `text-align: center` و یکی با `start`. در صفحه فارسی بگو `start` کدام لبه است.  
۲. یک جعبه با `width: 50%` و `margin: 0 auto` بساز. بعد عرض را بردار و توضیح بده چرا وسط ماندن قطع شد.

### متوسط

۳. یک تصویر ۲۰۰ پیکسلی را یک بار با `display: block` و `margin: 0 auto` وسط کن و یک بار با `text-align: center` روی پدر.  
۴. یک نوار با `height` و `line-height` برابر ۸۰ پیکسل بساز، بعد داخلش دو خط متن بگذار و بیرون‌زدگی را ثبت کن.

### چالشی

۵. بنر ۲۰۰ پیکسلی پروژه را با تیتر و دکمه بساز (flex یا grid). زیرش ستون `max-width: 36rem` با `margin: auto`.  
۶. روی یک عکس، یک برچسب «پخش» را با `position: absolute` و `translate(-50%, -50%)` وسط عکس بگذار. پدر باید `position: relative` و ارتفاع معلوم داشته باشد.
