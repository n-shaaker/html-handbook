# سناریوی تدریس درس ۱۴: منوی کشویی (Dropdowns)

**صفحه جزوه:** [`pages/14-dropdowns.html`](../../pages/14-dropdowns.html)  
**پیش‌نیاز:** [نوار منو](./13-نوار-منو.md) · `:hover` (درس ۱۰)  
**مدت پیشنهادی:** حدود ۸۵ دقیقه  
**هدف:** submenu با `ul` تو در تو، مخفی/نمایش با `:hover` (و `:focus-within` intro)، `position: absolute`، combinator `nav > ul > li > a` برای سطح اول.

## ۱) شروع — مسئله (دیالوگ)

«منوی افقی ۱۲ لینk — شلوغ. UX: گروه «آموزش» با زیرمنو CSS/HTML/JS.

**بدون JS** (سطح این درس): `:hover` روی `li` زیرمنو را نشان دهد — با keyboard `:focus-within` هم لازم است.»

```html
<nav class="dropdown-nav" aria-label="منوی اصلی">
  <ul>
    <li><a href="#">خانه</a></li>
    <li class="has-sub">
      <a href="#">آموزش</a>
      <ul>
        <li><a href="#">HTML</a></li>
        <li><a href="#">CSS</a></li>
      </ul>
    </li>
  </ul>
</nav>
```

---

## ۲) Live — پایه navbar + nested reset

```css
.dropdown-nav ul {
  list-style: none;
  margin: 0;
  padding: 0;
}
.dropdown-nav > ul > li {
  display: inline-block;
  position: relative;
}
.dropdown-nav > ul > li > a {
  display: block;
  padding: 14px 16px;
  background: #333;
  color: #fff;
  text-decoration: none;
}
```

---

## ۳) مخفی کردن submenu

```css
.dropdown-nav li ul {
  display: none;
  position: absolute;
  top: 100%;
  inset-inline-start: 0;
  min-width: 10rem;
  background: #444;
  z-index: 10;
}
.dropdown-nav li ul a {
  display: block;
  padding: 10px 16px;
  color: #fff;
  text-decoration: none;
}
.dropdown-nav li ul a:hover {
  background: #222;
}
```

---

## ۴) نمایش با hover و focus-within

```css
.dropdown-nav li:hover > ul,
.dropdown-nav li:focus-within > ul {
  display: block;
}
```

«**focus-within** — Tab به لینk داخل submenu، menu باز بماند.»

**در مرورگر:** [`14-dropdowns.html`](../../pages/14-dropdowns.html) + [`dropdowns.css`](../../css/demos/dropdowns.css).

### سؤال کلاسی

«فقط `:hover` بدون focus-within?»  
**پاسخ:** keyboard user submenu نمی‌بیند — a11y fail.

---

## ۵) combinator — استایل سطح اول

```css
.dropdown-nav > ul > li > a {
  /* فقط top level */
}
.dropdown-nav li ul a {
  /* submenu darker */
}
```

«درس ۹ — `nav a` همه سطوح را می‌زند.»

---

## ۶) اشتباهات

- submenu بدون `position: absolute` — layout shift.  
- z-index بدون stacking context.  
- hover-only mobile (touch) — اشاره به JS hamburger در media query.

---

## ۷) پروژه mini

nav با یک dropdown «دوره‌ها» — hover + focus-within.

---

## ۸) جمع‌بندی

1. چرا `li { position: relative }`?  
   **پاسخ:** anchor for absolute submenu.

2. focus-within?  
   **پاسخ:** keyboard open submenu.
