## ۱) شروع؛ این صفحه قرار است چه کاری بکند

«امروز درس تازه با اسم جدید نداریم. صفحه معرفی‌ای که در HTML ساخته بودید ظاهر ندارد: فونت پیش‌فرض، لینک آبی زیرخط‌دار، عکس مربعی، جدول به‌هم‌ریخته، و هیچ فکری برای عرض ۳۲۰px.

جزوه دو بخش کرده. بخش اول مال دوره مقدماتی است: فونت، رنگ، عکس، لینک، جدول. بخش دوم مال همین دوره است: وسط چین ظرف، منوی چسبان، زیرمنو، مهارت، دو ستون، نشان، فرم، تیتر سیال، خط تزئینی، دکمه بازگشت به بالا، و پیمایش کیبورد.

قانون جلسه: هر گام را که نوشتم در مرورگر می‌بینیم، بعد گام بعد. آخر سر همه‌ی CSS را یکجا تایپ نمی‌کنیم.»

اگر HTML معرفی از قبل ندارند، اسکلت را با همین نقش‌ها بده، نه با `div`های بی‌نام. `head` حتماً viewport و `link` به `css/profile.css` داشته باشد.

```html
<body>
  <header class="site-header">
    <p class="brand">سارا محمدی</p>
    <nav class="site-nav" aria-label="بخش‌های صفحه">
      <ul class="menu">
        <li><a class="active" href="#about">درباره</a></li>
        <li>
          <a href="#work">نمونه‌کارها</a>
          <ul>
            <li><a href="#work">وب</a></li>
            <li><a href="#work">گرافیک</a></li>
          </ul>
        </li>
        <li><a href="#contact">تماس</a></li>
      </ul>
    </nav>
  </header>
  <div class="wrapper">
    <div class="row">
      <main id="about">
        <div class="avatar-box">
          <img src="avatar.jpg" alt="پرتره سارا محمدی" width="160" height="160">
          <span class="online">آنلاین</span>
        </div>
        <h1>سلام، من سارا هستم</h1>
        <h2>مهارت‌ها</h2>
        <ul class="tags"><li>HTML</li><li>CSS</li></ul>
        <div class="bar"><div class="fill w80">۸۰٪</div></div>
        <h2 id="work">نمونه‌کارها</h2>
        <!-- جدول دو ردیفه پروژه / سال -->
      </main>
      <aside>
        <h2>راه‌های ارتباطی</h2>
        <p>تهران — پاسخ‌گویی در روزهای کاری</p>
      </aside>
    </div>
    <section id="contact">
      <h2>تماس با من</h2>
      <!-- form با label برای نام و پیام -->
    </section>
  </div>
  <footer class="site-footer">© ۱۴۰۵</footer>
  <a class="to-top" href="#about">بالای صفحه</a>
</body>
```

«viewport را همان اول بگذار. درس ۲۱: بدون آن، media query آخر جلسه در گوشی دروغ می‌گوید. `alt` پرتره را خالی نگذار. کلاس `.w80 { width: 80%; }` را در CSS بگذار تا درصد را داخل style ننویسی.»

**در مرورگر:** صفحه خام و بلند. بگو «تا پایان جلسه باید بتوانم در ۳۲۰px بدون اسکرول افقی بخوانم و با Tab به فرم برسم.»

## ۲) بخش اول جزوه — ظاهر مقدماتی

فایل `css/profile.css`. هر زیرگام را ذخیره کن و رفرش کن.

**فونت و زمینه**

```css
body {
  margin: 0;
  font-family: Tahoma, sans-serif;
  background: #f7f9fc;
  color: #222;
  line-height: 1.8;
}
```

«اگر Vazirmatn را در پروژه دوره وصل کرده‌اید، همان خانواده جزوه را بگذارید: `"Vazirmatn", Tahoma, sans-serif`. خط خالی `margin: 0` را جا نینداز؛ وگرنه فاصله پیش‌فرض body با لبه، منوی چسبان را چند پیکسل پایین می‌اندازد.»

**تیترها**

```css
h1, h2 {
  color: #1a3a5c;
  border-bottom: 2px solid #d9e2ec;
  padding-bottom: 0.25rem;
}
```

جزوه بعداً برای `h2` یک `::after` هم می‌خواهد. اگر هم خط `border-bottom` بماند هم `::after`، دو خط زیر تیتر داری. وقتی به گام شبه‌عنصر رسیدی، `border-bottom` را از `h2` بردار و فقط روی `h1` نگه دار. این را از حالا بگو تا تعجب نکنند.

**عکس**

```css
.avatar-box img {
  width: 160px;
  height: 160px;
  border-radius: 50%;
  object-fit: cover;
  display: block;
}
```

«`object-fit: cover` را یک جمله: اگر عکس مربعی نباشد، دایره آن را نمی‌کشد؛ اضافه را می‌برد. جزئیات تصویر مال ماژول ۰۵ است. `border-radius: 50%` همان گام جزوه است.»

**لینک**

```css
a {
  color: #1a3a5c;
}

a:hover {
  color: #0b6e4f;
}
```

زیرخط را از لینک‌های **منو** بردار، نه لزوماً از هر لینک داخل متن. اگر `a { text-decoration: none }` سراسری بگذاری، لینک داخل پاراگراف هم بی‌علامت می‌شود و فقط رنگ می‌ماند. برای منو در گام بعد `text-decoration: none` را روی `.menu a` می‌گذاریم. این فرق را بگو؛ جزوه گفته «لینک‌ها بدون خط زیر»، و در صفحه معرفی اگر همه لینک‌ها منو و دکمه باشند قابل قبول است، به شرطی که hover رنگ را عوض کند و فوکوس حذف نشود.

**جدول**

```css
table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  border: 1px solid #cbd5e1;
  padding: 0.4rem 0.6rem;
  text-align: right;
}

tbody tr:nth-child(even) {
  background: #eef2f7;
}
```

«`border-collapse` دو خط همسایه را یکی می‌کند. ردیف راه‌راه با `nth-child` است، از درس شبه‌کلاس. اگر جدول در ۳۲۰px از صفحه بیرون زد، آخر جلسه `overflow-x: auto` روی یک دورپیچ بگذار؛ خود جدول را با `display` عجیب خرد نکن مگر وقت اضافه داشته باشی.»

### سؤال کلاسی

- «چرا CSS را داخل `<style>` صفحه نریختیم؟»  
  **پاسخ:** جزوه خواسته پوشه `css` و تگ `link`. برای یک صفحه هم عادت فایل خارجی را نگه دار تا مسیر نسبی `href` را اشتباه نبندی.

## ۳) ظرف وسط و منوی چسبان

نیاز: خط متن در مانیتور عریض از حد خواندن رد نشود، و هنگام اسکرول لینک بخش‌ها گم نشود.

```css
.wrapper {
  width: 100%;
  max-width: 900px;
  margin: 0 auto;
  padding: 0 16px;
}

.site-nav {
  position: sticky;
  top: 0;
  z-index: 100;
  background: #1a3a5c;
}

.menu {
  display: flex;
  flex-direction: column;
  list-style: none;
  margin: 0;
  padding: 0;
}

.menu a {
  display: block;
  color: white;
  padding: 12px 16px;
  text-decoration: none;
}

.menu a:hover,
.menu a:focus-visible,
.menu a.active {
  background: #0b6e4f;
}
```

«`max-width: 900px` با `margin: 0 auto` همان گام وسط‌چین جزوه است. `sticky` و `top: 0` منو را هنگام اسکرول نگه می‌دارد؛ `z-index` را با پس‌زمینه مات بگذار وگرنه متن از لای لینک‌ها خوانده می‌شود. پایه منو ستونی است (زیر هم در عرض کم). افقی شدنش داخل `min-width` است، نه مثل نمونه جزوه که از اول ردیف است. معنی `flex-direction` را به ماژول Flexbox بسپار.»

`:focus-visible` را حذف نکن. `.active` صفحه جاری را همان رنگ hover نشان می‌دهد تا فقط با hover فرق نکند.»

**در مرورگر:** صفحه را اسکرول کن. منو باید بچسبد و مطلب از زیرش رد شود نه از رویش. عرض ۳۲۰: لینک‌ها زیر هم، بدون لغزش افقی.

### اشتباهات رایج

- `sticky` روی عنصری که یکی از پدرهایش `overflow: hidden` دارد → نمی‌چسبد. اگر دیدی نچسبید، اول overflow پدرها را بگرد، نه اینکه فوراً `fixed` کنی.  
- `z-index` بدون `position` (غیر از static) اثر ندارد. `sticky` خودش موقعیت‌دهی است، پس z-index اینجا کار می‌کند.  
- فراموش کردن `list-style: none` → گلوله کنار لینک منو.

## ۴) زیرمنو که با کیبورد هم باز شود

الگوی درس ۱۴. امروز منو را از نو اختراع نکن.

```css
.menu li {
  position: relative;
}

.menu li ul {
  display: none;
  list-style: none;
  margin: 0;
  padding: 0;
  background: #0f2744;
}

@media (min-width: 700px) {
  .menu {
    flex-direction: row;
  }

  .menu li ul {
    position: absolute;
    top: 100%;
    right: 0;
    min-width: 10rem;
  }
}

.menu li:hover > ul,
.menu li:focus-within > ul {
  display: block;
}
```

«زیر ۷۰۰px، زیرمنو هم در جریان عادی صفحه باز می‌شود، نه روی متن مطلق. از ۷۰۰px که منو افقی شد، زیرمنو `absolute` است و پدر `li` باید `relative` باشد.

`:focus-within` را با Tab ثابت کن: برو روی «نمونه‌کارها»، منو باید باز بماند تا لینک «وب» هم به فوکوس برسد. اگر فقط `:hover` باشد، با کیبورد هیچ‌وقت «گرافیک» را نمی‌بینی.

باز شدن هنوز آنی است. اگر درس ۲۳ را خوانده‌اند می‌توانند بعد از کلاس `opacity` بگذارند. در این جلسه `display` کافی است و قول نرمی نده؛ می‌دانی `display` transition نمی‌گیرد.

روی لمس، hover چسبنده است. همان محدودیت درس ۱۴: این الگو برای ماوس و Tab است، نه منوی همبرگری.»

**در مرورگر:** یک‌بار ماوس، یک‌بار فقط Tab. هر دو را انجام بده.

## ۵) مهارت، دو ستون، نشان آنلاین

**برچسب مهارت** — inline-block، درس ۷:

```css
.tags {
  list-style: none;
  margin: 0;
  padding: 0;
}

.tags li {
  display: inline-block;
  margin: 0 0 8px 8px;
  padding: 4px 10px;
  background: #e0f2fe;
  border-radius: 999px;
}
```

**نوار پیشرفت** — درصد نسبت به پدر:

```css
.bar {
  width: 100%;
  background: #e2e8f0;
  border-radius: 999px;
  overflow: hidden;
}

.fill {
  background: #0b6e4f;
  color: white;
  padding: 2px 8px;
  font-size: 0.85rem;
}
```

«اگر درس ۱۸ را نخوانده‌اند: ۸۰٪ یعنی ۸۰ درصد عرض همین `.bar`، نه پنجره. `overflow: hidden` گوشه گرد پدر را روی نوار داخلی هم اعمال می‌کند.»

**دو ستون.** پایه برای موبایل زیر هم. کنار هم رفتن داخل `min-width`. این همان جایی است که از نمونه جزوه جدا می‌شویم؛ نمونه جزوه ستون را با `max-width: 600px` برمی‌گرداند به زیر هم، یعنی دسکتاپ‌اول. نتیجه یکی است اگر درست بنویسی. در فایل زنده این را بگذار:

```css
.row {
  display: flex;
  flex-direction: column;
  gap: 20px;
}

@media (min-width: 800px) {
  .row {
    flex-direction: row;
    align-items: flex-start;
  }

  .row main { flex: 7; }
  .row aside { flex: 3; }
}
```

«`flex: 7` و `flex: 3` همان نسبت حدود ۷۰ و ۳۰ جزوه است، بدون اینکه درصد و padding را دستی جمع کنی. اگر این نسبت در کلاس هنوز جا نیفتاده، به‌جایش در همان media query بنویس `width: 70%` و `width: 30%` با `box-sizing: border-box`، و `gap` را در نظر بگیر تا سرریز نکند. معنی عدد `flex` را به ماژول ۰۷ برگردان.

`align-items: flex-start` را یک جمله: ستون کناری به اندازه محتوا بماند و به زور هم قد `main` کش نیاید. اگر گیج‌کننده است حذف کن.»

**نشان آنلاین** — درس موقعیت:

```css
.avatar-box {
  position: relative;
  display: inline-block;
}

.online {
  position: absolute;
  bottom: 10px;
  left: 10px;
  width: 22px;
  height: 22px;
  background: #2b8a3e;
  border: 3px solid white;
  border-radius: 50%;
}
```

«متن «آنلاین» را از داخل دایره بردار و `aria-label="آنلاین"` روی همان span بگذار تا دایره بی‌نام نماند. یک‌بار `position: relative` را از پدر حذف کن تا نشان نسبت به صفحه بپرد، بعد برگردان.»

### سؤال کلاسی

- «چرا نشان، `absolute` است و خود عکس نه؟»  
  **پاسخ:** عکس در جریان صفحه می‌ماند و جا اشغال می‌کند. نشان باید روی گوشه همان عکس بنشیند، نسبت به `.avatar-box`.

## ۶) فرم، تیتر، خط تزئینی، دکمه بالا

**فرم** از درس ۱۶، فشرده:

```css
label {
  display: block;
  margin-top: 0.8rem;
}

input,
textarea {
  width: 100%;
  font: inherit;
  padding: 0.5rem 0.6rem;
  border: 1px solid #94a3b8;
  border-radius: 6px;
}

input:focus-visible,
textarea:focus-visible {
  outline: 2px solid #0b6e4f;
  border-color: #0b6e4f;
}

button {
  margin-top: 0.8rem;
  font: inherit;
  padding: 0.5rem 1rem;
  background: #0b6e4f;
  color: white;
  border: none;
  border-radius: 6px;
  cursor: pointer;
}
```

«`font: inherit` چون کنترل فرم، فونت `body` را خودش به ارث نمی‌گیرد. `width: 100%` بدون `box-sizing: border-box` با padding از ظرف بیرون می‌زند. بالای فایل این را داشته باش:

```css
*, *::before, *::after { box-sizing: border-box; }
```

اعتبار `required` را CSS جایگزین نمی‌کند. ما فقط ظاهر و فوکوس واضح را می‌سازیم.»

**تیتر سیال.** جزوه `clamp` خواسته. اگر درس ۱۹ را نخوانده‌اند، این یک خط را به‌عنوان ابزار آماده بده و آرگومان‌ها را فقط نام ببر: کف، دلخواه، سقف.

```css
h1 {
  font-size: clamp(1.5rem, 1rem + 2vw, 2.75rem);
  border-bottom: none;
}
```

«نسخه پیکسلی جزوه `clamp(24px, 5vw, 44px)` هم درست است. نسخه با `rem` با تنظیم قلم مرورگر هم کمی همراه می‌شود. یکی را انتخاب کن.»

**خط زیر h2 با شبه‌عنصر** — و برداشتن border قبلی h2:

```css
h2 {
  border-bottom: none;
}

h2::after {
  content: "";
  display: block;
  width: 50px;
  height: 3px;
  background: #0b6e4f;
  margin-top: 6px;
}
```

«`content` خالی اگر ننویسی، `::after` ساخته نمی‌شود. این خط تزئینی است نه متن.»

**دکمه بالای صفحه**

```css
.to-top {
  position: fixed;
  bottom: 16px;
  left: 16px;
  z-index: 90;
  background: #1a3a5c;
  color: white;
  padding: 8px 12px;
  border-radius: 8px;
  text-decoration: none;
}
```

«`fixed` به viewport چسبیده می‌ماند. `z-index` را کمتر از منو بگذار. `href` باید به یک `id` واقعی همین صفحه برسد. در ۳۲۰px چک کن روی دکمه ارسال ننشسته باشد.»

---

## ۷) گذر نهایی از سه عرض

فایل را روی ۳۲۰، حدود ۷۰۰، و حدود ۱۱۰۰ چک کن. جدول را بلند بخوان:

| عرض | باید ببینی |
|------|------------|
| ۳۲۰ | یک ستون، منو زیر هم، فرم تمام‌عرض پدر، بدون اسکرول افقی، عکس از صفحه بیرون نزده |
| ۷۰۰ | منو ممکن است افقی شده باشد؛ اگر دو ستون هنوز تنگ است، پله ۸۰۰ هنوز نیامده و باید زیر هم بمانند |
| ۱۱۰۰ | متن وسط با حداکثر ۹۰۰px، کنارش aside، سه لینک منو در یک ردیف |

اگر اسکرول افقی دیدی، در DevTools دنبال عرض ثابت، جدول، یا تصویر بدون سقف بگرد. پرتره را همان ۱۶۰×۱۶۰ با `object-fit` نگه دار. قانون عمومی `img { max-width: 100%; }` را فقط اگر تصویر دیگری صفحه را پهن کرد اضافه کن و بگذار قانون خاص‌ترِ `.avatar-box img` اندازه دایره را حفظ کند.

«query با `max-width` ته نمونه جزوه را کنار این `min-width` کپی نکن؛ روی `.row` با هم می‌جنگند.»

---

## ۸) آزمون Tab — معیار تمام شدن صفحه

ماوس را کنار بگذار. از بالای صفحه Tab بزن.

باید لینک‌های منو، زیرمنو، فیلدهای فرم و دکمه ارسال یکی‌یکی روشن شوند و حلقه یا پس‌زمینه فوکوس دیده شود. اگر `outline: none` مانده، همان گام را برگردان. دانشجو خودش Tab و Shift+Tab را بزند.

### سؤال کلاسی

- «چرا فرم را بدون label قابل قبول نمی‌دانیم، حتی اگر placeholder داشته باشد؟»  
  **پاسخ:** placeholder با تایپ کردن ناپدید می‌شود و به کنترل اسم پایدار نمی‌دهد. `label for` با `id` همان گام فرم است.

---

## ۹) پروژه کوله‌پشتی — اشکال را نام ببر، همه‌اش را در کلاس حل نکن

«صفحه معرفی را ساختید. حالا برعکسش: یک وبلاگ سفر به شما رسیده که HTML درست است و CSS خراب. صاحب سایت پنج علامت گفته. در پوشه starter پروژه ۶، **فقط CSS** را حق دارید عوض کنید، نه HTML را، و ستون‌ها را به Flex تبدیل نکنید؛ float را درست کنید چون هدف، خواندن کد قدیمی است.

علامت‌ها را از روی صورت‌مسئله بخوان، بدون اینکه راه‌حل را خط‌به‌خط لو بدهی:»

1. ستون کناری زیر مطلب است نه کنارش.  
2. کادر سفید دور مطلب یک نوار باریک است و پانویس آمده وسط متن.  
3. هنگام اسکرول، عکس روی منو می‌آید با اینکه z-index منو ۱۰۰ است.  
4. یک فرمول طولانی از کادر بیرون زده.  
5. متن روی عکس بالای صفحه به بالا چسبیده، با اینکه قرار بوده وسط باشد.

«برای هر اشکال در `fixes.md` سه چیز بنویسند: چه دیده می‌شد، چرا، کدام ویژگی عوض شد. `!important` ممنوع است. اگر کسی گیر کرد، بگذار در DevTools خط `calc` بدون فاصله دور `-` را خط‌خورده ببیند؛ کل آن خط نادیده گرفته می‌شود. امتیاز اضافه: زیر ۶۰۰px ستون‌ها زیر هم، با یک رویکرد، نه `min-width` و `max-width` با هم روی همان ویژگی.

ده دقیقه فایل starter را باز کنید و یک اشکال را در DevTools پیدا کنید. بقیه تکلیف حدود ۶۰ دقیقه است.»

## ۱۰) جمع‌بندی مدرس و سؤالات پایانی

1. منوی چسبان کدام ترکیب را می‌خواهد تا مطلب از لای آن خوانده نشود؟  
   **پاسخ:** `position: sticky`، `top: 0`، پس‌زمینه مات، و `z-index` بالاتر از محتوای عادی.

2. زیرمنو با Tab چرا به `:focus-within` نیاز دارد؟  
   **پاسخ:** چون `:hover` با کیبورد روشن نمی‌شود و لینک‌های داخل منوی بسته در دسترس نیستند.

3. چرا دو ستون را در CSS پایه زیر هم نوشتیم؟  
   **پاسخ:** mobile-first. کنار هم رفتن داخل `@media (min-width: …)` است. نمونه جزوه با `max-width` همان نتیجه را از جهت مخالف می‌سازد؛ در یک فایل قاطی‌شان نمی‌کنیم.

4. معیار تمام شدن صفحه، غیر از ظاهر دسکتاپ، چیست؟  
   **پاسخ:** بدون اسکرول افقی حدود ۳۲۰px، و رد شدن با Tab طوری که فوکوس هر لینک و کنترل فرم دیده شود.

**پیام پایانی:**

«این ماژول را تمام کرده‌اید اگر بتوانید یک صفحه معرفی را با بخش‌های معنایی، منوی قابل کیبورد، ستون‌هایی که از موبایل شروع می‌شوند، و فرم واضح تحویل بدهید، و وقتی چیدمان خراب است علت را در DevTools پیدا کنید نه اینکه با `!important` بپوشانید. Flex و Grid را در ماژول خودشان عمیق نگه دارید؛ اینجا فقط سر هم کردنشان را دیدید.»
