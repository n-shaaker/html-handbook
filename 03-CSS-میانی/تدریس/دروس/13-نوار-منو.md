## ۱) شروع کلاس؛ نیاز واقعی سایت

«بچه‌ها، مشتری یک فروشگاه کتاب پیام داده: بالای همه صفحه‌ها باید بروم خانه، اخبار، تماس، درباره ما. صفحه فعلی باید معلوم باشد. در گوشی هم لینک‌ها از صفحه بیرون نزنند.

نسخه‌ای که دیروز تحویل شده این است: چهار لینک داخل یک پاراگراف، با `br` زیر هم. کار می‌کند، ولی صفحه‌خوان نمی‌فهمد این بخش «منوی رفتن بین صفحه‌ها» است. موتور جستجو هم یک فهرست ناوبری نمی‌بیند. از نظر ظاهری هم نقطه‌های فهرست را اگر کسی با `ul` ساخته باشد هنوز هست، و آیتم‌ها تمام عرض صفحه را زیر هم گرفته‌اند.

سؤال: HTML درست این نوار چیست، و CSS پیش‌فرض مرورگر چرا شبیه منوی سایت‌ها نیست؟»

فایل پیشنهادی: `تدریس/live/13-navbar.html`

اول عمداً نسخه ضعیف را نشان بده، بعد پاکش کن:

```html
<p>
  <a href="index.html">خانه</a><br>
  <a href="news.html">اخبار</a><br>
  <a href="contact.html">تماس</a><br>
  <a href="about.html">درباره ما</a>
</p>
```

«لینک هست، ولی ساختار منو نیست. از اینجا به بعد همه مثال‌های امروز همین یک HTML را دارند. ظاهر را CSS عوض می‌کند، نه اینکه برای منوی افقی یک HTML و برای منوی عمودی یک HTML دیگر بنویسیم.»

**در مرورگر:** چهار لینک زیر هم، بدون پس‌زمینه، با زیرخط پیش‌فرض. این نقطه ورود است.

## ۲) ساختار HTML منو

«نوار منو یک فهرست از لینک‌هاست. فهرست را با `ul` و `li` می‌نویسیم و همه‌اش را داخل `nav` می‌گذاریم. `nav` به مرورگر و صفحه‌خوان می‌گوید این تکه‌صفحه برای رفتن بین صفحه‌هاست، نه یک فهرست معمولیِ داخل مقاله.»

```html
<nav aria-label="منوی اصلی">
  <ul>
    <li><a class="active" href="index.html" aria-current="page">خانه</a></li>
    <li><a href="news.html">اخبار</a></li>
    <li><a href="contact.html">تماس</a></li>
    <li><a href="about.html">درباره ما</a></li>
  </ul>
</nav>
```

«`aria-label` لازم است وقتی در صفحه بیش از یک `nav` داریم، مثلاً منوی اصلی و منوی پاورقی. این‌طور صفحه‌خوان می‌گوید «منوی اصلی»، نه فقط «ناوبری».

کلاس `active` را چشم می‌بیند، چون ما با CSS به آن رنگ می‌دهیم. کلاس برای نرم‌افزار خواندن صفحه معنی خاصی ندارد. `aria-current="page"` همان اطلاع را به صفحه‌خوان می‌دهد: این لینک، صفحه فعلی است. هر دو را با هم بگذار. در هر صفحه، این زوج را فقط روی لینک همان صفحه بگذار.»

**در مرورگر:** هنوز گلوله هست، هنوز زیر هم است، هنوز تورفتگی پیش‌فرض هست. بگو: «HTML درست شد. ظاهر هنوز مال مرورگر است.»

### سؤال کلاسی

- «چرا لینک‌ها را مستقیم داخل `nav` بدون `ul` ننویسیم؟»  
  **پاسخ:** می‌شود لینک خالی گذاشت، ولی فهرست معنی «مجموعه آیتم هم‌تراز» را هم می‌رساند و استایل‌دادن و افزودن زیرمنو در درس بعد ساده‌تر است. در این دوره ساختار استاندارد `nav > ul > li > a` است.

- «اگر فقط کلاس `active` باشد و `aria-current` نباشد چه کسی ضرر می‌کند؟»  
  **پاسخ:** کاربری که صفحه را می‌شنود. رنگ سبز را نمی‌بیند.

## ۳) قدم اول: برداشتن ظاهر پیش‌فرض فهرست

«قبل از هر طرحی، سه چیز پیش‌فرض `ul` را خاموش می‌کنیم: گلوله، فاصله بیرونی، فاصله داخلی. در صفحه راست‌چین آن `padding` معمولاً سمت راست جمع شده و آیتم‌ها را تورفته نشان می‌دهد.»

```css
nav ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}
```

**در مرورگر:** گلوله و تورفتگی رفت. آیتم‌ها هنوز زیر هم‌اند، چون `li` عنصر block است. این را با صدای بلند بگو تا کسی گمان نکند reset باید خودش منو را افقی کند.

### اشتباهات رایج

- فقط `list-style: none` بدون `padding: 0`، و تعجب از حاشیه خالی سمت راست.  
- Reset را روی همه `ul`های سایت گذاشتن، از جمله فهرست داخل مقاله. انتخابگر را با `nav ul` یا یک کلاس محدود کن.

## ۴) منوی عمودی کناری — تمام ردیف قابل کلیک

«در صفحه مقاله‌ها گاهی منو کنار متن است، نه بالای صفحه. عرض ثابت، پس‌زمینه خاکستری، و هر ردیف با ماوس کامل روشن شود.»

```css
nav.side ul {
  width: 200px;
  background: #f1f1f1;
}

nav.side li a {
  display: block;
  padding: 8px 16px;
  text-decoration: none;
  color: #111;
}

nav.side li a:hover,
nav.side li a:focus-visible {
  background: #555;
  color: white;
}

nav.side li a.active {
  background: #0b6e4f;
  color: white;
}
```

«`display: block` روی خود `a` مهم‌ترین خط این مثال است. لینک به‌طور پیش‌فرض inline است و فقط به اندازه متن جا می‌گیرد. اگر `padding` را به `li` بدهیم، مستطیل رنگی بزرگ است ولی ناحیه کلیک هنوز همان کلمه است. کاربر کنار کلمه کلیک می‌کند و هیچ اتفاقی نمی‌افتد.

`padding` و `display: block` را به `a` بده تا کل ردیف لینک باشد.

زیرخط پیش‌فرض لینک را با `text-decoration: none` برمی‌داریم، چون در نوار منو خود پس‌زمینه و رنگ، لینک بودن را نشان می‌دهد. اگر زیرخط را برداشتی، رنگ و حالت hover باید آن‌قدر واضح باشد که لینک با متن معمولی قاطی نشود.»

حالت کیبورد را همین‌جا عادت بده:

«کاربری که Tab می‌زند `:hover` ندارد. همان قانون را برای `:focus-visible` هم بنویس. `outline` پیش‌فرض را پاک نکن مگر اینکه همین پس‌زمینه یا یک حلقه جایگزین واقعاً دیده شود.»

**در مرورگر:** ماوس را کنار متن، روی ناحیه خالی ردیف کلیک کن؛ باید لینک عمل کند. بعد Tab بزن و نشان بده ردیف فوکوس هم همان ظاهر hover را می‌گیرد. اگر `display: block` را برداری، فقط متن کلیک‌پذیر است. این مقایسه را انجام بده.

### سؤال کلاسی

- «چرا `padding` را به `a` می‌دهیم نه به `li`؟»  
  **پاسخ:** تا مستطیل فاصله‌دار همان ناحیه لینک باشد، نه فقط جعبه آیتم.

- «صفحه فعلی کدام قانون را می‌گیرد؟»  
  **پاسخ:** `a.active` با پس‌زمینه سبز. hover را هم جدا نگه دار تا روی بقیه لینک‌ها کار کند.

### اشتباهات رایج

- `padding` روی `li` و ناحیه کلیک کوچک.  
- استایل فقط برای `:hover`.

## ۵) منوی افقی با `inline-block`

«حالا همان HTML را افقی می‌کنیم. هر `li` باید در جریان خط بماند و در عین حال جعبه باشد.»

```css
nav.top ul {
  background: #333;
}

nav.top li {
  display: inline-block;
}

nav.top li a {
  display: block;
  color: white;
  padding: 14px 16px;
  text-decoration: none;
}

nav.top li a:hover,
nav.top li a:focus-visible {
  background: #111;
}

nav.top li a.active {
  background: #0b6e4f;
}
```

«آیتم‌ها کنار هم آمدند. اگر دقیق نگاه کنید بین بعضی‌ها یک شکاف باریک هست. این باگ flex نیست. `inline-block` مثل متن، فاصله‌های بین تگ‌ها در HTML را هم نشان می‌دهد. همان موضوع درس ۷.

امروز این شکاف را دلیل کافی برای رفتن به روش بعدی می‌گیریم. راه درمان‌های قدیمی مثل چسباندن تگ‌ها در یک خط را لازم نیست حفظ کنید.»

**در مرورگر:** شکاف را با بزرگ‌نمایی نشان بده. در DevTools عرض `ul` و فاصله بین `li`ها را نگاه کنید.

### سؤال کلاسی

- «این فاصله را `margin` ما ساخته؟»  
  **پاسخ:** نه. از فاصلهٔ منبع HTML بین عنصرهای inline می‌آید.

## ۶) روش قدیمی: `float` و آیتم سمت مقابل

«در قالب‌های قدیمی منو را با `float` می‌ساختند. باید بتوانید بخوانیدش. برای پروژه تازه از بخش بعد استفاده کنید.»

```css
nav.old ul {
  background: #333;
  overflow: hidden; /* پدر ارتفاع بچه‌های شناور را نگه دارد */
}

nav.old li {
  float: right;
}

nav.old li.opposite {
  float: left;
}

nav.old li a {
  display: block;
  color: white;
  padding: 14px 16px;
  text-decoration: none;
}
```

```html
<li class="opposite"><a href="login.html">ورود / ثبت‌نام</a></li>
```

«در صفحه راست‌چین `float: right` آیتم‌ها را به سمت راست می‌چسباند و کنار هم می‌گذارد. `float: left` روی «ورود» آن را به سمت دیگر هل می‌دهد.

`overflow: hidden` اینجا یک نقش معروف دارد: پدر، بچه‌های float را در بر بگیرد و ارتفاعش صفر نشود. همین ویژگی در درس بعد دردسر می‌شود. منوی کشویی که از لبه نوار بیرون بزند، با `overflow: hidden` بریده می‌شود. این یکی از دلیل‌هایی است که float را برای منو کنار گذاشته‌ایم.»

**در مرورگر:** ورود سمت مقابل بقیه است. اگر `overflow: hidden` را برداری، بسته به بقیه CSS ممکن است پس‌زمینه نوار جمع شود. توضیح بده، بعد کد را به حالت قابل‌فهم برگردان.

### اشتباهات رایج

- کپی کردن `overflow: hidden` از منوی قدیمی به منویی که قرار است زیرمنو داشته باشد.  
- فراموش کردن جهت: در `dir="rtl"` سمت «شروع» راست است. `float: left` یعنی سمت چپ فیزیکی، نه «سمت شروع نوشتن».

## ۷) نوار فروشگاه با flex — روشی که امروز می‌سازیم

«لوگو سمت راست، لینک‌ها کنار لوگو، سبد خرید با عدد ۳ در سمت چپ. بین آیتم‌ها فاصله یکنواخت، بدون شکاف `inline-block`. اگر صفحه باریک شد، آیتم به خط بعد برود نه اینکه از پنجره بیرون بزند.»

```css
.shop-nav {
  display: flex;
  align-items: center;
  gap: 4px;
  flex-wrap: wrap;
  list-style: none;
  margin: 0;
  padding: 0 8px;
  background: #333;
}

.shop-nav a {
  display: block;
  color: white;
  padding: 14px 16px;
  text-decoration: none;
}

.shop-nav a:hover,
.shop-nav a:focus-visible {
  background: #111;
}

.shop-nav a.active {
  background: #0b6e4f;
}

.shop-nav .cart {
  margin-right: auto;
}

.cart-count {
  display: inline-block;
  padding: 0 7px;
  border-radius: 10px;
  background: #e8590c;
  color: white;
  font-size: 12px;
}
```

```html
<ul class="shop-nav">
  <li class="logo"><a href="index.html">کتاب‌سرا</a></li>
  <li><a class="active" href="index.html" aria-current="page">خانه</a></li>
  <li><a href="cats.html">دسته‌بندی‌ها</a></li>
  <li><a href="sale.html">تخفیف‌ها</a></li>
  <li class="cart">
    <a href="cart.html">سبد خرید <span class="cart-count">۳</span></a>
  </li>
</ul>
```

«`display: flex` روی خود `ul` بچه‌های مستقیم، یعنی `li`ها، را در یک ردیف می‌چیند. `gap` فاصله بین همان بچه‌هاست و مشکل فاصله حروف `inline-block` را ندارد. `align-items: center` لوگو و لینک را در راستای عمودی وسط هم می‌گذارد. `flex-wrap: wrap` می‌گوید اگر جا نبود، به خط بعد برو.

`margin-right: auto` روی سبد، در صفحه راست‌چین، فضای خالی را سمت راست سبد جمع می‌کند و سبد را به انتهای چپ نوار هل می‌دهد. این خط را آرام تایپ کن و یک بار `margin-left: auto` را جایش بگذار تا کلاس ببیند سبد به کدام لبه می‌رود. در راست‌چین، برای چسباندن به انتهای چپ، `margin-right: auto` همان چیزی است که جزوه گفته.»

عدد سبد را در HTML بگذار، نه در `content` شبه‌عنصر. «۳» اطلاعات است.

اگر خواستی نوار هنگام اسکرول بالا بماند، به همان `ul` یا به `nav` این سه تا را اضافه کن. درس‌های ۳ و ۴ را یادآوری کن، از نو درس نده:

```css
.shop-nav {
  position: sticky;
  top: 0;
  z-index: 100;
}
```

**در مرورگر:** پنجره را باریک کن تا `flex-wrap` آیتم را به خط بعد ببرد. `gap` را موقتاً صفر کن و دوباره ۴ پیکسل. `margin-right: auto` را خاموش کن تا سبد بچسبد کنار بقیه، بعد روشن کن.

### سؤال کلاسی

- «شکاف بین آیتم‌های flex از کجا می‌آید؟»  
  **پاسخ:** از `gap`، نه از فاصله منبع HTML.

- «چرا عدد سبد را با `::after` نساختیم؟»  
  **پاسخ:** چون تعداد کالا اطلاعات واقعی است و باید در HTML باشد.

### اشتباهات رایج

- `margin-left: auto` را از آموزش چپ‌چین کپی کردن و تعجب از اینکه سبد در سایت فارسی به لبه مورد نظر نرفته.  
- `flex` روی `a` به‌جای `ul`، و بعد تعجب از اینکه آیتم‌ها ردیف نشده‌اند. ظرف ردیف، پدرِ آیتم‌هاست.

## ۸) تب با خط زیر، بدون پرش

«صفحه مجله چند دسته دارد: همه، ورزشی، فرهنگی، علمی. خط زیر تب فعال نارنجی است. اگر این خط را فقط موقع hover بسازیم، ارتفاع لینک ناگهان ۳ پیکسل زیاد می‌شود و بقیه منو می‌پرد.»

```css
.tabs a {
  display: block;
  padding: 10px 16px;
  text-decoration: none;
  color: #333;
  border-bottom: 3px solid transparent;
}

.tabs a:hover,
.tabs a:focus-visible,
.tabs a.active {
  border-bottom-color: #e8590c;
  color: #e8590c;
}
```

«از اول حاشیه‌ای به همان ضخامت با رنگ شفاف می‌گذاریم. جا رزرو شده. در hover فقط رنگ عوض می‌شود. این ترفند را در دکمه‌ها هم به کار می‌برید: مرزی که ظاهر می‌شود نباید چیدمان را تکان بدهد.»

**در مرورگر:** یک نسخه غلط با `border-bottom` فقط در hover نشان بده تا پرش دیده شود، بعد `transparent` را برگردان.

### سؤال کلاسی

- «چرا رنگ اولیه `transparent` است نه حذف کامل `border`؟»  
  **پاسخ:** تا ضخامت از اول در جعبه باشد و هنگام hover ارتفاع عوض نشود.

## ۹) منوی دکمه‌ای گرد

«گاهی نوار یکپارچه نمی‌خواهیم. هر لینک یک کپسول جدا است.»

```css
.pills li {
  display: inline-block;
}

.pills a {
  display: block;
  padding: 8px 20px;
  margin-left: 6px;
  border: 1px solid #1a5fb4;
  border-radius: 20px;
  text-decoration: none;
  color: #1a5fb4;
}

.pills a.active {
  background: #1a5fb4;
  color: white;
}
```

«وقتی شعاع گردی از نصف ارتفاع لینک بیشتر باشد، دو سر لینک نیم‌دایره می‌شوند. `20px` با این padding معمولاً همان کپسول است. باز هم `display: block` و `padding` روی خود `a` است.»

**در مرورگر:** تب فعال پر است، بقیه فقط خط دور دارند.

## ۱۰) پروژه جلسه — نوار معرفی شخصی

دانشجو همراه تو این نوار را از صفر تایپ می‌کند. از HTML جزوه شروع کن، reset، بعد flex.

```html
<nav aria-label="منوی اصلی">
  <ul class="site-nav">
    <li class="logo"><a href="index.html">نگار</a></li>
    <li><a class="active" href="index.html" aria-current="page">خانه</a></li>
    <li><a href="work.html">نمونه‌کار</a></li>
    <li><a href="about.html">درباره</a></li>
    <li class="end"><a class="pill" href="contact.html">تماس با من</a></li>
  </ul>
</nav>
```

```css
.site-nav {
  display: flex;
  align-items: center;
  gap: 4px;
  flex-wrap: wrap;
  list-style: none;
  margin: 0;
  padding: 0;
  background: #0f2740;
}

.site-nav a {
  display: block;
  color: white;
  padding: 12px 14px;
  text-decoration: none;
  border-bottom: 3px solid transparent;
}

.site-nav a:hover,
.site-nav a:focus-visible,
.site-nav a.active {
  border-bottom-color: #e8590c;
}

.site-nav .end {
  margin-right: auto;
}

.site-nav a.pill {
  border: 1px solid white;
  border-radius: 999px;
  border-bottom-color: white;
}
```

«لوگو و لینک‌ها یک ردیف‌اند. تماس به سمت چپ رفته. خط زیرین از اول جا دارد. صفحه خانه هم کلاس دارد هم `aria-current`. با Tab روی لینک‌ها حرکت کن.»

**در مرورگر:** عرض را تا حدود ۳۶۰ پیکسل کم کن. اگر آیتم‌ها به خط بعد رفتند و اسکرول افقی صفحه ساخته نشد، `flex-wrap` کارش را کرده. یک لینک را با کیبورد فوکوس کن.

### سؤال کلاسی

- «اگر فردا لینک پنجم اضافه شود، HTML جدید لازم است یا فقط یک `li` دیگر؟»  
  **پاسخ:** یک `li` دیگر داخل همان `ul`. CSS ردیف را خودش گسترش می‌دهد.

## ۱۱) جمع‌بندی مدرس و سؤالات پایانی

1. ساختار HTML نوار منو در این درس چیست؟  
   **پاسخ راهنما:** `nav`، داخلش `ul`، داخلش `li`، داخلش `a`. برچسب دسترس‌پذیر برای خود `nav` وقتی چند ناوبری داریم.

2. چرا `a` را `display: block` می‌کنیم؟  
   **پاسخ:** تا padding بخشی از ناحیه کلیک باشد و کل ردیف لینک شود.

3. صفحه فعلی را چطور هم نشان می‌دهیم و هم اعلام می‌کنیم؟  
   **پاسخ:** کلاس `active` برای CSS، و `aria-current="page"` برای صفحه‌خوان.

4. برای نوار تازه، `float` را انتخاب می‌کنی یا `flex` را؟  
   **پاسخ:** `flex` با `gap` و `flex-wrap`. `float` را فقط برای خواندن قالب قدیمی بلد باش، به‌خصوص چون `overflow: hidden` زیرمنو را می‌برد.

**پیام پایانی:**

«منو قبل از هر رنگی یک فهرست لینک است. اول معنی HTML را درست کنید، بعد گلوله را بردارید، بعد ردیف را با flex بسازید، و صفحه فعلی را فقط با رنگ رها نکنید.»

## تمرین‌ها (ساده → چالشی)

### ساده

1. یک `nav` با چهار لینک بساز و فقط reset فهرست را اعمال کن. قبل و بعد را در مرورگر مقایسه کن.  
2. همان فهرست را عمودی کن. `padding` را یک بار روی `li` و یک بار روی `a` بگذار و ناحیه کلیک را امتحان کن.

### متوسط

3. منوی افقی با `inline-block` بساز و شکاف بین آیتم‌ها را پیدا کن. بعد همان HTML را با `display: flex` و `gap: 4px` بنویس.  
4. برای لینک فعال `aria-current="page"` و رنگ متفاوت بگذار. با Tab هم حالت فوکوس را رنگی کن.

### چالشی

5. نوار معرفی پروژه همین جلسه را کامل کن: لوگو، سه لینک، دکمه تماس در انتهای دیگر با `margin-right: auto`، خط زیر شفاف برای جلوگیری از پرش، و `flex-wrap`. در عرض ۳۶۰ پیکسل اسکرول افقی صفحه نباید ظاهر شود.  
6. توضیح بده چرا `overflow: hidden` در منوی float امروز، با منوی کشویی فردا نمی‌سازد.
