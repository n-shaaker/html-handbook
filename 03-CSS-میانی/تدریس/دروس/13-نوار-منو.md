## ۱) شروع — مسئله اول (دیالوگ)

«بچه‌ها، لینkهای سایت را داخل `<p>` با `<br>` گذاشتید — کار می‌کند ولی SEO و screen reader گیج.

HTML درست: **`nav` > `ul` > `li` > `a`**.

CSS پیش‌فرض: گلوله، padding راست، آیتم‌ها **زیر هم**. مشتری می‌خواهد **نوار افقی** — today.»

ساختار جزوه:

```html
<nav aria-label="منوی اصلی">
  <ul>
    <li><a class="active" href="index.html" aria-current="page">خانه</a></li>
    <li><a href="news.html">اخبار</a></li>
    <li><a href="contact.html">تماس</a></li>
  </ul>
</nav>
```

---

## ۲) Live — reset فهرست

```css
nav ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}
```

«`padding: 0` — در RTL padding-start پیش‌فرض ul حذف شود.»

---

## ۳) منوی عمودی (sidebar)

```css
nav.vertical ul {
  width: 200px;
  background-color: #f1f1f1;
}
nav.vertical li a {
  display: block;
  padding: 8px 16px;
  text-decoration: none;
  color: #000;
}
nav.vertical li a:hover,
nav.vertical li a:focus-visible {
  background-color: #555;
  color: white;
}
```

«**`display: block` روی `a`** — کل ردیف clickable.»

**در مرورگر:** demo عمودی [`navbar.css`](../../css/demos/navbar.css).

---

## ۴) منوی افقی (top bar)

```css
nav.horizontal li {
  display: inline-block;
}
nav.horizontal li a {
  display: block;
  padding: 14px 16px;
  text-decoration: none;
  color: white;
  background-color: #333;
}
nav.horizontal li a:hover {
  background-color: #111;
}
```

«`inline-block` روی `li` — items کنار هم؛ flex در Flexbox module قوی‌تر.»

---

## ۵) `.active` و `aria-current`

```css
nav li a.active {
  background-color: #04aa6d;
  color: white;
}
```

«کلاس برای CSS — **`aria-current="page"`** برای assistive tech. هر دو را با هم بگذارید.»

### سؤال کلاسی

«چرا `a` داخل `li` نه div?»  
**پاسخ:** list semantics — تعداد item مشخص برای screen reader.

---

## ۶) پروژه mini

## ۷) اشتباهات

- forget list-style none.  
- active فقط CSS بدون aria.  
- hit area کوچک — padding روی `a`.

## ۸) جمع‌بندی

1. reset ul سه property?  
   **پاسخ:** list-style none, margin 0, padding 0.

2. block on `a` in vertical nav?  
   **پاسخ:** full row click target.
