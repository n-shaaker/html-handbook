## 2) units

«px ثابت؛ rem از root؛ em از font خود element (nested رشد). % از parent. vh/vw از viewport.»

```css
html { font-size: 100%; }
.card { padding: 1rem; max-width: 40rem; margin-inline: auto; }
.title { font-size: 1.5rem; }
```

**در مرورگر:** بزرگ کردن font browser — rem scale.
