---

## 2) درصد + سقف

«`max-width` می‌گوید از این بزرگ‌تر نشو؛ با `width:100%` در والد باریک کوچک می‌شوی.»

«الگوی container: `width:100%; max-width:72rem; margin-inline:auto; padding-inline:1rem;`»

```css
.container {
  width: 100%;
  max-width: 48rem;
  margin-inline: auto;
  padding-inline: 1rem;
}
```

**در مرورگر:** DevTools عرض را کم کن — container جمع می‌شود؛ روی دسکتاپ وسط می‌ایستد.

### سؤال کلاسی

- «فقط max-width بدون width؟» → گاهی کوچک‌تر از انتظار؛ الگوی رایج 100%+max.

### انتقال

«عنصر باید از flow خارج شود — position.»

## پروژه کوچک جلسه

صفحه مقاله با container 40rem و padding؛ روی 320px تست.

## جمع‌بندی و سؤالات پایانی

1. container وسط چطور؟
   **پاسخ راهنما:** margin-inline:auto با width/max-width.

2. 72rem یعنی چه؟
   **پاسخ راهنما:** نسبت به font-size root — معمولاً ~1152px اگر root 16px.
