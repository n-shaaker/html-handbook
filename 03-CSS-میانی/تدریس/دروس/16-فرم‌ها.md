## ۱) شروع — مسئله اول (دیالوگ)

«بچه‌ها، HTML فرم درس ۱۲ را کپی کردید — `<input>`, `<label>`, `<button>`.

در مرورگر: فونت سیستم، کادر کوچک، فاصله نامنظم — **اعتماد کاربر** پایین.

CSS نمی‌تواند `required` validation را جایگزین کند — ولی **ظاهر** و **focus واضح** conversion را بالا می‌برد.

نکته فنی: controls فونت `body` را **ارث نمی‌برند** — `font-family: inherit` اجباری.»

---

## ۲) Live Coding — `input[type="text"]`

مطابق [`forms.css`](../../css/demos/forms.css):

```css
input[type="text"] {
  width: 100%;
  padding: 12px 16px;
  margin: 8px 0;
  box-sizing: border-box;
  font-family: inherit;
  border: 2px solid #cbd5e1;
  border-radius: 4px;
}
```

«`width: 100%` + padding بدون border-box = overflow (درس ۱۲).

`input[type="text"]` — attribute selector درس ۱۵.»

**در مرورگر:** demo `.f1` جزوه.

## ۳) border variants

```css
.f-border {
  border: 2px solid #1a5fb4;
  border-radius: 4px;
}
.f-bottom {
  border: none;
  border-bottom: 2px solid #e8590c;
}
.f-filled {
  border: none;
  background-color: #3f51b5;
  color: white;
}
```

**Live:** سه style — underline material vs filled.

---

## ۴) `:focus` و `:focus-visible`

```css
input:focus {
  border-color: #1a5fb4;
  outline: 3px solid #a5d8ff;
}
input:focus-visible {
  outline-offset: 2px;
}
```

«هرگز outline none بدون جایگزین — درس ۱۰.»

---

## ۵) `:invalid` / `:valid` (با احتیاط)

```css
input:invalid:not(:placeholder-shown) {
  border-color: #e03131;
}
```

«فقط وقتی user چیزی typed — placeholder-shown empty را قرمز نکن.»

## ۶) textarea و select

```css
  padding: 12px 16px;
  box-sizing: border-box;
  font-family: inherit;
  resize: vertical;
}
select {
  width: 100%;
  padding: 10px 12px;
  font-family: inherit;
  box-sizing: border-box;
}
```

## ۷) checkbox / radio (سطح intro)

```css
input[type="checkbox"],
input[type="radio"] {
  width: 1.1rem;
  height: 1.1rem;
  accent-color: #1a5fb4;
}
```

«`accent-color` modern — custom کامل در دوره پیشرفته.»

## ۸) پروژه mini — فرم تماس

```html
<form class="contact-form">
  <label>نام
    <input type="text" name="name" required autocomplete="name">
  </label>
  <label>ایمیل
    <input type="email" name="email" required autocomplete="email">
  </label>
  <label>پیام
    <textarea name="msg" required></textarea>
  </label>
  <button type="submit">ارسال</button>
</form>
```

```css
.contact-form {
  max-width: 24rem;
  display: flex;
  flex-direction: column;
  gap: 0.75rem;
}
.contact-form label {
  display: flex;
  flex-direction: column;
  gap: 0.35rem;
  font-weight: 600;
}
.contact-form input,
.contact-form textarea {
  width: 100%;
  padding: 0.65rem 0.85rem;
  box-sizing: border-box;
  font-family: inherit;
  border: 1px solid #cbd5e1;
  border-radius: 0.375rem;
}
.contact-form button {
  padding: 0.65rem 1rem;
  font-family: inherit;
  background: #1a5fb4;
  color: #fff;
  border: none;
  border-radius: 0.375rem;
  cursor: pointer;
}
```

## ۹) اشتباهات رایج

- forget inherit font.  
- width 100% no border-box.  
- label بدون `for` / nested input.  
- رنگ error فقط با color — border هم.

---

## ۱۰) جمع‌بندی

1. چرا inherit?  
   **پاسخ:** form controls don't inherit font-family.

2. border-box on inputs?  
   **پاسخ:** padding inside 100% width.
