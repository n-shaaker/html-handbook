## ۱) شروع کلاس؛ اول بگو چه چیزی روی سایت می‌خواهیم

اول کلاس این‌طور شروع کن:

«بچه‌ها، در درس حداکثر عرض نگذاشتیم ستون از صفحه بیرون بزند. آنجا خود جعبه با صفحه کوچک می‌شد. امروز مسئله برعکس است: جعبه اندازهٔ ثابتی دارد و **محتوا** از جعبه بزرگ‌تر است.

چهار خواستهٔ واقعی:

خواسته اول: کارت توضیح محصول ارتفاع مشخصی دارد تا ردیف کارت‌ها هم‌قد بمانند. توضیح بعضی محصول‌ها بلندتر از این ارتفاع است. باید تصمیم بگیریم اضافه دیده شود، بریده شود، یا داخل همان کارت اسکرول بخورد.

خواسته دوم: یک ردیف مهارت یا فیلتر — HTML، CSS، JavaScript و چند اسم دیگر — در موبایل در یک خط جا نمی‌شود. نمی‌خواهیم بروند خط بعد و کارت را خیلی بلند کنند. می‌خواهیم همان یک ردیف بماند و کاربر به چپ و راست اسکرول کند.

خواسته سوم: عنوان کارت در فهرست باید یک خط بماند. اگر عنوان بلند است، ته جمله با سه‌نقطه قطع شود تا کارت بعدی پایین نیفتد.

خواسته چهارم، که بیشتر هشدار است: برچسب «جدید» را درس موقعیت از گوشهٔ کارت بیرون زدیم. منوی بازشونده هم از لبهٔ هدر بیرون می‌زند. اگر روی پدر `overflow: hidden` بگذاریم، همان چیزهایی که عمداً بیرون زده بودند بریده و ناپدید می‌شوند. پس hidden همیشه «مرتب‌کاری» نیست.

ویژگی‌ای که می‌گوید با قسمت اضافه چه شود `overflow` است. تا وقتی جعبه از محتوا کوچک‌تر نشده، این ویژگی چیزی برای بریدن ندارد. اگر ارتفاع آزاد باشد و جعبه با متن بلند شود، سرریز عمودی پیش نمی‌آید.»

فایل زنده (پیشنهاد: `تدریس/live/05-overflow.html`):

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — سرریز</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      background: #f1f5f9;
      padding: 1.5rem;
    }
  </style>
</head>
<body>
  <div class="card">
    <p>
      این متن خیلی بلند است و اگر ارتفاع کارت را محدود کنیم،
      از پایین جعبه بیرون می‌زند. هنوز overflow ننوشته‌ایم.
      خط اضافه. خط اضافه. خط اضافه. خط اضافه.
    </p>
  </div>
</body>
</html>
```

اول بدون ارتفاع نشان بده: کارت به قد متن است و چیزی بیرون نزده.

بعد فقط ارتفاع را اضافه کن:

```css
.card {
  width: 220px;
  height: 90px;
  background: #fff;
  border: 1px solid #94a3b8;
  padding: 8px;
}
```

**در مرورگر:** متن از زیر لبهٔ کارت ادامه پیدا می‌کند و روی هر چه پایین کارت باشد می‌افتد. بگو: «این حالت پیش‌فرض است. اسمش را هنوز نگفته‌ایم. خواستهٔ ما این نیست که متن روی کارت بعدی بیفتد. حالا چهار جواب ممکن را کنار هم می‌گذاریم.»

## ۲) چهار جواب: نشان بده، ببر، همیشه اسکرول، اسکرول فقط اگر لازم است

بگو:

«`overflow` یک ویژگی است با چهار مقدار پرکاربرد.

`visible` پیش‌فرض است. اضافه دیده می‌شود و از جعبه بیرون می‌زند.

`hidden` اضافه را می‌برد و پنهان می‌کند. اسکرول هم نمی‌دهد. آنچه بیرون افتاد از دسترس کاربر خارج است.

`scroll` نوار اسکرول را می‌گذارد، حتی اگر محتوا کاملاً جا شود. نوار خالی گاهی زشت است، ولی جا برای آن از قبل رزرو می‌شود.

`auto` فقط وقتی محتوا واقعاً جا نشود نوار را می‌آورد. برای جعبهٔ متن، معمولاً همین را می‌خواهیم.»

هر چهار تا را در یک شبکهٔ کوچک بگذار تا مقایسه شود:

```html
<div class="grid">
  <div class="box v"><strong>visible</strong> متن زیادی که در این جعبه کوچک جا نمی‌شود و از پایین آن بیرون می‌زند و روی بقیه می‌افتد.</div>
  <div class="box h"><strong>hidden</strong> متن زیادی که در این جعبه کوچک جا نمی‌شود و قسمت اضافه‌اش بریده می‌شود و دیده نمی‌شود.</div>
  <div class="box s"><strong>scroll</strong> متن زیادی که در این جعبه کوچک جا نمی‌شود؛ برای همین نوار اسکرول داریم تا بقیه را ببینیم.</div>
  <div class="box a"><strong>auto</strong> متن زیادی که در این جعبه کوچک جا نمی‌شود؛ اسکرول فقط وقتی ظاهر می‌شود که لازم باشد.</div>
</div>
```

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 16px;
  align-items: start;
}

.box {
  height: 90px;
  background: #fff;
  border: 1px solid #94a3b8;
  padding: 8px;
}

.v { overflow: visible; }
.h { overflow: hidden; }
.s { overflow: scroll; }
.a { overflow: auto; }
```

«`display: grid` اینجا فقط برای چیدن چهار نمونه کنار هم است. اگر هنوز grid نخوانده‌اید، چهار `div` را زیر هم بگذارید. موضوع درس، ستون‌ها نیستند.»

**در مرورگر:**

visible روی جعبهٔ زیر خودش می‌افتد. اگر `gap` کافی باشد، بیرون‌زدگی را واضح ببینند.

hidden ته جمله را قیچی کرده. راهی برای خواندن بقیه نیست.

scroll هم نوار عمودی دارد هم معمولاً نوار افقی، حتی اگر افقی لازم نباشد. این را بلند بگو تا فرق با auto دیده شود.

auto نوار را جایی می‌آورد که متن واقعاً جا نشده. داخلش اسکرول کن تا آخر جمله را بخوانند.

حالا متن جعبهٔ auto را کوتاه کن، فقط یک کلمه. نوار می‌رود. متن جعبهٔ scroll را هم کوتاه کن. نوار اغلب می‌ماند. این تفاوت خواسته است: «همیشه جای اسکرول را نگه دار» در برابر «فقط وقتی لازم شد».

«محور را هم می‌شود جدا کرد. `overflow-x` مال محور افقی است و `overflow-y` مال عمودی. وقتی فقط `overflow` می‌نویسیم، هر دو محور همان مقدار را می‌گیرند.»

### سؤال کلاسی

- «اگر ارتفاع جعبه را پاک کنیم، چرا `overflow: hidden` متن را نمی‌برد؟»  
  **پاسخ:** جعبه با محتوا بلند می‌شود. اضافهٔ عمودی به وجود نمی‌آید که بریده شود.

- «بین `scroll` و `auto` برای جعبهٔ «قوانین سایت» کدام را می‌خواهیم و چرا؟»  
  **پاسخ:** `auto`. اگر متن کوتاه بود نوار خالی نمی‌ماند، و اگر بلند شد کاربر می‌تواند بقیه را بخواند.

### اشتباهات رایج

- `overflow: scroll` روی جعبه‌ای که محتوایش کم است. نوار خالی و همیشگی دیده می‌شود.  
- انتظار بریدن متن، بدون `height` یا `max-height`.

## ۳) ردیف برچسب؛ فقط محور افقی اسکرول شود

«خواستهٔ دوم. برچسب‌ها باید یک خط بمانند. اگر `overflow: auto` را تنها بگذاریم و نگذاریم متن بشکند، باید محور را هم کنترل کنیم.»

```html
<div class="row">
  <span class="chip">HTML</span>
  <span class="chip">CSS</span>
  <span class="chip">JavaScript</span>
  <span class="chip">React</span>
  <span class="chip">Vue</span>
  <span class="chip">Node.js</span>
  <span class="chip">Python</span>
  <span class="chip">Git</span>
  <span class="chip">Figma</span>
  <span class="chip">SQL</span>
</div>
```

```css
.row {
  overflow-x: auto;
  white-space: nowrap;
  background: #fff;
  border: 1px solid #cbd5e1;
  padding: 8px;
  max-width: 100%;
}

.chip {
  display: inline-block;
  margin-left: 8px;
  padding: 4px 10px;
  background: #e7f5ff;
  border-radius: 999px;
}
```

«`white-space: nowrap` یعنی فاصله و متن به خط بعد نروند. بدون این، برچسب‌ها می‌شکنند و زیر هم می‌آیند و اصلاً سرریز افقی پیش نمی‌آید.

`overflow-x: auto` یعنی اگر همین یک خط از عرض پدر پهن‌تر شد، اسکرول افقی بیاور. `overflow-y` را دست نمی‌زنیم تا ارتفاع ردیف بی‌دلیل نوار عمودی نگیرد.

`inline-block` را از درس نمایش به یاد بیاورید: برچسب در همان خط می‌ماند و padding واقعی دارد.»

جزوه برای این ردیف نمونه `direction: ltr` می‌گذارد تا تراشه‌ها از چپ شروع شوند. اگر در کلاس خواستی همان ظاهر جزوه را ببینی، روی `.row` بگذار `direction: ltr`. بگو این فقط جهت چیدن همین ردیف نمونه است، نه اینکه صفحهٔ فارسی را چپ‌چین کرده باشیم. اگر نگذاری، در `dir="rtl"` ردیف از راست شروع می‌شود و اسکرول همچنان کار می‌کند. هر دو را اگر وقت هست نشان بده.

**در مرورگر:** عرض پنجره را حدود ۳۶۰ پیکسل کن. ردیف یک خط است. با انگشت روی ترک‌پد یا با Shift و چرخ ماوس افقی اسکرول کن تا SQL دیده شود. `nowrap` را بردار: برچسب‌ها چندخطی می‌شوند و نوار افقی می‌رود. برگردان.

### سؤال کلاسی

- «چرا `white-space: nowrap` برای این خواسته لازم است؟»  
  **پاسخ:** تا آیتم‌ها به خط بعد نروند و واقعاً از عرض جعبه سر بروند، تا اسکرول افقی معنی پیدا کند.

- «چرا اینجا `overflow-x` نوشتیم نه خود `overflow`؟»  
  **پاسخ:** فقط محور افقی را می‌خواهیم. مقدار کوتاه `overflow` هر دو محور را با هم تنظیم می‌کند.

## ۴) عنوان یک‌خطی با سه‌نقطه

«خواستهٔ سوم سه ویژگی با هم است. هیچ‌کدام به‌تنهایی سه‌نقطه نمی‌سازد.»

```html
<p class="ellipsis">آموزش کامل طراحی سایت با HTML و CSS از صفر تا صد همراه با پروژه عملی</p>
```

```css
.ellipsis {
  width: 250px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  background: #fff;
  border: 1px solid #cbd5e1;
  padding: 8px;
}
```

«`width: 250px` جعبه را محدود می‌کند. بدون عرض محدود، متن جایی برای بریده شدن ندارد.

`white-space: nowrap` جمله را در یک خط نگه می‌دارد. اگر این نباشد، جمله می‌رود خط بعد و `text-overflow` کاری نمی‌کند.

`overflow: hidden` قسمت بیرون‌زده را پنهان می‌کند. اگر این نباشد، جمله از جعبه می‌زند بیرون و باز هم سه‌نقطه نمی‌آید.

`text-overflow: ellipsis` به‌جای آن قسمت پنهان، سه‌نقطه می‌گذارد.

در متن فارسی سه‌نقطه ته جمله می‌آید، یعنی سمت چپ این خط، چون خط از راست شروع شده و اضافه به انتهای خط می‌رسد.»

**در مرورگر:** جمله قطع شده و سه‌نقطه دارد. هر بار یکی از سه ویژگی را در DevTools خاموش کن:

بدون nowrap، متن دو یا چند خط می‌شود و سه‌نقطه نیست.

بدون hidden، متن از جعبه بیرون می‌زند.

بدون ellipsis، متن بریده می‌شود ولی سه‌نقطه ندارد؛ فقط قیچی شده.

عرض را از ۲۵۰ به ۶۰۰ ببر. اگر جمله جا شود، سه‌نقطه می‌رود. این سالم است: وقتی سرریز نیست، نشانه‌اش هم نیست.

«عنصر باید خودش عرض بگیرد. یک `span` خالص inline عرض ۲۵۰ را آن‌طور که می‌خواهیم اعمال نمی‌کند. یا `p` و `div` بلوکی بگذارید، یا `inline-block` با width. این همان درس نمایش است.»

### سؤال کلاسی

- «کدام سه ویژگی با هم سه‌نقطه می‌سازند؟»  
  **پاسخ:** `white-space: nowrap`، `overflow: hidden`، `text-overflow: ellipsis`، به‌اضافهٔ عرض محدود.

- «اگر عرض را آن‌قدر زیاد کنیم که جمله جا شود، سه‌نقطه می‌ماند؟»  
  **پاسخ:** نه. سرریز رخ نداده است.

### اشتباهات رایج

- فقط `text-overflow: ellipsis` بدون hidden و nowrap. هیچ سه‌نقطه‌ای نمی‌آید و دانشجو فکر می‌کند ویژگی خراب است.  
- گذاشتن این الگو روی span اینلاین خالص، بدون عرض مؤثر.

## ۵) hidden پدر، برچسب و منو را هم می‌برد

«خواستهٔ چهارم را با چیزی که ساخته‌ایم نشان بدهیم، نه با تعریف تازه.»

کارت درس موقعیت را کوتاه بیاور:

```html
<div class="card-badge">
  <span class="badge">جدید</span>
  <strong>دوره CSS</strong>
  <p>برچسب از گوشه بیرون زده است.</p>
</div>
```

```css
.card-badge {
  position: relative;
  width: 220px;
  margin: 24px;
  padding: 14px;
  background: #fff;
  border: 1px solid #cfd8e3;
  border-radius: 8px;
}

.badge {
  position: absolute;
  top: -10px;
  left: -10px;
  background: #2b8a3e;
  color: #fff;
  font-size: 12px;
  padding: 2px 10px;
  border-radius: 12px;
}
```

**در مرورگر:** برچسب کمی بیرون گوشه است و کامل دیده می‌شود. بعد این یک خط را اضافه کن:

```css
.card-badge {
  overflow: hidden;
}
```

**در مرورگر:** بخشی از برچسب که خارج از padding و لبهٔ کارت بوده قیچی می‌شود. گوشهٔ «جدید» ناقص است. `overflow: hidden` فرق نمی‌گذارد که آن بیرون‌زدگی مال یک absolute است یا مال متن. هر چه از لبهٔ پدر بیرون بزند بریده می‌شود.

خط را بردار تا برچسب کامل شود.

«منوی بازشونده همین‌طور ناپدید می‌شود. فهرست فرزند معمولاً absolute است و زیر هدر می‌افتد. اگر روی `header` یا روی ظرف کارت `overflow: hidden` گذاشته باشید تا یک مشکل دیگر را بپوشانید، منو همان‌جا بریده می‌شود و به نظر می‌رسد z-index خراب است. اول overflow جدها را در DevTools نگاه کنید، بعد عدد لایه را بزرگ کنید.

ارتباط با sticky را هم یک جمله بگویید، چون درس موقعیت قولش را داده بود: اگر یک جد `overflow` غیر از visible داشته باشد، چسبیدن sticky داخل همان جد اتفاق می‌افتد. hidden کردن یک پوشش کلی دور صفحه، عنوان چسبان داخلش را حبس می‌کند.»

لازم نیست یک منوی کامل بسازی اگر وقت کم است. یک جعبهٔ absolute با `top: 100%` زیر یک نوار، و hidden روی نوار، همان «ناپدید شدن» را نشان می‌دهد.

### سؤال کلاسی

- «برچسب گوشه ناقص شده. اولین جایی که نگاه می‌کنی کدام ویژگی پدر است؟»  
  **پاسخ:** `overflow: hidden` (یا هر مقداری که بیرون‌زدگی را ببرد) روی خود کارت یا یک جد.

- «برای هم‌قد کردن کارت‌ها اگر hidden متن را می‌برد و برچسب را هم خراب می‌کند، چه جایگزینی از همین درس داریم؟»  
  **پاسخ:** ارتفاع یا max-height با `overflow: auto` تا متن اسکرول شود، و hidden را روی همان پدری که برچسب از آن بیرون زده نگذاریم. یا برچسب را داخل لبه‌ها بیاوریم تا hidden لازم، آن را نبرد. راه‌حل را با خواسته انتخاب کن، نه با یک مقدار ثابت.

### اشتباهات رایج

- `overflow: hidden` سراسری روی پدر منو یا پدر برچسب، فقط برای اینکه «یک گوشه تمیز شود».  
- دیدن منوی بریده و جنگیدن با `z-index`، در حالی که لایه رو است ولی قیچی شده.

## ۶) تصویر داخل قاب؛ hidden همراه اندازهٔ ثابت

در درس حداکثر عرض، تصویر با `max-width: 100%` و `height: auto` نسبت خودش را نگه داشت. یک خواستهٔ دیگر گالری این است که همهٔ قاب‌ها یک اندازه باشند و اضافهٔ عکس دیده نشود.

این را به پروژهٔ اصلی تبدیل نکن اگر وقت کم است؛ یک نمایش کوتاه کافی است:

```css
.frame {
  width: 12rem;
  height: 8rem;
  overflow: hidden;
  border-radius: 0.5rem;
}

.frame img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
```

«`object-fit: cover` یعنی عکس قاب را پر کند و اگر نسبت‌ها یکی نبود، اضافه بریده شود، نه اینکه عکس له شود. خود `overflow: hidden` اینجا هم اضافه را نگه می‌دارد، به‌خصوص همراه `border-radius` تا گوشهٔ عکس از گوشهٔ گرد قاب بیرون نزند.

اگر `object-fit` را هنوز نمی‌خواهید وارد کنید، فقط بگویید قاب با ارتفاع ثابت و hidden، اضافه را می‌برد، و برگردید به متن. اسم را ببرید تا در گالری غریبه نباشد.»

**در مرورگر:** دو عکس با نسبت متفاوت را اگر دارید در قاب یکسان نشان بده. اگر تصویر دوم ندارید، همان `bg.jpg` کافی است و توضیح را کوتاه کن.

## ۷) پروژه کوچک جلسه — جعبهٔ قوانین

خواستهٔ خواندن متن بلند را کامل کن. برچسب را عمداً بیرون این جعبه نگه دار تا hidden پروژه، برچسب را نبرد.

### Live Coding مرحله‌به‌مرحله

۱) HTML:

```html
<section class="policy">
  <h2>قوانین استفاده</h2>
  <div class="policy-body">
    <p>ثبت‌نام به معنی پذیرفتن این متن است.</p>
    <p>هر حساب برای یک نفر است و اشتراک‌گذاری رمز مجاز نیست.</p>
    <p>محتوای دوره فقط برای استفاده شخصی است.</p>
    <p>در صورت قطعی کوتاه، دسترسی بعداً برمی‌گردد.</p>
    <p>پرسش‌ها را از طریق فرم تماس بفرستید.</p>
    <p>این بند آخر باید با اسکرول دیده شود، نه با بلند شدن بی‌نهایت جعبه.</p>
  </div>
</section>
```

۲) CSS:

```css
.policy {
  width: 100%;
  max-width: 28rem;
  margin: 16px auto;
  background: #fff;
  border: 1px solid #cbd5e1;
  border-radius: 8px;
  padding: 12px 16px 16px;
  box-sizing: border-box;
}

.policy-body {
  height: 150px;
  overflow: auto;
  padding-left: 4px;
}
```

«سقف عرض از درس ۲ آمده تا خود بخش در موبایل بیرون نزند. ارتفاع ۱۵۰ پیکسل فقط مال بدنهٔ متن است، نه مال عنوان. اگر `overflow` را روی کل `.policy` بگذاریم، عنوان هم داخل اسکرول می‌رود. خواسته این است که عنوان بماند و متن اسکرول شود، پس overflow روی `.policy-body` است.

`auto` را انتخاب کردیم تا اگر یک روز متن کوتاه شد، نوار خالی نماند.»

**در مرورگر:** عنوان ثابت بالای جعبه است. بدنه اسکرول می‌شود و بند آخر خوانده می‌شود. ارتفاع را بردار و نشان بده اسکرول ناپدید می‌شود چون سرریز رفته. ارتفاع را برگردان. در عرض ۳۲۰ مطمئن شو خود صفحه اسکرول افقی ندارد.

یک عنوان تک‌خطی هم بالای همین پروژه اضافه کن اگر وقت هست، با الگوی ellipsis و عرض ۱۰۰ درصد، تا هر سه خواستهٔ متنی در یک صفحه باشند.

### سؤال کلاسی

- «چرا overflow روی `.policy-body` است نه روی `section`؟»  
  **پاسخ:** تا عنوان بیرون از ناحیهٔ اسکرول بماند و فقط متن بلند اسکرول شود.

## ۸) جمع‌بندی مدرس

۱. چهار مقدار را با خواسته بگو، نه با ترجمهٔ لغت‌نامه.  
   **پاسخ:** `visible` اضافه را نشان می‌دهد. `hidden` می‌برد و راه خواندن نمی‌دهد. `scroll` همیشه نوار می‌گذارد. `auto` فقط وقتی جا نشود نوار می‌گذارد.

۲. سه‌نقطه کدام سه خط را می‌خواهد؟  
   **پاسخ:** `white-space: nowrap`، `overflow: hidden`، `text-overflow: ellipsis`، روی جعبه‌ای با عرض محدود.

۳. چرا منوی بازشونده ممکن است «ناپدید» شود در حالی که z-index درست است؟  
   **پاسخ:** یک جد `overflow: hidden` بیرون‌زدگی را بریده. اول همان را نگاه کن.

۴. `overflow: hidden` روی `body` را کی می‌شنویم؟  
   **پاسخ:** گاهی برای اینکه پشت پنجرهٔ گفتگو، صفحه اسکرول نخورد. با احتیاط، چون اسکرول کل صفحه را می‌گیرد و اگر فراموش شود کاربر دیگر نمی‌تواند صفحه را تکان بدهد. در این درس پیاده‌اش نکن؛ فقط اسم عارضه را بگو.

**پیام پایانی:**

«هدف این جلسه چهار کلمهٔ انگلیسی نبود. هدف این بود که وقتی محتوا از جعبه بزرگ‌تر است، اول بگویید کاربر باید بقیه را بخواند، یا اضافه باید مخفی شود، یا فقط یک محور باید اسکرول بخورد. و قبل از `hidden` کردن یک پدر، یادتان باشد برچسب گوشه و منوی باز هم فرزند همان پدرند.»

## تمرین‌ها (ساده → چالشی)

### ساده

۱. یک جعبه با ارتفاع ۹۰ پیکسل بساز و هر چهار مقدار overflow را یکی‌یکی روش بگذار. برای هر کدام یک جمله بنویس چه دیدی.  
۲. متن جعبهٔ `scroll` را خیلی کوتاه کن و ببین نوار می‌ماند یا نه. همان متن را با `auto` مقایسه کن.

### متوسط

۳. جعبهٔ «قوانین سایت» با ارتفاع ۱۵۰ پیکسل و `overflow: auto` بساز. عنوان را بیرون ناحیهٔ اسکرول نگه دار.  
۴. یک عنوان بلند با عرض ۲۵۰ پیکسل و سه‌نقطه بساز. هر بار یکی از سه ویژگی را حذف کن و بنویس کدام حذف، سه‌نقطه را می‌برد.

### چالشی

۵. ردیف ده برچسب با `overflow-x: auto` و `white-space: nowrap` در عرض ۳۶۰ پیکسل اسکرول افقی بدهد و به خط بعد نرود.  
۶. کارت با برچسب absolute بیرون گوشه بساز، بعد `overflow: hidden` را روی کارت بگذار و برش را نشان بده. در دو جمله بنویس این با باگ z-index چه فرقی دارد، و برای متن بلند همان کارت به‌جای hidden چه مقداری می‌گذاری.
