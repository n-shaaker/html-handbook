## ۱) شروع کلاس — مسئله اول (دیالوگ)

«بچه‌ها، blockquote نقل‌قول داریم. طراح می‌خواهد قبل از متن **«** بزرگ بنفش — بدون `<span>` اضافه در HTML.

Content writer می‌گوید: *«HTML تمیز بماند — فقط `<blockquote><p>…</p></blockquote>`.»*

**Pseudo-element** = بخشی *مجازی* از عنصر — مرورگر جعبه‌ای می‌سازد که در DOM source نیست.

Syntax: **دو نقطه** `::before` — در contrast با pseudo-class **یک نقطه** `:hover`.»

---

## ۲) Live Coding مرحله ۱ — ::before با content

```css
.quote::before {
  content: "«";
  color: #6366f1;
  font-size: 1.5em;
  margin-inline-end: 0.25rem;
}
```

```html
<blockquote class="quote">
  <p>CSS ظاهر را از محتوا جدا می‌کند.</p>
</blockquote>
```

«**`content` اجباری** — حتی تزئین خالی: `content: ""`.

بدون content، ::before/::after **رندر نمی‌شوند**.»

**در مرورگر:** DevTools → element → `::before` در subtree.

### سؤال کلاسی

«متن `content: "مهم"` برای price محصول کافی است؟»  
**پاسخ:** خیر برای اطلاعات حیاتی — screen reader / copy ممکن است نادیده بگیرد؛ در HTML بنویسید.

---

## ۳) Live Coding مرحله ۲ — ::after و required

```css
.required-label::after {
  content: " *";
  color: #ef4444;
}
```

```html
<label class="required-label" for="name">نام</label>
```

«ستاره decorative — معنی «الزامی» باید در HTML (`required` یا متن) هم باشد.»

---

## ۴) ::before as decorative box

```css
.card-with-icon::before {
  content: "";
  display: inline-block;
  width: 0.5rem;
  height: 100%;
  background: #2563eb;
  margin-inline-end: 0.75rem;
}
```

«`content: ""` + display + background — نوار رنگی بدون img.»

---

## ۵) ::first-line و ::first-letter

```css
p.lead::first-line {
  color: #1a5fb4;
  font-weight: bold;
}
```

«**first-line** با reflow — resize پنجره، «خط اول» عوض می‌شود.

**first-letter** در فارسی connected script مشکل اتصال — جزوه مثال انگلیسی [`11-pseudo-elements.html`](../../pages/11-pseudo-elements.html).»

---

## ۶) ::marker و ::selection

```css
ul.custom ::marker {
  color: #0b6e4f;
  font-weight: bold;
}
::selection {
  background: #fde68a;
  color: #0f172a;
}
```

**Live:** متن را select کنید — رنگ highlight.

---

## ۷) ::placeholder (input)

```css
.field::placeholder {
  color: #94a3b8;
  font-size: 0.9rem;
}
```

«فقط decor placeholder — label واقعی در HTML.»

---

## ۸) اشتباهات رایج

- ::before بدون `content`.  
- اطلاعات قیمت/خطا فقط در `content`.  
- `:before` در کد جدید — `:before` legacy هنوز کار می‌کند ولی `::` استاندارد.  
- pseudo-element interactive بدون اندازه (click target).

---

## ۹) پروژه mini

blockquote `.quote` + form label `.required-label` + `::selection` brand color.

## ۱۰) جمع‌بندی

1. بدون content on ::before?  
   **پاسخ:** دیده نمی‌شود.

2. : vs ::?  
   **پاسخ:** class/state vs part/sub-element.

3. a11y risk?  
   **پاسخ:** محتوای مهم فقط در pseudo.

**پیام:** «Decor in CSS — meaning in HTML. فردا **opacity** کل subtree.»
