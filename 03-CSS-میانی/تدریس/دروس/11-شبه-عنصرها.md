## ۱) شروع کلاس؛ نیاز واقعی سایت

اول کلاس این‌طور شروع کن. هنوز اسم `::before` را روی تخته ننویس.

«بچه‌ها، فرض کنید سایت یک مجله آموزشی داریم. در صفحه مقاله، طراح سه چیز خواسته:

اول، قبل از نقل‌قول یک گیومه بزرگ و کم‌رنگ بیاید.  
دوم، زیر عنوان هر بخش یک خط نارنجی کوتاه باشد.  
سوم، کنار فیلدهایی که پر کردنشان اجباری است یک ستاره قرمز دیده شود.

نویسنده محتوا می‌گوید: *HTML باید تمیز بماند.* یعنی داخل `blockquote` فقط خود جمله باشد. زیر `h2` یک `div` خالی برای خط نسازیم. داخل `label` هم کلمه «ستاره» را به‌عنوان متن واقعی قاطی اسم فیلد نکنیم.

سؤال من از شما این است: اگر تگ تازه اضافه نکنیم، این شکل‌ها از کجا بیایند؟ آیا مجبوریم برای هر تزئین یک `span` در HTML بگذاریم؟»

بگذار دو سه جواب بیاید. معمولاً می‌گویند «با عکس» یا «با `border`». هر دو را جدی بگیر، بعد فایل زنده را باز کن.

فایل پیشنهادی: `تدریس/live/11-pseudo-elements.html`

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — شبه‌عنصرها</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      background: #f8fafc;
      padding: 1.5rem;
      line-height: 1.8;
    }
    .quote {
      margin: 0;
      padding: 1rem 1.25rem;
      background: #fff;
      border-radius: 12px;
    }
  </style>
</head>
<body>
  <blockquote class="quote">
    دانستن کافی نیست، باید به کار ببریم.
  </blockquote>
</body>
</html>
```

«ببینید. HTML فقط یک نقل‌قول است. هنوز گیومه‌ای در منبع صفحه نیست. امروز یاد می‌گیریم مرورگر چطور یک جعبه مجازی به این عنصر بچسباند.»

**در مرورگر:** کارت سفید ساده، بدون علامت نقل‌قول. این نقطه ورود است. هنوز `content` را ننویس.

## ۲) شبه‌عنصر چیست و چه فرقی با شبه‌کلاس دارد

«در درس قبل با شبه‌کلاس کار کردیم. `:hover` یک **حالت** است. عنصر همان عنصر می‌ماند؛ فقط وقتی ماوس رویش است ظاهرش عوض می‌شود.

شبه‌عنصر یک **بخش** است. یا تکه‌ای از خود متن را جدا می‌کند، مثل خط اول، یا یک جعبه تازه قبل یا بعد از محتوا می‌سازد که در فایل HTML نوشته نشده.

علامت استانداردش دو دونقطه است: `::before`، `::after`، `::first-letter`، `::first-line`، `::marker`، `::selection`.

در کدهای قدیمی گاهی `:before` و `:after` با یک دونقطه می‌بینید. هنوز در مرورگر کار می‌کند، ولی در کد تازه‌ای که امروز می‌نویسیم شکل استاندارد همان `::` است.»

روی تخته این دو خط را کنار هم بگذار:

```css
a:hover { color: #0b6e4f; }      /* حالت */
.quote::before { content: "«"; } /* بخش / جعبه مجازی */
```

«شبه‌عنصر در درخت عناصر DevTools دیده می‌شود، ولی اگر View Source بگیری داخل HTML نیست. برای همین اسمش شبه‌عنصر است: عنصرِ ساخته‌شده توسط CSS.»

### سؤال کلاسی

- «`:hover` بخش تازه‌ای به صفحه اضافه می‌کند یا فقط حالت را عوض می‌کند؟»  
  **پاسخ:** فقط حالت. بخش تازه کار `::before` و `::after` است.

## ۳) `::before` و گیومه — `content` اجباری است

حالا Live Coding. گیومه را با CSS بساز:

```css
.quote::before {
  content: "«";
  font-size: 50px;
  line-height: 0.6;
  color: #ced4da;
  margin-inline-end: 0.35rem;
}
```

«به مرورگر گفتیم: قبل از محتوای این نقل‌قول یک جعبه بساز و داخلش نویسه گیومه بگذار.

کلمه کلیدی این جعبه `content` است. اگر `content` را ننویسیم، `::before` و `::after` اصلاً ساخته نمی‌شوند. حتی وقتی جعبه را خالی می‌خواهیم، باید بنویسیم `content: ""`. رشته خالی هم یک مقدار است. نبودن ویژگی، با رشته خالی یکی نیست.»

عمداً یک لحظه `content` را پاک کن و ذخیره کن.

**در مرورگر:** گیومه غیب می‌شود. DevTools را باز کن، روی `blockquote` برو و نشان بده که بدون `content` گره `::before` در زیردرخت نیست. بعد `content` را برگردان.

«در DevTools این جعبه را می‌بینید، ولی اگر متن صفحه را با ماوس انتخاب کنید، گیومه مثل جمله مقاله انتخاب نمی‌شود. این متن مال CSS است، مال HTML نیست.»

### سؤال کلاسی

- «اگر بنویسیم `.quote::before { color: red; }` و `content` را فراموش کنیم چه می‌بینیم؟»  
  **پاسخ:** هیچ. قانون رنگ بی‌اثر می‌ماند چون جعبه‌ای ساخته نشده.

- «گیومه را داخل خود `blockquote` در HTML بنویسیم بهتر است یا در `content`؟»  
  **پاسخ:** برای یک علامت تزئینی، `content` مناسب است. اگر خود نقل‌قول بدون آن گیومه معنی‌اش ناقص شود، متن را در HTML بگذار.

### اشتباهات رایج

- نوشتن `::before` بدون `content` و تعجب از اینکه «رنگ اعمال نشد».  
- گذاشتن فاصله بین عدد و واحد، یا فراموش کردن نقل‌قول دور رشته: `content: «;` نامعتبر است. رشته باید داخل `" "` باشد.

## ۴) `::after` — ستاره الزامی و واحد پول

«حالا نیاز دوم فرم ثبت‌نام. برچسب فیلد «نام» است. طراح ستاره قرمز می‌خواهد. اگر ستاره را فقط با CSS بسازیم، باید حواسمان باشد معنی «الزامی» در HTML هم باشد.»

```html
<label class="required" for="name">نام و نام خانوادگی</label>
<input id="name" name="name" required>
```

```css
.required::after {
  content: " *";
  color: #c92a2a;
  font-weight: bold;
}
```

«`::after` جعبه را **بعد** از محتوای عنصر می‌سازد. اینجا بعد از کلمه نام، یک فاصله و ستاره می‌آید.

ستاره تزئین است. ویژگی `required` روی `input` به مرورگر و به فناوری کمکی می‌گوید این فیلد اجباری است. اگر فقط ستاره CSS داشته باشیم و `required` را نگذاریم، فرم خالی هم ارسال می‌شود و بعضی صفحه‌خوان‌ها اصلاً ستاره را نمی‌خوانند.»

همان الگو را برای قیمت نشان بده. عدد در HTML است، واحد تزئینی در CSS:

```html
<p>قیمت: <span class="price">۱۲۰٬۰۰۰</span></p>
```

```css
.price::after {
  content: " تومان";
  color: #868e96;
  font-size: 0.85em;
}
```

مکث کن و این سؤال را جدی بپرس. جواب عجله‌ای «هر دو خوب است» را نپذیر.

«اگر واحد پول را فقط در `content` بگذاریم و در صفحه سه قیمت داشته باشیم، کاربر نابینا ممکن است فقط عدد را بشنود. تومان بخشی از اطلاعات خرید است. پس واحد پول را در HTML بنویسید. `::after` را برای خط تزئینی و علامت کمکی نگه دارید، نه برای متنی که اگر نباشد خرید اشتباه می‌شود.»

یک نسخه درست را کنار نسخه نمایشی بنویس:

```html
<p>قیمت: <span class="price">۱۲۰٬۰۰۰ تومان</span></p>
```

«در جزوه واحد را با `::after` نشان داده‌ایم تا مکانیزم را ببینید. در پروژه واقعی فروشگاه، «تومان» داخل HTML می‌ماند.»

**در مرورگر:** ستاره قرمز بعد از برچسب؛ عدد قیمت با پسوند خاکستری. در Elements هر دو `::after` را باز کن.

### سؤال کلاسی

- «`::before` کجای عنصر می‌نشیند و `::after` کجا؟»  
  **پاسخ:** قبل از محتوای عنصر، و بعد از محتوای عنصر. هر عنصر فقط یک `::before` و یک `::after` دارد.

- «چرا ستاره به‌تنهایی کافی نیست؟»  
  **پاسخ:** چون در منبع HTML نیست، انتخاب و کپی و خواندن آن مثل متن واقعی تضمین نمی‌شود. الزام را با `required` هم اعلام کن.

## ۵) جعبه خالی — خط زیر عنوان بخش

«سومین خواسته طراح: زیر «خدمات ما» یک خط نارنجی ۶۰ پیکسلی. اگر یک `div` خالی در HTML بگذاریم، معنایی به صفحه اضافه نکرده‌ایم و فقط شلوغی ساخته‌ایم.

اینجا `content` را خالی می‌گذاریم و به جعبه اندازه و رنگ می‌دهیم.»

```html
<h2 class="fancy">خدمات ما</h2>
```

```css
.fancy::after {
  content: "";
  display: block;
  width: 60px;
  height: 4px;
  background: #e8590c;
  margin-top: 6px;
  border-radius: 2px;
}
```

«`content: ""` جعبه را می‌سازد ولی نویسه‌ای داخلش نیست. تا وقتی `display` پیش‌فرض این شبه‌عنصر inline است، `width` و `height` آن‌طور که انتظار داریم عمل نمی‌کنند. با `display: block` جعبه به خط بعد می‌رود و ۶۰ در ۴ پیکسل نارنجی می‌شود.

این همان درسی است که در `display` خواندید: نوع جعبه تعیین می‌کند عرض و ارتفاع اثر کنند یا نه.»

اگر وقت بود یک نوار کنار کارت هم نشان بده، تا ببینند `inline-block` هم ممکن است:

```css
.note::before {
  content: "";
  display: inline-block;
  width: 4px;
  height: 1em;
  background: #0b6e4f;
  margin-inline-end: 0.6rem;
  vertical-align: -0.1em;
}
```

**در مرورگر:** خط نارنجی دقیقاً زیر متن عنوان است و با زیاد شدن کلمات عنوان، عرض خط ثابت می‌ماند. این را با `border-bottom` روی خود `h2` مقایسه کن: `border` تمام عرض عنوان را می‌گیرد، `::after` می‌تواند کوتاه‌تر از متن باشد.

### سؤال کلاسی

- «چرا اینجا `display: block` لازم شد؟»  
  **پاسخ:** چون می‌خواهیم جعبه خالی عرض و ارتفاع مشخص بگیرد و زیر متن، در خط خودش باشد.

### اشتباهات رایج

- `content: ""` را با حذف کامل `content` یکی گرفتن.  
- انتظار اینکه `width` روی شبه‌عنصر inline مثل یک `div` عمل کند.

## ۶) جاهایی که `::before` ساخته نمی‌شود

«یک دام رایج. دانشجو روی خود `input` یا `img` شبه‌عنصر می‌گذارد و هیچ چیز نمی‌بیند.»

```css
input::before { content: "*"; color: red; }
img::after { content: ""; display: block; height: 4px; background: orange; }
```

«`img` و `input` محتوای داخلی به آن معنا ندارند. مرورگر داخلشان `::before` و `::after` نمی‌سازد. شبه‌عنصر را روی عنصری بگذار که محتوا دارد: `label`، `div` دور تصویر، یا خود `button` اگر محتوایش متن باشد.»

```html
<div class="shot">
  <img src="cover.jpg" alt="جلد کتاب">
</div>
```

```css
.shot::after {
  content: "";
  display: block;
  height: 4px;
  background: #e8590c;
}
```

**در مرورگر:** قانون روی `input` را در DevTools نشان بده که اعمال نمی‌شود یا جعبه ساخته نمی‌شود. بعد همان ستاره را به `label` برگردان.

### سؤال کلاسی

- «علامت فایل PDF را می‌خواهیم کنار یک لینک. شبه‌عنصر را روی `a` بگذاریم یا روی `img`؟»  
  **پاسخ:** روی `a`، چون لینک محتوا دارد. درس ۱۵ همین الگو را با انتخابگر ویژگی کامل می‌کند.

## ۷) خط اول و حرف اول

«تا اینجا جعبه تازه ساختیم. بعضی شبه‌عنصرها جعبه اضافه نمی‌سازند؛ تکه‌ای از متن موجود را جدا می‌کنند.»

```html
<p class="lead">
  فقط خط اول این پاراگراف آبی و پررنگ است. اگر پنجره را کوچک یا بزرگ کنید،
  می‌بینید که همیشه همان خط اول، هر چقدر که در عرض جا شود، تغییر می‌کند
  و بقیه متن عادی می‌ماند.
</p>
```

```css
.lead::first-line {
  color: #1a5fb4;
  font-weight: bold;
}
```

عرض پنجره را آرام کم کن.

«`::first-line` به یک تعداد کلمه ثابت وصل نیست. هر بار که چیدمان عوض شود، مرورگر دوباره حساب می‌کند خط اول کدام واژه‌ها هستند. برای شروع مقاله این رفتار زیباست. برای جمله‌ای که باید همیشه آبی بماند، یک `span` با کلاس مطمئن‌تر است، چون با باریک شدن صفحه واژه‌ها جابه‌جا می‌شوند.»

حرف اول را جدا نشان بده. مثال را انگلیسی نگه دار، همان‌طور که جزوه گفته:

```html
<p class="drop" dir="ltr">Once upon a time, there was a little web page.</p>
```

```css
.drop::first-letter {
  font-size: 40px;
  font-weight: bold;
  color: #c92a2a;
  margin-inline-end: 4px;
}
```

«در متن فارسی حروف به هم می‌چسبند. اگر حرف اول را با `::first-letter` درشت کنیم، ممکن است اتصال همان حرف با حرف بعدی بشکند. برای همین در جزوه مثال انگلیسی است. در مقاله فارسی اگر حرف اول تزئینی می‌خواهید، نتیجه را در همان فونت سایت چک کنید و اگر شکست، از این شبه‌عنصر صرف نظر کنید.»

**در مرورگر:** با تغییر عرض، محدوده پررنگ `::first-line` عوض می‌شود. حرف O انگلیسی درشت و قرمز است.

### سؤال کلاسی

- «اگر پنجره را باریک کنیم، آیا همان کلمه‌های قبلی آبی می‌مانند؟»  
  **پاسخ:** نه. هر چه در خط اولِ جدید جا شود آبی می‌شود.

### اشتباهات رایج

- استفاده از `::first-letter` روی متن فارسی بدون دیدن نتیجه در فونت واقعی.  
- انتظار اینکه `::first-line` با `padding` یا `margin` مثل یک `div` رفتار کند. ویژگی‌های مجاز این شبه‌عنصر محدود است؛ عمدتاً رنگ، پس‌زمینه و فونت.

## ۸) علامت فهرست و رنگ انتخاب متن

«فهرست خدمات هنوز نقطه پیش‌فرض مرورگر را دارد. طراح نقطه را نارنجی و درشت می‌خواهد. به‌جای حذف `list-style` و گذاشتن عکس برای هر آیتم، خود علامت را هدف می‌گیریم.»

```css
ul.mark li::marker {
  color: #e8590c;
  font-size: 20px;
}
```

```html
<ul class="mark">
  <li>علامت این فهرست نارنجی است</li>
  <li>با ::marker تغییر کرده</li>
</ul>
```

«`::marker` همان گلوله یا شماره است. روی آن فقط ویژگی‌های محدودی کار می‌کند: رنگ، اندازه و نوع فونت. `padding` و `margin` و `background` را اینجا انتظار نداشته باشید. اگر علامت باید یک شکل کاملاً سفارشی باشد، آن وقت `list-style: none` و یک `::before` با `content` راه بعدی است.»

حالا انتخاب متن. برند مجله زرد است. وقتی کاربر جمله‌ای را هایلایت می‌کند، زرد برند دیده شود:

```css
.article ::selection {
  background: #ffd43b;
  color: #1a1a1a;
}
```

«از یک دانشجو بخواه متن را با ماوس انتخاب کند. پس‌زمینه زرد می‌شود و رنگ نوشته سیاه می‌ماند تا خوانا باشد.

`::selection` هم ویژگی‌هایش محدود است. معمولاً `color` و `background`. این شبه‌عنصر جعبه جدید نمی‌سازد؛ فقط ظاهر متنِ در حال انتخاب را عوض می‌کند.»

**در مرورگر:** گلوله نارنجی؛ با drag روی پاراگراف، زردِ انتخاب. اگر contrast زرد با متن سفید کم شد، رنگ متن انتخاب را تیره کن و این را با صدای بلند بگو.

### سؤال کلاسی

- «می‌شود به `::marker` یک `padding` داد تا از متن فاصله بگیرد؟»  
  **پاسخ:** نه به‌صورت قابل اتکا. فاصله آیتم را با `padding` خود `li` تنظیم کن، یا علامت را با `::before` بساز.

## ۹) پروژه جلسه — کارت مقاله مجله

مثال‌های جدا را جمع کن. یک کارت بساز و همه را در آن نشان بده. مرحله‌به‌مرحله تایپ کن، یک‌جا کپی نکن.

### HTML

```html
<article class="article">
  <h2 class="fancy">یادداشت سردبیر</h2>
  <p class="lead">
    طراحی خوب از یک جعبه شروع نمی‌شود. از یک جمله روشن شروع می‌شود.
    بقیه صفحه باید به همان جمله خدمت کند، نه اینکه حواس را پرت کند.
  </p>
  <blockquote class="quote">دانستن کافی نیست، باید به کار ببریم.</blockquote>
  <ul class="mark">
    <li>HTML معنی را نگه می‌دارد</li>
    <li>CSS شکل را اضافه می‌کند</li>
  </ul>
  <label class="required" for="email">ایمیل خبرنامه</label>
  <input id="email" type="email" required>
</article>
```

### CSS

```css
.article {
  max-width: 36rem;
  padding: 1.25rem;
  background: #fff;
  border-radius: 16px;
}

.fancy::after {
  content: "";
  display: block;
  width: 60px;
  height: 4px;
  margin-top: 6px;
  background: #e8590c;
}

.lead::first-line {
  color: #1a5fb4;
  font-weight: bold;
}

.quote::before {
  content: "«";
  color: #ced4da;
  font-size: 50px;
  line-height: 0;
  margin-inline-end: 0.25rem;
}

.mark li::marker {
  color: #e8590c;
}

.required::after {
  content: " *";
  color: #c92a2a;
}

.article ::selection {
  background: #ffd43b;
  color: #111;
}
```

«ببینید HTML هنوز مقاله است: عنوان، پاراگراف، نقل‌قول، فهرست، برچسب. خط، گیومه، رنگ گلوله، ستاره و رنگ انتخاب همه از CSS آمده‌اند. فیلد ایمیل `required` دارد، پس ستاره تنها حامل معنی نیست.»

**در مرورگر:** عرض را عوض کن تا خط اول جابه‌جا شود. متن را انتخاب کن. در DevTools هر شبه‌عنصر را یکی‌یکی خاموش کن تا دانشجو ببیند کدام تکه از صفحه ناپدید می‌شود.

### سؤال کلاسی

- «اگر فردا طراح رنگ خط را سبز خواست، HTML را عوض می‌کنیم یا CSS را؟»  
  **پاسخ:** فقط مقدار `background` در `::after`. ساختار مقاله دست نمی‌خورد.

## ۱۰) جمع‌بندی مدرس و سؤالات پایانی

قبل از تمرین این سه سؤال را بپرس:

1. شبه‌عنصر را با چه علامتی می‌نویسیم و فرقش با شبه‌کلاس چیست؟  
   **پاسخ راهنما:** دو دونقطه. شبه‌کلاس حالت است، شبه‌عنصر بخش یا جعبه مجازی است.

2. چرا `::before` بدون `content` دیده نمی‌شود، حتی اگر رنگ داشته باشد؟  
   **پاسخ:** چون مرورگر تا `content` — حتی رشته خالی — نباشد آن جعبه را نمی‌سازد.

3. چه متنی را نباید فقط داخل `content` گذاشت؟  
   **پاسخ:** اطلاعاتی که اگر خوانده یا کپی نشود کاربر اشتباه می‌کند: قیمت کامل، پیام خطا، نام فیلد. تزئین و علامت کمکی در CSS؛ معنی در HTML.

**پیام پایانی:**

«هدف این جلسه حفظ کردن فهرست شبه‌عنصرها نبود. هدف این بود که وقتی طراح یک خط، یک گیومه یا یک ستاره می‌خواهد، اول بپرسید این تکه معنی است یا تزئین. تزئین را با `::before` و `::after` بسازید و `content` را فراموش نکنید. معنی را در HTML بگذارید.»

## تمرین‌ها (ساده → چالشی)

### ساده

1. یک `blockquote` با کلاس `quote` بساز و با `::before` گیومه « را خاکستری و درشت کن. یک بار `content` را حذف کن و تفاوت را در DevTools بنویس.  
2. زیر یک `h2` با `::after` و `content: ""` خطی ۴ پیکسلی و ۶۰ پیکسلی بساز. بدون `display: block` نتیجه را هم ببین.

### متوسط

3. برای لینک‌هایی که کلاس `external` دارند با `::after` نویسه `↗` اضافه کن. در HTML همان لینک‌ها `target="_blank"` داشته باشند تا درس بعد و درس ۱۵ به همین علامت برگردد.  
4. یک فهرست سه آیتمی با `li::marker` بساز و رنگ علامت را عوض کن. بعد سعی کن به `::marker` مقدار `padding` بدهی و ببین چه ویژگی‌هایی اثر دارند.

### چالشی

5. کارت مقاله همین جلسه را کامل کن: `::first-line`، گیومه، خط عنوان، ستاره روی `label`، و `::selection`. فیلد اجباری باید ویژگی `required` هم داشته باشد.  
6. توضیح بده چرا واحد «تومان» را در فروشگاه واقعی داخل HTML می‌نویسی، ولی خط نارنجی زیر عنوان را در `::after`.
