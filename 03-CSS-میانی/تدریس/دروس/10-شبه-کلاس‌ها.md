## ۱) شروع کلاس — مسئله اول (دیالوگ)

«بچه‌ها، دکمه «ثبت‌نام» را استایل کردید — `:hover` سبز می‌شود، کاربر ماوس خوشحال است.

اما همکلاسی که فقط **کیبورد** دارد Tab می‌زند — دکمه focus می‌گیرد ولی **هیچ حلقه‌ای** نمی‌بیند. نمی‌داند کجای صفحه است. این bug دسترسی (accessibility) است، نه «سلیقه».

یا بدتر: `outline: none` زدید تا «زشت نباشد» — بدون `:focus-visible` جایگزین.

امروز **pseudo-class** — حالت‌هایی که در HTML class ننوشتید؛ مرورگر از تعامل یا جایگاه در DOM تشخیص می‌دهد.»

Syntax روی تخته:

```css
selector:pseudo-class {
  property: value;
}
```

«**بدون فاصله** بین selector و `:` — `a:hover` درست؛ `a :hover` یعنی descendant hover شده **داخل** a.»

---

## ۲) Live Coding مرحله ۱ — دکمه زنده

مطابق [`pseudo-classes.css`](../../css/demos/pseudo-classes.css):

```css
.btn {
  padding: 0.5rem 1.25rem;
  border: none;
  border-radius: 0.375rem;
  background-color: #1a5fb4;
  color: white;
  cursor: pointer;
  font-family: inherit;
}
.btn:hover {
  background-color: #0b6e4f;
}
.btn:active {
  transform: scale(0.95);
}
```

**در مرورگر:** ماوس بیارید — سبز؛ کلیک — کوچک می‌شود (`:active`).

### سؤال کلاسی

«`:hover` روی موبایل touch همیشه مثل دسکتاپ است؟»  
**پاسخ:** رفتار touch متفاوت — استایل پایه باید بدون hover هم خوانا باشد؛ hover enhancement است.

## ۳) Live Coding مرحله ۲ — `:focus` روی input

```css
.field {
  padding: 0.5rem 0.75rem;
  border: 1px solid #cbd5e1;
  border-radius: 0.25rem;
}
input:focus {
  border-color: #1a5fb4;
  background-color: #e8f4fd;
  outline: 3px solid #a5d8ff;
}
```

**در مرورگر:** کلیک داخل input — border و outline.

«**هرگز** `outline: none` بدون جایگزین واضح — کاربران Tab به آن وابسته‌اند.»

---

## ۴) Live Coding مرحله ۳ — `:focus-visible`

«با ماوس روی دکمه کلیک → outline زیاد می‌خواهیم نباشد؛ با Tab → باشد:

```css
.btn:focus {
  outline: none;
}
.btn:focus-visible {
  outline: 2px solid #6366f1;
  outline-offset: 2px;
}
```

**در مرورگر:** Tab روی دکمه جزوه — حلقه indigo؛ کلیک ماوس — بدون حلقه (در مرورگرهای مدرن).

لینک‌های nav جزوه با Tab — کادر نارنجی [`10-pseudo-classes.html`](../../pages/10-pseudo-classes.html).»

### سؤال کلاسی

«تفاوت `:focus` و `:focus-visible`?»  
**پاسخ:** focus هر focus؛ focus-visible وقتی مرورگر فکر می‌کند نشان دادن حلقه برای کاربر لازم است (اغلب keyboard).

## ۵) لینک — ترتیب LVHA (یا LVFHA)

«برای `<a href>` چهار حالت:

```css
a:link { color: #2563eb; }
a:visited { color: #7c3aed; }
a:hover { color: #0b6e4f; }
a:active { color: #c92a2a; }
a:focus-visible { outline: 2px solid #f59e0b; outline-offset: 2px; }
```

**ترتیب مهم است** — `:link` و `:visited` قبل از `:hover` و `:active` تا hover برنده نشود.

یادآوری: **Love Hate** — Link Visited Focus Hover Active (تلفظ‌های مختلف در منابع).»

**Live:** ترتیب را عوض کنید — `:visited` بعد `:hover` — رفتار عجیب ببینید.

---

## ۶) Live Coding مرحله ۴ — `:first-child` و `:last-child`

```css
li:first-child {
  color: green;
  font-weight: bold;
}
li:last-child {
  color: red;
}
```

**در مرورگر:** demo `.list-fl` — اول سبز، آخر قرمز.

«`:first-child` یعنی **اولین فرزند والد** — اگر قبل از `li` یک `<p>` باشد، `li:first-child` match **نمی‌کند**.»

---

## ۷) Live Coding مرحله ۵ — `:nth-child()`

```css
li:nth-child(odd) {
  background: #f1f3f5;
}
li:nth-child(3n) {
  color: #c92a2a;
}
li:nth-child(2) {
  font-weight: bold;
}
```

«شمارش از **۱** — روی **همه** فرزندان والد، نه فقط `li`.

اگر `<div>` قبل از `li` باشد، «سومین li» ≠ «nth-child(3)`.

**راه‌حل:** `:nth-of-type(3)` فقط بین `li`ها می‌شمارد — جزوه tip را بخوانید.»

### سؤال کلاسی

«`:nth-child(2n)` چه جایگاه‌هایی?»  
**پاسخ:** زوج: 2، 4، 6، …

---

## ۸) `:not()` و `:disabled`

```css
.menu a:not(.disabled) {
  cursor: pointer;
}
.menu a.disabled {
  opacity: 0.5;
  pointer-events: none;
}
button:disabled {
  opacity: 0.6;
  cursor: not-allowed;
}
```

«`:not(.disabled)` — همه لینک‌ها جز class disabled.  
`:disabled` — attribute روی button/input.»

## ۱۰) پروژه mini — فرم کوتاه

```html
<form class="signup">
  <label>
    ایمیل
    <input class="field" type="email" required placeholder="you@example.com">
  </label>
  <button class="btn" type="submit">ثبت</button>
</form>
```

```css
input:invalid:not(:placeholder-shown) {
  border-color: #ef4444;
}
input:valid:not(:placeholder-shown) {
  border-color: #059669;
}
```

**نمایش:** ایمیل نامعتبر — border قرمز؛ `:placeholder-shown` empty را قرمز نمی‌کند.

---

## ۱۱) اشتباهات رایج

- فاصله قبل `:hover` — selector اشتباه.  
- `outline: none` سراسری بدون focus-visible.  
- `:nth-child` وقتی sibling غیر li شمارش را خراب می‌کند — nth-of-type.  
- فراموش `:active` — feedback کلیک.

---

## ۱۲) جمع‌بندی و سؤالات پایانی

1. `a :hover` vs `a:hover`?  
   **پاسخ:** اولی descendant؛ دومی خود لینک hover.

2. چرا LVHA ترتیب?  
   **پاسخ:** specificity/cascade — hover/visited conflict.

3. outline حذف?  
   **پاسخ:** فقط با focus-visible جایگزین.

**پیام پایانی:** «Pseudo-class = **زمان و state**. فردا **pseudo-element** — `::before` / `::after` برای تزئین بدون HTML اضافه.»
