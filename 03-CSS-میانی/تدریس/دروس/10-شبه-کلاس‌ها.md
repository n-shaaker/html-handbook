## ۱) شروع کلاس؛ مسئله واقعی سایت

«بچه‌ها، فرم ثبت‌نام یک دکمه آبی دارد. طرح می‌گوید وقتی ماوس روی دکمه می‌رود سبز شود، و همان لحظه که کلیک می‌شود کمی کوچک شود تا کاربر بفهمد فشار ثبت شده.

اگر بخواهیم این را با کلاس HTML حل کنیم، باید با جاوااسکریپت روی `mouseover` کلاس اضافه کنیم و روی `mouseout` برداریم. برای «اولین ردیف جدول» هم باید یادمان بماند به همان `tr` کلاس `first` بدهیم. این حالت‌ها در فایل HTML نوشته نشده‌اند. مرورگر خودش می‌داند ماوس کجاست، کدام کادر فوکوس دارد، و هر عنصر چندمین فرزند پدرش است.

اسم این انتخاب، **شبه‌کلاس** است. به انتخابگر با یک دونقطه می‌چسبد:

```css
selector:pseudo-class {
  property: value;
}
```

بین نام و دونقطه **فاصله نگذارید**. `a:hover` یعنی خود لینک، وقتی ماوس روی آن است. `a :hover` یعنی یک عنصر hoverشده *داخل* لینک. فاصله این‌جا همان‌قدر معنی را عوض می‌کند که دیروز فاصله بین `.card` و `p`.»

فایل زنده (پیشنهاد: `تدریس/live/10-pseudo-classes.html`):

```html
<button class="btn" type="button">ثبت‌نام</button>
```

```css
body { font-family: Tahoma, sans-serif; padding: 1.5rem; background: #f8fafc; }
.btn {
  padding: 0.5rem 1.25rem;
  border: none;
  border-radius: 0.375rem;
  background-color: #1a5fb4;
  color: white;
  cursor: pointer;
}
```

**در مرورگر:** دکمه آبی است و با ماوس هیچ فرقی نمی‌کند. این «قبل» درس است. هنوز `:hover` را ننویس تا دانشجو نبودن بازخورد را ببیند.

### سؤال کلاسی

- «شبه‌کلاس را در HTML کجا می‌نویسیم؟»  
  **پاسخ:** هیچ‌جا. در CSS است. HTML کلاس تازه‌ای برای hover نمی‌گیرد.

## ۲) `:hover` و `:active` — دکمه زنده

«`:hover` وقتی است که اشاره‌گر روی عنصر است. `:active` لحظه فعال شدن است؛ برای دکمه، همان فشرده شدن کلیک.»

```css
.btn:hover {
  background-color: #0b6e4f;
}

.btn:active {
  transform: scale(0.95);
}
```

**در مرورگر:** ماوس را ببر روی دکمه تا سبز شود. کلیک را نگه دار تا دکمه به ۹۵٪ اندازه خودش جمع شود. رها کن تا برگردد. این مثال ۱ جزوه است.

حالا عمداً فاصله را نشان بده:

```css
.btn :hover {
  background: red;
}
```

**در مرورگر:** خود دکمه با این قانون قرمز نمی‌شود، مگر داخل دکمه یک عنصر باشد و ماوس روی همان فرزند برود. قانون را پاک کن و `.btn:hover` را برگردان. این اشتباه رایج جزوه است؛ ده ثانیه دیدنش از پنج بار توضیح بهتر است.

«روی صفحه لمسی hover پایدار نیست. رنگ عادی دکمه باید بدون hover هم خوانا باشد؛ سبز شدن فقط بازخورد اضافه است.»

### سؤال کلاسی

- «`:active` بعد از رها کردن کلیک می‌ماند؟»  
  **پاسخ:** نه. فقط مدت فعال بودن فشار است.

### اشتباهات رایج

- `outline` یا رنگ متن را فقط در hover عوض کردن، طوری که بدون ماوس دکمه شبیه متن معمولی شود.  
- فراموش کردن `:active`. کاربر کلیک می‌کند و هیچ تغییری نمی‌بیند و فکر می‌کند دکمه خراب است.

## ۳) `:focus` — کادری که الان مقصد تایپ است

«کاربر دو کادر دارد. باید بفهمد حرف‌هایی که می‌زند داخل کدام است. این حالت `:focus` است.»

```html
<input class="field" type="text" placeholder="روی من کلیک کن" aria-label="کادر نمونه اول">
<input class="field" type="text" placeholder="یا روی من" aria-label="کادر نمونه دوم">
```

```css
.field {
  display: block;
  margin: 0.5rem 0;
  padding: 0.5rem 0.75rem;
  border: 1px solid #cbd5e1;
  border-radius: 0.25rem;
  font-family: inherit;
  font-size: 1rem;
}

input:focus {
  border-color: #1a5fb4;
  background-color: #e8f4fd;
  outline: 3px solid #a5d8ff;
}
```

**در مرورگر:** در کادر کلیک کن. حاشیه آبی، زمینه آبی خیلی روشن، و یک حلقه روشن دور کادر. Tab را بزن تا فوکوس به کادر دوم برود. این مثال ۲ جزوه است.

«حلقه `outline` را بی‌دلیل حذف نکن. کسی که با Tab حرکت می‌کند، بدون حلقه نمی‌فهمد کجای صفحه است. جزوه می‌گوید هرگز outline را بدون جایگزین واضح برندار.»

### `:focus-visible` — حلقه وقتی خود کاربر به آن نیاز دارد

«`:focus-visible` نسخه محتاط‌تر `:focus` است. مرورگر حلقه را وقتی نشان می‌دهد که تشخیص دهد کاربر باید آن را ببیند؛ معمولاً وقتی با صفحه‌کلید (Tab) آمده، نه وقتی با ماوس روی دکمه کلیک کرده.

برای کادر متن، `:focus` هنوز مناسب است، چون حتی کلیک ماوس هم یعنی «دارم این‌جا تایپ می‌کنم» و بازخورد زمینه لازم است. برای دکمه و لینک، `:focus-visible` انتخاب بهتری است تا کلیک ماوس یک حلقه اضافه روی دکمه نگذارد و Tab هنوز حلقه را داشته باشد.»

```css
.btn:focus {
  outline: none;
}

.btn:focus-visible {
  outline: 2px solid #f59e0b;
  outline-offset: 2px;
}
```

**در مرورگر:** با ماوس روی «ثبت‌نام» کلیک کن. در مرورگرهای جدید حلقه نارنجی نمی‌آید، چون `:focus-visible` برقرار نشده، و `:focus` فقط outline پیش‌فرض را خاموش کرده. بعد Tab را بزن تا دکمه با صفحه‌کلید فوکوس بگیرد. حلقه نارنجی با ۲ پیکسل فاصله (`outline-offset`) دیده می‌شود.

«این الگو را حفظ کن: اگر `outline: none` می‌نویسی، همان عنصر باید یک `:focus-visible` با outline یا سایه واقعاً دیده‌شونده داشته باشد. `outline: none` تنها، در فایل پروژه ممنوع است.

در خود جزوه، لینک‌های ناوبری با Tab کادر نارنجی می‌گیرند. یک بار از صفحه [`10-pseudo-classes.html`](../../pages/10-pseudo-classes.html) Tab را نشان بده تا دانشجو فکر نکند این رفتار فقط مال دکمه آزمایشی ماست.»

### سؤال کلاسی

- «فرق `:focus` و `:focus-visible` چیست؟»  
  **پاسخ:** `:focus` هر وقت عنصر فوکوس دارد برقرار است. `:focus-visible` وقتی است که مرورگر نمایش حلقه را برای همین فوکوس لازم می‌داند؛ اغلب ورود با صفحه‌کلید.

### اشتباهات رایج

- `outline: none` سراسری روی `*` یا `button` بدون قانون جایگزین.  
- تکیه بر فقط تغییر `border` برای فوکوس، با رنگی که روی زمینه صفحه گم می‌شود. حلقه باید از خود دکمه جدا دیده شود.

## ۴) چهار حالت لینک — ترتیب LVHA

«لینک `<a href>` چهار حالت پرکاربرد دارد و ترتیب نوشتنشان مهم است، چون اگر specificity یکی باشد، قانونی که دیرتر آمده برنده می‌شود.

اگر `:hover` را قبل از `:visited` بنویسی، لینکی که قبلاً باز شده دیگر رنگ hover را نمی‌گیرد: قانون visited که دیرتر آمده، رنگ را پس می‌گیرد.»

```html
<p><a href="https://example.com">یک لینک نمونه</a></p>
```

```css
a:link    { color: #1a5fb4; }   /* هنوز نرفته‌ایم */
a:visited { color: #6741d9; }   /* در تاریخچه مرورگر هست */
a:hover   { color: #0b6e4f; }   /* ماوس روی لینک */
a:active  { color: #c92a2a; }   /* لحظه کلیک */
```

«برای یاد ماندن، جزوه این جمله را داده: **LoVe HAte** — Link، Visited، Hover، Active.»

**در مرورگر:** اگر این آدرس را قبلاً باز نکرده‌ای، لینک آبی است. ماوس را ببر تا سبز شود. کلیک را نگه دار تا قرمزِ لحظه active را ببینی. برای visited، یک بار لینک را باز کن و برگرد، یا موقتاً در درس از یک نشانی که مطمئنی در تاریخچه است استفاده کن. اگر محیط کلاس تاریخچه را نشان نمی‌دهد، ترتیب را با جابه‌جایی عمدی خراب کن:

```css
a:link    { color: #1a5fb4; }
a:hover   { color: #0b6e4f; }
a:visited { color: #6741d9; }
```

اگر لینک visited باشد، ماوس را که می‌بری سبز نمی‌ماند؛ بنفش visited که دیرتر آمده برنده است. ترتیب را به LVHA برگردان تا سبز hover برگردد.

«`:focus-visible` را می‌توانی بعد از این چهار تا، برای حلقه کیبورد، اضافه کنی. حلقه با `outline` است و با `color` این چهار قانون دعوا نمی‌کند. جای Love/Hate را به‌هم نزن.»

```css
a:focus-visible {
  outline: 2px solid #f59e0b;
  outline-offset: 2px;
}
```

### اشتباهات رایج

- بلوک LVHA را با یک `a { color }` دیرتر در فایل باطل کردن. چهار خط را یک‌جا و به همان ترتیب نگه دار.  
- استایل `a:hover` بدون `:link`، و بعد تعجب از رنگ پیش‌فرض مرورگر برای visited.

## ۵) `:first-child` و `:last-child` — جایگاه بین همه فرزندان

«فهرست رتبه‌ها: نفر اول سبز و پررنگ، نفر آخر قرمز.»

```html
<ul class="list-fl">
  <li>نفر اول (برنده)</li>
  <li>نفر دوم</li>
  <li>نفر سوم</li>
  <li>نفر آخر</li>
</ul>
```

```css
li:first-child {
  color: green;
  font-weight: bold;
}

li:last-child {
  color: red;
}
```

**در مرورگر:** اولی سبز، آخری قرمز. وسط‌ها رنگ معمولی. مثال ۳ جزوه.

«`:first-child` یعنی این عنصر **اولین فرزند پدرش** است، نه «اولین `li`». اگر قبل از `li` فرزند دیگری باشد، قانون سبز هیچ‌کس را نمی‌گیرد. تله را با همین فهرست بساز:»

```html
<ul class="list-fl">
  <h4>رتبه‌ها</h4>
  <li>نفر اول</li>
  <li>نفر دوم</li>
  <li>نفر آخر</li>
</ul>
```

**در مرورگر:** `li:first-child` دیگر match ندارد، چون اولین فرزند `ul` همان `h4` است. این `h4` داخل `ul` فقط برای آزمایش شمارش است؛ در پروژه تیتر را بیرون فهرست بگذار.

«درمان جزوه: `li:first-of-type`. این یکی بین عنصرهای هم‌نوع می‌شمارد. اولین `li` را می‌گیرد، حتی اگر قبلش خواهرِ غیرِ `li` باشد.»

```css
li:first-of-type {
  color: green;
  font-weight: bold;
}

li:last-of-type {
  color: red;
}
```

**در مرورگر:** سبز و قرمز برمی‌گردند. `first-child` را در فایل کامنت کن تا فقط of-type اثر کند و دانشجو فرق را به کلاس نسبت ندهد.

### اشتباهات رایج

- `:first-child` را «اولین مورد از این کلاس» معنی کردن. جایگاه بین همه فرزندان پدر است، نه بین هم‌کلاسی‌ها. برای «اولی از این نوع» of-type است.

## ۶) `:nth-child` — شماره، فرد، و هر چندمین

«فهرست هفت‌تایی. فردها زمینه خاکستری روشن، هر سومین مورد متن قرمز، و فقط مورد دوم پررنگ.»

```html
<ol class="list-nth">
  <li>آیتم ۱</li><li>آیتم ۲</li><li>آیتم ۳</li><li>آیتم ۴</li>
  <li>آیتم ۵</li><li>آیتم ۶</li><li>آیتم ۷</li>
</ol>
```

```css
li:nth-child(odd) {
  background: #f1f3f5;
}

li:nth-child(3n) {
  color: #c92a2a;
}

li:nth-child(2) {
  font-weight: bold;
}
```

**در مرورگر:** ردیف‌های ۱، ۳، ۵، ۷ زمینه دارند. ردیف‌های ۳ و ۶ متن قرمز دارند (۳ هم فرد است، پس هم زمینه دارد هم قرمز). ردیف ۲ پررنگ است. شمارش از **۱** است، نه از ۰.

«`odd` فرد است و `even` زوج. `3n` جایگاه‌های ۳ و ۶ و ۹ است. `nth-child(2)` فقط ردیف ۲ است؛ هر دو تا می‌شود `even`. روی تخته پیش‌بینی کن، بعد با ردیف ۶ نشان بده که `3n` فقط «سومین» نیست.»

«شمارش روی **همه فرزندان پدر** است، نه فقط روی `li`. اگر قبل از آیتم‌ها یک عنصر دیگر فرزند همان پدر باشد، شماره `li`ها یکی شیفت می‌خورد. آن وقت «سومین آیتم فهرست» با `nth-child(3)` یکی نیست.

`:nth-of-type(3)` فقط بین عنصرهای همان نوع می‌شمارد. اگر ساختار تمیز است و همه فرزندان `li` هستند، `nth-child` و `nth-of-type` یکی به نظر می‌رسند. تله را با همان `h4` بخش قبل نشان بده: `li:nth-child(1)` هیچ‌کس را نمی‌گیرد، `li:nth-of-type(1)` اولین `li` را می‌گیرد.»

### سؤال کلاسی

- «`:nth-child(2n)` کدام جایگاه‌هاست؟»  
  **پاسخ:** زوج‌ها: ۲، ۴، ۶، …

- «`:nth-child(3)` و `:nth-child(3n)` چه فرقی دارند؟»  
  **پاسخ:** اولی فقط جایگاه ۳. دومی ۳ و ۶ و ۹ و …

### اشتباهات رایج

- شروع شمارش از صفر. اولین عنصر `nth-child(1)` است.  
- zebra را با کلاس `even` در HTML ساختن، در حالی که `tr:nth-child(even)` با اضافه شدن یک ردیف خودش به‌روز می‌شود.

## ۷) `:not` — همه به‌جز یکی

«سه زبانه: توضیحات، نظرات، مشخصات. زبانه نظرات کلاس `active` دارد. بقیه کم‌رنگ باشند. نمی‌خواهیم به هر زبانه غیرفعال یک کلاس جدا بدهیم.»

```html
<div class="tabs">
  <a href="#one">توضیحات</a>
  <a href="#two" class="active">نظرات</a>
  <a href="#three">مشخصات</a>
</div>
```

```css
.tabs a {
  display: inline-block;
  margin-left: 0.5rem;
  color: #1a5fb4;
}

.tabs a:not(.active) {
  opacity: 0.5;
}
```

**در مرورگر:** «نظرات» پررنگ می‌ماند. دو تای دیگر نیمه‌شفاف‌اند. `:not(.active)` یعنی همین انتخابگر، به شرطی که کلاس active نداشته باشد. مثال ۵ جزوه.

«داخل `:not()` در همین سطح یک انتخابگر ساده می‌گذاریم، مثل یک کلاس. فاصله اضافه نگذار: `a:not(.active)` درست است.»

### سؤال کلاسی

- «اگر هیچ لینکی active نباشد، opacity روی چند تا اعمال می‌شود؟»  
  **پاسخ:** روی هر سه. `:not` حذف می‌کند، نه اینکه وجود active را الزامی کند.

## ۸) پیام مخفی — hover روی پدر، و فوکوس برای کیبورد

«کنار یک اصطلاح، توضیح کوتاهی هست که همیشه جا نمی‌گیرد. طرح: توضیح پنهان باشد و وقتی ماوس روی جعبه آمد ظاهر شود.

جزوه هشدار داده: روی گوشی ماوس نیست، و کاربر کیبورد هم hover ندارد. پس کنار `:hover` یک `:focus` هم بگذار. برای اینکه `div` بتواند فوکوس بگیرد، `tabindex="0"` لازم است.»

```html
<div class="hint" tabindex="0">
  ماوس را اینجا بیاور (یا با Tab به اینجا بیا)
  <p>سلام! من پیام مخفی هستم.</p>
</div>
```

```css
.hint {
  max-width: 24rem;
  padding: 0.75rem 1rem;
  background: #fff;
  border: 1px solid #cbd5e1;
}

.hint p {
  display: none;
  margin: 0.5rem 0 0;
}

.hint:hover p,
.hint:focus p {
  display: block;
}
```

**در مرورگر:** پیام اول نیست. ماوس را روی جعبه ببر تا بیاید. ماوس را ببر بیرون. بعد با Tab به جعبه برو؛ پیام باید دوباره بیاید، حتی بدون ماوس. اگر فقط `:hover` باشد، Tab هیچ متنی نشان نمی‌دهد. این را یک بار با حذف `:focus` ثابت کن و برگردان.

«اینجا ترکیب‌کننده دیروز هم هست: `.hint:hover p` یعنی پاراگراف **داخل** جعبه‌ای که hover شده. فاصله قبل از `p` عمدی است. فاصله قبل از `:hover` عمدی نیست و نباید باشد.»

### سؤال کلاسی

- «`.hint p:hover` با `.hint:hover p` چه فرقی دارد؟»  
  **پاسخ:** اولی فقط وقتی خود پاراگراف hover شده. اگر پاراگراف `display: none` باشد، نمی‌شود رویش ماوس برد. دومی وقتی خود جعبه hint hover شده، پاراگراف داخلش را نشان می‌دهد.

## ۹) `:checked` — چک‌باکس و برچسب همسایه

«فهرست کارها. وقتی جعبه را می‌زنی، متن کار خط بخورد و سبز شود. خود چک‌باکس متن ندارد. متن در `label` کنار آن است.

دیروز `+` یعنی همسایه بلافاصله بعد. امروز همان را به حالت checked وصل می‌کنیم.»

```html
<div class="todo">
  <input type="checkbox" id="t1">
  <label for="t1">خرید نان</label>
  <br>
  <input type="checkbox" id="t2">
  <label for="t2">تمرین CSS</label>
  <br>
  <input type="checkbox" id="t3">
  <label for="t3">ورزش</label>
</div>
```

```css
input:checked + label {
  color: green;
  text-decoration: line-through;
}
```

**در مرورگر:** هر مورد را جدا تیک بزن. فقط label همان مورد خط می‌خورد، چون `+` همسایه بعدی همان input است. `for` و `id` را دست نزن؛ بدون آن‌ها کلیک روی متن، جعبه را روشن نمی‌کند و دانشجو فکر می‌کند `:checked` خراب است.

اگر بین `input` و `label` یک عنصر دیگر بگذاری، `+` قطع می‌شود. یک بار امتحان کن.

### سؤال کلاسی

- «`:checked` را روی `label` می‌نویسیم؟»  
  **پاسخ:** نه. حالت checked مال `input` است. ظاهر متن را با ترکیب‌کننده به label می‌رسانیم.

### اشتباهات رایج

- `label:checked`. برچسب این حالت را ندارد.  
- فراموش کردن `id` / `for` و انتظار اینکه کلیک روی متن کافی باشد.

## ۱۰) پروژه جلسه — جدول راه‌راه با ردیف زیر ماوس

تمرین جزوه: جدولی که ردیف‌های زوجش رنگی باشد (`:nth-child(even)`) و ردیف زیر ماوس پررنگ شود (`:hover`).

سرستون را در `thead` بگذار تا وارد شمارش `tbody` نشود.

```html
<table class="scores">
  <thead>
    <tr><th>نام</th><th>درس</th></tr>
  </thead>
  <tbody>
    <tr><td>آیدا</td><td>CSS</td></tr>
    <tr><td>کیان</td><td>HTML</td></tr>
    <tr><td>سارا</td><td>CSS</td></tr>
    <tr><td>مانی</td><td>HTML</td></tr>
  </tbody>
</table>
```

```css
.scores {
  border-collapse: collapse;
  width: 100%;
  max-width: 28rem;
  background: #fff;
}

.scores th,
.scores td {
  border: 1px solid #cbd5e1;
  padding: 0.5rem 0.75rem;
  text-align: start;
}

.scores tbody tr:nth-child(even) {
  background: #f1f3f5;
}

.scores tbody tr:hover {
  background: #dbeafe;
  font-weight: 700;
}
```

**در مرورگر:** ردیف‌های ۲ و ۴ خاکستری‌اند. ماوس روی هر ردیف، آبیِ hover را می‌نشاند، چون این قانون دیرتر آمده و همان `background` را می‌نویسد.

### سؤال حین پروژه

- «اگر `:hover` را قبل از `:nth-child(even)` بنویسیم، ردیف زوج زیر ماوس چه رنگی می‌ماند؟»  
  **پاسخ:** خاکستری even، چون دیرتر آمده و specificity این دو در این فایل با هم قابل مقایسه‌اند (هر دو یک عنصر و یک شبه‌کلاس، به‌علاوه زنجیره `.scores tbody`). ترتیب را همان‌طور که در پروژه است نگه دار: اول راه‌راه، بعد hover.

## ۱۱) جمع‌بندی مدرس و سؤالات پایانی

۱. `a :hover` و `a:hover` هر کدام چه چیزی را انتخاب می‌کنند؟  
   **پاسخ راهنما:** با فاصله، عنصر hoverشده داخل لینک. بدون فاصله، خود لینک در حالت hover.

۲. چرا چهار حالت لینک را به ترتیب link، visited، hover، active می‌نویسیم؟  
   **پاسخ راهنما:** تا قانون دیرتر، رنگ hover و active را از لینک دیده‌شده نگیرد. یادیار: LoVe HAte.

۳. چرا `li:first-child` گاهی هیچ آیتمی را سبز نمی‌کند، و به‌جایش چه می‌نویسیم؟  
   **پاسخ راهنما:** چون قبل از آن `li` فرزند دیگری هست و خود `li` اولین فرزند پدر نیست. `li:first-of-type`.

۴. outline دکمه را حذف کرده‌ایم. چه قانونی باید کنارش باشد؟  
   **پاسخ راهنما:** `:focus-visible` با یک حلقه واقعاً دیده‌شونده. حذف تنها کافی نیست.

**پیام پایانی:**

«شبه‌کلاس حالت است، نه برچسب تازه در HTML: ماوس، لحظه کلیک، فوکوس، شماره بین خواهر و برادرها، تیک خوردن. فاصله قبل از دونقطه را مثل فاصله اشتباه دیروز جدی بگیر. هر جا حلقه فوکوس را برمی‌داری، همان‌جا جایگزین کیبورد را بنویس.»

## تمرین‌ها (ساده → چالشی)

### ساده

۱. دکمه جزوه را با `:hover` سبز و `:active` با `scale(0.95)` بساز.  
۲. دو `input` با `:focus` : حاشیه، زمینه، و outline. با Tab بینشان جابه‌جا شو.

### متوسط

۳. چهار خط LVHA را بنویس. یک بار ترتیب hover و visited را عوض کن و اگر لینک بازدیدشده داری، تفاوت را ببین. بعد ترتیب را درست کن و `:focus-visible` نارنجی اضافه کن.  
۴. فهرست چهارتایی با `:first-child` و `:last-child`. سپس یک عنوان را به‌عنوان اولین فرزند همان پدر بگذار و سبز شدن را با `:first-of-type` برگردان.  
۵. جدول پروژه: `nth-child(even)` و `tr:hover`.

### چالشی

۶. هفت `li` با `nth-child(odd)`، `nth-child(3n)` و `nth-child(2)`. روی کاغذ پیش‌بینی کن، بعد در مرورگر تطبیق بده.  
۷. سه زبانه با `:not(.active)` و یک فهرست کار با `input:checked + label`. بین input و label یک عنصر اضافه کن و بگو چرا خط‌خوردن قطع شد.  
۸. جعبه `.hint` با پیام مخفی. نشان بده فقط `:hover` با Tab کار نمی‌کند، بعد `:focus` و `tabindex="0"` را اضافه کن.
