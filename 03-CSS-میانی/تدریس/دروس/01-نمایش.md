## ۱) شروع کلاس — دیالوگ کامل

«بچه‌ها، فرض کنید صفحه **ثبت‌نام** دارید:

```html
<button>ارسال</button>
<button>انصراف</button>
```

بدون CSS، هر دکمه **کنار هم** می‌نشینند — inline/replaced.

حالا یک کلاس utility اضافه می‌کنید:

```css
button { display: block; width: 100%; }
```

ناگهان هر دکمه **یک خط کامل** — انگار bug!

یا برعکس: می‌خواهید سه **برچسب** فیلتر کنار هم باشند:

```html
<span class="tag">رایگان</span>
<span class="tag">جدید</span>
```

روی `.tag` می‌گذارید `width: 120px` — **هیچ اتفاقی نمی‌افتد**.

سؤال: آیا مرورگر «width را ignore می‌کند» یا **نوع جعبه** اجازه نمی‌دهد؟

امروز `display` را با Live code و [`01-display.html`](../../pages/01-display.html) جواب می‌دهیم — **بدون** invent کردن مقادیر عجیب.»

---

## ۲) مفهوم — display چیست؟

«`display` به مرورگر می‌گوید برای این عنصر **چه مدل جعبه** بسازد و در **flow** normal کنار بقیه چطور بنشیند.

HTML پیش‌فرض دارد: `div` → block، `span` → inline.

CSS می‌تواند override کند — **معنی semantic** تگ عوض نمی‌شود؛ `a` با `display: block` هنوز لینک است.»

---

## ۳) Live مرحله ۱ — block vs inline (demo 1)

HTML داخل `.demo-display`:

```html
<div class="box-block">من div هستم (block)</div>
<div class="box-block">من هم div هستم؛ زیر قبلی</div>
<span class="box-inline">من span</span>
<span class="box-inline">کنار قبلی</span>
```

CSS — در حین تایپ توضیح بده:

```css
.demo-display .box-block {
  background-color: #ffe8cc;
  border: 1px solid #f08c00;
  padding: 6px 10px;
  margin: 4px 0;
}

.demo-display .box-inline {
  background-color: #d3f9d8;
  border: 1px solid #2b8a3e;
  padding: 2px 8px;
}
```

**در مرورگر:** divها زیر هم؛ spanها در یک خط.

### جدول جزوه (خلاصه)

| | block | inline |
|---|--------|--------|
| شروع خط | خط جدید | همان خط |
| عرض | در دسترس والد | محتوا |
| width/height | اثر دارد | روی pure inline اثر ندارد |
| margin عمودی | اثر دارد | روی flow خط اثر vertical معمولاً ندارد |

### سؤال کلاسی

«`p` بدون CSS چه displayای دارد؟»  
**پاسخ:** block.

«`img` چطور؟»  
**پاسخ راهنما:** inline از نظر flow ولی **replaced** — می‌توان width/height داد (جزوه tip).

## ۴) Live مرحله ۲ — منوی افقی (inline روی li)

«`li` پیش‌فرض list-item است — زیر هم. برای منوی ساده افقی:»

```css
.demo-display .menu-inline {
  margin: 0;
  padding: 0;
}

.demo-display .menu-inline li {
  display: inline;
  margin-left: 16px;
}
```

```html
<ul class="menu-inline">
  <li><a href="#">خانه</a></li>
  <li><a href="#">محصولات</a></li>
  <li><a href="#">درباره ما</a></li>
</ul>
```

**در مرورگر:** آیتم‌ها در یک ردیف — در RTL `margin-left` فاصله با item بعدی (طبق جزوه).

«flex بعداً روش حرفه‌ای‌تر است؛ **این** برای فهم inline کافی است.»

## ۵) Live مرحله ۳ — span را block کن

```css
.demo-display .span-block span {
  display: block;
  background-color: #e7f5ff;
  border-right: 4px solid #1a5fb4;
  padding: 4px 10px;
  margin-bottom: 4px;
}
```

```html
<p class="span-block">
  <span>نام: سارا</span>
  <span>شهر: شیراز</span>
</p>
```

**در مرورگر:** هر span یک «ردیف» — مثل label/value ساده.

### سؤال کلاسی

«الان `width: 50%` روی span?»  
**پاسخ:** اثر دارد — چون block شده.

## ۶) Live مرحله ۴ — none vs visibility

«می‌خواهیم جعبه ۲ را پنهان کنیم — دو راه:»

```css
.demo-display .hide-none { display: none; }
.demo-display .hide-hidden { visibility: hidden; }
```

```html
<div class="row-boxes">
  <div class="mini">۱</div>
  <div class="mini hide-none">۲</div>
  <div class="mini">۳</div>
</div>
```

(parent `.row-boxes` در CSS جزوه `display: flex` دارد — فقط برای چیدمان demo mini boxes)

**در مرورگر با none:** ۳ کنار ۱ — جای ۲ **نیست**.

**با hidden:** gap خالی جای ۲ — ۳ جابجا نشده.

### سؤال کلاسی

«برای modal بسته کدام بهتر؟»  
**پاسخ راهنما:** `display: none` — از layout و معمولاً از tab flow؛ focus management جداگانه.

«`opacity: 0`?»  
**پاسخ:** جای عنصر می‌ماند؛ هنوز clickable — جزوه mistake.

## ۸) اشتباهات — غلط / درست

| غلط | درست |
|-----|------|
| `width` روی `span` inline | `display: block` یا `inline-block` اول |
| `visibility: hidden` برای «حذف» از صفحه | `display: none` |
| block کردن همهٔ چیز برای layout | flex/grid یا semantic structure |
| فکر کردن display نوع HTML را عوض می‌کند | فقط rendering box |
