## ۱) شروع کلاس؛ نیاز واقعی روی سایت

اول کلاس این‌طور شروع کن:

«بچه‌ها، این جلسه **اختیاری** است. اگر عجله دارید مسیر اصلی را ادامه بدهید؛ ولی اگر تا حالا یک فهرست مراحل، یک پرسش متداول، یا فهرست مطالب نوشته‌اید، این ابزار را لازم دارید.

فرض کنید صفحه «سؤالات متداول» یک آموزشگاه را می‌نویسید. نویسنده محتوا ده سؤال گذاشته و شما جلوی هر کدام در HTML نوشته‌اید: سؤال ۱، سؤال ۲، سؤال ۳.

فردا سؤال جدیدی بین سؤال ۲ و ۳ اضافه می‌شود. چه اتفاقی برای بقیه شماره‌ها می‌افتد؟»

بگذار دانشجو جواب بدهد. جمع‌بندی:

«باید از سؤال ۳ به بعد را یکی‌یکی دست بزنید. اگر یک سؤال حذف شود، دوباره همین کار. این کارِ محتواست، نه کارِ مرورگر. ما می‌خواهیم **ترتیب** در HTML بماند و **عدد** را CSS خودش بسازد.»

HTML اولیه را بدون هیچ عددی بنویس:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — شمارنده‌ها</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      padding: 1.5rem;
      background: #f8fafc;
      line-height: 1.7;
    }
  </style>
</head>
<body>
  <h1>سؤالات متداول ثبت‌نام</h1>
  <section class="faq">
    <h2>مهلت ثبت‌نام تا کی است؟</h2>
    <p>تا پایان هفته آینده.</p>
    <h2>آیا کلاس ضبط می‌شود؟</h2>
    <p>بله، لینک ضبط در همان روز می‌آید.</p>
    <h2>پیش‌نیاز چیست؟</h2>
    <p>HTML مقدماتی.</p>
  </section>
</body>
</html>
```

«ببینید: در HTML هیچ «۱» و «۲» و «۳»ای نیست. اگر فردا یک `h2` دیگر بین این‌ها بیاید، نویسنده فقط متن سؤال را اضافه می‌کند. عدد را مرورگر می‌سازد. هنوز CSS شمارنده را ننوشته‌ایم؛ پس فقط سه تیتر ساده می‌بینید. این نقطه شروع است.»

**در مرورگر:** سه تیتر بدون شماره. عمداً این حالت را چند ثانیه نگه دار تا نیاز دیده شود.

### سؤال کلاسی

- «اگر شماره را داخل خود متن `h2` بنویسیم و بعد سؤال وسط را حذف کنیم، چه چیزی خراب می‌شود؟»  
  **پاسخ:** ترتیب اعداد. سؤال بعدی هنوز شماره قدیمی را نشان می‌دهد تا کسی دستی اصلاحش کند.

## ۲) شمارنده چیست و سه مرحله‌اش

بگو:

«شمارنده CSS یک متغیر عددی است که مرورگر خودش کم و زیاد می‌کند. ما فقط سه چیز را تعیین می‌کنیم: **نام** شمارنده، **کجا صفر شود**، و **کجا روی صفحه دیده شود**.

سه مرحله ثابت است:

۱. `counter-reset` روی **پدر** — شمارنده را می‌سازد. اگر عددی ننویسیم از صفر شروع می‌شود.  
۲. `counter-increment` روی **هر آیتم** — هر بار که مرورگر به آن عنصر می‌رسد یکی اضافه می‌کند. پس اولین آیتم عدد ۱ را نشان می‌دهد، نه صفر.  
۳. `content: counter(نام)` داخل `::before` یا `::after` — مقدار فعلی را به متن تبدیل می‌کند.

اگر reset و increment هر دو روی **یک** عنصر باشند، مرورگر اول reset را انجام می‌دهد و بعد increment را. برای همین reset را روی پدر می‌گذاریم تا هر فرزند فقط یکی اضافه کند، نه اینکه هر فرزند شمارنده را از نو بسازد.»

جدول را روی برد بنویس:

| دستور | کجا | کار |
|------|------|-----|
| `counter-reset: faq;` | پدر (`.faq`) | ساختن شمارنده؛ شروع از ۰ |
| `counter-increment: faq;` | هر آیتم (`h2`) | هر بار +۱ |
| `content: counter(faq);` | `h2::before` | نشان دادن عدد |

«نام را خودمان انتخاب می‌کنیم. `faq` و `section` و `step` فقط اسم‌اند. در هر سه جا باید **دقیقاً** یکی باشد. `step` با `steps` فرق دارد و مرورگر خطایی نشان نمی‌دهد؛ فقط عدد ظاهر نمی‌شود یا شمارنده دیگری را زیاد می‌کند.»

### اشتباهات رایج

- `counter-reset` روی خود آیتم‌ها → هر آیتم شمارنده را صفر می‌کند و بعد یکی اضافه می‌کند؛ همه شماره ۱ می‌گیرند.  
- فراموش کردن `content` → `::before` ساخته نمی‌شود و عدد دیده نمی‌شود.  
- نوشتن شماره هم در HTML و هم در CSS → دو شماره کنار هم.

## ۳) Live Coding — شماره خودکار تیترها

حالا همان صفحه را کامل کن. مطابق مثال ۱ جزوه، فقط ظرف را `.faq` گرفته‌ایم تا چند مثال در یک فایل تداخل نکنند:

```css
.faq {
  counter-reset: section;
}

.faq h2::before {
  counter-increment: section;
  content: "سؤال " counter(section) ": ";
  color: #0f766e;
  font-weight: 700;
}
```

«به مرورگر گفتیم: روی `.faq` شمارنده‌ای به نام `section` بساز و از صفر شروع کن. هر `h2` داخل این بخش یکی به آن اضافه کند و قبل از متن تیتر بنویس «سؤال » به‌علاوه عدد به‌علاوه «: ».

`content` می‌تواند چند تکه باشد: متن ثابت داخل نقل‌قول، بعد تابع `counter()`، بعد دوباره متن ثابت. فاصله‌های داخل نقل‌قول واقعاً روی صفحه می‌آیند؛ اگر بعد از «سؤال» فاصله نگذاریم می‌شود «سؤال۱».»

**در مرورگر:** «سؤال ۱: مهلت ثبت‌نام…»، «سؤال ۲: …»، «سؤال ۳: …».

بلافاصله یک `h2` جدید را **بین** سؤال ۱ و ۲ در HTML بچسبان: «آیا شهریه اقساطی است؟»

«شماره‌ها خودشان جابه‌جا شدند. HTML را دست نزدیم جز اینکه یک تیتر اضافه کردیم. این همان دلیلی است که روی سایت، شماره را از CSS می‌گیریم.»

### سؤال کلاسی

- «اگر `counter-increment` را فراموش کنیم چه می‌بینیم؟»  
  **پاسخ:** یا عدد دیده نمی‌شود، یا اگر increment جای دیگری باشد همان عدد ثابت روی همه تکرار می‌شود. در این مثال چون increment روی همان `::before` است، بدون آن `counter(section)` صفر می‌ماند و هر سه تیتر «سؤال ۰» می‌شوند.

- «چرا اولین سؤال ۱ است نه ۰؟»  
  **پاسخ:** reset از ۰ شروع می‌کند و increment قبل از نمایش، یکی اضافه می‌کند.

### نکته مدرس

`counter-increment` را می‌توان روی خود `h2` گذاشت و `content` را جدا در `::before`. هر دو درست است. در جزوه، برای تیترها هر دو روی `::before` آمده تا کد کوتاه بماند. برای دایره‌های مرحله، increment را روی `li` می‌گذاریم چون خود دایره فقط نمایش است.

شروع از عدد دلخواه:

```css
.faq {
  counter-reset: section 4; /* آیتم اول می‌شود ۵ */
}
```

«`counter-reset: section 4` یعنی مقدار اولیه ۴ است. اولین increment آن را ۵ می‌کند. در فهرست‌هایی که ادامه صفحه قبل‌اند به کار می‌آید. پیش‌فرض بدون عدد، همان صفر است.»

## ۴) مراحل یک دستور پخت — دایره شماره‌دار

نیاز را عوض کن:

«حالا یک صفحه آشپزی. ترتیب مراحل مهم است، پس در HTML از `ol` استفاده می‌کنیم، نه `div`های پشت‌سرهم. معنی «این‌ها مرحله‌اند و ترتیب دارند» کار HTML است. ظاهر دایره رنگی کار CSS است.»

```html
<ol class="steps">
  <li>آب را جوش بیاورید</li>
  <li>ماکارونی را اضافه کنید</li>
  <li>۱۰ دقیقه صبر کنید</li>
  <li>آبکش کنید و سس بریزید</li>
</ol>
```

اول بدون CSS نشان بده: شماره پیش‌فرض مرورگر (۱. ۲. ۳.) دیده می‌شود.

«اگر هم `list-style` را روشن بگذاریم و هم `::before` بسازیم، **دو** شماره کنار هم می‌آید. پس شماره پیش‌فرض را خاموش می‌کنیم و مال خودمان را می‌سازیم.»

```css
.steps {
  counter-reset: step;
  list-style-type: none;
  padding: 0;
}

.steps li {
  counter-increment: step;
  margin: 0.6rem 0;
}

.steps li::before {
  content: counter(step);
  display: inline-block;
  width: 28px;
  height: 28px;
  line-height: 28px;
  border-radius: 50%;
  background: #e8590c;
  color: white;
  text-align: center;
  margin-left: 10px;
  font-size: 0.9rem;
}
```

«`width` و `height` روی `::before` فقط وقتی اثر مورد انتظار را دارند که `display` آن `inline-block` (یا block / flex) باشد. `::before` به‌طور پیش‌فرض inline است.

`line-height` برابر ارتفاع دایره، عدد را عمودی وسط می‌آورد، به شرطی که خود عدد یک خط باشد. `text-align: center` آن را افقی وسط می‌کند.

`margin-left: 10px` در صفحه راست‌چین فاصله بین دایره و متن است، چون دایره قبل از متن است و سمت چپ دایره به متن می‌چسبد.»

**در مرورگر:** چهار مرحله با دایره نارنجی. یک `li` را از وسط حذف کن و نشان بده شماره‌ها دوباره ۱ تا ۳ می‌شوند.

### سؤال کلاسی

- «چرا اینجا `ol` گذاشتیم نه `ul`؟»  
  **پاسخ:** ترتیب مراحل معنی دارد. حتی اگر شماره پیش‌فرض را با CSS خاموش کنیم، HTML هنوز می‌گوید این فهرست مرتب است. برای صفحه‌خوان و برای روزی که CSS لود نشود، `ol` درست‌تر است.

### اشتباهات رایج

- `padding: 0` را فراموش کردن → شماره قدیمی حذف شده ولی تورفتگی پیش‌فرض `ol` مانده و دایره‌ها جلوتر از متن صفحه نیستند؛ بسته به طرح یا باید padding را صفر کنی یا تورفتگی را خودت تنظیم کنی.  
- `margin-right` به‌جای `margin-left` در `dir="rtl"` → فاصله آن طرف دایره می‌افتد و دایره به متن می‌چسبد.

## ۵) شماره تودرتو — دو شمارنده، مثل ۱.۱ و ۱.۲

«یک کتاب یا دوره آموزشی فقط «بخش ۱، بخش ۲» نیست. داخل بخش ۱ زیربخش داریم: ۱.۱ تگ‌ها، ۱.۲ ویژگی‌ها. اگر یک شمارنده برای همه‌چیز داشته باشیم، زیربخش‌ها شماره فصل را ادامه می‌دهند و «۱.۱» ساخته نمی‌شود.

دو نام لازم است. `main` روی کل کتاب صفر می‌شود و هر فصل یکی به آن اضافه می‌کند. `sub` روی **خود فصل** صفر می‌شود تا هر فصل از ۱.۱ شروع کند، نه اینکه شماره زیربخش در فصل بعد ادامه پیدا کند.»

```html
<div class="book">
  <div class="chapter">
    <h2>HTML</h2>
    <p>تگ‌ها</p>
    <p>ویژگی‌ها</p>
  </div>
  <div class="chapter">
    <h2>CSS</h2>
    <p>انتخابگرها</p>
    <p>رنگ‌ها</p>
    <p>مدل جعبه‌ای</p>
  </div>
</div>
```

```css
.book {
  counter-reset: main;
}

.chapter {
  counter-reset: sub;
  margin-bottom: 1rem;
}

.chapter h2::before {
  counter-increment: main;
  content: counter(main) ". ";
  color: #1a3a5c;
}

.chapter p::before {
  counter-increment: sub;
  content: counter(main) "." counter(sub) " ";
  color: #0f766e;
  font-weight: 700;
}
```

«در `content` چند مقدار را کنار هم می‌نویسیم: شماره فصل، یک نقطه به‌صورت متن، شماره زیربخش، یک فاصله.

روی فصل دوم، `counter-reset: sub` دوباره اجرا می‌شود. پس بعد از «۱.۲ ویژگی‌ها» می‌رسیم به «۲. انتخابگرها» و بعد «۲.۱». اگر reset زیربخش را فقط روی `.book` می‌گذاشتیم، اولین پاراگراف فصل CSS می‌شد ۲.۳.»

**در مرورگر:** HTML → ۱. تگ‌ها، ۱.۲ ویژگی‌ها؛ CSS → ۲. انتخابگرها، ۲.۱، ۲.۲، ۲.۳. یک پاراگراف به فصل اول اضافه کن و بگو فصل دوم همچنان از ۱ شروع می‌شود.

### سؤال کلاسی

- «اگر `counter-reset: sub` را از `.chapter` برداریم، اولین زیربخش CSS چه شماره‌ای می‌گیرد؟»  
  **پاسخ:** ادامه شمارنده قبلی؛ با دو پاراگراف در فصل HTML، اولین پاراگراف CSS می‌شود ۲.۳.

### نکته مدرس

در این مثال increment فصل روی `h2` است و increment زیربخش روی `p`. اگر داخل فصل یک `p` مقدمه بدون شماره بخواهیم، نباید همه `p`ها را زیاد کنیم؛ یک کلاس مثل `.chapter .item` بگذار. این را موقع پروژه اگر دانشجو گیر کرد بگو، از اول با پاراگراف ساده شروع کن تا الگو دیده شود.

## ۶) وقتی عمق نامعلوم است — `counters()`

«الگوی قبلی برای **دو** سطح مشخص خوب است. فهرست مطالب یک کتاب ممکن است سه یا چهار سطح `ol` تو در تو داشته باشد و ما از قبل تعداد سطح‌ها را ندانیم.

تابع `counters()` — با **s** — همه سطح‌های همان نام را کنار هم می‌گذارد.»

```html
<ol class="toc">
  <li>مقدمه</li>
  <li>نصب
    <ol>
      <li>ویندوز</li>
      <li>مک</li>
    </ol>
  </li>
  <li>اولین صفحه</li>
</ol>
```

```css
.toc,
.toc ol {
  counter-reset: item;
  list-style-type: none;
}

.toc li {
  counter-increment: item;
}

.toc li::before {
  content: counters(item, ".") " ";
  font-weight: 700;
  color: #1a3a5c;
}
```

«هر `ol` شمارنده `item` را برای فرزندان خودش از نو صفر می‌کند. `counters(item, ".")` از بیرونی‌ترین سطح تا همین `li` را با نقطه به هم می‌چسباند: `1` ، `2` ، `2.1` ، `2.2` ، `3`.

آرگومان دوم، جداکننده است. اگر `" - "` بگذاریم خروجی شبیه `2 - 1` می‌شود.»

**در مرورگر:** درخت فهرست. سطح سوم را هم یک‌بار اضافه کن تا `2.1.1` دیده شود، بعد حذفش کن تا وقت کلاس نرود.

فرق را یک جمله بگو:

«`counter(item)` فقط عدد **همین** سطح را می‌دهد. `counters(item, ".")` زنجیره پدرها را هم می‌آورد. برای ۱.۲.۳ دومی را می‌خواهیم.»

## ۷) رقم فارسی

«تا اینجا رقم‌ها لاتین بودند: 1، 2، 3. برای صفحه فارسی آرگومان دوم `counter()` یا سوم `counters()` سبک عدد است.»

```css
.fa-num {
  counter-reset: item;
  list-style-type: none;
  padding: 0;
}

.fa-num li {
  counter-increment: item;
}

.fa-num li::before {
  content: counter(item, persian) "- ";
}
```

```html
<ul class="fa-num">
  <li>سیب</li>
  <li>پرتقال</li>
  <li>انار</li>
</ul>
```

«خروجی: ۱- سیب، ۲- پرتقال، ۳- انار. سبک‌های دیگری مثل `arabic-indic` هم وجود دارد؛ در این کلاس همان `persian` کافی است.

برای فهرست تودرتو:

```css
content: counters(item, ".", persian) " ";
```

هر سطح با رقم فارسی و نقطه جدا می‌شود.»

**در مرورگر:** سه میوه با رقم فارسی. بعد همان `toc` را اگر وقت بود به `persian` عوض کن.

### اشتباهات رایج

- انتظار اینکه `lang="fa"` به‌تنهایی رقم شمارنده را فارسی کند. زبان صفحه، رقم `counter()` را عوض نمی‌کند؛ سبک را باید صریح بدهی.  
- نوشتن `counter(item persian)` بدون ویرگول → مقدار نامعتبر و `content` خالی.

## ۸) تله‌ها: عنصر پنهان، نام اشتباه، reset روی آیتم

این سه را زنده خراب کن و درست کن. هر کدام کمتر از یک دقیقه.

**۱) reset روی خود `li`:**

```css
.steps li {
  counter-reset: step;
  counter-increment: step;
}
```

«همه دایره‌ها ۱ می‌شوند. reset را برگردان روی `ol`.»

**۲) نام ناهم‌خوان:**

```css
.steps { counter-reset: step; }
.steps li { counter-increment: steps; } /* s اضافه */
```

«هیچ خطایی در کنسول نمی‌آید. شمارنده‌ای به نام `steps` زیاد می‌شود و `counter(step)` همچنان صفر است.»

**۳) `display: none`:**

یک `li` را با `display: none` پنهان کن.

«عنصری که `display: none` است در درخت نمایش نیست و increment روی آن اجرا نمی‌شود. شماره‌ها می‌پرند از روی آن آیتم، انگار وجود ندارد. اگر فقط بصری پنهانش کنی (`visibility` یا انتقال به بیرون) ممکن است همچنان شمرده شود. برای فهرست، آیتم حذف‌شده را از HTML درنیاور اگر نباید در شماره بیاید؛ یا واقعاً `display: none` بده و بدان که شماره نمی‌گیرد.»

`content: none` روی `::before` هم عدد را پاک می‌کند ولی increment اگر روی `li` باشد همچنان اتفاق می‌افتد. این ریزه‌کاری را فقط اگر کسی پرسید بگو.

## ۹) پروژه ترکیبی جلسه — پرسش‌های متداول

دیگر مثال تازه نزن. همان FAQ اول را به شکل قابل تحویل جمع کن.

```html
<section class="faq" aria-labelledby="faq-title">
  <h1 id="faq-title">سؤالات متداول</h1>
  <h2>مهلت ثبت‌نام تا کی است؟</h2>
  <p>تا پایان هفته آینده.</p>
  <h2>آیا کلاس ضبط می‌شود؟</h2>
  <p>بله.</p>
  <h2>پیش‌نیاز چیست؟</h2>
  <p>HTML مقدماتی.</p>
</section>
```

```css
.faq {
  counter-reset: q;
  max-width: 40rem;
}

.faq h2 {
  font-size: 1.15rem;
  margin: 1.2rem 0 0.3rem;
}

.faq h2::before {
  counter-increment: q;
  content: "سؤال " counter(q, persian) ": ";
  color: #0f766e;
}

.faq p {
  margin: 0;
  color: #334155;
}
```

«شماره در HTML نیست، رقم فارسی است، و با اضافه شدن سؤال وسط، بقیه به‌روز می‌شوند. `aria-labelledby` را اگر هنوز نگفته‌ای فقط به‌عنوان «عنوان این بخش را به خود بخش وصل کردیم» یک جمله بگو؛ وارد ARIA کامل نشو.»

**نمایش:** یک سؤال را Cut کن و Paste بین دو تای دیگر. شماره‌ها را با صدای بلند بخوان.

## ۱۰) جمع‌بندی مدرس و سؤالات پایانی

قبل از تمرین این چهار سؤال را بپرس:

1. سه مرحله ساخت شماره خودکار چیست و هر کدام روی چه عنصری می‌نشیند؟  
   **پاسخ راهنما:** `counter-reset` روی پدر، `counter-increment` روی هر آیتم، `counter()` داخل `content` در `::before` یا `::after`.

2. چرا اولین آیتم معمولاً ۱ است نه ۰؟  
   **پاسخ:** reset از ۰ شروع می‌کند و increment قبل از خواندن مقدار، یکی اضافه می‌کند.

3. اگر reset را روی خود آیتم بگذاریم چه می‌شود؟  
   **پاسخ:** همه آیتم‌ها شماره ۱ می‌گیرند.

4. فرق `counter(item)` و `counters(item, ".")` چیست؟  
   **پاسخ:** اولی فقط عدد همین سطح؛ دومی زنجیره سطح‌ها را با جداکننده کنار هم می‌گذارد، مثل `2.1`.

**پیام پایانی:**

«هدف این جلسه حفظ کردن سه ویژگی نبود. هدف این بود که روی یک سایت، شماره فهرست را داخل متن HTML ننویسی؛ ترتیب را با `ol` یا تیترها نگه داری و عدد را با شمارنده CSS بسازی. این درس اختیاری است، ولی هر جا فهرست طولانی و در حال تغییر داری، همین الگو را برگردان.»
