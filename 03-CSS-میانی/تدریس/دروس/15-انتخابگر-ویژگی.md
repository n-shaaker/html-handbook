## 2) attributes

«`[type="email"]`, `[href^="https"]`, `[class*="btn"]`, `[data-state="open"]`. specificity مثل class.»

```css
input[type="email"] { direction: ltr; text-align: left; }
a[href^="mailto:"]::after { content: " ✉"; font-size: 0.85em; }
[data-theme="dark"] { color-scheme: dark; }
```
