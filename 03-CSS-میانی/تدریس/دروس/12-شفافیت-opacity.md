## ۱) شروع کلاس؛ نیاز واقعی سایت

اول کلاس این صحنه را بساز. هنوز کلمه `opacity` را به‌عنوان راه‌حل نگفته باش.

«بچه‌ها، صفحه اول فروشگاه کتاب یک عکس بزرگ دارد. روی عکس باید این جمله خوانده شود: *ارسال رایگان برای خرید بالای ۵۰۰ هزار تومان.*

طراح گفته پس‌زمینه جمله تیره و کمی شفاف باشد تا عکس از پشت پیدا باشد، ولی خود نوشته سفید و واضح بماند.

همکار شما این کار را کرده: یک `div` گذاشته، `background` آبی داده، و `opacity: 0.4` نوشته. جمله هم داخل همان `div` است.

به نظر شما کاربر جمله را راحت می‌خواند؟»

فایل پیشنهادی: `تدریس/live/12-opacity.html`

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — شفافیت</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      background: #e9ecef;
      padding: 1.5rem;
    }
    .hero {
      max-width: 640px;
      min-height: 220px;
      padding: 1.5rem;
      background: #1a5fb4 url("../images/bg.jpg") center/cover;
      color: white;
    }
  </style>
</head>
<body>
  <section class="hero">
    <h1>کتاب‌سرا</h1>
    <p>ارسال رایگان برای خرید بالای ۵۰۰ هزار تومان</p>
  </section>
</body>
</html>
```

اگر تصویر جزوه در مسیر live در دسترس نیست، یک پس‌زمینه شطرنجی یا راه راه با CSS بساز تا شفافیت دیده شود:

```css
.stage {
  background:
    linear-gradient(45deg, #ced4da 25%, transparent 25%),
    linear-gradient(-45deg, #ced4da 25%, transparent 25%),
    linear-gradient(45deg, transparent 75%, #ced4da 75%),
    linear-gradient(-45deg, transparent 75%, #ced4da 75%);
  background-size: 24px 24px;
  background-position: 0 0, 0 12px, 12px -12px, -12px 0;
  padding: 1.5rem;
}
```

«عکس یا طرح پشت هست، متن سفید هم هست، ولی هنوز لایه‌ای که طراح خواسته را نساخته‌ایم. اول خود ویژگی شفافیت را ببینیم، بعد برمی‌گردیم به همین هیرو و اشتباه همکار را زنده می‌سازیم.»

**در مرورگر:** عنوان و جمله واضح‌اند. این حالتِ سالم است. دانشجو باید بعداً بتواند بگوید کدام کد این وضوح را خراب می‌کند.

## ۲) `opacity` یعنی میزان مات بودن کل عنصر

«`opacity` می‌گوید این عنصر چقدر مات است.

- `1` یعنی کاملاً مات. این مقدار پیش‌فرض است.  
- `0` یعنی کاملاً نامرئی.  
- بین این دو، مثلاً `0.5`، عنصر نیمه‌شفاف است.

می‌شود همان مقدار را با درصد نوشت: `50%` همان `0.5` است. عدد ۵۰ بدون درصد، پنجاه برابرِ ماتِ کامل است و مرورگر آن را نامعتبر می‌داند. قانون نادیده گرفته می‌شود و عنصر همان مات معمولی می‌ماند.»

چهار نسخه از یک تصویر یا یک مربع رنگی را کنار هم بگذار:

```css
.swatch {
  width: 120px;
  height: 80px;
  background: #1a5fb4;
  color: white;
  display: inline-block;
  margin: 0.25rem;
  text-align: center;
  line-height: 80px;
}

.o1 { opacity: 0.2; }
.o2 { opacity: 0.5; }
.o3 { opacity: 0.8; }
.o4 { opacity: 1; }
```

```html
<div class="stage">
  <div class="swatch o1">۰٫۲</div>
  <div class="swatch o2">۰٫۵</div>
  <div class="swatch o3">۰٫۸</div>
  <div class="swatch o4">۱</div>
</div>
```

«از چپ، طرح شطرنجی بیشتر از پشت مربع پیدا است. مربع آخر هیچ شفافیتی ندارد. به نوشته داخل مربع هم نگاه کنید: هر چه `opacity` کمتر می‌شود، نوشته سفید هم کم‌رنگ‌تر می‌شود. این تصادفی نیست.»

عمداً این قانون غلط را هم یک لحظه بنویس:

```css
.broken { opacity: 50; }
```

**در مرورگر:** DevTools کنار `opacity: 50` خط هشدار می‌زند و مقدار را اعمال نمی‌کند. بعد درستش کن: `opacity: 0.5` یا `opacity: 50%`.

### سؤال کلاسی

- «`opacity: 0.2` به شفافیت نزدیک‌تر است یا `opacity: 0.8`؟»  
  **پاسخ:** `0.2` شفاف‌تر است. هر چه عدد کوچک‌تر، عنصر نامرئی‌تر.

- «چرا `opacity: 50` کار نمی‌کند؟»  
  **پاسخ:** مقیاس این ویژگی از ۰ تا ۱ است، یا ۰٪ تا ۱۰۰٪. ۵۰ خارج از بازه ۰ تا ۱ است.

### اشتباهات رایج

- نوشتن `opacity: 50` به‌جای `0.5` یا `50%`.  
- تصور اینکه ۰ یعنی «کمی روشن» و ۱ یعنی «خاموش». قرارداد برعکسِ زبان روزمره بعضی دانشجوهاست: ۱ کاملاً حاضر است.

## ۳) شفافیت پدر به همه فرزندان می‌رسد

حالا اشتباه هیرو را عمداً بساز.

```html
<div class="stage">
  <div class="hero-bad">
    <h1>کتاب‌سرا</h1>
    <p>ارسال رایگان برای خرید بالای ۵۰۰ هزار تومان</p>
  </div>
</div>
```

```css
.hero-bad {
  background: #1a5fb4;
  color: white;
  padding: 1.5rem;
  opacity: 0.4;
}
```

«پس‌زمینه آبی شفاف شد. جمله هم شفاف شد. کاربر روی عکس شلوغ این متن را به زور می‌خواند.

دانشجویی می‌گوید: به خود `h1` مقدار `opacity: 1` می‌دهم تا پررنگ شود. امتحان کنیم.»

```css
.hero-bad h1,
.hero-bad p {
  opacity: 1;
}
```

«هیچ فرقی نکرد. `opacity` روی عنصر و **همه فرزندانش با هم** اعمال می‌شود. شفافیت‌ها در هم ضرب می‌شوند. فرزندِ یک عنصر ۴۰درصدی، حتی اگر خودش `opacity: 1` باشد، در نهایت همان حدود ۴۰درصد دیده می‌شود. راه برگشت از داخل فرزند وجود ندارد.»

این را با یک کارت تو در تو هم نشان بده تا ضرب دیده شود:

```css
.outer { opacity: 0.5; background: white; padding: 1rem; }
.inner { opacity: 0.5; background: #1a5fb4; color: white; padding: 1rem; }
```

«۰٫۵ ضرب در ۰٫۵ می‌شود ۰٫۲۵. جعبه داخلی خیلی محو است، نه نیمه‌شفافِ ساده.»

**در مرورگر:** متن هیرو همزمان با پس‌زمینه کم‌رنگ است. تغییر `opacity` فرزند به ۱ را در DevTools زنده عوض کن تا کلاس ببیند اتفاقی نمی‌افتد.

### سؤال کلاسی

- «پدر `opacity: 0.5` دارد و فرزند `opacity: 1`. فرزند در صفحه چقدر مات دیده می‌شود؟»  
  **پاسخ:** حدود نصف. شفافیت پدر از بین نمی‌رود.

- «اگر هم پدر و هم فرزند `0.5` باشند، نتیجه به ۱ نزدیک می‌شود یا به ۰؟»  
  **پاسخ:** به ۰. حاصل‌ضرب حدود ۰٫۲۵ است.

### اشتباهات رایج

- تلاش برای «جبران» شفافیت پدر با `opacity: 1` روی فرزند.  
- گذاشتن `opacity` روی ظرفی که هم عکس، هم متن، هم دکمه داخلش است، فقط به امید کم‌رنگ شدن پس‌زمینه.

## ۴) نامرئی هنوز جا دارد و کلیک می‌شود

«`opacity: 0` عنصر را از صفحه پاک نمی‌کند. فقط رنگش را برمی‌دارد.»

```html
<button type="button" class="ghost">این دکمه دیده نمی‌شود</button>
<p>متن بعدی اینجاست.</p>
```

```css
.ghost { opacity: 0; }
```

«بین جای خالی و پاراگراف بعد فاصله است. اگر روی همان ناحیه خالی کلیک کنید، دکمه هنوز کلیک را می‌گیرد. برای کاربر مبهم است: چیزی نمی‌بیند ولی چیزی اتفاق می‌افتد.

اگر باید از چیدمان هم حذف شود، `display: none` است. اگر باید جایش بماند ولی نه دیده شود و نه کلیک شود، `visibility: hidden` است. `opacity: 0` برای محو شدن در انیمیشن به کار می‌آید، نه برای حذف واقعی.»

این سه را در سه خط روی تخته بنویس و فقط همین فرق را بگو. وارد درس انیمیشن نشو؛ یک جمله کافی است که درس ۲۲ همین محو شدن را نرم می‌کند.

| ابزار | دیده می‌شود؟ | جا می‌گیرد؟ | کلیک؟ |
|------|----------------|------------|--------|
| `opacity: 0` | نه | بله | بله |
| `visibility: hidden` | نه | بله | نه |
| `display: none` | نه | نه | نه |

### سؤال کلاسی

- «دکمه ناموجود را فقط با `opacity: 0` مخفی کنیم کافی است؟»  
  **پاسخ:** نه. هنوز کلیک می‌شود و جایش هم هست. برای کالای ناموجود هم کم‌رنگ کردن تنها کافی نیست؛ در بخش بعد `disabled` را می‌گذاریم.

## ۵) گالری محصولات و دکمه غیرفعال

«دو جای واقعی فروشگاه که `opacity` انتخاب درستی است، چون می‌خواهیم **کل** عنصر کم‌رنگ شود، نه فقط پس‌زمینه‌اش.»

اول گالری. عکس‌ها آرام‌اند تا وقتی ماوس روی یکی برود، همان یکی واضح شود:

```css
.gallery img {
  width: 140px;
  height: 90px;
  object-fit: cover;
  opacity: 0.5;
  transition: opacity 0.3s;
}

.gallery img:hover,
.gallery img:focus-visible {
  opacity: 1;
}
```

«`transition` را همین‌قدر معرفی کن: تغییر شفافیت یک‌دفعه نپرد، حدود ۰٫۳ ثانیه طول بکشد. جزئیات `transition` مال درس ۲۲ است.

برای کسی که با کیبورد به تصویر می‌رسد، اگر تصویر داخل لینک است، `:focus-visible` را هم کنار `:hover` بگذار تا واضح شدن فقط مخصوص ماوس نباشد.»

دوم، دکمه کالای ناموجود:

```html
<button class="btn" type="button">افزودن به سبد</button>
<button class="btn" type="button" disabled>ناموجود</button>
```

```css
.btn {
  background: #0b6e4f;
  color: white;
  border: none;
  padding: 0.6rem 1rem;
  border-radius: 8px;
  cursor: pointer;
}

.btn:disabled {
  opacity: 0.4;
  cursor: not-allowed;
}
```

«اینجا کم‌رنگ شدن کل دکمه دقیقاً همان پیامی است که می‌خواهیم: این کنترل الان در دسترس نیست. ولی کم‌رنگ بودن به‌تنهایی جلوی کلیک را نمی‌گیرد. ویژگی `disabled` در HTML هم دکمه را از کار می‌اندازد و هم به فناوری کمکی می‌گوید غیرفعال است. CSS فقط این وضعیت را قابل دیدن می‌کند.»

**در مرورگر:** ماوس را روی عکس‌های گالری ببر. روی دکمه ناموجود کلیک کن و نشان بده اتفاقی نمی‌افتد. اگر `disabled` را موقتاً برداری و فقط شفافیت بماند، کلیک دوباره کار می‌کند. این مقایسه را حتماً انجام بده.

### سؤال کلاسی

- «چرا در گالری `opacity` روی خود `img` درست است، ولی در هیرو روی ظرف متن غلط بود؟»  
  **پاسخ:** در گالری می‌خواهیم خود عکس کم‌رنگ شود. در هیرو می‌خواهیم فقط لایه پشت متن شفاف باشد و نوشته واضح بماند.

### اشتباهات رایج

- دکمه غیرفعال فقط با کم کردن `opacity`، بدون `disabled`.  
- فراموش کردن `:focus-visible` کنار `:hover` در گالری لینک‌دار.

## ۶) وقتی فقط پس‌زمینه باید شفاف باشد

برگرد به هیرو. دو جعبه را کنار هم، روی همان طرح شطرنجی، بگذار.

```html
<div class="stage">
  <div class="box-op">با opacity — متن هم کم‌رنگ است</div>
  <div class="box-rgba">با rgba — متن کاملاً واضح است</div>
</div>
```

```css
.box-op,
.box-rgba {
  color: white;
  padding: 1rem 1.25rem;
  margin: 0.5rem;
  max-width: 280px;
}

.box-op {
  background: rgb(26, 95, 180);
  opacity: 0.4;
}

.box-rgba {
  background: rgba(26, 95, 180, 0.4);
}
```

«جعبه اول کل خودش را ۴۰درصد کرده؛ نوشته سفید هم خاکستری شده. جعبه دوم فقط رنگ پس‌زمینه ۴۰درصد آبی است. خود عنصر `opacity` ندارد، پس متن سفید کاملاً مات می‌ماند و از پشت، طرح صفحه پیدا است.

`rgba` یعنی قرمز، سبز، آبی، و کانال آلفا. آلفا همان شفافیت **آن رنگ** است، نه شفافیت عنصر.

در CSS امروزی همین را کوتاه‌تر هم می‌نویسیم:»

```css
.box-modern {
  background: rgb(26 95 180 / 40%);
}
```

«بین عددها فاصله است، و بعد از `/` میزان شفافیت رنگ آمده. `40%` همان ۰٫۴ است. نتیجه با `rgba(26, 95, 180, 0.4)` یکی است. هر دو را بلد باشید، چون هر دو را در پروژه‌ها می‌بینید.»

حالا هیرو را درست کن. لایه تیره را از متن جدا کن. ساده‌ترین شکل همین است که پس‌زمینه خود جعبه متن، رنگِ شفاف باشد و `opacity` روی جعبه نباشد:

```css
.hero-good {
  padding: 1.5rem;
  color: white;
  background: rgb(15 23 42 / 55%);
}
```

اگر عکس باید پشت همین جعبه باشد، عکس را به پدر بده و جعبه متن را فرزند با پس‌زمینه شفاف:

```html
<section class="hero-photo">
  <div class="hero-good">
    <h1>کتاب‌سرا</h1>
    <p>ارسال رایگان برای خرید بالای ۵۰۰ هزار تومان</p>
  </div>
</section>
```

```css
.hero-photo {
  background: #1a5fb4 url("bg.jpg") center/cover;
  padding: 2rem 1rem;
}
```

«متن دیگر فرزندِ یک عنصرِ `opacity`دار نیست. شفافیت فقط در رنگ پس‌زمینه است. برای همین سفید، سفید می‌ماند.»

**در مرورگر:** دو جعبه را کنار هم نگه دار. از ردیف آخر بخواه با صدای بلند بگویند کدام جمله را راحت‌تر می‌خوانند. بعد هیرو درست را نشان بده.

### سؤال کلاسی

- «می‌خواهیم فقط پس‌زمینه کارت ۴۰درصد مشکی باشد و قیمت کاملاً خوانا بماند. چه می‌نویسیم؟»  
  **پاسخ:** `background: rgb(0 0 0 / 40%)` یا `rgba(0, 0, 0, 0.4)` روی خود کارت، بدون `opacity` روی پدر متن.

- «`opacity: 0.4` روی کارت با `background: rgba(..., 0.4)` چه فرقی در متن داخل کارت دارد؟»  
  **پاسخ:** اولی متن را هم محو می‌کند. دومی فقط همان رنگ پس‌زمینه را شفاف می‌کند.

### اشتباهات رایج

- حل کردن لایه روی عکس با `opacity` روی همان عنصری که متن را نگه می‌دارد.  
- نوشتن `rgba(26, 95, 180, 40)` با آلفا خارج از ۰ تا ۱. کانال آلفا در شکل قدیمی هم ۰ تا ۱ است. در شکل `rgb(… / 40%)` درصد مجاز است.

## ۷) اشاره کوتاه به لایه جدید

اگر کلاس خسته نیست، یک جمله سطح میانی بگو و رد شو. این نکته را به درس `z-index` وصل کن.

«وقتی `opacity` عنصری از ۱ کمتر باشد، مرورگر برای آن عنصر یک لایه مستقل می‌سازد. اثر عملی‌اش این است که `z-index` فرزندان گاهی آن‌طور که انتظار دارید از پدر بیرون نمی‌زند. اگر نشان فروش ویژه زیر همسایه‌اش رفت و به پدر `opacity` داده بودید، اول شفافیت را به رنگ پس‌زمینه منتقل کنید، بعد سراغ `z-index` بروید.»

لازم نیست stacking context را با این اسم طولانی درس بدهی. یک بار نشان دادن کافی است: پدر با `opacity: 0.99` و فرزند با `z-index` بالا که از همسایه بیرون نمی‌آید. اگر وقت کم است این بند را فقط شفاهی بگو.

## ۸) پروژه جلسه — کارت محصول روی عکس

همه را در یک کارت جمع کن. دو نسخه غلط و درست را همزمان روی صفحه نگه دار.

```html
<div class="stage">
  <article class="card bad">
    <h2>کتاب CSS</h2>
    <p class="price">۱۸۰٬۰۰۰ تومان</p>
    <button type="button" disabled>ناموجود</button>
  </article>

  <article class="card good">
    <h2>کتاب CSS</h2>
    <p class="price">۱۸۰٬۰۰۰ تومان</p>
    <button type="button">افزودن به سبد</button>
  </article>
</div>
```

```css
.card {
  display: inline-block;
  width: 220px;
  margin: 0.5rem;
  padding: 1rem;
  color: white;
  vertical-align: top;
}

.card.bad {
  background: rgb(15, 23, 42);
  opacity: 0.55;
}

.card.good {
  background: rgb(15 23 42 / 55%);
}

.card button {
  background: white;
  color: #0f172a;
  border: none;
  padding: 0.45rem 0.8rem;
  border-radius: 8px;
}

.card button:disabled {
  opacity: 0.45;
  cursor: not-allowed;
}
```

«کارت چپ همه‌چیز را کم‌رنگ کرده، حتی قیمت. کارت راست فقط زمینه را شفاف کرده و قیمت سفید خوانا است. دکمه ناموجود هم کم‌رنگ است، ولی این بار `opacity` روی خود دکمه است و `disabled` هم دارد. اینجا کم‌رنگ شدن کل کنترل درست است.»

**در مرورگر:** هر دو کارت روی طرح شطرنجی. قیمت‌ها را با هم مقایسه کن. روی دکمه غیرفعال کلیک کن.

### سؤال کلاسی

- «اگر بخواهیم با hover کل کارت کمی واضح‌تر شود، `opacity` را کجا بگذاریم؟»  
  **پاسخ:** اگر کارت از اول `opacity` ندارد و فقط رنگ پس‌زمینه‌اش شفاف است، یا آلفا را در hover زیاد کن، یا اگر عمداً کل کارت باید محو و واضح شود `opacity` را روی خود کارت بگذار و متن را جداگانه با رنگ مات جبران نکن؛ از همان اول تصمیم بگیر کدام رفتار را می‌خواهی.

## ۹) جمع‌بندی مدرس و سؤالات پایانی

1. بازه درست `opacity` چیست؟  
   **پاسخ راهنما:** از ۰ تا ۱، یا از `0%` تا `100%`. مقدار `1` کاملاً مات است.

2. چرا `opacity: 1` روی فرزند، شفافیت پدر را لغو نمی‌کند؟  
   **پاسخ:** شفافیت پدر روی کل زیردرخت اعمال شده و با شفافیت فرزند ضرب می‌شود.

3. برای نوار متن روی عکس هیرو کدام را انتخاب می‌کنی؟  
   **پاسخ:** شفافیت را در رنگ پس‌زمینه بنویس: `rgb(… / …)` یا `rgba(...)`. `opacity` را برای وقتی بگذار که خود عنصر — عکس گالری یا دکمه غیرفعال — باید کم‌رنگ شود.

**پیام پایانی:**

«`opacity` ابزار بدی نیست. ابزار همه‌کاره هم نیست. هر وقت متن باید خوانا بماند، شفافیت را به رنگ بده، نه به پدرِ متن. هر وقت خود شیء باید محو شود، `opacity` سر جایش است و برای کنترل غیرفعال، HTML را هم غیرفعال کن.»

## تمرین‌ها (ساده → چالشی)

### ساده

1. چهار مربع با `opacity`های `0.2` و `0.5` و `0.8` و `1` بساز و پشتشان یک طرح شطرنجی بگذار.  
2. یک بار `opacity: 80` بنویس و در DevTools ببین چرا اعمال نمی‌شود. بعد `0.8` و `80%` را مقایسه کن.

### متوسط

3. سه تصویر گالری با `opacity: 0.5` که در `:hover` به `1` برسند. `transition: opacity 0.3s` را هم بگذار.  
4. دو دکمه: یکی فعال، یکی `disabled` با `opacity: 0.4` و `cursor: not-allowed`. موقتاً `disabled` را بردار و کلیک را امتحان کن.

### چالشی

5. یک کارت روی تصویر پس‌زمینه بساز که نوار متنش `rgb(0 0 0 / 60%)` باشد و عنوان سفید کاملاً خوانا بماند. کنارش همان کارت را با `opacity: 0.6` روی پدر بساز و فرق خوانایی را در دو جمله بنویس.  
6. توضیح بده در کدام‌یک از این سه مورد `opacity` انتخاب توست و در کدام رنگ شفاف: عکس گالری، لایه روی هیرو، دکمه ناموجود.
