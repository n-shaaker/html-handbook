از وبلاگ آکادمی

نمونهٔ مقاله با تصویر شناور و متنی که دورش می‌پیچد.

چرا قبل از Flex باید جعبه را بفهمیم؟

خیلی‌ها مستقیم سراغ Flexbox می‌روند و وقتی برچسب گوشهٔ کارت جابه‌جا نمی‌شود یا منوی کشویی بریده می‌شود، گیج می‌شوند. مسیر میانی اول رفتار جعبه، سقف عرض، موقعیت و سرریز را محکم می‌کند.

در آکادمی وب همین صفحه را قدم‌به‌قدم جلو می‌بریم: اول نوع نمایش، بعد قاب امن، بعد برچسب absolute، بعد لایه‌ها و overflow، بعد منو و فرم، و در نهایت media query تا روی موبایل اسکرول افقی نماند.

float را برای پیچیدن متن دور تصویر بشناسید؛ چیدمان اصلی صفحه را با Flex و Grid بسازید.
