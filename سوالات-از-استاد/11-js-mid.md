# ۱۱) JavaScript میانی — سوالات پرتکرار از استاد

## آرایه و متدها
1. آرایه را کی به‌جای چند متغیر جدا استفاده کنیم؟
2. فرق `push` / `pop` / `shift` / `unshift`؟
3. `map` با `forEach` چه فرقی دارد؟ کی کدام؟
4. `filter` و `find` را قاطی کرده‌ام.
5. `reduce` سخت است؛ یک مثال جونیور بدهید (جمع قیمت‌ها).
6. آیا متدهای آرایه آرایهٔ اصلی را عوض می‌کنند؟ (mutating)

## scope، arrow، this، JSON، خطا
7. Scope یعنی چه؟ چرا بیرون تابع متغیر داخل را نمی‌بینم؟
8. Hoisting را باید حفظ باشم یا فقط بدونم `var` عجیب است؟
9. Arrow function همیشه بهتر است؟ کی نه؟
10. `this` چرا گیج‌کننده است؟ برای جونیور حداقل چه قانونی؟
11. Destructuring و spread را با یک شیء کاربر مثال بزنید.
12. JSON با شیء JS چه فرقی دارد؟ `stringify` / `parse` کی؟
13. `try/catch` را دور چه کدی بگذاریم؟
