# ۱۳) پروژه رستوران با JS — سوالات پرتکرار از استاد

1. باید اول کل `app.js` را بخوانم یا از روی کوییزها بسازم؟
2. داده منو را در HTML بگذارم یا آرایه JS؟
3. فیلتر دسته و جستجو را جدا بنویسم یا یک تابع render؟
4. سبد خرید را چطور مدل کنم؟ (آرایه اشیا)
5. `localStorage` را کی load کنم؟ (اول اجرا)
6. اعتبارسنجی فرم رزرو چه فیلدهایی حداقل؟
7. toast را چطور بعد از چند ثانیه ببندم؟
8. پنل کناری با کلیک بیرون بسته نمی‌شود؛ چطور؟
9. Escape و برگرداندن فوکوس را فراموش کردم؛ استاد از من چه می‌خواهد؟
10. Event delegation روی لیست غذا چرا بهتر از listener روی هر دکمه است؟
11. باگ فقط گاهی Occurs؛ چطور reproduce کنم؟
12. CSS را از پروژه ۰۷ کپی کردم ولی JS می‌شکند؛ ترتیب اسکریپت؟
13. برای رزومه چطور این پروژه را توضیح بدهم؟ (۳ جمله)
14. فیچر اضافه برای امتیاز بیشتر چه پیشنهاد می‌کنید؟
15. بعد از این پروژه مسیر یادگیری فرانت چیست؟ (React؟ TypeScript؟ بیشتر JS؟)
