# ۱۳) پروژه رستوران JS — سوال و جواب

### ۱. کل `app.js` را بخوانم یا از کوییزها بسازم؟
**جواب:** اول رفتار محصول را لمس کنید، بعد کوییز موضوعی (فیلتر، سبد، …). خواندن یک‌جای کل فایل بدون تمرین کم‌بازده است.

### ۲. داده منو در HTML یا آرایه JS؟
**جواب:** برای نسخهٔ تعاملی بهتر است آرایه/داده در JS باشد تا فیلتر و رندر آسان شود. HTML فقط ظرف خالی/قالب ریشه.

### ۳. فیلتر و جستجو جدا یا یک render؟
**جواب:** یک `render` که از روی state (دسته + متن جستجو + سبد) UI را می‌سازد؛ توابع فیلتر فقط داده را آماده کنند.

### ۴. سبد را چطور مدل کنم؟
**جواب:** آرایه‌ای از `{ id, name, price, qty }` یا Map با id. هر تغییر → ذخیره اختیاری → render سبد.

### ۵. `localStorage` را کی load کنم؟
**جواب:** اول اجرای اسکریپت، قبل از اولین رندر معنادار؛ اگر JSON خراب بود، آرایه خالی و خطا را ببلعید/لاگ کنید.

### ۶. اعتبارسنجی فرم رزرو؛ حداقل فیلدها؟
**جواب:** نام، تلفن/ایمیل با الگوی ساده، تعداد نفر، تاریخ/ساعت اگر دارید. پیام خطای قابل فهم زیر فیلد.

### ۷. toast را چطور ببندم؟
**جواب:** نشان بده → `setTimeout` برای پنهان → کلاس CSS. برای a11y از `aria-live` استفاده کنید.

### ۸. پنل با کلیک بیرون بسته نمی‌شود؟
**جواب:** listener روی `document`؛ اگر کلیک بیرون از پنل و بیرون از دکمهٔ بازکننده بود ببند. حواستان به bubbling باشد.

### ۹. Escape و فوکوس؛ استاد چه می‌خواهد؟
**جواب:** با Escape بسته شود و فوکوس به دکمهٔ بازکننده برگردد تا کیبوردگیر نمانید.

### ۱۰. چرا delegation روی لیست غذا؟
**جواب:** دکمه‌های «افزودن» بعد از فیلتر دوباره ساخته می‌شوند؛ listener روی والد پایدار می‌ماند.

### ۱۱. باگ گاهی Occurs؛ چطور reproduce؟
**جواب:** مراحل دقیق را یادداشت کنید (ترتیب کلیک، فیلتر فعال، رفرش). Console را باز بگذارید؛ فرض‌ها را با log ثابت کنید.

### ۱۲. CSS از ۰۷ کپی؛ JS می‌شکند؟
**جواب:** id/class در HTML با چیزی که JS می‌گیرد یکی نیست، یا اسکریپت قبل از DOM، یا خطای JS اجرای بعدی را می‌خواباند — اولین خطای قرمز را درست کنید.

### ۱۳. برای رزومه در ۳ جمله؟
**جواب:** «منوی رستوران واکنش‌گرا با فیلتر و جستجو ساختم؛ سبد خرید با localStorage؛ فرم رزرو با اعتبارسنجی و UI دسترس‌پذیر (کیبورد/ARIA).»

### ۱۴. فیچر اضافه برای امتیاز؟
**جواب:** خالی کردن سبد، تعداد موجودی، حالت باز/بسته بودن رستوران بر اساس ساعت، یا تم روشن/تاریک با متغیر CSS.

### ۱۵. بعد از این پروژه مسیر چیست؟
**جواب:** یک Deploy زنده + ۲–۳ پروژه کوچک دیگر. بعد در صورت علاقه React یا TypeScript؛ اول JS و DOM را محکم کنید نه اینکه زود فقط فریم‌ورک حفظ کنید.
