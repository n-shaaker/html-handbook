# ۱۲) JavaScript پیشرفته — سوال و جواب

## مباحث سنگین / اختیاری

### ۱. Closure با مثال شمارنده؟
**جواب:** تابع درونی به متغیر بیرونی زنده دسترسی دارد حتی بعد از برگشت تابع بیرونی. شمارنده: تابعی که `count` را می‌بندد و با هر صدا یکی زیاد می‌کند.

### ۲. `call` / `apply` / `bind` واجب است؟
**جواب:** برای مسیر جونیور سایت‌ساز **اختیاری** است. وجودشان را بدانید؛ عمیق شدن را بگذارید برای بعد.

### ۳. کلاس و وراثت تا کجا؟
**جواب:** ساختن کلاس ساده با constructor و متد کافی است. وراثت عمیق و private fields را اگر سخت بود علامت اختیاری بزنید و رد شوید.

### ۴. `Set` و `Map` کی بهتر از آرایه؟
**جواب:** Set برای یکتایی سریع. Map وقتی کلید غیررشته یا نیاز به دیکشنری مرتب‌تر دارید. برای لیست UI معمولاً آرایه کافی است.

## زمان‌بندی و ناهمگام

### ۵. `setTimeout` با `setInterval`؟
**جواب:** timeout یک‌بار بعد از تأخیر. interval تکرار تا `clearInterval`.

### ۶. Callback hell؟
**جواب:** تو در تو شدن callbackها تا کد خوانا نماند. راه‌حل مدرن: Promise و async/await.

### ۷. Promise بدون jargon؟
**جواب:** قول نتیجهٔ بعدی: یا موفق (`then`/`await`) یا شکست (`catch`). برای کارهایی که طول می‌کشند (شبکه).

### ۸. `async/await` فقط شکر روی Promise؟
**جواب:** تقریباً بله — همان Promise با ظاهر همگام‌تر و خواناتر. زیرش هنوز ناهمگام است.

### ۹. خطا در `async` را چطور بگیرم؟
**جواب:** `try/catch` دور `await`، یا `.catch` روی Promise. بدون گرفتن، خطای Uncaught می‌گیرید.

### ۱۰. چرا کد بعد از `fetch` زود اجرا می‌شود؟
**جواب:** چون fetch ناهمگام است و صبر نمی‌کند مگر `await`/`.then`. بقیهٔ کد همگام جلو می‌رود.

## Fetch، ماژول، storage

### ۱۱. CORS خطا می‌دهد؛ من چه کنم؟
**جواب:** مرورگر جلوی خواندن پاسخ از دامنهٔ دیگر بدون اجازهٔ سرور را می‌گیرد. جونیور: از API عمومی مجاز استفاده کنید یا سرور خودتان header بدهد؛ CORS را از فرانت «دور» نزنید با هک ناامن.

### ۱۲. چرا ماژول با دوبارکلیک باز نمی‌شود؟
**جواب:** ES modules برای بسیاری مرورگرها به HTTP نیاز دارند. Live Server یا سرور محلی بزنید.

### ۱۳. ظرفیت و امنیت `localStorage`؟
**جواب:** حدود چند مگابایت؛ برای پسورد/توکن حساس مناسب نیست (هر اسکریپت همان صفحه می‌خواند). دادهٔ UI مثل تم و Todo OK.

### ۱۴. چرا `JSON.stringify`؟
**جواب:** storage فقط رشته نگه می‌دارد. شیء/آرایه را باید متن کنید و موقع خواندن `parse`.

### ۱۵. RegExp را کامل حفظ باشم؟
**جواب:** نه. چند الگوی رایج (ایمیل ساده، فقط عدد) و تست کردن کافی است؛ مرجع کنار دستتان باشد.

## Delegation، دیباگ، a11y، deploy

### ۱۶. چرا event delegation برای لیست پویا؟
**جواب:** آیتم‌های جدید listener قدیمی ندارند. یک listener روی والد با `event.target`/`closest` همه را پوشش می‌دهد.

### ۱۷. `debugger` با breakpoint؟
**جواب:** هر دو اجرا را متوقف می‌کنند. breakpoint در DevTools روی خط؛ `debugger` داخل کد وقتی Console باز است می‌ایستد.

### ۱۸. حداقل a11y پنل بازشو؟
**جواب:** `<button>`، `aria-expanded`، بستن با Escape، برگرداندن فوکوس، ترجیحاً `aria-controls`.

### ۱۹. GitHub Pages یا Netlify Drop؟
**جواب:** برای اولین بار Netlify Drop خیلی سریع است. Pages برای کسی که از قبل GitHub دارد عالی است. هر دو برای استاتیک مناسب‌اند.

### ۲۰. بعد از Deploy تصاویر 404؟
**جواب:** مسیر مطلق سیستم محلی، حروف بزرگ/کوچک، یا فراموش کردن آپلود پوشهٔ `images`. در Network تب سایتِ آنلاین چک کنید.

## پروژه فروشگاه

### ۲۱. معماری را چطور تکه کنم؟
**جواب:** داده → رندر لیست → سبد → storage → رویدادها. هر تکه را جدا تست کنید قبل از اتصال کامل.

### ۲۲. سبد ماندگار را کجا به storage وصل کنم؟
**جواب:** بعد از هر تغییر سبد `save`؛ در شروع برنامه `load` و بعد اولین `render`.

### ۲۳. اگر API قطع باشد UI چه نشان بدهد؟
**جواب:** پیام وضعیت واضح (`role="status"`)، نه صفحهٔ خالی. دکمهٔ تلاش دوباره اگر مناسب است.
