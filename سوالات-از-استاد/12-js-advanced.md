# ۱۲) JavaScript پیشرفته — سوالات پرتکرار از استاد

## مباحث سنگین / اختیاری
1. Closure را با یک مثال شمارنده توضیح دهید.
2. `call` / `apply` / `bind` برای جونیور واجب است؟ (اختیاری علامت خورده)
3. کلاس و وراثت را تا کجا یاد بگیرم کافی است؟
4. `Set` و `Map` کی از آرایه بهترند؟

## زمان‌بندی و ناهمگام
5. `setTimeout` با `setInterval` چه فرقی دارد؟
6. Callback hell یعنی چه؟
7. Promise را بدون jargon بگویید.
8. `async/await` فقط شکر روی Promise است؟
9. خطا در `async` را چطور بگیرم؟
10. چرا کد بعد از `fetch` قبل از جواب اجرا می‌شود؟

## Fetch، ماژول، storage
11. CORS خطا می‌دهد؛ یعنی چه و من چه کار می‌توانم بکنم؟
12. چرا مثال ماژول با دوبارکلیک فایل باز نمی‌شود؟ (Live Server)
13. `localStorage` چقدر داده جا می‌دهد؟ امن است برای پسورد؟
14. چرا باید `JSON.stringify` کنیم؟
15. RegExp را کامل حفظ باشم یا فقط الگوهای رایج ایمیل/عدد؟

## Delegation، دیباگ، a11y، deploy
16. Event delegation برای لیست پویا چرا لازم است؟
17. `debugger` با breakpoint چه فرقی دارد؟
18. برای پنل بازشو حداقل a11y چیست؟ (button، Escape، aria-expanded)
19. GitHub Pages با Netlify Drop کدام برای اول کار ساده‌تر است؟
20. بعد از Deploy تصاویرم 404 می‌شوند؛ علت رایج؟

## پروژه فروشگاه
21. از کجا معماری پروژه را تکه کنم تا قورت ندهد؟
22. سبد خرید ماندگار را کجای کد به storage وصل کنم؟
23. اگر API قطع باشد UI چه باید نشان بدهد؟
