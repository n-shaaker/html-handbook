# ۵) تصاویر در CSS — سوالات پرتکرار از استاد

1. کی از `<img>` استفاده کنیم و کی از `background-image`؟
2. مسیر نسبی `../images/` را چطور از روی محل فایل CSS حساب کنیم؟
3. چرا در HTML تصویر هست ولی در CSS پس‌زمینه نه؟ (مسیر نسبت به فایل CSS)
4. Hero خوانا نیست چون متن روی عکس شلوغ است؛ چه راه‌هایی داریم؟
5. `object-fit: cover` با `contain` چه فرقی دارد؟
6. عکس پروفایل دایره‌ای کج می‌شود/کش می‌آید؛ علت؟
7. کارت محصول؛ تصویر ارتفاع ثابت می‌خواهد چطور؟
8. `max-width: 100%` روی img کافی است برای واکنش‌گرایی؟
9. `srcset` را باید در CSS یاد بگیرم یا HTML؟
10. تصویر سنگین سایت را کند می‌کند؛ حداقل کار جونیور چیست؟ (اندازه، فرمت، lazy)
11. alt را برای background-image چطور تأمین کنیم؟ (معمولاً نداریم → محتوا در HTML)
12. قبل از پروژه رستوران از این فصل چه چیزهایی حتماً باید بلد باشم؟
