# ۵) تصاویر در CSS — سوال و جواب

### ۱. کی `<img>` و کی `background-image`؟
**جواب:** محتوای معنادار/سئو/alt → `<img>`. تزئینی یا Hero پیچیدهٔ لایه‌ای → گاهی background. اگر معنا دارد، HTML را ترجیح دهید.

### ۲. مسیر نسبی از روی فایل CSS چطور حساب می‌شود؟
**جواب:** نسبت به **محل فایل CSS**، نه HTML. از `css/style.css` به `images/a.jpg` معمولاً `../images/a.jpg`.

### ۳. در HTML تصویر هست ولی در CSS پس‌زمینه نه؟
**جواب:** مسیر CSS را نسبت به HTML کپی کرده‌اید. در Network ببینید درخواست background 404 می‌دهد یا نه.

### ۴. Hero خوانا نیست؛ چه راه‌هایی؟
**جواب:** لایهٔ تیره `rgba`/`linear-gradient` روی عکس، متن با سایه ملایم، عکس خلوت‌تر، یا جابه‌جایی متن به ناحیهٔ ساده‌تر تصویر.

### ۵. `object-fit: cover` با `contain`؟
**جواب:** `cover` کادر را پر می‌کند و ممکن است برش بخورد. `contain` کل تصویر دیده می‌شود و ممکن است فضای خالی بماند.

### ۶. عکس پروفایل دایره‌ای کج/کش می‌آید؛ علت؟
**جواب:** عرض و ارتفاع نابرابر بدون object-fit، یا نبود `border-radius: 50%` روی عنصر مربعی. معمولاً ظرف مربع + `object-fit: cover`.

### ۷. کارت محصول؛ تصویر ارتفاع ثابت؟
**جواب:** به تصویر ارتفاع/aspect مشخص بدهید و `object-fit: cover` تا کارت‌ها یک‌دست شوند.

### ۸. `max-width: 100%` روی img کافی است؟
**جواب:** برای نریختن از ستون بله پایه است؛ برای چیدمان چندستونه هنوز Flex/Grid و گاهی MQ لازم است.

### ۹. `srcset` در CSS یا HTML؟
**جواب:** در **HTML** روی `img`/`source`. CSS مسئول برش و fit است، نه انتخاب رزولوشن واکنش‌گرا به‌سبک srcset.

### ۱۰. تصویر سنگین؛ حداقل کار جونیور؟
**جواب:** اندازهٔ مناسب export، فرمت مدرن در صورت امکان، فشرده‌سازی، و `loading="lazy"` برای تصاویر پایین صفحه.

### ۱۱. alt برای background-image؟
**جواب:** ندارد. اگر محتوا مهم است از `<img alt="...">` استفاده کنید؛ وگرنه تزئینی بماند.

### ۱۲. قبل از پروژه رستوران چه چیزهایی حتماً؟
**جواب:** فرق img/bg، مسیر نسبی، object-fit، Hero خوانا، تصویر واکنش‌گرا با max-width، کارت با تصویر یک‌دست.
