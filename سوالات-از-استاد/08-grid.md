# ۸) CSS Grid — سوالات پرتکرار از استاد

1. Grid با Flex چه فرقی دارد؟ کی کدام؟
2. `fr` یعنی چه؟
3. `repeat(3, 1fr)` با `repeat(auto-fit, minmax(220px, 1fr))` چه فرقی دارد؟
4. `auto-fit` و `auto-fill` را قاطی کرده‌ام؛ فرق چیست؟
5. `grid-template-areas` را چطور برای اسکلت صفحه استفاده کنم؟
6. قرار دادن آیتم با شماره خط (`grid-column`) سخت است؛ از کجا شروع کنم؟
7. `gap` در Grid با Flex یکسان است؟
8. تراز داخل خانه با تراز کل شبکه چه فرقی دارد؟
9. شبکه ضمنی (implicit) کی ساخته می‌شود؟
10. صفحه داشبورد را اول Grid بسازم یا Flex؟
11. روی موبایل Grid را چطور تک‌ستون کنم؟
12. می‌شود Grid و Flex را با هم در یک صفحه استفاده کرد؟
13. قبل از پروژه رستوران حداقل کدام ۳ الگوی Grid را باید بلد باشم؟
14. خطای رایج: فراموش کردن `display: grid` روی والد — علائم چیست؟
