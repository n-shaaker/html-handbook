# ۲) CSS مقدماتی — سوالات پرتکرار از استاد

## اتصال و نحو
1. سه روش افزودن CSS کدام‌اند و کدام را در پروژه واقعی ترجیح بدهیم؟
2. چرا CSS اینلاین بد است؟
3. ترتیب نوشتن ویژگی‌ها مهم است؟
4. اگر قانون CSS کار نکرد اول کجا را چک کنم؟ (selector، مسیر فایل، غلط املایی)
5. کامنت در CSS چطور نوشته می‌شود؟

## رنگ و پس‌زمینه
6. Hex با RGB چه فرقی دارد؟ کدام رایج‌تر است؟
7. `rgba` برای چه به درد می‌خورد؟
8. فرق `background-color` و `background-image`؟
9. چرا تصویر پس‌زمینه تکرار می‌شود؟ چطور یک‌بار و cover کنم؟

## جعبه: border، margin، padding، size
10. فرق margin و padding را با یک مثال واقعی بگویید.
11. چرا دو margin روی هم «جمع» نمی‌شوند؟ (collapse)
12. `width: 100%` با padding باعث اسکرول افقی می‌شود؛ چرا؟
13. `box-sizing: border-box` چیست و چرا همه پروژه‌ها می‌گذارندش؟
14. فرق `px` و `em` و `rem`؟ برای فونت کدام بهتر است؟
15. `outline` با `border` چه فرقی دارد؟ چرا برای فوکوس مهم است؟

## متن و فونت
16. چطور فونت فارسی وب را وصل کنم؟
17. `@font-face` با فونت گوگل چه فرقی دارد؟
18. `line-height` را عددی بگذاریم یا با واحد؟
19. استایل لینک (`:link :visited :hover :focus`) ترتیب مهم دارد؟

## لیست و جدول
20. بولت لیست را چطور عوض/حذف کنیم؟
21. جدول را چطور زیبا کنیم بدون اینکه برای layout استفاده شود؟

## تمرین

23. چند فایل CSS بهتر است یا یکی؟
