# ۲) CSS مقدماتی — سوال و جواب

## اتصال و نحو

### ۱. سه روش افزودن CSS کدام‌اند و کدام را ترجیح بدهیم؟
**جواب:** اینلاین (`style=""`)، داخلی (`<style>`)، خارجی (`link` به فایل `.css`). در پروژه واقعی **خارجی**؛ اینلاین فقط استثنای نادر.

### ۲. چرا CSS اینلاین بد است؟
**جواب:** تکرار، سخت برای نگهداری، قاطی شدن محتوا و ظاهر، و اولویت خیلی بالا که دیباگ را سخت می‌کند.

### ۳. ترتیب نوشتن ویژگی‌ها مهم است؟
**جواب:** داخل یک قانون معمولاً نه (آخرین ویژگی تکراری برنده است). بین چند قانون: منبع، specificity و ترتیب فایل مهم است.

### ۴. اگر قانون CSS کار نکرد اول کجا را چک کنم؟
**جواب:** ۱) فایل CSS اصلاً لینک شده؟ ۲) selector درست است؟ ۳) غلط املایی ویژگی/مقدار ۴) قانون دیگری قوی‌تر است؟ (DevTools)

### ۵. کامنت در CSS چطور نوشته می‌شود؟
**جواب:** `/* این یک کامنت است */` — تک‌خط `//` در CSS خام معتبر نیست.

## رنگ و پس‌زمینه

### ۶. Hex با RGB چه فرقی دارد؟ کدام رایج‌تر است؟
**جواب:** هر دو همان مدل نور RGBاند؛ Hex فشرده‌تر است (`#1a5fb4`). در طراحی وب Hex خیلی رایج است؛ HSL برای ساخت پالت راحت‌تر است.

### ۷. `rgba` برای چه به درد می‌خورد؟
**جواب:** وقتی رنگ + شفافیت می‌خواهید (پوشش تیره روی Hero بدون کم‌رنگ کردن متن فرزند مثل `opacity`).

### ۸. فرق `background-color` و `background-image`؟
**جواب:** یکی رنگ یکنواخت است، دیگری تصویر/گرادیان. می‌شود هر دو با هم؛ تصویر روی رنگ می‌نشیند.

### ۹. چرا تصویر پس‌زمینه تکرار می‌شود؟ چطور cover؟
**جواب:** پیش‌فرض `repeat` است. برای Hero معمولاً: `background-size: cover; background-position: center; background-repeat: no-repeat;`

## جعبه: border، margin، padding، size

### ۱۰. فرق margin و padding؟
**جواب:** padding فاصله **داخل** کادر تا محتوا؛ margin فاصله **بیرون** کادر تا همسایه‌ها.

### ۱۱. چرا دو margin روی هم جمع نمی‌شوند؟ (collapse)
**جواب:** در جریان عمودی عادی، marginهای مجاور گاهی یکی می‌شوند (بزرگ‌تر می‌ماند). برای جلوگیری می‌توان از padding/border یا Flex/Grid استفاده کرد.

### ۱۲. `width: 100%` با padding باعث اسکرول افقی می‌شود؛ چرا؟
**جواب:** با `content-box` عرض محتوا ۱۰۰٪ است و padding اضافه می‌شود → از والد بیرون می‌زند. با `box-sizing: border-box` padding داخل همان عرض حساب می‌شود.

### ۱۳. `box-sizing: border-box` چیست؟
**جواب:** می‌گوید width شامل padding و border باشد. تقریباً همه پروژه‌ها با `* { box-sizing: border-box; }` شروع می‌کنند.

### ۱۴. فرق `px` و `em` و `rem`؟ برای فونت کدام؟
**جواب:** `px` ثابت. `em` نسبت به فونت والد (تودرتو گیج می‌شود). `rem` نسبت به ریشه (`html`) — برای فونت و فاصله معمولاً بهتر.

### ۱۵. `outline` با `border` چه فرقی دارد؟
**جواب:** outline در جعبهٔ اندازه حساب نمی‌شود و برای فوکوس کیبورد حیاتی است. حذف کامل outline بدون جایگزین = آسیب a11y.

## متن و فونت

### ۱۶. چطور فونت فارسی وب را وصل کنم؟
**جواب:** یا `@font-face` با فایل‌های محلی، یا لینک سرویس فونت؛ بعد `font-family` با نام همان فونت و یک fallback مثل Tahoma.

### ۱۷. `@font-face` با فونت گوگل چه فرقی دارد؟
**جواب:** `@font-face` کنترل کامل و میزبانی خودتان. گوگل ساده‌تر است ولی به اینترنت/سرویس خارجی وابسته می‌شوید.

### ۱۸. `line-height` را عددی بگذاریم یا با واحد؟
**جواب:** عدد بدون واحد (مثل `1.6`) معمولاً بهتر است؛ با اندازه فونت مقیاس می‌شود.

### ۱۹. ترتیب استایل لینک مهم دارد؟
**جواب:** بله؛ ترتیب کلاسیک LVHA: `:link` → `:visited` → `:hover` → `:active` و جداگانه `:focus`/`:focus-visible`.

## لیست و جدول

### ۲۰. بولت لیست را چطور عوض/حذف کنیم؟
**جواب:** `list-style-type` یا `list-style: none` و در صورت نیاز padding دستی برای تراز.

### ۲۱. جدول را چطور زیبا کنیم بدون layout؟
**جواب:** `border-collapse`، padding سلول، رنگ هدر، `zebra` با `nth-child`. فقط برای دادهٔ جدولی.

---

## تمرین

### ۲۲. چرا کلاس گذاشتم ولی استایل نیامد؟
**جواب:** غلط املایی class در HTML/CSS، مسیر فایل، یا specificity قانون دیگر. در Elements ببینید کلاس روی عنصر هست یا نه.

### ۲۳. چند فایل CSS بهتر است یا یکی؟
**جواب:** برای جونیور یک/چند فایل مرتب (پایه، کامپوننت) کافی است. زیاده‌روی بدون نظم گیج می‌کند.

### ۲۴. از کجا بفهمم کدام قانون برنده شده؟
**جواب:** DevTools → تب Elements → Styles (خط‌خورده‌ها باخته‌اند) و Computed (مقدار نهایی).
