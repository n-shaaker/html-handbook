# ۱) HTML مقدماتی — سوال و جواب

## مفاهیم وب و مرورگر

### ۱. اینترنت با وب چه فرقی دارد؟
**جواب:** اینترنت شبکهٔ سخت‌افزاری/ارتباطی بین کامپیوترهاست. وب (WWW) یکی از سرویس‌های روی اینترنت است: صفحات HTML که با HTTP جابه‌جا می‌شوند. ایمیل و … هم روی اینترنت‌اند ولی «وب» نیستند.

### ۲. مرورگر دقیقاً چه کار می‌کند وقتی آدرس را می‌زنم؟
**جواب:** آدرس را به سرور می‌فرستد (درخواست HTTP)، فایل‌های HTML/CSS/JS/تصویر را می‌گیرد، HTML را به DOM تبدیل می‌کند، CSS را اعمال می‌کند و صفحه را رسم می‌کند؛ بعد JS را اجرا می‌کند.

### ۳. HTML و CSS و JS هرکدام مسئول چه چیزی‌اند؟
**جواب:** HTML محتوا و ساختار. CSS ظاهر. JS رفتار و تعامل. مثل اسکلت، پوست و عضله.

### ۴. چرا بعضی سایت‌ها بدون اینترنت هم باز می‌شوند؟
**جواب:** چون فایل‌ها روی همان کامپیوتر ذخیره شده‌اند (مثل جزوهٔ شما). مرورگر از دیسک می‌خواند، نه از سرور دوردست.

### ۵. localhost یعنی چه؟
**جواب:** آدرس «همین کامپیوتر». وقتی Live Server می‌زنید، سایت از روی سیستم خودتان سرو می‌شود؛ برای ماژول‌ها و `fetch` محلی لازم است.

## ساختار سند

### ۶. چرا باید `<!DOCTYPE html>` باشد؟ بدون آن چه می‌شود؟
**جواب:** به مرورگر می‌گوید HTML5 استاندارد را استفاده کند. بدون آن ممکن است وارد حالت قدیمی (quirks) شود و اندازه‌ها/جعبه عجیب شوند.

### ۷. فرق `head` و `body` چیست؟
**جواب:** `head` اطلاعات صفحه برای مرورگر/موتور جستجو (عنوان، meta، لینک CSS). `body` هر چیزی که کاربر می‌بیند.

### ۸. `lang="fa"` و `dir="rtl"` برای چه لازم‌اند؟
**جواب:** `lang` زبان را به صفحه‌خوان و ابزارها می‌گوید. `dir="rtl"` جهت متن و چیدمان پیش‌فرض را راست‌به‌چپ می‌کند.

### ۹. اگر `charset` نگذاریم چه بلایی سر فارسی می‌آید؟
**جواب:** ممکن است حروف به‌هم‌ریخته (¿ یا مربع) دیده شوند. همیشه `meta charset="UTF-8"` بگذارید.

### ۱۰. viewport را چرا در موبایل می‌گذاریم؟
**جواب:** بدون آن گوشی صفحه را مثل دسکتاپ کوچک‌شده نشان می‌دهد. با `width=device-width` عرض واقعی دستگاه مبنا می‌شود و Media Query درست کار می‌کند.

## تگ‌های متن، لینک، تصویر، لیست، جدول

### ۱۱. فرق `h1` تا `h6` فقط ظاهری است یا معنایی هم هست؟
**جواب:** هر دو. ظاهر را CSS عوض می‌کند؛ معنا سلسله‌مراتب عنوان است (برای سئو و دسترس‌پذیری). `h1` موضوع اصلی صفحه.

### ۱۲. چند تا `h1` در یک صفحه مجاز است؟
**جواب:** از نظر استاندارد می‌شود بیش از یکی، ولی برای جونیور: **یک `h1` واضح** برای موضوع صفحه بهتر و امن‌تر است.

### ۱۳. فرق `<strong>` و `<b>` / `<em>` و `<i>` چیست؟
**جواب:** `strong`/`em` معنا دارند (اهمیت / تأکید). `b`/`i` بیشتر ظاهری‌اند. برای اهمیت واقعی از semantic استفاده کنید.

### ۱۴. لینک داخلی (`#id`) کار نمی‌کند؛ از کجا شروع به دیباگ کنم؟
**جواب:** ۱) همان `id` روی هدف هست؟ ۲) املا یکی است؟ ۳) `id` یکتا است؟ ۴) لینک `href="#id"` است نه فقط متن.

### ۱۵. `target="_blank"` خطر امنیتی دارد؟ `rel` چیست؟
**جواب:** تب جدید می‌تواند به `window.opener` دسترسی داشته باشد. همیشه بگذارید: `rel="noopener noreferrer"`.

### ۱۶. چرا تصویرم نشان داده نمی‌شود؟
**جواب:** مسیر غلط، نام فایل اشتباه، حروف بزرگ/کوچک (روی سرور لینوکس مهم است)، یا فایل جابه‌جا شده. در Network تب DevTools وضعیت 404 را ببینید.

### ۱۷. فرق `ul` و `ol` و کی از `dl` استفاده کنیم؟
**جواب:** `ul` بدون ترتیب، `ol` شماره‌دار، `dl` جفت اصطلاح/توضیح (مثل واژه‌نامه یا راهنمای منو).

### ۱۸. جدول برای چیدمان صفحه درست است یا نه؟
**جواب:** نه برای چیدمان کل صفحه. جدول فقط برای **دادهٔ جدولی**. چیدمان با CSS (Flex/Grid).

## فرم و معنایی

### ۱۹. چرا باید `label` به `input` وصل باشد؟
**جواب:** با کلیک روی متن، فوکوس به ورودی می‌رود؛ صفحه‌خوان هم ارتباط را می‌فهمد. با `for` و `id` یکسان وصل کنید.

### ۲۰. فرق `GET` و `POST` در فرم چیست؟
**جواب:** `GET` داده‌ها را در آدرس می‌گذارد (جستجو، لینک‌پذیر). `POST` بدنهٔ درخواست می‌فرستد (ثبت‌نام، دادهٔ حساس‌تر). بدون سرور واقعی فقط برای تمرین است.

### ۲۱. `required` و `type="email"` کافی‌اند یا JS هم لازم است؟
**جواب:** برای شروع خوب‌اند ولی کافی نیستند: می‌شود دور زد، پیام سفارشی می‌خواهید، منطق پیچیده‌تر. در پروژه واقعی معمولاً هر دو لایه دارید.

### ۲۲. semantic یعنی چه؟ `div` همه‌جا بد است؟
**جواب:** یعنی تگ نقش محتوا را بگوید (`nav`, `main`, `article`). `div` بد نیست وقتی نقش خاصی ندارد؛ همه‌جا `div` یعنی معنا کم است.

### ۲۳. فرق `section` و `article` و `div`؟
**جواب:** `article` محتوای مستقل (پست، کارت خبر). `section` بخش موضوعی داخل صفحه. `div` ظرف بدون معنای خاص.

### ۲۴. `header` و `footer` فقط یکی در صفحه؟
**جواب:** خیر؛ می‌توانند داخل `article`/`section` هم باشند. معمولاً یک جفت برای کل سایت دارید.

## ویژگی‌ها، media، پاسخ‌گویی

### ۲۵. `class` و `id` چه فرقی دارند؟ کی از id؟
**جواب:** `class` تکرارپذیر برای استایل. `id` یکتا در صفحه؛ برای لنگر لینک و `getElementById`. برای استایل روزمره class را ترجیح دهید.

### ۲۶. `iframe` هنوز مجاز است؟ برای چه؟
**جواب:** بله برای نقشه، ویدیو یوتیوب، ویجت. زیاده‌روی نکنید؛ دسترس‌پذیری و عملکرد را در نظر بگیرید.

### ۲۷. ویدیو/صدا بدون کنترل‌ها چطور پخش می‌شود؟
**جواب:** با `autoplay` (اغلب مرورگر بدون `muted` جلویش را می‌گیرد) و `controls` برای کنترل دستی. برای جونیور همیشه `controls` بگذارید.

### ۲۸. SVG را کی به جای PNG بگذاریم؟
**جواب:** آیکن، لوگو، شکل‌های ساده که باید Sharp در هر سایز بمانند. عکس واقعی هنوز JPG/WebP/PNG.

### ۲۹. دسترس‌پذیری حداقلی چیست؟
**جواب:** `alt` معنادار برای تصویر مهم، `lang`، عنوان صفحه، `label` فرم، کنتراست قابل قبول، حرکت با Tab، تگ معنایی.

### ۳۰. برای سئو فقط `title` و `description` کافی است؟
**جواب:** پایهٔ خوب است ولی کافی برای رقابت حرفه‌ای نه. محتوا، ساختار عنوان‌ها، سرعت، لینک‌ها و موبایل هم مهم‌اند. برای جونیور همان پایه + semantic کافی است.

## تمرین و پروژه

### ۳۱. Validator چیست و خطایش را چطور بخوانم؟
**جواب:** ابزار W3C صحت HTML را چک می‌کند. خط شماره و پیام را بخوانید؛ اغلب تگ بسته‌نشده یا ویژگی غلط است. یکی‌یکی درست کنید.

### ۳۲. چرا صفحه‌ام در گوشی ریز/درهم است؟
**جواب:** معمولاً نبود viewport، عرض ثابت خیلی بزرگ، یا تصویر بدون `max-width: 100%`. DevTools را روی موبایل بگذارید.

### ۳۳. از کجا بفهمم تگ را درست بسته‌ام؟
**جواب:** رنگ‌بندی ادیتور، فرمت خودکار، Validator، و Elements در DevTools (درخت تودرتو را ببینید).

### ۳۴. ترتیب ساخت صفحه معرفی از صفر؟
**جواب:** ۱) اسکلت HTML معنایی ۲) محتوای واقعی ۳) CSS پایه (فونت، رنگ، فاصله) ۴) تصویر و لینک ۵) واکنش‌گرایی ساده ۶) Validator و تست Tab.
