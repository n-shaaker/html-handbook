# ۹) پروژه رستوران استاتیک — سوالات پرتکرار از استاد

1. چرا می‌گویید اول Flex و Grid را بخوانم؟ نمی‌توانم از روی CSS پروژه کپی کنم؟
2. از کجا شروع کنم: HTML کامل یا بخش‌بخش؟
3. ساختار پوشهٔ درست برای تصاویر و CSS چیست؟
4. Hero با متن روی عکس خوانا نمی‌شود؛ چه کنم؟
5. گرید غذاها روی موبایل درهم است؛ کدام media query؟
6. فرم رزرو بدون بک‌اند چه فایده‌ای دارد؟
7. `details` / FAQ را خودمان باید استایل کنیم؟
8. چرا navbar من مثل نمونه نیست؟ (فضا، gap، wrap)
9. Validator چه خطاهایی معمولاً در این پروژه می‌گیرم؟
10. کوییزها را باید قبل از دیدن solution تمام کنم؟
11. چقدر اجازه دارم از `style.css` نمونه نگاه کنم؟
12. بعد از این پروژه دقیقاً سراغ کدام ماژول JS بروم؟
13. برای پورتفولیو همین صفحه کافی است یا باید شخصی‌سازی کنم؟
14. دسترسی‌پذیری: alt تصاویر غذا و label فرم را جدی بگیرم؟
