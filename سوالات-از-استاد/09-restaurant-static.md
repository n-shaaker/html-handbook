# ۹) پروژه رستوران استاتیک — سوال و جواب

### ۱. چرا اول Flex و Grid؟ نمی‌شود از CSS کپی کرد؟
**جواب:** کپی ظاهر می‌سازد ولی مهارت نه. در مصاحبه/پروژه بعدی گیر می‌کنید. نمونه را مرجع بگیرید، نه رونویسی کور.

### ۲. از کجا شروع کنم: HTML کامل یا بخش‌بخش؟
**جواب:** بخش‌بخش: هدر → هیرو → یک بخش غذا → فرم → فوتر. هر بخش را در مرورگر ببینید بعد بروید جلو.

### ۳. ساختار پوشهٔ درست؟
**جواب:** مثلاً `index.html`، `css/style.css`، `images/…`. مسیرها نسبی و یکسان با جزوه. فایل CSS را در ریشه قاطی نکنید.

### ۴. Hero خوانا نیست؛ چه کنم؟
**جواب:** گرادیان/لایه تیره روی عکس، رنگ متن روشن، کنتراست را در موبایل هم چک کنید، دکمه را جدا از شلوغی تصویر بگذارید.

### ۵. گرید غذاها روی موبایل درهم است؟
**جواب:** `@media` با یک ستون (`1fr`) یا `auto-fit` با minmax مناسب. عرض ثابت پیکسلی ندهید.

### ۶. فرم رزرو بدون بک‌اند چه فایده‌ای دارد؟
**جواب:** تمرین ساختار، استایل، اعتبارسنجی HTML، و UX. بعداً به سرور وصل می‌شود؛ الان باید درست و دسترس‌پذیر باشد.

### ۷. `details` / FAQ را باید استایل کنیم؟
**جواب:** بله تا با برند یکی شود؛ ولی رفتار باز/بسته پیش‌فرض مرورگر را بدون دلیل سنگین دور نزنید.

### ۸. چرا navbar مثل نمونه نیست؟
**جواب:** نبود `display:flex`، `gap`، تراز، یا عرض کم بدون wrap. RTL و `margin-inline` را چک کنید.

### ۹. Validator چه خطاهایی رایج است؟
**جواب:** تگ بسته‌نشده، `alt` خالی روی تصویر مهم، `label` ناصحیح، ساختار نادرست لیست/جدول.

### ۱۰. کوییزها را قبل از solution؟
**جواب:** بله. اول خودتان؛ solution فقط برای مقایسهٔ نهایی. وگرنه یادگیری نمی‌چسبد.

### ۱۱. چقدر از `style.css` نمونه نگاه کنم؟
**جواب:** برای ایده و نام کلاس OK؛ خط‌به‌خط کپی نه. اگر گیر کردید ۱۰ دقیقه نگاه کنید، ببندید، خودتان بنویسید.

### ۱۲. بعد از این پروژه کدام ماژول JS؟
**جواب:** از [10 JS پایه](../10-JS-پایه/) طبق README ریشه، تا برسید به نسخهٔ تعاملی ۱۱.

### ۱۳. برای پورتفولیو همین صفحه کافی است؟
**جواب:** پایه خوب است؛ حداقل محتوا، رنگ و تصاویر را مال خودتان کنید و Deploy کنید تا لینک زنده داشته باشید.

### ۱۴. a11y: alt و label جدی؟
**جواب:** بله. بدون آن‌ها پروژه «خوب» نیست حتی اگر زیبا باشد. Tab را هم از اول تا آخر صفحه تست کنید.
