# ۶) آزمایشگاه رنگ — سوالات پرتکرار از استاد

1. چرا HSL برای ساخت پالت راحت‌تر از Hex است؟
2. Hue / Saturation / Lightness را با مثال رنگ برند توضیح دهید.
3. کنتراست متن و پس‌زمینه را چطور سریع بفهمم قابل قبول است؟
4. فقط با رنگ قرمز خطای فرم را نشان بدهم کافی است؟
5. چند رنگ در یک سایت جونیور کافی است؟
6. متغیرهای رنگ را کجا متمرکز کنم؟
7. آزمایشگاه رنگ به JS نیاز دارد؛ اگر هنوز JS نخوانده‌ام چه کنم؟
8. Dark Mode فقط برعکس کردن رنگ‌هاست؟
