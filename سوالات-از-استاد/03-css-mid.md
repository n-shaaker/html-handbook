# ۳) CSS میانی — سوالات پرتکرار از استاد

## Display، اندازه، موقعیت
1. فرق `block`، `inline`، `inline-block` چیست؟
2. چرا `width` روی `inline` کار نمی‌کند؟
3. `max-width` کی به‌جای `width` بهتر است؟
4. `position: relative` و `absolute` را با مثال درب و قاب توضیح دهید.
5. `fixed` با `sticky` چه فرقی دارد؟
6. `z-index` چرا گاهی کار نمی‌کند؟ (stacking context)
7. `overflow: hidden` چه بلایی سر دراپ‌داون می‌آورد؟

## Float و تراز قدیمی
8. هنوز باید Float یاد بگیریم؟ کجا هنوز دیده می‌شود؟
9. `clear` چیست؟
10. وسط‌چین افقی با `margin: auto` چه شرطی دارد؟

## انتخابگرها و شبه‌کلاس/عنصر
11. فرق ` ` (فرزند نسلی) با `>` چیست؟
12. `+` و `~` را کی استفاده کنیم؟
13. `:hover` روی موبایل reliably نیست؛ چه کنیم؟
14. فرق `:focus` و `:focus-visible`؟
15. `::before` و `::after` بدون `content` کار می‌کنند؟
16. Attribute selector مثل `[type="email"]` کی مفید است؟

## Navbar، dropdown، فرم، واحدها
17. منوی افقی را بدون Flex چطور می‌ساختند؟ چرا الان Flex بهتر است؟
18. دراپ‌داون فقط با CSS ممکن است؟ محدودیت a11y چیست؟
19. استایل `input` در مرورگرهای مختلف فرق دارد؛ نرمالایز یعنی چه؟
20. `vh` / `vw` روی موبایل مشکل دارند؟
21. `calc` و `clamp` را با یک مثال کاربردی بگویید.

## Media Queries و حرکت (درس‌های جدید)
22. `max-width` با `min-width` کدام mobile-first است؟
23. بدون meta viewport چرا MQ درست حس نمی‌شود؟
24. چند breakpoint کافی است؟
25. `transition` روی چه ویژگی‌هایی سبک‌تر است؟
26. چرا `transition` روی `display` کار نمی‌کند؟
27. `animation` با `transition` چه فرقی دارد؟
28. `prefers-reduced-motion` را چرا باید احترام بگذاریم؟

## اشتباه‌های کلاسی
29. منو با `position` درست شد ولی روی موبایل شکست؛ از کجا شروع کنم؟
30. قبل از Flex/Grid این فصل را تا کجا واجب است بخوانم؟
