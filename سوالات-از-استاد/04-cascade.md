# ۴) آبشاری + متغیرها — سوال و جواب

## آبشار و اولویت

### ۱. Cascading دقیقاً یعنی چه؟
**جواب:** قوانین CSS روی هم می‌ریزند و برای هر ویژگی فقط **یک مقدار نهایی** می‌ماند؛ مرورگر با قواعد منبع، !important، specificity و ترتیب برنده را انتخاب می‌کند.

### ۲. اگر دو قانون هم‌قدرت باشند کدام برنده است؟
**جواب:** آن‌که در CSS **پایین‌تر** آمده (یا فایلی که دیرتر لینک شده)، به‌شرط برابر بودن بقیهٔ شرایط.

### ۳. Specificity را چطور سریع حساب کنیم؟
**جواب:** تقریباً: id قوی‌تر از class/attribute/pseudo-class، آن‌ها قوی‌تر از نام تگ/pseudo-element. تعداد بیشتر در همان سطح برنده است. اینلاین از همهٔ این‌ها (بدون !important) قوی‌تر است.

### ۴. چرا `#box` از `.box` قوی‌تر است؟
**جواب:** چون id در مقیاس specificity وزن بیشتری دارد؛ برای یک عنصر طراحی شده و یکتاست.

### ۵. استایل اینلاین از کلاس قوی‌تر است؟
**جواب:** بله، معمولاً بر کلاس و تگ می‌برد مگر با `!important` در stylesheet (و حتی آن هم قواعد پیچیده‌تری دارد). برای همین اینلاین دیباگ را سخت می‌کند.

### ۶. `!important` کی مجاز است؟
**جواب:** تقریباً هیچ‌وقت در کد عادی. فقط استثنای کوتاه (مثلاً override ابزار سوم‌شخص). اگر زیاد لازم شد، معماری/specificity مشکل دارد.

### ۷. ترتیب چند فایل CSS مهم است؟
**جواب:** بله. بین قوانین هم‌قدرت، فایلی که **دیرتر** در HTML لینک شده برنده است.

### ۸. Inheritance یعنی چه؟
**جواب:** بعضی ویژگی‌ها (مثل `color`, `font-family`) به فرزند می‌رسند. `margin` و `border` معمولاً ارث نمی‌برند.

### ۹. `inherit` و `initial` و `unset`؟
**جواب:** `inherit` از والد بگیر. `initial` مقدار اولیهٔ مشخصات. `unset` مثل inherit برای ارثی‌ها و initial برای بقیه.

### ۱۰. دو کلاس روی یک عنصر؛ ترتیب در HTML مهم است؟
**جواب:** **خیر.** ترتیب کلاس در `class="a b"` اولویت نمی‌سازد؛ ترتیب و قدرت قوانین در فایل CSS مهم است.

**جواب:** تب Styles: قوانین خط‌خورده باخته‌اند. منبع و specificity کنارشان دیده می‌شود.

## متغیرهای CSS

### ۱۳. `--brand` کجا تعریف شود؟
**جواب:** برای تم سراسری روی `:root`. برای تم یک بخش، روی همان والد (مثلاً `.card` یا `.theme-dark`).

### ۱۴. `var(--x)` اگر تعریف نشده باشد؟
**جواب:** ویژگی نامعتبر می‌شود مگر مقدار جایگزین بدهید: `var(--x, #333)`.

### ۱۵. متغیر برای Dark Mode چطور؟
**جواب:** مقادیر روشن در `:root`؛ با کلاس `.theme-dark` روی `html`/`body` همان نام‌ها را با رنگ تیره عوض کنید.

### ۱۶. فرق با متغیر Sass؟
**جواب:** Sass در build حذف/جایگزین می‌شود. متغیر CSS در مرورگر زنده است و می‌تواند در runtime عوض شود.

### ۱۷. می‌شود در JS متغیر CSS را عوض کرد؟
**جواب:** بله؛ مثلاً `element.style.setProperty('--brand', '#0b6e4f')`. برای جونیور بعد از DOM کافی است بدانید ممکن است.
