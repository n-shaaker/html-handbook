# ۴) آبشاری بودن CSS + متغیرها — سوالات پرتکرار از استاد

## آبشار و اولویت
1. Cascading دقیقاً یعنی چه؟
2. اگر دو قانون هم‌قدرت باشند کدام برنده است؟
3. Specificity را چطور سریع حساب کنیم؟ (id / class / element)
4. چرا `#box` از `.box` قوی‌تر است؟
5. استایل اینلاین از کلاس قوی‌تر است؟
6. `!important` کی مجاز است و کی نشانهٔ طراحی بد؟
7. چند فایل CSS لینک کردم؛ ترتیب `link` مهم است؟
8. Inheritance یعنی چه ویژگی‌هایی ارث می‌برند؟ (`color` بله، `margin` معمولاً نه)
9. `inherit` و `initial` و `unset` را ساده بگویید.
10. دو کلاس روی یک عنصر؛ ترتیب در HTML مهم است یا در CSS؟

## دیباگ اولویت
11. در DevTools از کجا ببینم کدام قانون خط خورده؟
12. قانونم هست ولی اعمال نمی‌شود؛ چک‌لیست سه‌مرحله‌ای چیست؟

## متغیرهای CSS
13. `--brand` کجا تعریف شود بهتر است؟ (`:root` یا کامپوننت)
14. `var(--x)` اگر تعریف نشده باشد چه می‌شود؟ مقدار جایگزین؟
15. متغیر برای Dark Mode چطور کار می‌کند؟
16. فرق متغیر CSS با متغیر Sass چیست؟
17. می‌شود در JS متغیر CSS را عوض کرد؟ (سطح اشاره)
