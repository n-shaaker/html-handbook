۱۹) حلقه For

حلقه (Loop) یعنی یک کار را چند بار تکرار کنید، بدون اینکه همان دستور را به تعداد تکرار در کد کپی کنید. حلقهٔ for وقتی مناسب است که از قبل بدانید تکرار چند بار، یا از چه شماره‌ای تا چه شماره‌ای، انجام می‌شود. سه بخش داخل پرانتز این محدوده را مشخص می‌کنند: از کجا شروع شود، تا کی ادامه پیدا کند و بعد از هر دور شمارنده چقدر عوض شود.

for (let i = 1; i <= 5; i++) {
  console.log("تکرار شماره " + i);
}





let i = 1 فقط یک بار، قبل از شروع، شمارنده را می‌سازد. پیش از هر دور، شرط i <= 5 بررسی می‌شود. اگر درست باشد، دستور داخل آکولاد اجرا می‌شود و بعد i++ یکی به شمارنده اضافه می‌کند. وقتی i به ۶ برسد شرط غلط می‌شود و حلقه تمام می‌شود. به همین دلیل عددهای ۱ تا ۵ چاپ می‌شوند، نه ۶.





بخشمثالکی اجرا می‌شود


شروعlet i = 1یک بار، اول کار


شرطi <= 5قبل از هر تکرار؛ اگر false شد حلقه تمام می‌شود


گامi++بعد از هر تکرار





سه بخش داخل پرانتز با ; از هم جدا می‌شوند. گام لازم نیست همیشه i++ باشد؛ می‌تواند i += 10 یا i-- (شمارش معکوس) هم باشد.



مثال: جمع اعداد ۱ تا ۱۰۰



let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;
}
console.log(sum);   // 5050










sum بیرون از حلقه ساخته شده تا حاصل هر دور از بین نرود. در هر تکرار، مقدار فعلی i به جمع اضافه می‌شود. اگر sum را داخل حلقه با let می‌ساختید، هر دور از صفر شروع می‌شد و نتیجهٔ نهایی فقط عدد آخر بود. بعد از پایان حلقه، متغیر جمع هنوز وجود دارد و می‌توان آن را چاپ کرد.



مثال کاربردی: جدول تبدیل دما (گام ۱۰تایی)



for (let c = 0; c <= 40; c += 10) {
  const f = c * 9 / 5 + 32;
  console.log(`${c}°C = ${f}°F`);
}










شمارنده از صفر شروع می‌شود، تا ۴۰ ادامه دارد و به‌جای یکی‌یکی، هر بار ۱۰ واحد زیاد می‌شود. داخل هر دور، همان دما با فرمول به فارنهایت تبدیل می‌شود و هر دو عدد در یک رشتهٔ قالبی چاپ می‌شوند. چون گام ۱۰ است، پنج خط دارید: ۰، ۱۰، ۲۰، ۳۰ و ۴۰.



محدوده متغیر حلقه (let در for)



متغیری که با let در پرانتز for ساخته شود، فقط داخل حلقه وجود دارد. اگر بعد از حلقه به مقدار نهایی نیاز دارید، متغیر را قبل از حلقه تعریف کنید.



for (let i = 1; i <= 3; i++) {
  // i فقط اینجا قابل استفاده است
}
console.log(typeof i);   // undefined ← i بیرون از حلقه وجود ندارد

let tries;
for (tries = 1; tries <= 3; tries++) {
  // ...
}
console.log(tries);      // 4 ← بعد از آخرین تکرار، شرط 4 <= 3 غلط شد و حلقه تمام شد










در حلقهٔ اول، i جزئی از خود for است و بعد از آکولاد دیگر وجود ندارد؛ به همین دلیل typeof i رشتهٔ "undefined" است و خطا نمی‌دهد. در حلقهٔ دوم، tries قبل از حلقه ساخته شده تا بعد از پایان هم قابل خواندن باشد. وقتی شرط tries <= 3 غلط می‌شود، گام قبلی شمارنده را به ۴ رسانده است؛ پس مقدار باقی‌مانده ۴ است، نه ۳.



در کدهای قدیمی for (var i = 0; ...) زیاد می‌بینید. var بیرون از حلقه هم باقی می‌ماند و اگر داخل حلقه رویداد بسازید، همهٔ رویدادها ممکن است آخرین مقدار همان متغیر را ببینند. در کد تازه شمارنده را با let بسازید. var را فقط وقتی نگه دارید که دارید کد قدیمی را می‌خوانید و به این تفاوت آگاهید.



حلقه روی حرف‌های یک رشته



let word = "سلام";
for (let i = 0; i < word.length; i++) {
  console.log(i, word[i]);
}










طول رشته تعداد دورها را مشخص می‌کند و i شمارهٔ هر حرف است. چون شماره از صفر شروع می‌شود، شرط باید i < word.length باشد تا آخرین حرف هم خوانده شود و یک خانهٔ بعد از پایان رشته خوانده نشود. در هر دور، هم شماره و هم خود حرف چاپ می‌شود.



چون شماره‌ها از ۰ شروع می‌شوند، شرط i < word.length است، نه i <= word.length. با <= یک دور اضافه اجرا می‌شود و word[4] برابر undefined است.



for...of — ساده‌تر برای پیمایش



let vowels = 0;
for (const letter of "JavaScript") {
  if ("aeiou".includes(letter.toLowerCase())) {
    vowels++;
  }
}
console.log("تعداد حروف صدادار:", vowels);   // 3










for...of به‌جای شماره، خود هر حرف رشته را یکی‌یکی در letter می‌گذارد. toLowerCase حرف را کوچک می‌کند تا هم A و هم a با فهرست مصوت‌ها مقایسه شوند. includes می‌گوید آن حرف داخل "aeiou" هست یا نه. اگر باشد، شمارنده یکی زیاد می‌شود. در پایان، تعداد مصوت‌های کلمه چاپ می‌شود.



در for...of به شماره (index) نیاز نداریم و هر بار مستقیم خود حرف را می‌گیریم. اگر شماره هم لازم بود، از همان for معمولی استفاده کنید.



مثال زنده: جدول ضرب



const numInput = document.getElementById("table-num");
const tableBtn = document.getElementById("table-btn");
const list = document.getElementById("table-list");

tableBtn.addEventListener("click", function () {
  const n = Number(numInput.value);
  let html = "";
  for (let i = 1; i <= 10; i++) {
    html += `<li>${n} × ${i} = ${n * i}</li>`;
  }
  list.innerHTML = html;
});








    

    


    با کلیک، متن کادر به عدد تبدیل می‌شود. متغیر html خالی شروع می‌شود و حلقه ده بار یک آیتم فهرست به آن اضافه می‌کند؛ هر آیتم حاصل‌ضرب عدد در شمارنده است. بعد از تمام شدن حلقه، کل این متن یک‌باره داخل ul گذاشته می‌شود. چون n عدد است، متن تایپ‌شدهٔ کاربر مستقیم به‌صورت HTML تفسیر نمی‌شود.
    


    اشتباه رایج: حلقه بی‌پایان: for (let i = 0; i < 10; i--). چون i هیچ‌وقت به ۱۰ نمی‌رسد، مرورگر هنگ می‌کند!
    


    در اینجا innerHTML مشکلی ندارد، چون n با Number() به عدد تبدیل شده و متن کاربر مستقیم وارد HTML نمی‌شود. HTML را اول در متغیر html جمع کرده‌ایم و یک بار در صفحه گذاشته‌ایم که سریع‌تر از ده بار تغییر صفحه است.
    


    تمرین: (۱) با حلقه for همه اعداد زوج بین ۱ تا ۳۰ را چاپ کنید (دو راه: گام i += 2 یا شرط i % 2 === 0). (۲) با حلقه یک «مثلث ستاره» ۵ طبقه در Console بسازید (راهنما: "*".repeat(i)). (۳) قسط‌بندی: کالایی ۱۲٬۰۰۰٬۰۰۰ تومانی در ۶ قسط مساوی پرداخت می‌شود؛ با حلقه برای هر ماه بنویسید «قسط ماه ۱: ۲٬۰۰۰٬۰۰۰ تومان — باقیمانده: ۱۰٬۰۰۰٬۰۰۰ تومان».
