# مبحث ۱۲ — بولین و مقایسه

**درس مرتبط:** [بولین و مقایسه (Booleans & Comparisons)](../../../pages/15-booleans-comparisons.html)

> هر تمرین را در `ex-n.html` و `ex-n.js` بنویسید. تمرین ۱ و ۲ در Console و تمرین ۳ در صفحه است.
> در این مبحث هنوز `if` نداریم؛ همه چیز با عبارت‌های `true`/`false` حل می‌شود.
> پاسخ استاد در پوشه `solution` است؛ اول خودتان حل کنید.

---

## تمرین ۱ — اول حدس، بعد اجرا ⭐

**هدف:** فهمیدن فرق `===` و `==`، مقایسه رشته‌ها و truthy/falsy.

**صورت مسئله:** قبل از اجرای هر خط، حدس خودتان را به‌صورت توضیح بالای آن بنویسید؛ بعد اجرا کنید و مقایسه کنید.

**الزامات:**
- هفت عبارت: `"5" === 5`، `"5" == 5`، `"10" < "9"`، `10 < 9`، `Boolean("0")`، `!""`، `"apple" === "Apple"`.
- بالای هر خط یک توضیح `// حدس من: ...`.
- هر خط، خود عبارت و نتیجه‌اش را چاپ کند.

**تست‌ها:**
- اجرای فایل ← `false` / `true` / `true` / `false` / `true` / `true` / `false`

---

## تمرین ۲ — قانون‌های تخفیف موزه ⭐⭐

**هدف:** ترکیب شرط‌ها با `&&`، `||` و `!` داخل تابعی که بولین برمی‌گرداند.

**صورت مسئله:** موزه ملی دو قانون دارد: (۱) تخفیف دانشجویی برای سن ۱۸ تا ۳۰ **و** داشتن کارت دانشجویی؛ (۲) ورود رایگان برای زیر ۵ سال **یا** ۶۵ سال و بیشتر.

**الزامات:**
- `hasStudentDiscount(age, hasCard)` و `hasFreeEntry(age)`؛ هر دو مستقیم یک عبارت بولین را `return` کنند.
- حداقل ۶ نفر مختلف را بررسی و چاپ کنید.
- با `!` بگویید یک نفر بلیت کامل می‌خرد یا نه.

**تست‌ها:**
- `hasStudentDiscount(22, true)` ← `true`
- `hasStudentDiscount(22, false)` ← `false`
- `hasStudentDiscount(35, true)` ← `false`
- `hasFreeEntry(3)` ← `true`، `hasFreeEntry(70)` ← `true`، `hasFreeEntry(40)` ← `false`
- `!hasFreeEntry(40)` ← `true`

---

## تمرین ۳ — بررسی زنده فرم ثبت‌نام ⭐⭐⭐

**هدف:** ساختن متغیرهای بولین از مقایسه طول و برابری رشته‌ها و نمایش زنده آن‌ها.

**صورت مسئله:** فرم ثبت‌نام یک سایت باید همان‌طور که کاربر تایپ می‌کند بگوید نام کاربری و رمز معتبرند یا نه.

**الزامات:**
- دو کادر با `label`: نام کاربری (متنی) و رمز (`type="password"`).
- قانون‌ها: نام کاربری (بعد از `trim()`) حداقل ۳ حرف؛ رمز حداقل ۸ حرف **و** مخالف نام کاربری.
- یک تابع `checkForm()` که به رویداد `input` **هر دو** کادر وصل شود.
- سه خط نتیجه: «نام کاربری معتبر: …»، «رمز معتبر: …»، «اجازه ثبت‌نام: …».

**تست‌ها:**
- `sa` و `12345678` ← `false` / `true` / `false`
- `sara` و `1234` ← `true` / `false` / `false`
- `sara1234` و `sara1234` ← `true` / `false` (رمز همان نام کاربری است) / `false`
- `sara` و `Sara1405!` ← `true` / `true` / `true`

---

## اشتباه‌های رایج این مبحث

- `=` به‌جای `===`: اولی مقدار می‌دهد، دومی مقایسه می‌کند.
- نوشتن `18 <= age <= 30`؛ باید `age >= 18 && age <= 30` نوشت.
- مقایسه عددهایی که هنوز رشته‌اند: `"10" < "9"` برابر `true` است!
- فکر کردن اینکه `"0"` یا `"false"` falsy هستند؛ هر رشته غیرخالی truthy است.
