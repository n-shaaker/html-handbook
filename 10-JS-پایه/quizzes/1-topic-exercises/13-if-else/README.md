# مبحث ۱۳ — شرط‌ها (if...else)

**درس مرتبط:** [شرط‌ها (If...Else)](../../../pages/16-if-else.html)

> هر تمرین را در `ex-n.html` و `ex-n.js` بنویسید. تمرین ۱ و ۲ در Console و تمرین ۳ در صفحه است.
> پاسخ استاد در پوشه `solution` است؛ اول خودتان حل کنید.

---

## تمرین ۱ — سلام به‌موقع ⭐

**هدف:** زنجیره `if / else if / else` با ترتیب درست شرط‌ها.

**صورت مسئله:** اپلیکیشن بانک بالای صفحه بر اساس ساعت به کاربر سلام می‌کند.

**الزامات:**
- تابع `greeting(hour)` که متن مناسب را `return` کند.
- قبل از ۱۲: «صبح بخیر ☀️»، از ۱۲ تا قبل از ۱۷: «ظهر بخیر»، بقیه: «عصر بخیر 🌙».
- ساعت کمتر از ۰ یا بیشتر از ۲۳: «ساعت نامعتبر است» (این شرط **اول** بررسی شود).
- حداقل ۵ ساعت مختلف را امتحان کنید.

**تست‌ها:**
- `8` ← `صبح بخیر ☀️`
- `12` ← `ظهر بخیر`
- `16` ← `ظهر بخیر`
- `20` ← `عصر بخیر 🌙`
- `25` ← `ساعت نامعتبر است`

---

## تمرین ۲ — هزینه ارسال فروشگاه ⭐⭐

**هدف:** شرط با چند حالت و مقایسه رشته، و شرط سه‌تایی (`? :`) برای انتخاب ساده.

**صورت مسئله:** فروشگاه اینترنتی برای خرید یک میلیون تومان و بیشتر ارسال رایگان دارد؛ وگرنه تهران ۳۵٬۰۰۰ و شهرهای دیگر ۵۰٬۰۰۰ تومان.

**الزامات:**
- تابع `shippingCost(cartTotal, city)` که هزینه را برگرداند.
- شرط مبلغ **قبل از** شرط شهر بررسی شود.
- مقایسه شهر با `===`.
- یک متغیر `stock` و با شرط سه‌تایی متن «موجود» یا «ناموجود» بسازید.

**تست‌ها:**
- `(1200000, "یزد")` ← `0`
- `(400000, "تهران")` ← `35000`
- `(400000, "یزد")` ← `50000`
- `(1000000, "تهران")` ← `0` (دقیقاً یک میلیون هم رایگان است)
- `stock = 0` ← `وضعیت انبار: ناموجود`

---

## تمرین ۳ — قیمت بلیت سینما ⭐⭐⭐

**هدف:** اعتبارسنجی ورودی با «بازگشت زودهنگام» (`return`) و بعد محاسبه با شرط.

**صورت مسئله:** باجه بلیت سینما قیمت را بر اساس سن حساب می‌کند: زیر ۵ سال رایگان، زیر ۱۲ سال ۶۰٬۰۰۰، ۶۵ سال و بیشتر ۵۰٬۰۰۰ و بقیه ۱۰۰٬۰۰۰ تومان.

**الزامات:**
- یک کادر عددی «سن» با `label` و دکمه «قیمت را ببین».
- کادر خالی ← «لطفاً سن را وارد کنید.»؛ سن کمتر از ۰ یا بیشتر از ۱۲۰ ← «سن باید بین ۰ تا ۱۲۰ باشد.»
- بعد از هر پیام خطا با `return` بیرون بیایید (کد اصلی داخل `else` نرود).
- پیام خطا قرمز و نتیجه سبز باشد؛ رنگ با `classList` عوض شود.
- قیمت با `toLocaleString("fa-IR")` نمایش داده شود.

**تست‌ها:**
- (خالی) ← `لطفاً سن را وارد کنید.` (قرمز)
- `-3` ← `سن باید بین ۰ تا ۱۲۰ باشد.`
- `3` ← `ورود رایگان است 🎈`
- `8` ← `قیمت بلیت: ۶۰٬۰۰۰ تومان`
- `30` ← `قیمت بلیت: ۱۰۰٬۰۰۰ تومان`
- `70` ← `قیمت بلیت: ۵۰٬۰۰۰ تومان`

---

## اشتباه‌های رایج این مبحث

- ترتیب غلط: اگر `hour < 17` قبل از `hour < 12` بیاید، صبح هیچ‌وقت چاپ نمی‌شود.
- `if (city = "تهران")` با یک `=`؛ همیشه درست می‌شود!
- بررسی نکردن کادر خالی؛ `Number("")` صفر است و «ورود رایگان» نشان داده می‌شود.
- شرط سه‌تایی تودرتو برای بیش از دو حالت؛ آنجا `if...else` خواناتر است.
