## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«مرورگر HTML را به یک درخت شیء به نام DOM (Document Object Model) تبدیل می‌کند. JavaScript با DOM عنصرها را پیدا می‌کند، متن‌شان را عوض می‌کند و به کلیک گوش می‌دهد. بدون این مفهوم، درس رویدادها گیج‌کننده است.»

«بعد از این: رویدادها · عمیق‌تر در میانی: انتخاب DOM»

«اگر عنصر پیدا نشود نتیجه null است — قبل از استفاده چک کنید. درس عمیق‌تر DOM در JS میانی است.»

«اشتباه: اسکریپت را در head بدون defer بگذارید؛ DOM هنوز آماده نیست.»

**روی جزوه این عناوین را دنبال کنید:** *۱۰) DOM چیست؟* · *مثال زنده* · *عنوان اولیه*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const title = document.getElementById("demo-title");
const box = document.querySelector(".demo-box");
title.textContent = "سلام از DOM";
box.style.backgroundColor = "#0b6e4f";
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
