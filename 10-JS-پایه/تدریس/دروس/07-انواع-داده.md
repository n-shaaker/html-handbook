## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«هر مقداری که در JavaScript می‌نویسید یک «نوع» دارد و نوع مشخص می‌کند با آن مقدار چه کارهایی مجاز است. متن را نمی‌شود مثل عدد تقسیم کرد و عدد را نمی‌شود مثل متن برش داد، مگر اینکه اول نوعش را عوض کنید. عملگر typeof نوع یک مقدار را به‌صورت متن برمی‌گرداند تا بتوانید قبل از محاسبه بفهمید با چه چیزی طرف هستید.»

«typeof را جلوی مقدار می‌نویسند و نتیجه یک رشته است، مثل "string" یا "number" . آرایه و شیء هر دو از نظر typeof برابر "object" هستند، پس این عملگر به‌تنهایی آرایه را تشخیص نمی‌دهد. typeof null هم به دلیل یک رفتار قدیمی زبان "object" برمی‌گرداند، نه "null" . عددی که داخل گیومه باشد متن است، حتی اگر فقط رقم داشته باشد.»

«در JavaScript نوع به مقدار بستگی دارد، نه به متغیر. یک متغیر let می‌تواند اول عدد و بعد متن نگه دارد:»

«متغیر value اول عدد ۱۰ را نگه می‌دارد، پس نوعش number است. بعد همان متغیر متن «ده» را می‌گیرد و نوعش به string عوض می‌شود. این رفتار را تایپ پویا می‌نامند: نوع به مقدار فعلی وابسته است، نه به نام متغیر. با const هم نوع عوض نمی‌شود، چون اصلاً نمی‌توان مقدار را جایگزین کرد.»

**روی جزوه این عناوین را دنبال کنید:** *۷) انواع داده (Data Types)* · *مثال: typeof* · *نوع متغیر می‌تواند عوض شود (Dynamic Typing)* · *تبدیل نوع*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
console.log(typeof "سارا");             // string
console.log(typeof 25);                 // number
console.log(typeof true);               // boolean
console.log(typeof undefined);          // undefined
console.log(typeof { name: "علی" });    // object
console.log(typeof [1, 2, 3]);          // object ← آرایه هم object است!
console.log(typeof null);               // object ← یک اشتباه قدیمی در خود JavaScript
console.log(typeof "25");               // string ← عدد داخل گیومه، متن است
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let value = 10;
console.log(typeof value);   // number
value = "ده";
console.log(typeof value);   // string
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
console.log(Number("42") + 8);     // 50  ← متن به عدد
console.log(String(100) + "%");    // 100% ← عدد به متن
console.log(Number("سلام"));       // NaN یعنی «عدد نیست» (Not a Number)
console.log(Number(""));           // 0   ← متن خالی صفر می‌شود؛ مراقب باشید!
console.log(typeof NaN);           // number ← NaN با اینکه «عدد نیست»، از نوع number است
console.log(Boolean(0), Boolean(1), Boolean(""));   // false true false
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«Number("42") متنی را که فقط رقم است به عدد تبدیل می‌کند تا جمع واقعی انجام شود. String(100) عدد را به متن تبدیل می‌کند تا بتوان آن را به علامت درصد چسباند. اگر متن قابل تبدیل به عدد نباشد، نتیجه NaN است؛ یعنی «این یک عدد معتبر نیست». متن خالی با Number به صفر تبدیل می‌شود و این تبدیل گاهی بی‌سروصدا جواب محاسبه را عوض می‌کند. Boolean مقدار را به درست یا غلط تبدیل می‌کند: صفر و متن خالی غلط می‌شوند و عدد غیرصفر درست.»

«NaN وقتی به وجود می‌آید که یک محاسبه عددی جواب معنادار نداشته باشد؛ مثلاً Number("سلام") یا "سیب" * 2 . هر محاسبه‌ای که یک طرفش NaN باشد، نتیجه‌اش هم NaN می‌شود. جزئیات بیشتر در درس «اعداد».»

«Boolean() هر مقداری را به true یا false تبدیل می‌کند. مقدارهایی مثل 0 ، "" ، null ، undefined و NaN به false تبدیل می‌شوند؛ به آن‌ها falsy می‌گوییم. در درس «بولین و مقایسه» کامل بررسی‌شان می‌کنیم.»

«undefined یعنی «هنوز مقدار نگرفته» و null یعنی «برنامه‌نویس عمداً خالی گذاشته».»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
