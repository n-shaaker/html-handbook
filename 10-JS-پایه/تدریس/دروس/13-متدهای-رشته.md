## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«متد یعنی کاری که می‌شود روی یک مقدار انجام داد و با نقطه بعد از آن مقدار نوشته می‌شود. متدهای رشته، رشتهٔ اصلی را تغییر نمی‌دهند؛ یک رشتهٔ جدید برمی‌گردانند. اگر نتیجه را در متغیر نریزید یا همان لحظه استفاده نکنید، رشتهٔ قبلی همان‌طور که بود باقی می‌ماند. این رفتار با تغییرناپذیر بودن رشته، که در درس قبل دیدید، هماهنگ است.»

«trim فاصله‌های ابتدا و انتهای متن را برمی‌دارد و toLowerCase حروف انگلیسی را کوچک می‌کند. چون این دو متد پشت سر هم نوشته شده‌اند، اول فاصله‌ها حذف می‌شوند و بعد روی همان نتیجه حروف کوچک می‌شود. کروشه دور مقدار فقط برای این است که فاصله‌های پنهان در خروجی دیده شوند. متغیر email خودش عوض نشده و متن اولیه هنوز فاصله و حروف بزرگ دارد.»

«می‌شود متدها را پشت سر هم نوشت (Chaining): email.trim().toLowerCase() . اول trim اجرا می‌شود، بعد روی نتیجه‌اش toLowerCase.»

«slice با یک عدد از همان شماره تا آخر رشته را برمی‌دارد و با عدد منفی از انتها می‌شمارد. includes فقط وجود یک تکه را با true یا false جواب می‌دهد و به بزرگی و کوچکی حروف حساس است. indexOf شمارهٔ شروع همان تکه را می‌دهد. replace یک رشتهٔ تازه می‌سازد و text را عوض نمی‌کند؛ به همین دلیل چاپ بعدی هنوز جملهٔ اصلی است. split(" ") رشته را از روی هر فاصله می‌بُرد و یک فهرست (آرایه) از کلمه‌ها برمی‌گرداند.»

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let email = "   Sara@Example.COM  ";
let clean = email.trim().toLowerCase();
console.log("[" + email + "]");
console.log("[" + clean + "]");
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let text = "I love JavaScript";
console.log(text.slice(7));                 // JavaScript ← از شماره 7 تا آخر
console.log(text.slice(-10));               // JavaScript ← 10 حرف آخر
console.log(text.includes("love"));         // true
console.log(text.includes("Love"));         // false ← به بزرگی و کوچکی حروف حساس است
console.log(text.indexOf("Java"));          // 7
console.log(text.replace("love", "like"));  // I like JavaScript
console.log(text);                          // I love JavaScript ← رشته اصلی عوض نشد
console.log(text.split(" "));               // ["I","love","JavaScript"]
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function maskPhone(phone) {
  const clean = phone.trim();
  return clean.slice(0, 4) + "***" + clean.slice(-4);
}

console.log(maskPhone("09121234567"));     // 0912***4567
console.log(maskPhone(" 09351112233 "));   // 0935***2233
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«در slice(start, end) حرفِ شماره end جزو نتیجه نیست : "Hello".slice(1, 4) حرف‌های شماره ۱، ۲ و ۳ را برمی‌دارد.»

«تابع اول فاصله‌های اطراف شماره را حذف می‌کند. slice(0, 4) چهار رقم اول را برمی‌دارد، سه ستاره وسط گذاشته می‌شود و slice(-4) چهار رقم آخر را می‌آورد. بقیهٔ رقم‌ها در نتیجه نیستند. چون تابع رشتهٔ جدید برمی‌گرداند، شمارهٔ اصلی اگر بیرون از تابع در متغیر دیگری باشد دست‌نخورده می‌ماند.»

«با هر تغییر در کادر، رویداد input تابع را اجرا می‌کند. length تعداد حرف‌های متن خام را می‌دهد، از جمله فاصله. برای شمردن کلمه‌ها اول فاصله‌های دو سر متن حذف می‌شود. اگر بعد از آن چیزی مانده باشد، split متن را از روی فاصله‌ها جدا می‌کند و length تعداد تکه‌ها را می‌شمارد. اگر کادر خالی باشد، تعداد کلمه صفر می‌ماند تا یک رشتهٔ خالی به‌اشتباه یک کلمه حساب نشود.»

«اگر از split(" ") استفاده کنیم، دو فاصله پشت سر هم یا رفتن به خط بعد، کلمه‌ها را اشتباه می‌شمارد. /\s+/ یک «الگو» (Regular Expression) است یعنی «یک یا چند فاصله، تب یا خط جدید». فعلاً همین قدر کافی است؛ الگوها را در دوره‌های بعد کامل یاد می‌گیرید. شرط if را هم در درس ۱۶ کامل می‌بینیم.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
