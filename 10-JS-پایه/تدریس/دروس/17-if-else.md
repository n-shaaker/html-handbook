## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«برنامه بدون شرط همیشه یک مسیر را اجرا می‌کند. با if می‌گویید: اگر این شرط درست بود، دستورهای داخل آکولاد اول را اجرا کن. else مسیر جایگزین است و فقط وقتی اجرا می‌شود که شرط غلط باشد. شرط باید عبارتی باشد که به درست یا غلط تعبیر شود؛ معمولاً همان مقایسه‌هایی که در درس قبل دیدید.»

«let hour = 14; if (hour < 12) { console.log("صبح بخیر"); } else { console.log("عصر بخیر"); // این اجرا می‌شود، چون 14 < 12 غلط است } مقدار hour برابر ۱۴ است. شرط hour < 12 غلط است، پس بلوک اول رد می‌شود و فقط بلوک else اجرا می‌شود. اگر ساعت را به عددی کوچک‌تر از ۱۲ عوض کنید، پیام صبح چاپ می‌شود و بلوک دوم اصلاً اجرا نمی‌شود. در هر اجرا فقط یکی از این دو مسیر انتخاب می‌شود.»

«let score = 16; if (score >= 17) { console.log("عالی"); } else if (score >= 14) { console.log("خوب"); } else if (score >= 10) { console.log("قبول"); } else { console.log("مردود"); } else if یک شرط تازه را فقط وقتی بررسی می‌کند که شرط‌های قبلی غلط بوده باشند. نمرهٔ ۱۶ از ۱۷ کوچک‌تر است، پس شاخهٔ «عالی» رد می‌شود. شرط بعدی، بزرگ‌تر یا مساوی ۱۴، درست است و «خوب» چاپ می‌شود. شرط‌های پایین‌تر دیگر دیده نمی‌شوند، حتی اگر آن‌ها هم از نظر ریاضی درست باشند.»

«شرط‌ها از بالا به پایین بررسی می‌شوند و اولین شرط درست اجرا می‌شود؛ بقیه نادیده گرفته می‌شوند. پس ترتیب شرط‌ها مهم است. نمره ۱۶ هم از ۱۰ بزرگ‌تر است، ولی چون شرط score >= 14 زودتر درست شده، فقط «خوب» چاپ می‌شود.»

**روی جزوه این عناوین را دنبال کنید:** *۱۷) شرط‌ها (If...Else)* · *else if — چند حالت* · *مثال کاربردی: هزینه ارسال سفارش* · *مثال: کارنامه زنده*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let hour = 14;

if (hour < 12) {
  console.log("صبح بخیر");
} else {
  console.log("عصر بخیر");     // این اجرا می‌شود، چون 14 < 12 غلط است
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let score = 16;

if (score >= 17) {
  console.log("عالی");
} else if (score >= 14) {
  console.log("خوب");
} else if (score >= 10) {
  console.log("قبول");
} else {
  console.log("مردود");
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
function shippingCost(cartTotal, city) {
  if (cartTotal >= 500000) {
    return 0;                          // خرید بالای ۵۰۰ هزار تومان: ارسال رایگان
  } else if (city === "تهران") {
    return 30000;
  } else {
    return 45000;
  }
}

console.log(shippingCost(650000, "شیراز"));   // 0
console.log(shippingCost(200000, "تهران"));   // 30000
console.log(shippingCost(200000, "تبریز"));   // 45000
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
