## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«حلقهٔ while تا وقتی شرط درست است بدنه را تکرار می‌کند. برخلاف for ، شمارنده و تغییر آن را خودتان بیرون و داخل بدنه می‌نویسید. این شکل وقتی مناسب است که از اول نمی‌دانید تکرار چند بار لازم است و فقط می‌دانید «تا وقتی این شرط برقرار است ادامه بده». اگر فراموش کنید متغیری که شرط به آن وابسته است را داخل بدنه عوض کنید، شرط همیشه درست می‌ماند و حلقه تمام نمی‌شود.»

«i قبل از حلقه برابر ۱ است. هر بار اول شرط i <= 5 دیده می‌شود، بعد عدد چاپ می‌شود و سپس یکی به i اضافه می‌شود. وقتی i به ۶ برسد، شرط غلط است و بدنه دیگر اجرا نمی‌شود. خط افزایش اگر حذف شود، i روی ۱ می‌ماند و شرط همیشه درست است.»

«فرق اصلی: while اول شرط را بررسی می‌کند و بعد اجرا می‌کند؛ do...while اول اجرا می‌کند و بعد شرط را بررسی می‌کند. کاربرد معمول: «حداقل یک بار از کاربر بپرس، اگر جواب نامعتبر بود دوباره بپرس».»

«بدنه یک بار اجرا می‌شود و n را چاپ می‌کند، حتی اگر شرط پایین از همان اول غلط باشد. بعد از این اجرا، n یکی زیاد می‌شود و شرط n < 5 بررسی می‌شود. چون نتیجه غلط است، تکرار دوم رخ نمی‌دهد. اگر همین منطق را با while می‌نوشتید، بدنه اصلاً اجرا نمی‌شد.»

**روی جزوه این عناوین را دنبال کنید:** *۲۰) حلقه While، Break و Continue* · *do...while — حداقل یک بار اجرا* · *break — خروج از حلقه* · *continue — رد شدن از این دور*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let i = 1;
while (i <= 5) {
  console.log(i);
  i++;          // بدون این خط حلقه بی‌پایان می‌شود!
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let n = 10;
do {
  console.log("این حداقل یک بار اجرا می‌شود. n =", n);
  n++;
} while (n < 5);   // شرط از همان اول غلط است، ولی بدنه یک بار اجرا شد
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;          // حلقه همین‌جا تمام می‌شود
  }
  console.log(i);
}
// خروجی (هر عدد در یک خط): 1 2 3 4 ← عدد 5 و بعد از آن چاپ نمی‌شوند
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«حلقه از ۱ تا ۱۰ آماده است، ولی داخل بدنه یک شرط اضافه وجود دارد. وقتی i به ۵ برسد، break فوراً از کل حلقه خارج می‌شود و console.log همان دور و دورهای بعدی اجرا نمی‌شوند. پس خروجی فقط ۱ تا ۴ است. break شرط اصلی حلقه را عوض نمی‌کند؛ فقط ادامهٔ تکرار را قطع می‌کند.»

«مثال کاربردی‌تر: پیدا کردن اولین رقم در رمز عبور. وقتی پیدا شد، دیگر لازم نیست بقیه حرف‌ها را بگردیم:»

«مقدار اولیهٔ -1 یعنی «هنوز رقمی پیدا نشده». حلقه حرف‌های رمز را از چپ بررسی می‌کند. includes می‌گوید این حرف جزو رقم‌های ۰ تا ۹ هست یا نه. اولین رقمی که پیدا شود، شماره‌اش ذخیره می‌شود و break بقیهٔ حرف‌ها را نادیده می‌گیرد. اگر هیچ رقمی نباشد، متغیر روی -1 می‌ماند و می‌توانید بعداً همین مقدار را به‌عنوان «پیدا نشد» بررسی کنید.»

«continue فقط بقیهٔ دستورهای همان دور را رد می‌کند و حلقه را تمام نمی‌کند. اگر i بر ۳ بخش‌پذیر باشد، برنامه به چاپ نمی‌رسد و مستقیم به دور بعد می‌رود. عددهای دیگر چاپ می‌شوند. در for ، گام i++ حتی بعد از continue هم انجام می‌شود.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
