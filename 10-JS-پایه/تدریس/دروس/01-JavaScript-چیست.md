## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«صفحهٔ وب فقط نوشته و رنگ نیست. وقتی روی دکمه‌ای کلیک می‌کنید، متنی عوض می‌شود یا فرمی پیش از ارسال بررسی می‌شود، این رفتار را زبان JavaScript انجام می‌دهد. هر صفحه معمولاً از سه بخش ساخته می‌شود و هر بخش کار جداگانه‌ای دارد:»

«JavaScript زبان برنامه‌نویسی وب است. با آن می‌توان محتوای صفحه را بعد از بارگذاری عوض کرد، به کلیک و تایپ کاربر واکنش نشان داد، درستی فرم را پیش از ارسال بررسی کرد و از سرور اطلاعات گرفت. امروزه این زبان فقط داخل مرورگر اجرا نمی‌شود؛ با ابزاری مثل Node.js روی سرور و در بعضی برنامه‌های دسکتاپ هم به کار می‌رود. تمرکز این دوره روی همان رفتاری است که کاربر در مرورگر می‌بیند.»

«در کد بالا، document.getElementById عنصری را پیدا می‌کند که در HTML همان شناسه را دارد و آن را در یک متغیر نگه می‌دارد. addEventListener("click", ...) به دکمه می‌گوید هر بار که کاربر کلیک کرد، تابع داخل پرانتز اجرا شود. داخل آن تابع، textContent متن تیتر را با جملهٔ جدید عوض می‌کند. HTML فقط اسکلت را ساخته و JavaScript محتوای همان عنصر را تغییر داده است.»

«JavaScript می‌تواند به عنصر کلاس CSS اضافه یا از آن حذف کند. ظاهر را CSS تعیین می‌کند و JavaScript فقط کلاس را عوض می‌کند.»

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
<!-- HTML -->
<h3 id="demo-title">متن اولیه</h3>
<button id="demo-btn">کلیک کن</button>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
// JavaScript
const title = document.getElementById("demo-title");
const button = document.getElementById("demo-btn");

button.addEventListener("click", function () {
  title.textContent = "سلام! این متن را JavaScript عوض کرد.";
});
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
const box = document.getElementById("light-box");
const toggle = document.getElementById("light-btn");

toggle.addEventListener("click", function () {
  box.classList.toggle("active");   // اگر کلاس بود حذف کن، نبود اضافه کن
});
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«classList فهرست کلاس‌های CSS همان عنصر است. متد toggle اگر کلاس active روی جعبه نباشد آن را اضافه می‌کند و اگر باشد حذف می‌کند؛ به همین دلیل هر کلیک ظاهر جعبه را بین دو حالت جابه‌جا می‌کند. قانون رنگ در CSS نوشته شده و JavaScript فقط حضور یا نبودن آن کلاس را عوض می‌کند.»

«JavaScript با Java فرق دارد! این دو زبان کاملاً جدا هستند و فقط اسمشان شبیه است. JavaScript را کوتاه «JS» هم می‌نویسند.»

«فعلاً لازم نیست همه کلمه‌های کد بالا را بفهمید. در درس‌های بعد تک‌تک آن‌ها را یاد می‌گیرید. هدف این درس فقط دیدن «قدرت» JavaScript است.»

«نام رسمی: نسخه استاندارد این زبان ECMAScript نام دارد (مثلاً ES6 یا ES2015). همه مرورگرهای امروزی نسخه‌های جدید را پشتیبانی می‌کنند و در این دوره از همان نحو جدید (مثل let ، const و Template Literal) استفاده می‌کنیم.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
