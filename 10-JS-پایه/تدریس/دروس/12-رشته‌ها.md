## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«رشته (String) یعنی متن. هر نام، پیام، نشانی یا عددی که داخل گیومه باشد از این نوع است. متن را داخل گیومهٔ تکی '...' ، دوتایی "..." یا بک‌تیک `...` می‌نویسیم. هر سه شکل برای متن ساده یک نتیجه دارند؛ تفاوت وقتی ظاهر می‌شود که بخواهید گیومه را داخل متن بیاورید یا مقدار متغیر را وسط جمله بگذارید.»

«هر سه متغیر متن «سلام» را نگه می‌دارند. گیومهٔ باز و بسته باید از یک نوع باشند. بک‌تیک برای متن ساده هم درست است، ولی قابلیت اضافه‌اش این است که بعداً بتوان متغیر را با ${ } داخل همان متن گذاشت. آن شکل را در درس رشته‌های قالبی می‌بینید.»

«length تعداد واحدهای رشته را می‌دهد و یک ویژگی است، نه تابع؛ پس پرانتز نمی‌گیرد. شمارهٔ خانه‌ها از صفر شروع می‌شود: خانهٔ ۰ حرف اول است. word[4] حرف پنجم را می‌دهد. at(-1) از انتها می‌شمارد و آخرین حرف را برمی‌گرداند. اگر شماره‌ای بیرون از طول رشته باشد، نتیجه undefined است و خطا نمی‌گیرید.»

«شماره‌گذاری (index) در JavaScript همیشه از صفر شروع می‌شود. پس آخرین حرف در شماره length - 1 است: word[word.length - 1] همان word.at(-1) است. فاصله و نیم‌فاصله هم یک حرف حساب می‌شوند.»

**روی جزوه این عناوین را دنبال کنید:** *۱۲) رشته‌ها (Strings)* · *طول رشته و دسترسی به حرف‌ها* · *گیومه داخل گیومه و کاراکترهای خاص* · *رشته‌ها تغییرناپذیرند*

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let a = "سلام";
let b = 'سلام';
let c = `سلام`;
console.log(a, b, c);
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let word = "JavaScript";
console.log(word.length);    // 10 ← تعداد حرف‌ها
console.log(word[0]);        // J  ← اولین حرف (شماره‌گذاری از صفر)
console.log(word[4]);        // S
console.log(word.at(-1));    // t  ← آخرین حرف (عدد منفی از آخر می‌شمارد)
console.log(word[20]);       // undefined ← چنین شماره‌ای وجود ندارد
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```javascript
let s1 = "او گفت: 'سلام'";        // گیومه متفاوت
let s2 = "او گفت: \"سلام\"";     // با بک‌اسلش (Escape)
let s3 = "خط اول\nخط دوم";        // \n یعنی خط جدید
console.log(s1);
console.log(s2);
console.log(s3);
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اگر گیومهٔ داخلی با گیومهٔ بیرونی فرق داشته باشد، نیازی به علامت اضافه نیست. اگر هر دو یکی باشند، قبل از گیومهٔ داخلی یک بک‌اسلش می‌گذارند تا مرورگر آن را پایان رشته حساب نکند. \n یک حرف واقعی روی صفحه نیست؛ دستور رفتن به خط بعد است و فقط وقتی دیده می‌شود که خروجی بتواند خط جدید را نشان دهد، مثل Console.»

«نمی‌شود یک حرف از رشته را «سر جایش» عوض کرد. رشته بعد از ساخته شدن ثابت است (Immutable). برای تغییر، باید یک رشته جدید بسازیم و دوباره در متغیر بریزیم.»

«جملهٔ name[0] = "S" خانهٔ اول را عوض نمی‌کند، چون رشته بعد از ساخته شدن ثابت است. برای داشتن متن جدید باید رشتهٔ تازه‌ای بسازید و آن را دوباره به متغیر نسبت دهید. متغیر name با let ساخته شده، پس خود متغیر می‌تواند به رشتهٔ دیگری اشاره کند؛ این با عوض کردن یک حرف از رشتهٔ قبلی فرق دارد.»

«در حالت عادی خط name[0] = "S" بی‌صدا نادیده گرفته می‌شود، ولی در «حالت سخت‌گیرانه» ( "use strict" ) که در بسیاری از پروژه‌ها فعال است، خطای TypeError می‌دهد. در درس بعد با متدهایی مثل toUpperCase() و slice() رشته جدید می‌سازیم.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
