آموزش JavaScript — سطح پیشرفته

ادامه دوره میانی؛ مثال به مثال، از مفاهیم پایه‌ای تا یک پروژه کامل

پیش‌نیاز: درس‌های دوره پایه و دوره میانی JavaScript (به‌خصوص آرایه‌ها، تابع پیکانی، Destructuring، JSON و DOM).

نکته: مثال درس «ماژول‌ها» فقط وقتی اجرا می‌شود که صفحه با یک سرور محلی (مثل افزونه Live Server در VS Code) باز شود. مثال‌های درس Fetch هم به اینترنت نیاز دارند. بقیه مثال‌ها با باز کردن مستقیم فایل (دوبار کلیک) کار می‌کنند. خروجی مثال‌ها در جعبه‌های سیاه «Console» صفحه نمایش داده می‌شود و هم‌زمان در Console مرورگر (کلید F12) هم چاپ می‌شود.

فهرست درس‌ها
  1. توابع پیشرفته (پارامترها و توابع مرتبه بالا)
  2. بستارها (Closures)
  3. متدهای call، apply و bind (اختیاری برای جونیور)
  4. کلاس‌ها (Classes)
  5. وراثت، static و فیلدهای خصوصی (اختیاری برای جونیور)
  6. مجموعه و نگاشت (Set و Map)
  7. زمان‌بندی (setTimeout، setInterval و debounce)
  8. توابع Callback و کد ناهمگام
  9. وعده‌ها (Promises)
  10. async و await
  11. دریافت داده از سرور (Fetch API)
  12. ماژول‌ها (Modules)
  13. ذخیره‌سازی در مرورگر (localStorage)
  14. عبارت‌های منظم (Regular Expressions)
  15. انتشار رویداد و Event Delegation
  16. عملگرهای مدرن و متدهای Object
  17. اشکال‌زدایی و نکات حرفه‌ای (Debugging & Best Practices)
  18. JavaScript و دسترس‌پذیری
  19. انتشار سایت استاتیک (Deploy)
  20. پروژه نهایی: فروشگاه کوچک

قدم بعدی: بعد از این دوره آماده یادگیری یک فریم‌ورک (مثل React یا Vue) یا TypeScript هستید.
