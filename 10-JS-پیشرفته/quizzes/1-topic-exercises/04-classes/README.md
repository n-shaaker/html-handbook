## تمرین ۱ — کلاس کتاب ⭐

**هدف:** نوشتن یک کلاس ساده با `constructor` و دو متد، و ساختن چند شیء از آن با `new`.

**صورت مسئله:** کتابخانه مدرسه می‌خواهد مشخصات کتاب‌ها را یک‌دست نمایش دهد.

**الزامات:**
- کلاس `Book` با `constructor(title, author, pages)`.
- متد `getSummary()` متنی مثل «کلیدر — محمود دولت‌آبادی (۲٬۸۳۶ صفحه)» برگرداند.
- متد `isLong()` اگر کتاب بیشتر از ۳۰۰ صفحه دارد `true` برگرداند.
- سه کتاب بسازید و خلاصه هر کدام را در یک `li` نمایش دهید؛ کنار کتاب‌های طولانی «📚 طولانی» بیاید.

**تست‌ها:**
- `new Book("شازده کوچولو", "سنت‌اگزوپری", 96).getSummary()` ← «شازده کوچولو — سنت‌اگزوپری (۹۶ صفحه)»
- `new Book("کلیدر", "محمود دولت‌آبادی", 2836).isLong()` ← `true`
- `new Book("شازده کوچولو", "سنت‌اگزوپری", 96).isLong()` ← `false`

## تمرین ۲ — کلاس سبد خرید ⭐⭐

**هدف:** نگه داشتن یک **آرایه از اشیا** داخل کلاس و نوشتن متدهایی که آن را تغییر می‌دهند یا از آن حساب می‌کنند.

**صورت مسئله:** برای یک کتاب‌فروشی آنلاین، منطق سبد خرید را جدا از ظاهر صفحه در یک کلاس بنویسید.

**الزامات:**
- کلاس `ShoppingCart` که در `constructor` یک آرایه خالی `this.items = []` می‌سازد.
- `addItem(name, price)`: اگر کالا در سبد بود فقط `qty` آن یکی زیاد شود، وگرنه `{ name, price, qty: 1 }` اضافه شود.
- `removeItem(name)`: کالا را کامل حذف کند.
- `getTotal()` جمع کل و `getCount()` تعداد کل اقلام را برگرداند.
- سه دکمه افزودن کتاب و یک دکمه «حذف دفتر نقاشی»؛ بعد از هر کلیک فهرست سبد، تعداد و جمع کل نمایش داده شود.

**تست‌ها:**
- دو بار `addItem("رمان", 150000)` و یک بار `addItem("دفتر نقاشی", 60000)` ← تعداد: ۳ — جمع: ۳۶۰٬۰۰۰ تومان
- سپس `removeItem("دفتر نقاشی")` ← تعداد: ۲ — جمع: ۳۰۰٬۰۰۰ تومان
- سبد خالی ← تعداد: ۰ — جمع: ۰ تومان

## تمرین ۳ — کلاس فهرست کارها با رابط کاربری ⭐⭐⭐

**هدف:** جدا کردن **منطق** (کلاس) از **نمایش** (تابع `render`) و وصل کردن آن‌ها با رویدادها.

**صورت مسئله:** یک فهرست کار روزانه بسازید. کاربر کار جدید اضافه می‌کند و با کلیک روی هر کار، آن را «انجام‌شده» یا «انجام‌نشده» می‌کند.

**الزامات:**
- کلاس `TodoList` با آرایه `this.tasks` و متدهای `add(title)`، `toggle(id)` و `getRemaining()`.
- هر کار یک شیء ساده: `{ id, title, done }`؛ برای `id` از `Date.now()` استفاده کنید.
- `add` اگر عنوان (بعد از `trim`) خالی بود، `false` برگرداند و چیزی اضافه نکند.
- تابع `render()` (بیرون از کلاس) فهرست را با `createElement` و `textContent` از نو بسازد؛ کار انجام‌شده کلاس `done` بگیرد.
- متن «n کار باقی مانده» با رقم فارسی زیر فهرست بیاید.

**تست‌ها:**
- افزودن «خرید نان» و «تمرین JS» ← «۲ کار باقی مانده»
- کلیک روی «خرید نان» ← خط‌خورده می‌شود و «۱ کار باقی مانده»
- کلیک دوباره روی «خرید نان» ← خط برداشته می‌شود و «۲ کار باقی مانده»
- افزودن عنوان خالی یا فقط فاصله ← پیام «عنوان کار را بنویسید.» و چیزی اضافه نمی‌شود

## اشتباه‌های رایج این مبحث

- فراموش کردن `new`: `Book("...")` خطای `Class constructor Book cannot be invoked without 'new'` می‌دهد.
- فراموش کردن `this.` داخل متدها: `items.push(...)` به جای `this.items.push(...)`.
- گذاشتن ویرگول بین متدهای کلاس (مثل شیء)؛ در کلاس متدها ویرگول نمی‌خواهند.
- دستکاری DOM داخل کلاس منطق؛ بهتر است کلاس فقط داده را مدیریت کند و نمایش جدا باشد.
- مقایسه `id` عددی با `dataset.id` رشته‌ای بدون `Number(...)`.
