## تمرین ۱ — تنظیمات پخش‌کننده با ?? و ?. ⭐

**هدف:** فرق `??` با `||`، و خواندن امن یک ویژگی شاید-ناموجود با `?.`.

**صورت مسئله:** پخش‌کننده موسیقی تنظیمات کاربر را می‌خواند. کاربری که صدا را عمداً روی `0` گذاشته، نباید صدایش به پیش‌فرض ۵۰ برگردد! بعضی کاربران هم اصلاً آدرس ثبت نکرده‌اند.

**الزامات:**
- تابع `getVolumeWrong(settings)` با `settings.volume || 50` و تابع `getVolume(settings)` با `settings.volume ?? 50`.
- نتیجه هر دو تابع برای سه کاربر (صدای ۰، صدای ۸۰، بدون صدا) در صفحه نمایش داده شود تا تفاوت دیده شود.
- تابع `getCity(user)` با `user.address?.city ?? "نامشخص"`.

**تست‌ها:**
- `getVolumeWrong({ volume: 0 })` ← `50` (اشتباه!)
- `getVolume({ volume: 0 })` ← `0`
- `getVolume({})` ← `50`
- `getCity({ name: "سارا", address: { city: "شیراز" } })` ← `شیراز`
- `getCity({ name: "علی" })` ← `نامشخص` (بدون خطا)

## تمرین ۲ — کارنامه کلاس با Object.entries ⭐⭐

**هدف:** پیمایش یک شیء با `Object.keys`، `Object.values` و `Object.entries` و destructuring در حلقه.

**صورت مسئله:** نمره‌های کلاس در یک شیء ذخیره شده‌اند: `{ سارا: 18, علی: 15, مریم: 19, رضا: 9 }`. معلم یک کارنامه خلاصه می‌خواهد.

**الزامات:**
- تعداد دانش‌آموزان با `Object.keys(scores).length`.
- میانگین با `Object.values(scores)` و یک حلقه.
- برای هر دانش‌آموز با `for (const [name, score] of Object.entries(scores))` یک `li` «سارا: ۱۸ — قبول» یا «… — مردود» (زیر ۱۰) بسازید.
- بهترین دانش‌آموز با همان حلقه پیدا شود.

**تست‌ها:**
- تعداد ← «۴ دانش‌آموز»
- میانگین ← «۱۵٫۲۵»
- رضا ← «رضا: ۹ — مردود»
- بهترین ← «مریم (۱۹)»

## تمرین ۳ — ویرایش پروفایل بدون خراب کردن اصل داده ⭐⭐⭐

**هدف:** ساختن نسخه جدید شیء با **spread** (`{ ...a, ...b }`)، **destructuring** و فرق کپی سطحی با `structuredClone`.

**صورت مسئله:** صفحه «ویرایش پروفایل» نباید تا قبل از زدن «ذخیره» داده اصلی را تغییر دهد. تنظیمات پیش‌فرض سایت هم باید با تنظیمات کاربر ترکیب شوند.

**الزامات:**
- `const defaults = { theme: "light", fontSize: 16, language: "fa" }` و `const userSettings = { fontSize: 20 }`؛ ترکیب با `{ ...defaults, ...userSettings }`.
- یک شیء `user` با `name`، `city` و آرایه `skills`. با فرم (کادر شهر)، نسخه جدید بسازید: `const updated = { ...user, city: newCity }`؛ `user` نباید عوض شود.
- نشان دهید کپی سطحی (`{ ...user }`) آرایه `skills` را **مشترک** نگه می‌دارد ولی `structuredClone(user)` نه (با `push` روی هر کدام و نمایش `user.skills`).
- با destructuring (`const { name, city } = updated;`) پیام «سارا، اصفهان» را بسازید.

**تست‌ها:**
- ترکیب تنظیمات ← `theme: light — fontSize: 20 — language: fa`
- شهر جدید «اصفهان» ← نسخه جدید: «سارا، اصفهان»؛ `user.city` هنوز «شیراز»
- `shallow.skills.push("CSS")` ← `user.skills` هم «CSS» می‌گیرد
- `deep.skills.push("React")` ← `user.skills` تغییری نمی‌کند

---

## اشتباه‌های رایج این مبحث

- استفاده از `||` برای مقدار پیش‌فرض وقتی `0` یا `""` مقدار درستی است؛ `??` فقط برای `null` و `undefined` جایگزین می‌کند.
- زیاده‌روی در `?.`؛ فقط جایی بگذارید که واقعاً ممکن است مقدار نباشد، وگرنه باگ‌ها پنهان می‌شوند.
- فکر کردن این‌که `{ ...obj }` کپی کامل است؛ شیءها و آرایه‌های داخلی هنوز مشترک‌اند.
- ترتیب spread: در `{ ...userSettings, ...defaults }` پیش‌فرض‌ها روی انتخاب کاربر می‌نشینند.
