# مبحث ۱۲ — ماژول‌ها (Modules)

📖 درس مرتبط: [ماژول‌ها](../../../pages/12-modules.html)

> ⚠️ **حتماً با سرور محلی اجرا کنید.** مرورگر فایل‌های ماژول (`type="module"`) را از آدرس `file://` بارگذاری نمی‌کند و در Console خطای CORS می‌دهد.
> در VS Code افزونه **Live Server** را نصب کنید، روی `ex-1.html` راست‌کلیک کنید و «Open with Live Server» را بزنید.
>
> نام‌گذاری فایل‌ها: فایل اصلی هر تمرین `ex-n.js` است و ماژول‌های کمکی‌اش `ex-n-نام.js` (مثلاً `ex-1-math.js`). پاسخ نمونه در پوشه `solution` است.

---

## تمرین ۱ — اولین ماژول: ابزار حساب ⭐

**هدف:** `export` کردن چند تابع و ثابت از یک فایل و `import` کردن آن‌ها در فایل دیگر.

**صورت مسئله:** توابع حساب فروشگاه در چند صفحه لازم‌اند. به جای کپی کردن، آن‌ها را در یک ماژول جدا بنویسید.

**الزامات:**
- فایل `ex-1-math.js` با `export function add(a, b)`، `export function multiply(a, b)` و `export const TAX_RATE = 0.09`.
- فایل `ex-1.js` با `import { add, multiply, TAX_RATE } from "./ex-1-math.js";`
- در HTML: `<script type="module" src="ex-1.js"></script>` (ماژول خودش مثل `defer` رفتار می‌کند).
- نتیجه `add(2, 3)`، `multiply(4, 5)` و مالیات ۲۰۰٬۰۰۰ تومان در صفحه نمایش داده شود.

**تست‌ها:**
- `add(2, 3)` ← `5`
- `multiply(4, 5)` ← `20`
- `200000 * TAX_RATE` ← `18000`
- باز کردن با دوبار کلیک (`file://`) ← خطای CORS در Console (یعنی Live Server لازم است)

## تمرین ۲ — export پیش‌فرض و تغییر نام ⭐⭐

**هدف:** تفاوت `export default` با export نام‌دار، و تغییر نام هنگام import با `as`.

**صورت مسئله:** در یک فروشگاه، یک ماژول فقط وظیفه قالب‌بندی قیمت را دارد و ماژول دیگر سبد خرید را مدیریت می‌کند.

**الزامات:**
- `ex-2-format.js`: فقط یک `export default function formatPrice(n)` که «۱۲۰٬۰۰۰ تومان» برگرداند.
- `ex-2-cart.js`: آرایه `items` (export نشود) و `export function addItem(name, price)` و `export function getTotal()`.
- در `ex-2.js`: `import formatPrice from "./ex-2-format.js";` (بدون آکولاد) و `import { addItem, getTotal as getCartTotal } from "./ex-2-cart.js";`
- دو دکمه افزودن کالا؛ بعد از هر کلیک جمع کل با `formatPrice(getCartTotal())` نمایش داده شود.

**تست‌ها:**
- کلیک «دفتر» (۴۵٬۰۰۰) و «مداد» (۱۰٬۰۰۰) ← «جمع کل: ۵۵٬۰۰۰ تومان»
- در Console: `items` ← خطای `items is not defined` (ماژول متغیرهایش را پنهان نگه می‌دارد)

## تمرین ۳ — شکستن یک برنامه کوچک به سه ماژول ⭐⭐⭐

**هدف:** تقسیم یک برنامه به ماژول‌های **داده**، **نمایش** و **اصلی** با وظیفه‌های جدا.

**صورت مسئله:** یک صفحه جستجوی کتاب داریم که همه کدش در یک فایل است. آن را مرتب کنید تا هر فایل یک کار انجام دهد.

**الزامات:**
- `ex-3-data.js`: `export const books = [...]` (دست‌کم ۵ کتاب با `title` و `author`).
- `ex-3-render.js`: `export function renderBooks(list, listElement)` که فهرست را با `createElement` بسازد و اگر خالی بود «کتابی پیدا نشد.» بنویسد. این فایل نباید `books` را import کند (فقط چیزی که به آن داده می‌شود را نمایش می‌دهد).
- `ex-3.js`: هر دو را import کند، کادر جستجو را به رویداد `input` وصل کند و نتیجه فیلترشده (عنوان یا نویسنده شامل عبارت) را به `renderBooks` بدهد.
- هیچ متغیر سراسری ساخته نشود.

**تست‌ها:**
- بارگذاری صفحه ← هر ۵ کتاب
- جستجوی «مرادی» ← فقط کتاب‌های هوشنگ مرادی کرمانی
- جستجوی «xyz» ← «کتابی پیدا نشد.»
- در Console: `typeof books` ← `"undefined"`

---

## اشتباه‌های رایج این مبحث

- باز کردن صفحه با دوبار کلیک (`file://`)؛ ماژول‌ها فقط از سرور (مثل Live Server) بارگذاری می‌شوند.
- جا انداختن `./` یا `.js` در مسیر: `from "ex-1-math"` کار نمی‌کند؛ درستش `from "./ex-1-math.js"` است.
- فراموش کردن `type="module"` در تگ `script`؛ خطای `Cannot use import statement outside a module`.
- آکولاد گذاشتن دور export پیش‌فرض (`import { formatPrice } ...`) یا برداشتن آن از export نام‌دار.
- انتظار این‌که تابع‌های ماژول در Console در دسترس باشند؛ ماژول دامنه جدا دارد.
