۱۲) ماژول‌ها (Modules)

در پروژه‌های بزرگ کد را در چند فایل جدا می‌نویسیم. با export چیزی را از یک فایل «بیرون می‌دهیم» و با import در فایل دیگر استفاده می‌کنیم. هر ماژول محدوده (scope) خودش را دارد؛ پس متغیرهای دو فایل با هم تداخل پیدا نمی‌کنند و فقط چیزهایی که export شده‌اند از بیرون دیده می‌شوند.

مهم — قبل از شروع: ماژول‌ها با باز کردن مستقیم فایل HTML (دوبار کلیک، آدرسی که با file:// شروع می‌شود) کار نمی‌کنند. مرورگر به دلیل سیاست امنیتی CORS بارگذاری ماژول از file:// را مسدود می‌کند و در Console خطایی شبیه Access to script at 'file:///...' from origin 'null' has been blocked by CORS policy می‌بینید. صفحه را حتماً با یک سرور محلی باز کنید (بخش «اجرا با سرور محلی» پایین همین صفحه).

js/
├── modules/
│   ├── math-utils.js     ← export
│   └── format.js         ← export default
└── demos/
    └── modules.js        ← import

ماژول یعنی فایل JavaScript که خودش انتخاب می‌کند چه چیزهایی را بیرون بدهد. فایل‌های math-utils.js و format.js صادر می‌کنند و modules.js آن‌ها را وارد می‌کند. مرورگر فقط اگر اسکریپت با type="module" بارگذاری شود این import را می‌فهمد.

export نام‌دار (Named)

// js/modules/math-utils.js
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export function circleArea(r) {
  return PI * r * r;
}

export قبل از const یا function آن نام را برای فایل‌های دیگر قابل وارد کردن می‌کند. تابع‌هایی که export نشده‌اند فقط داخل همین فایل دیده می‌شوند. circleArea از ثابت PI همان فایل استفاده می‌کند.

export پیش‌فرض (Default)

// js/modules/format.js
export default function formatPrice(n) {
  return n.toLocaleString("fa-IR") + " تومان";
}

هر فایل می‌تواند یک export پیش‌فرض داشته باشد. واردکننده نام آن را خودش انتخاب می‌کند و لازم نیست نام را داخل آکولاد بیاورد. این تابع عدد را با رقم فارسی و واحد پول به متن نمایش تبدیل می‌کند.

import

// js/demos/modules.js
import { add, circleArea, PI as piNumber } from "../modules/math-utils.js";
import formatPrice from "../modules/format.js";

const output = document.getElementById("module-out");

output.textContent = `✔ ماژول با موفقیت اجرا شد:
add(2, 3) = ${add(2, 3)}
circleArea(2) = ${circleArea(2).toFixed(2)}
PI = ${piNumber}
formatPrice(1250000) = ${formatPrice(1250000)}
typeof window.add = ${typeof window.add}`;

// خروجی (با سرور محلی):
// add(2, 3) = 5
// circleArea(2) = 12.57
// PI = 3.14159
// formatPrice(1250000) = ۱٬۲۵۰٬۰۰۰ تومان
// typeof window.add = undefined   ← چیزی که import شده سراسری نیست

آکولاد مخصوص exportهای نام‌دار است و می‌توان هنگام ورود نام را با as عوض کرد. تابع پیش‌فرض بدون آکولاد می‌آید. این نام‌ها فقط داخل همین ماژول هستند و به window اضافه نمی‌شوند، پس فایل دیگر آن‌ها را نمی‌بیند مگر اینکه خودش import کند.

PI as piNumber یعنی «PI را با اسم piNumber وارد کن»؛ برای وقتی که اسم تکراری است یا اسم کوتاه‌تری می‌خواهید. همه export‌های نام‌دار یک فایل را هم می‌شود یک‌جا وارد کرد: import * as MathUtils from "../modules/math-utils.js"; و بعد MathUtils.add(2, 3).

وصل کردن به HTML

<script type="module" src="js/demos/modules.js"></script>

فقط فایل اصلی (نقطه شروع) را با type="module" به HTML وصل می‌کنیم؛ فایل‌هایی که import شده‌اند را مرورگر خودش بارگذاری می‌کند.

اگر این متن را می‌بینید، ماژول اجرا نشده است.
صفحه را با یک سرور محلی (مثل Live Server در VS Code) باز کنید؛
مرورگر اجازه نمی‌دهد ماژول‌ها از آدرس file:// بارگذاری شوند.

اجرا با سرور محلی

  1. در VS Code از بخش Extensions افزونه Live Server (از Ritwick Dey) را نصب کنید.
  2. پوشه کل پروژه را در VS Code باز کنید (File ← Open Folder)، نه فقط یک فایل را.
  3. روی فایل HTML کلیک راست کنید و Open with Live Server را بزنید (یا دکمه Go Live پایین پنجره).
  4. آدرس مرورگر باید با http://127.0.0.1:5500 یا http://localhost شروع شود، نه file://.

اگر Node.js یا Python نصب دارید، در پوشه پروژه این دستورها هم یک سرور ساده بالا می‌آورند: npx serve یا python -m http.server 8000 (سپس آدرس http://localhost:8000 را باز کنید).

ویژگی ماژولتوضیح
type="module"اسکریپت به عنوان ماژول اجرا می‌شود
defer خودکارماژول‌ها همیشه بعد از ساخته شدن HTML اجرا می‌شوند
strict خودکارهمیشه در حالت "use strict" هستند
محدوده جدامتغیرهای هر ماژول سراسری نیستند
مسیر کامل لازمدر مرورگر، مسیر import باید با ./، ../ یا / شروع شود و پسوند .js را داشته باشد ("./utils" کار نمی‌کند؛ ابزارهایی مثل Vite این محدودیت را برمی‌دارند)
یک بار اجرااگر چند فایل یک ماژول را import کنند، کد آن ماژول فقط یک بار اجرا می‌شود

هر فایل فقط یک export default می‌تواند داشته باشد ولی هر تعداد export نام‌دار. موقع import، نام‌دارها داخل { } و با همان اسم می‌آیند؛ default بدون آکولاد و با هر اسم دلخواه.

اشتباه رایج: باز کردن صفحه دارای ماژول با دوبار کلیک روی فایل HTML. مرورگر به خاطر سیاست امنیتی CORS آن را بارگذاری نمی‌کند؛ از Live Server استفاده کنید.

اشتباه رایج: فراموش کردن type="module" در تگ script. خطای SyntaxError: Cannot use import statement outside a module می‌گیرید.

اشتباه رایج: قاطی کردن نوع import: export نام‌دار را بدون آکولاد وارد کردن (import add from "./math-utils.js") خطای does not provide an export named 'default' می‌دهد؛ و export پیش‌فرض را داخل آکولاد نوشتن هم خطا می‌دهد.

اشتباه رایج: صدا زدن تابع یک ماژول از onclick="" در HTML. چون توابع ماژول سراسری نیستند، خطای ... is not defined می‌گیرید؛ رویداد را داخل خود ماژول با addEventListener وصل کنید.

تمرین: فایل js/modules/cart.js بسازید که یک آرایه خصوصی items (export نشده) و توابع addItem(name, price) و getTotal() را export کند. فایل js/app.js آن‌ها را import کند، سه کالا اضافه کند و جمع کل را با formatPrice (از format.js) در صفحه نشان دهد. صفحه را با Live Server اجرا کنید و بررسی کنید که از Console نمی‌توان به items دسترسی داشت.
