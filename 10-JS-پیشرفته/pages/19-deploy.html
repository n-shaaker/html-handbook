۱۹) انتشار سایت استاتیک

سایت HTML/CSS/JS بدون بک‌اند را می‌توان رایگان روی اینترنت گذاشت تا در پورتفولیو لینک بدهید.

گزینه ۱: GitHub Pages

  1. پروژه را روی GitHub push کنید
  2. Settings → Pages → Branch را main (ریشه یا پوشه docs) انتخاب کنید
  3. چند دقیقه بعد آدرس https://USER.github.io/REPO/ آماده است

گزینه ۲: Netlify Drop

  1. به صفحه Netlify Drop بروید
  2. پوشه ساخته‌شده سایت را بکشید و رها کنید
  3. لینک فوری بگیرید؛ بعداً می‌توانید به Git وصل کنید

قبل از Deploy: مسیر تصاویر نسبی باشد، با Live Server چک کنید، و در موبایل هم ببینید.

اشتباه: مسیر مطلق دسکتاپ یا درایو محلی در src یا href — روی اینترنت می‌شکند. همیشه مسیر نسبی مثل images/photo.jpg بگذارید.

تمرین: پروژه رستوران یا Todo را روی یکی از دو سرویس بالا منتشر کنید و لینک را ذخیره کنید.
