۱۸) JavaScript و دسترس‌پذیری

تعامل با JS نباید کیبورد و صفحه‌خوان را بشکند. حداقل‌های جونیور:

  • برای باز/بسته کردن پنل از <button> استفاده کنید نه div با کلیک
  • aria-expanded را با وضعیت پنل هماهنگ کنید
  • با Escape پنل را ببندید و فوکوس را برگردانید
  • پیام‌های وضعیت را در aria-live="polite" بگذارید

مثال: پنل ساده

محتوای پنل — با Escape یا دکمه ببندید.

btn.addEventListener("click", () => {
  const open = !panel.hidden;
  panel.hidden = open;
  btn.setAttribute("aria-expanded", String(!open));
  if (!open) closeBtn.focus();
  else btn.focus();
});
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape" && !panel.hidden) closePanel();
});

نمونه کامل‌تر در کوییز panel-toggle پروژه رستوران JS.

تمرین: منوی موبایل همبرگری با aria-expanded و Escape بسازید.
