۱۶) عملگرهای مدرن و متدهای Object

نسخه‌های جدید JavaScript چند شکل نوشتاری اضافه کرده‌اند که کد را کوتاه‌تر و بعضی خطاهای رایج را قابل‌پیشگیری می‌کنند. هیچ‌کدام منطق تازهٔ پنهان نیست: یا خواندن امن مقدار است، یا کپی، یا ساختن شیء از روی دادهٔ موجود. هر کدام را با مثالی می‌بینید که بدون آن شکل چه خطایی یا چه مقدار اشتباهی پیش می‌آید.

Optional Chaining (?.)

اگر بخواهیم به ویژگی یک شیء که ممکن است وجود نداشته باشد دسترسی پیدا کنیم، ?. به جای خطا undefined برمی‌گرداند.

const user = { name: "سارا", address: { city: "شیراز" } };
const guest = { name: "مهمان" };

console.log(user.address.city);          // شیراز
console.log(guest.address?.city);        // undefined (بدون ?. خطا می‌داد)
console.log(guest.getAge?.());           // undefined ← متدی که شاید نباشد
console.log(user.orders?.[0]);           // undefined ← آرایه‌ای که شاید نباشد

اگر address وجود نداشته باشد، خواندن .city بدون علامت سؤال خطا می‌دهد چون نمی‌شود از undefined ویژگی خواند. ?. در همان نقطه توقف می‌کند و کل عبارت undefined می‌شود. همین شکل برای صدازدن متدی که شاید نباشد و برای عضو آرایه‌ای که شاید نباشد هم به کار می‌رود. اگر مقدار واقعاً وجود داشته باشد، خواندن عادی ادامه پیدا می‌کند.






Nullish Coalescing (??)



a ?? b یعنی «اگر a برابر null یا undefined بود، b». فرقش با || این است که 0 و "" را مقدار معتبر می‌داند.



const settings = { volume: 0, title: "" };

console.log(settings.volume || 50);   // 50 ✖ صفر را نادیده گرفت
console.log(settings.volume ?? 50);   // 0  ✔
console.log(settings.title ?? "بدون عنوان");   // "" ← رشته خالی حفظ شد (یک خط خالی چاپ می‌شود)
console.log(settings.color ?? "آبی");          // آبی ← color وجود ندارد (undefined)



عملگر || هر مقدار falsy، از جمله صفر و رشتهٔ خالی، را کنار می‌گذارد و طرف راست را برمی‌گرداند. ?? فقط وقتی طرف راست را انتخاب می‌کند که طرف چپ null یا undefined باشد. صفر و متن خالی با این عملگر حفظ می‌شوند. برای تنظیماتی که صفر معنی دارد، ?? انتخاب دقیق‌تری است.










عملگرهای انتساب منطقی



let a = null;
a ??= "پیش‌فرض";      // اگر null/undefined بود مقدار بده
console.log(a);       // پیش‌فرض

let count = 0;
count ||= 10;         // اگر falsy بود مقدار بده
console.log(count);   // 10 ← چون 0 هم falsy است

let isAdmin = true;
isAdmin &&= "دسترسی کامل";   // اگر truthy بود مقدار بده
console.log(isAdmin);            // دسترسی کامل



??= فقط اگر متغیر null یا undefined باشد مقدار جدید می‌گذارد. ||= هر مقدار falsy را عوض می‌کند، به همین دلیل صفر را به ۱۰ تبدیل کرده است. &&= فقط وقتی انتساب می‌کند که مقدار فعلی truthy باشد. این سه عملگر هم مقایسه می‌کنند و هم در صورت نیاز همان متغیر را به‌روز می‌کنند.



a ??= b کوتاه‌شده a ?? (a = b) است؛ کاربرد رایجش مقدار پیش‌فرض دادن به تنظیمات است: options.lang ??= "fa";










متدهای Object





متدخروجی


Object.keys(obj)آرایه کلیدها


Object.values(obj)آرایه مقدارها


Object.entries(obj)آرایه جفت‌های [کلید, مقدار]


Object.fromEntries(arr)برعکس entries


Object.assign(target, src)کپی ویژگی‌ها


Object.freeze(obj)قفل کردن شیء (تغییرناپذیر)؛ فقط سطح اول — شیءهای تو در تو قفل نمی‌شوند


structuredClone(obj)کپی عمیق (شامل شیءهای تو در تو)





const scores = { سارا: 18, علی: 15, مریم: 19 };

console.log(Object.keys(scores));       // ["سارا","علی","مریم"]
console.log(Object.values(scores));     // [18,15,19]

for (const [name, score] of Object.entries(scores)) {
  console.log(`${name}: ${score}`);
}

// یک نمره ارفاقی به همه: شیء ← آرایه جفت‌ها ← map ← دوباره شیء
const withBonus = Object.fromEntries(
  Object.entries(scores).map(([name, score]) => [name, score + 1])
);
console.log(withBonus);                 // {"سارا":19,"علی":16,"مریم":20}



Object.keys نام ویژگی‌ها را در آرایه می‌دهد و Object.values فقط مقدارها را. Object.entries هر ویژگی را به زوج [کلید, مقدار] تبدیل می‌کند تا بشود در حلقه نام و نمره را با هم دید. fromEntries آن آرایهٔ زوج‌ها را دوباره شیء می‌کند. در این مثال هر نمره یکی زیاد شده و شیء تازه ساخته شده است.










کپی سطحی در مقابل کپی عمیق



const original = { name: "سارا", skills: ["JS"] };

const shallow = { ...original };
const deep = structuredClone(original);

shallow.skills.push("CSS");       // آرایه داخلی مشترک است!
console.log(original.skills);     // ["JS","CSS"] ← اصلی هم تغییر کرد

deep.skills.push("React");        // کاملاً جدا
console.log(original.skills, deep.skills);   // ["JS","CSS"] ["JS","React"]



گسترش با سه نقطه فقط لایهٔ اول را کپی می‌کند. آرایهٔ skills در کپی سطحی همان آرایهٔ اصلی است و push هر دو را عوض می‌کند. structuredClone ساختار تودرتو را جدا می‌کند، پس افزودن مهارت به کپی عمیق، فهرست اصلی را تغییر نمی‌دهد. این تابع بعضی چیزها مثل تابع و گرهٔ DOM را کپی نمی‌کند.



deep قبل از push کردن "CSS" ساخته شده؛ برای همین فقط "JS" را دارد. structuredClone تابع‌ها و عنصرهای DOM را کپی نمی‌کند (خطا می‌دهد)؛ برای داده‌های معمولی (شیء، آرایه، Date، Map، Set) مناسب است. روش قدیمی JSON.parse(JSON.stringify(obj)) هم Date را به رشته تبدیل می‌کند و undefined را حذف می‌کند.










چند ترفند کوچک دیگر



const big = 1_000_000;                 // جداکننده عددی برای خوانایی
console.log(big);                      // 1000000

const name = "علی", age = 30;
const person = { name, age };          // خلاصه‌نویسی ویژگی
console.log(person);                   // {"name":"علی","age":30}

const key = "color";
const obj = { [key]: "قرمز" };         // نام ویژگی محاسبه‌شده
console.log(obj);                      // {"color":"قرمز"}

console.log([10, 20, 30].at(-1));      // 30 ← آخرین عضو (به جای arr[arr.length - 1])



زیرخط داخل عدد فقط برای خواندن انسان است و در مقدار ذخیره نمی‌شود. اگر نام متغیر و نام ویژگی یکی باشد، می‌توان فقط یک بار آن را در شیء نوشت. کروشه دور نام ویژگی یعنی کلید از روی مقدار یک عبارت ساخته شود، نه اینکه کلمهٔ key خودش نام ویژگی باشد. at(-1) آخرین عضو آرایه را بدون حساب کردن length - 1 می‌دهد.










اشتباه رایج: استفاده از || برای مقدار پیش‌فرض وقتی 0 یا "" مقدار معتبر است. در این موارد از ?? استفاده کنید.



اشتباه رایج: استفاده بیش از حد از ?.. اگر یک مقدار حتماً باید وجود داشته باشد (مثلاً عنصری که در HTML نوشته‌اید)، ?. فقط باگ را پنهان می‌کند؛ بهتر است خطا بگیرید و علتش را پیدا کنید.



تمرین:

۱) تابع getAvatar(response) بنویسید که از پاسخ API با ?. و ?? مقدار response.data.user.profile.avatar را بخواند و اگر هر کدام از بخش‌ها نبود "default.png" برگرداند. آن را با این سه ورودی امتحان کنید: { data: { user: { profile: null } } }، {} و { data: { user: { profile: { avatar: "sara.jpg" } } } }. خروجی مورد انتظار: default.png، default.png، sara.jpg.

۲) از شیء { سیب: 45000, موز: 80000, انار: 60000 } با Object.entries، filter و Object.fromEntries شیء جدیدی بسازید که فقط میوه‌های ارزان‌تر از ۷۰٬۰۰۰ تومان را داشته باشد.
