۱۳) ذخیره‌سازی در مرورگر (localStorage)

با localStorage می‌توان داده را در مرورگر کاربر ذخیره کرد تا با بستن صفحه پاک نشود.

متدکار
localStorage.setItem(key, value)ذخیره
localStorage.getItem(key)خواندن (اگر نبود: null)
localStorage.removeItem(key)حذف یک مورد
localStorage.clear()حذف همه

داده هر سایت جداست: سایت دیگری نمی‌تواند localStorage سایت شما را بخواند. هر دو، متدهای یکسانی دارند؛ یعنی هر جا localStorage نوشته شده، می‌توانید sessionStorage بگذارید.

ذخیره رشته

localStorage.setItem("username", "سارا");
console.log(localStorage.getItem("username"));   // سارا
localStorage.removeItem("username");
console.log(localStorage.getItem("username"));   // null ← کلیدی که وجود ندارد

localStorage.setItem("age", 25);                  // عدد خودکار به رشته تبدیل می‌شود
console.log(typeof localStorage.getItem("age"));  // string

setItem یک رشته را با یک کلید در حافظهٔ محلی مرورگر ذخیره می‌کند و بعد از بستن صفحه هم می‌ماند. getItem همان رشته را برمی‌گرداند و اگر کلید نباشد null می‌دهد. removeItem فقط همان کلید را پاک می‌کند. عدد را هم به رشته تبدیل می‌کند؛ اگر بعداً جمع لازم دارید باید آن را با Number برگردانید.






ذخیره شیء و آرایه با JSON



const settings = { theme: "dark", fontSize: 18, langs: ["fa", "en"] };

localStorage.setItem("settings", JSON.stringify(settings));    // شیء ← متن

const saved = JSON.parse(localStorage.getItem("settings"));    // متن ← شیء
console.log(saved.theme, saved.langs);                         // dark ["fa","en"]



حافظهٔ محلی فقط رشته نگه می‌دارد. شیء و آرایه را اول با JSON.stringify به متن تبدیل می‌کنیم و هنگام خواندن با JSON.parse برمی‌گردانیم. بعد از parse، saved.langs دوباره آرایه است و می‌شود عضوهایش را جدا خواند.










خواندن و نوشتن امن با try...catch



داده localStorage دست کاربر است: ممکن است خودش آن را در DevTools ویرایش کند، نسخه قدیمی برنامه چیز دیگری ذخیره کرده باشد یا داده نیمه‌کاره بماند. اگر متن JSON معتبر نباشد، JSON.parse خطای SyntaxError می‌دهد و کل برنامه از کار می‌افتد. نوشتن هم ممکن است به خاطر پر شدن فضا خطای QuotaExceededError بدهد. پس دو تابع کمکی امن می‌سازیم:



function loadJSON(key, fallback) {
  const text = localStorage.getItem(key);
  if (text === null) return fallback;            // هنوز چیزی ذخیره نشده
  try {
    return JSON.parse(text);
  } catch (err) {
    console.warn(`داده «${key}» خراب است؛ مقدار پیش‌فرض استفاده شد.`);
    return fallback;
  }
}

function saveJSON(key, value) {
  try {
    localStorage.setItem(key, JSON.stringify(value));
    return true;
  } catch (err) {                                // مثلاً پر شدن فضا
    console.error("ذخیره ناموفق بود:", err.name);
    return false;
  }
}

localStorage.setItem("demo-cart", "{خراب");      // شبیه‌سازی داده خراب
console.log(loadJSON("demo-cart", []));          // ⚠ هشدار و سپس []

saveJSON("demo-cart", [{ id: 1, qty: 2 }]);
console.log(loadJSON("demo-cart", []));          // [{"id":1,"qty":2}]
console.log(loadJSON("not-saved-yet", { theme: "light" }));   // {"theme":"light"}



اگر کلید هنوز ذخیره نشده باشد، getItem مقدار null می‌دهد و تابع همان مقدار پیش‌فرض را برمی‌گرداند. اگر متن ذخیره شده JSON معتبر نباشد، parse خطا می‌دهد و catch به‌جای خراب کردن صفحه، پیش‌فرض را برمی‌گرداند. saveJSON مقدار را قبل از ذخیره به متن تبدیل می‌کند.










مثال زنده: حالت شب ماندگار



حالت را عوض کنید و صفحه را دوباره بارگذاری کنید (F5)؛ انتخاب شما حفظ می‌شود.



function applyTheme(theme) {
  themeBox.classList.toggle("dark", theme === "dark");
  themeBtn.textContent = theme === "dark" ? "☀ حالت روز" : "🌙 حالت شب";
  themeBtn.setAttribute("aria-pressed", theme === "dark");
}

let theme = localStorage.getItem("theme") || "light";   // اگر ذخیره نشده بود: روز
applyTheme(theme);

themeBtn.addEventListener("click", () => {
  theme = theme === "dark" ? "light" : "dark";
  localStorage.setItem("theme", theme);
  applyTheme(theme);
});







این کادر پیش‌نمایش ظاهر سایت است.








مثال زنده: یادداشت ماندگار



چیزی بنویسید و صفحه را دوباره بارگذاری کنید (F5)؛ متن سر جایش می‌ماند.



note.value = localStorage.getItem("note") || "";

note.addEventListener("input", () => {
  localStorage.setItem("note", note.value);
  savedMsg.textContent = "ذخیره شد ✔ " + new Date().toLocaleTimeString("fa-IR");
});

clearBtn.addEventListener("click", () => {
  localStorage.removeItem("note");
  note.value = "";
});



هنگام بارگذاری، اگر یادداشتی ذخیره شده باشد در کادر قرار می‌گیرد و اگر نه، رشتهٔ خالی می‌ماند. هر تغییر کادر همان متن را ذخیره می‌کند و ساعت ذخیره را نشان می‌دهد. دکمهٔ پاک کردن کلید را از حافظه برمی‌دارد و کادر را خالی می‌کند. این داده مخصوص همین مبدأ (دامنه و پورت) است.












در این مثال با هر حرف تایپ‌شده یک بار ذخیره می‌کنیم که برای متن کوتاه مشکلی ندارد. برای داده‌های بزرگ‌تر، ذخیره را با debounce (درس ۷) انجام دهید.



مثال زنده: شمارنده بازدید



let visits = Number(localStorage.getItem("visits")) || 0;
visits++;
localStorage.setItem("visits", visits);
visitText.textContent = `شما ${visits} بار این صفحه را باز کرده‌اید.`;



بازدید به‌صورت رشته ذخیره شده، پس قبل از جمع باید به عدد تبدیل شود. اگر کلید نباشد، Number(null) صفر است و || 0 همان صفر را نگه می‌دارد. بعد یکی اضافه می‌شود و دوباره ذخیره می‌شود. هر بار باز کردن این صفحه، همان کلید را بیشتر می‌کند.










در DevTools (F12) زبانه Application ← Local Storage می‌توانید داده‌های ذخیره‌شده را ببینید و ویرایش کنید.



اگر سایت در دو زبانه باز باشد و یکی localStorage را تغییر دهد، در زبانه دیگر رویداد storage روی window اجرا می‌شود؛ با آن می‌توانید مثلاً سبد خرید را در همه زبانه‌ها هماهنگ کنید.



اشتباه رایج: ذخیره شیء بدون JSON.stringify: setItem("user", user) متن "[object Object]" را ذخیره می‌کند!



اشتباه رایج: فراموش کردن تبدیل نوع موقع خواندن: localStorage.getItem("age") + 1 نتیجه "251" می‌دهد نه 26، چون مقدار خوانده‌شده رشته است. از Number(...) یا JSON.parse استفاده کنید.



اشتباه رایج: JSON.parse بدون try...catch روی داده localStorage. یک داده خراب کافی است تا صفحه هر بار با خطا باز شود و کاربر نتواند کاری بکند.



اشتباه رایج: ذخیره اطلاعات حساس (رمز عبور، توکن ورود، اطلاعات بانکی) در localStorage. هر اسکریپتی که در صفحه اجرا شود (از جمله کد مخرب تزریق‌شده) می‌تواند آن را بخواند.



تمرین: پروژه Todo List دوره میانی را بردارید و بعد از هر تغییر (افزودن، حذف، تیک زدن)، آرایه todos را با تابع saveJSON در localStorage ذخیره کنید و موقع باز شدن صفحه با loadJSON("todos", []) بخوانید. سپس در DevTools مقدار ذخیره‌شده را عمداً خراب کنید و مطمئن شوید صفحه بدون خطا با فهرست خالی باز می‌شود.
