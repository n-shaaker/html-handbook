# مبحث ۱۰ — نمایش و پنهان کردن پنل سبد

📖 بخش مرتبط پروژه: [صفحه منوی نارنج](../../../index.html) (دکمه شناور «سبد سفارش») — در [`js/app.js`](../../../js/app.js) توابع باز و بسته کردن سبد.

> HTML و CSS آماده است (پوشه `starter`). پوشه `starter` را کنار همین پوشه کپی کنید و فقط `ex-n.js` را بنویسید. پنل `aside#cart` با ویژگی `hidden` پنهان است و دکمه شناور `#cart-toggle` ویژگی `aria-expanded` دارد که صفحه‌خوان‌ها از آن می‌فهمند پنل باز است یا بسته. پاسخ نمونه در پوشه `solution` است.

---

## تمرین ۱ — باز و بسته کردن سبد ⭐

**هدف:** کار با ویژگی `hidden` و هماهنگ نگه داشتن `aria-expanded`.

**صورت مسئله:** با کلیک روی دکمه شناور «🧺 سفارش من» پنل سبد باز شود و با کلیک دوباره بسته شود.

**الزامات:**
- یک شنونده `click` روی `#cart-toggle` که `cart.hidden` را برعکس کند.
- `aria-expanded` همیشه با وضعیت پنل یکی باشد (`"true"` / `"false"`).
- متن دکمه: پنل بسته ← «🧺 سفارش من»، پنل باز ← «✕ بستن سفارش».

**تست‌ها:**
- کلیک اول ← پنل باز، متن «✕ بستن سفارش»، در DevTools `aria-expanded="true"`
- کلیک دوم ← پنل بسته، متن «🧺 سفارش من»، `aria-expanded="false"`

---

## تمرین ۲ — بستن با دکمه و Escape ⭐⭐

**هدف:** جدا کردن دو تابع `openCart()` و `closeCart()` و مدیریت **فوکوس** برای کاربر صفحه‌کلید.

**صورت مسئله:** پنل حالا دکمه ✕ (`#cart-close`) دارد. کاربرانی که با صفحه‌کلید کار می‌کنند باید بتوانند با Escape هم پنل را ببندند و فوکوس گم نشود.

**الزامات:**
- `openCart()`: پنل را نشان دهد، `aria-expanded="true"` و فوکوس را به `#cart-close` ببرد.
- `closeCart()`: پنل را پنهان کند، `aria-expanded="false"` و فوکوس را به `#cart-toggle` برگرداند.
- دکمه شناور: اگر پنل بسته بود `openCart()` و گرنه `closeCart()`.
- دکمه ✕ ← `closeCart()`.
- `keydown` روی `document`: اگر `event.key === "Escape"` و پنل **باز** بود ← `closeCart()`.

**تست‌ها:**
- فقط با صفحه‌کلید: Tab تا دکمه شناور، Enter ← پنل باز و فوکوس روی ✕
- Escape ← پنل بسته و فوکوس دوباره روی دکمه شناور
- Escape وقتی پنل بسته است ← هیچ اتفاقی نمی‌افتد (فوکوس جابه‌جا نمی‌شود)

---

## تمرین ۳ — بستن با کلیک بیرون پنل ⭐⭐⭐

**هدف:** تشخیص کلیک «بیرون از یک عنصر» با `element.contains(event.target)`.

**صورت مسئله:** بیشتر مهمان‌ها برای بستن پنل جایی از منو را کلیک می‌کنند. پنل باید با کلیک بیرون خودش بسته شود، ولی کلیک داخل پنل آن را نبندد.

**الزامات:**
- همه الزامات تمرین ۲، به‌علاوه:
- یک شنونده `click` روی `document`: اگر پنل باز بود و کلیک **نه داخل پنل** و **نه روی دکمه شناور** بود ← بستن.
- برای «داخل بودن» از `cart.contains(event.target)` و `toggleButton.contains(event.target)` استفاده کنید.
- در این حالت فوکوس **جابه‌جا نشود** (کاربر جای دیگری را کلیک کرده)؛ پس `closeCart` یک پارامتر بگیرد: `closeCart(moveFocus)`.

**تست‌ها:**
- باز کردن پنل و کلیک روی متن داخل پنل ← پنل باز می‌ماند
- کلیک روی عکس یک غذا ← پنل بسته می‌شود
- کلیک روی دکمه شناور وقتی پنل باز است ← بسته می‌شود (و فوراً دوباره باز نمی‌شود)

---

## اشتباه‌های رایج این مبحث

- عوض کردن `style.display` در یک جا و `hidden` در جای دیگر؛ یک روش را انتخاب کنید.
- به‌روز نکردن `aria-expanded`؛ ظاهر درست است ولی صفحه‌خوان وضعیت غلط می‌خواند.
- بستن پنل با Escape حتی وقتی بسته است و پرت شدن فوکوس.
- فراموش کردن استثنای دکمه شناور در «کلیک بیرون»؛ کلیک روی دکمه پنل را می‌بندد و بلافاصله دوباره باز می‌کند.
- مقایسه `event.target === cart`؛ کلیک روی `li` داخل پنل `target` دیگری دارد. از `contains` استفاده کنید.
