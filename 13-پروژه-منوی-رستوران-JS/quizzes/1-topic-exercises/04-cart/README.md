# مبحث ۴ — سبد سفارش: افزودن، حذف و تعداد

📖 بخش مرتبط پروژه: [صفحه منوی نارنج](../../../index.html) (دکمه «🧺 سفارش من») — در [`js/app.js`](../../../js/app.js) بخش «سبد سفارش» (`addToOrder`، `changeQty`، `renderCart`).

> HTML و CSS آماده است (پوشه `starter`؛ هر سه تمرین یک HTML دارند). پوشه `starter` را کنار همین پوشه کپی کنید و فقط `ex-n.js` را بنویسید. نام و قیمت را از `data-*` کارت بخوانید. پاسخ نمونه در پوشه `solution` است.

---

## تمرین ۱ — افزودن به سفارش ⭐

**هدف:** نگه داشتن سفارش در یک **آرایه** و ساختن دوباره فهرست بعد از هر تغییر.

**صورت مسئله:** نسخه اول سبد: با هر «+ افزودن» نام غذا به فهرست سفارش اضافه شود و عدد کنار «سفارش من» به‌روز شود.

**الزامات:**
- آرایه `orderNames = []`.
- listener روی هر `.add-btn`؛ نام از `button.closest(".dish").dataset.name`.
- تابع `renderCart()` که `#cart-list` را خالی کند و برای هر نام یک `li` بسازد (`textContent`)، و `#cart-count` را با رقم فارسی به‌روز کند.
- سبد خالی ← یک `li` «هنوز چیزی سفارش نداده‌اید.»

**تست‌ها:**
- شروع ← «هنوز چیزی سفارش نداده‌اید.» و شمارنده ۰
- ۲ بار کوبیده + ۱ بار دوغ ← ۳ ردیف (کوبیده دو بار تکرار شده) و شمارنده ۳

---

## تمرین ۲ — سبد بدون ردیف تکراری ⭐⭐

**هدف:** استفاده از یک **شیء** با کلید نام غذا تا هر غذا فقط یک ردیف داشته باشد و تعدادش بالا برود.

**صورت مسئله:** آشپزخانه از فهرست تمرین ۱ گیج شده بود («کوبیده، کوبیده، کوبیده...»). هر غذا باید یک ردیف با تعداد داشته باشد.

**الزامات:**
- شیء `order = {}` با این شکل: `{ "چلوکباب کوبیده": { price: 420000, qty: 2 } }`.
- تابع `addToOrder(name, price)`: اگر غذا بود `qty++`، وگرنه با `qty: 1` اضافه شود.
- `renderCart()` با حلقه `for...in` روی `order` برای هر غذا یک `li` «نام × تعداد» بسازد.
- شمارنده = **جمع تعدادها** (نه تعداد ردیف‌ها).

**تست‌ها:**
- ۲ بار کوبیده + ۱ بار دوغ ← ۲ ردیف: «چلوکباب کوبیده × ۲» و «دوغ محلی × ۱»؛ شمارنده ۳
- یک بار دیگر دوغ ← «دوغ محلی × ۲»؛ شمارنده ۴

---

## تمرین ۳ — تغییر تعداد در سبد ⭐⭐⭐

**هدف:** دکمه‌های **+**، **−** و **✕** داخل سبد با **یک listener** (Event Delegation) و `data-*`.

**صورت مسئله:** مهمان می‌خواهد بدون برگشتن به منو، تعداد را در خود سبد کم و زیاد کند یا غذایی را کامل حذف کند.

**الزامات:**
- همه کارهای تمرین ۲.
- هر `li` سبد ویژگی `data-name` و سه دکمه با `data-action="plus"`، `"minus"` و `"remove"` داشته باشد؛ هر دکمه `aria-label` مثل «یکی کمتر دوغ محلی».
- **فقط یک** listener روی `#cart-list`؛ با `event.target.closest("button")` و `closest("li").dataset.name`.
- تابع `changeQty(name, amount)`؛ اگر `qty` به صفر رسید، غذا با `delete order[name]` حذف شود.
- بعد از هر تغییر فقط `renderCart()` صدا زده شود (دکمه‌ها مستقیم DOM را دستکاری نکنند).

**تست‌ها:**
- کوبیده ×۲ و دوغ ×۱؛ − روی دوغ ← ردیف دوغ حذف می‌شود؛ شمارنده ۲
- + روی کوبیده ← «× ۳»؛ شمارنده ۳
- ✕ روی کوبیده ← «هنوز چیزی سفارش نداده‌اید.»؛ شمارنده ۰

---

## اشتباه‌های رایج این مبحث

- گذاشتن listener روی دکمه‌های داخل سبد در `renderCart`؛ هر بار ساختن دوباره، listenerها از دست می‌روند یا تکراری می‌شوند. Delegation روی `#cart-list` بگذارید.
- شمردن ردیف‌ها (`Object.keys(order).length`) به جای جمع `qty`ها برای شمارنده.
- خالی نکردن `#cart-list` قبل از ساختن دوباره؛ ردیف‌ها دوبار می‌شوند.
- خواندن قیمت از متن «۴۲۰٬۰۰۰ تومان» به جای `data-price`.
