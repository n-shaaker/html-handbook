# مبحث ۳ — دکمه‌های فیلتر دسته‌بندی

📖 بخش مرتبط پروژه: [صفحه منوی نارنج](../../../index.html) (دکمه‌های «همه / گیاهی / تند / جدید») — در [`js/app.js`](../../../js/app.js) بخش «جستجو و فیلتر».

> HTML و CSS آماده است (پوشه `starter`). پوشه `starter` را کنار همین پوشه کپی کنید و فقط `ex-n.js` را بنویسید. هر دکمه فیلتر `data-filter` دارد و هر کارت `data-category`. پاسخ نمونه در پوشه `solution` است.

---

## تمرین ۱ — فیلتر دسته‌بندی ⭐

**هدف:** مقایسه `data-filter` دکمه با `data-category` کارت‌ها.

**صورت مسئله:** مهمانی که فقط دسر می‌خواهد نباید بین کباب‌ها بگردد. با زدن هر دکمه فقط غذاهای همان دسته دیده شوند.

**الزامات:**
- به هر `.filter-btn` یک listener کلیک بدهید.
- مقدار `button.dataset.filter` را بخوانید.
- `all` ← همه کارت‌ها؛ وگرنه فقط کارت‌هایی که `dataset.category` آن‌ها برابر فیلتر است (بقیه `hidden`).

**تست‌ها:**
- «غذای اصلی» ← ۳ کارت (کوبیده، جوجه‌کباب، زرشک‌پلو)
- «نوشیدنی» ← ۲ کارت (چای، دوغ)
- «همه» ← ۸ کارت

---

## تمرین ۲ — دکمه فعال و عنوان نتیجه ⭐⭐

**هدف:** مدیریت **حالت انتخاب** دکمه‌ها با `classList` و `aria-pressed`.

**صورت مسئله:** مهمان باید بفهمد الان کدام فیلتر روشن است و چند غذا در آن دسته هست.

**الزامات:**
- همه کارهای تمرین ۱.
- با هر کلیک: کلاس `active` از همه دکمه‌ها برداشته و به دکمه زده‌شده اضافه شود؛ `aria-pressed` هم همین‌طور (`"true"`/`"false"`).
- عنوان `#filter-title`: «همه غذاها (۸ مورد)» یا «غذای اصلی (۳ مورد)» (نام از `button.textContent`، تعداد با شمارش در حلقه).

**تست‌ها:**
- «دسر» ← فقط دکمه «دسر» نارنجی است؛ عنوان «دسر (۱ مورد)»
- «پیش‌غذا» ← عنوان «پیش‌غذا (۲ مورد)»؛ دکمه «دسر» دیگر فعال نیست
- با DevTools: فقط یک دکمه `aria-pressed="true"` دارد

---

## تمرین ۳ — فیلتر ترکیبی ⭐⭐⭐

**هدف:** نوشتن **یک تابع** `applyFilters()` که چند شرط را با هم بررسی می‌کند، و نگه داشتن فیلتر فعلی در یک متغیر.

**صورت مسئله:** مهمان گیاه‌خوار با بودجه کم می‌خواهد هم دسته را انتخاب کند، هم «فقط گیاهی» و «فقط زیر ۱۰۰٬۰۰۰ تومان» را تیک بزند.

**الزامات:**
- متغیر `currentFilter` (شروع: `"all"`) که با کلیک دکمه‌ها عوض می‌شود (به‌علاوه `active` و `aria-pressed` مثل تمرین ۲).
- تابع `applyFilters()` برای هر کارت سه شرط را بررسی کند:
  - دسته: `currentFilter === "all"` یا برابر `dataset.category`
  - گیاهی: اگر تیک خورده، کارت باید `.tag-veg` داشته باشد (`dish.querySelector(".tag-veg") !== null`)
  - ارزان: اگر تیک خورده، `Number(dataset.price) < 100000`
- `applyFilters` هم با کلیک دکمه‌ها و هم با رویداد `change` چک‌باکس‌ها اجرا شود.
- اگر هیچ کارتی نماند، `#no-result` دیده شود.

**تست‌ها:**
- «همه» + فقط زیر ۱۰۰٬۰۰۰ ← ۴ کارت (سالاد شیرازی، فالوده، چای، دوغ)
- «پیش‌غذا» + فقط گیاهی ← ۲ کارت
- «همه» + هر دو تیک ← فقط سالاد شیرازی
- «غذای اصلی» + فقط گیاهی ← «غذایی با این شرایط پیدا نشد.»

---

## اشتباه‌های رایج این مبحث

- نوشتن کد فیلتر جداگانه داخل هر listener؛ وقتی شرط سوم اضافه شد، همه‌جا باید عوض شود. یک `applyFilters()` بنویسید.
- برنداشتن کلاس `active` از دکمه قبلی؛ چند دکمه هم‌زمان نارنجی می‌مانند.
- `setAttribute("aria-pressed", true)` درست کار می‌کند ولی خواندن `getAttribute` همیشه رشته `"true"` برمی‌گرداند، نه بولی.
- مقایسه قیمت رشته‌ای: `"75000" < "100000"` نادرست است (مقایسه متنی)! اول `Number(...)`.
