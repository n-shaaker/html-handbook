# پروژه منوی رستوران (با JavaScript)

نسخهٔ تعاملی منوی رستوران: جستجو، فیلتر دسته، سبد خرید، `localStorage`، اعتبارسنجی فرم، toast و پنل کناری.

## پیش‌نیاز (اجباری)

1. پروژه استاتیک [09-پروژه-منوی-رستوران](../09-پروژه-منوی-رستوران/) (ساختار HTML/CSS)
2. **[07 Flexbox](../07-CSS-Flexbox/)** و **[08 Grid](../08-CSS-Grid/)**
3. [10 JS پایه](../10-JS-پایه/) + [11 JS میانی](../11-JS-میانی/) (حداقل DOM، رویدادها، فرم‌ها)
4. از [12 JS پیشرفته](../12-JS-پیشرفته/): `localStorage`، event delegation، ترجیحاً debugging

> فایل `css/style.css` از Flex/Grid استفاده می‌کند. اگر هنوز layout نخوانده‌اید، اول ۰۷ و ۰۸ را بخوانید.

## معماری `js/app.js` (نقشه خواندن)

کد را از بالا به پایین این‌طور بخوانید / بازسازی کنید:

| بخش مفهومی | مسئولیت |
| --- | --- |
| داده منو / انتخاب DOM | گرفتن دکمه‌ها، لیست غذا، سبد، فرم |
| رندر لیست | ساخت کارت‌ها با `createElement` یا template |
| فیلتر و جستجو | با `filter` روی آرایه و رندر دوباره |
| سبد خرید | افزودن/حذف، جمع مبلغ، به‌روزرسانی UI |
| `localStorage` | ذخیره سبد بین رفرش‌ها |
| فرم رزرو | `preventDefault` + اعتبارسنجی دستی |
| toast / پنل | نمایش پیام، Escape، کلیک بیرون، فوکوس |
| event delegation | کلیک روی دکمه‌های داخل لیست از روی والد |

## چطور تمرین کنید

1. یک‌بار `index.html` را با Live Server باز کنید و رفتار را لمس کنید.
2. کوییزهای [`quizzes/`](quizzes/README.md) را موضوع‌به‌موضوع بسازید (نه کپی کل `app.js`).
3. در پایان، یک فیچر کوچک خودتان اضافه کنید (مثلاً دکمه «خالی کردن سبد» یا فیلتر قیمت).

## دسترسی‌پذیری که باید حفظ شود

- دکمه/لینک واقعی برای باز و بسته کردن پنل
- بستن با `Escape`
- برگرداندن فوکوس بعد از بستن پنل
- `aria-live` برای toast (اگر در کد هست، نگه دارید)
