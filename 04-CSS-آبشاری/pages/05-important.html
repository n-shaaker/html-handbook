۵) استفاده از !important

!important به آخر یک اعلان می‌چسبد؛ یعنی به یک ویژگی، نه به کل قانون. اگر در یک بلوک سه ویژگی نوشته باشید و فقط کنار color علامت !important بگذارید، فقط همان رنگ به گروه «مهم» می‌رود و بقیه ویژگی‌ها عادی می‌مانند. مرورگر اول اعلان‌های مهم را جدا بررسی می‌کند. برای همین یک اعلان !important از هر اعلان عادی برنده است، حتی اگر اعلان عادی دیرتر آمده باشد یا انتخابگرش قوی‌تر باشد.

این برتری مطلق نیست. اگر هر دو طرف !important داشته باشند، دوباره قدرت انتخابگر و بعد ترتیب نوشتن تصمیم می‌گیرند. استفادهٔ زیاد از آن هم کد را شکننده می‌کند، چون برای عوض کردن ظاهر باید !important دیگری بنویسید.

بدون !important — قانون دیرتر برنده است

.demo-imp .normal { color: #c92a2a; font-size: 20px; }
.demo-imp .normal { color: #1a5fb4; }   /* آبی برنده */

متن آبی است.

با !important — حتی قانون بعدی هم نمی‌تواند عوضش کند

.demo-imp .force { color: #c92a2a !important; font-size: 20px; }
.demo-imp .force { color: #1a5fb4; }   /* نادیده گرفته می‌شود */

متن قرمز ماند، با اینکه قانون آبی پایین‌تر است.

!important در برابر id

.demo-imp #force-id    { color: #0b6e4f; }              /* (1, 1, 0) */
.demo-imp .force-vs-id { color: #c92a2a !important; }   /* (0, 2, 0) */

کلاس با !important از id هم قوی‌تر شد.

دو !important در برابر هم

اگر هر دو اعلان !important باشند، !important دیگر برتری ایجاد نمی‌کند و دوباره همان قوانین همیشگی اجرا می‌شوند: اول قدرت انتخابگر، بعد ترتیب. 

.demo-imp p.both { color: #0b6e4f !important; }   /* (0, 2, 1) → برنده */
.demo-imp .both  { color: #c92a2a !important; }   /* (0, 2, 0) — دیرتر ولی ضعیف‌تر */

متن سبز است: هر دو !important دارند، پس انتخابگر قوی‌تر برنده شد.

چند نکته دقیق‌تر

  • استایل درون‌خطی: style="color: blue" از هر قانون عادی در فایل CSS قوی‌تر است، اما یک اعلان !important در فایل CSS از آن برنده می‌شود (مگر اینکه خود استایل درون‌خطی هم !important داشته باشد).
  • منبع (origin): در اعلان‌های عادی، CSS سایت از تنظیمات کاربر و پیش‌فرض مرورگر قوی‌تر است؛ ولی در اعلان‌های !important ترتیب برعکس می‌شود و !important کاربر (مثلاً تنظیم دسترس‌پذیری برای فونت بزرگ‌تر) از !important سایت قوی‌تر است.
  • لایه‌ها (@layer): در اعلان‌های عادی، لایه‌ای که دیرتر تعریف شده برنده است و CSS بیرون از لایه‌ها از همه لایه‌ها قوی‌تر است. در اعلان‌های !important این ترتیب هم برعکس می‌شود.

اشتباه رایج: زیاد استفاده کردن از !important. بعداً برای تغییر ظاهر باید !importantهای بیشتری بنویسید و کد به‌هم می‌ریزد. اول قدرت انتخابگر و ترتیب را درست کنید؛ !important را فقط برای موارد خاص بگذارید؛ مثلاً کلاس‌های کمکی کوچک که باید همیشه اعمال شوند (مثل .hidden { display: none !important; }) یا بازنویسی CSS کتابخانه‌ای که به آن دسترسی ندارید.

تمرین: !important را از .force بردارید. رنگ متن چه می‌شود؟
