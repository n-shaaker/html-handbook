۴) وراثت از والد به فرزند

بعضی ویژگی‌ها مثل color و font-family از والد به فرزند می‌رسند (ارثی هستند). بعضی‌ها مثل border و padding به ارث نمی‌رسند. اینکه هر ویژگی ارثی هست یا نه، در استاندارد CSS برای همان ویژگی مشخص شده است. قاعده سرانگشتی این است که ویژگی‌های مربوط به متن معمولاً ارثی‌اند و ویژگی‌های مربوط به جعبه نه؛ اما تصمیم نهایی را نام ویژگی در استاندارد مشخص می‌کند، نه این دسته‌بندی.

وراثت وقتی وارد عمل می‌شود که روی خود عنصر برای آن ویژگی هیچ مقداری ننوشته باشید. در این حالت مرورگر مقدار محاسبه‌شدهٔ والد را برای فرزند هم به کار می‌برد. برای همین اگر روی body رنگ متن را تعیین کنید، پاراگراف‌ها و عنوان‌ها همان رنگ را نشان می‌دهند، مگر اینکه خودشان رنگ دیگری داشته باشند. واحدهای نسبی مثل em در font-size پیش از رسیدن به فرزند محاسبه می‌شوند؛ فرزند اندازهٔ پیکسلی والد را به ارث می‌برد، نه خود عبارت 1.2em را. 

/* inheritance.css */
.demo-inherit .parent {
  color: #1a3a5c;
  font-family: Georgia, "Times New Roman", serif;
  line-height: 2;
  border: 2px solid #1a3a5c;
  padding: 12px;
}

.demo-inherit .child-keep {
  /* color و font-family ننوشته‌ایم → از والد به ارث می‌رسند */
  background-color: #e8f4fd;
  padding: 8px;
  margin: 8px 0;
}

.demo-inherit .child-override {
  color: #c92a2a; /* مقدار خود فرزند → جای مقدار ارثی را می‌گیرد */
  background-color: #fff5f5;
  padding: 8px;
  margin: 8px 0;
}

.demo-inherit .no-inherit {
  /* border به ارث نمی‌رسد؛ این جعبه border را خودش جداگانه تعریف کرده */
  border: 2px dashed #e67700;
  padding: 8px;
  margin-top: 8px;
}
والد: رنگ سرمه‌ای، فونت serif و کادر سرمه‌ای
فرزند ۱: رنگ و فونت را به ارث برده، ولی کادر سرمه‌ای والد را ندارد.
فرزند ۲: رنگ خودش را نوشته (قرمز)، پس مقدار ارثی جایگزین شده است.
فرزند ۳: کادر نارنجی را خودش تعریف کرده؛ border هرگز خودبه‌خود از والد نمی‌آید.
به ارث می‌رسد (نمونه‌ها) به ارث نمی‌رسد (نمونه‌ها)
color ، font-* (مثل font-family و font-size) ، line-height ، text-align ، text-indent ، text-transform ، letter-spacing ، word-spacing ، white-space ، direction ، list-style ، visibility ، cursor margin ، padding ، border ، background ، width / height ، display ، position ، box-shadow ، opacity ، text-decoration

وراثت ضعیف‌ترین منبع مقدار است: فقط وقتی به کار می‌رود که هیچ قانونی مستقیماً روی خود فرزند آن ویژگی را تعیین نکرده باشد. هر قانونی که فرزند را انتخاب کند، حتی انتخابگر همگانی * با قدرت (0, 0, 0)، از مقدار ارثی قوی‌تر است.

کنترل وراثت با کلمه‌های کلیدی

سه کلمهٔ کلیدی مقدار را به‌جای یک رنگ یا اندازهٔ مشخص، از یک منبع دیگر می‌گیرند. این‌ها را روی همان ویژگی می‌نویسید که می‌خواهید کنترلش کنید.

  • inherit مقدار محاسبه‌شدهٔ والد را می‌گیرد، حتی اگر آن ویژگی به‌طور عادی ارثی نباشد. مثلاً border: inherit کادر والد را روی فرزند هم می‌کشد، در حالی که border خودش به ارث نمی‌رسد.
  • initial مقداری را می‌گذارد که استاندارد CSS برای همان ویژگی به‌عنوان نقطهٔ شروع تعریف کرده است، نه مقدار مرورگر در stylesheet پیش‌فرض و نه مقدار والد. برای color این مقدار معمولاً سیاه است.
  • unset بین آن دو تصمیم می‌گیرد: اگر ویژگی ارثی باشد مثل inherit عمل می‌کند و اگر ارثی نباشد مثل initial.
/* دکمه‌ها و فیلدهای فرم فونت صفحه را به ارث نمی‌برند؛ این‌طور درستش می‌کنیم: */
button, input, select, textarea {
  font: inherit;
}

اشتباه رایج: تعجب از اینکه لینک‌ها رنگ والد را نمی‌گیرند. مرورگر در استایل پیش‌فرض خودش برای a رنگ آبی گذاشته و این قانون مستقیم، از مقدار ارثی قوی‌تر است. برای ارث بردن بنویسید a { color: inherit; }.

تمرین: قانون color را از .child-override حذف کنید. متن فرزند ۲ چه رنگی می‌شود؟
