۷) متغیرهای CSS (Custom Properties)

متغیر CSS (Custom Property) با -- تعریف می‌شود و با var() خوانده می‌شود. برای تم، فاصله‌ها و یک منبع حقیقت برای رنگ برند ضروری است. 

:root {
  --brand: #1a5fb4;
  --radius: 8px;
}
.card {
  background: var(--brand);
  border-radius: var(--radius);
}

مثال: یک تم، دو ظاهر

کارت با رنگ برند

روی یک والد کلاس تم بگذارید تا همه var(--brand)ها عوض شوند — پایه Dark Mode ساده.

اشتباه: نوشتن $brand مثل Sass؛ در CSS خام باید -- باشد.

تمرین: سه متغیر برای رنگ متن، پس‌زمینه و فاصله تعریف کنید و یک کارت بسازید.
