۱) ترتیب قوانین در یک فایل

آبشار یعنی وقتی چند قانون CSS هم‌زمان به یک عنصر می‌رسند، مرورگر با قاعده‌ای ثابت تصمیم می‌گیرد کدام مقدار بماند. ساده‌ترین حالت این است که دو قانون قدرت یکسان داشته باشند؛ مثلاً هر دو فقط یک کلاس باشند و همان عنصر را هدف بگیرند. در این حالت ترتیب نوشتن تعیین‌کننده است: قانونی که پایین‌تر در همان فایل آمده برنده می‌شود، چون مرورگر stylesheet را از بالا به پایین می‌خواند و برای ویژگی تکراری، مقدار دیرتر را جایگزین مقدار قبلی می‌کند.

این جایگزینی برای هر ویژگی جداگانه انجام می‌شود. اگر قانون دوم فقط color را دوباره بنویسد، ویژگی‌هایی مثل font-size که فقط در قانون اول آمده‌اند سر جایشان می‌مانند. قانون بعدی کل بلوک قبلی را پاک نمی‌کند؛ فقط ویژگی‌های مشترک را بازنویسی می‌کند. 

/* order.css */
.demo-order .first {
  color: #c92a2a;      /* قرمز */
  font-size: 20px;
}

.demo-order .first {
  color: #0b6e4f;      /* این دیرتر آمده → برنده برای color */
}

.demo-order .later-wins {
  background-color: #ffe0b2;   /* نارنجی روشن */
  padding: 10px;
  margin: 8px 0;
}

.demo-order .later-wins {
  background-color: #c3fae8;   /* سبز روشن → برنده */
}

پیشوند .demo-order فقط برای این است که قانون‌های این مثال به کادر «نتیجه» محدود شوند و روی بقیه صفحه اثر نگذارند. هر دو قانون این پیشوند را دارند، پس قدرتشان همچنان برابر است.

این متن سبز تیره است، نه قرمز؛ ولی اندازه ۲۰px از قانون اول هنوز اعمال می‌شود.

پس‌زمینه سبز روشن است، نه نارنجی.

مرورگر اول همه قوانین را جمع می‌کند، بعد برای هر ویژگی جداگانه تصمیم می‌گیرد. اینجا هر دو قانون برای color مقدار داده‌اند؛ پس رنگ آخر پیروز می‌شود. اما font-size فقط در قانون اول آمده و تداخلی ندارد؛ پس همان اعمال می‌شود. یعنی قانون دوم کل قانون اول را «پاک» نمی‌کند، فقط ویژگی‌های مشترک را بازنویسی می‌کند.

اشتباه رایج: فکر کردن که «قانون اول همیشه اعمال می‌شود»، یا برعکس، تصور کردن که قانون دوم همهٔ قانون اول را بی‌اثر می‌کند. در قدرت برابر، برای هر ویژگی که در هر دو قانون آمده مقدار قانون آخر می‌ماند و بقیه ویژگی‌ها از همان قانونی جمع می‌شوند که آن‌ها را نوشته است.

تمرین: در فایل order.css جای دو قانون .first را عوض کنید. رنگ متن چه می‌شود؟
