۶) چند کلاس هم‌قدرت روی یک عنصر

یک عنصر می‌تواند هم‌زمان چند کلاس داشته باشد، مثلاً class="red green blue". اگر برای هر کلاس یک قانون جدا نوشته باشید و قدرت همهٔ آن قانون‌ها برابر باشد، مرورگر به ترتیب اسم‌ها در HTML نگاه نمی‌کند. ترتیب کلاس‌ها در صفت class هیچ اولویتی ایجاد نمی‌کند؛ نه کلاس سمت راست برنده است و نه کلاس سمت چپ. چیزی که تصمیم می‌گیرد این است که کدام قانون در فایل CSS پایین‌تر نوشته شده باشد. همان قانون، برای ویژگی‌های مشترک، مقدار نهایی را تعیین می‌کند.

اگر یکی از کلاس‌ها اصلاً قانونی برای آن ویژگی نداشته باشد، از رقابت کنار می‌رود. در مثال زیر هر سه کلاس color دارند و قدرت‌شان یکی است، پس قانون .blue که آخر آمده رنگ را تعیین می‌کند، چه در HTML اول نوشته شده باشد و چه آخر. 

/* tie-break.css — همه (0, 2, 0) هستند */
.demo-tie .red   { color: #c92a2a; font-size: 20px; }
.demo-tie .green { color: #0b6e4f; font-size: 20px; }
.demo-tie .blue  { color: #1a5fb4; font-size: 20px; }   /* آخر → برنده برای color */
<!-- ترتیب کلاس در HTML عوض شده، ولی نتیجه یکی است -->
<p class="red green blue">...</p>
<p class="blue green red">...</p>

کلاس‌ها: red green blue → رنگ آبی

کلاس‌ها: blue green red → باز هم آبی

کلاس‌ها: red green → سبز (چون green در CSS بعد از red است)

کلاس‌ها: green red → باز هم سبز

برای به‌خاطرسپردن، در تداخل هم‌قدرت به ترتیب قانون‌ها در فایل CSS نگاه کنید، نه به ترتیب اسم کلاس‌ها داخل تگ HTML. جابه‌جا کردن کلاس‌ها در class ظاهر را عوض نمی‌کند؛ جابه‌جا کردن بلوک‌ها در stylesheet عوض می‌کند.

اشتباه رایج: فکر کردن که کلاس سمت چپ یا راست در class="..." اولویت دارد. مرورگر صفت کلاس را فقط فهرست عضویت عنصر می‌داند و برای حل تداخل به محل قانون در CSS برمی‌گردد.

جمع‌بندی کل مجموعه

  1. اول ببینید اعلانی !important دارد یا نه؛ اعلان مهم از اعلان عادی برنده است (و آن را فقط در موارد ضروری استفاده کنید).
  2. اگر هیچ‌کدام !important نباشد، استایل درون‌خطی (style="...") از هر انتخابگری که در فایل CSS نوشته شده قوی‌تر است.
  3. بین قانون‌های عادی، قدرت انتخابگر را ستون به ستون مقایسه کنید: اول شناسه، بعد کلاس و شبه‌کلاس، و در آخر نام تگ.
  4. فقط وقتی هر سه ستون قدرت برابر باشند، قانونی که دیرتر آمده برنده است؛ چه پایین‌تر در همان فایل باشد و چه در فایل CSSای که دیرتر لینک شده.
  5. اگر هیچ قانونی برای آن ویژگی نبود، ویژگی‌های ارثی مقدار والد را می‌گیرند و بقیه مقدار اولیه را.

تمرین: در tie-break.css قانون .green را به پایین فایل ببرید. رنگ دو پاراگراف اول چه می‌شود؟
