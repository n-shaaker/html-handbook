## صورت مسئله

پنل مدیریت «فروشگاه کتاب نوروز» یک مشکل ظاهری دارد: متن دکمه **«حذف»** آبی روی قرمز است و خوانده نمی‌شود،
و وقتی ماوس را رویش می‌برید رنگش تغییر نمی‌کند. همکار قبلی برای «درست کردن» مشکلات، چند `!important` و
چند انتخابگر عجیب اضافه کرده و حالا هر تغییر کوچکی یک جای دیگر را خراب می‌کند.

تیم تصمیم گرفته قانونی بگذارد: **در CSS نه `!important`، نه انتخابگر id**. شما باید فایل
[`starter/style.css`](starter/style.css) را طوری بازنویسی کنید که صفحه دقیقاً طبق مشخصات زیر نمایش داده شود.

## مشخصات ظاهری مورد انتظار

| بخش | ظاهر |
| --- | --- |
| کل صفحه | محتوا حداکثر `720px` و وسط صفحه |
| کارت معمولی | پس‌زمینه سفید، کادر خاکستری `1px`، گوشه گرد، padding |
| کارت ویژه (`.featured`) | مثل کارت معمولی، ولی کادر طلایی `2px` |
| تیتر کارت | سرمه‌ای |
| لینک متنی داخل کارت («مشاهده صفحه محصول») | آبی و زیرخط‌دار |
| همه دکمه‌ها (`.btn`) | **بدون** زیرخط، پس‌زمینه خاکستری روشن، متن تیره؛ در hover کمی تیره‌تر |
| دکمه انتشار (`.btn-primary`) | پس‌زمینه سبز، متن سفید؛ در hover سبز تیره‌تر |
| دکمه حذف (`.btn-danger`) | پس‌زمینه قرمز، متن سفید؛ در hover قرمز تیره‌تر |
| دکمه پانویس («بازگشت به داشبورد») | دقیقاً مثل یک `.btn` معمولی |

## الزامات

1. پوشه `starter` را کپی کنید و فقط `style.css` را تغییر دهید. `index.html` را تغییر ندهید (کلاس `app` از قبل روی `div` هست).
2. صفحه نهایی دقیقاً طبق جدول بالا نمایش داده شود — همه حالت‌ها، از جمله hover هر سه نوع دکمه، داخل و بیرون کارت.
3. در کل فایل **هیچ** `!important` نباشد.
4. در کل فایل **هیچ** انتخابگر id (`#…`) نباشد.
5. قدرت **هیچ** انتخابگری از `(0, 2, 1)` بیشتر نباشد.
6. وصله‌های اضافه حذف شوند؛ هر قانونی که بعد از بازنویسی دیگر اثری ندارد باید پاک شود.
7. یک فایل `notes.md` بنویسید که در آن:
   - ریشه اصلی مشکل را در یک یا دو جمله توضیح دهید (کدام قانون و چرا)؛
   - برای هر تغییر، انتخابگر قبل و بعد و قدرت هر دو را بنویسید؛
   - قوی‌ترین انتخابگر فایل نهایی و قدرتش را مشخص کنید.

## محدودیت‌ها

- بدون `!important`، بدون id در CSS، سقف قدرت `(0, 2, 1)`.
- بدون استایل درون‌خطی و بدون تغییر HTML.
- رنگ‌ها و اندازه‌های فعلی را عوض نکنید؛ ظاهر هدف همان است که همکار می‌خواست.

## امتیازی (تا ۲ نمره)

- قوی‌ترین انتخابگر فایل شما حداکثر `(0, 2, 0)` باشد.
- در `notes.md` توضیح دهید اگر کسی بعداً قانون `.btn` را به انتهای فایل منتقل کند، چه چیزی خراب می‌شود و چرا.

| بند | نمره |

## نکته استاد

- قبل از هر تغییری، در DevTools روی دکمه «حذف» کلیک راست کنید و ببینید رنگ متن از کدام قانون می‌آید. ریشه را پیدا کنید، نه علامت را.
- راه حل این نیست که دکمه‌ها را قوی‌تر کنید؛ گاهی باید قانونی را که بی‌دلیل قوی است **ضعیف** کنید.
- بعد از حذف هر `!important`، صفحه را دوباره امتحان کنید؛ بعضی‌هایشان بعد از اصلاح ریشه دیگر لازم نیستند.
