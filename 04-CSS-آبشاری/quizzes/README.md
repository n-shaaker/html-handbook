# تمرین‌ها و پروژه‌های عملی — آبشاری بودن CSS

این تمرین‌ها مهارت **فکر کردن مثل مرورگر** را می‌سازند: اینکه بدانید کدام قانون برنده می‌شود، چرا، و چطور بدون `!important` درستش کنید.
تمرین‌ها دو بخش دارند:

1. **بخش اول — تمرین‌های مبحثی** ([`1-topic-exercises`](1-topic-exercises)): برای هر درس یک پوشه با **سه تمرین کوتاه** (⭐ ← ⭐⭐ ← ⭐⭐⭐).
   دو نوع تمرین دارید: **«پیش‌بینی کن، بعد بررسی کن»** (پاسخ در یک فایل `answers.md`) و **«بدون !important درستش کن»** (اصلاح کد).
   هر تمرین فقط از همان درس و درس‌های قبلی استفاده می‌کند و ۱۰ تا ۲۵ دقیقه وقت می‌گیرد.
2. **بخش دوم — پروژه‌های ترکیبی** ([`2-combined-projects`](2-combined-projects)): پروژه‌هایی که چند مبحث بخش اول را **هدفمند** کنار هم می‌گذارند.

## روش کار

**برای هنرجو:**

1. بخش اول را **به ترتیب** و مبحث به مبحث جلو بروید؛ بعد از هر درس، تمرین‌های همان مبحث را حل کنید.
2. داخل پوشه هر مبحث (یا هر پروژه) یک پوشه به اسم خودتان بسازید، **کنار** پوشه `starter`، و محتوای `starter` را در آن کپی کنید.
3. در تمرین‌های پیش‌بینی، **اول** فایل پاسخ‌نامه (`ex-N-answers.md`) را بدون باز کردن صفحه پر کنید و **بعد** با DevTools بررسی کنید.
   پیش‌بینی غلط را پاک نکنید؛ کنارش بنویسید کجا اشتباه کردید. نمره برای استدلال است، نه فقط جواب.
4. ابزار اصلی شما DevTools است (F12 یا کلیک راست ← Inspect ← تب Styles و Computed). قانون‌های خط‌خورده همان بازنده‌ها هستند.
   مبحث ۷ مخصوص همین ابزار است؛ اگر با DevTools راحت نیستید، تمرین ۱ آن را زودتر حل کنید.
5. بعد از تمام شدن بخش اول، سراغ بخش دوم بروید.
6. پوشه `solution` را قبل از حل کردن باز نکنید.

## برای استاد

- در بخش اول، پاسخ تمرین‌های پیش‌بینی در `solution/ex-N-answers.md` (با دلیل و قدرت انتخابگرها) و پاسخ تمرین‌های اصلاحی در `solution/ex-N.html` و فایل‌های CSS همان تمرین است.
- در بخش دوم: پروژه ۱ `solution/answers.md`، پروژه ۳ و ۵ `solution/notes.md` (ریشه مشکل و راه‌حل جایگزین)، پروژه ۲ و ۴ فایل CSS نمونه.
- پاسخ‌های اصلاحی نمونه‌اند؛ هر راه‌حلی که الزامات و محدودیت‌ها را رعایت کند قابل قبول است.
- تمرین‌های بخش اول بارم ندارند؛ پیشنهاد: ⭐ = ۱، ⭐⭐ = ۲، ⭐⭐⭐ = ۳ امتیاز. پروژه‌های بخش دوم جدول بارم‌بندی از ۲۰ دارند.

## نکات کلی نمره‌دهی

- قدرت انتخابگرها را به‌صورت سه‌تایی `(id, کلاس, نوع)` بنویسید؛ پاسخ بدون دلیل، نصف نمره دارد.
- در تمرین‌ها و پروژه‌های اصلاحی، هر `!important` یا انتخابگر id که خود هنرجو اضافه کند **۲ نمره** کسر دارد
  (به‌جز کلاس‌های کمکی که در تمرین ۳ مبحث `!important` با دلیل نگه داشته می‌شوند).
- استایل درون‌خطی فقط در تمرین‌هایی آمده که درباره خود آن هستند؛ هنرجو آن را اضافه نمی‌کند.
- کد CSS باید بخش‌بندی شده (با توضیح‌های کوتاه) و تورفتگی یکدست داشته باشد؛ کد درهم تا ۱ نمره کسر دارد.
- بخش «امتیازی» پروژه‌ها تا ۲ نمره اضافه دارد، ولی جمع نمره از ۲۰ بیشتر نمی‌شود.
