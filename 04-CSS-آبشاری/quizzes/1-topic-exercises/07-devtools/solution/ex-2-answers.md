# پاسخ تمرین ۲

| ویژگی | مقدار نهایی | از کجا آمده؟ |
| --- | --- | --- |
| `font-size` | `19.8px` | ارث از `p.intro`: ۱٫۱ × ۱۸ (اندازه `.article`) |
| `color` | `rgb(52, 58, 64)` | ارث از `article.article` (`#343a40`)؛ رنگ `body` بازنده است |
| `line-height` | `37.62px` | ارث از `.article`؛ عدد بدون واحد ۱٫۹ در اندازه فونت **خود** عنصر ضرب می‌شود: ۱٫۹ × ۱۹٫۸ |
| `font-weight` | `700` | قانون پیش‌فرض مرورگر برای `strong` (در DevTools: user agent stylesheet) |
| `font-family` | `Tahoma, sans-serif` | ارث از `body` |

پرسش: تب Computed مقدار **نهایی محاسبه‌شده** را نشان می‌دهد و مرورگر همه رنگ‌ها را به یک شکل استاندارد (`rgb`) برمی‌گرداند. `#343a40` همان `rgb(52, 58, 64)` است.

راهنمای DevTools: در تب Computed روی فلش کنار هر ویژگی کلیک کنید تا قانونی که مقدار از آن آمده (و قانون‌های بازنده) نشان داده شود.
