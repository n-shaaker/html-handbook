# پاسخ تمرین ۳

۱. صف CSS به ترتیب سند: `ex-3-a.css` ← تگ `style` ← `ex-3-c.css` (با `@import` آمده و **جای** خط import، یعنی قبل از قانون‌های خود `b`، قرار می‌گیرد) ← قانون‌های `ex-3-b.css`.

۲.

| پیام | رنگ | دلیل |
| --- | --- | --- |
| `msg` | نارنجی | سه قانون هم‌قدرت در `a`، `style` و `c`؛ آخرینشان در `c` است. |
| `note` | بنفش | `style` و `b`؛ `b` دیرتر است. |
| `tag` | نارنجی | `a` و `c`؛ `c` دیرتر است. |

۳. `20px`؛ فقط در `ex-3-a.css` آمده و رقیبی ندارد.

۴. `@import` فقط وقتی معتبر است که **اول** فایل باشد (قبل از هر قانون دیگر). اگر پایین برود، مرورگر آن را نادیده می‌گیرد
و `ex-3-c.css` اصلاً بارگذاری نمی‌شود. نتیجه: `msg` سبز (از `style`) و `tag` قرمز (از `a`) می‌شود؛ `note` همان بنفش می‌ماند.
در DevTools تب Network می‌بینید که `ex-3-c.css` دیگر درخواست نمی‌شود.
