# مبحث ۳ — چند فایل CSS و ترتیب لینک

درس مرتبط: [چند فایل CSS و ترتیب لینک](../../../pages/03-stylesheets.html)

قاعده این مبحث: همه CSSهای صفحه (فایل‌های `link`، تگ‌های `style` و فایل‌های `@import`) به ترتیب سند در یک صف قرار می‌گیرند. بین قانون‌های هم‌قدرت، هر کدام دیرتر در صف باشد برنده است.

---

## تمرین ۱ — دو فایل CSS ⭐

**هدف:** پیش‌بینی نتیجه وقتی دو فایل خارجی برای یک عنصر قانون دارند.

**صورت مسئله:** صفحه انجمن عکاسان ([`starter/ex-1.html`](starter/ex-1.html)) دو فایل دارد: `ex-1-base.css` و بعد `ex-1-theme.css`.

**الزامات:**

- بدون باز کردن صفحه، جدول [`starter/ex-1-answers.md`](starter/ex-1-answers.md) را پر کنید.
- برای پاراگراف داخل جعبه، قدرت دو انتخابگر رقیب را بنویسید.
- به پرسش اضافه جواب دهید و بعد با DevTools بررسی کنید (DevTools نام فایل هر قانون را کنارش نشان می‌دهد).

**خروجی مورد انتظار:** تیتر نارنجی ولی `28px`؛ پاراگراف داخل جعبه آبی، چون ترتیب فایل‌ها فقط بین قانون‌های **هم‌قدرت** مهم است.

---

## تمرین ۲ — فایل سفارشی که اثر ندارد ⭐⭐

**هدف:** درست کردن ترتیب لینک فایل‌ها و هم‌قدرت کردن انتخابگر با فایل کیت.

**صورت مسئله:** آموزشگاه آشپزی یک کیت آماده (`ex-2-kit.css`) و یک فایل رنگ‌های سایت (`ex-2-custom.css`) دارد ([`starter/ex-2.html`](starter/ex-2.html)). هیچ‌کدام از رنگ‌های نارنجی سایت دیده نمی‌شوند.

**الزامات:**

- مشکل اول را فقط با تغییر **ترتیب لینک‌ها** در HTML حل کنید.
- بعد از آن، دکمه هنوز خاکستری است. با DevTools علت را پیدا کنید و فقط در `ex-2-custom.css` درستش کنید.
- فایل کیت را تغییر ندهید؛ بدون `!important`.

**خروجی مورد انتظار:** کادر کارت، تیتر و دکمه نارنجی. علت مشکل دوم: انتخابگر کیت `.card .btn` (0,2,0) از `.btn` (0,1,0) قوی‌تر است؛ دیرتر آمدن فایل فقط بین هم‌قدرت‌ها کمک می‌کند.

---

## تمرین ۳ — link، style و @import ⭐⭐⭐

**هدف:** ساختن صف کامل CSS از `link`، `style` و `@import` و پیش‌بینی نتیجه.

**صورت مسئله:** [`starter/ex-3.html`](starter/ex-3.html) یک `link`، یک تگ `style` و یک `link` دیگر دارد و فایل دوم خودش با `@import` فایل سومی را می‌آورد.

**الزامات:**

- به چهار پرسش [`starter/ex-3-answers.md`](starter/ex-3-answers.md) جواب دهید.
- پرسش ۴ را بعد از پیش‌بینی، با تغییر **موقت** فایل امتحان کنید و بعد فایل را به حالت اول برگردانید.

**خروجی مورد انتظار:** صف: `a` ← `style` ← `c` ← `b`. پیام اول و سوم نارنجی، پیام دوم بنفش.

---

## اشتباه‌های رایج این مبحث

- فکر کردن اینکه فایل دیرتر **همیشه** برنده است؛ قدرت انتخابگر قبل از ترتیب بررسی می‌شود.
- لینک کردن فایل سفارشی قبل از کتابخانه یا کیت آماده.
- نوشتن `@import` وسط یا پایین فایل؛ آن‌وقت نادیده گرفته می‌شود.
- فراموش کردن اینکه تگ `style` هم جزو همین صف است و جایش در `head` مهم است.
