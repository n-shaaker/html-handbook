# پاسخ تمرین ۱

| ویژگی والد | پاراگراف | لینک | دکمه |
| --- | --- | --- | --- |
| `color` | ارث می‌برد | نمی‌برد (مرورگر به لینک رنگ مستقیم می‌دهد) | نمی‌برد (مرورگر رنگ مستقیم می‌دهد) |
| `font-family` | ارث می‌برد | ارث می‌برد | نمی‌برد (مرورگر برای دکمه فونت مستقیم دارد) |
| `line-height` | ارث می‌برد | ارث می‌برد | نمی‌برد (در فونت پیش‌فرض دکمه تعیین شده) |
| `text-align` | ارث می‌برد | ارث می‌برد | نمی‌برد (مرورگر خودش `center` گذاشته؛ ولی خود دکمه چون `inline-block` است، با `text-align` والد وسط خط می‌رود) |
| `border` | نمی‌برد | نمی‌برد | نمی‌برد (کادر دکمه مال خود مرورگر است) |
| `padding` | نمی‌برد | نمی‌برد | نمی‌برد |
| `background-color` | نمی‌برد | نمی‌برد | نمی‌برد |

پرسش ۱: نه. پس‌زمینه فرزند به طور پیش‌فرض **شفاف** است و ما از پشت آن، پس‌زمینه والد را می‌بینیم.
جعبه `.box` این را ثابت می‌کند: پس‌زمینه سفید خودش را دارد.

پرسش ۲: وراثت فقط وقتی کار می‌کند که برای آن ویژگی **هیچ** قانونی مستقیماً روی خود عنصر نباشد.
مرورگر در CSS پیش‌فرض خودش (در DevTools با عنوان user agent stylesheet) برای `a:link` رنگ آبی گذاشته و هر قانون مستقیم از مقدار ارثی قوی‌تر است.
