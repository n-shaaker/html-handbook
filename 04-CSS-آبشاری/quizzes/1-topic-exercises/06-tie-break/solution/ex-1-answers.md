# پاسخ تمرین ۱

| جمله | رنگ | اندازه | دلیل |
| :---: | --- | --- | --- |
| ۱ | آبی | پیش‌فرض | سه کلاس هم‌قدرت؛ `.blue` در CSS پایین‌تر از بقیه است. |
| ۲ | آبی | پیش‌فرض | ترتیب کلاس‌ها در HTML هیچ اثری ندارد؛ باز هم `.blue` پایین‌تر است. |
| ۳ | سبز | پیش‌فرض | `.green` در CSS بعد از `.red` آمده. |
| ۴ | پیش‌فرض | `14px` | `.small` در CSS بعد از `.big` آمده، با اینکه در HTML اول نوشته شده. |
| ۵ | آبی | `24px` | رنگ: `.blue` آخرین کلاس رنگی؛ اندازه: فقط `.big`. |
| ۶ | نارنجی | `14px` | `.red.small` قدرت (0,2,0) دارد و از `.red` (0,1,0) قوی‌تر است؛ بالاتر بودنش مهم نیست. |

قاعده: بین کلاس‌های هم‌قدرت، به **فایل CSS** نگاه کنید، نه به ترتیب نام‌ها در `class="..."`.
