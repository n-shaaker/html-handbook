# مبحث ۶ — چند کلاس هم‌قدرت روی یک عنصر

درس مرتبط: [چند کلاس هم‌قدرت روی یک عنصر](../../../pages/06-tie-break.html)

قاعده این مبحث: ترتیب کلاس‌ها در `class="..."` مهم **نیست**؛ بین کلاس‌های هم‌قدرت، قانونی که در فایل CSS پایین‌تر است برنده است.

---

## تمرین ۱ — ترتیب کلاس‌ها در HTML ⭐

**هدف:** تشخیص اینکه نتیجه را ترتیب CSS تعیین می‌کند، نه ترتیب کلاس‌ها در HTML.

**صورت مسئله:** [`starter/ex-1.html`](starter/ex-1.html) شش جمله با ترکیب‌های مختلف کلاس دارد.

**الزامات:**

- جدول [`starter/ex-1-answers.md`](starter/ex-1-answers.md) را قبل از باز کردن صفحه پر کنید.
- برای جمله ۶ قدرت دو انتخابگر رقیب را بنویسید.
- با DevTools بررسی کنید.

**خروجی مورد انتظار:** جمله ۱ و ۲ هر دو آبی‌اند؛ جمله ۶ نارنجی است.

---

## تمرین ۲ — پایه، نوع، حالت ⭐⭐

**هدف:** چیدن قانون‌های هم‌قدرت به ترتیب «پایه ← نوع ← حالت».

**صورت مسئله:** پنل مدیریت یک فروشگاه ([`starter/ex-2.css`](starter/ex-2.css)) چهار دکمه دارد، ولی همه خاکستری‌اند و دکمه‌های غیرفعال هم شبیه بقیه‌اند.

**الزامات:**

- علت را در یک جمله بنویسید.
- فقط با جابه‌جا کردن قانون‌ها مشکل را حل کنید؛ بدون تغییر انتخابگرها، بدون `!important`، بدون تغییر HTML.
- سه بخش با توضیح بسازید: پایه، نوع، حالت.

**خروجی مورد انتظار:** «ذخیره» آبی، «حذف» قرمز، و هر دو دکمه غیرفعال خاکستری کم‌رنگ با نشانگر ممنوع.

---

## تمرین ۳ — کل الگوریتم آبشار ⭐⭐⭐

**هدف:** اجرای همه مراحل تصمیم آبشار به ترتیب درست، برای هر عنصر.

**صورت مسئله:** در [`starter/ex-3.html`](starter/ex-3.html) شش جمله داریم که هر کدام در یک مرحله متفاوت تکلیفشان روشن می‌شود.

**الزامات:**

- مراحل تصمیم مرورگر را به ترتیب بنویسید.
- برای هر جمله رنگ و مرحله تعیین‌کننده را در [`starter/ex-3-answers.md`](starter/ex-3-answers.md) بنویسید.
- با DevTools بررسی کنید؛ برای جمله ۵ بخش «Inherited from» را پیدا کنید.

**خروجی مورد انتظار:** هر پنج مرحله (`!important`، درون‌خطی، قدرت، ترتیب، وراثت) دست‌کم یک بار در جدول آمده است.

---

## اشتباه‌های رایج این مبحث

- فکر کردن اینکه کلاس اول یا آخر در `class="..."` اولویت دارد.
- نوشتن کلاس حالت (`is-disabled`، `is-active`) بالای فایل؛ کلاس‌های نوع آن را می‌برند.
- نوشتن قانون پایه (`.btn`) پایین فایل که همه نوع‌ها را بازنویسی می‌کند.
- یادتان باشد ترتیب فقط **آخرین** مرحله است؛ اول `!important`، درون‌خطی و قدرت بررسی می‌شوند.
