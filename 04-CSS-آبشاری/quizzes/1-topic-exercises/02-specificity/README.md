# مبحث ۲ — قدرت انتخابگر (Specificity)

درس مرتبط: [قدرت انتخابگر](../../../pages/02-specificity.html)

قدرت را همیشه به شکل سه‌تایی `(id, کلاس, نوع)` بنویسید و ستون به ستون از چپ مقایسه کنید.

---

## تمرین ۱ — محاسبه قدرت ⭐

**هدف:** محاسبه قدرت انتخابگرها به‌صورت سه‌تایی و مرتب کردن آن‌ها.

**صورت مسئله:** هم‌تیمی شما ده انتخابگر از پروژه‌های مختلف جمع کرده و می‌خواهد بداند کدام قوی‌تر است.

**الزامات:**

- جدول [`starter/ex-1-answers.md`](starter/ex-1-answers.md) را پر کنید.
- ده انتخابگر را از قوی‌ترین به ضعیف‌ترین مرتب کنید و انتخابگرهای هم‌قدرت را مشخص کنید.
- برای ردیف‌های ۶، ۸ و ۱۰ یک جمله توضیح بنویسید.

**خروجی مورد انتظار:** مثلاً `#header .nav a` برابر (1, 1, 1) و `:where(.card) p` برابر (0, 0, 1).

---

## تمرین ۲ — پیش‌بینی برنده ⭐⭐

**هدف:** استفاده از قدرت انتخابگر برای پیش‌بینی رنگ نهایی چند عنصر.

**صورت مسئله:** کارت محصول ([`starter/ex-2.html`](starter/ex-2.html) و [`starter/ex-2.css`](starter/ex-2.css)) رنگ‌های غیرمنتظره دارد.

**الزامات:**

- برای هر عنصر، همه قانون‌هایی که به آن رنگ می‌دهند را با قدرتشان بنویسید ([`starter/ex-2-answers.md`](starter/ex-2-answers.md)).
- رنگ نهایی را پیش‌بینی کنید.
- با DevTools بررسی کنید و به پرسش آخر جواب دهید.

**خروجی مورد انتظار:** تیتر آبی، قیمت سبز ولی پررنگ، توضیح سبز، لینک آبی.

---

## تمرین ۳ — نجات دکمه از دست id ⭐⭐⭐

**هدف:** رفع تداخل با **کم کردن** قدرت انتخابگر قوی، نه بالا بردن بی‌حساب انتخابگر ضعیف.

**صورت مسئله:** در ستون کناری یک فروشگاه ([`starter/ex-3.css`](starter/ex-3.css)) دکمه «عضویت در خبرنامه» به جای متن سفید بدون زیرخط، متن آبی زیرخط‌دار دارد.

**الزامات:**

- با DevTools پیدا کنید کدام قانون برنده شده و قدرت دو قانون رقیب را بنویسید.
- انتخابگر id را از فایل حذف کنید (HTML کلاس `sidebar` هم دارد).
- کاری کنید که دکمه و حالت hover آن درست دیده شوند، با **کمترین** قدرت لازم.
- بدون `!important` و بدون هیچ انتخابگر id؛ HTML را تغییر ندهید.
- قدرت انتخابگرهای جدید را در توضیح کنارشان بنویسید.

**خروجی مورد انتظار:** لینک‌های متنی آبی و زیرخط‌دار، دکمه سبز با متن سفید. یک راه دیگر قابل قبول: `:where(.sidebar) a` با قدرت (0, 0, 1) که دیگر از `.btn` نمی‌برد.

---

## اشتباه‌های رایج این مبحث

- جمع زدن ستون‌ها مثل یک عدد (مثلاً ۱۱ کلاس از یک id قوی‌تر نمی‌شود؛ ستون id همیشه اول مقایسه می‌شود).
- امتیاز دادن به فاصله، `>` یا `*`؛ این‌ها امتیازی ندارند.
- فراموش کردن اینکه شبه‌کلاس (`:hover`) و صفت (`[type]`) در ستون کلاس‌اند.
- حل کردن تداخل با اضافه کردن id یا `!important`؛ مشکل را برای تغییر بعدی سخت‌تر می‌کند.
