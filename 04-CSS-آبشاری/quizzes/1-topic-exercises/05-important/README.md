# مبحث ۵ — استفاده از !important

درس مرتبط: [استفاده از !important](../../../pages/05-important.html)

قاعده این مبحث: اعلان `!important` از هر اعلان عادی می‌برد (حتی از id و استایل درون‌خطی). اگر هر دو طرف `!important` باشند، دوباره قدرت انتخابگر و بعد ترتیب تصمیم می‌گیرند.

---

## تمرین ۱ — پیش‌بینی با !important ⭐

**هدف:** پیش‌بینی نتیجه وقتی `!important` با id، با `!important` دیگر و با استایل درون‌خطی روبه‌رو می‌شود.

**صورت مسئله:** [`starter/ex-1.html`](starter/ex-1.html) چهار پیام دارد و [`starter/ex-1.css`](starter/ex-1.css) چند `!important`.

**الزامات:**

- جدول [`starter/ex-1-answers.md`](starter/ex-1-answers.md) را قبل از باز کردن صفحه پر کنید.
- برای پیام ۲ قدرت دو انتخابگر را بنویسید.
- با DevTools بررسی کنید.

**خروجی مورد انتظار:** پیام ۱ قرمز، ۲ بنفش، ۳ آبی، ۴ قرمز.

---

## تمرین ۲ — حذف !important با قدرت درست ⭐⭐

**هدف:** جایگزین کردن `!important` با درست کردن ریشه مشکل (انتخابگر id).

**صورت مسئله:** منوی کافه ([`starter/ex-2.css`](starter/ex-2.css)) دو `!important` دارد، چون `#menu p` همه رنگ‌ها را می‌برد.

**الزامات:**

- علت وجود هر `!important` را با DevTools پیدا کنید (موقتاً آن را بردارید و ببینید چه می‌شود).
- هر دو `!important` و انتخابگر id حذف شوند (HTML کلاس `menu` هم دارد).
- ظاهر تغییر نکند: قیمت‌ها قرمز و پررنگ، قیمت تمام‌شده خاکستری و خط‌خورده.
- HTML را تغییر ندهید.

**خروجی مورد انتظار:** فایل بدون `!important` و بدون `#`؛ قیمت تمام‌شده خاکستری است چون `.menu .sold-out` هم‌قدرت با `.menu .price` و پایین‌تر است.

---

## تمرین ۳ — کدام !important بماند؟ ⭐⭐⭐

**هدف:** تشخیص `!important` قابل دفاع (کلاس کمکی) از `!important` وصله‌ای.

**صورت مسئله:** گل‌فروشی «یاس» ([`starter/ex-3.css`](starter/ex-3.css)) پنج `!important` دارد. مدیر فنی گفته: «هر کدام دلیل محکم ندارد، حذفش کن.»

**الزامات:**

- برای هر پنج مورد در [`starter/ex-3-answers.md`](starter/ex-3-answers.md) بنویسید بماند یا حذف شود و چرا.
- موارد حذفی را واقعاً حذف کنید و با راه درست (کم کردن قدرت رقیب یا جابه‌جا کردن قانون) جایگزین کنید.
- حداکثر **دو** `!important` باقی بماند و بالای فایل در یک بخش جدا با توضیح باشد.
- ظاهر صفحه، شامل hover دکمه، درست باشد؛ HTML را تغییر ندهید.

**خروجی مورد انتظار:** فقط `.text-center` و `.hidden` با `!important` ماندند؛ hover دکمه حالا کار می‌کند.

---

## اشتباه‌های رایج این مبحث

- فکر کردن اینکه `!important` کل قانون را مهم می‌کند؛ فقط همان یک اعلان مهم می‌شود.
- جنگ `!important` با `!important`؛ نتیجه دوباره به قدرت انتخابگر برمی‌گردد و مشکل بزرگ‌تر می‌شود.
- استفاده از `!important` به جای پیدا کردن قانون رقیب در DevTools.
- نوشتن `! important` با فاصله یا جای غلط (قبل از `;` و بعد از مقدار درست است).
