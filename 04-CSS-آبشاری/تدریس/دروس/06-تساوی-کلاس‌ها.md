## ۱) شروع — دیالوگ

«بچه‌ها، فرض کنید دکمه دارید:

```html
<button class="primary large disabled">ثبت</button>
```

و در CSS:

```css
.primary { background: blue; }
.large { background: green; }
.disabled { background: gray; }
```

یک دانشجو می‌گوید: «چون `disabled` **آخر** class list است، پس‌زمینه خاکستری می‌شود.»

یکی دیگر می‌گوید: «چون `primary` **اول** است، آبی.»

**کدام درست است؟** — یا **هیچ‌کدام**؟

امروز با [`tie-break.css`](../../css/demos/tie-break.css) ثابت می‌کنیم مرورگر به **فایل CSS** نگاه می‌کند، نه به ترتیب کلمات در attribute.»

---

## ۲) Live — سه class هم‌قدرت

```css
.demo-tie .red {
  color: #c92a2a;
  font-size: 20px;
}

.demo-tie .green {
  color: #0b6e4f;
  font-size: 20px;
}

.demo-tie .blue {
  color: #1a5fb4;
  font-size: 20px;
}
```

HTML:

```html
<div class="demo-tie">
  <p class="red green blue">ترتیب: red green blue</p>
  <p class="blue green red">ترتیب: blue green red</p>
  <p class="red green">فقط red green</p>
  <p class="green red">ترتیب: green red</p>
</div>
```

**در مرورگر (قبل از توضیح):** از کلاس بپرس رنگ پاراگراف اول و دوم.

**بعد از رفرش:** هر دو **آبی** — چون `.blue` **آخرین rule** در CSS است.

«ترتیب HTML عوض شد — رنگ **همان** آبی.»

### پاراگراف سوم و چهارم

- `red green` → **سبز** (`.green` بعد از `.red` در فایل).  
- `green red` → **باز هم سبز**.

### سؤال کلاسی

«اگر `.red` را پایین فایل ببریم چه می‌شود؟»  
**پاسخ:** برای عناصری که هر سه class را دارند، اگر `.blue` هنوز آخر باشد آبی؛ اگر `.red` آخر شود قرمز — **فقط** با edit CSS.

## ۳) مشاهده DevTools

Inspect `<p class="blue green red">` — هر سه rule `.red`, `.green`, `.blue` اعمال شده‌اند ولی دو `color` خط‌خورده.

---

## ۴) چک‌لیست cascade (از جزوه)

1. **!important** — بین important و normal.  
2. **inline** `style` — از almost file rules بدون important.  
3. **specificity** — ستون‌به‌ستون.  
4. **order** — پایین فایل / link دیرتر — **فقط اگر برابر**.  
5. **inherit / initial** — اگر rule نبود.

«درس ۶ جمع‌بندی ماژule است — این لیست را روی پوستر کلاس بزنید.»

---

## ۵) اشتباهات

| غلط | درست |
|-----|------|
| `class="btn primary"` → primary برنده چون آخر HTML | order در **CSS** |
| افزودن class بدون rule | آن class در tie رقابت نمی‌کند |
| BEM + utility war بدون ترتیب فایل | convention: utilities last در bundle |

## ۷) جمع‌بندی

1. `class="a b c"` — برنده color?  
   **پاسخ:** rule آخر در CSS برای آن classها با specificity `(0,2,0)` هر کدام.

2. فقط `red green` on element?  
   **پاسخ:** بین `.red` و `.green` — آن که پایین‌تر در CSS.

3. آیا tie-break به id کمک می‌کند؟  
   **پاسخ:** id specificity بالاتر — دیگر tie class pure نیست.
