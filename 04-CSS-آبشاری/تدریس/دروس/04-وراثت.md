## ۱) شروع کلاس — دیالوگ

«بچه‌ها، فرض کنید فقط این CSS را دارید:

```css
body { color: #1a3a5c; font-family: Tahoma, sans-serif; }
```

روی `<body>` هیچ `<p>` و `<h2>` استایل جدا ننوشته‌اید. باز هم همهٔ متن‌ها **آبی تیره** و **Tahoma** هستند.

سؤال: آیا مرورگر برای **هر** پاراگراف جداگانه `color` را copy-paste کرده؟ یا مکانیزم دیگری هست؟

و سؤال دوم: اگر روی `.parent` `border: 2px solid` بگذاریم، آیا `<div class="child">` داخلش **خودکار** همان border را می‌گیرد؟

امروز با [`inheritance.css`](../../css/demos/inheritance.css) جواب را **در مرورگر** می‌بینیم — مطابق جزوه، بدون حدس.»

---

## ۲) Live — ساختار demo

```html
<div class="demo-inherit">
  <div class="parent">
    <p>متن داخل parent</p>
    <div class="child-keep">فرزند بدون color</div>
    <div class="child-override">فرزند با color قرمز</div>
    <div class="no-inherit">فرزند با border خودش</div>
  </div>
</div>
```

### CSS مرحله ۱ — parent

در حین تایپ:

«رنگ، فونت serif، line-height، border و padding روی **والد**.»

```css
.demo-inherit .parent {
  color: #1a3a5c;
  font-family: Georgia, "Times New Roman", serif;
  line-height: 2;
  border: 2px solid #1a3a5c;
  padding: 12px;
}
```

**در مرورگر:** `<p>` داخل parent همان رنگ و فونت را دارد — **بدون rule جدا برای p**.

### CSS مرحله ۲ — child-keep

```css
.demo-inherit .child-keep {
  background-color: #e8f4fd;
  padding: 8px;
  margin: 8px 0;
}
```

**نمایش:** `color` و `font-family` **ارث** — پس‌زمینه و padding خودش.

### CSS مرحله ۳ — child-override

```css
.demo-inherit .child-override {
  color: #c92a2a;
  background-color: #fff5f5;
  padding: 8px;
  margin: 8px 0;
}
```

«وقتی روی فرزند `color` می‌نویسیم، **cascade روی همان عنصر** ارث را برای آن property قطع می‌کند.»

### CSS مرحله ۴ — no-inherit

```css
.demo-inherit .no-inherit {
  border: 2px dashed #e67700;
  padding: 8px;
  margin-top: 8px;
}
```

**نمایش:** border والد **دور کل parent** است؛ فرزند border **خودش** دارد — border به فرزند **ارث نمی‌رسد** (طبق جزوه).

### سؤال کلاسی

«`line-height` روی parent — فرزند بدون rule؟»  
**پاسخ:** ارثی — معمولاً همان line-height دیده می‌شود.

«`padding` parent داخل child-keep دیده می‌شود؟»  
**پاسخ:** padding ارثی نیست — فقط layout والد/فرزند جدا است.

---

## ۳) ارث vs cascade — یک جملهٔ کلیدی

«**Cascade** = چند rule به **یک عنصر** رسیدند — کدام برنده؟  
**Inheritance** = روی **این** عنصر rule نیست — از **والد** مقدار بگیر.»

### سؤال کلاسی

«`body { color: gray }` و `p { color: black }` — پاراگراف؟»  
**پاسخ:** سیاه — cascade روی p؛ نه ارث.

---

## ۴) keyword `inherit` (سطح جزوه)

«گاهی می‌خواهیم عمداً مقدار والد را بگیریم حتی برای property غیرارثی — در سطح پیشرفته `inherit` می‌آید. در این ماژule تمرکز روی رفتار پیش‌فرض استاندارد است.»

**اشتباه رایج:** فکر کردن همهٔ propertyها ارثی‌اند.

---

## ۵) em و font-size (اشارهٔ جزوه)

«واحد `em` در `font-size` فرزند نسبت به **computed font-size والد** است؛ فرزند **عبارت** `1.2em` را ارث نمی‌برد — مقدار **محاسبه‌شده** را. برای جزئیات به [`18-واحدها-تکمیلی`](../../../03-CSS-میانی/تدریس/دروس/18-واحدها-تکمیلی.md) بعداً برمی‌گردیم.»

---

## ۶) اشتباهات — غلط / درست

| غلط | درست |
|-----|------|
| انتظار border والد روی فرزند | border روی box خود والد |
| `color` روی div و انتظار برای `img` | img رفتار متفاوت — محتوا |
| فراموش کردن override روی `.child` | `color` صریح روی فرزند |

---

## ۷) پروژه mini — «مقالهٔ blog»

```html
<article class="demo-inherit parent">
  <h2>عنوان</h2>
  <p class="child-keep">Lead paragraph…</p>
  <p class="child-override">نقل‌قول با رنگ accent</p>
</article>
```

یک `color` روی `article` — همهٔ متن inherit؛ یک کلاس accent override.

---

## ۸) جمع‌بندی

1. سه property ارثی از جزوه؟  
   **پاسخ:** `color`, `font-family`, `line-height` (در demo parent).

2. `border` روی parent به child؟  
   **پاسخ:** خیر.

3. اگر rule مستقیم روی child باشد؟  
   **پاسخ:** cascade همان عنصر — ارث برای آن property قطع.

---

## تمرین‌ها (ساده → چالشی)

### ساده
1. فقط `body { font-family: ... }` — `h1` بدون rule.  
2. `child-keep` را inspect — computed `color` از کدام ancestor؟

### متوسط
3. `parent` را `line-height: 1.4` — فرزند override با `line-height: 2`.  
4. جدول: ۵ property بگو ارثی یا نه (border, color, margin, font-family, padding).

### چالشی
5. طراحی token: `body { color: var(--text) }` و یک `.muted` با override.  
6. تفاوت inherit و initial در یک جمله (بحث کوتاه).
