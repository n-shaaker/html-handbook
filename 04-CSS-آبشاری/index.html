آبشاری بودن CSS

وقتی چند قانون با هم تداخل دارند، کدام‌یک برنده می‌شود؟

Cascading (حرف C در نام CSS) یعنی قوانین CSS مثل آبشار روی هم می‌ریزند. مرورگر برای هر ویژگی (مثل color) فقط یک مقدار نهایی انتخاب می‌کند. در این مجموعه با مثال‌های جدا می‌بینید چه چیزی برنده را مشخص می‌کند.

فهرست مثال‌ها
  1. ترتیب قوانین در یک فایل
  2. قدرت انتخابگر (Specificity)
  3. چند فایل CSS و ترتیب لینک
  4. وراثت از والد به فرزند
  5. استفاده از !important
  6. چند کلاس هم‌قدرت روی یک عنصر
  7. متغیرهای CSS (Custom Properties)

خلاصه قانون آبشار

وقتی چند قانون برای یک ویژگی از یک عنصر مقدار می‌دهند، مرورگر این مراحل را به‌ترتیب بررسی می‌کند. هر مرحله که برنده را مشخص کرد، مراحل بعدی دیگر بررسی نمی‌شوند.

مرحله (به‌ترتیب بررسی) یعنی چه؟
۱. منبع و !important اعلان‌های !important از اعلان‌های عادی قوی‌ترند. در اعلان‌های عادی، CSS نویسنده (ما) از CSS پیش‌فرض مرورگر قوی‌تر است.
۲. استایل درون‌خطی صفت style="..." از هر انتخابگری در فایل CSS قوی‌تر است (مگر در برابر !important).
۳. قدرت انتخابگر (Specificity) id قوی‌تر از کلاس، و کلاس قوی‌تر از نام تگ است.
۴. ترتیب اگر همه‌چیز برابر بود، قانون پایین‌تر / فایلی که دیرتر لینک شده برنده است.
اگر هیچ قانونی نبود ویژگی‌های ارثی (مثل color) مقدار والد را می‌گیرند؛ بقیه (مثل border) مقدار اولیه (initial) را می‌گیرند.

همه ظاهر این مجموعه فقط با فایل‌های CSS خارجی نوشته شده است؛ بدون تگ style و بدون style="...".
