# پروژه منوی رستوران (استاتیک)

نمونهٔ کامل یک سایت رستوران با HTML و CSS — بدون JavaScript.

## پیش‌نیاز (اجباری)

قبل از ساختن یا تقلید این پروژه، این ماژول‌ها را تمام کنید:

1. [01 HTML مقدماتی](../01-HTML-مقدماتی/)
2. [02–05 CSS](../02-CSS-مقدماتی/) (مقدماتی، میانی، آبشاری، تصاویر)
3. **[12 CSS Flexbox](../12-CSS-Flexbox/)** ← بدون این، هدر و دکمه‌ها را نمی‌فهمید
4. **[13 CSS Grid](../13-CSS-Grid/)** ← بدون این، گرید غذاها را نمی‌فهمید
5. درس‌های Media Queries و Transition در [03 CSS میانی](../03-CSS-میانی/) (اگر اضافه شده‌اند)

> اگر فقط به ترتیب عددی پوشه‌ها آمده‌اید: الان بروید ۱۲ و ۱۳ را بخوانید، بعد برگردید.

## چطور از صفر بسازید (walkthrough)

کپی کردن `index.html` کافی نیست. به این ترتیب بسازید:

| مرحله | کار | نگاه کنید به |
| ---: | --- | --- |
| ۱ | اسکلت معنایی: `header`، `main`، `section`، `footer` | `index.html` خطوط سربرگ و main |
| ۲ | هیرو با تصویر پس‌زمینه و متن خوانا | `.hero` در `css/style.css` |
| ۳ | کارت غذا با `img` + `object-fit` | `.dish` |
| ۴ | چیدمان کارت‌ها با **Grid** | `.dishes-grid` |
| ۵ | نوار بالا با **Flex** | `.site-header`، `.main-nav` |
| ۶ | فرم رزرو و استایل `:focus` | `#reserve` |
| ۷ | واکنش‌گرایی با `@media` | انتهای `style.css` |
| ۸ | جزئیات: جدول، FAQ با `details`، آدرس | بخش‌های پایین صفحه |

## تمرین پیشنهادی

1. بدون نگاه به CSS، فقط HTML را از روی منوی واقعی یک کافه بنویسید.
2. بعد CSS را خودتان بنویسید؛ فقط وقتی گیر کردید `css/style.css` را باز کنید.
3. کوییزهای پوشه [`quizzes/`](quizzes/README.md) را انجام دهید (کپی از solution ممنوع است مگر برای چک نهایی).
