## صورت مسئله

صاحب رستوران نارنج کنار رستوران یک کافه کوچک به اسم **«کافه بهارنارنج»** باز کرده و یک صفحه منوی تک‌صفحه‌ای می‌خواهد. گفته: «همان چیدمان سایت رستوران خوب است، ولی رنگ کافه سبز و طلایی است و محتوا فرق دارد.»

## الزامات

1. HTML معتبر و معنایی: `header`، `nav` با `aria-label`، `main`، `section`های دارای `id`، `article` برای کارت، `table` با `caption`/`thead`/`tbody`/`tfoot` و `scope`، `footer` با `address`.
2. سربرگ با Flexbox: لوگو راست، منو چپ؛ در عرض کم منو زیر لوگو برود.
3. hero: عکس پس‌زمینه با `cover` + لایه `linear-gradient` + رنگ پشتیبان؛ محتوا وسط.
4. کارت‌ها: یک کلاس پایه برای همه، عکس هم‌ارتفاع با `object-fit: cover`، گوشه گرد با `overflow: hidden`، برچسب‌ها با کلاس کمکی.
5. کارت‌ها در شبکه سه‌ستونی Grid با `gap`.
6. تیتر هر بخش خط طلایی زیرش دارد؛ محتوای `main` حداکثر ۹۰۰px و وسط.
7. جدول: تمام‌عرض، `border-collapse`، سرستون سبز با متن سفید، ردیف‌های راه‌راه کرم، `tfoot` با `colspan`؛ جدول داخل یک ظرف با `overflow-x: auto`.
8. پاورقی سبز تیره با متن روشن، `address` بدون مورب، لینک تلفن قابل لمس.
9. **فقط یک** `@media (max-width: 600px)` که: Grid را تک‌ستونی کند، فاصله hero را کم کند و اندازه تیتر hero را کوچک کند.
10. همه رنگ‌ها از جدول رنگ کافه باشند.

## محدودیت‌ها

- JavaScript، `style` درون‌خطی و `!important` ممنوع است.
- فایل‌های پروژه نارنج را کپی نکنید؛ از نو بنویسید (نام کلاس‌ها لازم نیست با پروژه یکی باشد).
- متغیر CSS (`--...`) لازم نیست؛ رنگ‌ها را مستقیم بنویسید.
- عکس‌ها را از پوشه `images` پروژه بخوانید؛ کپی نکنید.

## امتیازی (حداکثر ۲ نمره اضافه)

- سربرگ هنگام اسکرول بالای صفحه بچسبد (`position: sticky`).
- بخش «نظر مهمان‌ها» با `blockquote` و `cite` با حاشیه طلایی.

## نکته استاد

- اول HTML کامل را بدون CSS بنویسید و ببینید صفحه بدون استایل هم مرتب و قابل فهم است؛ بعد سراغ CSS بروید.
- هر بخش را جدا از تمرین‌های بخش ۱ به یاد بیاورید، نه با کپی؛ این پروژه برای محک همین «به یاد آوردن» است.
- رنگ‌ها را یک بار بالای فایل CSS در یک کامنت فهرست کنید تا موقع نوشتن قانون‌ها اشتباه نکنید.
