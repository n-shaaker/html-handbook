# HTML Handbook — جزوه فرانت‌اند جونیور

مسیر خودآموز HTML، CSS و JavaScript برای ساخت یک سایت واقعی (لندینگ + تعامل).  
**لازم نیست خیلی پیشرفته باشد؛ باید کامل، کاربردی و قابل سلف‌استادی باشد.**

## ترتیب یادگیری

شماره پوشه‌ها همان ترتیب مطالعه است — از `01` تا `13` بروید:

```text
01 HTML → 02 CSS پایه → 03 CSS میانی (تا فرم‌ها)
    → 07 Flexbox → 08 Grid  ← در فهرست ۰۳ هم بعد از فرم‌ها آمده‌اند
    → ادامه ۰۳: چیدمان سایت + Media Queries (+ اختیاری: counters/units/math/transition/animation)
    → 04 آبشاری → 05 تصاویر → 06 رنگ
    → 09 پروژه رستوران (استاتیک)
    → 10 JS پایه → 11 JS میانی → 12 JS پیشرفته
    → 13 پروژه رستوران (JS)
```

## چطور مطالعه کنید

1. هر ماژول را از `index.html` شروع کنید، بعد `pages/` را به ترتیب بخوانید.
2. بعد از هر بخش، پوشه `quizzes/` را انجام دهید (starter → خودتان → solution).
3. برای فایل‌های JS ماژول و `type="module"`، از Live Server (یا سرور استاتیک محلی) استفاده کنید؛ باز کردن مستقیم `file://` بعضی درس‌ها را می‌شکند.
4. پروژه ۰۹ را بعد از Flex و Grid به‌عنوان کپ‌استون استاتیک بسازید؛ پروژه ۱۳ را بعد از DOM/فرم/storage.
