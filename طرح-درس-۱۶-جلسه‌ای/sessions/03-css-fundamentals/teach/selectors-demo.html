روش‌های اعمال CSS

CSS را به سه شکل به صفحه وصل می‌کنید. استایل اینلاین داخل ویژگی style همان عنصر نوشته می‌شود. استایل داخلی داخل عنصر style در head است، مثل قانون‌های همین صفحه. استایل خارجی یک فایل جداست که با <link rel="stylesheet"> به صفحه وصل می‌شود. در پروژهٔ واقعی روش سوم را به کار ببرید، چون یک فایل برای چند صفحه استفاده می‌شود و مرورگر آن را در حافظهٔ موقت نگه می‌دارد.

این پاراگراف رنگش را از CSS اینلاین گرفته است. قانون اینلاین از هر انتخاب‌گری در فایل CSS قوی‌تر است و فقط !important بر آن غلبه می‌کند. چون این رنگ داخل خود عنصر قفل شده، عوض کردنش در پروژهٔ بزرگ سخت است.

این پاراگراف با انتخاب‌گر کلاس (.highlight) رنگ زمینه گرفته است. کلاس را می‌توانید روی چند عنصر تکرار کنید، پس برای ظاهر مشترک، مثل برجسته‌کردن چند نکته، انتخاب مناسب است.

این پاراگراف با انتخاب‌گر شناسه (#warning) قرمز و پررنگ شده است. شناسه در هر صفحه باید یکتا باشد. آن را برای استایل نگه ندارید؛ برای مقصد پیوندهای داخلی و برای JavaScript مفیدتر است.

این جعبه آبشار (Cascade) را نشان می‌دهد. دو قانون .box اختصاصی‌بودن یکسانی دارند، پس قانونی که دیرتر در style نوشته شده برنده است و رنگ حاشیه را از خاکستری به آبی عوض می‌کند.

این پاراگراف هم کلاس note دارد و هم شناسهٔ special. رنگ بنفش شناسه برنده است، چون اختصاصی‌بودن انتخاب‌گر (Specificity) شناسه از کلاس بیشتر است. دیرتر نوشته شدن .note این برتری را عوض نمی‌کند. اختصاصی‌بودن را مثل امتیاز ببینید: شناسه از کلاس سنگین‌تر است و کلاس از نام عنصر.
