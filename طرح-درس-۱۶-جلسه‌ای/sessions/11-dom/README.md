# جلسه ۱۱ — DOM

**مدت:** ۱۲۰ دقیقه  
**هدف:** دانشجو صفحهٔ HTML را از طریق DOM با JavaScript عوض کند، یعنی عنصر را انتخاب کند، بسازد و به درخت صفحه اضافه کند، بدون آنکه فایل HTML را روی دیسک بازنویسی کند.  
**فایل‌ها:** برگهٔ دستورها در `teach/dom-cheatsheet.js`، و کارت پویا در `live/index.html`، `live/styles.css` و `live/app.js`

| زمان | کار |
|------|-----|
| ۰–۱۰ | شیء و آرایه را مرور کنید، چون کارت محصول از همین داده ساخته می‌شود و فقط روش وصل شدنش به صفحه عوض می‌شود. |
| ۱۰–۳۵ | DOM را به‌عنوان درخت صفحه معرفی کنید و `querySelector` و `querySelectorAll` را با یک انتخاب‌گر درست و یک انتخاب‌گر `null` نشان دهید. |
| ۳۵–۵۵ | `textContent`، `innerHTML`، `classList` و `style` را کنار هم بگذارید و نشان دهید فقط `textContent` متن بیرونی را اجرا نمی‌کند. |
| ۵۵–۷۵ | عنصر را با `createElement` بسازید، ویژگی بدهید و با `append` وارد صفحه کنید. یک بار `append` را فراموش کنید تا دیده شدن عنصر به والد وابسته باشد. |
| ۷۵–۱۰۵ | کارت محصول را از آرایه، زنده، داخل `#products` رسم کنید. |
| ۱۰۵–۱۲۰ | دانشجو حذف کارت و نشان «پرفروش» را اضافه کند و جمع‌بندی کنید که رسم دوباره باید از داده شروع شود نه از وصلهٔ تک‌کارت. |

`teach/dom-cheatsheet.js` را وقتی `live/index.html` در مرورگر باز است در Console اجرا کنید. دستورهای انتخاب عنصر فقط وقتی کار می‌کنند که آن عنصرها واقعاً در صفحهٔ باز وجود داشته باشند.

## مفاهیم کلیدی

- **DOM** درخت صفحه در حافظهٔ مرورگر است. هر تگ HTML یک گره از این درخت می‌شود. JavaScript با عوض کردن همین درخت، چیزی را که کاربر می‌بیند عوض می‌کند. فایل HTML روی دیسک دست نمی‌خورد. با یک نوسازی صفحه، تغییرهای DOM از بین می‌رود مگر آنکه خودتان آن‌ها را جایی ذخیره کرده باشید.
- **انتخاب:** `querySelector` اولین عنصر مطابق انتخاب‌گر CSS را برمی‌گرداند و اگر چیزی پیدا نکند `null` می‌دهد. `querySelectorAll` همهٔ مطابق‌ها را در یک NodeList می‌دهد و روی آن می‌توانید `forEach` بزنید. NodeList شبیه آرایه است ولی همهٔ متدهای آرایه را ندارد. اگر نتیجه `null` باشد، خط بعدی معمولاً `Cannot read properties of null` می‌دهد. دو علت رایجش انتخاب‌گر اشتباه است، یا اجرای اسکریپت پیش از ساخته شدن HTML.
- **جای `<script>`:** آن را انتهای `body` بگذارید، یا در `head` با ویژگی `defer`. `defer` یعنی اسکریپت دانلود شود ولی اجرا نشود تا مرورگر HTML را تا آخر خوانده باشد. بدون این ترتیب، `querySelector` عنصرهایی را می‌گردد که هنوز وجود ندارند.
- **`textContent` در برابر `innerHTML`:** `textContent` مقدار را متن ساده می‌نویسد و تگ داخل آن اجرا نمی‌شود، پس برای دادهٔ کاربر و API امن است. `innerHTML` رشته را به‌عنوان HTML تفسیر می‌کند و فقط برای HTML ثابتی مناسب است که خودتان نوشته‌اید. دادهٔ بیرونی را با `createElement` بسازید و متنش را با `textContent` بگذارید تا حملهٔ XSS، یعنی اجرای اسکریپت از راه متن ورودی، رخ ندهد.
- **`classList`** با `add`، `remove` و `toggle` کلاس CSS را عوض می‌کند و ظاهر را به فایل CSS می‌سپارد. ویژگی `style` را فقط برای مقداری به کار ببرید که در لحظه حساب می‌شود، مثل یک عرض که از روی عدد ورودی ساخته شده، چون استایل خطی بعداً از فایل CSS سخت‌تر پیدا می‌شود.
- **ساختن عنصر:** اول `createElement` گره را در حافظه می‌سازد، بعد ویژگی‌ها و متن را تنظیم می‌کنید، و آخر با `append` آن را داخل والد در صفحه می‌گذارید. اگر `append` را فراموش کنید عنصر وجود دارد ولی دیده نمی‌شود. `replaceChildren()` همهٔ فرزندهای یک والد را پاک می‌کند و برای رسم دوبارهٔ فهرست مناسب است، تا کارت‌های قدیمی کنار کارت‌های تازه نمانند.
- **`dataset`:** ویژگی `data-*` در HTML، مثلاً `data-id="3"`، در JavaScript با `element.dataset.id` خوانده می‌شود. از آن برای نگه داشتن شناسهٔ کوچک روی خود عنصر استفاده کنید تا بعداً، مثلاً هنگام حذف، بدانید این دکمه مال کدام محصول است.

اشتباه‌هایی که باید عمداً یک بار بسازید و پیام خطا را بخوانید: `querySelector("products")` بدون `#` یا `.` دنبال تگ `<products>` می‌گردد نه دنبال شناسه. فراموش کردن `append` عنصر را نامرئی می‌گذارد. `innerHTML +=` داخل حلقه هم کند است، چون هر بار کل HTML والد را از نو تفسیر می‌کند، و هم ناامن، اگر داده از بیرون آمده باشد.

## Live Coding

در `live/app.js` از آرایهٔ محصولات شروع کنید. تابع `createProductCard` برای هر محصول یک کارت می‌سازد و آن را در عنصر `#products` با `append` می‌گذارد. قیمت با `toLocaleString("fa-IR")` به رقم فارسی و جداکنندهٔ هزارگان تبدیل می‌شود، مثلاً `1280000` به شکل `۱٬۲۸۰٬۰۰۰` دیده می‌شود.

## تمرین

1. به هر کارت دکمهٔ «حذف» با `type="button"` اضافه کنید. `type="button"` لازم است تا اگر دکمه داخل فرم بود، فرم را ناخواسته ارسال نکند. با کلیک، `article.remove()` همان کارت را از درخت DOM برمی‌دارد.
2. نشان «پرفروش» فقط روی محصولی باشد که قیمتش بالای ۳۰۰ هزار تومان است. شرط را پیش از ساختن نشان بسنجید تا خانهٔ خالی در کارت نماند.

## تکلیف

صفحهٔ «فهرست دانشجویان» را از آرایه‌ای از شیءها با کلیدهای `name`، `track` و `score` بسازید و همه‌چیز را با `createElement` و `textContent` بنویسید. دانشجویی که نمره‌اش زیر ۱۰ است کلاس `is-failed` بگیرد تا ظاهر مردودی از CSS بیاید نه از استایل خطی. تعداد کل دانشجویان بالای فهرست دیده شود و با هر بار رسم دوباره، این عدد از طول همان آرایه حساب شود.
