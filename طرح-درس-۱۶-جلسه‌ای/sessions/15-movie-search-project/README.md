# جلسه ۱۵ — پروژه Movie / Show Search App

**مدت:** ۱۲۰ دقیقه · کاملاً پروژه‌ای  
**خروجی:** جست‌وجوی نمایش، با حالت‌های بارگذاری و خطا و نتیجهٔ خالی، و کارت نتیجه از یک API واقعی

> از [TVMaze API](https://www.tvmaze.com/api) استفاده می‌کنیم. این سرویس رایگان است و کلید API نمی‌خواهد. پروژه بدون تنظیم اضافه، با باز کردن `live/index.html` کار می‌کند، به شرطی که اینترنت وصل باشد.

## نکته‌های فنی

- **نقطهٔ پایانی (endpoint)** نشانی مشخصی است که یک کار از API را انجام می‌دهد. اینجا `https://api.tvmaze.com/search/shows?q=QUERY` آرایه‌ای از شیءهای `{ score, show }` برمی‌گرداند. `score` میزان نزدیکی نتیجه به عبارت جست‌وجو است و `show` خود نمایش است. عبارت جست‌وجو را حتماً با `encodeURIComponent` کدگذاری کنید. این تابع فاصله، `&` و حروف فارسی را به شکلی درمی‌آورد که معنی نشانی را به‌هم نریزد. بدون آن، یک فاصله یا یک `&` در متن کاربر بقیهٔ نشانی را خراب می‌کند.
- **حالت‌های رابط:** «در حال بارگذاری…»، «نتیجه‌ای پیدا نشد»، خطای شبکه که معمولاً `TypeError` است، و خطای HTTP که با `!response.ok` شناخته می‌شود، هر کدام پیام جدا دارند. این چهار وضعیت یکی نیستند. نتیجهٔ خالی یعنی سرور جواب سالم داده و چیزی پیدا نشده. پیام‌ها در عنصر `#status` با `aria-live="polite"` اعلام می‌شوند تا صفحه‌خوان آن‌ها را بگوید بدون آنکه وسط جملهٔ کاربر بپرد.
- **شرط مسابقه (race condition):** اگر کاربر سریع دو جست‌وجو بفرستد، ممکن است پاسخ قدیمی دیرتر برسد و نتایج تازه را بازنویسی کند. با `AbortController` درخواست قبلی را لغو می‌کنید. یک کنترل‌کننده می‌سازید، `signal` آن را به `fetch` می‌دهید، و پیش از درخواست تازه `abort()` را صدا می‌زنید. درخواست لغوشده با خطا تمام می‌شود و نباید آن خطا را مثل قطع اینترنت به کاربر نشان دهید.
- **دادهٔ ناقص:** بعضی نمایش‌ها تصویر، تاریخ یا امتیاز ندارند. با `?.` ویژگی غایب را امن می‌خوانید و با `??` مقدار جایگزین می‌گذارید. برای تصویر نبود، یک تصویر ثابت جایگزین نشان دهید تا کارت نشکند.
- **امنیت:** همهٔ متن‌های آمده از API با `textContent` نمایش داده می‌شوند تا تگ داخل خلاصهٔ نمایش اجرا نشود. پیوند بیرونی `rel="noopener noreferrer"` دارد تا صفحهٔ مقصد به پنجرهٔ شما دسترسی پیدا نکند.

برای دیدن خطای شبکه، در DevTools از تب Network گزینهٔ Offline را روشن کنید و یک جست‌وجو بزنید. صفحه باید پیام خطا نشان دهد، نه فهرست قبلی و نه سکوت.

## نسخهٔ جایگزین با OMDb، اگر کلید API داشته باشید

اگر به‌جای سریال بخواهید فیلم جست‌وجو کنید، [OMDb API](https://www.omdbapi.com/) کلید رایگان لازم دارد. TVMaze برای کلاس کافی است. این مسیر را فقط وقتی بروید که دانشجو خودش کلید گرفته باشد.

1. به [صفحهٔ دریافت کلید](https://www.omdbapi.com/apikey.aspx) بروید، طرح رایگان (FREE، هزار درخواست در روز) را انتخاب کنید و ایمیل را وارد کنید.
2. پیوند فعال‌سازی را از ایمیل باز کنید. کلید پیش از فعال‌سازی کار نمی‌کند و پاسخ سرور خطای کلید نامعتبر می‌دهد.
3. بالای `app.js` کلید را بگذارید و اگر رشته خالی بود، همان اول پیام روشن نشان دهید تا دانشجو فکر نکند جست‌وجو خراب است:

```js
const OMDB_API_KEY = ""; // paste your key here, e.g. "a1b2c3d4"

if (!OMDB_API_KEY) {
  setStatus("کلید OMDb تنظیم نشده است. طبق README کلید رایگان بگیرید و در app.js قرار دهید.", true);
}

async function searchMovies(query, signal) {
  const url = `https://www.omdbapi.com/?apikey=${OMDB_API_KEY}&s=${encodeURIComponent(query)}`;
  const response = await fetch(url, { signal });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);

  const data = await response.json();
  // OMDb returns HTTP 200 even for errors: check the Response field
  if (data.Response === "False") {
    if (data.Error === "Movie not found!") return [];
    throw new Error(data.Error); // e.g. "Invalid API key!"
  }
  return data.Search; // [{ Title, Year, imdbID, Poster }]
}
```

تفاوت مهم با TVMaze این است که OMDb حتی برای خطا هم اغلب کد HTTP برابر ۲۰۰ می‌فرستد و شکست را داخل JSON، در فیلد `Response`، اعلام می‌کند. پس بررسی `response.ok` به‌تنهایی کافی نیست. نتیجه‌ها در `data.Search` هستند، نه در خود بدنه به‌صورت آرایهٔ مستقیم. نام فیلدها با حرف بزرگ شروع می‌شود، مثل `Title`، `Year` و `Poster`. پوستر نبود مقدار `null` نیست و رشتهٔ `"N/A"` است، پس شرط درست این است: `Poster !== "N/A" ? Poster : PLACEHOLDER_IMAGE`.

> کلید API در کد فرانت‌اند برای هر کسی که صفحه را باز کند قابل دیدن است. برای پروژهٔ آموزشی اشکالی ندارد، ولی این کلید را در مخزن عمومی گیت‌هاب commit نکنید. در محصول واقعی درخواست باید از سرور خودتان برود تا کلید در مرورگر نباشد.

## تکلیف

1. با کلیک روی کارت، جزئیات نمایش را از `https://api.tvmaze.com/shows/ID` در بخشی جدا نشان دهید: خلاصه، ژانرها و شبکه. خلاصهٔ TVMaze تگ HTML دارد. آن را با `new DOMParser().parseFromString(summary, "text/html").body.textContent` به متن ساده تبدیل کنید. DOMParser سند را می‌خواند ولی اسکریپت اجرا نمی‌کند و تصویر بار نمی‌کند. نتیجه را با `textContent` در صفحه بگذارید، نه با `innerHTML`.
2. جست‌وجوی زنده را با رویداد `input` بسازید و ۴۰۰ میلی‌ثانیه تأخیر بگذارید. به این تأخیر debounce می‌گویند: تایمر قبلی را پاک می‌کنید و فقط اگر کاربر ۴۰۰ میلی‌ثانیه دیگر تایپ نکرد درخواست می‌رود، تا با هر حرف یک تماس شبکه زده نشود.
3. پنج جست‌وجوی آخر را در LocalStorage نگه دارید و هر کدام را به‌صورت دکمه نشان دهید. کلیک روی دکمه باید همان عبارت را دوباره جست‌وجو کند. اگر فهرست از پنج تا بیشتر شد، قدیمی‌ترین را حذف کنید.
