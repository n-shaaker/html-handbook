# تمرین ۳ — CSS Grid

دموی الگوهای Grid: ستون‌ها، نواحی، گالری واکنش‌گرا.

## پیش‌نیاز

- **[13 CSS Grid](../13-CSS-Grid/)** را کامل بخوانید.

## معیار موفقیت

1. یک صفحه با `grid-template-areas` (مثلاً header / main / aside / footer)
2. گالری با `repeat(auto-fit, minmax(...))`
3. در موبایل با Media Query به تک‌ستون تبدیل شود
4. فرق عمدی با Flex: اینجا چیدمان دوبعدی است

## کار شما

1. دمو را بخوانید.
2. یک «صفحه مجله» سه ستونه از صفر بسازید.
3. کوییزهای [13-CSS-Grid/quizzes](../13-CSS-Grid/quizzes/) را انجام دهید.
