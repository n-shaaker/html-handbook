آزمایشگاه تعاملی رنگ

اگر تازه‌کارید اول درس‌های گام‌به‌گام رنگ را بخوانید، بعد اینجا تمرین کنید.

یک طرف رنگ را با HSL بساز و طرف دیگر با RGB. هر پنل پیش‌نمایش و کد CSS خودش را دارد.

HSL

hsl(فام, اشباع%, روشنایی%)

پیش‌نمایش HSL

از ۰ تا ۳۶۰ درجه دور چرخ رنگ می‌چرخد و دوباره به قرمز می‌رسد.

در صفر درصد، رنگ خاکستری می‌شود.

۰٪ سیاه، ۵۰٪ معمولی، ۱۰۰٪ سفید.

کد HSL

.sw-hsl {
  background-color: hsl(32, 100%, 50%);
}

RGB

rgb(قرمز, سبز, آبی) — هر کدام ۰ تا ۲۵۵

پیش‌نمایش RGB

کد RGB

.sw-rgb {
  background-color: rgb(255, 136, 0);
}

معادل هگزادسیمال: #ff8800

یادآوری کوتاه

  • فام: مثل چرخ رنگ؛ ۰ تا ۳۶۰ درجه دور می‌زند و به قرمز برمی‌گردد.
  • اشباع / روشنایی: میزان زنده بودن رنگ، و تیرگی یا روشنی آن در HSL.
  • RGB: مخلوط نور قرمز + سبز + آبی؛ rgb(0, 0, 0) سیاه و rgb(255, 255, 255) سفید است.
  • هگز: همان RGB در مبنای ۱۶ است؛ در #ff8800 دو رقم اول قرمز (ff = ۲۵۵)، دو رقم وسط سبز (88 = ۱۳۶) و دو رقم آخر آبی (00 = ۰) است.
  • کاربرد HSL: برای ساختن رنگ‌های هم‌خانواده (مثلاً حالت hover یک دکمه) کافی است فقط روشنایی را کم و زیاد کنید؛ با RGB باید هر سه عدد را عوض کنید.
  • امتحان کن: hsl(32, 100%, 50%) و rgb(255, 136, 0) تقریباً یک رنگ‌اند؛ هر دو روش رنگ را توصیف می‌کنند، فقط زبان نوشتن فرق دارد.
