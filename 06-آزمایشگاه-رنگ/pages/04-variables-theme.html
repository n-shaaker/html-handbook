۴) متغیر CSS و تم رنگ

رنگ‌ها را در متغیر نگه دارید تا تم عوض شود بدون شکار همه کلاس‌ها.

:root {
  --bg: #f4f7fb;
  --text: #222;
  --brand: #1a5fb4;
}
.theme-dark {
  --bg: #1a1a1a;
  --text: #eee;
  --brand: #6cb6ff;
}
body { background: var(--bg); color: var(--text); }

درس کامل‌تر: متغیرهای CSS در ماژول آبشاری.
