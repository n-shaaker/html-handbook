## صورت مسئله

یک آژانس طراحی سایت برای مشتری‌های دولتی کار می‌کند و طبق قانون، متن سایت‌ها باید استاندارد دسترس‌پذیری
**WCAG** را رعایت کند تا افراد کم‌بینا هم بتوانند آن را بخوانند. یک ابزار بسازید که طراح دو رنگ (متن و پس‌زمینه)
انتخاب کند و فوراً ببیند نسبت کنتراست چقدر است و از کدام سطح استاندارد قبول می‌شود.

## فرمول (WCAG 2)

**۱. روشنایی نسبی (Relative Luminance) هر رنگ:** برای هر کانال r، g و b (عدد ۰ تا ۲۵۵):

```text
c = channel / 255
اگر c <= 0.03928  ←  C = c / 12.92
وگرنه             ←  C = ((c + 0.055) / 1.055) ^ 2.4
L = 0.2126 × R + 0.7152 × G + 0.0722 × B
```

`L` عددی بین ۰ (سیاه) و ۱ (سفید) است. توان را با `Math.pow(x, 2.4)` یا `x ** 2.4` حساب کنید.

**۲. نسبت کنتراست:**

```text
ratio = (L_روشن‌تر + 0.05) / (L_تیره‌تر + 0.05)
```

نتیجه بین ۱ (دو رنگ یکسان) تا ۲۱ (سیاه روی سفید) است و به شکل `4.54:1` نوشته می‌شود.

**۳. سطح‌ها:**

| سطح | حداقل نسبت |
| --- | :---: |
| AA — متن معمولی | ۴٫۵ |
| AA — متن درشت (۲۴px یا ۱۸٫۶۶px پررنگ به بالا) | ۳ |
| AAA — متن معمولی | ۷ |

## الزامات

1. سه فایل `index.html`، `style.css` و `app.js` (با `defer`)؛ دو `<input type="color">` با `label`:
   «رنگ متن» (پیش‌فرض `#1a3a5c`) و «رنگ پس‌زمینه» (پیش‌فرض `#ffffff`). کد هگز هر رنگ کنار آن نوشته شود.
2. یک جعبه پیش‌نمایش با یک تیتر درشت و یک پاراگراف معمولی که رنگ متن و پس‌زمینه‌اش رنگ‌های انتخاب‌شده باشد.
3. با رویداد `input` (یعنی هم‌زمان با کشیدن ماوس در انتخابگر رنگ) همه‌چیز به‌روز شود؛ دکمه «محاسبه» لازم نیست.
4. تابع‌های جدا: `hexToRgb(hex)`، `relativeLuminance(rgb)` و `contrastRatio(hex1, hex2)`.
   ترتیب ورودی‌های `contrastRatio` نباید در نتیجه اثر داشته باشد.
5. نسبت با **دو رقم اعشار** نمایش داده شود (مثلاً `4.54:1`).
6. برای هر سه سطح جدول بالا یک ردیف «قبول ✔» یا «رد ✘» نمایش داده شود؛ رنگ سبز/قرمز ردیف با یک کلاس CSS
   (مثلاً `pass` و `fail`) باشد و متن «قبول/رد» هم نوشته شود. مقایسه با عدد **گرد‌نشده** انجام شود.
7. یک دکمه «جابه‌جایی ⇄» که رنگ متن و پس‌زمینه را عوض کند (نسبت نباید تغییر کند، پیش‌نمایش باید عوض شود).

## محدودیت‌ها

- `onclick` داخل HTML، `alert` و `var` ممنوع.
- از کتابخانه یا سایت آماده استفاده نکنید؛ فرمول را خودتان پیاده کنید.
- رنگ‌ها را با `style.color` و `style.backgroundColor` روی پیش‌نمایش بگذارید، ولی رنگ «قبول/رد» با کلاس CSS باشد.

## نکته استاد

- `#777777` نسبت ۴٫۴۷۸ دارد که با `toFixed(1)` می‌شود «4.5» ولی **قبول نیست**؛ برای همین مقایسه را با عدد خام انجام دهید.
- مقدار `input type="color"` همیشه هگز شش‌رقمی کوچک است (`#rrggbb`)، پس اینجا لازم نیست هگز سه‌رقمی را پشتیبانی کنید.
- اگر نسبت شما کمتر از ۱ شد، جای روشن‌تر و تیره‌تر را در کسر اشتباه گذاشته‌اید.
