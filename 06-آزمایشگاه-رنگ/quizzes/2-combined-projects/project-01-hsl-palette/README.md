# پروژه ترکیبی ۱: پالت رنگ برند با HSL

- **سطح:** ⭐
- **زمان پیشنهادی:** ۴۵ دقیقه

**هدف پروژه:** ساختن صفحه «راهنمای رنگ» یک برند فقط با CSS، طوری که همه سایه‌ها و دکمه‌ها از یک فام و اشباع ساخته شوند و با عوض کردن یک عدد کل رنگ‌ها عوض شوند.

## درس‌های مرتبط

- [آزمایشگاه تعاملی رنگ](../../../index.html): پنل HSL (فام، اشباع، روشنایی) و «یادآوری کوتاه» پایین صفحه
- متغیرهای CSS (`--name` و `var()`)

## صورت مسئله

کافه «فیروزه» یک رنگ برند دارد: **فام ۱۷۵ و اشباع ۶۰٪** (یک فیروزه‌ای ملایم). طراح کافه می‌خواهد
یک صفحه «راهنمای رنگ» داشته باشد که پنج سایه از همین رنگ، دکمه‌های سایت و یک خاکستری هماهنگ را نشان دهد.
شرط او این است: **همه رنگ‌ها با `hsl()` نوشته شوند** تا اگر روزی رنگ برند عوض شد، فقط یک عدد را تغییر دهد.

## الزامات

1. دو فایل `index.html` و `style.css` (بدون JavaScript)؛ صفحه با `lang="fa"` و `dir="rtl"`.
2. فام و اشباع برند **یک بار** در `:root` به‌صورت متغیر تعریف شوند (مثلاً `--brand-h: 175;` و `--brand-s: 60%;`)
   و همه رنگ‌های برند از آن‌ها ساخته شوند: `hsl(var(--brand-h), var(--brand-s), 50%)`.
3. یک پالت پنج‌تایی (پنج مربع یا کارت) با روشنایی **۹۰٪، ۷۵٪، ۵۰٪، ۳۵٪ و ۲۰٪** (فام و اشباع یکسان).
   روی هر مربع، کد رنگش نوشته شود (مثلاً `hsl(175, 60%, 90%)`) و رنگ متن روی آن خوانا باشد.
4. یک «خاکستری هماهنگ» که فقط با **اشباع ۰٪** ساخته شده باشد (مثلاً `hsl(var(--brand-h), 0%, 45%)`).
5. سه دکمه: «اصلی» (پس‌زمینه تیره برند با متن سفید)، «روشن» (پس‌زمینه روشن برند با متن تیره) و «خاکستری».
6. حالت‌های `:hover` و `:active` هر دکمه **فقط روشنایی** را تغییر دهند (فام و اشباع ثابت بماند). مثلاً
   ۲۸٪ ← هاور ۲۲٪ ← فشرده ۱۶٪. حالت `:focus-visible` هم یک `outline` دیده‌شدنی داشته باشد.
7. **همه** رنگ‌های فایل CSS (پس‌زمینه، متن، حاشیه، حتی سفید و سیاه) با `hsl()` نوشته شوند؛ هگز، `rgb()` و نام رنگ (`white`) ممنوع.
8. پرسش‌های زیر را در یک فایل `answers.md` کوتاه (هر کدام ۱ تا ۳ جمله) جواب دهید:
   1. چرا برای ساختن حالت hover با HSL فقط یک عدد را عوض کردید؟ با `rgb()` چه کاری باید می‌کردید؟
   2. اگر اشباع ۰٪ باشد، عوض کردن فام چه اثری روی رنگ دارد؟ چرا؟ (در آزمایشگاه امتحان کنید.)
   3. `hsl(0, 100%, 50%)` و `hsl(360, 100%, 50%)` چه فرقی با هم دارند؟
   4. روشنایی ۱۰۰٪ و ۰٪ با هر فام و اشباعی چه رنگی می‌شود؟
   5. روی سایه ۹۰٪ و روی سایه ۲۰٪ چه رنگ متنی گذاشتید و چرا؟
   6. اگر کافه فردا بگوید «رنگ برند را نارنجی کنید (فام ۳۲)»، در کد شما چند خط باید عوض شود؟

## محدودیت‌ها

- JavaScript ممنوع؛ این پروژه فقط CSS است.
- `style` داخل HTML ممنوع؛ همه CSS در `style.css`.
- عدد فام و اشباع برند نباید جز در `:root` جای دیگری تکرار شود (به‌جز اشباع ۰٪ خاکستری).

## امتیازی (تا ۲ نمره)

- یک مربع «رنگ تکمیلی» با فام مقابل روی چرخ رنگ (۱۸۰ درجه آن طرف‌تر)، مثلاً `hsl(355, 60%, 50%)`.

## نکته استاد

- داخل `hsl()` با متغیر، علامت `%` را فراموش نکنید: اگر `--brand-s: 60;` بنویسید، رنگ نامعتبر می‌شود و مرورگر کل آن خط را نادیده می‌گیرد.
- «خوانا بودن متن» حدسی نیست: روی سایه‌های روشن متن تیره و روی سایه‌های تیره متن روشن. سایه وسط (۳۵٪) را با دقت بیشتری بررسی کنید.
- اگر هاور «کار نمی‌کند»، ببینید قانون `:hover` بعد از قانون اصلی دکمه آمده یا نه و قدرت انتخابگرها برابر است یا نه.
