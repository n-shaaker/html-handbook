# پروژه ترکیبی ۴: انتخابگر رنگ تم سایت

- **سطح:** ⭐⭐⭐
- **زمان پیشنهادی:** ۷۵ دقیقه

**هدف پروژه:** ساختن ابزاری که از **یک فام** یک تم کامل (پس‌زمینه، کارت نیمه‌شفاف، متن، دکمه اصلی و فرعی با hover) در دو حالت روشن و تیره بسازد، پیش‌نمایش آن را زنده نشان دهد و کد CSS آماده تحویل بدهد.

## صورت مسئله

آموزشگاه آنلاین «پیمانه» می‌خواهد به هر مدرس اجازه دهد صفحه دوره‌اش را با رنگ دلخواه ببیند.
مدرس‌ها طراح نیستند و اگر هر رنگ را جدا انتخاب کنند، صفحه شلوغ و ناخوانا می‌شود.
یک ابزار بسازید که مدرس فقط **یک رنگ** (فام)، حالت روشن یا تیره و میزان پررنگی کارت را انتخاب کند
و بقیه رنگ‌ها خودکار و هماهنگ ساخته شوند.

## جدول رنگ‌های تم

| متغیر | حالت روشن | حالت تیره |
| --- | --- | --- |
| `--page-bg` | `hsl(h, 30%, 96%)` | `hsl(h, 25%, 12%)` |
| `--card-bg` | `hsla(0, 0%, 100%, a)` | `hsla(h, 20%, 22%, a)` |
| `--text` | `hsl(h, 30%, 15%)` | `hsl(h, 20%, 92%)` |
| `--primary` | `hsl(h, 70%, 40%)` | `hsl(h, 70%, 60%)` |
| `--primary-hover` | `hsl(h, 70%, 33%)` (تیره‌تر) | `hsl(h, 70%, 68%)` (روشن‌تر) |
| `--on-primary` (متن روی دکمه) | `hsl(0, 0%, 100%)` | `hsl(h, 30%, 10%)` |
| `--primary-soft` (hover دکمه فرعی) | `hsla(h, 70%, 50%, 0.12)` | `hsla(h, 70%, 60%, 0.15)` |

`h` فام اسلایدر و `a` مقدار اسلایدر پررنگی ÷ ۱۰۰ است.

## الزامات

1. سه فایل `index.html`، `style.css` و `app.js` (با `defer`)؛ صفحه با `lang="fa"` و `dir="rtl"`.
2. کنترل‌ها با `label`: اسلایدر فام (۰ تا ۳۶۰)، `select` حالت (روشن/تیره) و اسلایدر پررنگی کارت (۴۰ تا ۱۰۰). کنار اسلایدرها عدد فعلی.
3. یک ناحیه پیش‌نمایش با یک کارت دوره (عنوان، متن، دکمه «ثبت‌نام» و دکمه «جزئیات بیشتر»). پشت کارت یک شکل رنگی باشد تا شفافیت کارت دیده شود.
4. در `style.css` همه رنگ‌های پیش‌نمایش فقط از متغیرهای جدول بالا خوانده شوند (`var(--primary)` و …). hover هر دو دکمه و `:focus-visible` در CSS نوشته شوند.
5. تابع `buildTheme(h, mode, alpha)` که با `if` بر اساس حالت، یک **شیء** با هفت رنگ جدول برگرداند.
6. تابع `applyTheme(theme)` که هر هفت متغیر را روی ناحیه پیش‌نمایش بگذارد (راهنما پایین).
7. **یک** تابع `updateTheme()` که به `input` دو اسلایدر و `change` منو وصل شود و یک بار هم موقع باز شدن صفحه اجرا شود.
8. یک بلوک کد که متن `:root { ... }` تم فعلی را (با Template Literal چندخطی) نشان دهد.

**راهنما — عوض کردن متغیر CSS با JavaScript:** `preview.style.setProperty("--primary", theme.primary);`

## تست‌ها

| کار | خروجی مورد انتظار |
| --- | --- |
| باز کردن صفحه | تم آبی روشن؛ دکمه «ثبت‌نام» `hsl(210, 70%, 40%)` و کد `--primary: hsl(210, 70%, 40%);` |
| فام ۱۴۰ | دکمه‌ها، دایره پشت کارت و ته‌رنگ پس‌زمینه هم‌زمان سبز |
| حالت «تیره» | پس‌زمینه تیره، متن کارت روشن، دکمه اصلی روشن‌تر (`60%`) با متن تیره |
| hover روی «ثبت‌نام» در حالت روشن | کمی **تیره‌تر**؛ در حالت تیره کمی **روشن‌تر** |
| پررنگی ۴۰ | دایره رنگی از پشت کارت به‌خوبی دیده می‌شود ولی متن کارت کم‌رنگ **نمی‌شود** |
| پررنگی ۱۰۰ | کارت کاملاً مات؛ کد `--card-bg: hsla(0, 0%, 100%, 1);` |
| Tab تا دکمه‌ها | حاشیه فوکوس دیده‌شدنی |

## محدودیت‌ها

- `onclick`/`oninput` داخل HTML، `alert` و `var` ممنوع.
- برای شفافیت کارت از `opacity` استفاده **نکنید** (متن هم کم‌رنگ می‌شود)؛ فقط `hsla()`.
- رنگ‌ها در JavaScript فقط یک جا (`buildTheme`) ساخته شوند؛ hover در CSS است، نه با `mouseover`.
- همه رنگ‌ها با `hsl()`/`hsla()`؛ هگز و نام رنگ در `style.css` ممنوع.

## امتیازی (تا ۲ نمره)

- رنگ `--primary` را به هگز هم نشان دهید (راهنما: اول با پروژه ترکیبی ۳ آن را به RGB و بعد با `toHex` به هگز ببرید، یا یک `input type="color"` کمکی بگذارید).
- دکمه «تم تصادفی» که فام را تصادفی انتخاب کند (`Math.floor(Math.random() * 361)`) و اسلایدر را هم جابه‌جا کند.

## نکته استاد

- در حالت تیره hover باید **روشن‌تر** شود، نه تیره‌تر؛ وگرنه روی پس‌زمینه تیره تغییر دیده نمی‌شود.
- اسلایدر پررنگی ۴۰ تا ۱۰۰ است تا کسی کارت را کاملاً شفاف و متن را ناخوانا نکند. این هم یک تصمیم دسترس‌پذیری است.
- اگر رنگی عوض نمی‌شود، در DevTools روی ناحیه پیش‌نمایش کلیک کنید و ببینید متغیرها در `style` آن نشسته‌اند یا نه.
