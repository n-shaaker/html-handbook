# پروژه ترکیبی ۲: سازنده پالت رنگ برند

- **سطح:** ⭐⭐
- **زمان پیشنهادی:** ۶۰ دقیقه

**هدف پروژه:** ساختن ابزاری که با دو اسلایدر (فام و اشباع) پنج سایه برند را زنده بسازد، روی هر سایه رنگ متن خوانا بگذارد و یک دکمه نمونه با حالت hover از همان رنگ نشان دهد.

## مباحث ترکیب‌شده

| مبحث بخش ۱ | نقش در این پروژه |
| --- | --- |
| [HSL](../../1-topic-exercises/03-hsl/README.md) | پنج سایه با فام و اشباع ثابت و روشنایی ۹۰، ۷۵، ۵۰، ۳۵، ۲۰ |
| [رنگ در CSS](../../1-topic-exercises/04-color-in-css/README.md) | متغیرهای `--brand-h` و `--brand-s`، دکمه با `:hover`/`:active` فقط با روشنایی |
| [اسلایدر و به‌روزرسانی زنده](../../1-topic-exercises/05-range-live-update/README.md) | دو اسلایدر با رویداد `input` و **یک** تابع `updatePalette` |

## صورت مسئله

استودیو طراحی «نقش» برای هر مشتری تازه (کافه، کتاب‌فروشی، باشگاه) اول یک پالت رنگ می‌سازد. طراح‌ها تا امروز
پنج سایه را دستی در فتوشاپ حساب می‌کردند. یک ابزار وب بسازید که طراح فقط فام و اشباع را با اسلایدر انتخاب کند
و پنج سایه، یک پیش‌نمایش کوچک از سایت و کد CSS آماده برای برنامه‌نویس را ببیند.

## الزامات

1. سه فایل `index.html`، `style.css` و `app.js` (با `defer`)؛ صفحه با `lang="fa"` و `dir="rtl"`.
2. کنترل‌ها با `label`: کادر متنی «نام برند»، اسلایدر فام (۰ تا ۳۶۰) و اسلایدر اشباع (۰ تا ۱۰۰). کنار هر برچسب، عدد فعلی با `°` یا `%`.
3. پنج مربع سایه با روشنایی **۹۰، ۷۵، ۵۰، ۳۵ و ۲۰ درصد**؛ روی هر مربع کد `hsl()` آن نوشته شود.
4. یک تابع `paintShade(shade, h, s, l)` که مربع را رنگ کند، کدش را بنویسد و با `if` رنگ متن را انتخاب کند:
   روشنایی ۶۰ و بیشتر ← متن تیره از همان فام (روشنایی ۱۵٪)؛ کمتر ← متن سفید.
5. **یک** تابع `updatePalette()` که به رویداد `input` هر دو اسلایدر وصل شود و یک بار هم موقع باز شدن صفحه صدا زده شود.
6. کارت پیش‌نمایش و دکمه «مشاهده منو» رنگشان را در CSS از متغیرهای `--brand-h` و `--brand-s` بگیرند؛
   `updatePalette` این دو متغیر را عوض کند (راهنما پایین). hover دکمه فقط روشنایی را کم کند و `:focus-visible` داشته باشد.
7. با تایپ نام برند (رویداد `input`) عنوان کارت پیش‌نمایش عوض شود؛ اگر کادر خالی یا فقط فاصله بود، «نام برند» نمایش داده شود.
8. یک بلوک کد که متن آماده `:root { --brand-h: …; --brand-s: …%; }` را نشان دهد.

**راهنما — عوض کردن متغیر CSS با JavaScript:**
`document.body.style.setProperty("--brand-h", h);` و برای اشباع حتماً با درصد: `document.body.style.setProperty("--brand-s", s + "%");`

## تست‌ها

| کار | خروجی مورد انتظار |
| --- | --- |
| باز کردن صفحه (فام ۱۷۵، اشباع ۶۰) | پنج سایه فیروزه‌ای؛ مربع اول `hsl(175, 60%, 90%)` با متن تیره، مربع آخر `hsl(175, 60%, 20%)` با متن سفید |
| مربع ۵۰٪ | متن **سفید** (چون ۵۰ کمتر از ۶۰ است) |
| کشیدن فام به ۳۲ | همه سایه‌ها، کارت و دکمه هم‌زمان نارنجی می‌شوند؛ کد `--brand-h: 32;` |
| کشیدن اشباع به ۰ | همه سایه‌ها خاکستری؛ فام هر چه باشد فرقی نمی‌کند |
| رفتن ماوس روی دکمه | دکمه کمی تیره‌تر، با همان فام |
| تایپ «کتاب‌فروشی ققنوس» | عنوان کارت «کتاب‌فروشی ققنوس» |
| پاک کردن نام یا تایپ فقط فاصله | عنوان کارت «نام برند» |

## محدودیت‌ها

- `onclick`/`oninput` داخل HTML، `alert` و `var` ممنوع.
- همه رنگ‌های `style.css` با `hsl()` نوشته شوند.
- کد رنگ کردن سایه‌ها **پنج بار تکرار نشود**؛ یک تابع `paintShade` و پنج بار صدا زدن.
- `innerHTML` ممنوع؛ همه متن‌ها با `textContent`.

## امتیازی (تا ۲ نمره)

- یک مربع ششم «رنگ مکمل» (فام + ۱۸۰، با `% 360`) با روشنایی ۵۰٪.
- دکمه «کپی کد» که متن بلوک کد را در کلیپ‌بورد بگذارد (راهنما: `navigator.clipboard.writeText(text)`).

## نکته استاد

- اگر `--brand-s` را بدون `%` بفرستید، `hsl(var(--brand-h), var(--brand-s), 35%)` نامعتبر می‌شود و دکمه بی‌رنگ می‌ماند. در DevTools زبانه Elements را ببینید.
- `updatePalette()` را آخر فایل یک بار صدا بزنید؛ وگرنه مربع‌ها تا اولین حرکت اسلایدر خالی می‌مانند.
- اول با پروژه ترکیبی ۱ (پالت فقط با CSS) مقایسه کنید: اینجا همان پالت را JavaScript زنده کرده است.
