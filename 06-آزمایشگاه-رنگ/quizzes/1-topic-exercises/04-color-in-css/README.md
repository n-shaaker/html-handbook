# مبحث ۴ — کاربرد رنگ در CSS: سایه‌های hover و شفافیت

**درس مرتبط:** [آزمایشگاه تعاملی رنگ](../../../index.html) — بند «کاربرد HSL» در «یادآوری کوتاه»

> این مبحث فقط CSS است. فایل `style.css` پاسخ‌ها ظاهر عمومی صفحه است؛ قانون‌های رنگ هر تمرین در `ex-n.css` است.
> پاسخ استاد در پوشه `solution` است؛ اول خودتان حل کنید.

---

## تمرین ۱ — دکمه با سایه‌های hover ⭐

**هدف:** ساختن حالت‌های `:hover`، `:active` و `:focus-visible` فقط با عوض کردن روشنایی HSL.

**صورت مسئله:** فروشگاه اینترنتی «سبزینه» دو دکمه در صفحه سبد خرید دارد: «ثبت سفارش» (اصلی) و «ادامه خرید» (فرعی). رنگ برند: فام ۱۵۰ و اشباع ۶۰٪.

**الزامات:**
- دکمه اصلی: پس‌زمینه روشنایی ۳۵٪ و متن سفید؛ hover ۲۸٪؛ active ۲۲٪.
- دکمه فرعی: پس‌زمینه خیلی روشن (۹۷٪)، حاشیه ۳۵٪ و متن تیره؛ hover و active کمی تیره‌تر.
- در همه حالت‌ها **فام و اشباع ثابت** بماند.
- `:focus-visible` یک `outline` دیده‌شدنی داشته باشد (با کلید Tab امتحان کنید).

**تست‌ها:**
- رفتن ماوس روی «ثبت سفارش» ← کمی تیره‌تر؛ نگه داشتن کلیک ← باز هم تیره‌تر
- زدن Tab تا رسیدن به دکمه ← حاشیه سبز روشن دور دکمه
- مقایسه کد hover و حالت عادی ← فقط عدد سوم `hsl()` فرق دارد

---

## تمرین ۲ — بنر با لایه شفاف ⭐⭐

**هدف:** فهمیدن فرق `rgba()`/`hsla()` (شفافیت فقط رنگ) با `opacity` (شفافیت کل عنصر).

**صورت مسئله:** بنر جشنواره تابستانه یک پس‌زمینه رنگارنگ دارد و متن روی آن خوانده نمی‌شود. طراح می‌خواهد زیر متن یک لایه تیره نیمه‌شفاف بگذارد.

**الزامات:**
- یک بنر با پس‌زمینه گرادیان (`linear-gradient` با دو رنگ `hsl()`).
- دو کادر روی بنر با متن سفید: اولی با `background-color: rgba(0, 0, 0, 0.55)`، دومی با پس‌زمینه سیاه و `opacity: 0.55`.
- یک برچسب «۳۰٪ تخفیف» با پس‌زمینه `hsla(...)` نیمه‌شفاف.
- در یک جمله زیر بنر بنویسید کدام کادر متن خواناتری دارد و چرا.

**تست‌ها:**
- کادر `rgba` ← پس‌زمینه نیمه‌شفاف، متن **کاملاً** سفید و خوانا
- کادر `opacity` ← متن هم کم‌رنگ شده
- عدد چهارم را ۰ کنید ← کادر کاملاً شفاف؛ ۱ کنید ← کاملاً سیاه

## تمرین ۳ — جعبه‌های پیام از یک فام ⭐⭐⭐

**هدف:** ساختن یک خانواده رنگ (پس‌زمینه، متن، حاشیه) از **یک فام** با متغیر CSS.

**صورت مسئله:** سامانه ثبت‌نام آموزشگاه چهار نوع پیام دارد: اطلاع، موفقیت، هشدار و خطا. هر کدام سه رنگ لازم دارد و نمی‌خواهیم ۱۲ رنگ جدا بنویسیم.

**الزامات:**
- یک کلاس `.alert` با متغیر `--h` و سه رنگ: پس‌زمینه `hsl(var(--h), 80%, 94%)`، متن `hsl(var(--h), 60%, 25%)`، حاشیه سمت شروع `hsl(var(--h), 65%, 45%)`.
- چهار کلاس نوع پیام (`alert-info`، `alert-success`، `alert-warning`، `alert-error`) که **فقط** `--h` را عوض کنند (۲۱۰، ۱۴۰، ۴۰، ۰).
- هیچ رنگ دیگری در کلاس‌های نوع پیام نوشته نشود.
- حاشیه با `border-inline-start` تا در صفحه راست‌به‌چپ سمت راست بیفتد.

**تست‌ها:**
- `alert-success` ← سبز روشن با متن سبز تیره
- `alert-error` ← صورتی روشن با متن قرمز تیره
- عوض کردن `--h` در `.alert-warning` به ۲۸۰ ← هر سه رنگ با هم بنفش می‌شوند

---

## اشتباه‌های رایج این مبحث

- عوض کردن فام یا اشباع در hover؛ دکمه «رنگ دیگری» می‌شود، نه «سایه همان رنگ».
- استفاده از `opacity` برای پس‌زمینه کادر متن و کم‌رنگ شدن خود متن.
- نوشتن قانون `:hover` **قبل از** قانون اصلی یا با انتخابگر ضعیف‌تر؛ هاور دیده نمی‌شود.
- `--h: 210deg` یا `--h: "210"`؛ داخل `hsl(var(--h), ...)` عدد ساده بنویسید.
