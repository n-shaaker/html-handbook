# مبحث ۳ — رنگ با HSL (فام، اشباع، روشنایی)

**درس مرتبط:** [آزمایشگاه تعاملی رنگ](../../../index.html) — پنل HSL و بندهای «فام» و «اشباع / روشنایی» در «یادآوری کوتاه»

> فایل `style.css` پاسخ‌ها فقط ظاهر عمومی صفحه است؛ قانون‌های رنگ هر تمرین در `ex-n.css` است.
> پاسخ استاد در پوشه `solution` است؛ اول خودتان حل کنید.

---

## تمرین ۱ — چرخ رنگ با فام ⭐

**هدف:** دیدن اثر **فام** وقتی اشباع و روشنایی ثابت‌اند.

**صورت مسئله:** برای پوستر کلاس هنر، یک نوار «چرخ رنگ» لازم است که هر ۶۰ درجه یک رنگ نشان دهد.

**الزامات:**
- فایل‌ها: `ex-1.html` و `ex-1.css`.
- ۷ مربع با فام ۰، ۶۰، ۱۲۰، ۱۸۰، ۲۴۰، ۳۰۰ و ۳۶۰؛ همه با اشباع ۱۰۰٪ و روشنایی ۵۰٪.
- همه رنگ‌ها با `hsl()`؛ کد هر رنگ روی مربعش نوشته شود.
- زیر نوار در یک جمله بنویسید چرا مربع ۰ و ۳۶۰ یکسان‌اند.

**تست‌ها:**
- فام ۰ ← قرمز، ۶۰ ← زرد، ۱۲۰ ← سبز، ۱۸۰ ← فیروزه‌ای، ۲۴۰ ← آبی، ۳۰۰ ← سرخابی
- فام ۳۶۰ ← دوباره قرمز (همان فام ۰)

---

## تمرین ۲ — نردبان روشنایی و اشباع ⭐⭐

**هدف:** جدا کردن اثر **روشنایی** از اثر **اشباع**.

**صورت مسئله:** شرکت کشتیرانی «دریا» یک رنگ آبی با فام ۲۱۰ دارد و طراح می‌خواهد همه حالت‌های آن را کنار هم ببیند.

**الزامات:**
- نردبان اول: فام ۲۱۰، اشباع ۷۰٪ و روشنایی ۱۵، ۳۰، ۵۰، ۷۰، ۹۰ درصد.
- نردبان دوم: فام ۲۱۰، روشنایی ۵۰٪ و اشباع ۰، ۲۵، ۵۰، ۷۵، ۱۰۰ درصد.
- در هر نردبان **فقط یک عدد** عوض شود.
- متن روی سایه‌های تیره سفید (`hsl(0, 0%, 100%)`) و روی سایه‌های روشن تیره باشد.

**تست‌ها:**
- روشنایی ۱۵٪ ← سرمه‌ای خیلی تیره؛ ۹۰٪ ← آبی خیلی روشن
- اشباع ۰٪ ← خاکستری کامل (فام دیگر اثری ندارد)
- اشباع ۱۰۰٪ ← آبی پررنگ و زنده

---

## تمرین ۳ — حساب کردن با HSL ⭐⭐⭐

**هدف:** تابع‌هایی که فام را دور چرخ بچرخانند و روشنایی را در بازه ۰ تا ۱۰۰ نگه دارند.

**صورت مسئله:** ابزار طراحی یک تیم سه کار کوچک لازم دارد: ساختن متن `hsl()`، پیدا کردن رنگ مکمل، و تیره‌تر/روشن‌تر کردن رنگ برای حالت hover.

**الزامات:**
- `hslText(h, s, l)` ← متنی مثل `"hsl(175, 60%, 50%)"`.
- `complementHue(h)` ← فام مکمل (۱۸۰ درجه آن طرف)، همیشه بین ۰ تا ۳۵۹ (راهنما: باقیمانده `%`).
- `darker(l, step)` ← روشنایی منهای `step`، ولی هیچ‌وقت کمتر از ۰.
- `lighter(l, step)` ← روشنایی به‌علاوه `step`، ولی هیچ‌وقت بیشتر از ۱۰۰.
- یک خط که هر سه تابع را با هم استفاده کند.

**تست‌ها:**
- `hslText(175, 60, 50)` ← `hsl(175, 60%, 50%)`
- `complementHue(30)` ← `210`، `complementHue(200)` ← `20`، `complementHue(180)` ← `0`
- `darker(50, 15)` ← `35`، `darker(10, 15)` ← `0`
- `lighter(95, 10)` ← `100`
- `hslText(complementHue(175), 60, darker(50, 15))` ← `hsl(355, 60%, 35%)`

## اشتباه‌های رایج این مبحث

- جا انداختن `%` در اشباع و روشنایی: `hsl(210, 70, 50)` نامعتبر است و مرورگر کل خط را نادیده می‌گیرد.
- فکر کردن اینکه روشنایی ۱۰۰٪ «رنگ پررنگ‌تر» است؛ ۱۰۰٪ همیشه **سفید** و ۰٪ همیشه **سیاه** است.
- عوض کردن فام برای ساختن سایه؛ سایه یعنی همان فام با روشنایی دیگر.
- `h + 180` بدون `% 360`؛ فام ۲۰۰ می‌شود ۳۸۰.
