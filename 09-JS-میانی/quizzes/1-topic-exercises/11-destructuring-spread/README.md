# مبحث ۱۱: Destructuring، Spread و Rest — تمرین‌های جداگانه

درس مرتبط: [۱۱) تجزیه و پخش (Destructuring، Spread و Rest)](../../../pages/11-destructuring-spread.html)

خروجی در **Console** است.

## تمرین ۱ — پروفایل کاربر ⭐

**هدف:** بیرون کشیدن مقدار از شیء و آرایه با destructuring، با مقدار پیش‌فرض و تغییر نام.

**صورت مسئله:** اطلاعات کاربر `{ name: "نیما", city: "شیراز", age: 17 }` و سه نفر اول مسابقه `["سارا", "علی", "مریم"]` است.

**الزامات:**
- `name` و `city` را با destructuring شیء بیرون بکشید؛ `job` را هم با مقدار پیش‌فرض «نامشخص» بگیرید.
- `age` را با نام جدید `userAge` بگیرید.
- نفر اول و دوم مسابقه را با destructuring آرایه بگیرید.
- جای `first` و `second` را با `[first, second] = [second, first]` عوض کنید (با `let`).

**تست‌ها / خروجی مورد انتظار:**
```
نیما از شیراز، شغل: نامشخص، سن: 17
اول: سارا، دوم: علی
بعد از جابه‌جایی — اول: علی، دوم: سارا
```

## تمرین ۲ — کپی بدون دردسر ⭐⭐

**هدف:** کپی و ادغام آرایه و شیء با Spread، بدون تغییر نسخه اصلی.

**صورت مسئله:** تنظیمات پیش‌فرض یک برنامه `{ theme: "light", fontSize: 14, lang: "fa" }` است و کاربر فقط تم تیره را انتخاب کرده. فهرست خرید هم باید کپی شود و فقط کپی تغییر کند.

**الزامات:**
- `userSettings` را با `{ ...defaults, theme: "dark" }` بسازید؛ `defaults` عوض نشود.
- `listCopy` را با `[...shoppingList]` بسازید و فقط به کپی «چای» اضافه کنید.
- دو آرایه میوه و سبزی را با Spread در یک آرایه ادغام کنید.
- بیشترین نمره آرایه `scores` را با `Math.max(...scores)` پیدا کنید.

**تست‌ها / خروجی مورد انتظار:**
```
پیش‌فرض: light / کاربر: dark / اندازه فونت کاربر: 14
اصلی: نان، شیر (2) | کپی: نان، شیر، چای (3)
سبد بازار: سیب، موز، خیار، گوجه
بیشترین نمره: 19.5
```

## تمرین ۳ — ثبت سفارش با Rest ⭐⭐⭐

**هدف:** گرفتن تعداد نامشخص پارامتر با Rest و destructuring در پارامتر تابع.

**صورت مسئله:** صندوق رستوران باید هر تعداد قیمت را جمع بزند و برای هر سفارش یک خط خلاصه چاپ کند.

**الزامات:**
- `sum(...prices)` هر تعداد عدد را بگیرد و با `reduce` جمع بزند.
- `printOrder({ dish, qty = 1, table })` با destructuring در پارامتر، خلاصه سفارش را برگرداند (اگر `qty` نیامد ۱ فرض شود).
- `const [winner, ...others] = names` برنده قرعه‌کشی و بقیه را جدا کند.
- همه را امتحان کنید.

**تست‌ها / خروجی مورد انتظار:**
```
sum(1, 2, 3) → 6
sum(420000, 45000, 75000, 60000) → 600000
میز 4: 2 × کوبیده
میز 7: 1 × قورمه‌سبزی
برنده: سارا | بقیه: علی، مریم، رضا
```

## اشتباه‌های رایج این مبحث

- در destructuring شیء، **اسم** مهم است نه ترتیب؛ در آرایه، **ترتیب** مهم است نه اسم.
- `const copy = list` کپی نمی‌سازد؛ هر دو به یک آرایه اشاره می‌کنند. با `[...list]` کپی بگیرید.
- در `{ ...a, theme: "dark" }` ترتیب مهم است: ویژگی‌های بعدی، قبلی‌ها را بازنویسی می‌کنند.
- پارامتر Rest باید **آخرین** پارامتر باشد.
- Spread فقط یک لایه کپی می‌کند؛ شیء‌های داخلی هنوز مشترک‌اند.
