# مبحث ۸: Hoisting و حالت سخت‌گیرانه — تمرین‌های جداگانه

درس مرتبط: [۸) بالا بردن و حالت سخت‌گیرانه (Hoisting & Strict Mode)](../../../pages/08-hoisting-strict.html)

در این مبحث یاد می‌گیریم چه چیزی را می‌شود **قبل از تعریف** صدا زد و `"use strict"` جلوی چه اشتباه‌هایی را می‌گیرد. خروجی در **Console** است.

## تمرین ۱ — اول صدا بزن، بعد تعریف کن؟ ⭐

**هدف:** فرق تابع اعلانی (`function name() {}`) با تابعی که در `const` ذخیره شده.

**صورت مسئله:** در یک فایل، تابع‌ها پایین فایل نوشته شده‌اند و بالای فایل صدا زده می‌شوند. یکی کار می‌کند و یکی نه.

**الزامات:**
- بالای فایل `greet("مریم")` را صدا بزنید و تابع `greet` را **پایین فایل** به شکل `function greet(name) {...}` تعریف کنید.
- تابع `calcTax` را به شکل `const calcTax = function (price) {...}` (۱۰ درصد مالیات) تعریف کنید و فقط **بعد از** تعریفش صدا بزنید.
- در یک کامنت بنویسید چرا اگر `calcTax` را قبل از تعریفش صدا بزنیم، خطا می‌گیریم.

**تست‌ها / خروجی مورد انتظار:**
```
سلام مریم!
مالیات 200000 تومان: 20000
```

## تمرین ۲ — غلط تایپی که strict پیدا می‌کند ⭐⭐

**هدف:** دیدن اینکه `"use strict"` مقداردهی به متغیر تعریف‌نشده را خطا می‌کند.

**صورت مسئله:** این کد بدون خطا اجرا می‌شود ولی جواب غلط (`0`) می‌دهد:

```js
let total = 0;
function addPrice(price) {
  totl = total + price;   // غلط تایپی!
}
addPrice(50000);
addPrice(30000);
console.log(total);
```

**الزامات:**
- خط اول فایل `"use strict";` بگذارید و یک بار کد بالا را اجرا کنید تا خطای `ReferenceError` را در Console ببینید.
- غلط تایپی را درست کنید.
- مطمئن شوید هیچ متغیری بدون `let` یا `const` ساخته نشده.
- جمع نهایی را چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
(قبل از اصلاح، با strict) Uncaught ReferenceError: totl is not defined
(بعد از اصلاح) جمع: 80000
```

## تمرین ۳ — پیش‌بینی کن، بعد درست کن ⭐⭐⭐

**هدف:** پیدا کردن سه مشکل رایج Hoisting و Strict در یک کد کوتاه.

**صورت مسئله:** این کد کارنامه را چاپ می‌کند ولی سه مشکل دارد:

```js
"use strict";
console.log("دانش‌آموز: " + studentName);
let studentName = "سارا";

for (var i = 0; i < 3; i++) {}
console.log("i بعد از حلقه:", i);

average = (18 + 16 + 17) / 3;
console.log(showReport(average));

const showReport = function (avg) {
  return "معدل: " + avg;
};
```

**الزامات:**
- قبل از اجرا، برای هر مشکل در یک کامنت بنویسید چه اتفاقی می‌افتد (TDZ، نشت `var`، متغیر تعریف‌نشده در strict، صدا زدن `const` قبل از تعریف).
- کد را طوری بازنویسی کنید که همه متغیرها قبل از استفاده با `let`/`const` تعریف شوند و `var` نماند.
- `showReport` را به تابع اعلانی تبدیل کنید یا قبل از استفاده تعریف کنید.
- خروجی بدون خطا چاپ شود.

**تست‌ها / خروجی مورد انتظار:**
```
دانش‌آموز: سارا
تعداد درس‌ها: 3
معدل: 17
```

## اشتباه‌های رایج این مبحث

- فکر کردن به اینکه `let` و `const` «بالا نمی‌روند»؛ می‌روند، ولی تا خط تعریف در **TDZ** هستند و استفاده از آن‌ها خطا می‌دهد.
- `var` قبل از تعریف `undefined` می‌دهد، نه خطا؛ همین باگ را پنهان می‌کند.
- فقط تابع **اعلانی** را می‌شود قبل از تعریف صدا زد؛ تابعی که در `const` گذاشته شده نه.
- `"use strict"` باید **اولین خط** فایل یا تابع باشد، وگرنه اثری ندارد.
- بدون strict، غلط تایپی در اسم متغیر بی‌صدا یک متغیر سراسری تازه می‌سازد.
