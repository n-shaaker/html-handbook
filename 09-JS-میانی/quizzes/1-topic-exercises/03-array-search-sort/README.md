# مبحث ۳: جستجو و مرتب‌سازی آرایه — تمرین‌های جداگانه

درس مرتبط: [۳) جستجو و مرتب‌سازی آرایه](../../../pages/03-array-search-sort.html)

متدهای این مبحث: `indexOf`، `lastIndexOf`، `includes`، `find`، `findIndex`، `sort`، `reverse` و `localeCompare`. تابع پیکانی هنوز درس داده نشده؛ تابع‌های مقایسه را با `function` بنویسید. خروجی در **Console** است.

## تمرین ۱ — قفسه کتابخانه ⭐

**هدف:** جستجوی ساده با `includes`، `indexOf` و `lastIndexOf`.

**صورت مسئله:** قفسه کتابخانه مدرسه: `["شازده کوچولو", "بوف کور", "سمفونی مردگان", "کلیدر", "بوف کور"]`. کتابدار می‌خواهد بداند هر کتاب کجاست.

**الزامات:**
- با `includes` بررسی کنید «کلیدر» در قفسه هست یا نه.
- جای اولین و آخرین «بوف کور» را با `indexOf` و `lastIndexOf` چاپ کنید.
- تابع `findBook(name)` بنویسید که اگر کتاب نبود «پیدا نشد» و اگر بود «خانه شماره n» برگرداند (n از ۱ شروع شود).
- `findBook` را برای «سووشون» و «کلیدر» امتحان کنید.

**تست‌ها / خروجی مورد انتظار:**
```
کلیدر داریم؟ true
اولین بوف کور: 1
آخرین بوف کور: 4
سووشون: پیدا نشد
کلیدر: خانه شماره 4
```

## تمرین ۲ — مرتب کردن قیمت‌ها و میوه‌ها ⭐⭐

**هدف:** `sort` درست برای عدد (با تابع مقایسه) و برای متن فارسی (با `localeCompare`)، بدون خراب کردن آرایه اصلی.

**صورت مسئله:** قیمت‌های یک مغازه `[120000, 45000, 9000, 300000, 75000]` و میوه‌ها `["پرتقال", "انار", "سیب", "به"]` هستند.

**الزامات:**
- اول نشان دهید `sort()` بدون تابع مقایسه روی **کپی** قیمت‌ها نتیجه غلط می‌دهد.
- قیمت‌ها را صعودی و نزولی مرتب کنید (هر بار روی یک کپی با `slice()`).
- ارزان‌ترین قیمت را از آرایه صعودی بخوانید.
- میوه‌ها را با `localeCompare(..., "fa")` الفبایی کنید.
- در آخر نشان دهید آرایه `prices` دست‌نخورده است.

**تست‌ها / خروجی مورد انتظار:**
```
sort بدون مقایسه (غلط): 120000,300000,45000,75000,9000
صعودی: 9000,45000,75000,120000,300000
نزولی: 300000,120000,75000,45000,9000
ارزان‌ترین: 9000
میوه‌ها: انار، به، پرتقال، سیب
آرایه اصلی: 120000,45000,9000,300000,75000
```

## تمرین ۳ — رتبه‌بندی دانش‌آموزان ⭐⭐⭐

**هدف:** جستجو در آرایه اشیا با `find` و `findIndex` و مرتب‌سازی اشیا بر اساس یک ویژگی.

**صورت مسئله:** نمره‌ها: سارا ۱۸، علی ۹٫۵، رضا ۱۵، مریم ۹. معلم می‌خواهد اولین مردود، جای رضا و رتبه‌بندی کلاس را ببیند.

**الزامات:**
- آرایه `students` شامل اشیای `{ name, score }` بسازید.
- با `find` اولین دانش‌آموز با نمره کمتر از ۱۰ را پیدا کنید.
- با `findIndex` اندیس «رضا» را چاپ کنید.
- `find` را برای «نیما» امتحان کنید؛ چون `undefined` برمی‌گرداند، پیام «نیما پیدا نشد» چاپ کنید.
- یک کپی را بر اساس نمره نزولی مرتب و رتبه‌بندی را با حلقه چاپ کنید.

**تست‌ها / خروجی مورد انتظار:**
```
اولین مردود: علی
اندیس رضا: 2
نیما پیدا نشد
1. سارا - 18
2. رضا - 15
3. علی - 9.5
4. مریم - 9
```

## اشتباه‌های رایج این مبحث

- `sort()` بدون تابع مقایسه، عددها را مثل **متن** مقایسه می‌کند (۹۰۰۰ بعد از ۷۵۰۰۰ می‌آید).
- `sort` و `reverse` آرایه اصلی را تغییر می‌دهند؛ اگر اصل را لازم دارید، اول `slice()` بگیرید.
- `indexOf` وقتی چیزی پیدا نکند `-1` می‌دهد، نه `false`؛ شرط `if (index)` برای اندیس ۰ هم غلط کار می‌کند.
- `find` خود عضو را برمی‌گرداند و `findIndex` اندیسش را؛ اگر پیدا نشود اولی `undefined` و دومی `-1` است.
- برای متن فارسی `a > b` کافی نیست؛ از `localeCompare(b, "fa")` استفاده کنید.
