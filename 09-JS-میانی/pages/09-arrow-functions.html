۹) توابع پیکانی (Arrow Functions)

تابع پیکانی شکل کوتاه‌تری برای نوشتن تابع است و در متدهایی مثل map و filter زیاد دیده می‌شود. کار اصلی‌اش همان اجرای یک بلوک کد و برگرداندن مقدار است. تفاوت مهمش با تابع معمولی در دو جا ظاهر می‌شود: اگر بدنه فقط یک عبارت باشد می‌توان آکولاد و return را حذف کرد، و this خودش را جداگانه نمی‌سازد. مورد دوم را در درس this می‌بینید؛ اینجا اول شکل نوشتن را یاد بگیرید.

// تابع معمولی
const add1 = function (a, b) {
  return a + b;
};

// تابع پیکانی
const add2 = (a, b) => {
  return a + b;
};

// کوتاه‌تر: اگر فقط یک return دارد، { } و return حذف می‌شوند
const add3 = (a, b) => a + b;

console.log(add1(2, 3), add2(2, 3), add3(2, 3));

هر سه ثابت یک تابع جمع هستند. add1 شکل معمولی است. add2 همان بدنه را بعد از فلش => نوشته است. add3 چون فقط یک عبارت برمی‌گرداند، آکولاد و return را حذف کرده و خود a + b مقدار خروجی است. هر سه را با آرگومان‌های ۲ و ۳ صدا می‌زنیم و نتیجه یکی است.






قوانین کوتاه‌نویسی

چند پارامتر(a, b) => a + b


چند خط(a) => { const r = a * 2; return r; }


برگرداندن شیء() => ({ name: "علی" }) (داخل پرانتز)





const hello = () => "سلام!";
const double = x => x * 2;
const makeUser = (name, age) => ({ name: name, age: age });

console.log(hello());
console.log(double(21));
console.log(makeUser("مریم", 25));



اگر پارامترها صفر تا باشند پرانتز خالی لازم است. اگر دقیقاً یک پارامتر باشد می‌توان پرانتز را برداشت. برای برگرداندن شیء در شکل کوتاه، دور آکولاد شیء یک پرانتز اضافه می‌گذارند؛ وگرنه زبان آکولاد را بدنهٔ تابع حساب می‌کند نه شیء. hello متن ثابت برمی‌گرداند و double ورودی را دو برابر می‌کند.










بهترین جا: همراه با map، filter و ...



const nums = [1, 2, 3, 4, 5, 6];

// قبل
const evens1 = nums.filter(function (n) { return n % 2 === 0; });

// بعد
const evens2 = nums.filter(n => n % 2 === 0);
const squares = nums.map(n => n * n);
const total = nums.reduce((sum, n) => sum + n, 0);

console.log(evens2, squares, total);   // [2,4,6] [1,4,9,16,25,36] 21

// مثال واقعی: نام محصولات موجود زیر ۲ میلیون تومان
const products = [
  { name: "کیبورد", price: 1500000, inStock: true },
  { name: "مانیتور", price: 9800000, inStock: true },
  { name: "ماوس", price: 600000, inStock: false }
];
const affordable = products
  .filter(p => p.inStock && p.price < 2000000)
  .map(p => p.name);
console.log(affordable);               // ["کیبورد"]



وقتی تابع فقط یک پارامتر دارد و یک عبارت برمی‌گرداند، فلش جای function و return را می‌گیرد. filter عددهای زوج را جدا می‌کند، map مربع هر عدد را می‌سازد و reduce مجموع را با مقدار شروع صفر حساب می‌کند. در فهرست کالا، شرط موجود بودن و سقف قیمت در همان عبارت فلش نوشته شده است.










در رویدادها



const btn = document.getElementById("arrow-btn");
const box = document.getElementById("arrow-box");

btn.addEventListener("click", () => {
  box.classList.toggle("active");
});



شنوندهٔ کلیک یک تابع پیکانی بدون پارامتر است. با هر کلیک، classList.toggle کلاس active را اگر نباشد اضافه و اگر باشد حذف می‌کند. چون بدنه بیش از یک کار مفهومی ندارد، باز هم آکولاد آمده است؛ اگر فقط یک عبارت بود می‌شد آن را بدون آکولاد نوشت. اینجا آکولاد روشن‌تر است چون دستور، مقدار برنمی‌گرداند.





این جعبه با یک تابع پیکانی تغییر می‌کند






تفاوت‌های تابع پیکانی با تابع معمولی

فرق مهم تابع پیکانی با تابع معمولی در رفتار this است که در درس بعد می‌بینیم. برای متدهای شیء از تابع معمولی (یا شکل کوتاه greet() { ... }) استفاده کنید و برای callbackها (تابع‌هایی که به map، filter، addEventListener و ... می‌دهیم) تابع پیکانی بهترین انتخاب است.



اشتباه رایج: برگرداندن شیء بدون پرانتز: () => { name: "علی" }. JavaScript آکولاد را بلوک کد می‌فهمد و undefined برمی‌گرداند.



اشتباه رایج: نوشتن آکولاد در تابع پیکانی و فراموش کردن return: nums.map(n => { n * 2 }) آرایه‌ای پر از undefined می‌دهد. یا آکولاد را بردارید (n => n * 2) یا return بنویسید.



تمرین: (الف) این تابع را به شکل پیکانی یک‌خطی بنویسید: function greet(name) { return "سلام " + name; }. (ب) با map و یک تابع پیکانی قیمت‌های [100, 200, 300] را با ۲۰٪ تخفیف حساب کنید (جواب: [80, 160, 240]). (ج) با filter و تابع پیکانی، از آرایه نمره‌ها [12, 19, 8, 15, 20] نمره‌های ۱۵ و بالاتر را جدا کنید.
