۳) جستجو و مرتب‌سازی آرایه (Search & Sort)

وقتی فهرست طولانی است، پیدا کردن یک عضو با چشم یا با حلقه‌ای که خودتان از صفر می‌نویسید هم کندتر خوانده می‌شود و هم راحت‌تر اشتباه می‌شود. متدهای جستجو یا شمارهٔ عضو را می‌دهند، یا خود عضو را، یا فقط می‌گویند آن مقدار هست یا نه. مرتب‌سازی ترتیب نمایش را عوض می‌کند، ولی قاعده‌اش برای متن، عدد و شیء یکی نیست. اگر تابع مقایسه را درست ننویسید، عددی مثل ۱۰۰ ممکن است قبل از ۲۵ قرار بگیرد.

جستجو

متدخروجی
indexOf(x)شماره اولین x؛ اگر نبود -1
includes(x)true یا false
find(fn)اولین عضوی که شرط را دارد (یا undefined)
findIndex(fn)شماره اولین عضوی که شرط را دارد (یا -1)
const nums = [4, 9, 16, 25, 29];

console.log(nums.indexOf(16));
console.log(nums.indexOf(100));
console.log(nums.includes(25));

const firstBig = nums.find(function (n) {
  return n > 10;
});
console.log(firstBig);
console.log(nums.findIndex(function (n) { return n > 10; }));





indexOf با برابری دقیق دنبال مقدار می‌گردد و شمارهٔ اولین مورد را برمی‌گرداند؛ اگر نباشد نتیجه -1 است، نه undefined. includes فقط هست یا نیست را با true و false می‌گوید. find تابعی می‌گیرد و آن را روی عضو‌ها اجرا می‌کند تا اولین عضوی که شرطش true شود را برگرداند. findIndex به‌جای خود عضو، شمارهٔ همان عضو را می‌دهد.



find یک تابع می‌گیرد و آن را برای تک‌تک عضوها اجرا می‌کند. اولین عضوی که تابع برایش true برگرداند، جواب است. اگر همه عضوهای منطبق را می‌خواهید، از filter (درس بعد) استفاده کنید.



مرتب‌سازی متن



sort() بدون ورودی، عضوها را به رشته تبدیل می‌کند و بر اساس کد یونیکد کاراکترها (مثل ترتیب واژه‌نامه، ولی حرف به حرف) مرتب می‌کند. برای همین حروف بزرگ انگلیسی قبل از حروف کوچک می‌آیند.



const names = ["Sara", "Ali", "Maryam", "Reza"];
names.sort();
console.log(names);        // ["Ali","Maryam","Reza","Sara"]
names.reverse();           // فقط ترتیب فعلی را برعکس می‌کند
console.log(names);        // ["Sara","Reza","Maryam","Ali"]

const mixedCase = ["banana", "Cherry", "apple"];
console.log(mixedCase.sort());   // ["Cherry","apple","banana"] — حرف بزرگ اول!

const cities = ["مشهد", "گرگان", "تبریز", "پاوه", "اصفهان", "چالوس"];
console.log(cities.slice().sort());  // ✖ پ، چ و گ آخر رفتند (ترتیب یونیکد، نه الفبای فارسی)

// مرتب‌سازی درست متن (فارسی یا انگلیسی) با localeCompare
cities.sort(function (a, b) { return a.localeCompare(b, "fa"); });
console.log(cities);              // ✔ اصفهان، پاوه، تبریز، چالوس، گرگان، مشهد



حروف «پ، چ، ژ، گ» و «ک، ی» فارسی در جدول یونیکد بعد از حروف عربی آمده‌اند؛ برای همین sort() ساده آن‌ها را جای اشتباه می‌گذارد. a.localeCompare(b, "fa") طبق الفبای فارسی مقایسه می‌کند.










sort بدون تابع، عضو‌ها را به متن تبدیل می‌کند و بر اساس کد یونیکد مرتب می‌کند؛ به همین دلیل Cherry قبل از apple می‌آید. reverse فقط ترتیب فعلی را برمی‌گرداند و خودش قاعدهٔ الفبا ندارد. slice() قبل از sort یک کپی می‌سازد تا آزمایش ترتیب یونیکد، آرایهٔ اصلی شهرها را عوض نکند. localeCompare با زبان "fa" دو متن را طبق الفبای فارسی مقایسه می‌کند و عددی منفی، صفر یا مثبت برمی‌گرداند که sort با آن جابه‌جایی را انجام می‌دهد.



مرتب‌سازی عدد — حتماً تابع مقایسه بدهید



تابع مقایسه دو عضو a و b را می‌گیرد و یک عدد برمی‌گرداند: اگر منفی بود a اول می‌آید، اگر مثبت بود b اول می‌آید و اگر صفر بود ترتیبشان عوض نمی‌شود. a - b دقیقاً همین را برای عددها می‌سازد.



const scores = [40, 100, 1, 5, 25, 10];

scores.sort();
console.log(scores);              // ✖ غلط! [1,10,100,25,40,5] — مثل متن مرتب شد

scores.sort(function (a, b) { return a - b; });
console.log(scores);              // ✔ صعودی: [1,5,10,25,40,100]

scores.sort(function (a, b) { return b - a; });
console.log(scores);              // ✔ نزولی: [100,40,25,10,5,1]










همان sort بدون تابع، عدد ۱۰۰ را به متن "100" تبدیل می‌کند. چون نویسهٔ 1 قبل از 2 است، ۱۰۰ قبل از ۲۵ قرار می‌گیرد. تابع a - b اگر نتیجه منفی باشد a را جلوتر می‌گذارد و ترتیب صعودی می‌سازد. b - a علامت را برعکس می‌کند و ترتیب نزولی می‌شود. هر بار sort همان آرایهٔ scores را عوض می‌کند.



sort آرایه اصلی را تغییر می‌دهد



const prices = [300, 120, 450];
const sorted = prices.sort(function (a, b) { return a - b; });
console.log(prices);              // [120,300,450] — اصلی هم عوض شد!
console.log(sorted === prices);   // true — هر دو یک آرایه‌اند

const original = [300, 120, 450];
const sortedCopy = original.slice().sort(function (a, b) { return a - b; });
console.log(original);            // [300,120,450] — دست نخورد
console.log(sortedCopy);          // [120,300,450]










مقدار برگشتی sort خود همان آرایه است، نه فهرست تازه. به همین دلیل sorted === prices برابر true است و چاپ prices هم ترتیب مرتب‌شده را نشان می‌دهد. اگر ترتیب قبلی را لازم دارید، اول slice() آرایه‌ای جدید با همان عضو‌ها می‌سازد و sort فقط روی آن کپی اثر می‌گذارد.



slice() بدون ورودی (درس ۲) یک کپی از کل آرایه می‌سازد. پس arr.slice().sort(...) کپی را مرتب می‌کند و آرایه اصلی دست نمی‌خورد.



مرتب‌سازی آرایه‌ای از اشیا



const products = [
  { name: "کتاب", price: 120 },
  { name: "خودکار", price: 15 },
  { name: "کیف", price: 450 }
];

products.sort(function (a, b) { return a.price - b.price; });   // ارزان به گران
console.log(products);

const cheap = products.find(function (p) { return p.price < 100; });
console.log(cheap.name);

const missing = products.find(function (p) { return p.price > 1000; });
console.log(missing);             // undefined — چیزی پیدا نشد










تابع مقایسه این بار ویژگی price دو شیء را از هم کم می‌کند، پس ملاک مرتب‌سازی قیمت است نه نام. بعد از مرتب شدن، find اولین کالایی را برمی‌گرداند که قیمتش کمتر از ۱۰۰ باشد. اگر هیچ عضوی شرط را نداشته باشد، نتیجه undefined است و نباید مستقیم ویژگی‌ای مثل name را از آن بخوانید.



کمترین و بیشترین



const temps = [4, 9, 2];
console.log(Math.min(...temps));   // ... (Spread) آرایه را باز می‌کند — درس ۱۱
console.log(Math.max(...temps));
console.log(Math.max(temps));      // NaN — آرایه را بدون ... نمی‌پذیرد










Math.min و Math.max عددها را به‌صورت آرگومان جدا می‌خواهند. سه‌نقطه آرایه را باز می‌کند و هر عضو را یک آرگومان جدا می‌فرستد. اگر خود آرایه را بدون باز کردن بدهید، این تابع‌ها عضو‌ها را با هم مقایسه نمی‌کنند و نتیجه NaN می‌شود. کار سه‌نقطه در درس باز کردن آرایه کامل توضیح داده می‌شود؛ اینجا فقط برای پیدا کردن کمینه و بیشینه به آن نیاز است.



مثال زنده: مرتب‌سازی محصولات فروشگاه



const shopItems = [
  { name: "هدفون", price: 1850000 },
  { name: "کابل شارژ", price: 240000 },
  { name: "پاوربانک", price: 1290000 },
  { name: "قاب گوشی", price: 350000 }
];

const sortSelect = document.getElementById("sort-select");
const shopList = document.getElementById("shop-list");

function showProducts() {
  if (sortSelect.value === "cheap") {
    shopItems.sort(function (a, b) { return a.price - b.price; });
  } else if (sortSelect.value === "expensive") {
    shopItems.sort(function (a, b) { return b.price - a.price; });
  } else {
    shopItems.sort(function (a, b) { return a.name.localeCompare(b.name, "fa"); });
  }

  let html = "";
  for (const item of shopItems) {
    html += `<li><span>${item.name}</span><span>${item.price.toLocaleString("fa-IR")} تومان</span></li>`;
  }
  shopList.innerHTML = html;   // داده‌ها مال خودمان است، نه ورودی کاربر
}

sortSelect.addEventListener("change", showProducts);
showProducts();







    

    


    با هر تغییر فهرست، showProducts بر اساس مقدار انتخاب‌شده یکی از سه مقایسه را اجرا می‌کند: قیمت از کم به زیاد، قیمت از زیاد به کم، یا نام با localeCompare. حلقه نام و قیمت را به صورت آیتم فهرست جمع می‌کند و یک‌بار داخل ul می‌گذارد. چون داده‌ها از آرایهٔ خود برنامه می‌آیند، نه از متن آزاد کاربر، قرار دادن این HTML در صفحه در این مثال خطر تزریق ندارد.
    


    اشتباه رایج: sort() بدون تابع مقایسه برای عددها. چون عددها مثل متن مقایسه می‌شوند، 100 قبل از 25 می‌آید.
    


    اشتباه رایج: برگرداندن true/false از تابع مقایسه (مثلاً return a > b;). تابع مقایسه باید عدد (منفی، صفر یا مثبت) برگرداند؛ وگرنه نتیجه در مرورگرهای مختلف درست نیست.
    


    اشتباه رایج: استفاده از find و بعد خواندن ویژگی بدون بررسی: اگر چیزی پیدا نشود find مقدار undefined برمی‌گرداند و result.name خطای TypeError می‌دهد. اول بررسی کنید: if (result) { ... }.
    


    تمرین: آرایه‌ای از اشیای دانشجو (name، score) با حداقل ۵ عضو بسازید. (الف) با slice().sort(...) بر اساس نمره نزولی مرتب کنید و اسم نفر اول را چاپ کنید (آرایه اصلی نباید عوض شود). (ب) با find اولین دانشجوی مردود (نمره زیر ۱۰) را پیدا کنید و اگر کسی مردود نبود، پیام «همه قبول شدند» را چاپ کنید. (ج) با localeCompare فهرست را بر اساس نام الفبایی مرتب کنید.
