۱۵) DOM: تغییر محتوا، ویژگی و ظاهر

بعد از پیدا کردن عنصر، معمولاً می‌خواهید متن، ویژگی HTML یا کلاس CSS آن را عوض کنید. متنی که از کاربر آمده را با textContent بنویسید تا به‌صورت نوشته دیده شود. کلاس‌ها ظاهر را از CSS می‌گیرند و JavaScript فقط بود و نبود آن‌ها را عوض می‌کند. ویژگی‌هایی مثل href، value و disabled رفتار خود عنصر را تغییر می‌دهند.

کارکد
تغییر متن (امن)el.textContent = "..."
تغییر HTML داخل (فقط با داده مطمئن)el.innerHTML = "<b>...</b>"
خواندن/تغییر ویژگیel.getAttribute("href") / el.setAttribute("href", "...")
ویژگی‌های رایج مستقیمimg.src، a.href، input.value، input.disabled
کلاس‌هاel.classList.add / remove / toggle / contains
استایل مستقیمel.style.color = "red"
data-*el.dataset.price برای data-price

مثال ۱: ویژگی‌ها

const link = document.querySelector("#demo-link");
console.log(link.getAttribute("href"));    // https://developer.mozilla.org/

link.setAttribute("href", "https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model");
link.textContent = "مستندات DOM در MDN";
console.log(link.href);                    // آدرس جدید

const back = document.querySelector("#back-link");
console.log(back.getAttribute("href"));    // ../index.html ← همان چیزی که در HTML نوشته شده
console.log(back.href);                    // آدرس کامل؛ حروف فارسی مسیر به شکل %D8%... کدگذاری می‌شوند

const product = document.querySelector("#product");
console.log(product.dataset.price, product.dataset.color);   // 120000 آبی
console.log(typeof product.dataset.price);                   // string ← برای حساب Number(...) لازم است
مستندات MDN — فهرست درس‌ها

محصول: کوله‌پشتی (data-price و data-color)






getAttribute("href") دقیقاً متنی را برمی‌گرداند که در HTML نوشته شده؛ ولی ویژگی link.href آدرس کامل را می‌دهد (آدرس نسبی را به آدرس مطلق تبدیل می‌کند). مقدار dataset همیشه رشته است.



textContent یا innerHTML؟



const commentInput = document.getElementById("comment-input");
const previewBtn = document.getElementById("preview-btn");
const preview = document.getElementById("preview");

previewBtn.addEventListener("click", () => {
  preview.textContent = commentInput.value;   // ✔ امن: تگ‌ها به شکل متن نمایش داده می‌شوند
  // preview.innerHTML = commentInput.value;  // ✖ خطرناک: کد کاربر اجرا می‌شود (XSS)
});



مقدار کادر، متنی است که کاربر نوشته، حتی اگر داخلش علامت تگ باشد. textContent آن را به‌صورت نویسه نشان می‌دهد و مرورگر تگ را اجرا نمی‌کند. اگر همان رشته را به innerHTML بدهید، مرورگر آن را HTML تفسیر می‌کند و این برای متن کاربر ناامن است.








پیش‌نمایش نظر اینجا نشان داده می‌شود





اشتباه رایج (و خطرناک): گذاشتن متنی که کاربر وارد کرده داخل innerHTML. اگر کاربر به جای نظر، چیزی مثل <img src=x onerror="..."> بنویسد، کد او در صفحه اجرا می‌شود؛ به این حمله XSS می‌گویند. برای متن کاربر همیشه از textContent استفاده کنید و innerHTML را فقط برای HTML‌ای که خودتان نوشته‌اید به کار ببرید.



مثال ۲: classList (روش پیشنهادی برای تغییر ظاهر)



const box = document.getElementById("cls-box");
const addBtn = document.getElementById("cls-add");
const removeBtn = document.getElementById("cls-remove");
const toggleBtn = document.getElementById("cls-toggle");
const checkBtn = document.getElementById("cls-check");

addBtn.addEventListener("click", () => box.classList.add("active"));
removeBtn.addEventListener("click", () => box.classList.remove("active"));
toggleBtn.addEventListener("click", () => box.classList.toggle("active"));
checkBtn.addEventListener("click", () => {
  box.textContent = "کلاس active دارد؟ " + box.classList.contains("active");
});



add کلاس را اضافه می‌کند و اگر از قبل باشد دوباره اضافه نمی‌شود. remove همان کلاس را برمی‌دارد. toggle بین بود و نبود جابه‌جا می‌کند. contains فقط می‌پرسد کلاس هست یا نه و خودش ظاهر را عوض نمی‌کند. رنگ و اندازه در CSS کلاس active تعریف شده است.





جعبه نمونه









مثال ۳: style — تغییر اندازه فونت



let size = 16;
const text = document.getElementById("size-text");
const biggerBtn = document.getElementById("size-up");
const smallerBtn = document.getElementById("size-down");

biggerBtn.addEventListener("click", () => {
  size += 2;
  text.style.fontSize = size + "px";      // font-size در JS می‌شود fontSize
});

smallerBtn.addEventListener("click", () => {
  size = Math.max(10, size - 2);          // از ۱۰ پیکسل کوچک‌تر نشود
  text.style.fontSize = size + "px";
});





این متن را بزرگ و کوچک کنید.







ویژگی‌های CSS که خط تیره دارند در JavaScript به شکل camelCase نوشته می‌شوند: background-color ← backgroundColor.



تا جای ممکن به جای el.style از classList استفاده کنید تا ظاهر در فایل CSS بماند و JavaScript فقط کلاس را عوض کند؛ همان قانون «جدا نگه داشتن CSS» که در این دوره رعایت می‌کنیم.



مثال ۴: غیرفعال کردن دکمه



const agree = document.getElementById("agree");
const sendBtn = document.getElementById("send-btn");

agree.addEventListener("change", () => {
  sendBtn.disabled = !agree.checked;
});



رویداد change وقتی وضعیت چک‌باکس عوض شود اجرا می‌شود. checked بولین است. علامت ! آن را برعکس می‌کند تا دکمه وقتی تیک نخورده است غیرفعال بماند و وقتی تیک خورد فعال شود. ویژگی disabled هم ظاهر دکمه را عوض می‌کند و هم جلوی کلیک را می‌گیرد.











اشتباه رایج: نوشتن el.style.font-size. خط تیره در JavaScript یعنی منها! درستش el.style.fontSize است.



اشتباه رایج: نوشتن el.className = "active" برای اضافه کردن کلاس. این کار همه کلاس‌های قبلی (مثل demo-box) را پاک می‌کند؛ برای اضافه کردن از classList.add استفاده کنید.



تمرین: سه دکمه «قرمز»، «سبز» و «آبی» بسازید که هر کدام ویژگی data-color دارند (مثلاً data-color="red"). با کلیک روی هر دکمه، رنگ را با dataset.color بخوانید و رنگ پس‌زمینه یک جعبه را با style.backgroundColor عوض کنید. (امتیازی: به جای style، برای هر رنگ یک کلاس CSS بسازید و با classList عوضش کنید.)
