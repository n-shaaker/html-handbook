۱۹) اشکال‌زدایی پایه

قبل از پروژه Todo، این عادت‌ها را بگیرید. درس عمیق‌تر در دوره پیشرفته است؛ اینجا حداقل لازم جونیور است.

  1. کلید F12 یا راست‌کلیک → Inspect
  2. تب Console: خطاهای قرمز را بخوانید (فایل و شماره خط)
  3. تب Elements: ببینید DOM بعد از JS چه شکلی شده
  4. console.log(value) برای چاپ مقدار مشکوک
  5. در Sources روی شماره خط کلیک کنید تا breakpoint بگذارید، بعد صفحه را رفرش کنید
const el = document.getElementById("todo-input");
console.log("el =", el); // اگر null بود، id اشتباه است یا اسکریپت زود اجرا شده

ادامه: اشکال‌زدایی حرفه‌ای (درس ۱۷ پیشرفته)

تمرین: عمداً یک id غلط بدهید، خطا را در Console پیدا و درست کنید.
