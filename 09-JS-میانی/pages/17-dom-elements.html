۱۷) DOM: ساختن و حذف عنصرها

صفحه فقط از عنصرهایی که از اول در HTML نوشته شده‌اند ساخته نمی‌شود. با createElement عنصر تازه می‌سازید، با textContent متن امن داخلش می‌گذارید و با append آن را به عنصری که از قبل وجود دارد وصل می‌کنید. حذف و پیدا کردن پدر یا همسایه هم روی همین درخت انجام می‌شود.

کارکد
ساختن عنصرdocument.createElement("li")
اضافه به آخر / اولparent.append(el) / parent.prepend(el)
اضافه قبل / بعد از یک عنصرel.before(newEl) / el.after(newEl)
اضافه با HTML (فقط با داده مطمئن، نه ورودی کاربر)parent.insertAdjacentHTML("beforeend", "<li>...</li>")
حذفel.remove()
کپیel.cloneNode(true)

مثال ۱: ساختن یک عنصر کامل

const container = document.getElementById("card-container");

const card = document.createElement("div");
card.className = "js-card";

const title = document.createElement("h4");
title.textContent = "کارت جدید";

const text = document.createElement("p");
text.textContent = "این کارت کاملاً با JavaScript ساخته شد.";

card.append(title, text);
container.append(card);

createElement عنصر را در حافظه می‌سازد و هنوز آن را روی صفحه نشان نمی‌دهد. className کلاس CSS را می‌گذارد و textContent متن را. card.append عنوان و پاراگراف را داخل کارت می‌گذارد. container.append آخرین مرحله است: کارت را به عنصری که در HTML وجود دارد وصل می‌کند و همان لحظه دیده می‌شود.

مثال ۲: فهرست خرید (اضافه و حذف)

const itemInput = document.getElementById("item-input");
const addBtn = document.getElementById("item-add");
const list = document.getElementById("shop-list");

addBtn.addEventListener("click", () => {
  const value = itemInput.value.trim();
  if (value === "") return;

  const li = document.createElement("li");
  const span = document.createElement("span");
  span.textContent = value;                 // متن کاربر ← textContent (امن)

  const del = document.createElement("button");
  del.type = "button";
  del.textContent = "حذف";
  del.className = "btn danger";
  del.addEventListener("click", () => li.remove());

  li.append(span, del);
  list.append(li);
  itemInput.value = "";
  itemInput.focus();
});

itemInput.addEventListener("keydown", (e) => {
  if (e.key === "Enter") addBtn.click();    // با Enter هم اضافه شود
});

اگر متن بعد از trim خالی باشد، return جلوی ساختن آیتم خالی را می‌گیرد. برای هر کالا یک li، یک span و یک دکمه ساخته می‌شود. متن کاربر با textContent وارد می‌شود تا تگ اجرا نشود. دکمه با li.remove() همان ردیف را از درخت حذف می‌کند. خالی کردن کادر و focus کاربر را برای کالای بعدی آماده می‌کند. کلید Enter هم همان کلیک دکمه را صدا می‌زند.

    برای متنی که کاربر وارد کرده از createElement و textContent استفاده کنید نه innerHTML؛ این‌طوری اگر کاربر تگ HTML بنویسد، اجرا نمی‌شود (برای امتحان، <b>نان</b> را اضافه کنید). در اینجا روی هر دکمه «حذف» جداگانه listener گذاشتیم؛ روش دیگر Event Delegation است که در درس ۱۶ دیدید.

    پیمایش درخت DOM

    ویژگییعنی
    el.parentElementپدر
    el.childrenفرزندان (عنصرها)
    el.firstElementChild / lastElementChildاولین / آخرین فرزند
    el.nextElementSibling / previousElementSiblingخواهر/برادر بعدی / قبلی
    el.closest("selector")نزدیک‌ترین جد (یا خودش) که با انتخابگر منطبق است
    const middle = document.querySelector("#nav-demo .mid");
console.log(middle.parentElement.id);                      // nav-demo
console.log(middle.previousElementSibling.textContent);    // اول
console.log(middle.nextElementSibling.textContent);        // آخر
console.log(middle.parentElement.children.length);         // 3
console.log(middle.closest("section").className);          // lesson-demo

    parentElement عنصر بالایی مستقیم است. previousElementSibling و nextElementSibling عنصرهای هم‌سطح قبلی و بعدی‌اند، نه گره‌های متنی خالی. children فقط عنصرهای فرزند را می‌شمارد. closest از خود عنصر شروع می‌کند و به سمت بالا می‌رود تا اولین جد مطابق انتخابگر را پیدا کند.

    اشتباه رایج: ساختن عنصر با createElement و فراموش کردن append. عنصر ساخته می‌شود ولی تا به صفحه اضافه نشود دیده نمی‌شود.
    


    تمرین: با آرایه [{ name: "کتاب", price: 250000 }, { name: "دفتر", price: 45000 }, { name: "ماژیک", price: 30000 }] و forEach، برای هر محصول یک کارت (div.js-card) با createElement بسازید که نام (h4)، قیمت با toLocaleString("fa-IR") و یک دکمه «حذف» داشته باشد. با کلیک روی «حذف» کارت از صفحه پاک شود و زیر کارت‌ها «تعداد محصولات: ...» به‌روز شود (راهنما: container.children.length).
