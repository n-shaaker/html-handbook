۱۰) کلمه کلیدی this

this یک کلمه کلیدی است که داخل تابع معمولی به «شیئی که تابع را صدا زده» اشاره می‌کند. مقدارش به این بستگی ندارد که تابع کجا نوشته شده، بلکه به این بستگی دارد که چطور صدا زده شده. قانون ساده: در obj.method() هر چه قبل از نقطه است، this می‌شود.

کجا / چطور صدا زده شدهthis برابر است با
متد شیء: obj.method()همان شیء (obj)
تابع معمولی در addEventListenerعنصری که listener روی آن نصب شده (event.currentTarget)
تابع معمولی که تنها صدا زده شود: f()در حالت strict: undefined — بدون strict: window
بیرون از همه توابع (اسکریپت معمولی در مرورگر)window (در ماژول‌ها undefined)
تابع پیکانیthis ندارد؛ this محدوده بیرونی را برمی‌دارد (هر طور صدا زده شود)

this در متد شیء

const user = {
  name: "سارا",
  greet: function () {
    return "سلام، من " + this.name + " هستم";
  }
};

console.log(user.greet());

greet تابع معمولی است و با شکل user.greet() صدا زده می‌شود. چیزی که قبل از نقطه است user است، پس داخل تابع this همان شیء است و this.name مقدار «سارا» را می‌خواند. اگر پرانتز را فراموش کنید، تابع اجرا نمی‌شود و متن سلام ساخته نمی‌شود.






تابع پیکانی this خودش را ندارد



const user2 = {
  name: "علی",
  normal: function () { return this.name; },
  arrow: () => this.name        // this اینجا مال بیرون است، نه user2
};

console.log("normal:", user2.normal());   // normal: علی
console.log("arrow:", user2.arrow());     // arrow:  ← خالی!










چرا خالی؟ آکولاد شیء ({ }) محدوده جدید نمی‌سازد؛ پس this تابع پیکانی همان this بیرون از شیء است که در این صفحه window است. window.name یک ویژگی آماده مرورگر است که معمولاً رشته خالی است؛ برای همین چیزی چاپ نشد. (در ماژول یا حالت strict، this بیرونی undefined است و همین کد خطای TypeError می‌دهد.)



جدا کردن متد از شیء — this گم می‌شود



const shop = {
  name: "کتاب‌فروشی دانش",
  welcome: function () {
    return "به " + this.name + " خوش آمدید";
  }
};

console.log(shop.welcome());     // ✔ به کتاب‌فروشی دانش خوش آمدید

const welcomeFn = shop.welcome;  // فقط خود تابع کپی شد، نه shop
console.log(welcomeFn());        // ✖ به  خوش آمدید ← this دیگر shop نیست

const fixed = shop.welcome.bind(shop);   // bind: this را برای همیشه shop کن
console.log(fixed());            // ✔ به کتاب‌فروشی دانش خوش آمدید



وقتی متد را در متغیر دیگری می‌ریزید، فقط خود تابع کپی می‌شود و ارتباطش با shop قطع می‌شود. صدا زدن welcomeFn() دیگر «قبل از نقطه» ندارد، پس this شیء فروشگاه نیست. bind(shop) تابع تازه‌ای می‌سازد که this آن همیشه shop است، حتی اگر آن را بدون نقطه صدا بزنید.










وقتی welcomeFn() را بدون نقطه صدا می‌زنیم، چیزی قبل از نقطه نیست؛ پس this در این صفحه window می‌شود (در حالت strict undefined و خطای Cannot read properties of undefined (reading 'name')). همین اتفاق وقتی هم می‌افتد که متد را به عنوان callback بدهید: setTimeout(shop.welcome, 1000) یا btn.addEventListener("click", shop.welcome). راه‌حل: shop.welcome.bind(shop) یا یک تابع پیکانی: () => shop.welcome().



کجا تابع پیکانی مفید است؟ داخل یک متد



const team = {
  name: "تیم آبی",
  members: ["سارا", "علی"],
  show: function () {
    this.members.forEach(m => {
      console.log(m + " عضو " + this.name);   // this همان team است
    });
  }
};

team.show();
// اگر به جای m => {...} می‌نوشتیم function (m) {...}، آن تابع this خودش را
// داشت (چون forEach آن را تنها صدا می‌زند) و this.name دیگر «تیم آبی» نبود.



show با team.show() صدا زده می‌شود، پس this داخل آن همان team است. تابع پیکانی داخل forEach this جدا نمی‌سازد و this همان تابع بیرونی را برمی‌دارد؛ به همین دلیل this.name هنوز «تیم آبی» است. اگر به‌جای فلش یک function معمولی می‌نوشتید، forEach آن را تنها صدا می‌زد و this دیگر تیم نبود.










this در رویداد



const buttons = document.querySelectorAll(".this-btn");

buttons.forEach(btn => {
  btn.addEventListener("click", function () {
    this.textContent = "کلیک شدم ✔";   // this = همان دکمه‌ای که کلیک شد
  });
});



حلقه روی همهٔ دکمه‌هایی اجرا می‌شود که کلاس this-btn دارند. شنونده یک تابع معمولی است. در addEventListener، this این نوع تابع همان عنصری است که شنونده روی آن نصب شده، یعنی دکمه‌ای که کلیک شده. textContent متن همان دکمه را عوض می‌کند.











رویداد با تابع پیکانی: از event.currentTarget استفاده کنید



const arrowButtons = document.querySelectorAll(".arrow-this-btn");

arrowButtons.forEach(btn => {
  btn.addEventListener("click", (event) => {
    // this اینجا دکمه نیست (this بیرونی است)؛ پس از event استفاده می‌کنیم
    event.currentTarget.textContent = "کلیک شدم ✔ (currentTarget)";
  });
});



این شنونده تابع پیکانی است و this را از بیرون می‌گیرد، نه از دکمه. اطلاعات رویداد در پارامتر event است. currentTarget عنصری است که شنونده روی آن ثبت شده، پس متن همان دکمه عوض می‌شود. اگر به‌جای آن this می‌نوشتید، به دکمه نمی‌رسیدید.










event.currentTarget همیشه عنصری است که listener روی آن نصب شده؛ چه تابع معمولی بنویسید چه پیکانی. برای همین در کد امروزی معمولاً این روش واضح‌تر از this است.



اشتباه رایج: نوشتن متد شیء با تابع پیکانی و انتظار داشتن اینکه this خود شیء باشد.



اشتباه رایج: استفاده از this داخل تابع پیکانی رویداد: btn.addEventListener("click", () => this.classList.add("x")). اینجا this دکمه نیست و خطا می‌گیرید؛ از event.currentTarget یا همان متغیر btn استفاده کنید.



تمرین: شیء cart (سبد خرید) با ویژگی items: [] و این متدها بسازید که همه با this کار کنند: add(name, price) یک کالا به this.items اضافه کند، total() جمع قیمت‌ها را برگرداند (با reduce) و show() همه کالاها را چاپ کند (داخلش از forEach با تابع پیکانی استفاده کنید). سپس const t = cart.total; را صدا بزنید، توضیح دهید چرا خطا می‌دهد و با bind درستش کنید.
