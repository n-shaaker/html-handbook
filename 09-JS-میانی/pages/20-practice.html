۲۰) پروژه جمع‌بندی: فهرست کارها (Todo List)

این پروژه مهم‌ترین مباحث دوره را کنار هم می‌گذارد: آرایه اشیا، متدهای آرایه، تابع پیکانی، DOM، رویداد و فرم. اول نسخه زنده را امتحان کنید، بعد کد را بخوانید.

    ساختار داده

    حالت برنامه (state) در یک آرایه نگه داشته می‌شود و هر بار که تغییر کرد، تابع render فهرست را از نو می‌سازد. قانون مهم این الگو: در این الگو صفحه را جدا از داده عوض نکنید؛ اول آرایه todos را تغییر دهید و بعد render() را صدا بزنید. این‌طوری صفحه همیشه با داده هماهنگ است.

    بخش برنامهمبحثی که استفاده شده
    todos و filterآرایه اشیا (درس ۱ و ۲)
    فیلتر «همه / انجام نشده / انجام شده»filter (درس ۴)
    toggleTodofind برای پیدا کردن کار (درس ۳)
    deleteTodofilter برای حذف (درس ۴)
    ساختن هر ردیفcreateElement و textContent (درس ۱۷)
    افزودن کاررویداد submit و preventDefault (درس ۱۶ و ۱۸)
    دکمه‌های فیلترdataset و classList (درس ۱۵)
    let todos = [
  { id: 1, text: "خواندن درس آرایه‌ها", done: true },
  { id: 2, text: "تمرین map و filter", done: false }
];
let filter = "all";

    هر کار یک شیء با شناسه، متن و وضعیت انجام است. todos فهرست همهٔ کارهاست و filter می‌گوید کدام زیرمجموعه روی صفحه دیده شود. مقدار all یعنی در شروع، هر دو کار نشان داده شوند. این دو متغیر وضعیت برنامه هستند؛ صفحه باید از روی آن‌ها ساخته شود.

    کد کامل

    const form = document.getElementById("todo-form");
const input = document.getElementById("todo-input");
const list = document.getElementById("todo-list");
const count = document.getElementById("todo-count");
const filterButtons = document.querySelectorAll("#filters button");

function render() {
  const visible = todos.filter(t => {
    if (filter === "active") return !t.done;
    if (filter === "done") return t.done;
    return true;
  });

  list.innerHTML = "";
  visible.forEach(todo => {
    const li = document.createElement("li");
    if (todo.done) li.classList.add("done");

    const label = document.createElement("label");
    const checkbox = document.createElement("input");
    checkbox.type = "checkbox";
    checkbox.checked = todo.done;
    checkbox.addEventListener("change", () => toggleTodo(todo.id));

    const span = document.createElement("span");
    span.textContent = todo.text;
    label.append(checkbox, span);

    const del = document.createElement("button");
    del.type = "button";
    del.className = "btn danger";
    del.textContent = "حذف";
    del.addEventListener("click", () => deleteTodo(todo.id));

    li.append(label, del);
    list.append(li);
  });

  if (visible.length === 0) {
    const empty = document.createElement("li");
    empty.textContent = "کاری در این فهرست نیست.";
    list.append(empty);
  }

  const left = todos.filter(t => !t.done).length;
  count.textContent = `${left} کار باقی‌مانده از ${todos.length}`;
}

function addTodo(text) {
  todos.push({ id: Date.now(), text, done: false });
  render();
}

function toggleTodo(id) {
  const todo = todos.find(t => t.id === id);
  todo.done = !todo.done;
  render();
}

function deleteTodo(id) {
  todos = todos.filter(t => t.id !== id);
  render();
}

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const text = input.value.trim();
  if (text === "") return;
  addTodo(text);
  input.value = "";
  input.focus();
});

filterButtons.forEach(btn => {
  btn.addEventListener("click", () => {
    filter = btn.dataset.filter;
    // همه دکمه‌ها کم‌رنگ، فقط دکمه کلیک‌شده رنگ اصلی
    filterButtons.forEach(b => b.classList.add("secondary"));
    btn.classList.remove("secondary");
    render();
  });
});

render();

    render اول با filter تصمیم می‌گیرد کدام کارها دیده شوند، بعد محتوای فهرست را خالی می‌کند و ردیف‌ها را از نو می‌سازد. تغییر چک‌باکس و حذف، مستقیم فقط همان عنصر را به‌روز نمی‌کنند؛ تابع‌های toggleTodo و deleteTodo آرایه را عوض می‌کنند و دوباره render را صدا می‌زنند. افزودن کار هم شیء تازه‌ای با Date.now به‌عنوان شناسه به آرایه اضافه می‌کند. ارسال فرم با preventDefault جلوی بارگذاری صفحه را می‌گیرد و متن خالی را رد می‌کند.

    تمرین‌های تکمیلی

    id: Date.now() تعداد میلی‌ثانیه‌های فعلی را به عنوان شناسه یکتا استفاده می‌کند؛ برای این برنامه ساده کافی است. با id (و نه شماره جای کار در آرایه) کار را پیدا می‌کنیم؛ چون وقتی فیلتر فعال است، شماره‌ها در فهرست نمایش‌داده‌شده با آرایه اصلی فرق دارند.

    اشتباه رایج: عوض کردن ظاهر یک ردیف (مثلاً اضافه کردن کلاس done) بدون تغییر آرایه todos. با اولین render() بعدی، تغییر شما پاک می‌شود؛ چون render همه چیز را از روی آرایه می‌سازد.

    1. دکمه «حذف انجام‌شده‌ها» اضافه کنید که همه کارهای انجام‌شده را پاک کند (راهنما: todos = todos.filter(...) و بعد render()).
    2. با دوبار کلیک (dblclick) روی متن یک کار، بتوان آن را ویرایش کرد (راهنما: prompt("متن جدید:", todo.text)؛ اگر کاربر Cancel زد، null برمی‌گردد و نباید چیزی عوض شود).
    3. اگر متن تکراری بود اضافه نشود و پیام «این کار قبلاً اضافه شده است» زیر فرم نمایش داده شود (راهنما: todos.some(t => t.text === text)).
    4. هنگام ساختن هر کار، ویژگی createdAt: new Date() را هم ذخیره کنید و تاریخ ساخت را با toLocaleDateString("fa-IR") کنار متن نشان دهید.
    5. فهرست را طوری نمایش دهید که کارهای انجام‌نشده بالا و انجام‌شده‌ها پایین باشند (راهنما: todos.slice().sort((a, b) => a.done - b.done)؛ چون true - false برابر ۱ است).

    گام بعدی — ماندگاری: همین Todo با رفرش پاک می‌شود. بلافاصله بعد از این پروژه درس localStorage را بخوانید و آرایه todos را با JSON.stringify / JSON.parse ذخیره کنید. نسخه کلاس: جلسه ۱۳ طرح‌درس.
