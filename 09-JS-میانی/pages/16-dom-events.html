۱۶) DOM: رویدادها به صورت عمیق‌تر

در دوره پایه با addEventListener آشنا شدیم. حالا شیء event و چند تکنیک مهم را می‌بینیم.

ویژگی / متدکار
event.targetعنصری که رویداد واقعاً روی آن رخ داد
event.currentTargetعنصری که listener روی آن نصب شده
event.typeنوع رویداد (click، input، ...)
event.keyحرف یا نام کلید فشرده‌شده، مثل "Enter" یا "a" (به زبان صفحه‌کلید بستگی دارد)
event.codeجای فیزیکی کلید، مثل "KeyA" (مستقل از زبان صفحه‌کلید)
event.clientX / clientYمختصات ماوس
event.preventDefault()جلوگیری از رفتار پیش‌فرض مرورگر
event.stopPropagation()جلوگیری از رسیدن رویداد به پدرها

مثال ۱: مختصات ماوس

const area = document.getElementById("mouse-area");
const coords = document.getElementById("coords");

area.addEventListener("mousemove", (event) => {
  const rect = area.getBoundingClientRect();
  const x = Math.round(event.clientX - rect.left);
  const y = Math.round(event.clientY - rect.top);
  coords.textContent = `x: ${x} , y: ${y}`;
});

رویداد mousemove با هر حرکت ماوس روی ناحیه اجرا می‌شود. clientX و clientY مکان اشاره‌گر را نسبت به پنجره می‌دهند. getBoundingClientRect جای خود ناحیه را نسبت به همان پنجره می‌دهد. کم کردن این دو، مختصات را نسبت به گوشهٔ ناحیه حساب می‌کند و Math.round اعشار پیکسل را به عدد صحیح نزدیک می‌کند.

ماوس را اینجا حرکت دهید
x: 0 , y: 0

clientX/clientY نسبت به گوشه پنجره مرورگر است؛ با کم کردن rect.left و rect.top (موقعیت جعبه) مختصات را نسبت به خود جعبه به دست می‌آوریم.

مثال ۲: preventDefault — جلوی رفتن لینک را بگیر

const link = document.getElementById("stop-link");
const linkMsg = document.getElementById("link-msg");

link.addEventListener("click", (event) => {
  event.preventDefault();
  linkMsg.textContent = "لینک باز نشد؛ preventDefault جلویش را گرفت.";
});
این لینک به مستندات MDN می‌رود (ولی...)

کاربرد واقعی preventDefault: جلوگیری از ارسال فرم و بارگذاری دوباره صفحه تا اول داده‌ها را با JavaScript بررسی کنیم (درس ۱۸)، یا باز کردن یک پنجره تأیید قبل از رفتن به لینک.

مثال ۳: میان‌بر صفحه‌کلید

const searchBox = document.getElementById("search-box");
const shortcutMsg = document.getElementById("shortcut-msg");

document.addEventListener("keydown", (event) => {
  if (event.ctrlKey && event.code === "KeyK") {
    event.preventDefault();        // جلوی رفتار پیش‌فرض مرورگر
    searchBox.focus();
    shortcutMsg.textContent = "میان‌بر Ctrl + K اجرا شد!";
  }
});

event.key «حرفی» است که تایپ می‌شود و به زبان صفحه‌کلید بستگی دارد: اگر صفحه‌کلید فارسی باشد، با زدن کلید K مقدار event.key برابر "ن" است! event.code «جای فیزیکی کلید» است ("KeyK") و به زبان بستگی ندارد؛ برای میان‌برها از code استفاده کنید.

مثال ۴: یک بار اجرا و حذف listener

const onceBtn = document.getElementById("once-btn");
const onceMsg = document.getElementById("once-msg");
const hiBtn = document.getElementById("hi-btn");
const offBtn = document.getElementById("off-btn");
const hiMsg = document.getElementById("hi-msg");

onceBtn.addEventListener("click", () => {
  onceMsg.textContent = "فقط یک بار اجرا می‌شوم!";
}, { once: true });

function sayHi() { hiMsg.textContent += "سلام! "; }
hiBtn.addEventListener("click", sayHi);
offBtn.addEventListener("click", () => {
  hiBtn.removeEventListener("click", sayHi);   // برای حذف باید همان تابع با اسم باشد
  hiMsg.textContent += "(listener حذف شد) ";
});

مثال ۵: بالا رفتن رویداد (Bubbling) و واگذاری رویداد (Event Delegation)

وقتی روی یک عنصر کلیک می‌شود، رویداد اول روی خود آن عنصر اجرا می‌شود و بعد به ترتیب به پدر، پدربزرگ و ... تا document «بالا می‌رود» (Bubbling). به کمک همین رفتار، به جای اینکه روی تک‌تک دکمه‌ها listener بگذاریم، یک listener روی پدرشان می‌گذاریم و با event.target می‌فهمیم روی کدام کلیک شده. این روش برای عنصرهایی که بعداً با JavaScript اضافه می‌شوند هم کار می‌کند.

const productList = document.getElementById("product-list");
const cartInfo = document.getElementById("cart-info");
let cartCount = 0;

productList.addEventListener("click", (event) => {
  const button = event.target.closest("button");   // روی دکمه (یا داخل آن) کلیک شده؟
  if (!button || button.disabled) return;           // کلیک روی جای دیگر یا دکمه قبلاً زده‌شده

  cartCount++;
  button.disabled = true;
  button.textContent = "در سبد ✔";
  cartInfo.textContent = `${cartCount} کالا در سبد (آخرین: ${button.dataset.name})`;
});

سبد خرید خالی است.

event.target عنصری است که واقعاً کلیک شده (ممکن است یک span داخل دکمه باشد)؛ برای همین با closest("button") نزدیک‌ترین دکمه را پیدا می‌کنیم. event.currentTarget اینجا همیشه خود ul است. اگر جایی نخواستید رویداد به پدرها برسد، event.stopPropagation() را صدا بزنید (ولی بی‌دلیل از آن استفاده نکنید).

رویدادهای پرکاربرد دیگر

رویدادتوضیح

submitارسال فرم (درس فرم‌ها)
scrollاسکرول صفحه یا عنصر
resizeتغییر اندازه پنجره (روی window)

اشتباه رایج: استفاده از removeEventListener برای تابع بی‌نام. چون هر تابع بی‌نام یک تابع جدید است، حذف نمی‌شود؛ تابع را در یک متغیر یا با اسم تعریف کنید.

اشتباه رایج: صدا زدن تابع به جای دادن آن: btn.addEventListener("click", sayHi()). با پرانتز، sayHi همان لحظه اجرا می‌شود و خروجی آن (undefined) به عنوان listener داده می‌شود. درستش btn.addEventListener("click", sayHi) است.

تمرین ۱: با رویداد keydown روی document یک «جعبه متحرک» بسازید که با کلیدهای جهت‌دار (ArrowLeft، ArrowRight، ArrowUp، ArrowDown) هر بار ۱۰ پیکسل جابه‌جا شود. راهنما: دو متغیر x و y نگه دارید و با box.style.transform = `translate(${x}px, ${y}px)` جابه‌جا کنید؛ برای جلوگیری از اسکرول صفحه preventDefault() را صدا بزنید.

تمرین ۲: یک فهرست کارها با سه li بسازید که هر کدام دکمه «حذف» دارند. فقط با یک listener روی ul (Event Delegation) کاری کنید که کلیک روی هر دکمه، همان li را حذف کند (راهنما: event.target.closest("li").remove()).
