۶) ریاضی و عدد تصادفی (Math & Random)

شیء Math مجموعه‌ای از تابع‌ها و عددهای ریاضی آماده است. لازم نیست آن را با new بسازید؛ متدها را مستقیم روی خود Math صدا می‌زنید. از گرد کردن و جذر تا ساختن عدد تصادفی برای بازی یا نمونه، این شیء همان کاری را می‌کند که اگر بخواهید خودتان با حلقه بنویسید طولانی و خطاپذیر است. عدد تصادفی این شیء برای آموزش و بازی مناسب است، نه برای رمز و توکن امنیتی.

// تعداد صفحه‌های لازم برای ۴۳ محصول، ۱۰ تا در هر صفحه

round به نزدیک‌ترین عدد صحیح می‌رود، floor به سمت پایین و ceil به سمت بالا. sqrt جذر می‌گیرد و abs علامت منفی را برمی‌دارد. max و min بین عددهایی که جدا جدا به آن‌ها می‌دهید بزرگ‌ترین و کوچک‌ترین را برمی‌گردانند؛ اگر همان عددها داخل یک آرایه باشند، این دو متد خودبه‌خود عضوهای آرایه را یکی‌یکی نمی‌خوانند. toFixed مساحت را برای نمایش گرد می‌کند ولی رشته برمی‌گرداند. گرد کردن قیمت، عدد را به هزار تقسیم می‌کند، گرد می‌کند و دوباره در هزار ضرب می‌کند. ceil برای تعداد صفحه لازم است تا باقیماندهٔ کمتر از یک صفحه هم یک صفحهٔ کامل حساب شود.



Math.round نیمه را به سمت بالا (به سمت مثبت بی‌نهایت) گرد می‌کند: Math.round(4.5) می‌شود 5 ولی Math.round(-4.5) می‌شود -4. Math.floor و Math.trunc هم برای عددهای منفی فرق دارند: Math.floor(-4.7) برابر -5 و Math.trunc(-4.7) برابر -4 است.



عدد صحیح تصادفی در یک بازه



// عدد تصادفی صحیح بین min و max (هر دو شامل)
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

console.log(randomInt(1, 6));     // تاس
console.log(randomInt(1, 100));










Math.random عددی اعشاری از صفر تا کمتر از یک می‌دهد. ضرب در max - min + 1 این بازه را به اندازهٔ تعداد عددهای صحیح مطلوب کش می‌دهد. floor اعشار را حذف می‌کند تا به عدد صحیح برسید و جمع با min بازه را از نقطهٔ شروع جابه‌جا می‌کند. + 1 داخل پرانتز باعث می‌شود خود max هم شانس برابر داشته باشد. بدون آن، سقف بازه هرگز دیده نمی‌شود.



فرمول را حفظ کنید: Math.floor(Math.random() * تعداد) + شروع. مثلاً برای ۱ تا ۱۰: Math.floor(Math.random() * 10) + 1. چرا؟ Math.random() * 10 عددی از ۰ تا کمتر از ۱۰ است، Math.floor آن را به یکی از ۰ تا ۹ تبدیل می‌کند و + 1 بازه را به ۱ تا ۱۰ می‌برد.



خروجی این بخش با هر بار بارگذاری صفحه (F5) عوض می‌شود؛ چون تصادفی است.



مثال زنده: تاس و انتخاب تصادفی



const faces = ["⚀", "⚁", "⚂", "⚃", "⚄", "⚅"];

diceBtn.addEventListener("click", function () {
  const n = randomInt(1, 6);
  dice.textContent = faces[n - 1] + " " + n;   // شماره عضو آرایه از 0 است
});

quoteBtn.addEventListener("click", function () {
  const i = randomInt(0, quotes.length - 1);   // عضو تصادفی آرایه
  quote.textContent = quotes[i];
});

برای دیدن یک جمله تصادفی کلیک کنید






تاس عددی از ۱ تا ۶ می‌سازد. چون شمارهٔ آرایه از صفر است، برای رسیدن به شکل همان وجه باید یکی از عدد کم شود. انتخاب جمله از شمارهٔ ۰ شروع می‌شود و تا length - 1 ادامه دارد تا هم عضو اول شانس داشته باشد و هم از انتهای آرایه بیرون نزند. هر کلیک یک عدد تازه می‌سازد؛ مقدار قبلی ذخیره نمی‌شود.



اشتباه رایج: استفاده از Math.round برای عدد تصادفی. در این حالت احتمال آمدن عدد اول و آخر نصف بقیه است؛ همیشه از Math.floor استفاده کنید.



اشتباه رایج: استفاده از toFixed و بعد جمع زدن نتیجه: (2.5).toFixed(1) + 1 می‌شود "2.51"؛ چون toFixed رشته برمی‌گرداند. اگر عدد لازم دارید، با Number(...) تبدیل کنید.



تمرین: یک «کدساز تخفیف» بسازید: با کلیک روی دکمه، یک کد ۸ کاراکتری تصادفی از حروف رشته "ABCDEFGHJKLMNPQRSTUVWXYZ23456789" بسازد (راهنما: یک حلقه ۸ بار، و در هر بار chars[randomInt(0, chars.length - 1)]) و همراه یک درصد تخفیف تصادفی بین ۵ تا ۳۰ نشان دهد.



Math.random() برای بازی و نمونه‌های آموزشی مناسب است، ولی امن نیست و قابل پیش‌بینی است. برای ساختن رمز عبور یا توکن واقعی از crypto.getRandomValues() یا crypto.randomUUID() استفاده می‌شود.
