## صورت مسئله

کانون فرهنگی محله برای روز کودک یک «گوشه بازی» روی تبلت راه می‌اندازد. اولین بازی، سنگ، کاغذ، قیچی است:
کودک یکی از سه دکمه را می‌زند، کامپیوتر هم تصادفی انتخاب می‌کند، و هر کس زودتر به ۵ امتیاز برسد برنده است.

**قانون بازی:** سنگ قیچی را می‌شکند، قیچی کاغذ را می‌بُرد، کاغذ سنگ را می‌پوشاند؛ انتخاب یکسان مساوی است.

## الزامات

1. سه فایل `index.html`، `style.css` و `app.js`؛ صفحه با `lang="fa"` و `dir="rtl"`.
2. سه دکمه «سنگ»، «کاغذ»، «قیچی» و یک دکمه «بازی جدید». هر دکمه با `addEventListener` به تابع `playRound` وصل شود.
3. تابع `randomChoice()` عدد تصادفی را (با خط آماده پایین) با **`switch`** به `"rock"`، `"paper"` یا `"scissors"` تبدیل کند.
4. تابع `choiceName(choice)` با **`switch`** نام فارسی و ایموجی هر انتخاب را برگرداند.
5. تابع `getResult(player, computer)` فقط یکی از سه رشته `"win"`، `"lose"` یا `"draw"` را برگرداند (با `if` و `===`).
6. بعد از هر دست نمایش داده شود: انتخاب هر دو طرف، نتیجه دست (برد سبز، باخت قرمز، مساوی نارنجی با `classList`) و تابلوی امتیاز «شما: n — کامپیوتر: m — مساوی: k» با **Template Literal**.
7. امتیازها با `let` **بیرون** از تابع‌ها نگه داشته شوند. وقتی یک طرف به ۵ رسید، پیام پایان («تبریک! بازی را ۵ به ۳ بردی 🏆» یا پیام باخت) نشان داده شود و سه دکمه انتخاب **غیرفعال** شوند.
8. «بازی جدید» همه امتیازها و پیام‌ها را پاک کند و دکمه‌ها را دوباره فعال کند.
9. ناحیه نتیجه `aria-live="polite"` داشته باشد.

**خط آماده عدد تصادفی** (کپی کنید): `const number = Math.floor(Math.random() * 3);` ← یکی از ۰، ۱ یا ۲.
**غیرفعال کردن دکمه:** `rockBtn.disabled = true;` (و برای فعال کردن `false`).

## تست‌ها

تابع‌ها را می‌توانید مستقیم در Console صدا بزنید:

| ورودی | خروجی مورد انتظار |
| --- | --- |
| `getResult("rock", "scissors")` | `"win"` |
| `getResult("paper", "rock")` | `"win"` |
| `getResult("scissors", "paper")` | `"win"` |
| `getResult("rock", "paper")` | `"lose"` |
| `getResult("scissors", "rock")` | `"lose"` |
| `getResult("paper", "paper")` | `"draw"` |
| `choiceName("scissors")` | `"قیچی ✌️"` |
| ۲۰ بار صدا زدن `randomChoice()` | هر سه مقدار دیده شوند و هیچ مقدار دیگری نیاید |
| کلیک «سنگ» وقتی کامپیوتر قیچی آورده | «این دست را بردی! 🎉» سبز و امتیاز شما یکی بیشتر |
| رسیدن یکی به ۵ | پیام پایان + سه دکمه خاکستری و غیرقابل کلیک |
| «بازی جدید» | `شما: 0 — کامپیوتر: 0 — مساوی: 0` و دکمه‌ها فعال |

**نکته تست:** برای امتحان یک حالت خاص، موقتاً داخل `randomChoice` بنویسید `return "scissors";` و بعد از تست پاکش کنید.

## محدودیت‌ها

- `onclick` داخل HTML، `alert` و `var` ممنوع.
- منطق برد و باخت فقط **یک جا** (در `getResult`) نوشته شود؛ نه سه بار در سه رویداد کلیک.
- `innerHTML` ممنوع؛ همه متن‌ها با `textContent`.
- رنگ‌ها فقط با کلاس CSS و `classList`، نه با `style`.

## امتیازی (تا ۲ نمره)

- کلیدهای `1`، `2` و `3` صفحه‌کلید هم سنگ، کاغذ و قیچی را انتخاب کنند (رویداد `keydown` روی `document` و `event.key`). وقتی بازی تمام شده، کلیدها هم کار نکنند.
- شمارنده «دست شماره n» را نمایش دهید.

## نکته استاد

- اگر `let playerScore = 0` را داخل `playRound` بنویسید، امتیاز هیچ‌وقت از ۱ بالاتر نمی‌رود.
- `getResult` را اول در Console با جدول تست بالا امتحان کنید، **بعد** به دکمه‌ها وصلش کنید؛ پیدا کردن باگ خیلی ساده‌تر می‌شود.
- در `switch` برای نتیجه، `break` را فراموش نکنید؛ وگرنه با هر برد، باخت هم حساب می‌شود!
