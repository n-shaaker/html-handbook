۹) اشیا (Objects)

شیء (Object) چند مقدار مرتبط را با «اسم» کنار هم نگه می‌دارد. هر جفت کلید: مقدار یک ویژگی (property) است. وقتی اطلاعات یک چیز واقعی — مثل یک دانش‌آموز یا یک کالا — چند تکه دارد، به‌جای ساختن متغیرهای جدا و بی‌ربط، آن‌ها را در یک شیء جمع می‌کنید تا معلوم باشد همه متعلق به همان چیز هستند.

const student = {
  firstName: "سارا",
  lastName: "احمدی",
  age: 20,
  isActive: true
};

console.log(student.firstName);     // سارا ← دسترسی با نقطه
console.log(student["age"]);        // 20   ← دسترسی با براکت (اسم ویژگی داخل گیومه)
console.log(student.grade);         // undefined ← ویژگی‌ای که وجود ندارد خطا نمی‌دهد





آکولاد شیء را می‌سازد و هر ویژگی با کاما از ویژگی بعدی جدا می‌شود. student.firstName مقدار ویژگی firstName را می‌خواند. شکل student["age"] همان کار را با براکت انجام می‌دهد و نام ویژگی را به‌صورت متن می‌گیرد. اگر ویژگی‌ای وجود نداشته باشد، JavaScript خطا نمی‌دهد و undefined برمی‌گرداند.



تغییر، اضافه و حذف ویژگی



student.age = 21;               // تغییر
student.city = "تهران";         // اضافه
delete student.isActive;        // حذف
console.log(student);










دادن مقدار تازه به یک ویژگی موجود، همان ویژگی را عوض می‌کند. اگر نام ویژگی از قبل نباشد، با همان شکل نوشتن به شیء اضافه می‌شود. delete ویژگی را از شیء برمی‌دارد. خود متغیر student همچنان به همان شیء اشاره می‌کند؛ فقط محتوای داخل شیء عوض شده است.



Console واقعی مرورگر شیء را به شکل {firstName: 'سارا', lastName: 'احمدی', age: 21, city: 'تهران'} نشان می‌دهد؛ جعبه Console این صفحه آن را به شکل JSON (با گیومه دور کلیدها) می‌نویسد. محتوا یکی است.



با اینکه student با const ساخته شده، می‌توانیم داخلش را تغییر دهیم. const فقط اجازه نمی‌دهد کل متغیر را با یک شیء دیگر عوض کنیم.



متد: تابعی که داخل شیء است



const person = {
  firstName: "علی",
  lastName: "رضایی",
  fullName: function () {
    return this.firstName + " " + this.lastName;   // this یعنی «همین شیء»
  }
};

console.log(person.fullName());     // علی رضایی










وقتی مقدار یک ویژگی تابع باشد، به آن متد می‌گوییم. this داخل متد معمولی به همان شیئی اشاره می‌کند که متد از روی آن صدا زده شده؛ پس this.firstName یعنی ویژگی firstName خود person. پرانتز در person.fullName() متد را اجرا می‌کند. بدون پرانتز خود تابع برمی‌گردد و متن نام ساخته نمی‌شود.



مثال کاربردی: یک قلم از سبد خرید



const cartItem = {
  title: "هدفون بی‌سیم",
  price: 1200000,
  quantity: 2,
  total: function () {
    return this.price * this.quantity;
  }
};

console.log(`${cartItem.title}: ${cartItem.total()} تومان`);   // هدفون بی‌سیم: 2400000 تومان
cartItem.quantity = 3;                                          // کاربر یکی دیگر اضافه کرد
console.log(`${cartItem.title}: ${cartItem.total()} تومان`);   // هدفون بی‌سیم: 3600000 تومان










متد total هر بار قیمت و تعداد فعلی را در هم ضرب می‌کند و نتیجه را برمی‌گرداند. چون محاسبه داخل متد است، بعد از عوض کردن quantity لازم نیست قیمت کل را دستی دوباره بنویسید؛ کافی است total() را یک بار دیگر صدا بزنید. بک‌تیک و ${...} مقدار را وسط متن می‌گذارند.



در کد بالا از بک‌تیک و ${...} استفاده شده تا مقدارها داخل متن قرار بگیرند. این روش (Template Literal) را در درس ۱۳ کامل یاد می‌گیرید؛ فعلاً کافی است بدانید ${cartItem.title} مقدار ویژگی را داخل متن می‌گذارد.



چه موقع براکت لازم است؟



const key = "lastName";
console.log(person[key]);        // رضایی ← وقتی اسم ویژگی داخل متغیر است
console.log(person.key);         // undefined ← دنبال ویژگی به اسم key می‌گردد

const product = { "unit-price": 50000 };   // اسم ویژگی خط تیره دارد
console.log(product["unit-price"]);        // 50000 ← فقط با براکت می‌شود










نقطه فقط وقتی کار می‌کند که نام ویژگی را همان‌جا در کد بنویسید. اگر نام داخل یک متغیر باشد، باید از براکت استفاده کنید تا مقدار آن متغیر به‌عنوان نام ویژگی خوانده شود. person.key دنبال ویژگی‌ای به نام واقعی key می‌گردد و چون چنین ویژگی‌ای نیست، undefined می‌دهد. نام‌هایی که خط تیره یا فاصله دارند هم با نقطه قابل نوشتن نیستند و فقط با براکت خوانده می‌شوند.



اشتباه رایج: فراموش کردن پرانتز موقع صدا زدن متد: person.fullName خود تابع است و person.fullName() نتیجه آن.



اشتباه رایج: فراموش کردن this داخل متد: نوشتن return firstName + " " + lastName; خطای firstName is not defined می‌دهد، چون ویژگی‌های شیء متغیر جداگانه نیستند.



تمرین: یک شیء book با ویژگی‌های title، author و price بسازید و متد info() به آن بدهید که متنی مثل «شازده کوچولو اثر اگزوپری» برگرداند. سپس ویژگی price را ۲۰٪ گران‌تر کنید (book.price *= 1.2 یا book.price += book.price * 20 / 100) و قیمت جدید را چاپ کنید.
