۴) ساختار نوشتن و توضیحات (Syntax & Comments)

برنامهٔ JavaScript مجموعه‌ای از دستورها (Statements) است. مرورگر آن‌ها را یکی‌یکی و از بالا به پایین می‌خواند و اجرا می‌کند. هر دستور یک کار مشخص انجام می‌دهد: ساختن یک متغیر، محاسبه، یا نشان دادن نتیجه. اگر ترتیب را عوض کنید، نتیجه هم عوض می‌شود، چون هر خط به مقدارهایی تکیه دارد که خط‌های قبلی ساخته‌اند.

let price = 85000;            // دستور ۱: قیمت یک دفتر (تومان)
let count = 3;                // دستور ۲: تعداد
let total = price * count;    // دستور ۳: قیمت کل
console.log(total);           // دستور ۴  →  255000





خط اول با let جعبه‌ای به نام price می‌سازد و عدد ۸۵۰۰۰ را در آن می‌گذارد. خط دوم تعداد را نگه می‌دارد. خط سوم از عملگر * استفاده می‌کند تا قیمت را در تعداد ضرب کند و حاصل را در total ذخیره کند. console.log همان حاصل را در Console نشان می‌دهد. متن‌هایی که با // شروع شده‌اند توضیح هستند و اجرا نمی‌شوند.

مقدار ثابت (Literal) و متغیر (Variable)



10.5          // عدد
"سارا"        // متن (رشته)
let age = 20; // age یک متغیر است که مقدار 20 را نگه می‌دارد



مقدار ثابتی که مستقیم در کد نوشته می‌شود لیترال نام دارد؛ مثل عدد 10.5 یا متن "سارا". متغیر اسمی است که به یک مقدار اشاره می‌کند تا بعداً بتوانیم همان مقدار را با آن اسم بخوانیم یا عوض کنیم. در خط سوم، 20 لیترال است و age متغیر.



نام‌گذاری camelCase



در JavaScript رسم است نام‌های چندکلمه‌ای را به شکل camelCase بنویسیم: کلمه اول با حرف کوچک، بقیه با حرف بزرگ.



let firstName = "علی";      // ✔ camelCase
let first_name = "علی";     // کار می‌کند ولی رسم JS نیست
let first-name = "علی";     // ✖ خطا! خط تیره مجاز نیست



در firstName کلمهٔ اول با حرف کوچک شروع می‌شود و هر کلمهٔ بعدی با حرف بزرگ. این شکل را camelCase می‌نامند و در JavaScript رسم رایج است. خط تیره در نام متغیر مجاز نیست، چون مرورگر آن را علامت تفریق می‌خواند و کد را خراب می‌بیند. زیرخط (first_name) از نظر دستوری درست است، ولی در این زبان کمتر برای نام متغیر به کار می‌رود.



توضیحات (Comments)



توضیح‌ها اجرا نمی‌شوند و برای یادداشت یا غیرفعال کردن موقت کد هستند.



// توضیح یک‌خطی

/*
  توضیح
  چندخطی
*/

let price = 100; // توضیح در انتهای خط
// console.log("این خط اجرا نمی‌شود");
console.log("قیمت:", price);










هر چه بعد از // تا پایان همان خط باشد اجرا نمی‌شود. بلوک بین /* و */ می‌تواند چند خط را توضیح کند. اگر یک دستور را با // غیرفعال کنید، آن خط موقتاً از برنامه خارج می‌شود و بقیهٔ دستورها همچنان اجرا می‌شوند. توضیح برای انسان است، نه برای مرورگر.



در VS Code با Ctrl + / خط انتخاب‌شده توضیح (کامنت) می‌شود و دوباره از حالت توضیح خارج می‌شود.



اشتباه رایج: نوشتن Console.log یا console.Log. چون JavaScript به حروف بزرگ و کوچک حساس است، فقط console.log درست است.



تمرین: سه دستور بنویسید: متغیر width (عرض اتاق) با مقدار ۴، متغیر length (طول اتاق) با مقدار ۵، و چاپ مساحت اتاق (حاصل‌ضرب آن‌ها) در Console. بالای هر خط یک توضیح فارسی بنویسید.
