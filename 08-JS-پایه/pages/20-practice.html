۲۰) تمرین جمع‌بندی

این صفحه درس تازه نیست؛ جایی است که ابزارهای دوره را کنار هم به کار می‌برید. اول یک نمونهٔ حل‌شده را خط‌به‌خط می‌خوانید تا ببینید متغیر، تابع، تبدیل عدد، شرط و رویداد چطور در یک کار واقعی به هم وصل می‌شوند. بعد تمرین‌ها را خودتان می‌نویسید. اگر جایی گیر کردید، به درس همان موضوع برگردید و همان مفهوم را دوباره با مثال خودش بخوانید.

نمونه حل‌شده: محاسبه شاخص توده بدنی (BMI)

این مثال تقریباً همه مباحث این دوره را با هم دارد: متغیر، تابع، عدد، شرط، رویداد و Template Literal.

فرمول: وزن (کیلوگرم) تقسیم بر مجذور قد (متر). مثلاً برای ۶۵ کیلو و ۱۷۰ سانتی‌متر: 65 / (1.7 ** 2) که حدود ۲۲٫۵ می‌شود.

<!-- HTML -->
<label for="weight">وزن (کیلوگرم):</label>
<input type="number" id="weight">
<label for="height">قد (سانتی‌متر):</label>
<input type="number" id="height">
<button id="bmi-btn">محاسبه</button>
<p id="bmi-result"></p>

هر کادر یک label دارد که با for به id همان کادر وصل است، تا هم کلیک روی برچسب کادر را فعال کند و هم معنی فیلد برای خواننده روشن باشد. دکمه و پاراگراف نتیجه هم شناسه دارند تا JavaScript همان عنصرها را پیدا کند. واحد وزن کیلوگرم است و قد سانتی‌متر؛ تبدیل قد به متر داخل تابع انجام می‌شود.

// js/app.js
const weightInput = document.getElementById("weight");
const heightInput = document.getElementById("height");
const bmiBtn = document.getElementById("bmi-btn");
const bmiResult = document.getElementById("bmi-result");

function calculateBMI(weight, heightCm) {
  const heightM = heightCm / 100;
  return weight / (heightM ** 2);
}

function getStatus(bmi) {
  if (bmi < 18.5) {
    return "کمبود وزن";
  } else if (bmi < 25) {
    return "وزن طبیعی";
  } else if (bmi < 30) {
    return "اضافه وزن";
  } else {
    return "چاقی";
  }
}

bmiBtn.addEventListener("click", function () {
  const weight = Number(weightInput.value);
  const height = Number(heightInput.value);

  if (weight <= 0 || height <= 0) {
    bmiResult.textContent = "لطفاً وزن و قد را درست وارد کنید.";
    return;   // ادامه نده؛ تابع همین‌جا تمام می‌شود
  }

  const bmi = calculateBMI(weight, height);
  bmiResult.textContent = `BMI شما ${bmi.toFixed(1)} است: ${getStatus(bmi)}`;
});

دو تابع کار محاسبه را از کار نمایش جدا کرده‌اند. calculateBMI قد را از سانتی‌متر به متر تبدیل می‌کند و وزن را بر مجذور قد تقسیم می‌کند. getStatus فقط عدد شاخص را می‌گیرد و با چند بازه یکی از چهار برچسب را برمی‌گرداند. با کلیک، هر دو کادر به عدد تبدیل می‌شوند. اگر وزن یا قد صفر یا منفی باشد، پیام خطا نوشته می‌شود و return جلوی محاسبه را می‌گیرد. در غیر این صورت شاخص تا یک رقم اعشار و وضعیت کنار هم در صفحه قرار می‌گیرند.

کادر خالی با Number("") صفر می‌شود، پس شرط <= 0 آن را هم می‌گیرد. return بدون مقدار هم یعنی «از تابع بیرون برو»؛ این‌طوری لازم نیست بقیه کد را داخل else بنویسیم.

تمرین‌ها (به ترتیب سختی)

  1. معرفی: متغیرهای نام، سال تولد شمسی و شهر بسازید، سن را حساب کنید (سال جاری: ۱۴۰۵) و با Template Literal یک جمله معرفی مثل «من سارا هستم، ۲۵ ساله، از شیراز» داخل یک پاراگراف صفحه بنویسید.
  2. زوج یا فرد: یک input و دکمه بسازید که بگوید عدد وارد شده زوج است یا فرد (با %). اگر کادر خالی بود، پیام «یک عدد وارد کنید» نشان دهد.
  3. تبدیل دما: یک input و دو دکمه بسازید: «سانتی‌گراد به فارنهایت» (c * 9 / 5 + 32) و «فارنهایت به سانتی‌گراد» ((f - 32) * 5 / 9). هر تبدیل را در یک تابع جدا بنویسید و نتیجه را با یک رقم اعشار (toFixed(1)) نشان دهید.
  4. بزرگ‌ترین عدد: سه input بگیرید و فقط با if و && (بدون Math.max) بزرگ‌ترین عدد را نشان دهید. فراموش نکنید مقدارها را با Number() تبدیل کنید.
  5. ماشین‌حساب: دو input و یک select با گزینه‌های + - × ÷ بسازید و با switch نتیجه را حساب کنید. تقسیم بر صفر را با پیام خطا مدیریت کنید.
  6. شمارش معکوس: با حلقه for (با گام i--) اعداد ۱۰ تا ۱ را به صورت <li> داخل یک ul بسازید و آخرش بنویسید «پرتاب! 🚀».
  7. قدرت رمز عبور: با رویداد input رمز را بررسی کنید: کمتر از ۶ حرف «ضعیف»، ۶ تا ۱۰ حرف «متوسط» و بیشتر از ۱۰ حرف «قوی». امتیازی: اگر رمز حداقل یک رقم دارد (با حلقه و "0123456789".includes(...) مثل درس ۱۹) یک سطح بالاتر ببرید. رنگ پیام را با classList و کلاس‌های msg-error و msg-ok عوض کنید.
  8. فرم ورود ساده: دو input برای نام کاربری و رمز و یک دکمه «ورود» بسازید. اگر یکی خالی بود «همه فیلدها را پر کنید»، اگر نام کاربری admin و رمز 1234 بود «خوش آمدید»، وگرنه «نام کاربری یا رمز اشتباه است» نشان دهید (فاصله‌های اضافه را با trim() حذف کنید).
  9. حدس عدد: برنامه یک عدد تصادفی بین ۱ تا ۱۰۰ انتخاب کند (این خط آماده را کپی کنید: const secret = Math.floor(Math.random() * 100) + 1;) و کاربر با input حدس بزند؛ پیام «بزرگ‌تر»، «کوچک‌تر» یا «درست!» بدهد و تعداد تلاش‌ها را بشمارد (راهنما: شمارنده را با let بیرون از تابع رویداد تعریف کنید تا با هر کلیک صفر نشود).

قبل از کد زدن، مراحل را به فارسی روی کاغذ بنویسید: «۱. مقدار input را بگیر ۲. به عدد تبدیل کن ۳. اگر ... بود ...». به این کار شبه‌کد می‌گویند.

بعد از این دوره: آرایه‌ها، کار با DOM، فرم‌ها و ... در دوره JavaScript سطح میانی ادامه پیدا می‌کند.
