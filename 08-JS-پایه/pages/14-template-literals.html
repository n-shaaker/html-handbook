۱۴) رشته‌های قالبی (Template Literals)

وقتی چند متغیر را با علامت + به یک جمله می‌چسبانید، گیومه‌ها و فاصله‌ها زود شلوغ می‌شوند. رشتهٔ قالبی این کار را خواناتر می‌کند. متن را داخل بک‌تیک می‌نویسید؛ بک‌تیک کلیدی است بالای Tab و کنار عدد ۱ در صفحه‌کلید انگلیسی. هر جا مقدار یک متغیر یا نتیجهٔ یک محاسبه لازم باشد، آن را داخل ${...} می‌گذارید و JavaScript قبل از ساختن متن نهایی، آن بخش را حساب می‌کند.

let name = "سارا";
let age = 20;

// روش قدیمی
console.log("سلام " + name + "، تو " + age + " سال داری.");

// با Template Literal
console.log(`سلام ${name}، تو ${age} سال داری.`);





هر دو خط همان جمله را می‌سازند. در روش قدیمی باید متن‌های ثابت و متغیرها را با + به هم وصل کنید و فاصله‌ها را خودتان داخل گیومه بگذارید. در روش قالبی، جمله به همان شکلی که خوانده می‌شود نوشته می‌شود و فقط جاهای متغیر داخل ${ } هستند. اگر بک‌تیک را با گیومه عوض کنید، ${name} دیگر محاسبه نمی‌شود و عین همان نویسه‌ها چاپ می‌شود.



عبارت داخل ${ }



let price = 120000;
let count = 3;
console.log(`جمع کل: ${price * count} تومان`);        // جمع کل: 360000 تومان
console.log(`سال آینده ${age + 1} ساله می‌شوی.`);      // سال آینده 21 ساله می‌شوی.
console.log(`نام بزرگ: ${"sara".toUpperCase()}`);     // نام بزرگ: SARA
console.log(`وضعیت: ${age >= 18 ? "بزرگسال" : "نوجوان"}`);   // وضعیت: بزرگسال



داخل ${ } هر عبارتی که یک مقدار بسازد مجاز است: متغیر، محاسبه، صدا زدن تابع یا متد. خط آخر از عملگر سه‌تایی (? :) استفاده کرده که در درس ۱۶ کامل توضیح داده می‌شود: «اگر شرط درست بود اولی، وگرنه دومی».










داخل ${ } فقط نام متغیر نمی‌آید؛ هر عبارتی که یک مقدار بسازد مجاز است. در خط اول قیمت در تعداد ضرب می‌شود و حاصل وسط جمله قرار می‌گیرد. age + 1 از متغیر درس قبلی استفاده می‌کند و سال بعد را حساب می‌کند. toUpperCase هم می‌تواند همان‌جا صدا زده شود. خط آخر بین دو متن یکی را انتخاب می‌کند: اگر سن حداقل ۱۸ باشد «بزرگسال» و در غیر این صورت «نوجوان».



متن چندخطی



let poem = `بنی آدم اعضای یکدیگرند
که در آفرینش ز یک گوهرند`;
console.log(poem);










داخل بک‌تیک، رفتن به خط بعد واقعاً بخشی از رشته است. با گیومهٔ معمولی، شکستن خط در وسط متن خطای نحوی می‌دهد، مگر اینکه هر خط را جدا بنویسید و به هم بچسبانید. فاصله‌ها و تورفتگی داخل بک‌تیک هم در متن نهایی حفظ می‌شوند.



مثال کاربردی: ساختن کارت



const makeBtn = document.getElementById("card-btn");
const nameInput = document.getElementById("card-name");
const jobInput = document.getElementById("card-job");
const cardTitle = document.getElementById("card-title");
const cardText = document.getElementById("card-text");

makeBtn.addEventListener("click", function () {
  cardTitle.textContent = nameInput.value;
  cardText.textContent = `شغل: ${jobInput.value}`;
});











  
نام

  
شغل: ...





با کلیک، متن کادر نام مستقیم در عنوان کارت نوشته می‌شود. خط شغل از رشتهٔ قالبی استفاده می‌کند تا برچسب «شغل:» و مقدار کادر در یک متن جمع شوند. هر دو مقدار با textContent وارد صفحه می‌شوند، پس اگر کاربر به‌جای نام یک تگ HTML بنویسد، آن تگ اجرا نمی‌شود و فقط به‌صورت متن دیده می‌شود.





نکته امنیتی: متنی که کاربر تایپ کرده را با textContent نشان دادیم، نه innerHTML. همان‌طور که در درس ۳ گفتیم، اگر کاربر به جای اسم تگ HTML یا کد مخرب بنویسد، innerHTML آن را اجرا می‌کند (XSS).



اشتباه رایج: استفاده از گیومه معمولی به جای بک‌تیک: "سلام ${name}" عیناً همان ${name} را چاپ می‌کند.



تمرین: با Template Literal یک رسید خرید بسازید: نام کالا، تعداد، قیمت واحد، قیمت کل (حاصل‌ضرب)، ۱۰٪ مالیات و مبلغ نهایی را در یک متن چندخطی چاپ کنید. همه محاسبه‌ها را داخل ${ } انجام دهید.
