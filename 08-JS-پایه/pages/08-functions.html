۸) توابع (Functions)

تابع یک بلوک کد با اسم است که یک بار نوشته می‌شود و هر چند بار لازم باشد صدا زده می‌شود. وقتی یک محاسبه یا یک جمله را در چند جای برنامه لازم دارید، به‌جای کپی کردن همان خط‌ها، آن‌ها را داخل تابع می‌گذارید و فقط نام تابع را صدا می‌زنید. ورودی تابع داده‌ای است که هر بار ممکن است فرق کند و خروجی مقداری است که تابع بعد از انجام کار برمی‌گرداند.

// تعریف تابع
function sayHello() {
  console.log("سلام!");
}

// صدا زدن (فراخوانی) تابع
sayHello();
sayHello();





کلمهٔ function به‌همراه نام sayHello تابع را می‌سازد، ولی همان لحظه اجرا نمی‌کند. دستورهای داخل آکولاد تا وقتی تابع صدا زده نشود اجرا نمی‌شوند. نوشتن sayHello() یعنی «الان این تابع را اجرا کن». پرانتز خالی نشان می‌دهد این تابع ورودی نمی‌گیرد. چون دو بار صدا زده شده، پیام سلام دو بار چاپ می‌شود.



ورودی (پارامتر) و خروجی (return)



function add(a, b) {      // a و b پارامتر هستند
  return a + b;           // نتیجه را برمی‌گرداند
}

let result = add(3, 4);   // 3 و 4 آرگومان هستند
console.log(result);
console.log(add(10, 20));










نام‌های a و b در تعریف تابع پارامتر هستند؛ یعنی جاهایی که موقع صدا زدن با مقدار واقعی پر می‌شوند. return حاصل جمع را به جایی برمی‌گرداند که تابع صدا زده شده و اجرای تابع همان‌جا تمام می‌شود. عددهای ۳ و ۴ آرگومان هستند، یعنی مقدارهای واقعی همان صدا زدن. می‌توان نتیجه را در متغیر ریخت یا مستقیم به console.log داد.





اصطلاحیعنی


پارامتر (Parameter)اسم ورودی در تعریف تابع: a، b


آرگومان (Argument)مقدار واقعی موقع صدا زدن: 3، 4


returnمقدار خروجی را برمی‌گرداند و تابع همان‌جا تمام می‌شود





مثال کاربردی: تبدیل دما



function toCelsius(fahrenheit) {
  return (5 / 9) * (fahrenheit - 32);
}

const input = document.getElementById("f-input");
const button = document.getElementById("f-btn");
const output = document.getElementById("f-output");

button.addEventListener("click", function () {
  const f = Number(input.value);
  output.textContent = toCelsius(f).toFixed(1) + " درجه سانتی‌گراد";
});







نتیجه اینجا نمایش داده می‌شود





toCelsius یک عدد فارنهایت می‌گیرد، آن را با فرمول تبدیل به سانتی‌گراد برمی‌گرداند و خودش چیزی چاپ نمی‌کند. با کلیک، متن داخل کادر با Number به عدد تبدیل می‌شود، چون مقدار کادر همیشه متن است. toFixed(1) نتیجه را تا یک رقم اعشار گرد می‌کند و بعد به واحد اندازه‌گیری چسبانده می‌شود تا در صفحه دیده شود.



toFixed(1) عدد را تا یک رقم اعشار گرد می‌کند (مثلاً ۱۰۰ فارنهایت می‌شود 37.8). در درس «اعداد» بیشتر با آن آشنا می‌شویم.



پارامتر پیش‌فرض و آرگومان جاافتاده



اگر موقع صدا زدن، آرگومانی را نفرستیم، پارامتر آن undefined می‌شود و معمولاً جواب خراب (مثل NaN) می‌دهد. با مقدار پیش‌فرض می‌توانیم برای این حالت یک مقدار تعیین کنیم.



// قیمت نهایی: اول تخفیف کم می‌شود، بعد ۱۰٪ مالیات اضافه می‌شود
function finalPrice(price, discountPercent = 0) {
  const discounted = price - price * discountPercent / 100;
  return discounted + discounted * 10 / 100;
}

console.log(finalPrice(200000, 25));   // 165000 ← با ۲۵٪ تخفیف
console.log(finalPrice(200000));       // 220000 ← تخفیف پیش‌فرض: 0

console.log(add(5));                   // NaN ← b برابر undefined است و 5 + undefined عدد نیست










پارامتر discountPercent = 0 یعنی اگر موقع صدا زدن آرگومان دوم نفرستید، به‌جای undefined عدد صفر استفاده شود. تابع اول تخفیف را از قیمت کم می‌کند و بعد ده درصد همان مبلغ تخفیف‌خورده را به‌عنوان مالیات اضافه می‌کند. تابع add مقدار پیش‌فرض ندارد؛ پس add(5) یعنی 5 + undefined و نتیجه NaN است.



محدوده متغیر در تابع (Local Scope)



متغیری که داخل تابع ساخته شود، فقط داخل همان تابع وجود دارد و بعد از تمام شدن تابع از بین می‌رود. پارامترها هم همین‌طورند.



function calculateAverage(a, b, c) {
  const sum = a + b + c;      // sum فقط داخل تابع وجود دارد
  return sum / 3;
}

console.log(calculateAverage(18, 15, 12));   // 15
console.log(typeof sum);                     // undefined ← بیرون تابع، sum تعریف نشده










sum داخل تابع ساخته شده، پس فقط تا پایان همان اجرا وجود دارد. بیرون از تابع، typeof sum برابر "undefined" است، چون چنین متغیری در آن محدوده تعریف نشده. پارامترهای a و b و c هم همین محدودیت را دارند. آنچه از تابع بیرون می‌آید فقط مقداری است که return برمی‌گرداند.



تابع پیکانی (Arrow Function)



یک شکل کوتاه‌تر برای نوشتن تابع است که در کدهای امروزی زیاد می‌بینید. تابع را در یک متغیر (معمولاً const) نگه می‌داریم:



// شکل معمولی
function square(n) {
  return n * n;
}

// همان تابع به شکل پیکانی
const squareArrow = (n) => n * n;     // اگر بدنه فقط یک عبارت باشد، return لازم نیست

const kmToMile = (km) => {
  const miles = km * 0.621;
  return miles;                        // با آکولاد { } باید return بنویسید
};

console.log(square(4), squareArrow(4));   // 16 16
console.log(kmToMile(10));                // 6.21










فلش => تابع را به متغیر وصل می‌کند. اگر سمت راست فلش فقط یک عبارت باشد و آکولاد نداشته باشد، همان عبارت به‌طور خودکار برگردانده می‌شود و نوشتن return لازم نیست. اگر بدنه چند دستوری باشد و داخل آکولاد بیاید، باید خودتان return را بنویسید؛ وگرنه تابع undefined برمی‌گرداند. هر دو شکل square و squareArrow همان کار را می‌کنند.



اشتباه رایج: گذاشتن آکولاد در تابع پیکانی و فراموش کردن return: const f = (n) => { n * n }; همیشه undefined برمی‌گرداند.



بدون پرانتز = خود تابع، با پرانتز = اجرای تابع



console.log(add(2, 3));  // 5  ← اجرا شد
console.log(add);        // خود تابع چاپ می‌شود، اجرا نشد



پرانتز بعد از نام تابع یعنی «اجرا کن». بدون پرانتز، نام تابع به خود تابع اشاره می‌کند و آن را اجرا نمی‌کند. به همین دلیل console.log(add) حاصل جمع چاپ نمی‌کند و تعریف تابع را نشان می‌دهد. این تفاوت وقتی مهم می‌شود که بخواهید تابع را به جای دیگری بدهید تا بعداً اجرا شود، نه همین حالا.



وقتی خود تابع را چاپ کنید، Console مرورگر متن تعریف تابع را نشان می‌دهد (شکل دقیقش در مرورگرهای مختلف کمی فرق دارد). جعبه Console این صفحه آن را خلاصه به شکل ƒ add() نشان می‌دهد.










اسم تابع را با فعل شروع کنید تا معلوم باشد چه کاری انجام می‌دهد: calculateTotal، showMessage، getUserName.



اشتباه رایج: نوشتن console.log به جای return. تابعی که فقط چاپ می‌کند خروجی ندارد و let r = f() برابر undefined می‌شود.



تمرین: (۱) تابع calculateArea(width, height) بنویسید که مساحت مستطیل را برگرداند. (۲) تابع greet(name) بنویسید که متن "سلام " + name را برگرداند و اگر اسمی فرستاده نشد، از مقدار پیش‌فرض "دوست من" استفاده کند. (۳) تابع پیکانی toFahrenheit(celsius) بنویسید (فرمول: celsius * 9 / 5 + 32) و نتیجه را برای ۳۷ درجه چاپ کنید (جواب: 98.6).
