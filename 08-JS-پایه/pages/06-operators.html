۶) عملگرها (Operators)

عملگر علامتی است که روی یک یا چند مقدار کار انجام می‌دهد و معمولاً یک نتیجهٔ تازه می‌سازد. جمع و ضرب عملگر حسابی‌اند، = مقدار را داخل متغیر می‌گذارد و + وقتی یک طرفش متن باشد به‌جای جمع، متن‌ها را به هم می‌چسباند. در این درس هر گروه را جدا می‌بینید تا بدانید هر علامت چه می‌کند و در چه شرایطی جواب غیرمنتظره می‌دهد.

عملگرهای حسابی (Arithmetic)

عملگرمعنیمثالنتیجه
+جمع5 + 27
-تفریق5 - 23
*ضرب5 * 210
/تقسیم5 / 22.5
%باقیمانده5 % 21
**توان5 ** 225
++یکی اضافهx++x یکی بیشتر می‌شود
--یکی کمx--x یکی کمتر می‌شود
let x = 10;
let y = 3;
console.log(x + y, x - y, x * y);   // 13 7 30
console.log(x / y);                 // 3.3333333333333335 (تقسیم اعشاری است، نه صحیح)
console.log(x % y);                 // 1 ← باقیمانده 10 تقسیم بر 3
console.log(2 ** 10);               // 1024

let counter = 0;
counter++;
counter++;
console.log(counter);               // 2





دو متغیر x و y عددهای این محاسبه هستند. تقسیم در JavaScript اعشاری است؛ 10 / 3 به عدد صحیح گرد نمی‌شود. % خارج‌قسمت را دور می‌ریزد و فقط باقیمانده را برمی‌گرداند، پس 10 % 3 برابر ۱ است. ** توان است و 2 ** 10 یعنی ۲ را ده بار در خودش ضرب کن. counter++ همان counter = counter + 1 است و چون دو بار اجرا شده، شمارنده از صفر به ۲ می‌رسد.



کاربرد %: فهمیدن زوج یا فرد بودن (n % 2 === 0 یعنی زوج)، تبدیل دقیقه به «ساعت و دقیقه» (130 % 60 می‌شود ۱۰ دقیقه باقیمانده) و هر جا که «باقیمانده» یا «چرخش» لازم است.



اشتباه رایج: فرق x++ و ++x را ندانستن. هر دو x را یکی زیاد می‌کنند، ولی اگر نتیجه را همان لحظه استفاده کنید فرق دارند: let a = 5; let b = a++; ← b برابر ۵ و a برابر ۶ (اول مقدار قدیمی را می‌دهد، بعد زیاد می‌کند). let c = ++a; ← اول زیاد می‌کند، بعد مقدار جدید را می‌دهد. برای خوانایی، ++ را در یک خط جدا بنویسید.



ترتیب انجام عملیات



مثل ریاضی: اول پرانتز، بعد توان، بعد ضرب و تقسیم و باقیمانده (* / %)، آخر جمع و تفریق. عملگرهای هم‌رده از چپ به راست حساب می‌شوند.



console.log(2 + 3 * 4);     // 14
console.log((2 + 3) * 4);   // 20

// میانگین سه نمره: بدون پرانتز اشتباه می‌شود!
console.log(18 + 16 + 14 / 3);     // 38.666666666666664 ✖
console.log((18 + 16 + 14) / 3);   // 16 ✔










در 2 + 3 * 4 اول ضرب انجام می‌شود و حاصل با ۲ جمع می‌شود. پرانتز این ترتیب را عوض می‌کند و اول داخل پرانتز حساب می‌شود. در میانگین نمره‌ها، بدون پرانتز فقط عدد آخر بر ۳ تقسیم می‌شود و جمع دو نمرهٔ دیگر دست‌نخورده می‌ماند؛ به همین دلیل نتیجه میانگین واقعی نیست.



عملگرهای انتساب (Assignment)





عملگرمثالیعنی


=x = 5x را ۵ کن


+=x += 3x = x + 3


-=x -= 3x = x - 3


*=x *= 3x = x * 3


/=x /= 3x = x / 3





مثال کاربردی: جمع سبد خرید با تخفیف و مالیات (قیمت‌ها به تومان):



let total = 0;
total += 250000;          // کتاب        → 250000
total += 2 * 45000;       // دو دفتر     → 340000
total -= 40000;           // کد تخفیف    → 300000

let tax = total * 10 / 100;   // ۱۰٪ مالیات بر ارزش افزوده → 30000
total += tax;                 // → 330000
console.log("مالیات:", tax);
console.log("مبلغ قابل پرداخت:", total);










total از صفر شروع می‌شود تا چیزی برای اضافه کردن داشته باشیم. += مقدار سمت راست را به مقدار فعلی متغیر اضافه می‌کند و نتیجه را دوباره در همان متغیر می‌ریزد. -= به همین شکل کم می‌کند. مالیات جدا حساب شده تا هم مبلغ مالیات دیده شود و هم بعداً با += به جمع کل اضافه شود.



جمع متن‌ها (چسباندن رشته‌ها)



اگر یک طرف + متن باشد، JavaScript به جای جمع، دو طرف را به هم می‌چسباند.



let first = "علی";
let last = "رضایی";
console.log(first + " " + last);

console.log("5" + 2);     // "52"  ← چسباندن!
console.log(5 + 2 + "3"); // "73"  ← اول 5+2، بعد چسباندن
console.log("3" + 5 + 2); // "352" ← از همان اول متن است، پس همه چسبانده می‌شوند
console.log("5" - 2);     // 3     ← منها فقط برای عدد است؛ متن به عدد تبدیل می‌شود



علامت + اگر دست‌کم یک طرفش متن باشد، طرف دیگر را هم به متن تبدیل می‌کند و دو رشته را به هم می‌چسباند. ترتیب مهم است: در 5 + 2 + "3" دو عدد اول با هم جمع می‌شوند و بعد نتیجه به متن چسبانده می‌شود. عملگر - متن را نمی‌چسباند؛ اگر متن شبیه عدد باشد آن را به عدد تبدیل می‌کند و تفریق انجام می‌دهد.



Console گیومه دور متن را نشان نمی‌دهد؛ پس در خروجی 52 می‌بینید، ولی این مقدار متن (رشته) است نه عدد. در درس «انواع داده» با typeof می‌توانید این را بررسی کنید.










اشتباه رایج: فکر کردن اینکه "5" + 2 می‌شود ۷. مقداری که کاربر در کادر input تایپ می‌کند همیشه متن است و باید اول با Number() به عدد تبدیل شود: Number("5") + 2 برابر ۷ است.



تمرین: (۱) باقیمانده تقسیم ۱۷ بر ۲ را با % چاپ کنید؛ اگر ۰ بود عدد زوج است و اگر ۱ بود فرد. (۲) فیلمی ۱۳۵ دقیقه است؛ با / و % ساعت و دقیقه آن را حساب کنید (راهنما: (135 - 135 % 60) / 60 ساعت و 135 % 60 دقیقه). (۳) با += یک سبد خرید بسازید که سه قیمت را به جمع کل اضافه کند و در پایان ۵٪ تخفیف از آن کم کند.
