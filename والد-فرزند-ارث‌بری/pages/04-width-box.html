۴) width / margin / padding / border ارثی نیستند

اگر والد width: 80% داشته باشد، فرزند همان ۸۰٪ را «کپی» نمی‌کند. فرزند بلوکی معمولاً عرض موجود داخل والد را پر می‌کند (auto) — این ارث نیست؛ رفتار پیش‌فرض block است. 

.wb-parent { width: 80%; padding: 20px; border: 4px solid #1a5fb4; }
.wb-parent .kid { /* بدون width */ }
.wb-parent .kid-wide { width: 50%; } /* نصف عرض والد */
والد: ۸۰٪ عرض صفحه + padding + border آبی
فرزند بدون width — پهن داخل محتوا (نه «ارث ۸۰٪»)
فرزند با width: 50% — نصف عرض والد
ویژگیارث؟یادداشت جونیور
width / heightخیر٪ یعنی نسبت به والد، نه کپی عدد والد
margin / paddingخیرهر جعبه فاصله خودش را دارد
borderخیرکادر والد روی فرزند ظاهر نمی‌شود
backgroundخیرممکن است از پشت دیده شود اگر فرزند شفاف باشد
