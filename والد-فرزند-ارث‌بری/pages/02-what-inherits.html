۲) قانون سرانگشتی

اگر روی فرزند برای یک ویژگی چیزی ننویسید، بعضی ویژگی‌ها از والد می‌آیند (ارثی). بقیه باید خودتان بنویسید.

معمولاً ارث می‌برد (متن)معمولاً ارث نمی‌برد (جعبه)
color · font-family · font-size · line-height · text-align · direction width · height · margin · padding · border · background · display

مثال: متن ارث می‌برد، کادر نه

.parent {
  color: #1a3a5c;
  font-family: Georgia, serif;
  border: 2px solid #1a3a5c;
  padding: 12px;
}
/* فرزند: color و font می‌آید؛ border نمی‌آید */
والد: رنگ + فونت + کادر
فرزند: رنگ و فونت را گرفته — کادر سرمه‌ای والد را ندارد.

مثال: عرض ارث نمی‌برد

والد: width حدود ۷۰٪ + حاشیه قرمز
فرزند: عرض والد را «ارث» نبرده؛ فقط به‌اندازه محتواست (مگر خودتان width بدهید).

جزئیات بیشتر در وراثت — آبشاری. استثناها وجود دارد؛ جدول بالا برای شروع جونیور کافی است.

اشتباه رایج: فکر کردن که width: 50% روی والد یعنی همه فرزندان هم ۵۰٪ می‌شوند. نه — هر کدام جدا حساب می‌شوند.
