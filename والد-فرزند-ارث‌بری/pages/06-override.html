۶) چطور ارث را عوض کنیم؟

  1. روی فرزند مقدار جدید بنویسید → ارث برای همان ویژگی قطع می‌شود.
  2. inherit یعنی «عمداً همان مقدار محاسبه‌شدهٔ والد را بگیر».
.ov-parent { color: #1a3a5c; }
.ov-parent .own  { color: #c92a2a; }
.ov-parent .force { color: inherit; }
والد: رنگ سرمه‌ای
فرزند با رنگ خودش (قرمز)
فرزند با color: inherit → دوباره سرمه‌ای والد

inherit برای ویژگی‌های غیرارثی هم کار می‌کند (مثلاً مجبور کردن border به گرفتن از والد — نادر، ولی ممکن). برای اولویت قوانین (کدام کلاس برنده است) بروید به آبشاری.

ارث‌بری ≠ specificity. اول می‌پرسند «مقداری نوشته شده؟» بعد «کدام قانون قوی‌تر است؟»
