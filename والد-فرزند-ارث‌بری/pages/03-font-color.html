۳) فونت و رنگ از والد می‌آیند

روی body یا یک ظرف بنویسید؛ متن داخل معمولاً همان را می‌گیرد تا خودتان عوض کنید.

.fc-parent {
  color: #0b6e4f;
  font-size: 1.25rem;
  font-family: Georgia, serif;
}
.fc-parent .change {
  color: #c92a2a;              /* لغو ارث رنگ */
  font-family: Tahoma, sans-serif;
}
والد: سبز + Georgia + کمی درشت
فرزند بدون قانون اضافه → همان رنگ و فونت والد
فرزند با قانون خودش → قرمز و Tahoma

برای کل سایت معمولاً روی body (یا :root) فونت و رنگ متن پایه را می‌گذارند. درس رنگ: Colors · فونت: Fonts

background-color مثل color نیست — پس‌زمینه ارث نمی‌برد. فرزند شفاف است و رنگ والد از «پشت» دیده می‌شود، نه اینکه background را ارث برده باشد.
