۵) دو گیجی پرتکرار: ٪ و em

واحدنسبت به چیست؟
width: 50%معمولاً عرض والد
font-size: 1.5emفونت والد
padding: 0.5emفونت خود همان عنصر
1.5remفونت ریشه (html) — وابسته به والد وسط نیست
 
.pe-box { width: 300px; font-size: 16px; }
.half   { width: 50%; }      /* ≈ ۱۵۰px */
.em-pad { font-size: 1.5em; padding: 0.5em; }
والد: عرض ۳۰۰px · فونت ۱۶px
۵۰٪ عرض والد
فونت ۱٫۵em · پدینگ ۰٫۵em (نسبت به فونت خودش)
با rem — از ریشه، نه از والد وسط

گیج نشوید: 50% روی فونت ≠ نصف عرض. درصد برای font-size نسبت به فونت والد است؛ برای width نسبت به عرض والد.

درس واحدها: px / em / rem
