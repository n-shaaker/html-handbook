# تمرین‌ها و پروژه‌های عملی — CSS مقدماتی

تمرین‌های این دوره دو بخش دارند:

1. **بخش اول — تمرین‌های مبحثی** ([`1-topic-exercises`](1-topic-exercises)): برای هر درس یک پوشه با **سه تمرین کوتاه** (⭐ ← ⭐⭐ ← ⭐⭐⭐).
   هر تمرین فقط یک مهارت را تمرین می‌دهد و فقط از همان درس و درس‌های قبلی استفاده می‌کند. هر تمرین ۱۰ تا ۲۵ دقیقه وقت می‌گیرد.
2. **بخش دوم — پروژه‌های ترکیبی** ([`2-combined-projects`](2-combined-projects)): پروژه‌هایی که چند مبحث بخش اول را **هدفمند** کنار هم می‌گذارند تا یک صفحه واقعی ساخته شود.

## روش کار

**برای هنرجو:**

1. بخش اول را **به ترتیب** و مبحث به مبحث جلو بروید؛ بعد از هر درس، تمرین‌های همان مبحث را حل کنید.
2. داخل پوشه هر مبحث (یا هر پروژه) یک پوشه به اسم خودتان بسازید، **کنار** پوشه `starter` (مثلاً `04-colors/sara-ahmadi/`)
   و فایل‌های `starter` را در آن کپی کنید. چون پوشه شما هم‌سطح `starter` است، آدرس‌های نسبی فونت و تصویر
   (`../../../../fonts/...` و `../../../../images/...`) درست کار می‌کنند.
3. اگر تمرینی `starter` ندارد یا فقط HTML دارد، فایل CSS را با همان نامی بسازید که در HTML لینک شده (مثلاً `ex-1.css`).
4. **فایل HTML را تغییر ندهید**، مگر اینکه صورت تمرین صریحاً بخواهد.
5. بعد از تمام شدن همه مبحث‌ها (یا دست‌کم مبحث‌هایی که در جدول پروژه آمده)، سراغ بخش دوم بروید.
6. پوشه `solution` را قبل از حل کردن باز نکنید.

## برای استاد

- پاسخ‌ها در پوشه‌های `solution` هستند: در بخش اول `ex-1.html` + `ex-1.css` و ... (و برای تمرین‌های محاسباتی یک فایل `ex-N-answers.md`)؛
  در بخش دوم `index.html` + `style.css` (و در پروژه ۵ فایل `answers.md`).
- پاسخ‌ها نمونه‌اند، نه تنها جواب درست. رنگ و اندازه دقیق مهم نیست؛ **رعایت الزامات** مهم است.
- تمرین‌های بخش اول برای تمرین در کلاس یا تکلیف کوتاه‌اند و بارم ندارند؛ پیشنهاد: ⭐ = ۱، ⭐⭐ = ۲، ⭐⭐⭐ = ۳ امتیاز.
- پروژه‌های بخش دوم جدول بارم‌بندی از ۲۰ دارند.

## نکات کلی نمره‌دهی

- فقط از مباحث همین دوره استفاده کنید: **Flexbox، Grid، position، float و متغیرهای CSS در این دوره تدریس نشده‌اند** و استفاده از آن‌ها نمره بند مربوط را صفر می‌کند.
- `!important` و `style` درون‌خطی ممنوع است (هر مورد ۱ نمره کسر)؛ تنها استثنا تمرین ۲ مبحث «سه روش افزودن CSS» است.
- CSS باید بخش‌بندی شده باشد (با توضیح‌های کوتاه) و تورفتگی یکدست داشته باشد؛ کد درهم تا ۱ نمره کسر دارد.
- کد CSS را در [اعتبارسنج CSS سایت W3C](https://jigsaw.w3.org/css-validator/#validate_by_input) بررسی کنید؛ هر خطا ۰٫۵ نمره کسر دارد (حداکثر ۲ نمره).
- بخش «امتیازی» پروژه‌ها تا ۲ نمره اضافه دارد، ولی جمع نمره از ۲۰ بیشتر نمی‌شود.
