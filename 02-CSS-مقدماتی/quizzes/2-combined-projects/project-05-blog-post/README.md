## صورت مسئله

«کیان رستمی» یک وبلاگ سفر به اسم **«کوله‌پشتی»** دارد. پست جدیدش درباره ماسوله آماده است
([`starter/index.html`](starter/index.html)) ولی صفحه هنوز ظاهر پیش‌فرض مرورگر را دارد:
خطوط متن در مانیتور بزرگ آن‌قدر بلندند که خواندنشان خسته‌کننده است و سربرگ هیچ حسی از سفر ندارد.
شما `style.css` را بنویسید و به چند پرسش مدل جعبه هم جواب بدهید.

## بخش الف: کدنویسی

1. برای **همه** عناصر `box-sizing: border-box` تعیین کنید.
2. سربرگ (`#post-header`) تصویر پس‌زمینه `../../../../images/bg.jpg` داشته باشد: کل سربرگ را بپوشاند، وسط‌چین، بدون تکرار،
   همراه یک رنگ پس‌زمینه جایگزین. متن سربرگ سفید و وسط‌چین با `padding` عمودی کافی (حداقل `64px`).
3. نام وبلاگ (`.blog-name`) با حروف کوچک/بزرگ تغییر نمی‌کند (فارسی است)، پس به‌جایش `letter-spacing` و اندازه کوچک‌تر بگیرد.
   عنوان پست (`.post-title`) یک `text-shadow` داشته باشد که روی تصویر خواناتر شود.
4. بخش مقاله (`.post`) عرضش حداکثر `680px` باشد، وسط صفحه قرار بگیرد و در موبایل از دو طرف کمی فاصله داشته باشد.
5. متن مقاله `line-height` حدود ۱٫۹ داشته باشد. پاراگراف آغازین (`.lead`) کمی درشت‌تر باشد.
6. همه تیترهای `h2` **داخل مقاله** (و نه هر `h2` ای در صفحه) با **یک** قانون رنگ و فاصله بگیرند — از انتخابگر **نسل** (descendant) استفاده کنید.
7. جعبه خلاصه (`.box`) را دقیقاً این‌طور بسازید: `width: 100%` و `max-width: 400px`، `padding: 16px 20px`، `border: 2px solid` با رنگ دلخواه، گوشه گرد، رنگ پس‌زمینه ملایم.
8. نقل‌قول (`.quote`) یک خط ضخیم در **سمت راست**، رنگ پس‌زمینه، `padding`، و متن ایرانیک یا رنگ متفاوت داشته باشد. `cite` داخل آن کوچک‌تر و بدون ایرانیک باشد.
9. لینک‌های داخل مقاله در حالت عادی خط زیر داشته باشند و در hover، خط زیر برداشته شود (`text-decoration`).
10. حداقل یک **انتخابگر گروهی** (چند انتخابگر با کاما) معنی‌دار بنویسید، مثلاً برای `.tags` و `.site-footer` که هر دو کوچک و کم‌رنگ‌اند.
11. پانویس یک `border-top` و فاصله از مقاله داشته باشد.

## بخش ب: پرسش‌ها

پاسخ این پرسش‌ها را در یک فایل `answers.md` کنار `style.css` بنویسید (هر جواب با یک یا دو جمله دلیل):

**پرسش ۱.** قانون زیر را در نظر بگیرید (بدون `border-box`، یعنی حالت پیش‌فرض مرورگر):

```css
.box {
  width: 300px;
  padding: 16px 20px;
  border: 2px solid #0b6e4f;
  margin: 24px;
}
```

عرض **دیده‌شده** جعبه (از لبه بیرونی border تا لبه بیرونی border) چند پیکسل است؟ و جعبه در کل چقدر فضای افقی از صفحه اشغال می‌کند (با margin)؟

**پرسش ۲.** اگر به همان قانون `box-sizing: border-box;` اضافه کنیم، عرض دیده‌شده و عرض **محتوا** چقدر می‌شوند؟

**پرسش ۳.** پاراگراف بالایی `margin-bottom: 24px` و پاراگراف زیرینش `margin-top: 16px` دارد. فاصله عمودی بین این دو پاراگراف چند پیکسل است؟ اسم این پدیده چیست؟

**پرسش ۴.** قدرت تشخیص بین دو قانون زیر — کدام رنگ روی عنوان پست اعمال می‌شود و چرا؟
`#post-header h1 { color: white; }` در برابر `.post-title { color: black; }` (فرض کنید دومی پایین‌تر نوشته شده باشد.)

## محدودیت‌ها

- HTML را تغییر ندهید.
- بدون Flexbox، Grid، position و float.
- بدون `!important`.
- برای وسط‌چین کردن جعبه‌ها از `margin` استفاده کنید، نه `text-align` روی والد.

## امتیازی (تا ۲ نمره)

- فونت وزیرمتن را با `@font-face` از `../../../../fonts/` اضافه کنید.
- `:focus-visible` با `outline` برای لینک‌ها.

## نکته استاد

- برای پرسش ۱، padding و border **دو طرف** دارند؛ هر کدام را دو بار حساب کنید.
- فاصله بین تیتر و پاراگراف‌ها گاهی کمتر از انتظار شماست؛ قبل از اضافه کردن margin بیشتر، در DevTools بررسی کنید آیا marginها روی هم افتاده‌اند.
- انتخابگر id قدرت زیادی دارد؛ اگر قانونی روی سربرگ اعمال نشد، اول قدرت انتخابگرها را مقایسه کنید.
