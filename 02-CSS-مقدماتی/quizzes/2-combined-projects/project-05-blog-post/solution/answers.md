# پاسخ پرسش‌های پروژه ۵ (پاسخ استاد)

## پرسش ۱

در حالت پیش‌فرض (`content-box`)، `width` فقط عرض محتواست و padding و border به آن **اضافه** می‌شوند:

- عرض دیده‌شده = ۳۰۰ + (۲۰ × ۲) + (۲ × ۲) = **۳۴۴ پیکسل**
- فضای اشغال‌شده با margin = ۳۴۴ + (۲۴ × ۲) = **۳۹۲ پیکسل**

(padding عمودی ۱۶ در عرض نقشی ندارد؛ `16px 20px` یعنی بالا/پایین ۱۶ و چپ/راست ۲۰.)

## پرسش ۲

با `border-box`، عدد `width` شامل padding و border است:

- عرض دیده‌شده = **۳۰۰ پیکسل**
- عرض محتوا = ۳۰۰ − (۲۰ × ۲) − (۲ × ۲) = **۲۵۶ پیکسل**

margin در هر دو حالت بیرون از جعبه است و در `width` حساب نمی‌شود.

## پرسش ۳

فاصله **۲۴ پیکسل** است، نه ۴۰. marginهای عمودی دو عنصر بلوکی پشت سر هم روی هم می‌افتند و
فقط بزرگ‌ترشان باقی می‌ماند. به این پدیده **فروریختن margin** (Margin Collapse) می‌گویند.
(این اتفاق فقط برای margin عمودی رخ می‌دهد، نه افقی.)

## پرسش ۴

رنگ **سفید** اعمال می‌شود، چون انتخابگر id از کلاس قوی‌تر است (درس انتخابگرها: id &gt; class &gt; نام تگ).
به زبان دقیق‌تر (که در دوره «آبشاری بودن CSS» کامل می‌شود): قدرت `#post-header h1` برابر `(1, 0, 1)` و قدرت `.post-title` برابر `(0, 1, 0)` است؛
ستون id اولی بیشتر است، پس برنده است و ترتیب نوشتن (پایین‌تر بودن دومی) اهمیتی ندارد.
ترتیب فقط وقتی تعیین‌کننده است که قدرت دو انتخابگر **برابر** باشد.

## راهنمای نمره‌دهی

- هر پرسش ۱٫۵ نمره: ۱ نمره برای عدد/جواب درست و ۰٫۵ نمره برای دلیل.
- در پرسش ۱ اگر فقط عرض دیده‌شده را درست گفته و فضای با margin را نه، ۱ نمره.
- در پرسش ۴ اگر هنرجو بدون محاسبه سه‌تایی فقط گفته «id قوی‌تر است»، نمره کامل بگیرد.
