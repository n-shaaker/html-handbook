## صورت مسئله

«کافه دارچین» در رشت می‌خواهد منوی نوشیدنی‌هایش را روی تبلت کنار صندوق و QR روی میزها نمایش دهد.
صاحب کافه، «نیلوفر قاسمی»، گفته: «جدول باید راحت خوانده شود؛ قیمت‌ها زیر هم مرتب باشند و وقتی مشتری
انگشتش را روی یک ردیف می‌گذارد، آن ردیف مشخص شود.»
HTML آماده است ([`starter/index.html`](starter/index.html)). شما `style.css` را بنویسید.

## الزامات

**سربرگ (`site-header`)**

1. سربرگ یک تصویر پس‌زمینه داشته باشد: `../../../../images/bg.jpg` که کل سربرگ را بپوشاند (`cover`)، وسط‌چین باشد و تکرار نشود.
   یک **رنگ پس‌زمینه** هم کنارش تعریف کنید تا اگر تصویر لود نشد، متن سفید همچنان خوانا باشد.
2. متن سربرگ سفید، وسط‌چین، با `padding` عمودی کافی (سربرگ «باریکه» نباشد).

**محتوا**

3. بخش `content` حداکثر `720px` عرض داشته باشد و وسط صفحه باشد.

**جدول**

4. جدول تمام عرض محتوا را بگیرد و خطوطش **تک‌خطی** باشند (نه دوخطی، پیش‌فرض مرورگر).
5. همه خانه‌ها `padding` داشته باشند؛ خانه‌ها فقط خط افقی پایین داشته باشند (بدون خطوط عمودی).
6. سرستون‌ها (`th`) رنگ پس‌زمینه تیره و متن روشن داشته باشند.
7. `caption` پررنگ، کمی بزرگ‌تر از متن جدول و با فاصله از جدول باشد.
8. ردیف‌های **زوج** بدنه جدول رنگ پس‌زمینه متفاوت داشته باشند (راه‌راه) — فقط با CSS و **بدون** افزودن کلاس به HTML.
9. با بردن ماوس روی هر ردیف **بدنه**، آن ردیف رنگ دیگری بگیرد؛ ردیف سرستون نباید تغییر کند.
10. ستون قیمت (`.price`) **چپ‌چین** باشد تا ارقام زیر هم مرتب شوند، و پررنگ باشد. سرستون قیمت هم هم‌تراز با خود قیمت‌ها باشد.

**یادداشت‌ها**

11. فهرست `notes` به‌جای دایره، علامت **مربع** (`square`) داشته باشد و رنگ علامت با رنگ متن فرق کند.
12. فهرست یک رنگ پس‌زمینه ملایم، `border` در سمت راست (شروع خط در فارسی) و `padding` داشته باشد.

## محدودیت‌ها

- HTML را تغییر ندهید (کلاس و id اضافه نکنید).
- بدون Flexbox، Grid، position و float.
- بدون `!important`.
- تصویر را کپی نکنید؛ با آدرس نسبی به پوشه `images` دوره اشاره کنید.

## امتیازی (تا ۲ نمره)

- یک `text-shadow` تیره روی تیتر سربرگ تا روی تصویر خواناتر شود.
- گوشه‌های گرد برای سربرگ یا فهرست یادداشت‌ها.
- `text-transform` یا `letter-spacing` در جایی که منطقی باشد (مثلاً سرستون‌ها).

## نکته استاد

- اگر راه‌راه یا hover روی ردیف سرستون هم اعمال شد، انتخابگرتان را دقیق‌تر کنید؛ به جای `tr` بگویید **کدام** `tr`ها.
- در صفحه راست‌به‌چپ، «ابتدای خط» سمت راست است؛ قبل از نوشتن `text-align` فکر کنید ارقام کجا باید تراز شوند.
- آدرس `url()` در CSS نسبت به **خود فایل CSS** حساب می‌شود.
