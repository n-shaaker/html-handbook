# مبحث ۱ — CSS چیست و ساختار نوشتن آن

درس‌های مرتبط: [CSS چیست؟](../../../pages/01-intro.html) و [ساختار نوشتن CSS](../../../pages/02-syntax.html)

در این تمرین‌ها فقط از **انتخابگر نام تگ** (مثل `p` و `h1`) استفاده کنید. فایل HTML آماده است و به فایل CSS لینک شده؛
کافی است فایل CSS را کنار آن بسازید یا درست کنید.

---

## تمرین ۱ — اولین قانون‌ها ⭐

**هدف:** نوشتن قانون CSS کامل (انتخابگر، آکولاد، ویژگی، مقدار و `;`).

**صورت مسئله:** صاحب کافه کتاب «ورق» صفحه خوش‌آمدگویی ساده‌ای دارد ([`starter/ex-1.html`](starter/ex-1.html)) و می‌خواهد تیتر رنگ قهوه‌ای داشته باشد.

**الزامات:**

- فایل `ex-1.css` را کنار `ex-1.html` بسازید.
- تیتر `h1` رنگ قهوه‌ای و اندازه `36px` داشته باشد.
- همه پاراگراف‌ها رنگ خاکستری تیره و اندازه `18px` داشته باشند.
- هر اعلان در یک خط جدا باشد و با `;` تمام شود.

**خروجی مورد انتظار:** تیتر قهوه‌ای و بزرگ، دو پاراگراف خاکستری با متن کمی درشت‌تر از پیش‌فرض.

---

## تمرین ۲ — پیدا کردن خطاهای نگارشی ⭐⭐

**هدف:** تشخیص خطاهای Syntax که باعث می‌شوند مرورگر یک اعلان یا قانون را نادیده بگیرد.

**صورت مسئله:** هم‌کلاسی شما فایل [`starter/ex-2.css`](starter/ex-2.css) را نوشته ولی «هیچ‌چیز درست کار نمی‌کند».
در این فایل **پنج خطا** وجود دارد.

**الزامات:**

- هر پنج خطا را پیدا و درست کنید (محتوای قانون‌ها را عوض نکنید، فقط خطا را درست کنید).
- بعد از درست کردن: تیتر سرمه‌ای و وسط‌چین، پاراگراف‌ها `18px` و پس‌زمینه صفحه کرم باشد.
- فهرست پنج خطا را برای خودتان یادداشت کنید و با پاسخ مقایسه کنید.

**خروجی مورد انتظار:** پنج خطا: `;` جاافتاده بعد از `navy`، نام غلط `colour`، عدد بدون واحد `18`، استفاده از `=` به جای `:`، و آکولاد بسته‌نشده آخر فایل.

---

## تمرین ۳ — مرتب‌نویسی یک فایل یک‌خطی ⭐⭐⭐

**هدف:** نوشتن CSS خوانا با قالب استاندارد (هر قانون جدا، هر اعلان در یک خط، تورفتگی یکسان).

**صورت مسئله:** کتابخانه محله فایل [`starter/ex-3.css`](starter/ex-3.css) را از یک سایت قدیمی آورده که همه‌اش در یک خط است.
کار می‌کند، ولی هیچ‌کس نمی‌تواند ویرایشش کند.

**الزامات:**

- همه قانون‌ها را بدون تغییر در نتیجه، باز و مرتب بنویسید.
- هر اعلان در یک خط، با دو فاصله تورفتگی و `;` در انتها (حتی اعلان آخر).
- بین قانون‌ها یک خط خالی بگذارید.
- یک قانون جدید برای `p` اضافه کنید: اندازه `17px`.

**خروجی مورد انتظار:** ظاهر صفحه مثل قبل است (به‌جز پاراگراف‌ها که کمی درشت‌تر شده‌اند)، ولی فایل CSS حدود ۲۰ خط مرتب است.

---

## اشتباه‌های رایج این مبحث

- جا انداختن `;` بین دو اعلان: مرورگر هر دو اعلان را با هم یک مقدار نامعتبر می‌بیند و هر دو را نادیده می‌گیرد.
- نوشتن عدد بدون واحد (`font-size: 18`). فقط عدد `0` بدون واحد درست است.
- املای انگلیسی بریتانیایی (`colour`) یا غلط تایپی در نام ویژگی؛ مرورگر خطا نمی‌دهد، فقط اعلان را نادیده می‌گیرد.
- فراموش کردن آکولاد بسته؛ قانون‌های بعدی هم خراب می‌شوند.
