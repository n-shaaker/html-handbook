# مبحث ۳ — سه روش افزودن CSS و توضیحات (Comments)

درس‌های مرتبط: [سه روش افزودن CSS به HTML](../../../pages/04-howto.html) و [توضیحات (Comments)](../../../pages/05-comments.html)

---

## تمرین ۱ — لینک دادن فایل خارجی ⭐

**هدف:** وصل کردن یک فایل CSS خارجی با تگ `link` در `head`.

**صورت مسئله:** صفحه آموزشگاه زبان «پل» ([`starter/ex-1.html`](starter/ex-1.html)) هنوز هیچ CSSای ندارد.

**الزامات:**

- فایل `ex-1.css` را کنار HTML بسازید.
- در `head` با `<link rel="stylesheet" href="...">` آن را لینک کنید.
- تیتر رنگ فیروزه‌ای و پاراگراف‌ها خاکستری و `18px` شوند.
- هیچ CSSای داخل خود HTML ننویسید.

**خروجی مورد انتظار:** با باز کردن صفحه، رنگ‌ها اعمال شده‌اند. اگر اعمال نشدند، نام فایل و مسیر `href` را بررسی کنید.

---

## تمرین ۲ — سه روش کنار هم ⭐⭐

**هدف:** نوشتن CSS به هر سه روش External، Internal و Inline و دیدن اینکه کدام برنده می‌شود.

**صورت مسئله:** [`starter/ex-2.html`](starter/ex-2.html) چهار پاراگراف دارد و به `ex-2.css` لینک شده است.

**الزامات:**

- پاراگراف `ext` را در فایل `ex-2.css` آبی کنید.
- یک تگ `<style>` در `head` **بعد از** تگ `link` بگذارید و پاراگراف `int` را صورتی کنید.
- پاراگراف سوم را با `style="..."` روی خود تگ سبز کنید.
- پاراگراف `both` را در فایل خارجی آبی و در تگ `style` بنفش کنید.
- **قبل از** باز کردن صفحه پیش‌بینی کنید پاراگراف `both` چه رنگی می‌شود، بعد بررسی کنید.

**خروجی مورد انتظار:** پاراگراف آخر بنفش است؛ چون تگ `style` بعد از `link` آمده و از بین دو قانون هم‌قدرت، دیرتر برنده است.
(این تنها تمرینی است که CSS درون‌خطی و داخلی مجاز است.)

## تمرین ۳ — مرتب کردن فایل با توضیح ⭐⭐⭐

**هدف:** بخش‌بندی فایل CSS با توضیح، نوشتن توضیح «چرا» و غیرفعال کردن موقت یک اعلان.

**صورت مسئله:** نانوایی «گندم» فایل [`starter/ex-3.css`](starter/ex-3.css) را دارد که قانون‌هایش بی‌ترتیب‌اند
و یک حاشیه قرمز که برای اشکال‌یابی گذاشته شده بود، هنوز دور پانویس مانده است.

**الزامات:**

- قانون‌ها را به ترتیب صفحه مرتب کنید: کل صفحه، سربرگ، محتوا، پانویس.
- بالای هر بخش یک توضیح بخش‌بندی مثل `/* ===== سربرگ ===== */` بگذارید.
- حاشیه قرمز را **پاک نکنید**؛ آن را داخل توضیح بگذارید تا غیرفعال شود.
- کنار `font-size` پانویس یک توضیح کوتاه بنویسید که **چرا** کوچک‌تر است (نه اینکه چه می‌کند).

**خروجی مورد انتظار:** ظاهر صفحه مثل قبل است به‌جز حاشیه قرمز که دیگر دیده نمی‌شود؛ فایل چهار بخش واضح دارد.

---

## اشتباه‌های رایج این مبحث

- نوشتن `href` اشتباه (مثلاً `style.css` در حالی که فایل `ex-1.css` است) یا جا انداختن `rel="stylesheet"`.
- نوشتن انتخابگر و آکولاد داخل `style="..."`؛ در روش درون‌خطی فقط اعلان‌ها نوشته می‌شوند.
- استفاده از `//` برای توضیح؛ در CSS فقط `/* ... */` درست است.
- توضیح‌هایی که فقط کد را تکرار می‌کنند (`/* رنگ قرمز */` کنار `color: red`).
