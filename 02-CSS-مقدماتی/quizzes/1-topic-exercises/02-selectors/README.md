# مبحث ۲ — انتخابگرها

درس مرتبط: [انتخابگرها (Selectors)](../../../pages/03-selectors.html)

در این تمرین‌ها **HTML را تغییر ندهید**؛ هنر شما انتخاب انتخابگر درست است.

---

## تمرین ۱ — دستور پخت ⭐

**هدف:** تفاوت انتخابگر نام تگ و انتخابگر کلاس.

**صورت مسئله:** یک وبلاگ آشپزی صفحه دستور کوکو سبزی را ساخته ([`starter/ex-1.html`](starter/ex-1.html)) و می‌خواهد «نکته‌ها» از بقیه متن جدا دیده شوند.

**الزامات:**

- همه پاراگراف‌ها رنگ خاکستری تیره داشته باشند (یک قانون).
- فقط پاراگراف‌های نکته (`tip`) سبز و پررنگ باشند (یک قانون).
- تیترهای `h2` نارنجی تیره باشند.
- در کل فقط سه قانون بنویسید.

**خروجی مورد انتظار:** دو پاراگراف «نکته» سبز و پررنگ، بقیه پاراگراف‌ها خاکستری.

---

## تمرین ۲ — صفحه خبر ⭐⭐

**هدف:** استفاده از انتخابگر id، انتخابگر «عنصر + کلاس» و انتخابگر گروهی.

**صورت مسئله:** سایت خبری محله صفحه یک خبر را دارد ([`starter/ex-2.html`](starter/ex-2.html)).
کلاس `note` هم روی یک `p` آمده و هم روی یک `div`.

**الزامات:**

- تیتر خبر را با **id** آن انتخاب کنید: سرمه‌ای و وسط‌چین.
- فقط `p` دارای کلاس `note` خاکستری و `14px` شود؛ `div.note` نباید تغییر کند.
- `h2` و `h3` را با **یک** قانون گروهی سبز کنید.

**خروجی مورد انتظار:** تاریخ انتشار ریز و خاکستری، ولی جمله «این خبر از روابط عمومی...» بدون تغییر.

---

## تمرین ۳ — انتخابگر درست بدون تغییر HTML ⭐⭐⭐

**هدف:** انتخاب دقیق‌ترین انتخابگر برای هر هدف (کلاس، چند کلاس با هم، عنصر + کلاس، id، گروهی).

**صورت مسئله:** صفحه اول فروشگاه «مداد» ([`starter/ex-3.html`](starter/ex-3.html)) آماده است. طراح شش خواسته دارد و اجازه تغییر HTML را نداده است.

**الزامات (هر کدام دقیقاً یک قانون):**

1. همه عنصرهای دارای کلاس `center` وسط‌چین شوند.
2. فقط **پاراگراف‌های** دارای کلاس `large` اندازه `22px` بگیرند.
3. فقط عنصری که **هم** `center` و **هم** `large` است قرمز شود (راهنمایی: دو کلاس را بدون فاصله پشت هم بنویسید: `.center.large`).
4. فقط شماره تلفن آبی شود.
5. `h2` و `h3` با یک قانون بنفش شوند.
6. همه عنصرهای `large` (چه `p` چه `div`) پررنگ شوند.

**خروجی مورد انتظار:** فقط جمله «تخفیف ویژه...» قرمز است؛ «ساعت کار» پررنگ است ولی درشت نشده.

---

## اشتباه‌های رایج این مبحث

- جا انداختن نقطه قبل از نام کلاس (`tip {` به جای `.tip {`) یا `#` قبل از id.
- فاصله گذاشتن در `p.note` (نوشتن `p .note` معنای کاملاً دیگری دارد: «note داخل p»).
- استفاده از یک id برای چند عنصر؛ id در هر صفحه باید یکتا باشد، برای تکرار از کلاس استفاده کنید.
- فراموش کردن ویرگول در انتخابگر گروهی (`h2 h3` یعنی «h3 داخل h2»، نه «هر دو»).
