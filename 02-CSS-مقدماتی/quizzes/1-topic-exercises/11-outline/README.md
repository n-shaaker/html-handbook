# مبحث ۱۱ — خط دور (Outline)

درس مرتبط: [خط دور (Outline)](../../../pages/13-outline.html)

---

## تمرین ۱ — outline فضا نمی‌گیرد ⭐

**هدف:** دیدن فرق border (جزو جعبه) و outline (بیرون جعبه، بدون فضا).

**صورت مسئله:** در [`starter/ex-1.html`](starter/ex-1.html) سه جعبه زرد با متنی زیر هر کدام داریم.

**الزامات:**

- هر سه جعبه `width: 250px`، `padding` و پس‌زمینه زرد روشن داشته باشند.
- جعبه دوم `border` هشت‌پیکسلی نارنجی بگیرد.
- جعبه سوم `outline` هشت‌پیکسلی نارنجی با `outline-offset: 4px` بگیرد.
- در DevTools عرض جعبه دوم و سوم را بخوانید و مقایسه کنید.

**خروجی مورد انتظار:** جعبه border عرض ۲۸۶ دارد (۲۵۰ + ۲۰ + ۱۶) ولی جعبه outline همان ۲۷۰ است؛ outline روی متن‌های اطراف کشیده می‌شود.

---

## تمرین ۲ — فوکوس فرم جستجو ⭐⭐

**هدف:** طراحی حالت فوکوس صفحه‌کلید با `:focus-visible`، `outline` و `outline-offset`.

**صورت مسئله:** فرم جستجوی فروشگاه ([`starter/ex-2.html`](starter/ex-2.html)) برای کاربرانی که با Tab کار می‌کنند، فوکوس واضحی ندارد.

**الزامات:**

- فیلد جستجو `padding`، کادر خاکستری و گوشه گرد داشته باشد.
- دکمه پس‌زمینه فیروزه‌ای، متن سفید، بدون کادر و با گوشه گرد باشد.
- فیلد و دکمه در `:focus-visible` یک outline سه‌پیکسلی نارنجی با فاصله `2px` داشته باشند (یک قانون گروهی).
- هیچ‌جا `outline: none` ننویسید.

**خروجی مورد انتظار:** با Tab زدن، دور فیلد و بعد دکمه یک خط نارنجی واضح دیده می‌شود.

---

## تمرین ۳ — پیدا کردن مقصر با outline ⭐⭐⭐

**هدف:** استفاده از outline برای اشکال‌یابی چیدمان، بدون به هم زدن اندازه‌ها.

**صورت مسئله:** گالری عکس ([`starter/ex-3.css`](starter/ex-3.css)) اسکرول افقی دارد و صاحب سایت نمی‌داند چرا. دو عنصر از ستون `600px` بیرون زده‌اند.

**الزامات:**

- موقتاً قانون `* { outline: 1px solid red; }` را بالای فایل بگذارید و دو عنصر مقصر را پیدا کنید.
- هر دو را طوری درست کنید که هرگز از ستون بیرون نزنند (تصویر نسبت ابعادش را حفظ کند).
- قانون اشکال‌یابی را پاک نکنید؛ داخل توضیح بگذارید تا غیرفعال شود.
- در یک توضیح بنویسید چرا برای اشکال‌یابی outline بهتر از border است.

**خروجی مورد انتظار:** اسکرول افقی از بین رفته و فایل یک بخش «اشکال‌یابی (غیرفعال)» دارد.

---

## اشتباه‌های رایج این مبحث

- نوشتن `outline: none` برای «زشت نبودن» و جایگزین نگذاشتن؛ کاربر صفحه‌کلید گم می‌شود.
- انتظار تنظیم یک ضلع outline (`outline-top` وجود ندارد).
- استفاده از `:focus` به جای `:focus-visible` و دیدن outline بعد از هر کلیک ماوس.
- استفاده از border برای اشکال‌یابی؛ border اندازه جعبه‌ها را عوض می‌کند و خودش مشکل تازه می‌سازد.
