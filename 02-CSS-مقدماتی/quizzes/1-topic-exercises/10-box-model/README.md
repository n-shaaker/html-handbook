# مبحث ۱۰ — مدل جعبه‌ای (Box Model)

درس مرتبط: [مدل جعبه‌ای (Box Model)](../../../pages/12-boxmodel.html)

---

## تمرین ۱ — محاسبه عرض واقعی ⭐

**هدف:** محاسبه عرض دیده‌شده و کل فضای یک جعبه از روی width، padding، border و margin.

**صورت مسئله:** فایل‌های [`starter/ex-1.html`](starter/ex-1.html) و [`starter/ex-1.css`](starter/ex-1.css) آماده‌اند. **کد را تغییر ندهید.**

**الزامات:**

- جدول [`starter/ex-1-answers.md`](starter/ex-1-answers.md) را برای سه جعبه پر کنید.
- برای هر جعبه محاسبه را در یک خط بنویسید (مثلاً `۳۰۰ + ۴۰ + ۱۰`).
- **بعد از** محاسبه، با DevTools (تب Computed) جواب‌هایتان را بررسی کنید.

**خروجی مورد انتظار:** جدول کامل با محاسبه. جعبه C به خاطر `box-sizing: border-box` با دو جعبه دیگر فرق دارد.

---

## تمرین ۲ — دو پلن هم‌اندازه ⭐⭐

**هدف:** استفاده از `box-sizing: border-box` تا عدد width همان عرض دیده‌شده باشد.

**صورت مسئله:** یک شرکت میزبانی وب دو پلن دارد ([`starter/ex-2.html`](starter/ex-2.html)). پلن حرفه‌ای padding و کادر ضخیم‌تری دارد، ولی هر دو کارت باید **دقیقاً** هم‌عرض دیده شوند.

**الزامات:**

- هر دو پلن `width: 300px` و فاصله پایین داشته باشند.
- پلن پایه `padding: 16px` و کادر یک‌پیکسلی خاکستری داشته باشد.
- پلن حرفه‌ای `padding: 28px` و کادر چهارپیکسلی نارنجی داشته باشد.
- با یک قانون `*` برای همه عنصرها `box-sizing: border-box` بگذارید.

**خروجی مورد انتظار:** لبه چپ دو کارت دقیقاً زیر هم است و هر دو در DevTools عرض ۳۰۰ نشان می‌دهند.

---

## تمرین ۳ — جعبه‌ای که از والد بیرون زده ⭐⭐⭐

**هدف:** تشخیص و رفع بیرون‌زدگی جعبه `width: 100%` که padding و border دارد.

**صورت مسئله:** فرم خبرنامه آموزشگاه ([`starter/ex-3.css`](starter/ex-3.css)) یک ایراد عجیب دارد: پیام آبی و فیلد ایمیل از سمت چپ کادر خاکستری بیرون زده‌اند.

**الزامات:**

- با DevTools حساب کنید پیام آبی چند پیکسل از والدش پهن‌تر است و در یک خط توضیح در CSS بنویسید.
- مشکل را **بدون** تغییر width، padding و border حل کنید.
- فیلد ایمیل هم دقیقاً هم‌عرض پیام آبی شود.

**خروجی مورد انتظار:** پیام و فیلد کاملاً داخل کادر خاکستری‌اند. (پیام قبلاً ۴۴ پیکسل پهن‌تر بود: ۲۰ + ۲۰ padding و ۲ + ۲ border.)

---

## اشتباه‌های رایج این مبحث

- فراموش کردن اینکه در حالت پیش‌فرض، padding و border به width **اضافه** می‌شوند.
- جمع زدن فقط یک طرف padding یا border؛ هر دو طرف را حساب کنید.
- اضافه کردن margin به عرض دیده‌شده؛ margin جزو فضای اشغال‌شده است ولی جزو خود جعبه (رنگ‌دار) نیست.
- انتظار اینکه `border-box` margin را هم شامل شود؛ نمی‌شود.
