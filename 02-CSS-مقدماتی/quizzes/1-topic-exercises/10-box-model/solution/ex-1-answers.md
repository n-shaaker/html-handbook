# پاسخ تمرین ۱

| جعبه | عرض محتوا | عرض دیده‌شده (تا لبه بیرونی border) | کل فضای افقی (با margin) |
| --- | :---: | :---: | :---: |
| A | ۳۰۰ | ۳۵۰ | ۳۷۰ |
| B | ۲۰۰ | ۲۶۴ | ۲۹۴ |
| C | ۲۵۰ | ۳۰۰ | ۳۲۰ |

- **A** (حالت پیش‌فرض `content-box`): ۳۰۰ + (۲۰ + ۲۰) + (۵ + ۵) = ۳۵۰؛ با margin: ۳۵۰ + ۱۰ + ۱۰ = ۳۷۰.
- **B**: padding راست و چپ ۳۰ است (مقدار دوم)، پس ۲۰۰ + ۶۰ + ۴ = ۲۶۴؛ margin راست و چپ ۱۵: ۲۶۴ + ۳۰ = ۲۹۴.
- **C** (`border-box`): عدد `width` همان عرض دیده‌شده است: ۳۰۰. محتوا: ۳۰۰ − ۴۰ − ۱۰ = ۲۵۰؛ با margin: ۳۲۰.

برای بررسی: در DevTools روی هر جعبه کلیک کنید و نمودار مدل جعبه را در تب Computed ببینید.
