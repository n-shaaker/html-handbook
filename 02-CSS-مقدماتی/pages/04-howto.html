۴) سه روش افزودن CSS به HTML

در این پروژه فقط از روش External استفاده شده است. روش‌های Internal و Inline را در بلوک‌های کد می‌بینید؛ نتیجه زنده‌شان با کلاس‌هایی در فایل خارجی howto.css شبیه‌سازی شده تا صفحه بدون CSS داخلی یا Inline بماند.

روش ۱: External (فایل جداگانه) — بهترین روش

در این روش، قانون‌های CSS را در فایلی با پسوند .css می‌نویسیم و با تگ link داخل head به صفحه وصل می‌کنیم. مرورگر آن فایل را جداگانه می‌خواند و قانون‌هایش را روی HTML اعمال می‌کند. چون فایل جداست، چند صفحه می‌توانند به همان یک فایل لینک شوند و ظاهر مشترک داشته باشند. 

<head>
  <link rel="stylesheet" href="../css/demos/howto.css">
</head>
/* فایل css/demos/howto.css */
.demo-external {
  color: #c2185b;
  font-weight: bold;
}

این متن از فایل howto.css رنگ گرفته است.

روش ۲: Internal (داخل تگ style)

در این روش، قانون‌های CSS را داخل تگ style در بخش head همان صفحه می‌نویسیم. مرورگر این قانون‌ها را فقط برای همان سند می‌خواند. انتخابگر و آکولاد مثل فایل خارجی نوشته می‌شوند؛ تفاوت فقط در محل قرار گرفتن کد است. این روش وقتی مناسب است که ظاهر فقط به یک صفحه تعلق دارد و قرار نیست در صفحه‌های دیگر تکرار شود. 

<head>
  <style>
    .demo-internal {
      color: purple;
      font-weight: bold;
    }
  </style>
</head>

این متن ظاهر نمونه Internal را نشان می‌دهد (در این پروژه از فایل خارجی آمده).

روش ۳: Inline (روی خود تگ)

در این روش، تعریف‌ها را مستقیم در ویژگی style خود تگ می‌نویسیم. چون ظاهر به همان یک عنصر چسبیده است، انتخابگر و آکولاد لازم نیست و فقط جفت‌های ویژگی و مقدار، جدا شده با نقطه‌ویرگول، نوشته می‌شوند. این روش ظاهر را در میان HTML پخش می‌کند و برای پروژه‌ای که چند صفحه دارد نگهداری‌اش دشوار می‌شود. 

<p style="color: green; font-size: 18px;">متن سبز</p>

متن سبز

اگر چند روش با هم تداخل داشته باشند؟

<p class="demo-external" style="color: green;">کدام رنگ برنده است؟</p>

کدام رنگ برنده است؟

در صفحه واقعی، استایل Inline از قانون‌های فایل External و تگ style قوی‌تر است، پس متن سبز می‌شود؛ ولی font-weight: bold فایل External هنوز اعمال می‌شود، چون Inline آن را تغییر نداده است. بین External و Internal تفاوتی در قدرت نیست: اگر انتخابگرها هم‌قدرت باشند، قانونی که دیرتر خوانده شده (پایین‌تر در صفحه آمده) برنده است. پس ترتیب link و style در head مهم است. به همین رفتار «آبشاری» (Cascading) می‌گویند.

روش کجا نوشته می‌شود؟ چه زمانی؟
External فایل .css جدا همیشه برای پروژه واقعی؛ یک فایل برای همه صفحه‌ها
Internal تگ style در head وقتی فقط یک صفحه ظاهر خاص دارد
Inline attribute style روی تگ به‌ندرت؛ برای تست سریع (و در قالب ایمیل‌های HTML)

چرا External بهترین است؟ یک فایل CSS به همه صفحه‌ها لینک می‌شود؛ با تغییر آن، ظاهر کل سایت عوض می‌شود. مرورگر هم فایل را یک بار دانلود و در حافظه (cache) نگه می‌دارد، پس صفحه‌های بعدی سریع‌تر باز می‌شوند. استایل Inline برعکس، HTML را شلوغ می‌کند، قابل استفاده دوباره نیست و تغییرش با CSS معمولی سخت است.

اشتباه رایج: مسیر غلط در href. اگر فایل CSS در پوشه css/demos است، از داخل pages باید بنویسید ../css/demos/howto.css (../ یعنی یک پوشه بیرون).
فراموش کردن rel="stylesheet" در تگ link هم باعث می‌شود فایل CSS اصلاً اعمال نشود.
نوشتن تگ <style> در فایل .css هم غلط است؛ فایل CSS فقط قانون‌های CSS دارد، نه تگ HTML.

تمرین: برای صفحه معرفی خودتان یک فایل css/style.css بسازید، آن را با link وصل کنید و رنگ تیترها را تغییر دهید. بعد عمداً مسیر را غلط بنویسید و ببینید چه اتفاقی می‌افتد.
