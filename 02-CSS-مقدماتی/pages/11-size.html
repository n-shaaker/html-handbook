۱۱) عرض، ارتفاع و واحدها (px / em / rem)

به طور پیش‌فرض (width: auto و height: auto) یک عنصر بلوکی مثل div کل عرض در دسترس والدش را می‌گیرد و ارتفاعش به اندازه محتوا، به‌اضافه padding و border، تنظیم می‌شود. با width و height می‌توان این اندازه را عوض کرد. بعد از هر عدد طول، به‌جز صفر، باید واحد نوشت؛ مثل 220px یا 1.5rem. اگر واحد جا بیفتد، مرورگر آن تعریف را نادیده می‌گیرد.

یادآوری — Block و Inline

Block: از خط تازه · معمولاً کل عرض (مثل div، p). Inline: همان خط کنار متن · فقط به‌اندازه محتوا (مثل span، a). روی inline، width/height معمولاً اثر ندارد.

عرض و ارتفاع با پیکسل و درصد

.fixed   { width: 220px; height: 80px; }   /* اندازه ثابت */
.percent { width: 50%; }                    /* نصف عرض والد */
.max     { width: 100%; max-width: 400px; } /* حداکثر ۴۰۰ پیکسل */
۲۲۰ در ۸۰ پیکسل
۵۰٪ عرض والد
در صفحه بزرگ ۴۰۰ پیکسل، در موبایل کوچک‌تر

پنجره مرورگر را کوچک کنید: جعبه اول ثابت می‌ماند (و در صفحه خیلی باریک بیرون می‌زند)، ولی جعبه سوم خودش را با صفحه کوچک می‌کند. برای همین max-width برای موبایل بهتر از width ثابت است.

ویژگی کاربرد
width ، height اندازه مشخص (پیش‌فرض: auto)
max-width ، max-height بزرگ‌تر از این نشود (مثل عرض ستون محتوای سایت)
min-width ، min-height کوچک‌تر از این نشود؛ ولی اگر محتوا بیشتر بود، بزرگ‌تر شود

واحدهای اندازه: px ، em ، rem ، %

سه واحدی که خیلی می‌بینید px، em و rem هستند. فرق اصلی‌شان این است که هر کدام نسبت به چه چیزی حساب می‌شوند:

واحد یعنی چه؟ مناسب برای
px پیکسل؛ اندازه ثابت حاشیه نازک، سایه، اندازه دقیق تصویر
em نسبت به اندازه قلم عنصر والد وقتی برای font-size به کار رود. در ویژگی‌هایی مثل padding و margin، نسبت به اندازه قلم خود عنصر حساب می‌شود. padding دکمه که با فونتش بزرگ شود
rem نسبت به فونت ریشه (html)؛ معمولاً 1rem = 16px فونت، فاصله‌ها، پدینگ کلی صفحه
% درصدی از اندازه والد عرض ستون، نوار پیشرفت

ریشه (html) در مرورگر معمولاً فونت ۱۶ پیکسل دارد. پس 1rem = 16px، 1.5rem = 24px، 2rem = 32px. اگر کاربر در تنظیمات مرورگر فونت را بزرگ کند، همهٔ remها هم بزرگ می‌شوند؛ px ثابت می‌ماند.

مثال ۱: px — اندازه ثابت

واحد px اندازه را به پیکسل CSS ثابت می‌کند. عدد ۱۲ یعنی دوازده پیکسل، چه قلم والد بزرگ باشد چه کوچک. برای همین اگر بعداً اندازه قلم صفحه را عوض کنید، متنی که با px نوشته شده همان‌قدر می‌ماند و با تنظیمات درشت‌نمایی قلم کاربر هم بزرگ نمی‌شود. 

.px12 { font-size: 12px; }
.px16 { font-size: 16px; }
.px24 { font-size: 24px; }
.px32 { font-size: 32px; }

۱۲ پیکسل — ریز

۱۶ پیکسل — معمولی مرورگر

۲۴ پیکسل — تیتر کوچک

۳۲ پیکسل — تیتر بزرگ

مثال ۲: rem — نسبت به ریشه

rem یعنی «root em». همیشه نسبت به فونت تگ html حساب می‌شود، نه نسبت به پدر. برای همین قابل پیش‌بینی است. 

.rem-1   { font-size: 1rem; }     /* ۱۶px */
.rem-125 { font-size: 1.25rem; }  /* ۲۰px */
.rem-15  { font-size: 1.5rem; }   /* ۲۴px */
.rem-2   { font-size: 2rem; }     /* ۳۲px */
۱rem — متن معمولی
۱٫۲۵rem — کمی بزرگ‌تر
۱٫۵rem — تیتر بخش
۲rem — تیتر اصلی

جدول تبدیل سریع (با ریشه ۱۶ پیکسل): 0.5rem=8px · 0.75rem=12px · 1rem=16px · 1.25rem=20px · 1.5rem=24px · 2rem=32px

مثال ۳: em در برابر rem

پدر اینجا فونت ۲۰ پیکسل دارد. 1.5em می‌شود ۳۰ پیکسل (۱٫۵ × ۲۰)، ولی 1.5rem می‌شود ۲۴ پیکسل (۱٫۵ × ۱۶) — پدر را نادیده می‌گیرد. 

.em-parent { font-size: 20px; }

.em-child  { font-size: 1.5em; }   /* ۱.۵ × ۲۰ = ۳۰px */
.rem-child { font-size: 1.5rem; }  /* ۱.۵ × ۱۶ = ۲۴px */
متن پدر (۲۰ پیکسل)

فرزند با 1.5em ← ۳۰ پیکسل (قرمز)

فرزند با 1.5rem ← ۲۴ پیکسل (آبی)

مثال ۴: تله em در عنصرهای تودرتو

اگر هر سطح font-size: 1.2em بگیرد، اندازه‌ها در هم ضرب می‌شوند: ۱۶ → ۱۹٫۲ → ۲۳ → ۲۷٫۶ ... و متن هر سطح درشت‌تر می‌شود. 

.nest { font-size: 1.2em; }
سطح ۱ (۱٫۲em)
سطح ۲ (۱٫۲ × ۱٫۲)
سطح ۳ — هر بار درشت‌تر!

اشتباه رایج: نوشتن li { font-size: 1.2em; } وقتی فهرست داخل فهرست دارید. برای فونت معمولاً rem امن‌تر است چون زنجیره‌ای بزرگ نمی‌شود.

مثال ۵: padding با em — دکمه متناسب

اینجا فقط font-size فرق دارد؛ padding: 0.5em 1em روی هر سه دکمه یکی است. چون em نسبت به فونت خود دکمه است، دکمه بزرگ‌تر، فاصله داخلی بزرگ‌تری هم می‌گیرد. 

.btn {
  padding: 0.5em 1em;
  border-radius: 0.3em;
}

.btn-sm { font-size: 12px; }
.btn-md { font-size: 16px; }
.btn-lg { font-size: 24px; }

اگر padding را با px می‌نوشتید (8px 16px)، دکمه بزرگ فقط متنش درشت می‌شد و دورش تنگ می‌ماند. با em دکمه «با فونتش» رشد می‌کند.

مثال ۶: کارت محصول با rem

فونت و فاصله‌ها همه با rem: یک واحد مشترک، قابل پیش‌بینی، و سازگار با تنظیمات دسترسی کاربر. 

.card {
  max-width: 280px;
  padding: 1rem;          /* ۱۶px */
  margin-bottom: 0.75rem; /* ۱۲px */
  border-radius: 0.5rem;  /* ۸px */
}

.card-title { font-size: 1.25rem; }  /* ۲۰px */
.card-text  { font-size: 1rem; }     /* ۱۶px */
.card-price { font-size: 1.5rem; }   /* ۲۴px */

مثال ۷: یک عرض، سه واحد

هر سه جعبه حدود ۲۰۰ پیکسل عرض دارند — فقط واحد نوشتن فرق کرده. با فونت پیش‌فرض ۱۶ پیکسل، 12.5em و 12.5rem هر دو ۲۰۰ پیکسل می‌شوند. 

.compare-px  { width: 200px; }
.compare-em  { width: 12.5em; }    /* ۱۲.۵ × فونت خود عنصر */
.compare-rem { width: 12.5rem; }   /* ۱۲.۵ × فونت ریشه */

کاربرد واقعی: تصویر واکنش‌گرا

.article-img {
  max-width: 100%;   /* هیچ‌وقت از ظرفش پهن‌تر نشود */
  height: auto;      /* نسبت طول و عرض حفظ شود */
}

این دو خط تقریباً در همه سایت‌ها برای تصویرها نوشته می‌شود. نوشتن width و height واقعی تصویر در HTML هم کمک می‌کند مرورگر قبل از لود شدن تصویر جایش را نگه دارد.

چه واحدی را کی بنویسم؟

می‌خواهم ... واحد پیشنهادی
اندازه فونت تیتر و متن rem
فاصله و پدینگ کلی صفحه / کارت rem
padding دکمه‌ای که چند اندازه دارد em (با فونت دکمه بزرگ می‌شود)
حاشیه ۱ پیکسلی، سایه، آیکن ثابت px
عرض ستون نسبت به والد % یا max-width با px/rem
حداقل ارتفاع به اندازه صفحه min-height: 100vh

قاعده ساده برای شروع این دوره: فونت و فاصله‌ها با rem، عرض‌ها با % یا max-width، جزئیات خیلی کوچک با px. واحد vh که در جدول آخر آمده، یک‌صدم ارتفاع پنجره مرورگر است. min-height: 100vh یعنی جعبه دست‌کم به اندازه تمام ارتفاع پنجره بلند شود. در صفحه موبایل، نوار آدرس ممکن است این ارتفاع را تغییر دهد. واحدهای دقیق‌تر، از جمله vw و dvh، در درس واحدها در دوره میانی آمده است.

اشتباه رایج: فاصله بین عدد و واحد — 20 px اشتباه است؛ درستش 20px است. همچنین جا انداختن واحد: width: 20 نامعتبر است و مرورگر آن خط را نادیده می‌گیرد (فقط 0 بدون واحد مجاز است).
دادن height ثابت به جعبه‌ای که متن دارد؛ در موبایل یا با متن بیشتر، متن بیرون می‌زند — از min-height استفاده کنید.
دادن width به عنصرهای درون‌خطی مثل span؛ روی آن‌ها اثری ندارد مگر با display: block یا inline-block.
height: 50% وقتی والد ارتفاع مشخصی ندارد کار نمی‌کند.

تمرین الف: یک کارت محصول با max-width: 300px بسازید که تیترش 1.25rem، متنش 1rem و قیمتش 1.5rem باشد؛ پدینگ کارت را هم با rem بنویسید.

تمرین ب: سه دکمه کوچک / متوسط / بزرگ بسازید که فقط font-sizeشان فرق کند و padding همه با em باشد. ببینید با بزرگ شدن فونت، فاصله داخلی هم بزرگ می‌شود.

تمرین ج: یک فهرست تودرتو با li { font-size: 1.2em; } بسازید و ببینید متن چطور درشت می‌شود؛ بعد همان را با rem عوض کنید و فرق را مقایسه کنید.
