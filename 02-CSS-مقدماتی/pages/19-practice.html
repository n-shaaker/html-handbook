۱۹) تمرین جمع‌بندی: ظاهر دادن به صفحه معرفی شخصی

در این تمرین، صفحه معرفی‌ای را که در جلسه‌های HTML ساخته‌اید با یک فایل CSS خارجی ظاهر می‌دهید. هدف این است که ساختار HTML دست‌نخورده بماند و رنگ، فاصله، فونت، جدول و حالت فوکوس همگی از همان فایل بیایند. هر مرحله را در مرورگر امتحان کنید تا ببینید همان قانون دقیقاً کدام بخش را عوض کرده است.

  1. یک پوشه css بسازید و فایل‌های CSS را داخلش بگذارید (مثل همین پروژه).
  2. با تگ link فایل‌ها را به صفحه HTML وصل کنید.
  3. اولین قانون فایل را * { box-sizing: border-box; } بگذارید (درس ۱۲).
  4. برای body یک فونت فارسی (مثلاً Vazirmatn به صورت لوکال، یا Tahoma) با فونت جایگزین، رنگ پس‌زمینه روشن و line-height: 1.8 بگذارید.
  5. به h1 و h2 رنگ و یک border-bottom بدهید.
  6. عکس پروفایل را با عرض و ارتفاع برابر، object-fit: cover و border-radius: 50% دایره‌ای کنید.
  7. لینک‌های منو را بدون خط زیر و با رنگ متفاوت در حالت‌های :hover و :focus-visible بنویسید (لینک‌های داخل متن خط زیر داشته باشند).
  8. جدول پروژه‌ها را با caption، border-collapse و ردیف‌های راه‌راه مرتب کنید.
  9. محتوای صفحه را با max-width: 800px و margin: 0 auto وسط صفحه بیاورید.
  10. به جای left و right تا جای ممکن از مقدارها و ویژگی‌های منطقی (start، end، margin-inline، border-inline-start) استفاده کنید.
  11. صفحه را در عرض موبایل (DevTools، کلید F12) و فقط با صفحه‌کلید (کلید Tab) امتحان کنید.

یک شروع نمونه برای فایل CSS

/* ===== عمومی ===== */
* {
  box-sizing: border-box;
}

body {
  font-family: Tahoma, Arial, sans-serif;
  background-color: #f7f9fc;
  color: #222;
  line-height: 1.8;
  max-width: 800px;
  margin: 0 auto;
  padding: 0 16px;
}

img {
  max-width: 100%;
  height: auto;
}

/* ===== تیترها ===== */
h1 {
  color: #1a3a5c;
}

h2 {
  color: #0b6e4f;
  border-bottom: 2px solid #d9e2ec;
  padding-bottom: 6px;
}

/* ===== عکس پروفایل ===== */
img.profile {
  width: 160px;
  height: 160px;
  object-fit: cover;
  border-radius: 50%;
  border: 4px solid #1a3a5c;
}

/* ===== منو ===== */
.site-nav a {
  color: #1a3a5c;
  text-decoration: none;
  padding: 6px 10px;
}

.site-nav a:hover,
.site-nav a:focus-visible {
  color: #0b6e4f;
  background-color: #e8f4fd;
}

/* ===== جدول ===== */
table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  border: 1px solid #d9e2ec;
  padding: 8px;
  text-align: start;
}

tbody tr:nth-child(even) {
  background-color: #f2f5f9;
}

این فقط یک شروع است؛ رنگ‌ها، فونت و فاصله‌ها را به سلیقه خودتان تغییر دهید. بعد از هر تغییر صفحه را در مرورگر بارگذاری کنید (F5) و اگر چیزی اعمال نشد، با DevTools (کلید F12) ببینید قانون شما خوانده شده یا قانون دیگری روی آن نوشته شده است.

چک‌لیست تحویل: بدون CSS داخلی و Inline؛ همه رنگ‌های متن با پس‌زمینه کنتراست کافی دارند؛ همه تصویرها alt دارند؛ صفحه در عرض موبایل اسکرول افقی ندارد؛ با کلید Tab جای فوکوس همیشه دیده می‌شود.
