۱۳) خط دور (Outline)

outline خطی است که دور عنصر، بیرون از حاشیه، کشیده می‌شود. برخلاف border، این خط در مدل جعبه‌ای جا نمی‌گیرد: اضافه یا حذف کردنش عرض و ارتفاع جعبه را عوض نمی‌کند و عنصرهای کناری را هل نمی‌دهد. چون فضا اشغال نمی‌کند، ممکن است روی عنصرهای مجاور رسم شود. برای همین در طراحی دائمی کارت و جدول معمولاً از border استفاده می‌شود و outline را برای نشان دادن فوکوس یا موقتاً برای دیدن مرز یک جعبه هنگام اشکال‌یابی به کار می‌برند. 

.box {
  border: 2px solid #1a3a5c;
  outline: 3px dashed tomato;   /* ضخامت، سبک، رنگ — مثل border */
  outline-offset: 6px;          /* فاصله outline از border */
  margin: 16px;
  padding: 10px;
}
حاشیه سرمه‌ای و outline خط‌چین قرمز
border outline
جزو مدل جعبه‌ای است و فضا می‌گیرد فضا نمی‌گیرد و روی عنصرهای اطراف کشیده می‌شود
هر طرف را جدا می‌شود تنظیم کرد (border-top و ...) همیشه هر چهار طرف با هم است
برای ظاهر طراحی (کارت، جدول، دکمه) بیشتر برای نشان دادن «فوکوس» و برای اشکال‌یابی

ویژگی‌های جداگانه هم وجود دارند: outline-width، outline-style، outline-color و outline-offset. مثل border، بدون سبک (style) هیچ outlineای دیده نمی‌شود.

کاربرد اصلی: نشان دادن فوکوس صفحه‌کلید

وقتی کاربر با کلید Tab بین لینک‌ها و دکمه‌ها جابه‌جا می‌شود، مرورگر دور عنصر فعلی یک outline می‌کشد. با شبه‌کلاس :focus-visible می‌توانیم ظاهر این خط را هماهنگ با طراحی سایت کنیم. مرورگر این حالت را فقط وقتی فعال می‌کند که نشان دادن فوکوس لازم باشد: برای دکمه و لینک فقط با صفحه‌کلید (نه با کلیک ماوس)، و برای کادرهای تایپ متن همیشه، چون کاربر باید ببیند کجا تایپ می‌کند: 

.search-btn:focus-visible,
.search-input:focus-visible {
  outline: 3px solid #e6a700;
  outline-offset: 2px;
}

روی جعبه نتیجه کلیک کنید و چند بار Tab بزنید تا خط زرد دور کادر جستجو و دکمه را ببینید.

اشتباه رایج: برداشتن outline دکمه‌ها و لینک‌ها با outline: none، چون «زشت» به نظر می‌رسد. کسانی که با صفحه‌کلید (Tab) کار می‌کنند، به این خط نیاز دارند تا بفهمند کجای صفحه هستند. اگر ظاهر پیش‌فرض را دوست ندارید، آن را حذف نکنید؛ جایگزین کنید (مثل نمونه بالا).

تمرین: برای لینک‌های منوی صفحه معرفی‌تان یک استایل :focus-visible با outline ۲ پیکسلی و outline-offset: 3px بنویسید و فقط با کلید Tab در صفحه حرکت کنید.
