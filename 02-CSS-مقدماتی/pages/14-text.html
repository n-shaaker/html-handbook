۱۴) متن (Text)

این ویژگی‌ها ظاهر خود نوشته را تنظیم می‌کنند: رنگ، تراز، خط روی متن و فاصله سطرها. color رنگ خود نویسه‌ها را عوض می‌کند. text-align مشخص می‌کند خط‌ها در عرض جعبه از کدام سمت تراز شوند، وسط بنشینند، یا از هر دو طرف صاف شوند. text-decoration خطی روی متن می‌کشد یا خط موجود را برمی‌دارد؛ مثل زیرخط یا خط روی قیمت قبلی. text-transform شکل حروف لاتین را عوض می‌کند، مثلاً همه را بزرگ می‌نویسد، و روی حروف فارسی اثری ندارد. letter-spacing فاصله بین نویسه‌ها را زیاد یا کم می‌کند. line-height ارتفاع هر خط را نسبت به اندازه قلم تعیین می‌کند و هرچه بزرگ‌تر باشد، سطرها از هم بازتر می‌شوند. text-shadow سایه‌ای پشت متن می‌اندازد. در مقدار 2px 2px 4px #999 به ترتیب جابه‌جایی افقی، جابه‌جایی عمودی، میزان محو شدن و رنگ سایه آمده است. 

.t-color   { color: #0b6e4f; }
.t-center  { text-align: center; }
.t-justify { text-align: justify; }
.t-under   { text-decoration: underline; }
.t-strike  { text-decoration: line-through; }
.t-upper   { text-transform: uppercase; }
.t-space   { letter-spacing: 4px; }
.t-line    { line-height: 2.4; background-color: #f1f3f5; }
.t-shadow  { text-shadow: 2px 2px 4px #999; font-size: 22px; }

متن با سایه

دو نمونه انگلیسی با dir="ltr" در HTML چپ‌چین شده‌اند. جهت متن جزو محتواست و در HTML با dir تعیین می‌شود. CSS می‌تواند تراز را عوض کند، ولی زبان و جهت پایه متن را نباید فقط با text-align عوض کرد.

ویژگی مقدارهای رایج
text-align start (پیش‌فرض)، end، center، justify، right، left
text-decoration none، underline، line-through، overline
text-transform uppercase، lowercase، capitalize (فقط حروف لاتین)
line-height عدد بدون واحد مثل 1.8 (یعنی ۱.۸ برابر اندازه فونت)
text-indent تورفتگی خط اول پاراگراف، مثل 2em

نکته راست‌چین: مقدار پیش‌فرض text-align برابر start است؛ یعنی «از جایی که متن شروع می‌شود». در صفحه فارسی (dir="rtl") این یعنی راست و در صفحه انگلیسی یعنی چپ. پس به جای text-align: right بهتر است start بنویسید (و به جای left، مقدار end) تا اگر صفحه یا بخشی از آن انگلیسی شد، تراز خودبه‌خود درست شود.
برای حذف خط زیر لینک‌ها از text-decoration: none; استفاده می‌شود (درس ۱۶).

کاربرد واقعی: پاراگراف‌های یک مقاله

در متن بلند، line-height حدود ۲ برابر اندازه قلم، سطرها را از هم باز می‌کند و خواندن فارسی را راحت‌تر می‌کند. text-align: justify دو لبه پاراگراف را صاف می‌کند. تاریخ یا توضیح کوتاه را با text-align: end به انتهای جهت متن می‌بریم تا از خود مقاله جدا بماند. 

.article p {
  line-height: 2;            /* متن فارسی با فاصله خط بیشتر خواناتر است */
  text-align: justify;
  color: #333;               /* کمی روشن‌تر از سیاه، چشم را کمتر خسته می‌کند */
}

.article .meta {
  color: #666;
  font-size: 14px;
  text-align: end;           /* در صفحه فارسی: چپ */
}

کتاب‌خوانی فقط سرگرمی نیست؛ پژوهش‌ها نشان می‌دهد مطالعه منظم، تمرکز و دایره واژگان را تقویت می‌کند و حتی به خواب بهتر کمک می‌کند. اگر وقت کمی دارید، روزی بیست دقیقه مطالعه پیش از خواب شروع خوبی است.

نوشته شده در ۱۲ مهر — زمان مطالعه: ۳ دقیقه

اشتباه رایج: استفاده از letter-spacing برای متن فارسی؛ اتصال حروف فارسی به هم می‌خورد و خواندن سخت می‌شود. text-transform هم فقط روی حروف لاتین اثر دارد.
دادن line-height با واحد پیکسل (مثل 24px)؛ اگر بعداً اندازه فونت بزرگ شود، خط‌ها روی هم می‌افتند. عدد بدون واحد با اندازه فونت هماهنگ می‌ماند.
text-align: justify در ستون‌های خیلی باریک (مثل موبایل) فاصله‌های بزرگ و زشت بین کلمه‌ها می‌سازد.

تمرین: پاراگراف‌های صفحه معرفی‌تان را line-height: 2 و text-align: justify کنید و تاریخ زیر هر بخش را با text-align: end، رنگ خاکستری و فونت کوچک‌تر بنویسید.
