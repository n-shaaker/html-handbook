۱۶) لینک‌ها (Links)

لینک همان عنصر a است که کاربر را به نشانی دیگری می‌برد. مرورگر برای لینک چند حالت نگه می‌دارد و با شبه‌کلاس می‌توان برای هر حالت ظاهر جدا نوشت. :link لینکی است که در تاریخچه این مرورگر هنوز باز نشده. :visited لینکی است که قبلاً باز شده است. :hover وقتی فعال می‌شود که اشاره‌گر روی لینک باشد. :active همان لحظه کوتاهی است که دکمه ماوس یا انگشت هنوز روی لینک فشرده شده و رها نشده. این حالت‌ها در HTML نوشته نمی‌شوند؛ مرورگر خودش تشخیص می‌دهد کدام‌یک الان برقرار است. 

a:link    { color: #1a5fb4; }                          /* لینک دیده‌نشده */
a:visited { color: #7b2cbf; }                          /* لینکی که قبلاً باز شده */
a:hover   { color: #c92a2a; text-decoration: none; }   /* وقتی ماوس روی لینک است */
a:active  { color: #2b8a3e; }                          /* لحظه کلیک */

ماوس را روی این لینک ببرید و کلیک کنید: قوانین ارسال و مرجوعی کالا

عبارت‌هایی مثل :hover «شبه‌کلاس» (pseudo-class) هستند؛ یعنی حالتی از عنصر که در HTML نوشته نمی‌شود و مرورگر خودش تشخیص می‌دهد.
ترتیب نوشتن مهم است: اول :link، بعد :visited، بعد :hover، در آخر :active. چون این قانون‌ها هم‌قدرت‌اند، قانون پایین‌تر برنده است؛ اگر مثلاً :hover را قبل از :visited بنویسید، روی لینک‌های بازشده دیگر کار نمی‌کند. برای حفظ کردن: LoVe HAte.

حالت فوکوس صفحه‌کلید (:focus-visible)

کاربری که با کلید Tab در صفحه حرکت می‌کند، ماوس ندارد و :hover را نمی‌بیند. برای او حالت :focus-visible را هم طراحی کنید (درس ۱۳). جایش در ترتیب، کنار :hover است: :link، :visited، :hover و :focus-visible، :active.

ساخت دکمه از لینک

لینک به‌طور پیش‌فرض درون‌خطی است، زیرش خط دارد و پس‌زمینه نمی‌گیرد. با display: inline-block می‌توان به آن padding واقعی داد، با text-decoration: none خط زیر را برداشت و با رنگ پس‌زمینه آن را شبیه دکمه کرد. عنصر همچنان a است و با صفحه‌کلید هم قابل دسترسی می‌ماند؛ فقط ظاهر جعبه عوض شده است. 

.btn-link {
  display: inline-block;
  background-color: #0b6e4f;
  color: white;
  padding: 8px 18px;
  text-decoration: none;
  border-radius: 6px;
}

.btn-link:hover,
.btn-link:focus-visible {
  background-color: #1a3a5c;
}

.btn-link:focus-visible {
  outline: 3px solid #e6a700;
  outline-offset: 2px;
}
مشاهده نمونه‌کارها

کاربرد واقعی: منوی بالای سایت

منوی بالای سایت چند لینک کنار هم است که باید از متن معمولی جدا دیده شوند. پس‌زمینه تیره، رنگ روشن و حذف خط زیر، ناحیه کلیک را مشخص می‌کند. کلاس current لینک صفحه فعلی را متفاوت رنگ می‌کند تا کاربر بداند کجای سایت ایستاده است. 

.site-nav {
  background-color: #1a3a5c;
  padding: 8px;
}

.site-nav a {
  display: inline-block;
  color: white;
  text-decoration: none;
  padding: 8px 14px;
  border-radius: 4px;
}

.site-nav a:hover,
.site-nav a:focus-visible {
  background-color: #2f5f8f;
}

.site-nav a:focus-visible {
  outline: 3px solid #e6a700;
  outline-offset: 2px;
}

/* صفحه‌ای که الان در آن هستیم */
.site-nav a.current {
  background-color: white;
  color: #1a3a5c;
}
خانه محصولات وبلاگ تماس با ما

کلاس current به کاربر نشان می‌دهد کجای سایت است؛ aria-current="page" همین را به صفحه‌خوان‌ها (نرم‌افزار کاربران نابینا) می‌گوید. در دوره میانی منو را با فهرست و Flexbox کامل‌تر می‌سازیم.

اشتباه رایج: حذف خط زیر لینک‌های داخل متن پاراگراف‌ها. در منو و دکمه، شکل ظاهری نشان می‌دهد که قابل کلیک‌اند؛ ولی وسط متن، لینک بدون خط زیر فقط با رنگ از متن جدا می‌شود و بعضی کاربران آن را تشخیص نمی‌دهند.
برای :visited فقط ویژگی‌های رنگی (مثل color و background-color) کار می‌کنند؛ مرورگرها برای حفظ حریم خصوصی، بقیه ویژگی‌ها را در این حالت نادیده می‌گیرند.
متن لینک باید معنی‌دار باشد: «قوانین ارسال کالا» بهتر از «اینجا کلیک کنید» است.

تمرین: برای منوی صفحه معرفی‌تان (خانه، درباره من، نمونه‌کارها، تماس) یک نوار مثل نمونه بالا بسازید که حالت hover، focus-visible و صفحه فعلی را داشته باشد. فقط با کلید Tab آن را امتحان کنید.
