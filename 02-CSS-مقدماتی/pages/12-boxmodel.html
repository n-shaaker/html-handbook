۱۲) مدل جعبه‌ای (Box Model)

در CSS هر عنصر یک جعبه مستطیلی است. این جعبه از چهار لایه ساخته شده که از داخل به بیرون روی هم قرار می‌گیرند. مرورگر برای محاسبه جا، اول محتوا را اندازه می‌گیرد، بعد فاصله داخلی، بعد حاشیه، و در آخر فاصله بیرونی را به فضای اشغال‌شده اضافه می‌کند.

اجزای همین مدل در درس‌های قبل: width/height · padding · border · margin

  1. Content (محتوا): متن، تصویر یا عنصرهای داخل جعبه. width و height در حالت پیش‌فرض فقط همین لایه را اندازه می‌گیرند.
  2. Padding (فاصله داخلی): فضای بین محتوا و حاشیه. رنگ پس‌زمینه عنصر این لایه را هم می‌پوشاند.
  3. Border (حاشیه): خط دور جعبه. ضخامت آن به عرض و ارتفاع دیده‌شده اضافه می‌شود.
  4. Margin (فاصله بیرونی): فضای شفاف بین این جعبه و عنصرهای اطراف. جزو width حساب نمی‌شود.

رنگ پس‌زمینه عنصر زیر Content و Padding (و زیر border) دیده می‌شود، ولی Margin همیشه شفاف است. در نمایش بالا برای دیده شدن لایه‌ها به هر کدام رنگ جدا داده‌ایم. در مرورگر هم با F12 و انتخاب یک عنصر، همین نمودار را در بخش Computed ابزار DevTools می‌بینید.

محاسبه عرض واقعی (حالت پیش‌فرض مرورگر)

به طور پیش‌فرض (box-sizing: content-box)، width فقط عرض محتوا است و padding و border به آن اضافه می‌شوند:

div {
  width: 300px;
  padding: 20px;
  border: 5px solid gray;
  margin: 10px;
}
بخش محاسبه مقدار
Content width ۳۰۰
Padding ۲۰ + ۲۰ ۴۰
Border ۵ + ۵ ۱۰
عرض دیده‌شده ۳۰۰ + ۴۰ + ۱۰ ۳۵۰ پیکسل

box-sizing: border-box: محاسبه ساده‌تر

با border-box، عدد width شامل padding و border هم می‌شود و مرورگر فضای محتوا را خودش کم می‌کند. هر دو جعبه زیر width: 300px، padding: 20px و border: 5px دارند: 

.plan {
  width: 300px;
  max-width: 100%;
  padding: 20px;
  border: 5px solid #1a3a5c;
  margin-bottom: 10px;
  background-color: #e8f4fd;
}

.plan-content-box { box-sizing: content-box; }   /* عرض دیده‌شده: ۳۵۰ */
.plan-border-box  { box-sizing: border-box; }    /* عرض دیده‌شده: ۳۰۰ */
خط‌کش ۳۰۰ پیکسلی
content-box: ۳۵۰ پیکسل (از خط‌کش بیرون زده)
border-box: دقیقاً ۳۰۰ پیکسل

به همین دلیل بیشتر پروژه‌ها در اولین خط CSS این قانون را می‌نویسند تا همه عنصرها border-box شوند. این مجموعه هم با همین قانون در style.css شروع شده است: 

* {
  box-sizing: border-box;
}

اشتباه رایج: دادن width: 100% و padding به یک جعبه بدون border-box؛ جعبه از والدش بیرون می‌زند و اسکرول افقی در موبایل درست می‌کند.
حساب کردن margin جزو عرض جعبه؛ margin فاصله با بقیه است و در هیچ‌کدام از دو حالت جزو width نیست.

تمرین: جعبه‌ای با width: 200px ، padding: 15px و border: 2px solid black دارید. ۱) در حالت پیش‌فرض (content-box) عرض دیده‌شده چند پیکسل است؟ ۲) با border-box چطور؟ فضای محتوا چقدر می‌ماند؟ (پاسخ: ۱) ۲۰۰ + ۳۰ + ۴ = ۲۳۴ پیکسل. ۲) عرض دیده‌شده ۲۰۰ پیکسل و فضای محتوا ۲۰۰ − ۳۴ = ۱۶۶ پیکسل.)
