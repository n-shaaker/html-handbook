۱۵) فونت (Fonts)

فونت شکلی است که مرورگر با آن نویسه‌ها را رسم می‌کند. ویژگی font-family فهرست فونت‌های دلخواه را به ترتیب اولویت می‌گیرد. مرورگر از اول فهرست شروع می‌کند و اولین فونتی را به کار می‌برد که روی دستگاه کاربر نصب باشد یا قبلاً به صفحه معرفی شده باشد. اگر هیچ‌کدام پیدا نشود، آخرین نام باید یک خانواده عمومی باشد تا مرورگر دست‌کم یک قلم خوانا انتخاب کند.

نوع فونت و فونت جایگزین

body {
  font-family: Tahoma, Arial, sans-serif;
}

مرورگر اول Tahoma را امتحان می‌کند؛ اگر روی دستگاه کاربر نبود Arial، و اگر آن هم نبود یک فونت sans-serif. به این فهرست «فونت‌های جایگزین» (Fallback) می‌گویند. همیشه در آخر یک خانواده عمومی بنویسید. پنج خانواده عمومی: serif، sans-serif، monospace، cursive و fantasy. 

.f-serif { font-family: "Times New Roman", Times, serif; }
.f-sans  { font-family: Arial, Helvetica, sans-serif; }
.f-mono  { font-family: "Courier New", monospace; }

serif: letters have small strokes at the ends (Times New Roman)

sans-serif: clean letters without strokes (Arial)

monospace: all letters have the same width (Courier New)

سه خانواده عمومی را در نمونه بالا می‌بینید. serif در انتهای حروف زائده کوچک دارد، مثل Times. sans-serif همان حروف را بدون زائده رسم می‌کند، مثل Arial. monospace به هر نویسه عرض یکسان می‌دهد و برای کد مناسب است. برای متن فارسی روی صفحه معمولاً از خانواده بدون زائده استفاده می‌شود، مثل Vazirmatn یا Tahoma، چون در اندازه معمولی خواناتر می‌ماند.

اندازه، ضخامت و حالت

font-size اندازه قلم را تعیین می‌کند. با px اندازه ثابت می‌ماند. با rem اندازه نسبت به قلم ریشه (html) حساب می‌شود و با em، وقتی روی خود font-size باشد، نسبت به قلم عنصر والد. font-weight ضخامت را مشخص می‌کند: 400 یا normal وزن معمولی است و 700 یا bold وزن ضخیم. مرورگر فقط وزن‌هایی را دقیق نشان می‌دهد که آن فونت واقعاً داشته باشد. font-style: italic حالت کج را درخواست می‌کند. بسیاری از فونت‌های فارسی این حالت را ندارند و مرورگر فقط حروف را مایل می‌کشد، که معمولاً خوانا نیست. 

.f-px   { font-size: 24px; }    /* اندازه ثابت */
.f-rem  { font-size: 1.5rem; }  /* ۱.۵ برابر اندازه فونت ریشه (html) */
.f-em   { font-size: 1.5em; }   /* ۱.۵ برابر اندازه فونت والد */
.f-bold { font-weight: bold; }  /* یا عدد: 400 معمولی، 700 ضخیم */
.f-italic { font-style: italic; }

/* خلاصه: ضخامت، اندازه، نوع فونت */
.f-short { font: bold 20px Tahoma, sans-serif; }

نوشتن خلاصه font

px یا rem؟ اندازه فونت ریشه معمولاً ۱۶ پیکسل است، پس 1rem ≈ ۱۶ پیکسل. اگر کاربر فونت مرورگر را بزرگ کند، rem هم بزرگ می‌شود ولی px ثابت می‌ماند. em نسبت به والد است و در عنصرهای تودرتو ضرب می‌شود. مثال‌های بیشتر (دکمه با em، کارت با rem، تله تودرتو) در درس ۱۱ — واحدها آمده است.
در خلاصه font، اندازه و نوع فونت اجباری‌اند و باید آخر بیایند (اول اندازه، بعد نوع فونت).

اشتباه رایج: ننوشتن گیومه دور نام فونت‌هایی که فاصله دارند. درست: "Times New Roman". همچنین font-style: italic روی متن فارسی معمولاً زیبا و خوانا نیست (بیشتر فونت‌های فارسی حالت ایتالیک ندارند و مرورگر حروف را فقط کج می‌کند).

روش ۱: فونت اینترنتی (Google Fonts)

فونت‌هایی مثل Tahoma روی همه کامپیوترها نصب نیستند یا ظاهر ساده‌ای دارند. سایت fonts.google.com صدها فونت رایگان دارد (فونت‌های فارسی مثل Vazirmatn و Lalezar هم دارد) که مستقیم از اینترنت لود می‌شوند.

  1. به سایت fonts.google.com بروید و نام فونت را جستجو کنید (مثلاً Vazirmatn).
  2. روی فونت کلیک کنید، دکمه Get font و بعد Get embed code را بزنید.
  3. ضخامت‌هایی که لازم دارید را انتخاب کنید (مثلاً 400 برای معمولی و 700 برای ضخیم).
  4. کدهای link را کپی کنید و داخل head، قبل از فایل CSS خودتان بگذارید.
  5. در CSS با font-family از نام فونت استفاده کنید.
<head>
  <!-- ۱. اول فونت گوگل (دو خط preconnect اتصال به سرور فونت را زودتر شروع می‌کنند) -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;700&display=swap" rel="stylesheet">

  <!-- ۲. بعد فایل CSS خودمان -->
  <link rel="stylesheet" href="css/style.css">
</head>
body {
  font-family: "Vazirmatn", Tahoma, sans-serif;
}

h1 {
  font-family: "Lalezar", Tahoma, sans-serif;   /* یک فونت دیگر برای تیترها */
}

این متن با فونت Vazirmatn از گوگل نوشته شده است.

این متن Vazirmatn ضخیم (700) است.

این تیتر با فونت Lalezar است

در این صفحه برای اینکه فونت کل جزوه عوض نشود، همین font-familyها روی کلاس‌های جداگانه (f-google-vazir و f-google-lalezar در fonts.css) اعمال شده‌اند.

چند فونت با هم: اگر در سایت گوگل چند فونت انتخاب کنید، همه در یک link می‌آیند و با &family= از هم جدا می‌شوند: 

<link href="https://fonts.googleapis.com/css2?family=Lalezar&family=Vazirmatn:wght@400;700&display=swap" rel="stylesheet">

روش دیگر (@import): به جای link در HTML، می‌توانید آدرس را در اولین خط فایل CSS بنویسید: 

/* باید بالاترین خط فایل CSS باشد */
@import url("https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;700&display=swap");

body {
  font-family: "Vazirmatn", Tahoma, sans-serif;
}

اگر اینترنت قطع باشد، فونت گوگل لود نمی‌شود و مرورگر سراغ فونت بعدی (Tahoma) می‌رود. برای همین همیشه یک فونت جایگزین بنویسید. روش link سریع‌تر از @import است (چون مرورگر با @import تا خواندن فایل CSS صبر می‌کند و بعد سراغ فونت می‌رود) و پیشنهاد می‌شود.
بخش display=swap در آدرس یعنی تا فونت لود نشده، متن با فونت جایگزین نشان داده شود و صفحه خالی نماند.
اگر سرورهای گوگل برای کاربران شما کند یا در دسترس نباشند، صفحه با فونت جایگزین نمایش داده می‌شود؛ برای سایت واقعی، روش ۲ (فونت لوکال) مطمئن‌تر است.

روش ۲: فونت لوکال (فایل فونت داخل پروژه)

گاهی فونت مورد نظر در گوگل نیست، یا می‌خواهید سایت بدون اینترنت هم فونت درست را نشان دهد. در این حالت فایل فونت را داخل پروژه می‌گذاریم و با @font-face به مرورگر معرفی می‌کنیم.

  1. فایل فونت را دانلود کنید. بهترین فرمت برای وب woff2 است (فرمت‌های woff و ttf هم کار می‌کنند).
  2. یک پوشه fonts در پروژه بسازید و فایل‌ها را داخلش بگذارید.
  3. در فایل CSS با @font-face یک نام برای فونت تعیین کنید و آدرس فایل را بدهید.
  4. با همان نام در font-family از آن استفاده کنید.
my-site/
├── index.html
├── css/
│   └── style.css
└── fonts/
    ├── Vazirmatn-Regular.woff2
    └── Vazirmatn-Bold.woff2
/* css/style.css */

/* معرفی فونت معمولی */
@font-face {
  font-family: "MyVazir";                               /* هر نامی که دوست دارید */
  src: url("../fonts/Vazirmatn-Regular.woff2") format("woff2");
  font-weight: 400;                                     /* normal */
  font-style: normal;
  font-display: swap;                                   /* تا لود فونت، متن با فونت جایگزین دیده شود */
}

/* معرفی نسخه ضخیم همان فونت، با همان نام */
@font-face {
  font-family: "MyVazir";
  src: url("../fonts/Vazirmatn-Bold.woff2") format("woff2");
  font-weight: 700;                                     /* bold */
  font-style: normal;
  font-display: swap;
}

/* استفاده از فونت */
body {
  font-family: "MyVazir", Tahoma, sans-serif;
}

این متن با فایل فونت لوکال (Vazirmatn-Regular.woff2) نوشته شده است.

این متن از فایل Vazirmatn-Bold.woff2 آمده است.

نکته مسیر: مثل background-image، مسیر داخل url() نسبت به فایل CSS حساب می‌شود. چون style.css داخل پوشه css است، با ../ یک پوشه بیرون می‌رویم و وارد fonts می‌شویم. در همین صفحه فایل fonts.css داخل css/demos است، پس آنجا مسیر ../../fonts/ نوشته شده.
هر ضخامت یک فایل جدا دارد. چون هر دو @font-face نام یکسان دارند، وقتی font-weight: bold بنویسید مرورگر خودش فایل Bold را انتخاب می‌کند. اگر نسخه ضخیم را معرفی نکنید، مرورگر حروف را مصنوعی ضخیم می‌کند که زیبا نیست.

مقایسه Google Fonts فونت لوکال
نیاز به اینترنت دارد (و دسترسی به سرور گوگل) فقط به سرور سایت خودتان
کجا نوشته می‌شود link در HTML یا @import در CSS @font-face در CSS
فایل فونت روی سرور گوگل داخل پوشه fonts پروژه
مناسب برای شروع سریع و تمرین فونت‌هایی که در گوگل نیستند و سایت‌هایی که باید همیشه درست دیده شوند

اشتباه‌های رایج در فونت لوکال: مسیر اشتباه فایل (مسیر را نسبت به HTML نوشتن به جای CSS)، فرق داشتن نام داخل @font-face با نامی که در font-family نوشته شده، و اشتباه تایپی در نام فایل (حروف بزرگ و کوچک روی سرور مهم است).

تمرین: ۱) تیترهای صفحه معرفی‌تان را با فونت Lalezar از گوگل بنویسید. ۲) فایل فونت Vazirmatn را در پوشه fonts بگذارید و با @font-face برای متن body استفاده کنید. بعد اینترنت را قطع کنید و ببینید کدام فونت هنوز درست نمایش داده می‌شود.
