۶) رنگ‌ها (Colors)

در CSS رنگ را به ویژگی‌هایی مثل color (رنگ متن) و background-color (رنگ پس‌زمینه) می‌دهیم. مرورگر چند شیوه نوشتن را می‌فهمد و نتیجه نهایی همه آن‌ها یک رنگ است. فرق شیوه‌ها در این است که چطور آن رنگ را توصیف می‌کنیم: با یک نام آماده، با مقدار سه نور قرمز و سبز و آبی، با کد شانزده‌شانزده، یا با جایگاه رنگ روی چرخه رنگ. همان مقدار را می‌توان هم برای متن نوشت و هم برای پس‌زمینه. 

.swatch  { color: #222; }                               /* رنگ متن همه نمونه‌ها */

.sw-name { background-color: tomato; }                  /* نام رنگ */
.sw-rgb  { background-color: rgb(60, 179, 113); }       /* قرمز، سبز، آبی: ۰ تا ۲۵۵ */
.sw-hex  { background-color: #1e90ff; }                 /* هگز: #RRGGBB */
.sw-hsl  { background-color: hsl(39, 100%, 50%); }      /* رنگ، اشباع، روشنی */
.sw-rgba { background-color: rgba(255, 0, 0, 0.4); }    /* با شفافیت ۰ تا ۱ */

روش توضیح
نام رنگ حدود ۱۴۰ نام انگلیسی مثل tomato و navy؛ برای تمرین سریع خوب است، ولی انتخاب کمی دارد.
rgb() مقدار قرمز، سبز و آبی، هر کدام از ۰ (هیچ) تا ۲۵۵ (حداکثر). rgb(0, 0, 0) سیاه و rgb(255, 255, 255) سفید است.
هگز (#) همان سه عدد rgb در مبنای ۱۶ (00 تا ff). #000000 سیاه و #ffffff سفید است. اگر هر جفت دو رقم یکسان باشد، می‌شود کوتاه نوشت: #ffcc00 = #fc0. رایج‌ترین روش در طراحی سایت است.
hsl() رنگ روی چرخه رنگ (۰ تا ۳۶۰ درجه؛ ۰ قرمز، ۱۲۰ سبز، ۲۴۰ آبی)، اشباع (۰٪ خاکستری تا ۱۰۰٪ پررنگ) و روشنی (۰٪ سیاه، ۵۰٪ رنگ خالص، ۱۰۰٪ سفید). برای ساختن طیف روشن و تیره یک رنگ خیلی راحت است.
rgba() / hsla() عدد چهارم شفافیت (alpha) است: ۰ کاملاً شفاف و ۱ کاملاً مات.

مرورگرهای امروزی نوشتن بدون ویرگول را هم می‌پذیرند: rgb(255 0 0 / 40%) همان rgba(255, 0, 0, 0.4) است. هر دو شکل را در کدهای دیگران می‌بینید. رنگ دقیق را هم می‌توانید با ابزار Color Picker در DevTools مرورگر (کلید F12) انتخاب کنید.

کاربرد واقعی: پیام‌های موفقیت، خطا و اطلاع‌رسانی

.alert {
  padding: 10px 14px;
  border-radius: 6px;
}

.alert-success { background-color: #d3f9d8; color: #1b5e20; }
.alert-error   { background-color: #ffe3e3; color: #c92a2a; }
.alert-info    { background-color: #e7f5ff; color: #1864ab; }

ارسال رایگان برای خریدهای بالای ۵۰۰ هزار تومان.

در این سه پیام، پس‌زمینه خیلی روشن است و متن تیره از همان خانواده رنگی انتخاب شده است. سبز روشن معمولاً موفقیت را به ذهن می‌آورد، قرمز روشن خطا را، و آبی روشن یک اطلاع معمولی را. چون متن تیره روی زمینه روشن نشسته، جمله خوانا می‌ماند. معنی را فقط به رنگ واگذار نکنید؛ خود جمله باید بگوید چه اتفاقی افتاده است، چون بعضی کاربران رنگ‌ها را از هم تشخیص نمی‌دهند.

شفافیت: rgba یا opacity؟

/* فقط پس‌زمینه نیمه‌شفاف؛ متن کاملاً سفید و خوانا می‌ماند */
.caption-rgba {
  background-color: rgba(0, 0, 0, 0.5);
  color: white;
}

/* کل عنصر (پس‌زمینه + متن) نیمه‌شفاف می‌شود */
.caption-opacity {
  background-color: black;
  color: white;
  opacity: 0.5;
}

با rgba: متن کاملاً خوانا است

با opacity: متن هم کم‌رنگ شده است

اشتباه رایج: رنگ متن روشن روی پس‌زمینه روشن (مثلاً زرد روی سفید، یا سفید روی آبی روشن). متن باید با پس‌زمینه تضاد (کنتراست) کافی داشته باشد؛ ابزار DevTools مرورگر عدد کنتراست را نشان می‌دهد و برای متن معمولی حداقل ۴.۵ پیشنهاد می‌شود.
استفاده از opacity برای کم‌رنگ کردن پس‌زمینه؛ opacity متن داخل را هم کم‌رنگ می‌کند. برای پس‌زمینه نیمه‌شفاف از rgba استفاده کنید.

تمرین: یک تیتر با رنگ متن سفید و پس‌زمینه #1a3a5c بسازید. بعد یک پیام «هشدار» زردرنگ مثل نمونه‌های بالا بسازید (پس‌زمینه زرد روشن، متن قهوه‌ای تیره).
