۱۸) جدول‌ها (Tables)

جدول برای داده‌هایی است که در سطر و ستون معنا دارند؛ مثل قیمت، برنامه کلاسی یا مقایسه محصول. چیدمان کلی صفحه را با جدول نمی‌سازیم، چون صفحه‌خوان و تغییر اندازه صفحه با داده جدولی رفتار می‌کنند.

نقش عنصرهای جدول در HTML:

  • caption — عنوان جدول
  • thead — بخش ردیف عنوان ستون‌ها
  • tbody — ردیف‌های داده
  • th — سلول عنوان
  • td — سلول داده

CSS روی همین ساختار، حاشیه، رنگ ردیف‌ها و رفتار جدول در صفحه باریک را تنظیم می‌کند. 

<div class="table-wrap">
  <table>
    <caption>قیمت پلن‌های میزبانی وب</caption>
    <thead>
      <tr>
        <th scope="col">پلن</th>
        <th scope="col">فضا</th>
        <th scope="col">ایمیل</th>
        <th scope="col">قیمت ماهانه</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>پایه</td>
        <td>۵ گیگابایت</td>
        <td>۲ حساب</td>
        <td class="num">۹۰٬۰۰۰ تومان</td>
      </tr>
      <!-- ردیف‌های دیگر -->
    </tbody>
  </table>
</div>
.table-wrap {
  overflow-x: auto;              /* در موبایل جدول اسکرول افقی بخورد، نه کل صفحه */
}

table {
  width: 100%;
  border-collapse: collapse;     /* حاشیه‌های دوتایی یکی شوند */
}

caption {
  font-weight: bold;
  padding: 8px;
}

th, td {
  border: 1px solid #ccc;
  padding: 8px;
  text-align: start;             /* در صفحه فارسی: راست */
}

th {
  background-color: #0b6e4f;
  color: white;
}

td.num {
  white-space: nowrap;           /* عدد و واحد در دو خط نشکنند */
}

tbody tr:nth-child(even) {       /* ردیف‌های زوج بدنه جدول */
  background-color: #f2f2f2;
}

tbody tr:hover {                 /* ردیف زیر ماوس */
  background-color: #e3f2fd;
}
قیمت پلن‌های میزبانی وب
پلن فضا ایمیل قیمت ماهانه
پایه ۵ گیگابایت ۲ حساب ۹۰٬۰۰۰ تومان
استاندارد ۲۰ گیگابایت ۱۰ حساب ۱۹۰٬۰۰۰ تومان
حرفه‌ای ۵۰ گیگابایت نامحدود ۳۵۰٬۰۰۰ تومان
سازمانی ۲۰۰ گیگابایت نامحدود ۸۹۰٬۰۰۰ تومان

border-collapse: collapse حاشیه‌های سلول‌های همسایه را در هم ادغام می‌کند تا به‌جای دو خط چسبیده، یک خط دیده شود. مقدار پیش‌فرض separate است: هر سلول حاشیه خودش را جدا نگه می‌دارد و دو حاشیه کنار هم یک خط دوتایی می‌سازند. فاصله اضافه بین آن‌ها را ویژگی border-spacing تعیین می‌کند و مقدار اولیه‌اش صفر است. tr:nth-child(even) ردیف‌های زوج را بر اساس جایگاهشان بین فرزندان والد انتخاب می‌کند تا جدول راه‌راه شود و چشم ردیف را گم نکند. white-space: nowrap هم جلوی شکستن عدد و واحد پول در دو سطر را می‌گیرد. اگر جدول از عرض صفحه پهن‌تر شود، overflow-x: auto روی ظرف جدول فقط همان ظرف را افقی اسکرول می‌کند.

ویژگی یا انتخابگر کاربرد
border-collapse: collapse حاشیه سلول‌های کنار هم یکی شود
tr:nth-child(even) / (odd) انتخاب ردیف‌های زوج یا فرد برای جدول راه‌راه (خواندن ردیف‌های طولانی ساده‌تر می‌شود)
vertical-align تراز عمودی محتوای سلول: top، middle (پیش‌فرض)، bottom
caption-side جای عنوان جدول: top (پیش‌فرض) یا bottom

چرا text-align: start؟ مرورگر محتوای th را به طور پیش‌فرض وسط‌چین می‌کند و td را از لبه شروع متن. با start هر دو در صفحه فارسی راست‌چین و در صفحه انگلیسی چپ‌چین می‌شوند، بدون نیاز به تغییر کد.
caption عنوان جدول است و scope="col" به صفحه‌خوان‌ها می‌گوید هر th عنوان کدام ستون است؛ هر دو برای دسترس‌پذیری مهم‌اند.
با tbody tr به جای tr، راه‌راه و hover فقط روی ردیف‌های داده اعمال می‌شود، نه ردیف عنوان.

اشتباه رایج: بدون border-collapse: collapse بین سلول‌ها حاشیه دوتایی دیده می‌شود.
استفاده از جدول برای چیدمان صفحه (مثلاً ستون کناری و محتوا)؛ جدول فقط برای داده جدولی است و چیدمان را با Flexbox و Grid می‌سازیم (دوره میانی).
جدول عریض بدون overflow-x: auto در موبایل کل صفحه را اسکرول افقی می‌کند.

تمرین: برنامه هفتگی کلاس‌هایتان را به شکل جدول بنویسید (روز، ساعت، درس، استاد) با caption، سرستون رنگی، ردیف‌های راه‌راه و hover. پنجره را باریک کنید و اسکرول افقی جدول را امتحان کنید.
