۸) حاشیه (Borders)

حاشیه خطی است که دور لبه جعبه، بین فاصله داخلی و فاصله بیرونی، کشیده می‌شود. برای دیده شدن آن سه چیز لازم است: سبک (شکل خط)، ضخامت و رنگ. مقدار پیش‌فرض سبک none است؛ پس اگر فقط ضخامت و رنگ را بنویسید و سبک را مشخص نکنید، مرورگر هیچ خطی نشان نمی‌دهد. 

/* ضخامت و رنگ مشترک همه نمونه‌ها */
.bdemo {
  border-width: 3px;
  border-color: #1a3a5c;
  padding: 8px;
}

.b-solid  { border-style: solid; }
.b-dashed { border-style: dashed; }
.b-dotted { border-style: dotted; }
.b-double { border-style: double; border-width: 5px; }  /* double حداقل ۳ پیکسل لازم دارد */
.b-mixed  { border-style: solid dashed; }  /* بالا و پایین / راست و چپ */

solid — خط پیوسته

dashed — خط‌چین

dotted — نقطه‌چین

double — دوخطی

solid dashed — ترکیبی

علاوه بر خط پیوسته، خط‌چین، نقطه‌چین و دوخطی، سبک‌های groove، ridge، inset و outset هم وجود دارند. این چهار سبک با سایه‌روشن سعی می‌کنند لبه فرورفته یا برجسته نشان دهند و ظاهرشان به رنگ حاشیه وابسته است. اگر به border-style چند مقدار بدهید، ترتیب مثل margin است که در درس ۹ می‌آید: یک مقدار برای هر چهار طرف، دو مقدار برای بالا/پایین و راست/چپ، و به همین ترتیب. سبک double برای اینکه دو خط جدا دیده شود به ضخامت کافی نیاز دارد؛ با یک یا دو پیکسل معمولاً شبیه یک خط معمولی می‌شود.

نوشتن خلاصه و گوشه گرد: کارت محصول

در عمل معمولاً هر سه جزء را با ویژگی خلاصه border در یک خط می‌نویسیم: ضخامت، سبک و رنگ. مرورگر این سه را از روی نوع مقدار تشخیص می‌دهد، پس جابه‌جایی‌شان معمولاً خطا نمی‌سازد؛ ترتیب «ضخامت، سبک، رنگ» فقط رایج‌ترین شکل نوشتن است. border-radius گوشه‌های همان حاشیه را گرد می‌کند و روی پس‌زمینه هم اثر می‌گذارد، چون پس‌زمینه داخل گوشه گرد بریده می‌شود. 

.card {
  border: 1px solid #cfd8e3;   /* ضخامت، سبک، رنگ */
  border-radius: 12px;         /* گوشه‌های گرد */
  padding: 16px;
  max-width: 280px;
}

/* فاصله بین دو انتخابگر یعنی «داخل»: عنصر price که داخل card است */
.card .price {
  border-top: 1px dashed #cfd8e3;   /* فقط خط بالا */
  padding-top: 8px;
  color: #0b6e4f;
  font-weight: bold;
}

هدفون بی‌سیم

صدای شفاف، ۲۰ ساعت شارژدهی و اتصال بلوتوث.

۱٬۸۵۰٬۰۰۰ تومان

border-radius هم مثل margin تا چهار مقدار می‌گیرد؛ ترتیب از گوشه بالا-چپ شروع می‌شود و در جهت عقربه‌های ساعت می‌چرخد. مثلاً border-radius: 12px 12px 0 0; فقط دو گوشه بالا را گرد می‌کند.

حاشیه فقط در یک طرف (و نکته راست‌چین)

لازم نیست هر چهار طرف حاشیه یک شکل باشند. border-top یا border-inline-start فقط یک لبه را می‌کشد و بقیه لبه‌ها بدون خط می‌مانند. در یادداشت زیر، یک نوار رنگی در لبه‌ای که متن از آنجا شروع می‌شود دیده می‌شود تا آن جعبه از پاراگراف معمولی جدا شود. 

.note {
  border-inline-start: 6px solid #e67700;  /* لبه «شروع» متن؛ در صفحه فارسی = راست */
  background-color: #fff4e6;
  padding: 10px;
}

یادداشت: کلاس فردا ساعت ۱۰ برگزار می‌شود.

border-right همیشه سمت راست است. ولی border-inline-start لبه‌ای است که متن از آنجا شروع می‌شود: در صفحه فارسی (dir="rtl") سمت راست و در صفحه انگلیسی سمت چپ. به این‌ها «ویژگی‌های منطقی» (Logical Properties) می‌گویند و برای سایت‌های دوزبانه بهترند. معادل‌ها: border-inline-end (لبه پایان متن)، border-block-start (بالا) و border-block-end (پایین).

عکس پروفایل دایره‌ای

برای دایره، عرض و ارتفاع تصویر باید برابر باشند و border-radius: 50% هر گوشه را به اندازه نصف ضلع گرد کند. object-fit: cover عکس را داخل همان مربع می‌پوشاند و قسمت اضافه را می‌برد تا تصویر برای جا شدن کش نیاید. اگر عرض و ارتفاع برابر نباشند، همان ۵۰ درصد بیضی می‌سازد نه دایره. 

.avatar {
  width: 120px;
  height: 120px;          /* عرض و ارتفاع برابر */
  object-fit: cover;      /* عکس کشیده نشود؛ اضافه‌اش بریده شود */
  border: 4px solid #0b6e4f;
  border-radius: 50%;     /* دایره کامل */
}

اشتباه رایج: نوشتن border-width و border-color (یا border: 2px red) بدون سبک. مقدار پیش‌فرض border-style برابر none است، پس بدون سبک هیچ حاشیه‌ای دیده نمی‌شود.
یادتان باشد حاشیه هم به اندازه جعبه اضافه می‌شود (درس ۱۲، مدل جعبه‌ای).

تمرین: یک کارت «نظر مشتری» بسازید: حاشیه ۱ پیکسلی خاکستری، گوشه‌های گرد ۱۰ پیکسلی، یک نوار رنگی ۴ پیکسلی در لبه شروع متن (border-inline-start) و عکس دایره‌ای مشتری بالای متن.
