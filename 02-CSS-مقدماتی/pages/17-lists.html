۱۷) فهرست‌ها (Lists)

فهرست در HTML دو نوع رایج دارد: ul برای موردهایی که ترتیبشان مهم نیست، و ol برای مرحله‌ها یا موردهایی که ترتیبشان معنی دارد. مرورگر کنار هر آیتم یک علامت پیش‌فرض می‌گذارد: برای ul معمولاً دایره توپر و برای ol شماره. ویژگی list-style-type فقط شکل همین علامت را عوض می‌کند و نوع فهرست را در HTML تغییر نمی‌دهد. اگر شماره فارسی می‌خواهید، فهرست باید ol بماند و مقدار persian بگیرد. 

.l-square  { list-style-type: square; }
.l-circle  { list-style-type: circle; }
.l-persian { list-style-type: persian; }   /* شماره‌های فارسی: ۱، ۲، ۳ */

  3. چای را بریزید و ۵ دقیقه صبر کنید.
برای مقدارهای رایج
ul disc (پیش‌فرض، دایره توپر)، circle، square، none
ol decimal (1، 2، 3)، persian (۱، ۲، ۳)، arabic-indic (١، ٢، ٣)، upper-alpha، lower-roman
list-style-position outside (پیش‌فرض؛ علامت بیرون متن) یا inside (علامت جزو خط اول متن)

ویژگی خلاصه list-style نوع علامت، تصویر علامت و جایگاه آن را در یک خط جمع می‌کند. در list-style: square inside; شکل علامت مربع است و inside یعنی علامت جزو خط اول متن باشد، نه بیرون کادر متن. مقدار پیش‌فرض جایگاه outside است: علامت بیرون متن می‌نشیند و اگر خط دوم طولانی شود، زیر متن تراز می‌ماند نه زیر علامت. نوع فهرست را CSS عوض نمی‌کند. ol را وقتی بگذارید که ترتیب کار معنی دارد، مثل مراحل یک دستور، و ul را وقتی ترتیب مهم نیست.

رنگ دادن به علامت فهرست (::marker)

علامت گلوله یا شماره، جعبه جداگانه‌ای در HTML ندارد. شبه‌عنصر ::marker همان علامت را هدف می‌گیرد تا بتوان رنگ یا ضخامتش را عوض کرد، بدون اینکه متن آیتم تغییر کند. روی ::marker فقط تعداد محدودی از ویژگی‌ها اثر دارند؛ رنگ و ضخامت قلم از جمله آن‌هاست و مثلاً padding روی خود علامت کار نمی‌کند. 

.features li::marker {
  color: #0b6e4f;
  font-weight: bold;
}

::marker یک «شبه‌عنصر» است؛ یعنی بخشی از عنصر (اینجا علامت فهرست) که جداگانه در HTML نوشته نشده، ولی می‌شود به آن ظاهر داد.

حذف علامت فهرست: ساخت منو

منوهای سایت در HTML معمولاً یک فهرست از لینک‌ها هستند. برای ظاهر منو، علامت و فاصله پیش‌فرض فهرست را برمی‌داریم:

.menu {
  list-style-type: none;
  padding: 0;
}

.menu li {
  background-color: #e8f4fd;
  border-right: 4px solid #1a5fb4;
  margin-bottom: 6px;
}

.menu a {
  display: block;            /* کل ردیف قابل کلیک شود */
  padding: 6px 10px;
  color: #1a3a5c;
  text-decoration: none;
}

.menu a:hover,
.menu a:focus-visible {
  background-color: #d0e7fb;
}
  • خانه
  • درباره من
  • تماس

اشتباه رایج: بعد از list-style-type: none، فاصله سمت راست فهرست باقی می‌ماند. دلیلش این است که مرورگر به طور پیش‌فرض به فهرست padding-inline-start: 40px می‌دهد (در صفحه فارسی سمت راست، در انگلیسی سمت چپ) تا جا برای علامت باشد. باید padding: 0 هم بنویسید. فهرست‌ها margin بالا و پایین هم دارند که در صورت نیاز با margin: 0 برداشته می‌شود.
نوشتن padding-left: 0 در صفحه فارسی هم اشتباه رایجی است؛ فاصله پیش‌فرض سمت راست است، نه چپ.

تمرین: فهرست مهارت‌های صفحه معرفی‌تان را با list-style-type: square و علامت‌های رنگی (::marker) بنویسید، و مراحل یک کار (مثلاً «چطور ثبت‌نام کنیم») را با ol و شماره‌های فارسی.
