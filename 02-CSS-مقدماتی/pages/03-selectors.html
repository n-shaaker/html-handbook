۳) انتخابگرها (Selectors)

انتخابگر مشخص می‌کند قانون CSS روی کدام عنصرهای HTML اعمال شود. بدون انتخابگر، مرورگر نمی‌داند رنگ یا اندازه را به کدام بخش صفحه بدهد. انتخابگرهای پایه را با یک صفحه مقاله ساده یاد می‌گیریم.

ساده‌ترین انتخابگر، نام خود تگ است؛ مثلاً p همه پاراگراف‌ها را انتخاب می‌کند. اگر فقط یک عنصر خاص مدنظر باشد، در HTML به آن id می‌دهیم و در CSS با علامت # انتخابش می‌کنیم. هر شناسه در یک صفحه باید یکتا باشد. اگر بخواهیم یک ظاهر را روی چند عنصر تکرار کنیم، از class استفاده می‌کنیم و در CSS آن را با نقطه می‌نویسیم. یک کلاس را می‌توان به هر تعداد عنصر داد. نام تگ و کلاس را هم می‌توان بدون فاصله به هم چسباند تا فقط همان نوع عنصر، در صورتی که آن کلاس را داشته باشد، انتخاب شود. چند انتخابگر را نیز می‌توان با ویرگول در یک قانون نوشت تا ظاهر مشترک بگیرند.

کد HTML

<h3>چطور یک فنجان قهوه خوب دم کنیم؟</h3>
<p id="lead">در این مقاله پنج نکته ساده برای دم کردن قهوه را می‌خوانید.</p>
<p>اول از همه، دانه قهوه را درست قبل از دم کردن آسیاب کنید.</p>
<p class="center">«قهوه تازه، نصف موفقیت است.»</p>
<p class="center large">نکته مهم: آب جوش را مستقیم روی قهوه نریزید.</p>
<h4>منابع</h4>

کد CSS

/* ۱. انتخابگر عنصر (نام تگ): همه pها */
p {
  color: #c92a2a;
}

/* ۲. انتخابگر id: فقط عنصری که id="lead" دارد */
#lead {
  color: #1a5fb4;
}

/* ۳. انتخابگر class: همه عنصرهایی که کلاس center دارند */
.center {
  text-align: center;
}

/* ۴. عنصر + کلاس: فقط pهایی که کلاس large دارند */
p.large {
  font-size: 24px;
}

/* ۵. گروهی: چند انتخابگر با یک قانون (با ویرگول جدا می‌شوند) */
h3, h4 {
  color: #0b6e4f;
}

چطور یک فنجان قهوه خوب دم کنیم؟

در این مقاله پنج نکته ساده برای دم کردن قهوه را می‌خوانید.

اول از همه، دانه قهوه را درست قبل از دم کردن آسیاب کنید.

«قهوه تازه، نصف موفقیت است.»

نکته مهم: آب جوش را مستقیم روی قهوه نریزید.

منابع

به پاراگراف پنجم دقت کنید: class="center large" یعنی این عنصر دو کلاس دارد (با فاصله از هم جدا می‌شوند)، پس هم قانون .center و هم قانون p.large روی آن اعمال می‌شود.

انتخابگر همگانی (*)

/* همه عنصرهای صفحه */
* {
  box-sizing: border-box;
}

ستاره همه عنصرها را انتخاب می‌کند. بیشتر برای تنظیم‌های کلی ابتدای فایل استفاده می‌شود؛ مثل همین قانون که فایل style.css این مجموعه با آن شروع شده (در درس ۱۲ معنی‌اش را می‌بینید). آن را در مثال بالا اعمال نکرده‌ایم، چون روی کل صفحه اثر می‌گذارد.

انتخابگر نوشتن انتخاب می‌کند
عنصر p همه پاراگراف‌ها
id #lead تنها عنصری که این id را دارد (id در هر صفحه باید یکتا باشد)
class .center همه عنصرهای دارای آن کلاس (یک کلاس را می‌شود به هر تعداد عنصر داد)
عنصر + کلاس p.large فقط pهایی که کلاس large دارند (بدون فاصله نوشته می‌شود)
گروهی h3, h4 هر دو نوع با یک قانون
همگانی * همه عنصرها

چرا پاراگراف #lead آبی شد و قرمز نماند، با اینکه قانون p هم شامل آن می‌شود؟ چون انتخابگر id از انتخابگر نام تگ قوی‌تر است (به این قدرت «Specificity» یا «اولویت انتخابگر» می‌گویند). ترتیب قدرت: id > class > نام تگ. اگر دو انتخابگر هم‌قدرت باشند، قانونی که پایین‌تر نوشته شده برنده است.

class یا id؟ برای ظاهر دادن تقریباً همیشه از class استفاده کنید؛ چون قابل استفاده دوباره است و قدرتش آن‌قدر زیاد نیست که بعداً تغییر ظاهر را سخت کند. id را بیشتر برای لینک به یک بخش صفحه (مثل href="#lead") و جاوااسکریپت نگه دارید.

اشتباه رایج: جابه‌جا نوشتن نقطه (برای class) و # (برای id)، یا نوشتن نقطه در HTML (class=".center" غلط است). نام کلاس و id به حروف بزرگ و کوچک حساس است (.Center با .center فرق دارد)، نباید فاصله داشته باشد و نباید با عدد شروع شود (مثل .1box).

تمرین: در یک صفحه خبری، به دو پاراگراف که «خبر فوری» هستند کلاس urgent بدهید و با CSS پس‌زمینه زرد روشن و متن ضخیم برایشان بگذارید. بعد با h2, h3 رنگ همه تیترها را یکی کنید.
