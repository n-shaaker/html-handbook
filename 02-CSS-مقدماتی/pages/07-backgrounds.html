۷) پس‌زمینه (Backgrounds)

پس‌زمینه لایه‌ای است که پشت محتوای عنصر کشیده می‌شود. ساده‌ترین حالت آن یک رنگ یکدست است. اگر محتوا، فاصله داخلی یا ارتفاعی در کار نباشد، جعبه دیده نمی‌شود؛ چون پس‌زمینه به اندازه خود جعبه رسم می‌شود.

رنگ پس‌زمینه

.offer {
  background-color: #ffe0b2;
  padding: 16px;
}

پیشنهاد ویژه: تا پایان هفته، ۲۰٪ تخفیف روی همه کتاب‌ها.

تصویر پس‌زمینه: بنر بالای سایت (Hero)

به‌جای رنگ، می‌توان یک تصویر را پشت محتوا گذاشت. مرورگر تصویر را از مسیر url() می‌خواند. ویژگی background-size: cover تصویر را آن‌قدر بزرگ می‌کند که تمام جعبه پوشیده شود؛ اگر نسبت تصویر با جعبه یکی نباشد، لبه‌های اضافه بریده می‌شوند. background-position: center مشخص می‌کند کدام نقطه تصویر در وسط جعبه بماند. min-height هم حداقل ارتفاع جعبه را تعیین می‌کند تا حتی با متن کوتاه، بنر دیده شود. 

.hero {
  background-color: #1a3a5c;                    /* اگر تصویر لود نشد */
  background-image: url("../../images/bg.jpg");
  background-size: cover;                       /* تصویر کل جعبه را بپوشاند */
  background-position: center;                  /* وسط تصویر دیده شود */
  min-height: 200px;
  padding: 24px;
  color: white;
}

سفر به سرزمین آبدره‌ها

تور ۷ روزه طبیعت‌گردی — ثبت‌نام آغاز شد

نکته مهم مسیر: مسیر داخل url() نسبت به فایل CSS حساب می‌شود، نه فایل HTML. چون backgrounds.css داخل پوشه css/demos است، با ../../ دو پوشه بیرون می‌رویم و بعد وارد images می‌شویم.
همیشه کنار تصویر یک background-color هم بنویسید تا اگر تصویر لود نشد، متن سفید روی زمینه سفید گم نشود.

متن خواناتر روی تصویر: لایه تیره

متن سفید روی بخش‌های روشن تصویر (مثل آسمان) سخت خوانده می‌شود. راه‌حل رایج این است که یک لایه نیمه‌شفاف تیره روی تصویر بیندازیم. background-image می‌تواند چند لایه بگیرد که با ویرگول جدا می‌شوند؛ لایه اول روی بقیه قرار می‌گیرد. اینجا لایه اول یک «گرادیان» (طیف رنگ) است که هر دو رنگش یکی و نیمه‌شفاف است: 

.hero-dark {
  background-color: #1a3a5c;
  background-image:
    linear-gradient(rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.5)),  /* لایه تیره (رو) */
    url("../../images/bg.jpg");                               /* تصویر (زیر) */
  background-size: cover;
  background-position: center;
  min-height: 200px;
  padding: 24px;
  color: white;
}

سفر به سرزمین آبدره‌ها

تور ۷ روزه طبیعت‌گردی — ثبت‌نام آغاز شد

تصویر پس‌زمینه یا تگ img؟ اگر تصویر فقط تزئینی است (بنر، طرح پس‌زمینه)، از background-image استفاده کنید. اگر تصویر بخشی از محتواست (عکس محصول، عکس مقاله)، از <img> با alt مناسب استفاده کنید؛ چون صفحه‌خوان‌ها و موتورهای جستجو تصویر پس‌زمینه را نمی‌بینند.

تکرار تصویر

اگر تصویر از جعبه کوچک‌تر باشد، مرورگر به‌طور پیش‌فرض آن را هم در جهت افقی و هم در جهت عمودی تکرار می‌کند؛ به این رفتار کاشی‌کاری می‌گویند. مقدار پیش‌فرض background-repeat همان repeat است. با repeat-x تکرار فقط افقی می‌ماند، با repeat-y فقط عمودی، و با no-repeat تصویر یک بار نشان داده می‌شود. در مثال زیر عرض هر تکه با background-size کوچک شده و ردیف تصویر با background-position: top به بالای جعبه چسبیده است. فاصله داخلی بالا هم متن را زیر همان ردیف می‌آورد. 

.strip {
  background-color: #eef2ff;
  background-image: url("../../images/bg.jpg");
  background-size: 90px;           /* عرض هر تکه تصویر */
  background-repeat: repeat-x;     /* فقط افقی تکرار شود */
  background-position: top;        /* ردیف تصویر بالای جعبه باشد */
  padding: 95px 16px 10px;         /* متن زیر ردیف تصویر بیاید */
}
تصویر کوچک فقط در یک ردیف افقی تکرار شده است.
ویژگی مقدارهای رایج
background-repeat repeat ، repeat-x ، repeat-y ، no-repeat
background-size cover (کل جعبه پر شود؛ ممکن است لبه‌های تصویر بریده شود)، contain (کل تصویر دیده شود؛ ممکن است جای خالی بماند)، 100px
background-position center ، top ، right bottom ، 20% 50%

نکته راست‌چین: مقدارهای left و right در background-position همیشه سمت فیزیکی را می‌گویند و با dir="rtl" برعکس نمی‌شوند. اگر سایت شما دوزبانه است، جای تصویر را برای هر جهت جداگانه بررسی کنید.

نوشتن خلاصه (Shorthand)

ویژگی خلاصه background رنگ، تصویر، تکرار و موقعیت را در یک اعلامیه جمع می‌کند. اگر اندازه را هم در همان خط بخواهید، باید بعد از موقعیت و با علامت / بیاید؛ مثل center / cover. این خلاصه بقیه ویژگی‌های پس‌زمینه را هم به مقدار پیش‌فرض برمی‌گرداند. برای همین اگر قبلاً مثلاً فقط background-color را جدا نوشته باشید و بعد background را بنویسید، مقدار قبلی ممکن است پاک شود. 

.hero {
  /* رنگ، تصویر، تکرار، موقعیت / اندازه */
  background: #1a3a5c url("../../images/bg.jpg") no-repeat center / cover;
}

اشتباه رایج: نوشتن background (خلاصه) بعد از background-color یا background-image. خلاصه همه ویژگی‌های پس‌زمینه را از نو تنظیم می‌کند و مقدارهای قبلی پاک می‌شوند.
انتظار اینکه جعبه هم‌اندازه تصویر پس‌زمینه شود: تصویر پس‌زمینه برخلاف img به جعبه اندازه نمی‌دهد. جعبه خالی ارتفاع صفر دارد و تصویر اصلاً دیده نمی‌شود؛ با محتوا، padding یا min-height به آن ارتفاع بدهید.

تمرین: یک جعبه با تصویر پس‌زمینه بسازید که تصویر تکرار نشود و در گوشه پایین سمت چپ قرار بگیرد.
