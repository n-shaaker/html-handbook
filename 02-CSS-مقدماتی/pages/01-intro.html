۱) CSS چیست؟

CSS مخفف Cascading Style Sheets، یعنی «برگه‌های سبک آبشاری» است. مرورگر ابتدا HTML را می‌خواند و با آن ساختار صفحه را می‌سازد: کدام بخش تیتر است، کدام پاراگراف است و تصویر کجا قرار دارد. سپس قانون‌های CSS را روی همان عنصرها اعمال می‌کند و ظاهر را تعیین می‌کند؛ از جمله رنگ، نوع و اندازه قلم، فاصله‌ها و شیوه قرار گرفتن عنصرها کنار هم.

اگر HTML را اسکلت و دیوارهای یک خانه بدانیم، CSS رنگ دیوار، نوع کف‌پوش و چیدمان وسایل است. متن و معنی صفحه در HTML می‌ماند و ظاهر در CSS نوشته می‌شود. به همین دلیل می‌توان همان محتوا را با تغییر CSS متفاوت نشان داد، بدون اینکه جمله‌های صفحه عوض شوند.

چرا CSS؟

  • جدا بودن محتوا از ظاهر: متن و ساختار در HTML می‌ماند و ظاهر در فایل CSS؛ هر دو ساده‌تر خوانده و ویرایش می‌شوند.
  • یک بار نوشتن، همه‌جا استفاده: با یک فایل CSS می‌توان ظاهر صدها صفحه را یک‌جا تغییر داد.
  • نمایش مناسب در دستگاه‌های مختلف: با CSS می‌شود ظاهر صفحه را برای موبایل و کامپیوتر جداگانه تنظیم کرد.

کلمه Cascading به معنی «آبشاری» است. گاهی چند قانون هم‌زمان به یک عنصر می‌رسند؛ مثلاً یک قانون رنگ همه پاراگراف‌ها را قرمز می‌کند و قانون دیگری همان پاراگراف را آبی. مرورگر این قانون‌ها را با قاعده‌های مشخص مقایسه می‌کند و یکی را اعمال می‌کند. این مقایسه همان رفتار آبشاری است. در درس‌های ۳ و ۴ می‌بینید قدرت انتخابگر و ترتیب نوشتن قانون‌ها چطور برنده را مشخص می‌کنند.

همان HTML، بدون CSS و با CSS

برای دیدن تفاوت، همان دو خط HTML را یک بار بدون قانون CSS و یک بار با قانون‌های رنگ، تراز و قلم نشان می‌دهیم. متن هر دو نمونه یکی است؛ فقط ظاهر عوض می‌شود. 

<h1>کافه کتاب</h1>
<p>قهوه تازه، کتاب خوب و فضایی آرام برای مطالعه.</p>
body {
  background-color: lightblue;
  padding: 10px;
}

h1 {
  color: #1a3a5c;
  text-align: center;
}

p {
  font-family: "Inter", "Vazirmatn", Tahoma, sans-serif;
  font-size: 20px;
}

بدون CSS این درس:

کافه کتاب

قهوه تازه، کتاب خوب و فضایی آرام برای مطالعه.

با CSS:

کافه کتاب

قهوه تازه، کتاب خوب و فضایی آرام برای مطالعه.

محتوا (متن) در هر دو حالت یکی است؛ فقط ظاهر عوض شده. این یعنی «جدا بودن محتوا از ظاهر».
در این صفحه برای اینکه کل صفحه آبی نشود، قانون‌های body، h1 و p فقط روی یک جعبه (div) دور مثال اعمال شده‌اند (فایل css/demos/intro.css). در صفحه واقعی خودتان، همان کد بالا را بنویسید.

استایل‌های اولیه مرورگر

حتی وقتی هنوز هیچ CSS ننوشته‌اید، صفحه کاملاً بدون ظاهر نیست. هر مرورگر یک شیوه‌نامهٔ پیش‌فرض دارد که به آن user agent stylesheet می‌گویند: تیتر درشت است، پاراگراف فاصله دارد، پیوند معمولاً آبی و زیرخط‌دار است، فهرست گلوله دارد و body حاشیهٔ کوچک دارد. این ظاهر، معنی عنصر HTML نیست؛ قرارداد نمایش همان مرورگر است و جزئیاتش بین مرورگرها کمی فرق می‌کند. کار CSS این است که همین پیش‌فرض‌ها را آگاهانه عوض کند.

بسیاری از پروژه‌ها در ابتدای فایل، حاشیهٔ پیش‌فرض body را صفر می‌کنند و box-sizing را یکسان می‌گذارند تا محاسبهٔ عرض غافلگیرکننده نباشد. صفر کردن همهٔ فاصله‌ها الزامی نیست. مهم این است که اگر عنصری «خودش» رنگ یا فاصله دارد و در CSS شما چنین قانونی نیست، اول بپذیرید که ممکن است از مرورگر آمده باشد. 

body {
  margin: 0;
}

a {
  color: inherit;
  text-decoration: none;
}

در DevTools، بخش user agent stylesheet همان قانون‌های پیش‌فرض را نشان می‌دهد. اگر قانونی از فایل شما خط خورده باشد، قانون دیگری بر آن غلبه کرده است؛ دلیلش در درس آبشاری CSS می‌آید.

اشتباه رایج: استفاده از HTML برای ظاهر؛ مثلاً استفاده از <h1> فقط برای درشت شدن متن، یا تگ‌های قدیمی مثل <font> و <center>. تگ HTML نقش و معنی محتوا را می‌گوید و ظاهر را باید با CSS ساخت.
