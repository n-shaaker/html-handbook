## رویکرد تدریس — مسئله اول، بعد مفهوم

اسکریپت کامل هر درس در پوشه [`دروس/`](./دروس/) است. فایل [`سناریو-تدریس.md`](./سناریو-تدریس.md) فقط فهرست و راهنمای مسیر است، نه متن درس.

| اصل | معنی برای مدرس |
|-----|----------------|
| **مسئله اول** | با سناریوی واقعی (کارت، منو، بیرون‌زدن از صفحه…) شروع کن؛ تعریف بعد از «چرا» |
| **دیالوگ فارسی** | جمله‌های قابل خواندن سر کلاس — نه bullet خلاصه |
| **چرخه ثابت** | مفهوم → Live code → مرورگر → سؤال چالشی → راه‌حل |
| **یادآوری کوتاه** | Block/Inline، LVHA، collapse — فقط وقتی درس به آن می‌رسد |
| **پایان درس** | mini-project + سؤالات + تمرین ساده→سخت + جدول زمان + اشتباهات رایج + پل درس بعد |

**الگوی طلایی:** [`دروس/11-عرض-ارتفاع-واحدها.md`](./دروس/11-عرض-ارتفاع-واحدها.md)
