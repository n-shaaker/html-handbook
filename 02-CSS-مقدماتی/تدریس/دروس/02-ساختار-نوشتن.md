## ۱) شروع — وقتی CSS «نمی‌چسبد»

«یکی از شما دیروز نوشته:

```css
p
  color red
```

صفحه را رفرش کرده — هیچی قرمز نشده. مشکل HTML نیست؛ **زبان CSS** را رعایت نکرده‌ایم.

CSS مثل دستور آشپزی است: اگر «یک قاشق» را بنویسی «یک قاش»، آشپز نمی‌فهمد. مرورگر هم قانون نامعتبر را **رد** می‌کند — اغلب بی‌صدا، مگر DevTools را باز کنید.»

---

## ۲) شکل درست یک قانون

«هر **قانون (rule)** از این قطعات است:»

```css
p {
  color: red;
  text-align: center;
}
```

با کلاس نام ببر:

| بخش | نام | نقش |
|-----|-----|-----|
| `p` | **Selector** | کدام عنصرها |
| `{ ... }` | **Declaration block** | لیست ظاهرها |
| `color: red;` | **Declaration** | یک ویژگی + مقدار |
| `color` | **Property** | *چه* چیزی عوض شود |
| `red` | **Value** | *چطور* عوض شود |
| `:` | جداکننده | بین property و value |
| `;` | پایان declaration | (آخرین هم بهتر است `;` بگذارید) |

**Live:**

```html
<p>این پاراگراف باید قرمز و وسط باشد.</p>
```

```css
p {
  color: red;
  text-align: center;
}
```

**مرورگر:** متن قرمز، در عرض جعبه `p` وسط (block تمام عرض را می‌گیرد — بعداً با width بازی می‌کنیم).

---

## ۳) چند property روی یک selector

«یک بار `p` را انتخاب می‌کنیم؛ چند خط ظاهر می‌دهیم — مرورگر **همه** را با هم اعمال می‌کند.»

```css
p {
  color: #1e293b;
  font-size: 18px;
  line-height: 1.6;
  margin-block: 0.5rem;
}
```

### سؤال کلاسی

«ترتیب `color` و `font-size` داخل بلوک مهم است؟»  
**پاسخ:** برای propertyهای مستقل معمولاً **نه** — هر دو اعمال می‌شوند. (برخلاف دو قانون جدا برای همان selector که cascade دارد.)

---

## ۴) آزمایش خطا — عمداً خراب کنید

«برای یادگیری، یک خط را خراب می‌کنیم و در DevTools → Styles خط خطا را می‌بینیم.»

| اشتباه | نتیجه |
|--------|--------|
| `color red` (بدون `:`) | آن declaration نامعتبر |
| `color: red` (بدون `;` و خط بعدی property) | گاهی خط بعدی هم خراب می‌شود |
| `{` فراموش | کل قانون از کار می‌افتد |
| `p { color: red }` خارج از `<style>` یا فایل CSS | اعمال نمی‌شود |

**تمرین کلاسی:** یک `;` حذف کنید — ببینید کدام propertyها می‌افتند.

### اشتباهات رایج

- فاصله بین عدد و واحد: `20 px` ❌ → `20px` ✅  
- استفاده از `//` برای comment — در CSS استاندارد **`/* */`** است (درس ۵).

---

## ۵) selector ساده امروز — فقط تگ

«فعلاً `p` و `h1` می‌نویسیم. درس بعد **class** و **id** می‌آید — دقیق‌تر انتخاب می‌کنیم.»

```css
h1 {
  color: #0f766e;
  font-size: 1.75rem;
}

p {
  color: #334155;
}
```

«اگر فقط یک پاراگراف خاص را بخواهیم، با تگ alone نمی‌شود — به class نیاز داریم.»

---

## ۶) پروژه mini — کارت خوش‌آمد

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Syntax — کارت خوش‌آمد</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      background: #f1f5f9;
      padding: 2rem;
    }
    h1 {
      color: #1e3a8a;
      text-align: center;
      margin-block: 0 0.5rem;
    }
    p {
      color: #475569;
      text-align: center;
      line-height: 1.7;
      max-width: 32ch;
      margin-inline: auto;
    }
  </style>
</head>
<body>
  <h1>به دوره CSS خوش آمدید</h1>
  <p>هر قانون: selector، آکولاد، property: value و نقطه‌ویرگول.</p>
</body>
</html>
```

**نمایش:** جزوه [`02-syntax.html`](../../pages/02-syntax.html) — جدول اصطلاحات را یک بار با هم مرور کنید، نه قبل از Live.

---

## ۷) جمع‌بندی

1. سه بخش اصلی یک rule چیست؟ → selector، block، declarations.  
2. چرا `;` مهم است؟ → جدا کردن declarationها.  
3. `text-align: center` روی `p` چه می‌کند؟ → متن داخل جعبه پاراگراف را وسط می‌چیند (نه کل صفحه مگر `p` باریک باشد).

---

## تمرین‌ها

### ساده
1. یک `h2` با `color` و `font-size` استایل بده.  
2. عمداً `:` را حذف کن و خطا را در DevTools پیدا کن.

### متوسط
3. یک rule با ۴ property برای `body` (پس‌زمینه، margin، font-family، padding).  
4. دو rule جدا برای `h1` — رنگ متفاوت؛ بگو کدام برنده است.

### چالشی
5. بدون نگاه به جزوه، rule کامل برای «همه `a` آبی و بدون underline» بنویس (`color`, `text-decoration`).
