## ۱) شروع — دیوار متن

«مقاله ۱۵ خط: `font-size: 14px`, `line-height: 1`, `text-align: justify` در ستون باریک.

دانشجو می‌گوید «خوانده نمی‌شود». CSS متن فقط «رنگ» نیست — **ریتم** و **تراز** است.»

```css
.article {
  max-width: 65ch;
  line-height: 1.75;
  text-align: start;
}
```

**مرورگر:** نفس و خوانایی بهتر.

---

## ۲) text-align — left/right یا start/end?

«در `dir="rtl"`:

```css
text-align: start;  /* راست در RTL */
text-align: end;    /* چپ در RTL */
```

«`left`/`right` **فیزیکی** — اگر روزی LTR شود layout می‌شکند. در جزوه فارسی **start/end** ترجیح.»

**Live:** `dir` را ltr کنید — start/end جابه‌جا می‌شود.

---

## ۳) line-height

```css
p {
  line-height: 1.7;
  /* یا 1.7rem — واحد بدون rem/em ضرب در font-size فعلی */
}
```

«فارسی: معمولاً **۱.۶ تا ۱.۸** برای body. تیتر می‌تواند ۱.۲–۱.۳.»

### سؤال کلاسی

«`line-height: 24px` در برابر `1.5` — کدام با تغییر font-size scale بهتر?»  
**پاسخ:** **بدون واحد** (1.5) نسبت به font-size همان عنصر.

---

## ۴) text-decoration

```css
a { text-decoration: underline; text-underline-offset: 0.15em; }
.strike { text-decoration: line-through; }
```

«offset فاصله خط از حروف — برای فارسی تمیزتر.»

---

## ۵) text-transform

```css
.label-en { text-transform: uppercase; }
```

«روی **فارسی** معنا ندارد — فقط برای لاتین/انگلیسی در badge.»

---

## ۶) letter-spacing

```css
.badge {
  letter-spacing: 0.05em;
  font-size: 0.75rem;
}
```

«کم — زیاد کردن فارسی را می‌شکند.»

---

## ۷) text-shadow (سبک)

```css
.hero-title {
  text-shadow: 0 2px 8px rgba(0,0,0,0.25);
}
```

«روی hero تیره — sparingly.»

---

## ۸) پروژه mini — مقاله وبلاگ

```html
<article class="article">
  <h1>چرا line-height مهم است؟</h1>
  <p class="lead">خلاصه یک خط.</p>
  <p>بدنه با start و line-height 1.75.</p>
  <p><a href="#">ادامه</a></p>
</article>
```

```css
.article {
  max-width: 42rem;
  margin-inline: auto;
  padding: 1.5rem;
  font-family: Tahoma, sans-serif;
}
.article h1 {
  font-size: 1.75rem;
  line-height: 1.3;
  text-align: start;
}
.lead {
  color: #64748b;
  font-size: 1.125rem;
}
.article p {
  line-height: 1.75;
  text-align: start;
}
```

## ۹) Live Coding — لینk داخل مقاله

```css
.article a {
  color: #1a5fb4;
  text-decoration: underline;
  text-underline-offset: 0.15em;
}
```

### سؤال کلاسی

«`text-align: start` در RTL کدام طرف است؟»  
**پاسخ:** لبه شروع خط — در فارسی راست.

---

## ۱۰) اشتباهات رایج

- `text-align: left` ثابت در RTL.  
- justify در عرض کم — رiver نامنظم.  
- line-height خیلی کم برای فارسی.

---

## تمرین‌ها

### ساده — `text-align: center` فقط روی h1.  
### متوسط — lead با رنگ و line-height.  
### چالشی — blockquote با border-inline-start + padding-inline.
