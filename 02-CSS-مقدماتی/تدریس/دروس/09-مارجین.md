## ۱) شروع کلاس — مسئله اول (دیالوگ قابل گفتن)

«بچه‌ها، فرض کنید برای وبلاگ شخصی‌تون HTML را تمیز نوشتید: یک `<h1>`، سه `<p>`، یک دکمه «ادامه مطلب». صفحه را باز می‌کنید و… همه‌چیز **به هم چسبیده** — مثل Word وقتی فاصله پارagraph را صفر گذاشته باشید.

یکی از همکلاسی‌ها می‌گوید: *«border دور هر پارagraph بذاریم فاصله درست بشه!»*

آیا این ایده خوبی است؟ چند تا border دور هم = شلوغی بصری. ما فاصله **بین** جعبه‌ها می‌خواهیم، نه خط دور هر جمله.

راه درست: **`margin`** — فاصله **بیرون** حاشیه، همیشه **شفاف**.»

فایل Live پیشنهادی: `تدریس/live/09-margins.html` — اول بدون margin:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — margin</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      line-height: 1.7;
      margin: 0;
      padding: 1rem;
      background: #f1f5f9;
    }
    h1 { font-size: 1.5rem; }
    p { background: #e2e8f0; } /* فقط برای دیدن لبه جعبه */
  </style>
</head>
<body>
  <h1>یادگیری CSS</h1>
  <p>پاراگراف اول — به تیتر و پارagraph بعدی چسبیده.</p>
  <p>پاراگراف دوم.</p>
  <p>پاراگراف سوم.</p>
</body>
</html>
```

**در مرورگر:** پس‌زمینه خاکستری هر پارagraph را می‌بینید؛ فاصله **بیرون** آن خاکستری خالی است — همان جایی که margin می‌نشیند.

---

## ۲) Live Coding مرحله ۱ — نفس دادن به متن

«حالا به پارagraphها فقط فاصله **عمودی** می‌دهیم. از logical properties استفاده می‌کنیم تا با RTL راحت باشیم:»

```css
h1 {
  margin-block: 0 0.75rem;
}
p {
  margin-block: 0 1rem;
}
```

«`margin-block: 0 1rem` یعنی بالا صفر، پایین یک rem — پارagraphها از هم جدا می‌شوند.»

**نمایش:** رفرش — فاصله بین بلوک‌ها ظاهر شد؛ پس‌زمینه خاکستری **فقط داخل** جعبه است، نه در فاصله بین دو پارagraph.

### سؤال کلاسی

«اگر به `p` به‌جای margin، `padding: 1rem` بدهیم، فاصله بین دو پارagraph از نظر بصری شبیه می‌شود؟ تفاوت ظریف چیست؟»  
**پاسخ:** فاصله بین جعبه‌ها ممکن است شبیه شود، اما padding **داخل** border است و پس‌زمینه عنصر را می‌پوشاند؛ margin **بیرون** border است و شفاف می‌ماند. برای فاصله **بین** دو کارت مجزا معمولاً margin (یا بعداً `gap`) درست است.

---

## ۳) margin در مقابل padding — قانون انگشت شست

«این جدول را حفظ نکنید — **در DevTools ببینید**:

| | **margin** | **padding** |
|---|-----------|-------------|
| محل | بیرون border | داخل border |
| پس‌زمینه عنصر | نمی‌گیرد (شفاف) | می‌گیرد |
| کاربرد معمول | فاصله دو کارت / دو پارagraph | فاصله متن تا لبه دکمه یا کارت |

**دکمه:** فضای کلیک و متن تا لبه = **padding**.  
**دو دکمه کنار هم:** فاصله بینشان = **margin** (یا gap).

در جزوه [`09-margins.html`](../../pages/09-margins.html) نمونه `.box` داخل `.m-outer` است — پس‌زمینه نارنجی **والد** است تا margin آبی تیره دیده شود (مطابق [`margins.css`](../../css/demos/margins.css)).»

```css
.m-outer {
  background-color: #ffe8cc;
  border: 1px solid #e67700;
}
.box {
  margin: 20px 40px;
  background-color: #1a3a5c;
  color: white;
  padding: 10px;
}
```

**Live:** margin را صفر کنید — جعبه سرمه‌ای به لبه نارنجی می‌چسبد. padding را صفر کنید — متن به لبه سرمه‌ای می‌چسبد.

### اشتباهات رایج

- دادن margin به دکمه برای «بزرگ‌تر شدن» — باید **padding** باشد.  
- انتظار رنگ در ناحیه margin — اگر رنگ می‌خواهید padding یا پس‌زمینه والد.

---

## ۴) Live Coding مرحله ۲ — shorthand و logical

«چهار مقدار shorthand مثل padding است — از بالا، جهت عقربه‌های ساعت (در فیزیکی LTR):»

```css
.box-a { margin: 1rem; }                    /* هر چهار طرف */
.box-b { margin: 1rem 2rem; }                /* block | inline */
.box-c { margin: 0.5rem 1rem 1.5rem 2rem; } /* top right bottom left */
```

«در فارسی و RTL، **logical** خواناتر است:»

```css
.card {
  margin-block: 1rem;      /* بالا و پایین نوشتار */
  margin-inline: 0.5rem;     /* شروع و پایان خط */
}
```

«`margin-inline-start` لبه **شروع متن** است — در RTL راست؛ در LTR چپ. جزوه جدول shorthand را در [`09-margins.html`](../../pages/09-margins.html) دارد.»

**در مرورگر:** یک طرف را با `margin-inline-end: 2rem` زیاد کنید — فقط یک سمت فاصله می‌گیرد.

### سؤال کلاسی

«`margin: 10px 20px 30px` — طرف چپ (در LTR) چند پیکسل است؟»  
**پاسخ:** ۲۰ پیکسل — وقتی سه مقدار باشد: بالا، راست‌وچپ، پایین؛ طرف مقابل (چپ) همان مقدار راست را می‌گیرد.

---

## ۵) Live Coding مرحله ۳ — `margin-inline: auto` و کارت ورود

«مشتری می‌گوید: کارت ورود ۶۰٪ عرض صفحه، **وسط** افقی. عرض را می‌دهیم؛ فضای باقی‌مانده را مرورگر با `auto` تقسیم می‌کند:»

```css
.login-card {
  width: 60%;
  margin: 10px auto;
  background-color: #0b6e4f;
  color: white;
  padding: 10px;
  text-align: center;
}
```

«`margin: 10px auto` یعنی بالا/پایین ۱۰px، راست/چپ **خودکار** — فقط **افقی** وسط می‌چید.  
**شرط:** عنصر **block** با عرض مشخص (یا `max-width`) — اگر `width` نباشد و جعبه کل عرض را گرفته باشد، فضای اضافه‌ای برای تقسیم نیست.»

**Live:** `margin-inline: auto` را حذف کنید — کارت به یک طرف می‌چسبد. `width: 60%` را حذف کنید — ممکن است اثر auto دیده نشود.

الگوی ستون مقاله (ترکیب با درس ۱۱):

```css
.wrapper {
  max-width: 36rem;
  margin-inline: auto;
  padding-inline: 1rem;
}
```

### سؤال کلاسی

«آیا `margin-top: auto` یک `div` را عمودی وسط صفحه می‌برد؟»  
**پاسخ:** در جریان عادی block خیر — auto عمودی در flex/grid معنا دارد؛ در مقدماتی فقط **وسط افقی** با `margin-inline: auto` (+ width/max-width).

---

## ۶) margin collapse — رفتار عجیب اما واقعی

«دو خبر پشت سر هم در HTML:

```css
.news-1 { margin-bottom: 30px; }
.news-2 { margin-top: 20px; }
```

فکر می‌کنید فاصله ۵۰ پیکسل است؟ **در جریان block معمولاً ۳۰** — بزرگ‌تر برنده می‌شود، جمع نمی‌شوند. به این **margin collapse** می‌گویند.

**در مرورگر:** demo [`m-collapse`](../../css/demos/margins.css) در جزوه — DevTools → Layout → highlight margin.

**نکته عملی:** فاصله بین عنصرهای پشت سر هم را ترجیحاً **از یک طرف** بدهید (مثلاً فقط `margin-bottom`) تا ذهن شلوغ نشود.

### سؤال کلاسی

«collapse بین margin چپ دو عنصر inline کنار هم هم هست؟»  
**پاسخ:** رفتار collapse عمودی block شایع است؛ افقی بین inline-blockها جمع می‌شود — جزئیات در دوره میانی؛ فعلاً collapse عمودی پارagraph را یادتان باشد.

---

## ۷) margin منفی — فقط اشاره

«`margin` منفی وجود دارد و layout را می‌کشد — در پروژه مقدماتی **استفاده نکنید** مگر با هدف و تست. راه‌های مدرن (flex gap) بعداً جایگزین hack می‌شوند.»

---

## ۸) پروژه mini جلسه — ستون مقاله وسط‌چین

Live Coding مرحله‌به‌مرحله — همه مهارت‌های امروز:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ستون مقاله — margin</title>
  <style>
    body {
      margin: 0;
      font-family: Tahoma, sans-serif;
      line-height: 1.75;
      background: #e2e8f0;
      color: #0f172a;
    }
    .wrapper {
      max-width: 36rem;
      margin-inline: auto;
      padding: 1.5rem 1rem;
    }
    .panel {
      background: #ffffff;
      padding: 1.25rem;
      margin-block: 1rem;
      border-radius: 0.5rem;
      box-shadow: 0 1px 3px rgb(0 0 0 / 0.08);
    }
    h1 {
      margin-block: 0 1rem;
      font-size: 1.5rem;
    }
    p {
      margin-block: 0 1rem;
    }
    p:last-child {
      margin-block-end: 0;
    }
    .btn {
      display: inline-block;
      margin-block-start: 0.5rem;
      padding: 0.5rem 1rem;
      background: #2563eb;
      color: #fff;
      text-decoration: none;
      border-radius: 0.375rem;
    }
  </style>
</head>
<body>
  <div class="wrapper">
    <h1>وسط‌چین با margin-inline: auto</h1>
    <section class="panel">
      <p>پاراگراف اول — فاصله تا پارagraph بعد collapse را در DevTools ببینید.</p>
      <p>پاراگراف دوم.</p>
      <a class="btn" href="#">ادامه مطلب</a>
    </section>
  </div>
</body>
</html>
```

**نمایش:** عرض پنجره را باریک و پهن کنید — `max-width` ثابت می‌ماند، `auto` همیشه وسط نگه می‌دارد.

---

## ۹) اشتباهات رایج (جمع‌بندی برای کلاس)

- `margin: auto` بدون `width` / `max-width` — اثر افقی دیده نمی‌شود.  
- margin برای فاصله **داخل** دکمه.  
- دادن هم `margin-top` و `margin-bottom` به دو sibling و تعجب از collapse.  
- فراموش کردن واحد: `margin: 20` نامعتبر است — `20px` یا `1rem`.

---

## ۱۰) جمع‌بندی مدرس و سؤالات پایانی

1. margin پس‌زمینه عنصر را می‌گیرد؟  
   **پاسخ:** خیر — شفاف است.

2. برای وسط‌چین افقی یک کارت block چه دو ویژگی کلیدی؟  
   **پاسخ:** `width` یا `max-width` + `margin-inline: auto` (یا `margin: 0 auto`).

3. `.news-1 { margin-bottom: 30px }` و `.news-2 { margin-top: 20px }` — فاصله بینشان؟  
   **پاسخ:** معمولاً ۳۰px (collapse).

**پیام پایانی:** «margin فاصله **بیرون** است — برای تنفس بین بلوک‌ها و وسط‌چین ستون. درس بعد **padding** — فاصله **داخل**، جایی که متن نفس می‌کشد.»
