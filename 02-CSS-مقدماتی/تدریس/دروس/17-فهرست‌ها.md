# سناریوی تدریس درس ۱۷: استایل فهرست‌ها (Lists)

**مدت پیشنهادی:** حدود ۶۰ دقیقه  
**هدف:** `ul`/`ol` برای محتوا و nav؛ `list-style`؛ indent در RTL.

---

## ۱) شروع — منو شبیه Word

«`<nav><ul>` برای منو — درست semantically. اما bullet ● کنار «خانه» و «تماس» — ظاهر Word.

می‌خواهیم bullet **حذف** ولی HTML list **بماند** (screen reader).»

```css
.menu ul {
  list-style: none;
  padding: 0;
  margin: 0;
}
```

---

## ۲) list-style-type

```css
.skills {
  list-style-type: disc;
}
.steps {
  list-style-type: decimal;
}
```

«`circle`, `square`, `decimal`, `persian` (browser support varies) — جزوه را باز کنید.»

---

## ۳) list-style-position

```css
li {
  list-style-position: outside; /* پیش‌فرض — marker بیرون content box */
}
```

«`inside` — marker داخل — wrap متفاوت.»

---

## ۴) padding-inline-start

«در RTL marker سمت راست:

```css
.content-list {
  padding-inline-start: 1.5rem;
}
```

«فاصله marker از متن — با margin روی `li` هم می‌شود.»

---

## ۵) فهرست تو در تو

```css
ul ul {
  list-style-type: circle;
  margin-block-start: 0.25rem;
}
```

**Live:** سه سطح — type متفاوت.

---

## ۶) ::marker (اشاره)

```css
li::marker {
  color: #2563eb;
}
```

«سطح پیشرفته‌تر — optional demo.»

---

## ۷) پروژه mini — دو لیست

1. **`.skills`** — disc، padding، فاصله li  
2. **`.menu`** — none + flex (از درس ۱۶)

```css
.skills li {
  padding-block: 0.35rem;
}
```

---

## ۸) اشتباهات رایج

- `list-style: none` بدون semantic nav (در nav با aria-label OK).  
- `padding-left` ثابت در RTL به‌جای logical.  
- div به‌جای ul برای لیست واقعی محتوا.

---

## ۹) images inside li (preview)

«لیست با آیکون — در HTML میانی img یا background-image؛ فعلاً `list-style: none` + padding برای flex row کافی است.»

---

## ۱۰) جمع‌بندی

1. چرا nav را ul نگه می‌داریم؟  
2. `list-style: none` چه می‌کند؟  
3. padding-inline-start در RTL؟
