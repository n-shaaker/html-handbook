## ۱) شروع کلاس؛ ایجاد سؤال در ذهن دانشجو

اول کلاس این‌طور شروع کن:

«بچه‌ها، تا اینجا یاد گرفتیم که چطور با HTML ساختار یک صفحه وب رو بسازیم و با CSS بهش ظاهر بدیم.

حالا فرض کنید می‌خوایم یک **کارت محصول** طراحی کنیم. مثلاً کارتی که داخلش تصویر محصول، عنوان، توضیحات و قیمت وجود داره.

به نظرتون مرورگر از کجا می‌فهمه این کارت باید چقدر **عرض** داشته باشه؟ چقدر **ارتفاع** داشته باشه؟ یا متن داخلش با چه اندازه‌ای نمایش داده بشه؟

آیا ما باید تمام این اندازه‌ها رو خودمون مشخص کنیم یا مرورگر خودش تصمیم می‌گیره؟»

اینجا یک مثال ساده روی صفحه بنویس (فایل پیشنهادی: `تدریس/live/11-size.html`):

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — اندازه و واحدها</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      padding: 1.5rem;
      background: #f1f5f9;
    }
    .card {
      background-color: lightblue;
    }
  </style>
</head>
<body>
  <div class="card">
    <h2>آموزش CSS</h2>
    <p>یادگیری طراحی صفحات وب</p>
  </div>
</body>
</html>
```

بعد بگو:

«همون‌طور که می‌بینید، ما هیچ عرض و ارتفاعی برای این کارت مشخص نکردیم، اما مرورگر خودش یک اندازه براش در نظر گرفته. حالا بیایید ببینیم این اتفاق چطور می‌افته.»

**در مرورگر:** عرض کارت تقریباً کل صفحه است؛ ارتفاع به اندازه محتوا. این نقطه ورود به درس است — هنوز وارد تعریف `px` و `rem` نشو.

## ۲) مفهوم width و height

بگو:

«در CSS دو ویژگی مهم داریم به اسم `width` و `height`.

- `width` یعنی عرض عنصر.
- `height` یعنی ارتفاع عنصر.

با این دو ویژگی می‌تونیم مشخص کنیم یک عنصر چقدر فضا اشغال کنه.»

حالا Live Coding:

```css
.card {
  width: 300px;
  height: 150px;
  background-color: lightblue;
}
```

«الان به مرورگر گفتیم این کارت باید ۳۰۰ پیکسل عرض و ۱۵۰ پیکسل ارتفاع داشته باشه.»

**نمایش:** جعبه آبی با اندازه ثابت؛ اگر متن زیاد شود ممکن است بیرون بزند یا اسکرول بخورد — بعداً به این برمی‌گردیم.

بلافاصله سؤال کن:

«اگر این دو ویژگی رو ننویسیم چی می‌شه؟»

مفهوم `auto` را معرفی کن:

```css
.card {
  width: auto;
  height: auto;
}
```

«به‌صورت پیش‌فرض، `width` و `height` مقدار `auto` دارن. یعنی مرورگر با توجه به نوع عنصر و شرایط چیدمان، اندازه اون رو محاسبه می‌کنه.

مثلاً یک `div` که عنصر **block** هست، معمولاً تمام عرض در دسترس والدش رو می‌گیره؛ اما ارتفاعش متناسب با محتواش تعیین می‌شه.»

### سؤال کلاسی

- «اگر فقط `width: 300px` بگذاریم و `height` ننویسیم، ارتفاع چه می‌شود؟»  
  **پاسخ:** معمولاً `auto` می‌ماند و با محتوا رشد می‌کند.

### اشتباهات رایج

- قفل کردن `height` روی متنی که ممکن است چند خط شود → سرریز یا بریده شدن محتوا.  
- نوشتن `width: 300` بدون واحد → قانون نامعتبر (به‌جز `0`).

## ۳) یادآوری کوتاه Block و Inline

لازم نیست دوباره درس کامل بدهی؛ فقط یادآوری:

«بچه‌ها، یادتونه گفتیم عناصر HTML از نظر نحوه نمایش به دو دسته مهم **Block** و **Inline** تقسیم می‌شن؟

این موضوع اینجا اهمیت داره، چون رفتار عرض و ارتفاع این دو نوع عنصر یکسان نیست.»

روی برد / اسلاید یا با دو باکس زنده:

**Block** (`div`, `p`, `h2`…): معمولاً از خط جدید شروع می‌شود و عرض در دسترس والد را می‌گیرد.  
**Inline** (`span`, `a`, `strong`…): در همان خط می‌نشیند و به اندازه محتوا فضا می‌گیرد.

```html
<p>این یک <span class="badge">برچسب</span> داخل جمله است.</p>
```

```css
.badge {
  width: 200px;   /* روی span معمولی معمولاً اثر مورد انتظار را ندارد */
  height: 80px;
  background: gold;
}
```

«پس اگر روی یک `span` معمولی `width` و `height` تعریف کنیم، معمولاً نتیجه‌ای که انتظار داریم رو نمی‌بینیم. چون این عنصر inline هست.

البته بعداً وقتی به `display` برسیم، یاد می‌گیریم چطور رفتار این عناصر رو تغییر بدیم.»

### انتقال

«حالا که فهمیدیم اندازه پیش‌فرض از کجا می‌آید، یک مشکل واقعی موبایل را حل می‌کنیم.»

## ۴) درصد و max-width — مسئله واقعی

«فرض کنید یک کارت طراحی کردیم که عرضش ۴۰۰ پیکسل هست. روی کامپیوتر خوب نمایش داده می‌شه، اما وقتی صفحه رو با موبایل باز می‌کنیم، ممکنه کارت از صفحه بیرون بزنه.

چطور می‌تونیم این مشکل رو حل کنیم؟»

ابتدا:

```css
.card {
  width: 400px;
}
```

**نمایش:** DevTools را روی عرض حدود ۳۲۰px ببر — اسکرول افقی یا بیرون‌زدگی را نشان بده.

بعد نسخه دوم:

```css
.card {
  width: 100%;
  max-width: 400px;
}
```

«اینجا به مرورگر گفتیم عرض کارت تا جایی که فضای والد اجازه می‌ده، کامل باشه؛ اما از ۴۰۰ پیکسل بیشتر نشه.

پس روی صفحه بزرگ حداکثر ۴۰۰ پیکسل عرض می‌گیره و روی موبایل متناسب با فضای موجود کوچک می‌شه.»

| الگو | رفتار |
|------|--------|
| `width: 400px` | همیشه ۴۰۰px — در صفحه کوچک ممکن است از والد بیرون بزند |
| `width: 100%; max-width: 400px` | متناسب با والد، سقف ۴۰۰px |

کوتاه معرفی کن:

- `max-width` — از این بزرگ‌تر نشود  
- `min-width` — از این کوچک‌تر نشود  
- `max-height` / `min-height` — همان منطق برای ارتفاع  

**تأکید:** `height` ثابت برای محتوایی که تغییر می‌کند همیشه انتخاب مناسبی نیست؛ `min-height` معمولاً منعطف‌تر است.

### سؤال کلاسی

- «اگر بخواهیم عرض کارت متناسب با والد باشد ولی از ۳۰۰px بیشتر نشود، چه می‌نویسیم؟»  
  **پاسخ:** `width: 100%; max-width: 300px;`

### اشتباهات رایج

- فقط `width: 100%` بدون سقف → روی دسکتاپ کارت خیلی پهن و ناخوانا می‌شود.  
- فقط `max-width` بدون `width`/`width: auto` در بعضی چیدمان‌ها کمتر از انتظار جمع می‌شود — الگوی رایج همان `100%` + `max-width` است.

## ۵) ورود به واحدها — مکث و سؤال

مکث کن:

«تا اینجا فهمیدیم چطور اندازه یک عنصر رو مشخص کنیم. اما یک سؤال مهم باقی مونده:

وقتی می‌نویسیم `width: 200`، این ۲۰۰ یعنی چی؟ متر؟ سانتی‌متر؟ پیکسل؟

مرورگر برای فهمیدن اندازه‌ها به **واحد** نیاز داره.»

«در CSS بیشتر اندازه‌هایی که تعریف می‌کنیم باید واحد داشته باشن. مثلاً `200px` یا `2rem`.

البته **صفر** یک استثناست و می‌تونیم بدون واحد بنویسیم.»

```css
/* صحیح */
width: 200px;
margin: 20px;
padding: 0;

/* اشتباه */
width: 200;
margin: 20 px; /* فاصله بین عدد و واحد ممنوع */
```

«امروز سه واحد پرکاربرد رو یاد می‌گیریم: `px`، `em` و `rem`.»

---

## ۶) واحد px — اندازه ثابت

«`px` مخفف CSS Pixel هست. وقتی می‌نویسیم `font-size: 20px` یعنی اندازه قلم رو ۲۰ پیکسل CSS در نظر بگیر.

مزیتش اینه که اندازه مشخص و قابل پیش‌بینی‌ای داریم.»

```css
.title {
  font-size: 32px;
}

.description {
  font-size: 16px;
}
```

سؤال:

«اگر اندازه فونت والد رو تغییر بدیم، آیا اندازه متنی که با `px` تعریف کردیم هم تغییر می‌کنه؟»

**پاسخ:** خیر — مقدار `px` مستقل از فونت والد است.

روی صفحه چند نمونه زنده نشان بده: ۱۲ / ۱۶ / ۲۴ / ۳۲ پیکسل.

**نکته مدرس:** وارد تفاوت CSS Pixel و پیکسل فیزیکی نشو؛ برای مقدماتی، «اندازه ثابت» کافی است.

---

## ۷) واحد rem — نسبت به ریشه

«حالا فرض کنید در یک سایت ۵۰ تا تیتر و متن داریم. همه رو با `px` تعریف کردیم.

بعداً تصمیم می‌گیریم اندازه فونت کلی سایت رو تغییر بدیم. باید تمام این اندازه‌ها رو یکی‌یکی تغییر بدیم؟

اینجاست که `rem` به کمک ما میاد.»

«`rem` مخفف Root em هست و اندازه خودش رو از `font-size` عنصر ریشه یعنی `html` می‌گیره.

به‌صورت پیش‌فرض، اندازه فونت ریشه در بیشتر مرورگرها ۱۶ پیکسل هست.»

```css
html {
  font-size: 16px;
}

.title {
  font-size: 2rem; /* ۳۲px */
}

.description {
  font-size: 1rem; /* ۱۶px */
}
```

با کلاس حساب کن:

| rem | با ریشه ۱۶px |
|-----|----------------|
| `1rem` | ۱۶px |
| `1.5rem` | ۲۴px |
| `2rem` | ۳۲px |
| `0.5rem` | ۸px |

«اگر اندازه فونت `html` تغییر کنه، تمام اندازه‌هایی که با `rem` تعریف شدن متناسب با اون تغییر می‌کنن. به همین دلیل `rem` برای فونت‌ها و فاصله‌های عمومی سایت کاربرد زیادی داره.»

**نمایش:** `html { font-size: 20px; }` را عوض کن — تیترها و فاصله‌های rem را با هم بزرگ کن.

### سؤال کلاسی

- «با ریشه ۱۸px، مقدار `1.5rem` چند پیکسل است؟»  
  **پاسخ:** ۲۷px.

---

## ۸) واحد em — نسبت به فونت والد / همان عنصر

«واحد `em` هم نسبی هست، اما تفاوت مهمی با `rem` داره.

`em` وقتی برای `font-size` استفاده می‌شه، نسبت به اندازه فونت **والد** محاسبه می‌شه.»

```css
.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em; /* ۱٫۵ × ۲۰ = ۳۰px */
}
```

«۱٫۵ برابر ۲۰ چقدر می‌شه؟» → **۳۰ پیکسل.**

حالا کنارش `rem`:

```css
.parent {
  font-size: 20px;
}

.child-em {
  font-size: 1.5em;  /* ۳۰px اگر والد ۲۰px باشد */
}

.child-rem {
  font-size: 1.5rem; /* ۲۴px اگر html برابر ۱۶px باشد */
}
```

«فرزند اول با `em` اندازه فونتش رو از والد می‌گیره، ولی فرزند دوم با `rem` به `html` نگاه می‌کنه.»

### نمایش زنده

والد ۲۰px؛ کنار هم `1.5em` و `1.5rem` — دانشجو اختلاف ۳۰ در برابر ۲۴ را ببیند.

## ۹) تله em در عناصر تو در تو

«فرض کنید یک لیست تو در تو داریم و به تمام `li`ها می‌گیم اندازه فونتشون `1.2em` باشه.

فکر می‌کنید تمام متن‌ها یک اندازه می‌شن؟»

```css
li {
  font-size: 1.2em;
}
```

```html
<ul>
  <li>سطح ۱
    <ul>
      <li>سطح ۲
        <ul>
          <li>سطح ۳</li>
        </ul>
      </li>
    </ul>
  </li>
</ul>
```

«نه! چون هر `li` می‌تونه داخل یک `li` دیگه قرار بگیره. پس هر سطح اندازه خودش رو از والدش می‌گیره و اندازه‌ها روی هم ضرب می‌شن.»

با فرض والد اولیه ۱۶px تقریباً:

- سطح ۱: ۱۹٫۲px  
- سطح ۲: ۲۳٫۰۴px  
- سطح ۳: ۲۷٫۶۵px  

«برای همین وقتی می‌خوایم اندازه فونت در تمام بخش‌های سایت قابل پیش‌بینی باشه، `rem` انتخاب ساده‌تریه.»

### اشتباهات رایج

- `font-size: 1.2em` روی همه نسل‌های تو در تو بدون فکر → متن هر سطح درشت‌تر.  
- گیج کردن: `em` روی `padding` نسبت به **فونت همان عنصر** است (بعد از محاسبه `font-size` همان عنصر) — در بخش بعد نشان می‌دهیم چرا گاهی مفید است.

---

## ۱۰) کاربرد جذاب em در padding دکمه

حتماً عملی نشان بده:

«شاید بپرسید اگر `em` گاهی دردسرساز می‌شه، پس اصلاً چرا ازش استفاده کنیم؟

چون بعضی وقت‌ها دقیقاً می‌خوایم اندازه فاصله داخلی یک عنصر متناسب با فونتش تغییر کنه.»

```html
<button class="btn small">کوچک</button>
<button class="btn medium">متوسط</button>
<button class="btn large">بزرگ</button>
```

```css
.btn {
  padding: 0.5em 1em;
  border: none;
  border-radius: 0.35em;
  background: #2563eb;
  color: #fff;
  cursor: pointer;
}

.small  { font-size: 12px; }
.medium { font-size: 16px; }
.large  { font-size: 24px; }
```

«هر سه دکمه `padding` یکسانی دارن، اما چون `font-size` متفاوتی دارن، فاصله داخلی اون‌ها هم متفاوت می‌شه.

پس وقتی فونت دکمه بزرگ‌تر می‌شه، فضای داخلیش هم متناسب با اون بزرگ‌تر می‌شه.»

**جمع‌بندی انتخاب واحد:**

- **`rem`** — اندازه‌هایی که می‌خواهیم نسبت به ریشه و یکپارچه در کل سایت باشند (فونت صفحه، فاصله‌های عمومی).  
- **`em`** — وقتی می‌خواهیم فاصله/اندازه همان کامپوننت با فونت خودش مقیاس شود (مثل دکمه).  
- **`px`** — وقتی اندازه ثابت و مستقل می‌خواهیم (مثلاً ضخامت خط ۱px، یا در آموزش برای سادگی).

## ۱۱) پروژه ترکیبی جلسه — کارت محصول

دیگر مثال‌های جدا نزن؛ یک کارت بساز و همه‌چیز را در آن جمع کن.

### Live Coding مرحله‌به‌مرحله

۱) HTML:

```html
<div class="card">
  <h2 class="card-title">کتاب آموزش CSS</h2>
  <p class="card-description">
    آموزش طراحی صفحات وب از صفر تا پیشرفته
  </p>
  <span class="card-price">۲۴۰٬۰۰۰ تومان</span>
</div>
```

۲) CSS:

```css
.card {
  width: 100%;
  max-width: 300px;
  padding: 1rem;
  border-radius: 0.5rem;
  background-color: #f5f5f5;
  box-sizing: border-box;
}

.card-title {
  font-size: 1.25rem;
  margin: 0 0 0.5rem;
}

.card-description {
  font-size: 1rem;
  margin: 0 0 1rem;
  color: #475569;
}

.card-price {
  font-size: 1.5rem;
  font-weight: bold;
  color: #0f766e;
}
```

«ببینید: با `max-width` کارت در موبایل از صفحه بیرون نمی‌زنه. برای padding و فونت‌ها از `rem` استفاده کردیم تا سلسله‌مراتب و فاصله‌ها یکپارچه باشن. اگر `html { font-size }` را عوض کنیم، کل کارت متناسب بزرگ یا کوچک می‌شود.»

**نمایش:** عرض مرورگر را کم و زیاد کن؛ بعد `html { font-size: 18px; }` را تست کن.

## ۱۲) جمع‌بندی مدرس و سؤالات پایانی

قبل از تمرین، این سه سؤال را بپرس:

1. اگر بخواهیم عرض یک کارت متناسب با عرض والد باشد، از چه واحد یا ویژگی‌ای استفاده می‌کنیم؟  
   **پاسخ راهنما:** معمولاً `%` با الگوی `width: 100%` و در عمل اغلب همراه `max-width`.

2. اگر اندازه فونت والد ۲۰ پیکسل باشد، مقدار `1.5em` برای فونت فرزند چقدر می‌شود؟  
   **پاسخ:** ۳۰ پیکسل.

3. تفاوت اصلی `1.5em` و `1.5rem` چیست؟  
   **پاسخ:** `em` (برای font-size) نسبت به فونت والد؛ `rem` همیشه نسبت به فونت `html`.

**پیام پایانی:**

«هدف این جلسه حفظ کردن جدول واحدها نبود. هدف این بود که بعد از کلاس تشخیص بدی چه زمانی `px`، چه زمانی `em` و چه زمانی `rem`؛ و بتونی یک کامپوننت واکنش‌گرا با `width` و `max-width` بسازی.»

## تمرین‌ها (ساده → چالشی)

### ساده
1. یک باکس با `width: 250px` و `height: auto` بساز؛ متن طولانی داخلش بگذار و رفتار ارتفاع را ببین.  
2. همان باکس را به `width: 100%; max-width: 250px` تغییر بده و در عرض باریک تست کن.

### متوسط
3. سه تیتر با `1rem`، `1.5rem`، `2rem` بساز؛ سپس `html { font-size: 14px }` و `20px` را مقایسه کن.  
4. لیست تو در تو با `li { font-size: 1.2em }` بساز و بزرگ شدن زنجیره‌ای را در DevTools اندازه بگیر.

### چالشی
5. کارت محصول بالا را کامل کن: دکمه «خرید» با `padding: 0.5em 1em` و دو سایز `.btn--sm` / `.btn--lg` فقط با تغییر `font-size`.  
6. بدون نگاه به جزوه توضیح بده: چرا برای فونت بدنه سایت معمولاً `rem` و برای padding دکمه گاهی `em` بهتر است.

**ارجاع:** تمرین‌های بیشتر در [`quizzes/`](../../quizzes/README.md) و صفحه جزوه [`11-size.html`](../../pages/11-size.html).
