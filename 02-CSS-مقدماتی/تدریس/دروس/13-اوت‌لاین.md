## ۱) شروع — فوکوس نامرئی

«کاربر با **Tab** بین لینک‌ها می‌رود — هیچ نشانه‌ای نمی‌بیند کجاست. outline پیش‌فرض مرورگر را با CSS **حذف** کرده‌ایم:

```css
a:focus { outline: none; }
```

**بدون جایگزین** — این برای کاربر کیبورد فاجعه است.»

«راه درست: outline **سفارشی** یا border فقط برای focus — نه حذف کامل.»

---

## ۲) outline vs border

| | border | outline |
|---|--------|---------|
| در box model width | بله (با content-box) | **خیر** — layout جابه‌جا نمی‌شود |
| گوشه | radius دارد | معمولاً rectangular |
| استفاده رایج | ظاهر کارت | focus، debug |

```css
.btn {
  border: 2px solid #2563eb;
  padding: 0.5rem 1rem;
}
.btn:focus-visible {
  outline: 3px solid #f59e0b;
  outline-offset: 2px;
}
```

**Live:** Tab بزنید — حلقه نارنجی بدون جابه‌جایی layout.

---

## ۳) propertyهای outline

```css
outline: 3px solid #f59e0b;
outline-offset: 2px;
```

«`outline-offset` فاصله outline از border — برای contrast بهتر.»

---

## ۴) :focus-visible

«`:focus` با کلیک ماوس هم فعال می‌شود — بعضی طراحان outline زشت می‌نامند.

**`:focus-visible`** فقط وقتی مرورگر فکر کند focus باید **دیده** شود (اغلب keyboard):

```css
.field:focus-visible {
  outline: 3px solid #f59e0b;
  outline-offset: 2px;
}
```

**Live:** [`13-outline.html`](../../pages/13-outline.html) + [`12-boxmodel.html`](../live/12-boxmodel.html) input.

### سؤال کلاسی

«چرا focus را با border 2px اضافه simulate نکنیم?»  
**پاسخ:** border layout را 4px جابه‌جا می‌کند (لرزش)؛ outline نه.

## ۵) debug — outline روی همه (فقط demo)

```css
* { outline: 1px solid red; }
```

«درس ۱۲ — دیدن margin/padding؛ production حذف.»

---

## ۶) پروژه mini — فرم سه فیلد

لینک + input + button — همه `:focus-visible` یکسان؛ contrast کافی.

---

## ۷) اشتباهات رایج

- `outline: none` روی `*` یا `a` بدون جایگزین.  
- رنگ outline کم‌کنtrast روی پس‌زمینه تیره.  
- confuse outline با box-shadow (shadow هم layout shift ندارد — هر دو برای focus OK).

---

## ۸) ترکیب outline و border-radius

«outline معمولاً گوشه‌های گرد border را follow نمی‌کند — برای دکمه گرد **box-shadow** focus ring هم رایج است:

```css
.btn:focus-visible {
  outline: none;
  box-shadow: 0 0 0 3px #f59e0b;
}
```

در دوره مقدماتی **outline** کافی است؛ shadow را به‌عنوان «راه دیگر بدون layout shift» نام ببرید.»

---

## ۹) جمع‌بندی و سؤالات پایانی

1. outline در box model عرض اضافه می‌کند؟  
2. چرا حذف focus بدون جایگزین ممنوع؟  
3. `:focus-visible` با `:focus` چه فرقی دارد؟

**پیام:** «دسترس‌پذیری بخش CSS شما — نه addon.»
