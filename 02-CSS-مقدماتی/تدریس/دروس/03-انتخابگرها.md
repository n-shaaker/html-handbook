## ۱) شروع — یک پاراگراف خاص

«صفحه داریم: تیتر، مقدمه، و یک **پیشنهاد ویژه**. نوشته‌ایم:

```css
p { color: gray; }
```

همه پاراگراف‌ها خاکستری شد — حتی «پیشنهاد ویژه» که باید سبز و درشت باشد.

سؤال: چطور فقط **یک** پاراگراف را بدون عوض کردن تگ HTML به `<span>` انتخاب کنیم؟  
جواب HTML: `class`. جواب CSS: **selector کلاس**.»

```html
<p>متن عادی.</p>
<p class="highlight">پیشنهاد ویژه — ۲۰٪ تخفیف</p>
```

```css
p { color: #64748b; }
.highlight {
  color: #059669;
  font-weight: bold;
}
```

**مرورگر:** فقط دومی سبز.

---

## ۲) انواع انتخابگر — وقتی لازم می‌شوند

### تگ (Element)

```css
h1 { font-size: 1.5rem; }
```

«همه `h1`ها — برای قوانین پایه سراسری.»

### کلاس (Class) — **پیش‌فرض استایل شما**

```css
.card { padding: 1rem; }
```

«HTML: `class="card"`. نقطه در CSS فراموش نشود: `.card` نه `card`.»

### شناسه (ID)

```css
#site-title { margin: 0; }
```

«HTML باید **یکتا** باشد: `id="site-title"`. برای anchor و JS؛ برای استایل تکراری **کلاس** بهتر است — specificity کمتر درگیری می‌سازد.»

### عنصر + کلاس

```css
a.btn { text-decoration: none; }
```

«فقط لینک‌هایی که class `btn` دارند — نه هر `a` و نه هر `.btn` روی `span`.»

### چند کلاس روی یک عنصر

```html
<li class="product featured">...</li>
```

```css
.product { padding: 0.5rem; }
.featured {
  background: #eff6ff;
  border-inline-start: 4px solid #2563eb;
}
.product.featured { /* هر دو کلاس روی یک تگ */ }
```

### گروه (Grouping)

```css
h1, h2, h3 {
  color: #0f172a;
  line-height: 1.3;
}
```

«یک بلوک، چند selector — DRY.»

## ۳) Live — فهرست محصول

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — انتخابگرها</title>
  <style>
    #site-title { margin: 0; color: #0f172a; }
    .product-list { list-style: none; padding: 0; margin: 0; }
    .product-list li {
      padding: 0.5rem 0;
      border-block-end: 1px solid #e2e8f0;
    }
    .product-list .featured {
      background: #eff6ff;
      padding-inline: 0.75rem;
      border-inline-start: 4px solid #2563eb;
    }
    a.external { color: #059669; }
  </style>
</head>
<body>
  <h1 id="site-title">فروشگاه نمونه</h1>
  <ul class="product-list">
    <li>محصول عادی</li>
    <li class="featured">محصول ویژه</li>
  </ul>
  <p>لینک: <a class="external" href="#">خارجی</a></p>
</body>
</html>
```

**DevTools:** Inspect روی `li.featured` → ببینید کدام ruleها match شده‌اند.

### سؤال کلاسی

«چرا برای سه محصول «ویژه» سه تا `id` بد است؟»  
**پاسخ:** id یکتا؛ class برای تکرار. id specificity بالاتر — override سخت.

### اشتباهات رایج

- `. card` (فاصله) یعنی descendant — با `.card` فرق دارد.  
- `#featured` برای ده آیتم مختلف.  
- فراموش `.` در class selector.

---

## ۴) Specificity — فقط یک جمله

«اگر conflict باشد: id قوی‌تر از class، class قوی‌تر از تگ. امروز با **class تمیز** conflict کم می‌کنیم؛ جزئیات cascade در دوره بعد.»

---

## ۵) پروژه mini — کارت محصول در لیست

دانشجو خودش `featured` را به آیتم سوم اضافه کند؛ یک `.sale` با رنگ قرمز برای قیمت (`span.sale`).

---

## ۶) descendant vs child — فقط اشاره

«فاصله در selector معنی دارد:

```css
.card .title { }   /* هر .title داخل .card */
.card > .title { } /* فقط فرزند مستقیم */
```

در مقدماتی بیشتر **class مستقیم** (`.card-title`) تا nesting عمیق — specificity و خوانایی بهتر.»

**Live:** nested div — `.card .title` هر دو سطح را می‌گیرد؛ `>` فقط یکی.

---

## ۷) Live Coding مرحله ۴ — DevTools: چه چیزی match شد؟

«بعد از هر selector، **F12 → Elements → Styles** — روی rule hover کنید؛ مرورگر می‌گوید چند element match شده.

مثال: `p` — همه پارagraphها. `.highlight` — فقط class. `p.highlight` — پارagraph **و** class هم‌زمان (specificity بالاتر).

**در مرورگر:** یک rule را disable (checkbox) — ببینید کدام element فوراً به استایل قبلی برمی‌گردد.»

### سؤال کلاسی

«`div.card` (بدون فاصله) با `div .card` فرق دارد؟»  
**پاسخ:** اولی div با class card؛ دومی هر `.card` **داخل** div — combinator درس میانی، ولی اشتباه رایج همین است.

---

## ۸) پروژه extended — ویترین فروشگاه

سه محصول + دو تا featured + لینk footer. دانشجو:

- `#footer-link` فقط یک لینk  
- `.product` برای همه li  
- `.featured` برای highlight

HTML نمونه Live:

```html
<ul class="products">
  <li class="product">کتاب CSS</li>
  <li class="product featured">دوره VIP — ۲۰٪ تخفیف</li>
  <li class="product">جزوه HTML</li>
</ul>
<p>سؤال؟ <a id="footer-link" href="#">تماس</a></p>
```

```css
.product { padding: 0.5rem; border: 1px solid #e2e8f0; margin-block: 0.35rem; }
.product.featured {
  border-color: #059669;
  background: #ecfdf5;
  font-weight: 600;
}
#footer-link { color: #2563eb; }
```

**نمایش [`03-selectors.html`](../../pages/03-selectors.html)** — جدول selectorها را *بعد* از Live پر کنید.

### اشتباهات رایج

- `highlight` بدون نقطه در CSS.  
- id روی هر li «برای رنگ» — specificity جنگ.  
- selector `*` برای reset بی‌هدف در کل پروژه.

---

## ۹) جمع‌بندی و سؤالات پایانی

1. `.lead` در برابر `p` چه فرقی در *هدف* دارد؟  
2. `a.btn` چه عنصرهایی را می‌گیرد؟  
3. چرا استایل تکراری با class نه id؟  
4. `.product.featured` یعنی چه?

**پیام:** «نام class را **معنادار** بگذارید — `.box1` بعداً فراموش می‌شود.»

## تمرین‌ها (ساده → چالشی)

### ساده
1. `.muted` برای متن ثانویه (`color: #64748b`).  
2. در DevTools یک rule `.product` را موقت disable کنید.

### متوسط
3. `h1, .subtitle` یک `color` با **group selector** (کاما).  
4. `a.btn` فقط لینkهای class btn — نه button.

### چالشی
5. منوی nav: `.menu a` بدون underline، `.menu a.active` پس‌زمینه + `aria-current="page"` در HTML.  
6. لیست سه محصول با `.featured` — specificity `li.featured` vs `.featured` را compare کنید.
