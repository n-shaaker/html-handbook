## ۳) Live Coding مرحله‌ای

### مرحله ۱ — HTML (۵ دقیقه)

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>کارت معرفی — نام شما</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main class="page">
    <article class="card">
      <h1 class="card__name">سارا احمدی</h1>
      <p class="card__role">توسعه‌دهنده front-end</p>
      <p class="card__bio">علاقه‌مند به HTML معنادار و CSS خوانا.</p>
      <h2 class="card__heading">مهارت‌ها</h2>
      <ul class="skills">
        <li>HTML</li>
        <li>CSS</li>
        <li>Git</li>
      </ul>
      <nav class="contact" aria-label="تماس">
        <ul>
          <li><a href="mailto:hello@example.com">ایمیل</a></li>
          <li><a href="https://example.com">وب‌سایت</a></li>
        </ul>
      </nav>
    </article>
  </main>
</body>
</html>
```

### مرحله ۲ — پایه و layout (۱۰ دقیقه)

```css
/* style.css */
*, *::before, *::after { box-sizing: border-box; }

body {
  margin: 0;
  font-family: "Vazirmatn", Tahoma, sans-serif;
  font-size: 1rem;
  line-height: 1.75;
  color: #1e293b;
  background: #e2e8f0;
}

.page {
  max-width: 28rem;
  margin-inline: auto;
  padding: 1.5rem;
}
```

### مرحله ۳ — کارت (۱۰ دقیقه)

```css
.card {
  background: #ffffff;
  border: 1px solid #e2e8f0;
  border-radius: 0.75rem;
  padding: 1.5rem;
}

  margin-block: 0 0.25rem;
  font-size: 1.5rem;
  font-weight: 700;
}

.card__role {
  margin-block: 0 1rem;
  color: #2563eb;
  font-weight: 600;

  margin-block: 0 1.25rem;
  color: #475569;
}

.card__heading {
  margin-block: 0 0.5rem;
  font-size: 1rem;
}
```

## ۴) معیار قبولی (Live / تحویل)

- `style.css` جدا — بدون inline جز استثناء  
- `dir="rtl"` و `lang="fa"`  
- contrast کافی  
- `:focus-visible` روی لینkها  
- بدون scroll افقی ناخواسته در viewport معمول  
- screenshot DevTools box model روی `.card`
