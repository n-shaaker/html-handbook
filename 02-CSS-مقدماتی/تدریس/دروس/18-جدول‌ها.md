## ۱) شروع — جدول HTML خام

«جدول ساعات کاری — هر سلول border جدا — **double line** بین سلول‌ها؛ header از body جدا نیست.

```css
.schedule {
  border-collapse: collapse;
  width: 100%;
  max-width: 28rem;
}
```

یک خط — مرز مشترک.»

---

## ۲) border-collapse vs separate

| collapse | separate |
|----------|----------|
| مرز ادغام | فاصله بین سلول (`border-spacing`) |

«مقدماتی: **collapse** برای اکثر جداول داده.»

```css
.schedule th,
.schedule td {
  border: 1px solid #cbd5e1;
  padding: 0.5rem 0.75rem;
  text-align: start;
}
```

---

## ۳) thead و th

```css
.schedule th {
  background: #f1f5f9;
  font-weight: 600;
}
```

«HTML: `<th scope="col">` — دسترس‌پذیری.»

---

## ۴) zebra stripes

```css
.schedule tbody tr:nth-child(even) {
  background: #f8fafc;
}
```

**Live:** ردیف‌ها alternate — خوانایی ردیف بلند.

---

## ۵) caption

```css
.schedule caption {
  caption-side: top;
  text-align: start;
  font-weight: 600;
  padding-block-end: 0.5rem;
}
```

```html
<table class="schedule">
  <caption>ساعات کاری</caption>
  ...
</table>
```

---

## ۶) width و overflow

«جدول پهن — `max-width` روی table + `overflow-x: auto` روی wrapper (preview responsive).»

```html
<div class="table-wrap">
  <table>...</table>
</div>
```

```css
.table-wrap {
  overflow-x: auto;
}
```

## ۸) اشتباهات رایج

- border روی table و td بدون collapse.  
- `text-align: center` اجباری — اعداد و فارسی often start.  
- table برای layout صفحه (قدیم — anti-pattern).

---

## ۹) hover روی row (optional)

```css
.schedule tbody tr:hover {
  background: #eff6ff;
}
```

«برای جدول تعاملی — sparingly؛ zebra + hover با هم شلوغ نشود.»
