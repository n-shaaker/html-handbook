## ۱) شروع — بنر کافه

«می‌خواهیم بالای صفحه عکس قهوه باشد. نوشته‌ایم:

```css
.hero {
  background-image: url("cafe.jpg");
}
```

باز می‌کنید: عکس **کاشی** شده — ده‌ها فنجان کوچک! چون پیش‌فرض `background-repeat: repeat` است.

مسئله اول: repeat. مسئله دوم: متن سفید روی عکس روشن خوانده نمی‌شود — بعد overlay (درس ۶).»

---

## ۲) background-color + image

```css
.hero {
  background-color: #334155;
  background-image: url("cafe.jpg");
}
```

«اگر تصویر لود نشود، رنگ پس‌زمینه دیده می‌شود — **fallback**.»

*(در کلاس بدون فایل تصویر: فقط color + gradient.)*

```css
.hero {
  background-color: #475569;
  background-image: linear-gradient(135deg, #1e293b, #475569);
}
```

---

## ۳) background-repeat

```css
.hero {
  background-repeat: no-repeat;
}
```

«`repeat-x`, `repeat-y`, `no-repeat` — برای pattern و texture.»

---

## ۴) background-size — cover و contain

```css
.hero {
  min-height: 14rem;
  background-image: url("cafe.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

| مقدار | رفتار |
|--------|--------|
| `cover` | کل جعبه پر؛ ممکن است بریده شود |
| `contain` | کل تصویر دیده شود؛ ممکن است نوار خالی بماند |
| `100% 100%` | کشیدگی — معمولاً بد |

**Live:** DevTools — `cover` vs `contain` را عوض کنید.

### سؤال کلاسی

«برای hero تمام‌عرض که «حس پر شدن» بدهد، cover یا contain?»  
**پاسخ:** معمولاً **cover**.

---

## ۵) background-position

```css
background-position: center top;
background-position: 50% 30%;
```

«کدام بخش عکس در کادر دیده شود — مثلاً صورت در پرتره.»

---

## ۶) shorthand

```css
.hero {
  background: #334155 url("cafe.jpg") center / cover no-repeat;
}
```

«ترتیب shorthand حساس است — در مقدماتی می‌توانید property جدا بنویسید تا گیج نشوید. جزوه [`07-backgrounds.html`](../../pages/07-backgrounds.html) را باز کنید.»

---

## ۷) hero با overlay — ترکیب درس ۶

```html
<section class="hero">
  <div class="hero__overlay"></div>
  <div class="hero__content">
    <h1>کافه کتاب</h1>
    <p>فضایی برای مطالعه.</p>
  </div>
</section>
```

```css
.hero {
  position: relative;
  min-height: 14rem;
  background: url("cafe.jpg") center / cover no-repeat;
  border-radius: 0.75rem;
  overflow: hidden;
}
.hero__overlay {
  position: absolute;
  inset: 0;
  background: rgba(15, 23, 42, 0.55);
}
.hero__content {
  position: relative;
  padding: 2rem;
  color: #ffffff;
}
```

**نمایش:** متن سفید روی لایه تیره — عکس پشت.

---

## ۸) اشتباهات رایج

- `url(cafe.jpg)` مسیر اشتباه از CSS.  
- `cover` بدون `min-height` — hero صفر ارتفاع.  
- متن بدون overlay روی عکس شلوغ.

---

## ۹) پروژه mini

کارت با `background-color` ملایم + گوشه گرد (درس ۸ border-radius preview) — یا hero gradient بدون تصویر.

### ساده — `no-repeat` + `center`.  
### متوسط — `cover` + min-height 12rem.  
### چالشی — hero با overlay rgba و تیتر سفید.
