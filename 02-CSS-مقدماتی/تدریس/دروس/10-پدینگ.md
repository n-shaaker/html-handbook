## ۱) شروع کلاس — مسئله اول (دیالوگ)

«بچه‌ها، کارت اعلان ساختیم — border گرد، پس‌زمینه آبی روشن، متن مهم:

*«کلاس فردا لغو شد.»*

باز می‌کنید و متن **می‌چسبد** به خط دور کارت — انگار داخل جعبه خفه شده.

یکی می‌گوید margin بذاریم. margin **بیرون** کارت است — فاصله کارت تا کارت بعدی. ما فاصله **متن تا لبه داخل** خود کارت می‌خواهیم.

جواب: **`padding`**.»

Live — `تدریس/live/10-padding.html`:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — padding</title>
  <style>
    body {
      font-family: Tahoma, sans-serif;
      padding: 1.5rem;
      background: #f8fafc;
    }
    .notice {
      background-color: #d8ecff;
      border: 1px solid #93c5fd;
      max-width: 24rem;
    }
    .notice-tight { /* هنوز padding نداریم */ }
  </style>
</head>
<body>
  <div class="notice notice-tight">
    کلاس فردا لغو شد — لطفاً جزوه را از سایت بخوانید.
  </div>
</body>
</html>
```

**در مرورگر:** آبی دور متن است اما متن به لبه چسبیده — همان demo «tight» در [`10-padding.html`](../../pages/10-padding.html).

## ۲) Live Coding مرحله ۱ — تنفس داخل کارت

```css
.notice-roomy {
  padding: 25px 40px;
}
```

«بالا/پایین ۲۵، راست/چپ ۴۰ — متن **داخل** همان پس‌زمینه آبی فضا می‌گیرد.»

**نمایش:** دو کارت کنار هم — tight و roomy — تفاوت خوانایی.

### سؤال کلاسی

«padding می‌تواند منفی باشد؟»  
**پاسخ:** خیر — برخلاف margin، padding منفی ندارد.

---

## ۳) padding در مدل جعبه‌ای

«ترتیب از داخل به بیرون:

**content → padding → border → margin**

padding جزء **ابعاد داخلی** جعبه است — پس‌زمینه `background-color` آن را می‌پوشاند (margin نمی‌پوشاند).

در DevTools → Elements → Computed → box model diagram: لایه padding را highlight کنید.»

### اشتباهات رایج

- padding برای فاصله **بین دو کارت** مجزا (باید margin یا gap).  
- `padding: 20` بدون واحد — نامعتبر.

---

## ۴) Live Coding مرحله ۲ — shorthand و logical

همان قواعد margin:

```css
.pad-a { padding: 1rem; }
.pad-b { padding: 0.5rem 1rem; }           /* block | inline */
.pad-c { padding: 0.25rem 0.5rem 0.75rem 1rem; }
```

Logical (RTL-friendly):

```css
.card {
  padding-block: 1rem;
  padding-inline: 1.5rem;
}
```

**Live:** `padding-block-start: 0` — فقط بالای محتوا به border می‌چسبد.

جدول shorthand در جزوه [`10-padding.html`](../../pages/10-padding.html) — با margin یکسان است.

## ۵) Live Coding مرحله ۳ — دکمه واقعی

«عرض دکمه را با `width: 200px` ثابت نکنید — با **padding** و متن، دکمه خودش اندازه می‌گیرد:»

```css
.btn {
  display: inline-block;
  padding: 10px 24px;
  background-color: #1a5fb4;
  color: white;
  text-decoration: none;
  border-radius: 6px;
}
```

«`display: inline-block` تا padding بالا/پایین روی لینک درست بنشیند (در `<a>` پیش‌فرض inline است).

**margin** فقط اگر دکمه را از پارagraph بعد **جدا** می‌خواهید:

```css
.btn {
  margin-block-start: 0.5rem;
}
```

**در مرورگر:** demo دو دکمه «افزودن به سبد» و «خرید» — عرض متفاوت، padding یکسان.

### سؤال کلاسی

«بدون بزرگ کردن `font-size`، ناحیه کلیک دکمه را بزرگ‌تر کنید.»  
**پاسخ:** `padding` بیشتر (یا min-height در سطح بعد).

---

## ۶) Live Coding مرحله ۴ — تله `width: 100%` + padding

«بanner تمام‌عرض:

```css
.panel {
  width: 100%;
  padding: 1.25rem;
  background: #fff;
}
```

با `box-sizing: content-box` (پیش‌فرض کلاسیک)، **عرض کل** = ۱۰۰٪ **به‌علاوه** padding — **اسکرول افقی** روی موبایل.

**پیش‌نمایش درس ۱۲:**

```css
.panel {
  box-sizing: border-box;
  width: 100%;
  padding: 1.25rem;
  background: #fff;
}
```

**در مرورگر:** قبل/بعد — DevTools box model عرض content کوچک‌تر شده تا جمع با padding = ۱۰۰٪.

### سؤال کلاسی

«padding به width اعلام‌شده اضافه می‌شود یا داخل آن جا می‌گیرد — بستگی به چه؟»  
**پاسخ:** `box-sizing` — `content-box` اضافه؛ `border-box` داخل width.

## ۷) پروژه mini جلسه — کارت محصول

```html
<article class="product-card">
  <h2>کتاب CSS</h2>
  <p>از صفر تا چیدمان واکنش‌گرا.</p>
  <p class="price">۲۴۰٬۰۰۰ تومان</p>
</article>
```

```css
.product-card {
  box-sizing: border-box;
  max-width: 18rem;
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 0.75rem;
  background: #ffffff;
}
.product-card h2 {
  margin-block: 0 0.5rem;
  font-size: 1.125rem;
}
.product-card p {
  margin: 0;
  padding-block-end: 0.75rem;
}
.product-card .price {
  padding-block-start: 0.5rem;
  border-block-start: 1px solid #f1f5f9;
  font-weight: bold;
  color: #0f766e;
}
```

«padding برای body کارت؛ `border-block-start` + padding برای جدا کردن قیمت — بدون margin اضافه بین خطوط داخل کارت.»

**نمایش:** پس‌زمینه سفید تا لبه padding می‌رسد.

---

## ۸) اشتباهات رایج

- padding زیاد + `font-size` بزرگ در موبایل بدون `max-width` — overflow افقی.  
- padding به‌جای margin بین دو `.product-card` کنار هم.  
- فراموش `inline-block` روی دکمه لینک.

---

## ۹) جمع‌بندی و سؤالات پایانی

1. padding پس‌زمینه می‌گیرد؟  
   **پاسخ:** بله — داخل border.

2. فاصله دو کارت از هم؟  
   **پاسخ:** margin (یا gap) — نه padding روی محتوای داخل یک کارت.

3. چرا `box-sizing: border-box` با `width: 100%`؟  
   **پاسخ:** padding داخل همان ۱۰۰٪ جا می‌گیرد؛ overflow کمتر.

**پیام پایانی:** «padding = فضای راحت **داخل** جعبه. margin = فاصله **بیرون**. هر دو را با هم در یک کامپوننت اشتباه نگیرید.»
