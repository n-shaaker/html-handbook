## ۱) شروع — «اینجا کلیک کن»

«متن: «قوانین را بخوانید» — لینk آبی نیست، underline ندارد. کاربر نمی‌فهمد.

HTML `<a href>` درست است — **CSS** باید affordance بدهد.»

```css
a {
  color: #2563eb;
  text-decoration: underline;
  text-underline-offset: 0.15em;
}
```

---

## ۲) حالت‌های لینk (pseudo-classes)

«لینk **وضعیت** دارد — selector با `:`:

| pseudo | معنی |
|--------|------|
| `:link` | هنوز بازدید نشده |
| `:visited` | بازدید شده |
| `:hover` | ماوس روی آن |
| `:active` | لحظه کلیک |
| `:focus-visible` | فوکوس کیبورد |

---

## ۳) ترتیب LVHA

```css
a:link { color: #1d4ed8; }
a:visited { color: #6d28d9; }
a:hover { text-decoration: underline; }
a:active { color: #b91c1c; }
```

«**L**ink → **V**isited → **H**over → **A**ctive

اگر `:link` **بعد** از `:visited` بیاید، ممکن است visited override شود — باگ کلاسیک.»

**Live:** ترتیب را عمداً برعکس — یک لینk visited تست.

### سؤال کلاسی

«چرا همه را فقط `a { color: blue }` ننویسیم?»  
**پاسخ:** visited/hover/active کنترل نمی‌شود؛ specificity یکسان اما state از دست می‌رود.

---

## ۴) حذف underline — با مسئولیت

```css
nav a {
  text-decoration: none;
}
nav a:hover {
  text-decoration: underline;
}
nav a:focus-visible {
  outline: 2px solid #f59e0b;
  outline-offset: 2px;
}
```

«بدون underline باید **رنگ/contrast/hover/focus** جبران کند.»

---

## ۵) پروژه mini — منو

```html
<nav class="menu" aria-label="اصلی">
  <ul>
    <li><a href="#home">خانه</a></li>
    <li><a href="#about">درباره</a></li>
    <li><a href="#contact">تماس</a></li>
  </ul>
</nav>
```

```css
.menu ul {
  list-style: none;
  padding: 0;
  margin: 0;
  display: flex;
  gap: 1rem;
}
.menu a:link { color: #1d4ed8; text-decoration: none; }
.menu a:visited { color: #6d28d9; }
.menu a:hover { text-decoration: underline; }
.menu a:focus-visible {
  outline: 2px solid #f59e0b;
  border-radius: 2px;
}
```

*(display:flex در demo کوتاه — در CSS میانی عمیق‌تر.)*

---

## ۶) اشتباهات رایج

- `outline: none` روی لینk.  
- visited = همان link — کاربر مسیر را گم می‌کند.  
- `:hover` روی موبایل sticky — OK اما active مهم.

---

## ۷) لینk در پارagraph vs دکمه

«`<a class="btn">` از درس padding — لینk می‌تواند block شود:

```css
a.btn {
  display: inline-block;
  padding: 0.5rem 1rem;
  background: #2563eb;
  color: #fff;
  text-decoration: none;
  border-radius: 0.375rem;
}
a.btn:visited { color: #fff; }
a.btn:hover { filter: brightness(1.05); }
```

visited سفید روی دکمه — intentional.»
