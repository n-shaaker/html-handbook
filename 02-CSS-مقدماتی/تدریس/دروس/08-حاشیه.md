## ۱) شروع — کارت بدون مرز

«دو کارت سفید روی پس‌زمینه سفید — چشم مرز را گم می‌کند. کاربر نمی‌فهمد کجا کلیک کند.

**border** خط دور **جعبه** است — بین padding و margin (box model درس ۱۲).»

```css
.card {
  background: #ffffff;
  border: 1px solid #e2e8f0;
}
```

**مرورگر:** کارت از پس‌زمینه جدا شد.

---

## ۲) سه جزء border

```css
border-width: 2px;
border-style: solid;
border-color: #2563eb;
```

«بدون **style** مرورگر border را نمی‌کشد — `border: 2px` alone ❌»

| style | ظاهر |
|--------|--------|
| `solid` | پیوسته |
| `dashed` | خط چین |
| `dotted` | نقطه |
| `none` | حذف |

**Live:** styleها را عوض کنید.

---

## ۳) shorthand

```css
border: 2px solid #2563eb;
```

«width → style → color.»

---

## ۴) یک طرف — logical در RTL

```css
.card__header {
  border-block-end: 3px solid #2563eb;
  padding: 1rem;
}
```

«`border-block-end` = انتهای block در جهت نوشتار — در RTL مثل bottom فیزیکی.  
`border-inline-start` برای accent عمودی کنار آیتم featured (درس ۳).»

### سؤال کلاسی

«خط زیر عنوان در صفحه RTL — `border-bottom` یا `border-block-end`?»  
**پاسخ:** block-end آینده‌نگرتر؛ bottom در RTL اغلب همان نتیجه.

---

## ۵) border-radius

```css
.card {
  border-radius: 0.75rem;
}
.tag {
  border: 1px dashed #94a3b8;
  border-radius: 999px;
  padding: 0.25rem 0.75rem;
}
```

«گوشه گرد — `999px` برای **pill**.  
**نکته:** تصویر child از گوشه بیرون می‌زند مگر `overflow: hidden` روی parent.»

---

## ۶) Live — کارت عضویت

```html
<article class="card">
  <header class="card__header">عضویت ویژه</header>
  <div class="card__body">
    <span class="tag">جدید</span>
    <p>دسترسی به کتابخانه دیجیتال.</p>
  </div>
</article>
```

```css
body {
  font-family: Tahoma, sans-serif;
  padding: 1.5rem;
  background: #f8fafc;
}
.card {
  max-width: 22rem;
  background: #ffffff;
  border: 1px solid #e2e8f0;
  border-radius: 0.75rem;
  overflow: hidden;
}
.card__header {
  padding: 1rem;
  border-block-end: 3px solid #2563eb;
  font-weight: 600;
}
.card__body { padding: 1rem; }
```

---

## ۷) اشتباهات رایج

- `border: 1px` بدون solid.  
- border همه طرف برای جدا کردن ردیف لیست — فقط `border-block-end`.  
- فراموش که border در `content-box` به عرض **اضافه** می‌شود (درس ۱۲).

---

## ۸) جمع‌بندی و تمرین

### ساده — `2px solid` دور div.  
### متوسط — pill tag با dashed.  
### چالشی — کارت با header خط آبی پایین و radius.
