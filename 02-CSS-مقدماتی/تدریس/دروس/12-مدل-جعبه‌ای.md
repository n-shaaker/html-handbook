## ۱) شروع کلاس — مسئله اول (دیالوگ)

«بچه‌ها، طراح Figma گفته: *«این کارت دقیقاً ۳۰۰ پیکسل عرض داشته باشه.»*

شما می‌نویسید:

```css
.card {
  width: 300px;
  padding: 20px;
  border: 5px solid #1a3a5c;
}
```

صفحه را deploy می‌کنید. مشتری با خط‌کش روی مانیتور: *«۳۵۰ پیکسل شده!»*

آیا مرورگر اشتباه می‌کند؟ نه — شما **`box-sizing: content-box`** (پیش‌فرض کلاسیک) دارید: `width` فقط **محتوا** است؛ padding و border **اضافه** می‌شوند.

روی تخته:

```
عرض اشغال‌شده ≈ width + padding-inline + border-inline
              ≈ 300 + 40 + 10 = 350px
```

**در مرورگر:** demo `.plan-content-box` در [`12-boxmodel.html`](../../pages/12-boxmodel.html) زیر خط `.ruler` 300px — جعبه از ruler **بزرگ‌تر** بیرون می‌زند.»

---

## ۲) نقشه چهار لایه — از داخل به بیرون

«هر عنصر block یک مستطیل لایه‌ای است:

1. **Content** — متن، تصویر، فرزندان  
2. **Padding** — فاصله داخل؛ پس‌زمینه می‌آید  
3. **Border** — خط؛ ضخامت به footprint اضافه می‌شود  
4. **Margin** — شفاف؛ فاصله تا همسایه — در `width` حساب **نمی‌شود**

نمودار رنگی جزوه (`.bm-margin` → … → `.bm-content`) در [`boxmodel.css`](../../css/demos/boxmodel.css) — همان را در کلاس روی پروژکتور باز کنید.

**DevTools:** F12 → Elements → عنصر `.plan` → Computed → diagram box model — با hover هر لایه عدد بگیرید.»

### سؤال کلاسی

«margin در diagram داخل width آبی رنگ است؟»  
**پاسخ:** خیر — margin بیرون border است و در عرض «جعبه» (border edge) نیست؛ فاصله layout تا عنصر بعد.

## ۳) Live Coding مرحله ۱ — دو جعبه کنار ruler

HTML Live:

```html
<div class="ruler">عرض هدف: 300px</div>
<div class="plan plan-content-box">content-box — از ruler بزرگ‌تر</div>
<div class="plan plan-border-box">border-box — دقیقاً 300px کل</div>
```

CSS (مطابق demo):

```css
.ruler {
  width: 300px;
  max-width: 100%;
  background-color: #ffd8a8;
  text-align: center;
  margin-bottom: 10px;
}
.plan {
  width: 300px;
  max-width: 100%;
  padding: 20px;
  border: 5px solid #1a3a5c;
  margin-bottom: 10px;
  background-color: #e8f4fd;
}
.plan-content-box { box-sizing: content-box; }
.plan-border-box  { box-sizing: border-box; }
```

**نمایش:** دومی لبه بیرونی با ruler هم‌تراز — اولی پهن‌تر.

## ۴) Live Coding مرحله ۲ — `border-box` و عرض content

```css
.card {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid blue;
}
```

«**۲۰۰px = از لبه border چپ تا راست** — content داخل کوچک‌تر می‌شود:

content ≈ 200 − 40 (padding) − 10 (border) = **150px**»

**Live:** padding را 30px کنید — content باریک‌تر، **کل** همچنان 200px.

### سؤال کلاسی

«با `border-box`، اگر border ضخیم‌تر شود بدون تغییر width، چه اتفاقی برای content می‌افتد؟»  
**پاسخ:** content باریک‌تر — فضای ثابت بین borderها تقسیم می‌شود.

## ۵) الگوی رایج — reset سراسری

«در [`12-boxmodel.html`](../../pages/12-boxmodel.html) و اکثر پروژه‌های مدرن:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

**چرا؟** وقتی `width: 100%` + padding (درس ۱۰) می‌نویسید، دیگر scrollbar افقی ناخواسته کمتر می‌شود. همه عنصرها یک قانون یکسان دارند.

**بحث کوتاه:** بعضی کتابخانه‌ها فقط `html { box-sizing: border-box }` و inherit — هر دو رایج است؛ مهم *آگاه بودن* است.»

---

## ۶) Live Coding مرحله ۳ — فیلد فرم تمام‌عرض

«بدون border-box:

```css
.field {
  width: 100%;
  padding: 0.5rem 0.75rem;
  border: 1px solid #cbd5e1;
}
```

**در مرورگر:** input از والد wider — overflow.

با border-box:

```css
.field {
  box-sizing: border-box;
  display: block;
  width: 100%;
  max-width: 20rem;
  padding: 0.5rem 0.75rem;
  border: 1px solid #cbd5e1;
}
```

**نمایش:** عرض کل = 100% والد (تا max-width).»

---

## ۷) یادآوری margin و height

«**Height** هم در content-box مثل width — padding/border اضافه.  
**Margin collapse** (درس ۹) در diagram دیده می‌شود ولی part of box size نیست.

**Outline** (درس ۱۳) روی layout effect ندارد — برای debug:

```css
/* فقط demo — حذف در production */
* { outline: 1px solid rgba(255, 0, 0, 0.25); }
```

»

## ۸) پروژه mini — دو کارت «هم‌عرض» در grid ساده

```html
<div class="row">
  <div class="card card--legacy">content-box</div>
  <div class="card card--modern">border-box</div>
</div>
```

```css
.row {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  max-width: 40rem;
}
.card {
  flex: 1 1 12rem;
  width: 100%;
  padding: 1rem;
  border: 4px solid #1a3a5c;
  background: #e8f4fd;
}
.card--legacy { box-sizing: content-box; }
.card--modern  { box-sizing: border-box; }
```

«در DevTools عرض computed هر کارت را screenshot برای تکلیف — label لایه‌ها.»

---

## ۹) اشتباهات رایج

- فرض `width: 300px` یعنی کل کارت بدون border-box.  
- `height` ثابت + padding زیاد → overflow متن (راه‌حل: min-height یا padding کمتر).  
- reset border-box فراموش + grid درصد — layout «random» به نظر می‌رسد.

---

## ۱۰) جمع‌بندی و سؤالات پایانی

1. در content-box، `width` کدام لایه را اندازه می‌گیرد?  
   **پاسخ:** content.

2. چرا `border-box` برای طراح «عرض ثابت کارت» بهتر است?  
   **پاسخ:** width شامل padding و border — عدد Figma = footprint.

3. margin در عرض جعبه (border box) هست?  
   **پاسخ:** خیر — بیرون border.

**پیام پایانی:** «Box model پایه همه layout است — flex و grid هم روی جعبه‌ها کار می‌کنند. فردا **outline** برای focus و debug بدون جابه‌جایی layout.»
