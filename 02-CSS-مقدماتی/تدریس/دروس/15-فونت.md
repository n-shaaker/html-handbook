## ۱) شروع کلاس — مسئله اول (دیالوگ)

«بچه‌ها، دو landing page — HTML یکسان: عنوان، زیرعنوان، سه پارagraph.

صفحه A: فقط فونت پیش‌فرض مرورگر.  
صفحه B: **Vazirmatn** با `font-weight: 700` برای تیتر و `400` برای بدنه.

کاربر نمی‌گوید «فونت عوض شد» — می‌گوید «صفحه B **حرفه‌ای‌تر** است».

قبل از رنگ و shadow، **`font-family`** تصمیم اول typographic است. امروز زبان CSS برای قلم را می‌بندیم.»

Live — بدون فونت سفارشی:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — fonts</title>
  <style>
    body {
      padding: 1.5rem;
      line-height: 1.75;
    }
    h1 { font-size: 1.75rem; }
  </style>
</head>
<body>
  <h1>عنوان دوره CSS</h1>
  <p>متن بدنه — پیش‌فرض سیستم.</p>
</body>
</html>
```

**در مرورگر:** Tahoma یا Arial بسته به OS.

## ۲) Live Coding مرحله ۱ — font-family stack

```css
body {
  font-family: "Vazirmatn", Tahoma, sans-serif;
}
```

«**Stack** = اولویت چپ به راست:  
1. Vazirmatn اگر لود/نصب شد  
2. Tahoma  
3. `sans-serif` generic — مرورگر یک sans پیش‌فرض

**Quote:** نام با فاصله → `"Inter"` یا `'Vazirmatn'`.

پنج generic: `serif`, `sans-serif`, `monospace`, `cursive`, `fantasy` — demo در [`fonts.css`](../../css/demos/fonts.css):

```css
.f-serif { font-family: "Times New Roman", Times, serif; }
.f-sans  { font-family: Arial, Helvetica, sans-serif; }
.f-mono  { font-family: "Courier New", monospace; }
```

**نمایش:** serif با زائده؛ mono عرض ثابت — برای **کد** `monospace` جدا از body.»

### سؤال کلاسی

«چرا همیشه generic آخر stack?»  
**پاسخ:** اگر هیچ فونت named نبود، مرورگر حداقل خانواده درست را انتخاب کند.

## ۳) Live Coding مرحله ۲ — font-size و rem

```css
html {
  font-size: 100%; /* معمولاً 16px */
}
body {
  font-size: 1rem;
}
h1 {
  font-size: 1.75rem;
}
.small {
  font-size: 0.875rem;
}
```

«`1rem` = اندازه فونت **html** — تغییر ریشه همه rem را scale می‌کند (درس ۱۱).

مقایسه در جزوه:

```css
.f-px  { font-size: 24px; }
.f-rem { font-size: 1.5rem; }
.f-em  { font-size: 1.5em; } /* نسبت به font-size والد */
```

**Live:** `html { font-size: 18px; }` — h1 با rem بزرگ‌تر؛ `.f-px` ثابت می‌ماند.»

### اشتباهات رایج

- فقط px روی همه سطوح — scale سخت برای accessibility.  
- `em` تو در تو روی `font-size` بدون فکر — زنجیره درشت‌شدن (درس ۱۱).

## ۴) Live Coding مرحله ۳ — font-weight

```css
h1 {
  font-weight: 700;
}
.subtitle {
  font-weight: 400;
  color: #64748b;
}
strong {
  font-weight: 600;
}
```

«`400` = normal، `700` = bold — یا کلمات `normal` / `bold`.

**مهم:** فقط weightهایی که فایل فونت دارد render دقیق — لینk 400;600;700 در head:

```html
<link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;600;700&display=swap" rel="stylesheet">
```

یا [`shared/fonts.css`](../../../shared/fonts.css) جزوه — Inter + Vazirmatn.»

**در مرورگر:** weight 600 روی strong — اگر لینk نشده، مرورger fake bold می‌کند (کج و نازک).

---

## ۵) font-style و فارسی

```css
cite {
  font-style: normal;
  color: #64748b;
  font-size: 0.9rem;
}
```

«`italic` برای فارسی اغلب synthetic و بدخوان — تمایز با **color** یا **size** بهتر است.»

---

## ۶) font shorthand (اختیاری — بعد از درک جدا)

```css
h1 {
  font: 700 1.75rem/1.3 "Vazirmatn", Tahoma, sans-serif;
}
```

«ترتیب: `font-style font-weight font-size/line-height font-family` — در تمرین اول property جدا بنویسید.»

## ۷) پروژه mini — صفحه مقاله (۱۴ + ۱۵)

```html
<article class="article">
  <h1>مدل جعبه‌ای در CSS</h1>
  <p class="subtitle">راهنمای مقدماتی برای layout</p>
  <p>بدنه با line-height 1.75 از درس ۱۴…</p>
</article>
```

```css
body {
  font-family: "Vazirmatn", Tahoma, sans-serif;
  font-size: 1rem;
  line-height: 1.75;
  color: #0f172a;
  max-width: 40rem;
  margin-inline: auto;
  padding: 1.5rem;
}
.article h1 {
  font-size: 1.75rem;
  font-weight: 700;
  margin-block: 0 0.5rem;
}
.subtitle {
  font-size: 1.125rem;
  font-weight: 400;
  color: #64748b;
  margin-block: 0 1.25rem;
}
code {
  font-family: "Courier New", Consolas, monospace;
  font-size: 0.9em;
}
```

**نمایش:** [`15-fonts.html`](../../pages/15-fonts.html) — Lalezar demo اختیاری برای display font.

## ۸) اشتباهات رایج

- لینk ده weight بدون استفاده — حجم download.  
- `font-family: Vazirmatn` بدون quote (اگر یک کلمه — OK؛ نام ترکیبی quote).  
- monospace برای کل body.  
- فراموش `line-height` همراه font-size (درس ۱۴).

---

## ۹) جمع‌بندی و سؤالات پایانی

1. چرا quote دور `"Vazirmatn"`?  
   **پاسخ:** نام چندکلمه‌ای یا با کاراکتر خاص — safe parsing.

2. `1.25rem` نسبت به چه?  
   **پاسخ:** font-size عنصر `html`.

3. fallback چرا?  
   **پاسخ:** فونت web لود نشود / آفلاین — متن still readable.

**پیام پایانی:** «Typography = family + size scale + weight. فردا **لینک‌ها** — `:link`, `:visited`, underline.»
