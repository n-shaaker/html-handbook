# تمرین جمع‌بندی — صفحه معرفی شخصی

نمونهٔ نهایی چیزی است که در پایان دورهٔ **CSS مقدماتی** از دانشجو می‌خواهید.

- **جزوه و چک‌لیست:** [`../pages/19-practice.html`](../pages/19-practice.html)
- **شروع کار دانشجو:** [`starter/`](starter/)
- **نمونهٔ تحویل (برای نمایش در کلاس):** [`solution/index.html`](solution/index.html)

## هدف

یک صفحهٔ معرفی شخصی با HTML معنادار و **یک فایل CSS خارجی** که ظاهر کامل را بسازد — بدون CSS داخلی و بدون `style` درون‌خطی.

## مباحث مجاز (فقط همین دوره)

انتخابگرها · رنگ · پس‌زمینه · border · margin · padding · width/height · px / em / rem · % · max-width · box-sizing · outline و `:focus-visible` · متن · فونت · لینک · فهرست · جدول · `inline-block` · `border-radius` · `nth-child`

## ممنوع

Flexbox · Grid · `position` · `float` · متغیر CSS · `!important` · استایل درون‌خطی

## مسیر کار دانشجو

1. پوشهٔ `starter` را کپی کنید و اسم خودتان را روی پوشه بگذارید.
2. فقط `style.css` را کامل کنید (HTML را عوض نکنید مگر لازم باشد نام/متن شخصی شود).
3. صفحه را در مرورگر و با Tab و عرض موبایل (F12) چک کنید.
4. قبل از دیدن [`solution`](solution/) خودتان تمام کنید.

## چک‌لیست تحویل

- [ ] `link` به فایل CSS خارجی
- [ ] `* { box-sizing: border-box; }`
- [ ] فونت فارسی + `line-height` خوانا
- [ ] تیترها با رنگ و `border-bottom`
- [ ] عکس پروفایل دایره‌ای
- [ ] منو بدون زیرخط؛ `:hover` و `:focus-visible`
- [ ] جدول پروژه‌ها با `caption`، `border-collapse`، ردیف راه‌راه
- [ ] محتوا با `max-width` و `margin: 0 auto` وسط‌چین
- [ ] بدون اسکرول افقی ناخواسته در موبایل
