## رویکرد تدریس — مسئله اول، بعد مفهوم

اسکریپت کامل هر درس در پوشه [`دروس/`](./دروس/) است. فایل [`سناریو-تدریس.md`](./سناریو-تدریس.md) فقط فهرست و راهنمای مسیر است، **نه** متن درس.

| اصل | معنی برای مدرس |
|-----|----------------|
| **مسئله اول** | با سناریوی واقعی (فرم بدون `name`، heading فقط برای سایز، جدول layout…) شروع کن؛ تعریف بعد از «چرا» |
| **دیالوگ فارسی** | جمله‌های قابل خواندن سر کلاس — نه bullet خلاصه |
| **چرخه ثابت** | مفهوم → Live code → مرورگر → سؤال چالشی → راه‌حل |
| **یادآوری کوتاه** | وب/DOM، Block/Inline — فقط وقتی درس به آن می‌رسد |
| **پایان درس** | mini-project + سؤالات + تمرین ساده→چالشی + جدول زمان + اشتباهات رایج + پل درس بعد |
