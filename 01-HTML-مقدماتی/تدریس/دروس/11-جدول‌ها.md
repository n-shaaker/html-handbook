## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«جدول داده‌هایی را نشان می‌دهد که در ردیف و ستون معنا دارند، مانند کارنامه، قیمت کالا یا برنامهٔ هفتگی. جدول ابزار چیدمان کلی صفحه نیست. چیدمان صفحه با CSS انجام می‌شود. اگر داده واقعاً جدولی نباشد، استفاده از table ساختار را برای صفحه‌خوان گمراه‌کننده می‌کند.»

«<table> <caption>کارنامه نیم‌سال اول — درس طراحی وب</caption> <thead> <tr> <th>شماره دانشجویی</th> <th>نام</th> <th>نمره</th> </tr> </thead> <tbody> <tr> <td>۴۰۱۱۲۳۴</td> <td>سارا رضایی</td> <td>۱۸</td> </tr> <tr> <td>۴۰۱۱۲۳۵</td> <td>علی محمدی</td> <td>۱۷</td> </tr> </tbody> </table> کارنامه نیم‌سال اول — درس طراحی وب شماره دانشجویی نام نمره ۴۰۱۱۲۳۴ سارا رضایی ۱۸ ۴۰۱۱۲۳۵ علی محمدی ۱۷ هر tr یک ردیف است و سلول‌ها به ترتیب داخل آن نوشته می‌شوند. تعداد سلول‌های ردیف‌ها باید با هم جور باشد، مگر جایی که با colspan یا rowspan خانه‌ها را ادغام کرده باشید. در صفحهٔ راست‌به‌چپ، نخستین سلول در سمت راست قرار می‌گیرد. مرورگر اگر سلولی کم باشد گاهی خانهٔ خالی می‌سازد، اما بهتر است شبکه را خودتان کامل بنویسید.»

«ویژگی scope مشخص می‌کند هر th عنوان یک ستون است ( col ) یا عنوان یک ردیف ( row ). ظاهر جدول با این ویژگی عوض نمی‌شود. فایده‌اش برای صفحه‌خوان است تا هنگام خواندن یک خانه، عنوان مربوط به آن را هم بگوید.»

«<thead> <tr> <th scope="col">کالا</th> <th scope="col">قیمت</th> <th scope="col">موجودی</th> </tr> </thead> <tbody> <tr> <th scope="row">هدفون بی‌سیم</th> <td>۱٬۲۰۰٬۰۰۰ تومان</td> <td>موجود</td> </tr> </tbody> ادغام سلول‌ها: colspan و rowspan colspan="2" یعنی این سلول به اندازهٔ دو ستون پهن شود و جای دو خانه را بگیرد. rowspan="2" یعنی همین سلول به اندازهٔ دو ردیف بلند شود. هر خانه‌ای که ادغام شد، در ردیف یا ستون بعدی نباید دوباره نوشته شود؛ وگرنه جدول یک خانه اضافه پیدا می‌کند و چیدمان به‌هم می‌ریزد.»

**روی جزوه این عناوین را دنبال کنید:** *۱۱) جدول‌ها — عناصر پرکاربرد* · *ویژگی scope برای سرستون‌ها* · *ادغام سلول‌ها: colspan و rowspan* · *tfoot و colgroup*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<table>
  <caption>کارنامه نیم‌سال اول — درس طراحی وب</caption>
  <thead>
    <tr>
      <th>شماره دانشجویی</th>
      <th>نام</th>
      <th>نمره</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>۴۰۱۱۲۳۴</td>
      <td>سارا رضایی</td>
      <td>۱۸</td>
    </tr>
    <tr>
      <td>۴۰۱۱۲۳۵</td>
      <td>علی محمدی</td>
      <td>۱۷</td>
    </tr>
  </tbody>
</table>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<thead>
  <tr>
    <th scope="col">کالا</th>
    <th scope="col">قیمت</th>
    <th scope="col">موجودی</th>
  </tr>
</thead>
<tbody>
  <tr>
    <th scope="row">هدفون بی‌سیم</th>
    <td>۱٬۲۰۰٬۰۰۰ تومان</td>
    <td>موجود</td>
  </tr>
</tbody>
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<table>
  <tr>
    <th>روز</th>
    <th colspan="2">کلاس‌ها</th>
  </tr>
  <tr>
    <td rowspan="2">شنبه</td>
    <td>HTML</td>
    <td>CSS</td>
  </tr>
  <tr>
    <td>JavaScript</td>
    <td>پروژه</td>
  </tr>
</table>
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## تمرین‌ها (ساده → چالشی)

### ساده
1. همان مثال Live را بدون نگاه کردن یک بار دیگر بنویسید.
2. جزوه را باز کنید و خروجی مرورگر/Console را با پیش‌بینی خودتان مقایسه کنید.

### متوسط
3. یک variation کوچک روی مثال کلاس (مقدار دیگر، یک selector دیگر، یک عنصر DOM دیگر).
4. تمرین موضوعی در [`quizzes/`](../../quizzes/README.md) همان ماژول.

### چالشی
5. mini-project انتهای درس را کامل کنید و برای یک همکلاسی توضیح دهید **چرا** این راه‌حل کار می‌کند.
