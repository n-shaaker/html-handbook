## ۱) شروع

«`<a>کلیک</a>` بدون href — cursor pointer شاید نباشد؛ **مقصد نداریم**. وب = hypertext — **پیوند** قلب navigation.»

---

## ۲) پیوند خارجی

```html
<a href="https://www.wikipedia.org">ویکی‌پدیا</a>
```

«**مطلق** — scheme + host + path. همیشه برای سایت خارجی.»

---

## ۳) پیوند داخلی (نسبی)

```html
<a href="about.html">درباره ما</a>
<a href="../index.html">فهرست</a>
<a href="pages/07-text-tags.html">درس ۷</a>
```

**Live:** ساختار پوشه پروژه را روی برد — `.` همان پوشه، `..` والد.

### سؤال چالشی
«`href="https://"` vs `href="/"`?» — مطلق کامل vs root همین host.

### اشتباهات رایج
- backslash `\` در path — **slash** `/`

---

## ۴) anchor همان صفحه

```html
<h2 id="menu">منو</h2>
<a href="#menu">برو به منو</a>
```

«`#id` — fragment. id باید **یکتا** در صفحه.»

---

## ۵) target و rel

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">باز در تب جدید</a>
```

«`noopener` امنیت tabnabbing — **همیشه** با `_blank`.»

---

## ۶) mailto و tel

```html
<a href="mailto:info@cafe.ir">ایمیل</a>
<a href="tel:+982112345678">تماس</a>
```

---

## ۷) تصویر داخل لینk

«دکمهٔ گرافیکی = `<a>` دور `<img>` — **alt** بگوید کلیک کجا می‌برد.»

```html
<a href="../index.html">
  <img src="../images/demo.jpg" alt="رفتن به فهرست مطالب" width="120">
</a>
```

**نمایش:** [`08-links.html`](../../pages/08-links.html) — alt را با screen reader یا hover title compare.

---

## ۸) download

```html
<a href="../images/profile.jpg" download="my-photo.jpg">دانلود عکس</a>
```

«هم‌مبدأ reliableتر — cross-origin ممکن است ignore شود.»

---

## ۹) خطای href بدون https

```html
<!-- غلط — مرورگر relative فکر می‌کند -->
<a href="www.wikipedia.org">ویکی</a>

<!-- درست -->
<a href="https://www.wikipedia.org">ویکی</a>
```

**Live:** کلیک نسخه غلط — 404 local.

### اشتباهات رایج (جمع)

- `www...` بدون scheme  
- `_blank` بدون `rel="noopener noreferrer"`  
- id تکراری برای anchor  
- «click here» به‌جای متن معنادار لینk

---

## ۱۰) پروژه mini — nav کافه

```html
<nav aria-label="اصلی">
  <ul>
    <li><a href="index.html">خانه</a></li>
    <li><a href="#menu">منو</a></li>
    <li><a href="contact.html">تماس</a></li>
    <li><a href="https://instagram.com/..." target="_blank" rel="noopener noreferrer">اینستاگرام</a></li>
  </ul>
</nav>
...
<h2 id="menu">منو</h2>
```

**در مرورger:** fragment jump؛ external tab جدید.
