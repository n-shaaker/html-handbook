## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«ویژگی اطلاعات اضافه دربارهٔ یک عنصر است. همیشه در تگ آغازین نوشته می‌شود و معمولاً به شکل name="value" است. نام ویژگی می‌گوید چه چیزی تنظیم می‌شود و مقدار، تنظیم دقیق آن است. چند ویژگی با فاصله از هم جدا می‌شوند.»

«در نمونهٔ زیر دو ویژگی روی یک پیوند نوشته شده است:»

«ماوس را روی متن زیر نگه دارید:»

«در یک صفحه فارسی، می‌توان بخش انگلیسی را با زبان و جهت درست نوشت:»

**روی جزوه این عناوین را دنبال کنید:** *۱۶) ویژگی‌ها (Attributes)* · *ویژگی‌های مهم و پرکاربرد* · *ویژگی‌های بولی (Boolean)*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<a href="https://developer.mozilla.org/" title="مستندات رسمی فناوری‌های وب">MDN</a>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<p title="من یک راهنما هستم!">ماوس را روی من ببرید</p>
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<p lang="en" dir="ltr">Hello! This paragraph is English.</p>
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## ۴) نمایش در مرورگر و DevTools

- جزوه `16-attributes-styles.html` را کنار live بگذارید و پارagraph به paragraph جلو بروید.
- DevTools → Elements → computed styles؛ برای Flex/Grid overlay را فعال کنید.
- عرض viewport را باریک و پهن کنید — رفتار واکنش‌گرا را **قبل** media query هم بحث کنید اگر relevant است.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«Hello! This paragraph is English.»

«بعضی ویژگی‌ها مقدار جدا لازم ندارند. همین که نوشته شوند فعال‌اند. به این‌ها ویژگی بولی می‌گویند. نمونه‌های رایج disabled ، checked ، required ، hidden و controls هستند.»

«خطای متداول: نوشتن disabled="false" برای فعال کردن دکمه. در ویژگی بولی، حضور ویژگی یعنی فعال، حتی اگر مقدارش "false" باشد. برای اینکه دکمه غیرفعال نباشد، باید خود ویژگی را حذف کنید.»

«نکته (قرارداد نگارشی): نام ویژگی‌ها را با حروف کوچک بنویسید و مقدار را داخل نقل‌قول دوتایی بگذارید. HTML در بسیاری از موارد بدون نقل‌قول هم کار می‌کند، اما اگر مقدار فاصله یا علامت خاص داشته باشد نقل‌قول لازم است. اگر خود مقدار علامت " داشت، از نقل‌قول تکی استفاده کنید: title='او گفت "سلام"'»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
