## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«عنصر iframe یک صفحهٔ دیگر را داخل صفحهٔ شما نشان می‌دهد، مثل پنجره‌ای که محتوای جدا دارد. HTML ساختار صفحه را می‌سازد. JavaScript می‌تواند بعد از آن رفتار و واکنش بسازد. این درس هر دو را در حد آشنایی معرفی می‌کند.»

«تعریف: عنصر iframe یک قاب داخل صفحه است که صفحهٔ HTML دیگری را نمایش می‌دهد. محتوای داخل قاب سند جداگانه‌ای است و استایل صفحهٔ شما به‌طور خودکار به داخل آن نمی‌رود. برای دسترس‌پذیری همیشه ویژگی title را بنویسید تا صفحه‌خوان بگوید این قاب چیست.»

«سرویس‌های نقشه (مانند Google Maps یا نشان) و ویدیو (مانند یوتیوب و آپارات) در بخش «اشتراک‌گذاری / Embed» یک کد iframe آماده می‌دهند که کافی است آن را در صفحه خود بچسبانید:»

«نکته: بعضی سایت‌ها، مثلاً بانک‌ها و بسیاری از سایت‌های بزرگ، به دلایل امنیتی اجازه نمی‌دهند صفحه‌شان داخل iframe سایت دیگر دیده شود و به‌جای صفحه، قاب خالی یا پیام خطا دیده می‌شود. برای نقشه و ویدیو از کد جاسازی رسمی همان سرویس استفاده کنید.»

**روی جزوه این عناوین را دنبال کنید:** *۱۵) iframe و آشنایی با JavaScript* · *الف) iframe = جاسازی یک صفحه دیگر* · *نمونه واقعی: نقشه محل فروشگاه در صفحه «تماس با ما»* · *ب) تفاوت HTML و JavaScript*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<iframe src="mini-page.html" title="صفحه کوچک نمونه داخل iframe"></iframe>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<iframe
  src="https://www.google.com/maps/embed?pb=..."
  title="نقشه محل فروشگاه در تهران"
  width="600" height="300"
  loading="lazy">
</iframe>
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<button type="button">دکمه بدون رفتار</button>
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«دکمهٔ زیر فقط با HTML ساخته شده است. روی آن کلیک کنید؛ اتفاقی نمی‌افتد، چون HTML فقط خود دکمه را می‌سازد. اینکه بعد از کلیک چه کاری انجام شود، کار JavaScript است.»

«حالا همان نوع دکمه را با چند خط JavaScript داخل عنصر script فعال می‌کنیم. با هر کلیک، یک عدد به شمارندهٔ سبد خرید اضافه می‌شود. لازم نیست همین حالا همهٔ جزئیات این کد را بدانید؛ ببینید HTML چه چیزی را می‌سازد و JavaScript چه کاری روی آن انجام می‌دهد.»

«جزئیات همین الگو در درس ۲۲ آمده است. تا آنجا کافی است این تقسیم کار را به خاطر بسپارید.»

«تمرین: یک صفحهٔ کوچک، مثلاً card.html ، بسازید و آن را با iframe داخل صفحهٔ اصلی نشان دهید. ویژگی title را فراموش نکنید. سپس کد جاسازی یک ویدیوی آموزشی را از آپارات یا یوتیوب بگیرید و در همان صفحه قرار دهید.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
