## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«SVG (Scalable Vector Graphics) شکل را با توصیف هندسی می‌سازد، نه با شبکه‌ای از پیکسل‌های ثابت. به همین دلیل با بزرگ شدن تار نمی‌شود. آیکون و لوگوی سایت‌ها اغلب SVG هستند. کد SVG را می‌توان مستقیم داخل HTML نوشت، چون عنصرهای آن در صفحه قرار می‌گیرند.»

«عنصر circle یک دایره می‌سازد. ویژگی‌هایش:»

«مبدأ مختصات گوشهٔ بالا-چپ است و محور y به سمت پایین زیاد می‌شود.»

«SVG یک لوگوی ساده (با توضیح برای صفحه‌خوان) role="img" و aria-label به صفحه‌خوان می‌گویند این SVG یک تصویر است و چه معنایی دارد، شبیه alt برای img . اگر این توضیح نباشد، صفحه‌خوان ممکن است تکه‌های داخلی شکل را جدا جدا بخواند یا از آن بگذرد.»

**روی جزوه این عناوین را دنبال کنید:** *۲۱) SVG — گرافیک برداری*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<svg width="120" height="120">
  <circle cx="60" cy="60" r="45" stroke="#1a3a5c" stroke-width="4" fill="gold" />
</svg>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<svg width="260" height="110">
  <rect x="10" y="10" width="240" height="90" rx="16"
        fill="#0b6e4f" stroke="#1a3a5c" stroke-width="4" />
</svg>
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<svg width="300" height="130">
  <line x1="10" y1="120" x2="120" y2="10" stroke="crimson" stroke-width="4" />
  <polygon points="200,10 250,120 150,120" fill="#1a5fb4" />
  <text x="150" y="70" fill="#222" font-size="18">SVG</text>
</svg>
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«چون y از بالا به پایین زیاد می‌شود، میله‌ای که بلندتر است y کوچک‌تری دارد ( y + height برای همه میله‌ها ۱۴۰ است تا روی یک خط بنشینند).»

«نکته: پروندهٔ SVG را می‌توان مانند تصویر معمولی با <img src="logo.svg" alt="لوگو"> هم آورد. در این حالت اسکریپت داخل SVG اجرا نمی‌شود و بعضی تعامل‌ها کار نمی‌کنند. اگر بخواهید رنگ شکل را از CSS صفحه عوض کنید، کد SVG را مستقیم در HTML بگذارید. محور مختصات از گوشهٔ بالا-چپ شروع می‌شود و y به سمت پایین زیاد می‌شود.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
