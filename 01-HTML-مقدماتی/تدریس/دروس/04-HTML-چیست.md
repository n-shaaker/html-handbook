## ۱) شروع کلاس — مسئله واقعی

«مشتری فایل Word فرستاده:

*عنوان: کافه کتاب*  
*متن: بهترین قهوه محله*

می‌گوید: «همین را سایت کن.»

اگر همان متن را بدون برچسب در صفحه بریزیم، مرورگر **نمی‌داند** کدام خط عنوان است، کدام توضیح، کدام دکمه.

**HTML** — HyperText Markup Language — زبان **نشانه‌گذاری** است: به مرورگر می‌گوید *این `<h1>` است، این `<p>`، این `<a>` پیوند است*. رنگ و چیدمان بعداً با CSS؛ HTML **ساختار و معنا**.»

---

## ۲) تگ (Tag) چیست؟

«تگ **برچسب** دور محتواست. بیشتر تگ‌ها **جفت**‌اند: باز و بسته.»

Live Coding:

```html
<p>این یک بند متن است.</p>
```

| بخش | نقش |
|-----|-----|
| `<p>` | تگ آغاز — «از اینجا پاراگرaph» |
| متن میانی | محتوایی که کاربر می‌بیند |
| `</p>` | تگ پایان — `/` یعنی بسته |

**در مرورگر:** یک پاراگرaph با فاصله پیش‌فرض.

### سؤال کلاسی

«`<p>` و `</p>` هر کدام چه نام دارند؟ کل `<p>...</p>` چه نام دارد؟»  
**پاسخ:** هر دو **تگ**؛ کل مجموعه یک **عنصر (element)** `p`.

### اشتباهات رایج

- گفتن «HTML زبان برنامه‌نویسی است» — **نشانه‌گذاری** (markup).  
- `<P>` و `<p>` — در HTML5 یکی‌اند؛ قرارداد **حروف کوچک**.

---

## ۳) عنصر (Element)

«**عنصر** = تگ آغاز + (محتوا) + تگ پایان. تگ فقط بخشی از عنصر است.»

روی [`04-html-intro.html`](../../pages/04-html-intro.html) جدول را با کلاس پر کنید.

---

## ۴) Nesting — آخرین باز، اولین بسته

«عنصرها داخل هم می‌روند — مثل پرانتز ریاضی.»

```html
<!-- درست -->
<p>قیمت این کتاب <strong>۲۵۰ هزار تومان</strong> است.</p>

<!-- نادرست -->
<p>قیمت <strong>۲۵۰ هزار</p></strong>
```

**Live:** هر دو را در فایل جدا باز کنید → DevTools → Elements → درخت به‌هم‌ریخته در نسخه غلط.

### سؤال چالشی

«چرا مرورگر گاهی «درست» نشان می‌دهد با nesting غلط؟»  
**راه‌حل:** **error recovery** — ما **عمداً درست** می‌نویسیم؛ به حدس مرورگر تکیه نکنید.

### اشتباهات رایج

- بستن تگ‌ها به ترتیب اشتباه  
- فراموش کردن `/` در تگ بسته

---

## ۵) Attribute — `name="value"`

«**ویژگی** داخل تگ **باز** می‌آید: `نام="مقدار"`.»

```html
<a href="https://www.wikipedia.org">دانشنامه ویکی‌پدیا</a>
```

«متن لینک = محتوا؛ `href` = **مقصد**. بدون `href` مناسب، `<a>` پیوند واقعی نیست (درس ۸).»

**تأکید:** مقدار را در `"` یا `'` بگذارید.

### سؤال کلاسی

«تفاوت محتوای `<a>` و attribute `href`؟»  
**پاسخ:** محتوا visible و clickable text؛ href آدرس مقصد.

---

## ۶) Comment در HTML

```html
<!-- یادداشت برای خودمان — در صفحه دیده نمی‌شود -->
<p>این دیده می‌شود</p>
```

«مرورگر نادیده می‌گیرد. **جایگزین محتوا برای کاربر نیست.**»

### اشتباهات رایج

- باز کردن `<!--` و فراموش `-->` → بقیه فایل comment می‌شود.

---

## ۷) تگ‌های void (بدون محتوا)

```html
<br>
<hr>
<img src="photo.jpg" alt="توضیح تصویر">
```

«تگ پایانی ندارند. `img` **همیشه** `alt` (حتی خالی برای decorative) — درس ۹ و a11y.»

---

## ۸) پروژه mini جلسه — کافه کتاب

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>کافه کتاب</title>
</head>
<body>
  <h1>کافه کتاب</h1>
  <p>قهوه تازه و فضای <strong>آرام</strong> برای مطالعه.</p>
  <p><a href="#menu">مشاهده منو</a></p>
  <!-- تصویر در درس ۹ -->
</body>
</html>
```

**نمایش:** ساده اما **معنادار** — View Source با دانشجو.
