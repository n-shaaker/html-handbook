## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«در این درس چند مفهوم نزدیک به هم را کنار هم می‌بینیم تا فرق‌شان روشن شود. هر بخش را بخوانید، مثال را ببینید و بعد جدول همان بخش را مرور کنید. این مفهوم‌ها ظاهر را توضیح می‌دهند، اما انتخاب عنصر هنوز باید بر اساس معنا باشد.»

«مرورگر هر عنصر را با یک نحوهٔ نمایش پیش‌فرض نشان می‌دهد. عنصر بلوکی (Block) از خط تازه شروع می‌شود و معمولاً تمام عرض موجود را می‌گیرد، مثل یک ردیف کامل. عنصر درون‌خطی (Inline) در همان خط کنار متن می‌ماند و فقط به اندازهٔ محتوایش جا می‌گیرد. این رفتار پیش‌فرض است و با CSS و ویژگی display می‌توان آن را عوض کرد.»

«من هم Block هستم (پاراگراف p)»

«این بخش‌ها داخل همان خط کنار هم می‌مانند: span اول span دوم یک لینک و متن عادی ادامه پیدا می‌کند.»

**روی جزوه این عناوین را دنبال کنید:** *۱۴) Block و Inline، div و span، class و id* · *الف) تفاوت Block و Inline* · *ب) تفاوت div و span* · *ج) تفاوت class و id*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<div>من یک عنصر Block هستم (div)</div>
<div>من هم Block هستم (div بعدی)</div>
<p>من هم Block هستم (پاراگراف p)</p>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<p>
  این بخش‌ها داخل همان خط کنار هم می‌مانند:
  <span>span اول</span>
  <span>span دوم</span>
  <a href="#about">یک لینک</a>
  و متن عادی ادامه پیدا می‌کند.
</p>
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<div class="card">
  <h4>کتاب «شازده کوچولو»</h4>
  <p>نویسنده: آنتوان دو سنت‌اگزوپری — ۱۸۰٬۰۰۰ تومان</p>
</div>

<div class="card">
  <h4>کتاب «کیمیاگر»</h4>
  <p>نویسنده: پائولو کوئیلو — ۲۱۰٬۰۰۰ تومان</p>
</div>
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«همان خط · فقط به‌اندازه محتوا»

«نکته: بلوکی یا درون‌خطی بودن، رفتار پیش‌فرض مرورگر است و با ویژگی CSS display قابل تغییر است؛ مثلاً display: block یا display: inline . از نظر ساختار HTML، داخل span یا p نباید عنصر بلوکی مثل div بگذارید. استثنای مهم عنصر a است: در HTML5 یک پیوند می‌تواند یک بلوک کامل، مثلاً کارت شامل عنوان و بند، را در بر بگیرد، به شرطی که داخل آن پیوند دیگری نباشد.»

«ادامه در CSS: display · عرض و ارتفاع (فقط روی block معنا دارد)»

«div و span هر دو عنصر عمومی هستند و معنای خاصی مثل عنوان یا بند ندارند. فرق اصلی در نمایش پیش‌فرض است: div بلوکی است و span درون‌خطی. اگر عنصر معنایی مناسب وجود دارد، همان را به این دو ترجیح دهید.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
