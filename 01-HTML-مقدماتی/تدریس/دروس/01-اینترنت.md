## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«اینترنت شبکه‌ای جهانی از میلیون‌ها رایانه، تلفن همراه و سرور است که به هم وصل شده‌اند تا بتوانند داده را میان خود جابه‌جا کنند. داده همان اطلاعاتی است که به شکل پرونده، پیام یا صفحهٔ وب منتقل می‌شود. می‌توان اینترنت را شبکهٔ گسترده‌ای از مسیرهای ارتباطی دانست که به‌جای جابه‌جایی فیزیکی اشیا، اطلاعات را از یک دستگاه به دستگاه دیگر می‌رساند.»

«روی همین شبکه کارهای روزمرهٔ زیادی انجام می‌شود و وب‌سایت فقط یکی از آن‌هاست. چند کاربرد آشنا عبارت‌اند از:»

«نکته: اینترنت با وب یکسان نیست. اینترنت بستر شبکه و مسیر انتقال داده است. وب جهانی (WWW) یکی از خدماتی است که روی اینترنت کار می‌کند و همان صفحاتی را شامل می‌شود که با مرورگر می‌بینید. رایانامه و بسیاری از برنامه‌های پیام‌رسان هم از اینترنت استفاده می‌کنند، اما خودشان وب نیستند.»

«خطای متداول: اگر یک وب‌سایت باز نشود، لزوماً اینترنت قطع نیست. ممکن است فقط همان سرور خاموش باشد، نشانی اشتباه باشد، یا اختلال محدود به همان سایت باشد. برای تشخیص، یک سایت دیگر را هم امتحان کنید.»

**روی جزوه این عناوین را دنبال کنید:** *۱) اینترنت چیست؟* · *کاربردهای رایج اینترنت* · *اصطلاحات پایه*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله ۱ — اسکلت HTML:**

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Live — کلاس</title>
  <link rel="stylesheet" href="live.css">
</head>
<body>
  <div class="demo">محتوای live</div>
  <script src="live.js" defer></script>
</body>
</html>
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## ۴) نمایش در مرورگر و DevTools

- جزوه `01-internet.html` را کنار live بگذارید و پارagraph به paragraph جلو بروید.
- DevTools → Elements → computed styles؛ برای Flex/Grid overlay را فعال کنید.
- عرض viewport را باریک و پهن کنید — رفتار واکنش‌گرا را **قبل** media query هم بحث کنید اگر relevant است.
