## ۱) شروع کلاس؛ مسئله قبل از تعریف

اول با **مسئله** شروع کن — نه با لیست property.

«تعریف: عنوان صفحه است. این متن روی زبانهٔ مرورگر دیده می‌شود و موتورهای جستجو معمولاً همان را به‌عنوان نتیجه نشان می‌دهند. داخل بدنهٔ صفحه چاپ نمی‌شود.»

«عنوان باید کوتاه (حدود ۵۰ تا ۶۰ نویسه)، یکتا برای هر صفحه و گویای محتوای همان صفحه باشد. هر سند فقط یک title دارد.»

«تعریف: تعیین رمزگذاری نویسه‌ها. برای نمایش صحیح حروف فارسی ضروری است و بهتر است نخستین عنصر داخل head باشد؛ در غیر این صورت ممکن است متن فارسی به‌صورت نویسه‌های نامفهوم (مثل Ø³Ù„Ø§Ù… ) دیده شود.»

«تعریف: عرض نمایش را با عرض دستگاه هماهنگ می‌کند تا صفحه در تلفن همراه به‌صورت نامتناسب و بسیار کوچک دیده نشود.»

**روی جزوه این عناوین را دنبال کنید:** *۶) عناصر پرکاربرد داخل head* · *یک head کامل و واقعی*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

«عنوان باید کوتاه (حدود ۵۰ تا ۶۰ نویسه)، یکتا برای هر صفحه و گویای محتوای همان صفحه باشد. هر سند فقط یک title دارد.»

«تعریف: تعیین رمزگذاری نویسه‌ها. برای نمایش صحیح حروف فارسی ضروری است و بهتر است نخستین عنصر داخل head باشد؛ در غیر این صورت ممکن است متن فارسی به‌صورت نویسه‌های نامفهوم (مثل Ø³Ù„Ø§Ù… ) دیده شود.»

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<title>رزومه مریم احمدی | طراح وب</title>
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
<meta name="description" content="رزومه و نمونه‌کارهای مریم احمدی، طراح و توسعه‌دهنده وب در تهران">
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

«تعریف: پرونده CSS را به سند HTML پیوند می‌دهد.»

«تعریف: آیکون کوچک سایت (favicon) را مشخص می‌کند که کنار عنوان، در تب مرورگر دیده می‌شود. معمولاً یک تصویر کوچک مربعی با پسوند .ico یا .png است.»

«تعریف: برای نوشتن CSS داخلی ( style ) یا افزودن JavaScript ( script ) به‌کار می‌روند و می‌توانند در head قرار گیرند. این دو در درس‌های ۱۶ و ۲۲ کامل‌تر بررسی می‌شوند.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.
