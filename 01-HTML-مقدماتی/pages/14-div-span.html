۱۴) Block و Inline، div و span، class و id

در این درس چند مفهوم نزدیک به هم را کنار هم می‌بینیم تا فرق‌شان روشن شود. هر بخش را بخوانید، مثال را ببینید و بعد جدول همان بخش را مرور کنید. این مفهوم‌ها ظاهر را توضیح می‌دهند، اما انتخاب عنصر هنوز باید بر اساس معنا باشد.

الف) تفاوت Block و Inline

مرورگر هر عنصر را با یک نحوهٔ نمایش پیش‌فرض نشان می‌دهد. عنصر بلوکی (Block) از خط تازه شروع می‌شود و معمولاً تمام عرض موجود را می‌گیرد، مثل یک ردیف کامل. عنصر درون‌خطی (Inline) در همان خط کنار متن می‌ماند و فقط به اندازهٔ محتوایش جا می‌گیرد. این رفتار پیش‌فرض است و با CSS و ویژگی display می‌توان آن را عوض کرد. 

<div>من یک عنصر Block هستم (div)</div>
<div>من هم Block هستم (div بعدی)</div>
<p>من هم Block هستم (پاراگراف p)</p>
من یک عنصر Block هستم (div)
من هم Block هستم (div بعدی)

من هم Block هستم (پاراگراف p)

<p>
  این بخش‌ها داخل همان خط کنار هم می‌مانند:
  <span>span اول</span>
  <span>span دوم</span>
  <a href="#about">یک لینک</a>
  و متن عادی ادامه پیدا می‌کند.
</p>

این بخش‌ها داخل همان خط کنار هم می‌مانند: span اول span دوم یک لینک و متن عادی ادامه پیدا می‌کند.

مورد Block Inline
شروع از خط تازه شروع می‌شود. در همان خط جاری می‌ماند.
عرض به‌طور پیش‌فرض کل عرض موجود را می‌گیرد. فقط به اندازهٔ محتوایش جا می‌گیرد.
مثال div، p، h1، ul، table span، a، strong، em، img
کاربرد برای ساختن بخش و جعبه به‌کار می‌رود. برای علامت زدن تکهٔ کوچکی از متن به‌کار می‌رود.

نکته: بلوکی یا درون‌خطی بودن، رفتار پیش‌فرض مرورگر است و با ویژگی CSS display قابل تغییر است؛ مثلاً display: block یا display: inline. از نظر ساختار HTML، داخل span یا p نباید عنصر بلوکی مثل div بگذارید. استثنای مهم عنصر a است: در HTML5 یک پیوند می‌تواند یک بلوک کامل، مثلاً کارت شامل عنوان و بند، را در بر بگیرد، به شرطی که داخل آن پیوند دیگری نباشد.

ب) تفاوت div و span

div و span هر دو عنصر عمومی هستند و معنای خاصی مثل عنوان یا بند ندارند. فرق اصلی در نمایش پیش‌فرض است: div بلوکی است و span درون‌خطی. اگر عنصر معنایی مناسب وجود دارد، همان را به این دو ترجیح دهید.

<div>

تعریف: عنصر div ظرف بلوکی عمومی و بدون معنای خاص است. وقتی به‌کار می‌رود که عنصر معنایی مناسب در دسترس نباشد یا بخواهید چند عنصر را فقط برای CSS کنار هم گروه‌بندی کنید. خود div ظاهر ویژه‌ای ندارد؛ ظاهر کارت‌های نمونه از کلاس CSS می‌آید. 

<div class="card">
  <h4>کتاب «شازده کوچولو»</h4>
  <p>نویسنده: آنتوان دو سنت‌اگزوپری — ۱۸۰٬۰۰۰ تومان</p>
</div>

<div class="card">
  <h4>کتاب «کیمیاگر»</h4>
  <p>نویسنده: پائولو کوئیلو — ۲۱۰٬۰۰۰ تومان</p>
</div>

کتاب «شازده کوچولو»

نویسنده: آنتوان دو سنت‌اگزوپری — ۱۸۰٬۰۰۰ تومان

کتاب «کیمیاگر»

نویسنده: پائولو کوئیلو — ۲۱۰٬۰۰۰ تومان

(ظاهر کارت‌ها با CSS کلاس card ساخته می‌شود؛ خود div ظاهری ندارد.)

<span>

تعریف: عنصر span قطعهٔ درون‌خطی داخل متن است و خط تازه نمی‌سازد. وقتی فقط چند کلمه از یک جمله را می‌خواهید علامت بزنید یا به آن استایل بدهید، از span استفاده کنید. اگر کل بند معنا دارد، span جای p را نمی‌گیرد. 

<p>من در کلاس HTML <span class="highlight">ساختار صفحه</span> را یاد می‌گیرم.</p>
<p>قیمت: <span class="price">۲۵۰٬۰۰۰ تومان</span></p>

من در کلاس HTML ساختار صفحه را یاد می‌گیرم.

قیمت: ۲۵۰٬۰۰۰ تومان

مورد div span
نمایش پیش‌فرض Block (شروع در خط جدید) Inline (ادامه همان خط)
چه زمانی؟ برای گروه‌بندی بخش‌های بزرگ‌تر، وقتی عنصر معنایی مناسب نیست. برای برجسته یا علامت‌گذاری کردن چند کلمه داخل جمله.

خطای متداول: استفادهٔ افراطی از div در همه جا. ابتدا عنصر معنایی مناسب را بررسی کنید، مانند header، nav و section. اگر گزینهٔ مناسبی نبود، از div استفاده کنید. div خطا نیست، اما معنا را هم اضافه نمی‌کند.

ج) تفاوت class و id

ویژگی id نام یک عنصر است و در هر صفحه باید یکتا باشد. اگر دو عنصر id یکسان داشته باشند، پیوند و اسکریپت فقط به یکی از آن‌ها، معمولاً اولین، می‌رسند. ویژگی class نام گروه است و می‌تواند روی چند عنصر تکرار شود. پیوندی مثل #about به عنصری وصل می‌شود که id="about" دارد. 

<a href="#about">درباره</a> |
<a href="#skills">مهارت‌ها</a> |
<a href="#contact">تماس</a>

<div id="about" class="section"> ... </div>
<div id="skills" class="section"> ... </div>
<div id="contact" class="section"> ... </div>

مورد id class
تکرار نباید در یک صفحه تکرار شود. می‌تواند روی چند عنصر تکرار شود.
نوشتن در HTML id="about" class="section"
کاربرد رایج لنگر صفحه و انتخاب یک عنصر خاص در CSS یا JavaScript. استایل گروهی چند عنصر شبیه هم.
در CSS #about { ... } .section { ... }

خطای متداول: اگر دو عنصر هر دو id="menu" داشته باشند، پیوند و اسکریپت به‌درستی به هر دو نمی‌رسند. برای چیزهای مشترک از class استفاده کنید. در HTML5 شناسه می‌تواند با رقم شروع شود، اما انتخاب آن در CSS دشوار است؛ قرارداد رایج این است که نام id و class با حرف شروع شود. فاصله در مقدار class یعنی چند کلاس جدا: class="product card" دو کلاس product و card است، نه یک نام با فاصله.

چند عنصر کمکی دیگر

figure یک تصویر، نمودار یا قطعهٔ کد را با توضیحش گروه‌بندی می‌کند و figcaption همان توضیح است. جزئیات بیشتر در درس ۲۰ آمده است. time تاریخ یا ساعت را با معنای مشخص علامت می‌زند تا ماشین هم آن را بفهمد، نه فقط انسان. در درس ۲۲ دیده می‌شود. code تکه‌ای از کد را داخل جمله نشان می‌دهد و pre فاصله‌ها و خط‌های یک بلوک را همان‌طور که نوشته‌اید نگه می‌دارد. این دو در درس ۱۷ کامل‌تر توضیح داده شده‌اند.

جمع‌بندی

  1. Block معمولاً زیر هم می‌آید؛ Inline کنار هم می‌ماند.
  2. div جعبه بلوکی است؛ span تکه متن داخل خط است.
  3. id یکتا است؛ class می‌تواند مشترک باشد.

تمرین: یک صفحهٔ کوچک با سه div بسازید. به هر سه class="section" بدهید و برایشان idهای about، skills و contact بگذارید. بعد با پیوندهای # بین بخش‌ها جابه‌جا شوید و مطمئن شوید هیچ id تکراری نیست.
