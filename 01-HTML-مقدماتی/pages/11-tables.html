۱۱) جدول‌ها — عناصر پرکاربرد

جدول داده‌هایی را نشان می‌دهد که در ردیف و ستون معنا دارند، مانند کارنامه، قیمت کالا یا برنامهٔ هفتگی. جدول ابزار چیدمان کلی صفحه نیست. چیدمان صفحه با CSS انجام می‌شود. اگر داده واقعاً جدولی نباشد، استفاده از table ساختار را برای صفحه‌خوان گمراه‌کننده می‌کند.

عنصر تعریف
table عنصر table ظرف اصلی جدول است و ردیف‌ها داخل آن قرار می‌گیرند.
thead عنصر thead بخش عنوان ستون‌ها را جدا می‌کند تا معلوم باشد کدام ردیف سرستون است.
tbody عنصر tbody بدنهٔ جدول است و ردیف‌های داده داخل آن نوشته می‌شوند.
tr عنصر tr یک ردیف می‌سازد. سلول‌های آن ردیف داخل همین عنصر قرار می‌گیرند.
th عنصر th سلول عنوان است و معمولاً ضخیم و وسط‌چین دیده می‌شود. این ظاهر پیش‌فرض است؛ نقش آن معرفی ستون یا ردیف است.
td عنصر td سلول داده است و مقدار واقعی همان خانه را نگه می‌دارد.
caption عنصر caption عنوان توصیفی کل جدول است و باید اولین فرزند table باشد. این عنوان برای کاربر و صفحه‌خوان توضیح می‌دهد جدول چه چیزی را نشان می‌دهد. 
<table>
  <caption>کارنامه نیم‌سال اول — درس طراحی وب</caption>
  <thead>
    <tr>
      <th>شماره دانشجویی</th>
      <th>نام</th>
      <th>نمره</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>۴۰۱۱۲۳۴</td>
      <td>سارا رضایی</td>
      <td>۱۸</td>
    </tr>
    <tr>
      <td>۴۰۱۱۲۳۵</td>
      <td>علی محمدی</td>
      <td>۱۷</td>
    </tr>
  </tbody>
</table>

هر tr یک ردیف است و سلول‌ها به ترتیب داخل آن نوشته می‌شوند. تعداد سلول‌های ردیف‌ها باید با هم جور باشد، مگر جایی که با colspan یا rowspan خانه‌ها را ادغام کرده باشید. در صفحهٔ راست‌به‌چپ، نخستین سلول در سمت راست قرار می‌گیرد. مرورگر اگر سلولی کم باشد گاهی خانهٔ خالی می‌سازد، اما بهتر است شبکه را خودتان کامل بنویسید.

ویژگی scope برای سرستون‌ها

ویژگی scope مشخص می‌کند هر th عنوان یک ستون است (col) یا عنوان یک ردیف (row). ظاهر جدول با این ویژگی عوض نمی‌شود. فایده‌اش برای صفحه‌خوان است تا هنگام خواندن یک خانه، عنوان مربوط به آن را هم بگوید. 

<thead>
  <tr>
    <th scope="col">کالا</th>
    <th scope="col">قیمت</th>
    <th scope="col">موجودی</th>
  </tr>
</thead>
<tbody>
  <tr>
    <th scope="row">هدفون بی‌سیم</th>
    <td>۱٬۲۰۰٬۰۰۰ تومان</td>
    <td>موجود</td>
  </tr>
</tbody>

ادغام سلول‌ها: colspan و rowspan

colspan="2" یعنی این سلول به اندازهٔ دو ستون پهن شود و جای دو خانه را بگیرد. rowspan="2" یعنی همین سلول به اندازهٔ دو ردیف بلند شود. هر خانه‌ای که ادغام شد، در ردیف یا ستون بعدی نباید دوباره نوشته شود؛ وگرنه جدول یک خانه اضافه پیدا می‌کند و چیدمان به‌هم می‌ریزد. 

<table>
  <tr>
    <th>روز</th>
    <th colspan="2">کلاس‌ها</th>
  </tr>
  <tr>
    <td rowspan="2">شنبه</td>
    <td>HTML</td>
    <td>CSS</td>
  </tr>
  <tr>
    <td>JavaScript</td>
    <td>پروژه</td>
  </tr>
</table>

tfoot و colgroup

عنصر tfoot بخش پایانی جدول است و برای جمع کل یا یادداشت پایانی به‌کار می‌رود. مرورگر آن را معمولاً پایین جدول نشان می‌دهد، حتی اگر در کد پیش از tbody نوشته شود. colgroup همراه col اجازه می‌دهد به یک یا چند ستون کامل، یکجا استایل بدهید، بدون اینکه ویژگی را روی تک‌تک سلول‌ها تکرار کنید. 

<table>
  <colgroup>
    <col style="background-color: #e8f4fd">
    <col>
  </colgroup>
  <thead>
    <tr><th>کالا</th><th>قیمت</th></tr>
  </thead>
  <tbody>
    <tr><td>دفتر</td><td>۵۰</td></tr>
    <tr><td>خودکار</td><td>۲۰</td></tr>
  </tbody>
  <tfoot>
    <tr><td>جمع (هزار تومان)</td><td>۷۰</td></tr>
  </tfoot>
</table>

نکته: جدول خام HTML به‌طور پیش‌فرض حاشیهٔ مشخصی ندارد. برای خط‌کشی از CSS استفاده می‌کنیم: border: 1px solid روی th و td، و border-collapse: collapse روی table تا خط دو سلول مجاور یکی شود و دو خط چسبیده دیده نشود.

خطای متداول: چیدن کل صفحه با جدول، که روش قدیمی دههٔ نود میلادی بود. جدول برای داده است و چیدمان صفحه با CSS، مثلاً Flexbox و Grid، انجام می‌شود. ویژگی‌های قدیمی border، cellpadding و bgcolor روی table هم منسوخ شده‌اند و جای آن‌ها CSS است.

تمرین: برنامهٔ هفتگی کلاس‌های خود را با جدول بسازید. یک caption برای عنوان جدول بگذارید، سرستون روزها را با scope="col" مشخص کنید و برای کلاس دو ساعته از rowspan استفاده کنید تا یک خانه دو ردیف را بپوشاند.
