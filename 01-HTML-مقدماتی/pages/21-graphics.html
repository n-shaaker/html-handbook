۲۱) SVG — گرافیک برداری

SVG (Scalable Vector Graphics) شکل را با توصیف هندسی می‌سازد، نه با شبکه‌ای از پیکسل‌های ثابت. به همین دلیل با بزرگ شدن تار نمی‌شود. آیکون و لوگوی سایت‌ها اغلب SVG هستند. کد SVG را می‌توان مستقیم داخل HTML نوشت، چون عنصرهای آن در صفحه قرار می‌گیرند.

دایره — circle

عنصر circle یک دایره می‌سازد. cx و cy مختصات مرکز هستند، r شعاع است، fill رنگ داخل را مشخص می‌کند و stroke رنگ خط دور را. مبدأ مختصات گوشهٔ بالا-چپ است و y به سمت پایین زیاد می‌شود.

<svg width="120" height="120">
  <circle cx="60" cy="60" r="45" stroke="#1a3a5c" stroke-width="4" fill="gold" />
</svg>

مستطیل با گوشه گرد — rect

<svg width="260" height="110">
  <rect x="10" y="10" width="240" height="90" rx="16"
        fill="#0b6e4f" stroke="#1a3a5c" stroke-width="4" />
</svg>

خط، چندضلعی و متن — line / polygon / text

<svg width="300" height="130">
  <line x1="10" y1="120" x2="120" y2="10" stroke="crimson" stroke-width="4" />
  <polygon points="200,10 250,120 150,120" fill="#1a5fb4" />
  <text x="150" y="70" fill="#222" font-size="18">SVG</text>
</svg>

یک لوگوی ساده (با توضیح برای صفحه‌خوان)

role="img" و aria-label به صفحه‌خوان می‌گویند این SVG یک تصویر است و چه معنایی دارد، شبیه alt برای img. اگر این توضیح نباشد، صفحه‌خوان ممکن است تکه‌های داخلی شکل را جدا جدا بخواند یا از آن بگذرد. 

<svg width="320" height="100" role="img" aria-label="لوگوی کتاب‌فروشی Ketabyar">
  <rect width="320" height="100" rx="12" fill="#1a3a5c" />
  <circle cx="55" cy="50" r="30" fill="gold" />
  <text x="100" y="62" fill="white" font-size="32" font-family="Tahoma">Ketabyar</text>
</svg>

نمونه کاربردی: نمودار میله‌ای فروش سه ماه

<svg width="300" height="160" role="img" aria-label="فروش: فروردین ۴۰، اردیبهشت ۷۰، خرداد ۱۰۰ میلیون تومان">
  <rect x="30"  y="100" width="50" height="40"  fill="#9fb3c8" />
  <rect x="120" y="70"  width="50" height="70"  fill="#1a5fb4" />
  <rect x="210" y="40"  width="50" height="100" fill="#0b6e4f" />
  <line x1="20" y1="140" x2="280" y2="140" stroke="#222" stroke-width="2" />
</svg>

چون y از بالا به پایین زیاد می‌شود، میله‌ای که بلندتر است y کوچک‌تری دارد (y + height برای همه میله‌ها ۱۴۰ است تا روی یک خط بنشینند).

نکته: پروندهٔ SVG را می‌توان مانند تصویر معمولی با <img src="logo.svg" alt="لوگو"> هم آورد. در این حالت اسکریپت داخل SVG اجرا نمی‌شود و بعضی تعامل‌ها کار نمی‌کنند. اگر بخواهید رنگ شکل را از CSS صفحه عوض کنید، کد SVG را مستقیم در HTML بگذارید. محور مختصات از گوشهٔ بالا-چپ شروع می‌شود و y به سمت پایین زیاد می‌شود.

Canvas — بوم نقاشی با JavaScript

عنصر canvas فقط یک بوم خالی با اندازهٔ مشخص است. خود HTML شکلی روی آن نمی‌کشد. نقاشی با JavaScript و زمینهٔ دوبعدی انجام می‌شود. Canvas برای بازی، نمودار پویا و ویرایش تصویر به‌کار می‌رود. برخلاف SVG، شکل‌های کشیده‌شده عنصر جدا در صفحه نیستند و بعد از کشیدن، فقط پیکسل باقی می‌ماند. 

<canvas id="myCanvas" width="300" height="150" style="border: 1px solid #999; background: white;">
  مرورگر شما از canvas پشتیبانی نمی‌کند.
</canvas>

<script>
  const canvas = document.getElementById("myCanvas");
  const ctx = canvas.getContext("2d");

  ctx.fillStyle = "#0b6e4f";         // رنگ پر کردن
  ctx.fillRect(20, 20, 120, 80);     // مستطیل پر: فاصله از چپ، فاصله از بالا، عرض، ارتفاع

  ctx.beginPath();
  ctx.arc(220, 60, 40, 0, 2 * Math.PI); // دایره: مرکز افقی، مرکز عمودی، شعاع
  ctx.fillStyle = "gold";
  ctx.fill();

  ctx.font = "20px Tahoma";
  ctx.fillStyle = "#1a3a5c";
  ctx.fillText("Canvas", 110, 135);  // متن
</script>
مرورگر شما از canvas پشتیبانی نمی‌کند.

تفاوت SVG و Canvas

مورد SVG Canvas
نوع تصویر برداری است و شکل‌ها با توصیف هندسی ساخته می‌شوند. تصویر پیکسلی است و بعد از رسم، شبکه‌ای از نقطه‌ها باقی می‌ماند.
بزرگ‌نمایی با بزرگ شدن تیز می‌ماند، چون شکل دوباره محاسبه می‌شود. اگر نقشهٔ پیکسل را بزرگ‌تر از اندازهٔ واقعی‌اش نشان دهید تار می‌شود. با تنظیم درست اندازهٔ بوم می‌توان آن را واضح نگه داشت.
نوشتن با عنصرهایی شبیه HTML نوشته می‌شود و می‌توان آن را مستقیم در صفحه گذاشت. رسم فقط با JavaScript انجام می‌شود.
بهترین کاربرد برای آیکون، لوگو، نقشه و نمودار ساده مناسب است. برای بازی، پویانمایی سنگین و ویرایش عکس مناسب است.
دسترس‌پذیری متن و شکل‌ها در DOM هستند و می‌توان برایشان توضیح نوشت فقط پیکسل است؛ باید متن جایگزین را داخل تگ canvas یا کنار آن نوشت

تمرین: با SVG یک چراغ راهنمایی بکشید: یک مستطیل تیره و سه دایرهٔ قرمز، زرد و سبز زیر هم. برای هر دایره مرکز و شعاع را خودتان حساب کنید و به یاد داشته باشید y به سمت پایین زیاد می‌شود.
