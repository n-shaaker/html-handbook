۱۰) فهرست‌ها — عناصر ul، ol و li

فهرست چند مورد هم‌موضوع را زیر هم می‌چیند. سه شکل رایج دارد: فهرست بدون ترتیب (ul)، فهرست شماره‌دار (ol) و فهرست تعریف (dl). هر مورد فهرست ul و ol باید داخل عنصر li باشد. متن را مستقیم داخل ul یا ol ننویسید.

<ul> + <li>

تعریف: فهرست بدون ترتیب (Unordered List) وقتی به‌کار می‌رود که ترتیب موردها مهم نباشد. منوی سایت، ویژگی‌های یک محصول و نکته‌های هم‌سطح نمونه‌های مناسب آن هستند. مرورگر معمولاً کنار هر مورد یک نشانه می‌گذارد. شکل این نشانه با CSS و ویژگی list-style-type عوض می‌شود. 

<h3>ویژگی‌های گوشی مدل X</h3>
<ul>
  <li>صفحه‌نمایش ۶٫۵ اینچ</li>
  <li>حافظه داخلی ۱۲۸ گیگابایت</li>
  <li>باتری ۵۰۰۰ میلی‌آمپر ساعت</li>
</ul>

ویژگی‌های گوشی مدل X

  • صفحه‌نمایش ۶٫۵ اینچ
  • حافظه داخلی ۱۲۸ گیگابایت
  • باتری ۵۰۰۰ میلی‌آمپر ساعت

<ol> + <li>

تعریف: فهرست مرتب (Ordered List) وقتی به‌کار می‌رود که ترتیب مهم باشد، مانند مراحل انجام کار، دستور پخت یا رتبه‌بندی. مرورگر به‌طور پیش‌فرض موردها را با عدد نشان می‌دهد. نوع شماره، عدد شروع و شمارش معکوس را می‌توان با ویژگی تغییر داد. 

<h3>مراحل ثبت سفارش</h3>
<ol>
  <li>افزودن کالا به سبد خرید</li>
  <li>وارد کردن نشانی ارسال</li>
  <li>پرداخت اینترنتی</li>
</ol>

مراحل ثبت سفارش

  1. افزودن کالا به سبد خرید
  2. وارد کردن نشانی ارسال
  3. پرداخت اینترنتی

<dl>، <dt> و <dd>

تعریف: فهرست تعریف برای جفت «اصطلاح و توضیح» است:

  • dl — کل فهرست
  • dt — اصطلاح
  • dd — توضیح آن اصطلاح

برای واژه‌نامه، پرسش‌های متداول یا مشخصات «نام و مقدار» مناسب است. یک اصطلاح می‌تواند بیش از یک توضیح داشته باشد. 

<dl>
  <dt>HTML</dt>
  <dd>زبان ساختار صفحه وب</dd>
  <dt>مرورگر</dt>
  <dd>نرم‌افزاری که صفحه وب را نمایش می‌دهد</dd>
</dl>
HTML
زبان ساختار صفحه وب
مرورگر
نرم‌افزاری که صفحه وب را نمایش می‌دهد

ol: type / start / reversed

تعریف: سه ویژگی روی ol نحوهٔ شماره‌گذاری را عوض می‌کنند. type شکل شماره را تعیین می‌کند: 1 عدد، A و a حروف لاتین، I و i اعداد رومی. start عدد شروع را عوض می‌کند، حتی اگر ظاهر حروف باشد. reversed شمارش را معکوس می‌کند و مقدار جدا نمی‌گیرد؛ بودنش کافی است. 

<!-- گزینه‌های یک سؤال تستی -->
<ol type="A">
  <li>تهران</li>
  <li>اصفهان</li>
</ol>

<!-- ادامه مراحل از صفحه قبل -->
<ol start="5">
  <li>تأیید سفارش</li>
  <li>دریافت کد رهگیری</li>
</ol>

<!-- سه فیلم پرفروش هفته، از سوم تا اول -->
<ol reversed>
  <li>فیلم سوم</li>
  <li>فیلم دوم</li>
  <li>فیلم اول</li>
</ol>
  1. تهران
  2. اصفهان
  1. تأیید سفارش
  2. دریافت کد رهگیری
  1. فیلم سوم
  2. فیلم دوم
  3. فیلم اول

فهرست تودرتو (Nested List)

تعریف: فهرست تودرتو یعنی یک فهرست کامل را داخل یک li بگذارید تا زیرمجموعه بسازد. منوهای چندسطحی سایت‌ها همین‌طور ساخته می‌شوند. فهرست داخلی باید پیش از </li> بسته شود، یعنی هنوز داخل همان مورد باشد. 

<ul>
  <li>نوشیدنی‌ها
    <ul>
      <li>چای</li>
      <li>قهوه</li>
    </ul>
  </li>
  <li>شیرینی‌ها</li>
</ul>
  • نوشیدنی‌ها
    • چای
    • قهوه
  • شیرینی‌ها

خطای متداول: گذاشتن ul داخلی بعد از بسته شدن </li>. فهرست فرعی باید پیش از </li> و داخل همان مورد باشد. اگر بیرون از li بنشیند، ساختار فهرست نامعتبر می‌شود و مرورگر جای آن را حدس می‌زند.

نکته: شکل نشانهٔ ul، مانند دایره، مربع یا بدون نشانه، با ویژگی CSS list-style-type تغییر می‌کند. برای منوی افقی معمولاً list-style-type: none می‌گذارند تا نشانه حذف شود و خود فهرست با CSS کنار هم چیده شود.

نکته: هر مورد باید داخل عنصر li باشد. نوشتن متن مستقیم داخل ul یا ol درست نیست، چون مرورگر نمی‌داند آن متن کدام مورد فهرست است.
