۳) اینترنت، مرورگر و HTML چگونه به یکدیگر مرتبط می‌شوند؟

وقتی نشانی یک وب‌سایت را در مرورگر وارد می‌کنید، چند جزء با هم کار می‌کنند تا صفحه دیده شود. مسیر معمول، با کمی ساده‌سازی، این است:

۱) کاربر
نشانی را وارد می‌کند
→
۲) مرورگر
درخواست می‌فرستد
→
۳) اینترنت
داده را منتقل می‌کند
→
۴) سرور
HTML را ارسال می‌کند
→
۵) مرورگر
صفحه را نمایش می‌دهد

جزء نقش نمونه
اینترنت اینترنت مسیری است که داده را میان دستگاه شما و سرور جابه‌جا می‌کند. شبکهٔ بی‌سیم، دادهٔ تلفن همراه یا کابل شبکه
مرورگر مرورگر درخواست را می‌فرستد و پاسخ دریافتی را به شکل صفحه نشان می‌دهد. Chrome
سرور سرور پرونده‌های سایت را نگه می‌دارد و در پاسخ به درخواست، آن‌ها را می‌فرستد. رایانه‌ای که وب‌سایت روی آن میزبانی شده است
HTML HTML ساختار و معنای محتوا را مشخص می‌کند؛ یعنی کدام بخش عنوان است، کدام بند و کدام پیوند. عنوان، بند، پیوند
CSS CSS ظاهر همان ساختار را تنظیم می‌کند، مانند رنگ، قلم و چیدمان. رنگ، قلم، چیدمان
JavaScript JavaScript رفتار صفحه را می‌سازد؛ مثلاً بعد از کلیک واکنشی نشان می‌دهد یا یک حرکت ساده ایجاد می‌کند. واکنش به کلیک، پویانمایی ساده

URL چیست؟

URL نشانی دقیق یک منبع در وب است. منبع می‌تواند یک صفحه، یک تصویر یا پروندهٔ دیگری باشد. این نشانی معمولاً در نوار نشانی مرورگر دیده می‌شود و سه بخش رایج دارد: 

https://www.example.com/about.html
│       │               │
│       │               └─ مسیر صفحه یا پرونده
│       └─ نام دامنه
└─ پروتکل امن (HTTPS)

نکته (DNS): پیش از آنکه درخواست به سرور برسد، مرورگر باید بداند آن سرور در شبکه کجاست. برای همین ابتدا نام دامنه، مثلاً www.example.com، را از سامانهٔ DNS می‌پرسد و نشانی IP را می‌گیرد. بعد درخواست HTTP یا HTTPS را به همان نشانی می‌فرستد. در نمودار بالا این پرسش DNS پیش از مرحلهٔ ۲ انجام می‌شود.

نکته: وقتی روی رایانهٔ خودتان تمرین می‌کنید، پرونده را مستقیم در مرورگر باز می‌کنید و معمولاً سرور واقعی در کار نیست. بعد از انتشار، همان پرونده‌ها روی سرور قرار می‌گیرند تا دیگران از طریق اینترنت به آن‌ها برسند.

خطای متداول: این تصور که HTML خودش شبکه است یا بدون درخواست «در اینترنت حرکت می‌کند». پروندهٔ HTML از طریق اینترنت فرستاده می‌شود، اما فرستنده سرور است، مسیر اینترنت است و نمایش‌دهنده مرورگر. HTML فقط محتوای ساختاریافتهٔ همان پرونده است.
