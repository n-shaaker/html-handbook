۱۲) فرم‌ها — عناصر پرکاربرد

تمرین کامل: فرم-کامل فرم پیشرفته · استایل: CSS فرم

فرم راهی است برای گرفتن اطلاعات از کاربر، مانند تماس، ورود، جستجو و ثبت‌نام. HTML شکل فیلدها را می‌سازد و مشخص می‌کند داده به کدام نشانی فرستاده شود. ذخیره و پردازش آن داده کار HTML نیست و بر عهدهٔ برنامهٔ سمت سرور است.

عنصر تعریف
form عنصر form ظرف اصلی فرم است. فیلدها داخل آن قرار می‌گیرند و با هم ارسال می‌شوند.
label عنصر label برچسب فیلد است. اگر با for به id همان فیلد وصل شود، کلیک روی متن هم فیلد را فعال می‌کند.
input عنصر input ورودی تک‌خطی است. با ویژگی type مشخص می‌شود متن، رایانامه، گذرواژه یا گزینه است.
textarea عنصر textarea ناحیهٔ متن چندخطی است و برخلاف input تگ پایانی دارد.
select + option select فهرست کشویی است و هر option یکی از گزینه‌های قابل انتخاب آن است.
button عنصر button دکمهٔ اقدام است. نوع پیش‌فرض دکمه‌ای که داخل فرم باشد ارسال فرم است.

نمونه واقعی: فرم «تماس با ما» یک فروشگاه اینترنتی

<form action="/contact" method="post">
  <p>
    <label for="name">نام و نام خانوادگی:</label><br>
    <input id="name" type="text" name="fullname" placeholder="مثلاً سارا رضایی">
  </p>
  <p>
    <label for="email">رایانامه:</label><br>
    <input id="email" type="email" name="email" placeholder="name@example.com">
  </p>
  <p>
    <label for="topic">موضوع:</label><br>
    <select id="topic" name="topic">
      <option value="order">پیگیری سفارش</option>
      <option value="return">مرجوع کردن کالا</option>
      <option value="other">سایر موارد</option>
    </select>
  </p>
  <p>
    <label for="msg">متن پیام:</label><br>
    <textarea id="msg" name="message" rows="3"></textarea>
  </p>
  <button type="submit">ارسال پیام</button>
</form>





ویژگی‌های اصلی form و name

ویژگی تعریف
action action نشانی‌ای در سرور است که داده‌های فرم به آن فرستاده می‌شود، مثلاً /contact . اگر خالی باشد، داده به همین صفحه برمی‌گردد.
method="get" با get داده‌ها به انتهای URL افزوده می‌شوند، مثل ?q=کتاب . برای جستجو و فیلتر مناسب است، چون نشانی قابل دیدن و قابل اشتراک است. برای گذرواژه و اطلاعات شخصی مناسب نیست.
method="post" با post داده‌ها در بدنهٔ درخواست می‌روند و در نوار نشانی دیده نمی‌شوند. برای ثبت‌نام، ورود و اطلاعات شخصی مناسب‌تر است. خود post داده را رمزنگاری نمی‌کند؛ رمزنگاری مسیر با https انجام می‌شود.
name (روی هر فیلد) name نامی است که سرور مقدار فیلد را با آن می‌شناسد. فیلد بدون name ارسال نمی‌شود، حتی اگر کاربر آن را پر کرده باشد.
value (روی option ) ویژگی value مقداری است که به سرور فرستاده می‌شود. متن داخل option فقط برای نمایش به کاربر است و اگر value نباشد، همان متن ارسال می‌شود.

نکته: HTML داده‌های فرم را ذخیره نمی‌کند. بعد از ارسال، برنامهٔ سمت سرور (مثلاً PHP، Python یا Node.js) آن‌ها را می‌خواند. فرم‌های نمونهٔ این جزوه فقط شکل کار را نشان می‌دهند و به برنامهٔ واقعی فرستاده نمی‌شوند.

انواع پرکاربرد ویژگی type در input

مقدار type کاربرد
text متن معمولی یک‌خطی. اگر type نوشته نشود، همین حالت پیش‌فرض است.
email رایانامه. مرورگر شکل کلی نشانی را بررسی می‌کند، اما وجود واقعی آن صندوق را تضمین نمی‌کند.
password گذرواژه. نویسه‌ها معمولاً به‌صورت نقطه یا ستاره دیده می‌شوند، اما این پنهان‌سازی فقط ظاهری است و به‌تنهایی امنیت ایجاد نمی‌کند.
number عدد. مرورگر معمولاً دکمهٔ کم و زیاد نشان می‌دهد و مقدار غیرعددی را هنگام ارسال نمی‌پذیرد.
checkbox انتخاب چندگزینه‌ای. هر خانه مستقل است و می‌توان چند مورد را با هم انتخاب کرد.
radio انتخاب فقط یکی از چند گزینه. گزینه‌هایی که name یکسان دارند یک گروه می‌شوند.
submit دکمهٔ ارسال فرم. می‌توان به‌جای آن از عنصر button با type="submit" استفاده کرد.

نکته: همیشه label را با ویژگی for به id همان ورودی وصل کنید. مقدار for باید دقیقاً برابر id باشد. این اتصال هم کلیک روی برچسب را به فیلد می‌رساند و هم به صفحه‌خوان می‌گوید این متن مال کدام فیلد است.

خطای متداول: ساختن دکمه با div به‌جای button . div به‌خودی‌خود با صفحه‌کلید فعال نمی‌شود و برای صفحه‌خوان هم دکمه نیست. دکمهٔ واقعی با Tab به آن می‌رسید و با Enter فعال می‌شود.

خطای متداول: استفاده از placeholder به‌جای label . متن placeholder با شروع تایپ ناپدید می‌شود و صفحه‌خوان‌ها همیشه آن را نمی‌خوانند. placeholder فقط راهنمای کمکی داخل کادر است و جای برچسب دائمی را نمی‌گیرد.

تمرین: فرم جستجوی یک کتاب‌فروشی آنلاین بسازید که با method="get" کار کند. یک فیلد متنی با name="q" ، یک فهرست کشویی برای دسته‌بندی و دکمهٔ «جستجو» بگذارید. بعد از ارسال به نوار نشانی نگاه کنید تا ببینید نام و مقدار فیلدها چگونه به URL اضافه شده‌اند.

ادامه: همه انواع input ، ویژگی‌هایی مثل required و pattern ، و عناصر fieldset و datalist در درس ۱۹ — فرم‌های پیشرفته آمده‌اند.
