۱۶) ویژگی‌ها (Attributes)

ویژگی اطلاعات اضافه دربارهٔ یک عنصر است. همیشه در تگ آغازین نوشته می‌شود و معمولاً به شکل name="value" است. نام ویژگی می‌گوید چه چیزی تنظیم می‌شود و مقدار، تنظیم دقیق آن است. چند ویژگی با فاصله از هم جدا می‌شوند. 

<a href="https://developer.mozilla.org/" title="مستندات رسمی فناوری‌های وب">MDN</a>

در نمونهٔ زیر دو ویژگی روی یک پیوند نوشته شده است:

  • a نام عنصر است و می‌گوید این قطعه یک پیوند است.
  • href نام ویژگی است و "https://developer.mozilla.org/" مقدار آن، یعنی نشانی مقصد.
  • title ویژگی دوم است. ویژگی‌ها با فاصله از هم جدا می‌شوند و ترتیب‌شان معمولاً مهم نیست.

ویژگی‌های مهم و پرکاربرد

ویژگی روی چه عنصری کاربرد
href a، link href نشانی مقصد پیوند یا پروندهٔ مرتبط را مشخص می‌کند.
src img، video، audio، iframe، script src مسیر پرونده‌ای را می‌گوید که عنصر باید بارگذاری کند، مانند تصویر یا اسکریپت.
alt img alt متن جایگزین تصویر است و وقتی تصویر دیده نشود یا خوانده شود به‌کار می‌آید.
width / height img، video، iframe، canvas این دو ویژگی ابعاد را به پیکسل مشخص می‌کنند تا مرورگر پیش از بارگذاری جا را بشناسد.
id همه عناصر id نام یکتای یک عنصر در صفحه است و نباید تکرار شود.
class همه عناصر class نام گروه است. چند عنصر می‌توانند یک کلاس مشترک داشته باشند.
style همه عناصر ویژگی style CSS درون‌خطی همان عنصر را می‌نویسد و فقط روی خودش اثر دارد.
title همه عناصر ویژگی title متن راهنماست و معمولاً با نگه داشتن نشانگر ظاهر می‌شود. روی صفحهٔ لمسی اغلب دیده نمی‌شود.
lang html و همه عناصر ویژگی lang زبان محتوا را مشخص می‌کند، مثلاً fa برای فارسی و en برای انگلیسی، تا صفحه‌خوان تلفظ درست را انتخاب کند.
dir همه عناصر ویژگی dir جهت متن را تعیین می‌کند: rtl راست‌به‌چپ و ltr چپ‌به‌راست.
hidden همه عناصر وجود ویژگی hidden عنصر را از دید و از دسترس پنهان می‌کند. این ویژگی بولی است و بودنش کافی است.

title

ماوس را روی متن زیر نگه دارید:

<p title="من یک راهنما هستم!">ماوس را روی من ببرید</p>

ماوس را روی من ببرید

lang و dir

در یک صفحه فارسی، می‌توان بخش انگلیسی را با زبان و جهت درست نوشت:

<p lang="en" dir="ltr">Hello! This paragraph is English.</p>

Hello! This paragraph is English.

ویژگی‌های بولی (Boolean)

بعضی ویژگی‌ها مقدار جدا لازم ندارند. همین که نوشته شوند فعال‌اند. به این‌ها ویژگی بولی می‌گویند. نمونه‌های رایج disabled، checked، required، hidden و controls هستند. 

<label><input type="checkbox" checked> عضویت در خبرنامه</label>
<button type="button" disabled>پرداخت (ابتدا قوانین را بپذیرید)</button>

خطای متداول: نوشتن disabled="false" برای فعال کردن دکمه. در ویژگی بولی، حضور ویژگی یعنی فعال، حتی اگر مقدارش "false" باشد. برای اینکه دکمه غیرفعال نباشد، باید خود ویژگی را حذف کنید.

نکته (قرارداد نگارشی): نام ویژگی‌ها را با حروف کوچک بنویسید و مقدار را داخل نقل‌قول دوتایی بگذارید. HTML در بسیاری از موارد بدون نقل‌قول هم کار می‌کند، اما اگر مقدار فاصله یا علامت خاص داشته باشد نقل‌قول لازم است. اگر خود مقدار علامت " داشت، از نقل‌قول تکی استفاده کنید: title='او گفت "سلام"'

ویژگی style و رنگ‌ها

ویژگی style ظاهر یک عنصر را با CSS تغییر می‌دهد. نوشتار آن style="property: value;" است. این روش فقط همان عنصر را هدف می‌گیرد و برای طراحی کل سایت مناسب نیست، اما برای دیدن سریع اثر یک ویژگی مفید است. 

<h3 style="color: crimson;">تیتر قرمز</h3>
<p style="background-color: lightyellow;">پس‌زمینه زرد روشن</p>
<p style="font-size: 22px;">متن بزرگ‌تر</p>
<p style="text-align: center;">متن وسط‌چین</p>
<p style="font-family: 'Courier New';">فونت دیگر (Courier)</p>

روش‌های نوشتن رنگ

روش مثال نمونه
نام رنگ (حدود ۱۴۰ نام استاندارد انگلیسی) tomato
HEX (شانزده‌شانزدهی) #ff6347
RGB (قرمز، سبز، آبی ۰ تا ۲۵۵) rgb(255, 99, 71)
RGBA (با شفافیت ۰ تا ۱) rgba(255, 99, 71, 0.4)
HSL (رنگ، اشباع، روشنی) hsl(9, 100%, 64%)

همهٔ ردیف‌های بالا، جز RGBA، یک رنگ هستند و فقط شیوهٔ نوشتن‌شان فرق دارد. نام رنگ خواناتر است، HEX فشرده است، RGB مقدار هر کانال را جدا نشان می‌دهد و HSL تنظیم رنگ و روشنی را شهودی‌تر می‌کند. RGBA همان RGB است به‌اضافهٔ شفافیت از ۰ تا ۱. 

<p style="border: 3px solid DodgerBlue; color: white; background-color: #0b6e4f;">
  حاشیه آبی، متن سفید، پس‌زمینه سبز
</p>

حاشیه آبی، متن سفید، پس‌زمینه سبز

سه روش افزودن CSS به HTML

روش کجا نوشته می‌شود چه زمانی
درون‌خطی (Inline) ویژگی style روی خود عنصر فقط برای آزمایش سریع یا یک مورد استثنایی. اگر زیاد تکرار شود، نگهداری کد سخت می‌شود.
داخلی (Internal) تگ <style> داخل head وقتی استایل فقط به همین صفحه مربوط است و نمی‌خواهید پروندهٔ جدا بسازید.
خارجی (External) فایل جدا .css + تگ <link> روش مناسب پروژه‌های واقعی است، چون یک پروندهٔ CSS می‌تواند ظاهر چند صفحه را با هم تنظیم کند.

۱) Inline

<h1 style="color: blue;">تیتر آبی</h1>

۲) Internal

<head>
  <style>
    body { background-color: linen; }
    h1   { color: maroon; }
  </style>
</head>

۳) External

<!-- در فایل HTML -->
<head>
  <link rel="stylesheet" href="css/style.css">
</head>

/* در فایل css/style.css */
h1 { color: maroon; }

نکته: اگر چند قانون CSS به یک عنصر برسند، مرورگر با سازوکار آبشار (Cascade) تصمیم می‌گیرد کدام اعمال شود. برای شروع این ترتیب را به خاطر بسپارید: استایل inline معمولاً از انتخابگر id قوی‌تر است، id از class، و class از نام عنصر. اگر دو قانون وزن یکسانی داشته باشند، قانونی که دیرتر آمده اعمال می‌شود. این مدل ساده است. ویژگی !important و منبع استایل، یعنی مرورگر، کاربر یا نویسندهٔ صفحه، هم می‌توانند نتیجه را عوض کنند.

خطای متداول: استفاده از عنصرهای قدیمی مثل font و center یا ویژگی bgcolor. این‌ها در HTML5 منسوخ شده‌اند و ممکن است در آینده نادیده گرفته شوند. ظاهر را با CSS بنویسید.

تمرین: یک بند با پس‌زمینهٔ #fff3bf، متن rgb(26, 58, 92) و اندازهٔ قلم 18px بسازید. سپس همین ظاهر را به عنصر style در head منتقل کنید و با class روی بند اعمال کنید تا استایل از خود عنصر جدا شود.

مطالعه بیشتر: HTML Attributes (MDN)، Global attributes (MDN)، CSS color values (MDN)، Cascade (MDN)
