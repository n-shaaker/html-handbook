# مبحث ۱۲: Block و Inline، div و span، class و id

درس مرتبط: [۱۴) Block و Inline، div و span، class و id](../../../pages/14-div-span.html)

---

## تمرین ۱ — رنگ کردن قیمت‌ها با span ⭐

**هدف:** استفاده از `span` با `class` برای انتخاب تکه‌ای از متن داخل یک خط.

**صورت مسئله:** «نانوایی فانتزی سحر» می‌خواهد در متن پاراگراف‌ها، قیمت‌ها قرمز و پررنگ دیده شوند، ولی معنای متن عوض نشود.

**الزامات:**

- سه پاراگراف، هرکدام نام یک محصول و قیمتش (مثلاً «نان باگت: ۳۵ هزار تومان»).
- فقط **قیمت** داخل `<span class="price">` باشد.
- یک `style` در `head` که `.price` را قرمز و پررنگ کند.
- از `strong` یا `b` برای این کار استفاده نکنید (هدف فقط ظاهر است، نه اهمیت).

**خروجی مورد انتظار:** قیمت‌ها در همان خط متن، قرمز و پررنگ؛ خط‌ها نمی‌شکنند.

---

## تمرین ۲ — کارت کتاب‌ها با class مشترک ⭐⭐

**هدف:** استفاده از `div` به‌عنوان جعبه گروه‌بندی و یک `class` مشترک برای چند عنصر.

**صورت مسئله:** «کتاب‌فروشی ققنوس» سه کتاب پیشنهادی دارد که باید هرکدام در یک کارت با حاشیه و فاصله نمایش داده شوند.

**الزامات:**

- سه `div` با `class="book-card"`؛ داخل هرکدام یک `h2` (نام کتاب) و یک `p` (نویسنده).
- یک `style` در `head` که `.book-card` را حاشیه‌دار (`border`) با فاصله داخلی (`padding`) و فاصله بیرونی (`margin`) کند.
- کارت کتاب «پیشنهاد ویژه» علاوه بر آن یک `id="special"` داشته باشد که پس‌زمینه‌اش زرد کم‌رنگ شود.

**خروجی مورد انتظار:** سه کارت هم‌شکل زیر هم؛ فقط یکی پس‌زمینه زرد دارد.

---

## تمرین ۳ — رزومه با id و class ⭐⭐⭐

**هدف:** درک تفاوت `id` (یکتا، مقصد لینک) و `class` (مشترک، برای گروه)، و تفاوت Block و Inline.

**صورت مسئله:** «زهرا امینی» یک رزومه یک‌صفحه‌ای می‌خواهد با منوی بالا که به سه بخش «درباره من»، «مهارت‌ها» و «تماس» بپرد.

**الزامات:**

- سه `div` با `id` یکتا (`about`، `skills`، `contact`) و همه با `class="section"` مشترک.
- منوی بالا با سه لینک به همین `id`ها.
- در بخش مهارت‌ها، نام هر مهارت داخل `<span class="skill">` و همه در **یک** پاراگراف کنار هم (چون `span` درون‌خطی است).
- `style` در `head`: `.section` حاشیه پایین داشته باشد، `.skill` پس‌زمینه رنگی، و `#about` رنگ متن متفاوت.
- در یک توضیح HTML بنویسید چرا مهارت‌ها کنار هم ماندند ولی `div`ها زیر هم آمدند.

**خروجی مورد انتظار:** منو به بخش‌ها می‌پرد؛ مهارت‌ها برچسب‌های رنگی کنار هم در یک خط هستند.

---

## اشتباه‌های رایج این مبحث

- استفاده از یک `id` برای چند عنصر (`id` باید یکتا باشد).
- استفاده از `div` وقتی تگ معنایی مناسب (`header`، `article`، ...) وجود دارد.
- نقطه و `#` را جابه‌جا نوشتن در CSS (`.` برای class، `#` برای id).
- گذاشتن `div` (بلوکی) داخل `p` یا `span`.
