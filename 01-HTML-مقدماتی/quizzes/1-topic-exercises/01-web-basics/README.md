## تمرین ۱ — کالبدشکافی یک URL ⭐

**هدف:** تشخیص بخش‌های مختلف یک نشانی وب (پروتکل، دامنه، مسیر، پرس‌وجو، لنگر).

**صورت مسئله:** همکارتان سه نشانی برایتان فرستاده و می‌پرسد «هر تکه این آدرس یعنی چه؟».

```text
1) https://fa.wikipedia.org/wiki/اینترنت#تاریخچه
2) https://www.example.com/shop/books.html?page=2
3) http://127.0.0.1:5500/index.html
```

**الزامات:**

- برای هر نشانی، این بخش‌ها را جدا کنید (اگر نبود بنویسید «ندارد»): پروتکل، دامنه یا IP، پورت، مسیر، پرس‌وجو (`?`)، لنگر (`#`).
- بگویید کدام نشانی امن (رمزگذاری‌شده) نیست و چرا.
- بگویید نشانی سوم به کجا اشاره می‌کند (اینترنت یا کامپیوتر خودتان؟).

**خروجی مورد انتظار:** یک جدول یا فهرست مرتب برای هر سه نشانی و دو جواب کوتاه.

## تمرین ۲ — سفر یک درخواست، قدم‌به‌قدم ⭐⭐

**هدف:** چیدن مراحل «تایپ آدرس تا دیدن صفحه» به ترتیب درست و دیدن آن در تب Network.

**صورت مسئله:** مادربزرگتان پرسیده «وقتی آدرس را می‌زنی، صفحه از کجا می‌آید؟». این مراحل به هم ریخته‌اند:

```text
الف) مرورگر HTML را می‌خواند و صفحه را رسم می‌کند.
ب) کاربر آدرس را در نوار آدرس تایپ می‌کند.
ج) سرور فایل‌ها (HTML و ...) را به‌عنوان پاسخ برمی‌گرداند.
د) DNS نام دامنه را به نشانی IP تبدیل می‌کند.
هـ) مرورگر با HTTP یا HTTPS به سرور درخواست می‌فرستد.
```

**الزامات:**

- پنج مرحله را به ترتیب درست بچینید.
- یک سایت دلخواه باز کنید، با <kbd>F12</kbd> ابزار توسعه‌دهنده (DevTools) را باز کنید، به تب **Network** بروید و صفحه را دوباره بارگذاری کنید (<kbd>F5</kbd>).
- بنویسید: اولین درخواست از چه نوعی (Type) است؟ کد وضعیت (Status) آن چند است و یعنی چه؟ حدوداً چند درخواست در کل فرستاده شد؟
- در یک جمله توضیح دهید چرا برای یک صفحه، بیش از یک درخواست فرستاده می‌شود.

**خروجی مورد انتظار:** ترتیب درست + سه عدد/کلمه از تب Network + یک جمله توضیح.

## تمرین ۳ — یک صفحه را با DevTools بخوانید ⭐⭐⭐

**هدف:** استفاده از «View Source» و تب **Elements** برای پیدا کردن اطلاعات واقعی یک صفحه.

**صورت مسئله:** صفحه درس سوم همین جزوه ([`03-how-web-works.html`](../../../pages/03-how-web-works.html)) را در مرورگر باز کنید. فرض کنید بازرس کیفیت هستید و باید گزارش کوتاهی بدهید.

**الزامات:** با <kbd>Ctrl</kbd>+<kbd>U</kbd> (نمایش سورس) و تب Elements به این سؤال‌ها پاسخ دهید:

- زبان و جهت صفحه چیست؟ (ویژگی‌های تگ `html`)
- متن دقیق `title` صفحه چیست؟ کجای مرورگر دیده می‌شود؟
- صفحه از کدام فایل CSS استفاده می‌کند؟ (نشانی آن را بنویسید)
- متن تگ `h1` چیست؟
- روی یکی از لینک‌های «درس بعد» راست‌کلیک کنید و **Inspect** را بزنید؛ مقصد آن لینک (`href`) چیست؟
- در تب Elements متن `h1` را دوبار کلیک کنید و عوض کنید. با رفرش صفحه چه اتفاقی می‌افتد؟ چرا؟

**خروجی مورد انتظار:** شش پاسخ کوتاه و دقیق.

## اشتباه‌های رایج این مبحث

- یکی دانستن «اینترنت» و «وب»؛ وب فقط یکی از خدمات روی اینترنت است.
- یکی دانستن «مرورگر» و «موتور جستجو» (کروم مرورگر است، گوگل موتور جستجو).
- فکر کردن اینکه تغییر در DevTools فایل اصلی را عوض می‌کند؛ تغییرها فقط موقت و روی کامپیوتر خودتان است.
- جا انداختن DNS در مراحل؛ کامپیوترها با IP کار می‌کنند، نه با نام دامنه.
