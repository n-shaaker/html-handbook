# پاسخ تمرین ۳ — خواندن صفحه با DevTools

1. **زبان و جهت:** `lang="fa"` و `dir="rtl"` (فارسی، راست‌به‌چپ).
2. **عنوان:** `۳) نحوه اتصال اجزای وب | جزوه HTML` — روی زبانه (تب) مرورگر دیده می‌شود.
3. **فایل CSS:** `../css/style.css` (یعنی پوشه `css` یک سطح بالاتر از `pages`).
4. **متن h1:** «جزوه HTML مقدماتی».
5. **مقصد «درس بعد»:** `04-html-intro.html`.
6. **تغییر در Elements:** متن فقط روی صفحه خودتان عوض می‌شود و با رفرش برمی‌گردد؛
   چون DevTools فقط نسخه‌ای را که در حافظه مرورگر است تغییر می‌دهد و مرورگر با رفرش، فایل اصلی را دوباره می‌خواند.
