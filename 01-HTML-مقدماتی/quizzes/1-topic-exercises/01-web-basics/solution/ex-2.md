# پاسخ تمرین ۲ — سفر یک درخواست

**ترتیب درست:** ب ← د ← هـ ← ج ← الف

1. کاربر آدرس را تایپ می‌کند.
2. DNS نام دامنه را به IP تبدیل می‌کند.
3. مرورگر با HTTP/HTTPS درخواست می‌فرستد.
4. سرور فایل‌ها را به‌عنوان پاسخ برمی‌گرداند.
5. مرورگر HTML را می‌خواند و صفحه را رسم می‌کند.

**تب Network (جواب‌ها بسته به سایت فرق دارند، این‌ها نمونه درست است):**

- نوع اولین درخواست: `document` (همان فایل HTML صفحه).
- کد وضعیت: `200` یعنی «موفق، فایل پیدا شد». (اگر `304` دیدید یعنی از حافظه مرورگر آمده؛ آن هم درست است.)
- تعداد درخواست‌ها: پایین تب Network نوشته شده، مثلاً «۴۲ requests».

**چرا چند درخواست؟** چون HTML فقط اسکلت است؛ مرورگر بعد از خواندن آن، برای هر فایل CSS، تصویر، فونت و JavaScript که در صفحه آمده یک درخواست جدا می‌فرستد.
