# پاسخ تمرین ۱ — کالبدشکافی یک URL

| بخش | نشانی ۱ | نشانی ۲ | نشانی ۳ |
| --- | --- | --- | --- |
| پروتکل | `https` | `https` | `http` |
| دامنه / IP | `fa.wikipedia.org` | `www.example.com` | `127.0.0.1` (IP) |
| پورت | ندارد (پیش‌فرض ۴۴۳) | ندارد (پیش‌فرض ۴۴۳) | `5500` |
| مسیر | `/wiki/اینترنت` | `/shop/books.html` | `/index.html` |
| پرس‌وجو | ندارد | `page=2` | ندارد |
| لنگر | `تاریخچه` | ندارد | ندارد |

- **نشانی ناامن:** نشانی ۳، چون با `http` شروع می‌شود و ارتباط رمزگذاری نمی‌شود (`https` امن است).
- **نشانی ۳ کجاست؟** `127.0.0.1` یعنی «همین کامپیوتر» (localhost). معمولاً افزونه‌هایی مثل Live Server صفحه را روی آن نشان می‌دهند؛ از اینترنت نمی‌آید.
