۱۲) الگوهای پرکاربرد

حالا که همه ویژگی‌ها را می‌شناسیم، وقت ساختن چیزهای واقعی است. این شش الگو را تقریباً در هر سایتی می‌بینید؛ هر کدام فقط چند خط CSS است. خوب نگاهشان کنید، چون در کوییزها به کارشان می‌برید.

مثال ۱: وسط‌چین کامل

وقتی هم محور اصلی و هم محور فرعی باید یک عنصر را وسط ظرف بگذارند، روی پدر justify-content: center و align-items: center را با هم می‌نویسند. ظرف باید در محوری که وسط‌چین می‌شود فضای اضافه داشته باشد؛ برای همین اینجا min-height ارتفاع را از محتوای کارت بلندتر می‌کند. این الگو برای پیام «سبد خرید خالی است» یا حالت خالی یک بخش به کار می‌رود. 

.empty-cart {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 180px;
}

سبد خرید شما خالی است

مثال ۲: نوار منو

نوار منو دو گروه دارد که باید دو سر خط بروند: لوگو در شروع و لینک‌ها در پایان. justify-content: space-between همین کار را می‌کند و align-items: center همه را در ارتفاع نوار وسط می‌گذارد. flex-wrap: wrap باعث می‌شود اگر عرض صفحه به لینک‌ها نرسد، به‌جای بیرون زدن از صفحه به خط بعد بروند. 

.navbar {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  gap: 10px;
}

.navbar ul {
  display: flex;
  gap: 16px;
  list-style: none;
}

مثال ۳: ردیف کارت‌های هم‌قد

کارت‌ها با flex: 1 هم‌عرض و با stretch پیش‌فرض هم‌قد می‌شوند. داخل هر کارت هم column است و دکمه با margin-top: auto به ته کارت می‌چسبد، حتی اگر متن کارت‌ها کوتاه و بلند باشد: 

.cards { display: flex; gap: 12px; }

.card {
  flex: 1;
  display: flex;
  flex-direction: column;
}

.card .btn {
  margin-top: auto;   /* دکمه همیشه پایین کارت */
}

مثال ۴: شیء رسانه‌ای (عکس + متن)

الگوی «عکس یک طرف، متن طرف دیگر»؛ در نظرات کاربران، پیام‌ها و فهرست خبرها همه‌جا هست. عکس با flex: none اندازه‌اش را حفظ می‌کند و متن بقیه جا را می‌گیرد: 

.media {
  display: flex;
  align-items: flex-start;
  gap: 12px;
}

.media .avatar { flex: none; }
.media .text   { flex: 1; }

مریم رضایی

قهوه‌اش عالی بود و فضای کافه خیلی آرام. فقط کاش صبح‌ها زودتر باز می‌کرد تا قبل از کار سر بزنم. حتماً دوباره می‌آیم!

مثال ۵: فوتر چسبان (Sticky Footer)

وقتی محتوای صفحه کم است، فوتر نباید وسط صفحه بماند. کل صفحه را column می‌کنیم و به بخش اصلی flex: 1 می‌دهیم تا فضای خالی را بگیرد و فوتر را به پایین هل دهد. (در سایت واقعی به‌جای height این مثال، روی body از min-height: 100vh استفاده کنید.) 

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

main {
  flex: 1;   /* هر چقدر جا ماند، مال محتوا */
}

مثال ۶: گروه دکمه‌ها

دکمه‌ها به هم چسبیده‌اند و فقط دو گوشه بیرونی گرد است. با inline-flex گروه فقط به اندازه دکمه‌هایش جا می‌گیرد:

.btn-group {
  display: inline-flex;
  border: 1px solid #1c7ed6;
  border-radius: 8px;
  overflow: hidden;   /* گوشه‌های گرد روی دکمه‌ها هم اعمال شود */
}

اشتباه رایج: برای چسباندن دکمه به ته کارت، به متن کارت height ثابت می‌دهیم. با کمی متن بیشتر، متن بیرون می‌زند. راه درست: کارت flex-direction: column و دکمه margin-top: auto؛ هر چقدر متن کم و زیاد شود، دکمه پایین می‌ماند.

اشتباه رایج: در فوتر چسبان flex: 1 را روی footer می‌گذاریم و فوتر غول‌پیکر می‌شود! flex: 1 باید روی بخشی باشد که قرار است فضای خالی را بگیرد، یعنی main.

الگو ویژگی‌های کلیدی
وسط‌چین کامل justify-content: center + align-items: center + ارتفاع روی پدر
نوار منو space-between یا margin-inline-start: auto، align-items: center، flex-wrap
کارت‌های هم‌قد flex: 1 روی کارت، column داخل کارت، margin-top: auto روی دکمه
عکس + متن flex: none روی عکس، flex: 1 روی متن
فوتر چسبان column + min-height: 100vh روی body، flex: 1 روی main
گروه دکمه inline-flex + overflow: hidden

تمرین: یک صفحه کامل برای «کافه نارنج» بسازید که همه این الگوها را داشته باشد: سربرگ با لوگو و منو، سه کارت هم‌قد برای «نوشیدنی گرم»، «نوشیدنی سرد» و «کیک» با دکمه «سفارش» در ته کارت، بخش «نظر مشتری‌ها» با الگوی عکس + متن، و فوتری که حتی با محتوای کم پایین صفحه بماند.
