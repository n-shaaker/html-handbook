# تمرین‌های مبحث «تراز خط‌ها (align-content)»

درس مربوط: [تراز خط‌ها (align-content)](../../../pages/06-align-content.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — خط‌های برچسب، بالای کادر ⭐

**هدف:** با `align-content: flex-start` خط‌های یک ظرف چندخطی را بالای ظرف جمع کنید.

**صورت مسئله:**

کادر برچسب‌های یک فروشگاه ارتفاع ثابت ۲۵۰ پیکسل دارد. برچسب‌ها سه خط شده‌اند ولی خط‌ها در کل
ارتفاع **پخش** شده‌اند و بینشان فاصله زیادی افتاده. می‌خواهیم همه خط‌ها بالای کادر، پشت هم باشند.

**الزامات:**

- [ ] کادر `.box` با `max-width: 350px` و `height: 250px`، فلکس و `wrap` باشد.
- [ ] حداقل ده برچسب داخل کادر باشد.
- [ ] با `align-content: flex-start` خط‌ها بالای کادر جمع شوند.
- [ ] در یک کامنت بنویسید مقدار پیش‌فرض `align-content` چیست.

**خروجی مورد انتظار:**

```
+-----------------------+
| [t] [t] [t] [t]       |
| [t] [t] [t] [t]       |
| [t] [t]               |
|                       |
|                       |   <- فضای خالی پایین
+-----------------------+
```

## تمرین ۲ — align-content کار نمی‌کند! ⭐⭐

**هدف:** بفهمید `align-content` فقط در ظرف **چندخطی** (با `wrap`) اثر دارد.

**صورت مسئله:**

یک هنرجو برای گالری کوچکش نوشته `align-content: center` تا ردیف‌های عکس وسط کادر ۳۰۰ پیکسلی بیایند.
ولی عکس‌ها همه در یک خط له شده‌اند و هیچ‌چیز وسط نیست.

**فایل شروع:** `starter/ex-2.html` و `starter/ex-2.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] عکس‌ها عرض ۱۰۰ پیکسلی‌شان را حفظ کنند و به خط بعد بروند.
- [ ] مجموعه خط‌ها با هم وسطِ ارتفاع کادر قرار بگیرند.
- [ ] در یک کامنت بنویسید چرا کد قبلی اثری نداشت.

**خروجی مورد انتظار:**

```
+---------------------+
|                     |
| [p] [p] [p]         |
| [p] [p] [p]         |
| [p] [p]             |
|                     |
+---------------------+
```

## تمرین ۳ — سالن سینما: دو کادر، دو رفتار ⭐⭐⭐

**هدف:** `align-content` (جای خط‌ها) را از `justify-content` (جای آیتم‌ها در هر خط) جدا کنید.

**صورت مسئله:**

یک سایت فروش بلیت دو نقشه صندلی کوچک می‌خواهد. در سالن A همه صندلی‌ها باید یک گروه فشرده
**وسطِ وسط** کادر باشند. در سالن B ردیف اول بالای کادر و ردیف آخر پایین کادر بچسبد و بقیه بینشان پخش شوند.

**الزامات:**

- [ ] دو کادر `.hall` با عرض ۳۰۰ و ارتفاع ۲۶۰ پیکسل، هرکدام با ده صندلی ۵۰ پیکسلی.
- [ ] سالن A: `align-content: center` و `justify-content: center`.
- [ ] سالن B: `align-content: space-between`.
- [ ] در یک کامنت بنویسید چرا `align-items: center` به‌تنهایی همان نتیجه سالن A را نمی‌دهد.

**خروجی مورد انتظار:**

```
سالن A                    سالن B
+--------------+          +--------------+
|              |          | [s][s][s][s] |
|  [s][s][s]   |          |              |
|  [s][s][s]   |          | [s][s][s][s] |
|  [s][s][s]   |          |              |
|     [s]      |          | [s][s]       |
|              |          +--------------+
+--------------+
```

---

## اشتباه‌های رایج این مبحث

- استفاده از `align-content` بدون `flex-wrap: wrap`؛ روی ظرف تک‌خطی هیچ اثری ندارد.
- انتظار اثر بدون ارتفاع اضافه؛ اگر ظرف `height` نداشته باشد، فضای خالی برای جابه‌جا کردن خط‌ها نیست.
- قاطی کردن `align-items` (آیتم‌ها داخل هر خط) با `align-content` (خود خط‌ها داخل ظرف).
