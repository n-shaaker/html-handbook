## تمرین ۱ — نظر کاربر (شیء رسانه‌ای) ⭐

**هدف:** الگوی «عکس کنار متن» را با یک آیتم ثابت و یک آیتم `flex: 1` بسازید.

**صورت مسئله:**

زیر هر مطلب یک وبلاگ، نظرها نمایش داده می‌شوند: یک دایره عکس کاربر سمت راست
و نام و متن نظر کنارش. اگر متن طولانی شد، دایره نباید له شود و متن نباید زیر عکس برود.

**الزامات:**

- [ ] ظرف `.comment` فلکس با `gap` و `align-items: flex-start`.
- [ ] `.avatar` دایره ۶۰ پیکسلی با `flex: none` باشد.
- [ ] `.body` با `flex: 1` بقیه عرض را بگیرد.
- [ ] دست‌کم دو نظر، یکی کوتاه و یکی خیلی بلند.

**خروجی مورد انتظار:**

```
+---------------------------------+------+
| name                            | (  ) |
| long text long text long text   |      |
| long text long text             |      |
+---------------------------------+------+
```

## تمرین ۲ — فوتر چسبان ⭐⭐

**هدف:** با `min-height: 100vh` و `flex: 1` روی `main`، فوتر را حتی در صفحه کم‌محتوا پایین صفحه نگه دارید.

**صورت مسئله:**

صفحه «درباره ما» یک سایت فقط دو خط متن دارد و فوتر وسط صفحه آمده و زیرش خالی است.
فوتر باید همیشه **ته پنجره** باشد؛ و اگر محتوا زیاد شد، طبیعی پایین برود.

**الزامات:**

- [ ] `body` فلکس ستونی با `min-height: 100vh` و `margin: 0`.
- [ ] `main` با `flex: 1` فضای خالی را بگیرد.
- [ ] از `position: fixed` یا `absolute` استفاده نکنید.
- [ ] با محتوای کم و زیاد هر دو را امتحان کنید.

**خروجی مورد انتظار:**

```
+---------------------+
| header              |
+---------------------+
| main (short)        |
|                     |
|                     |
+---------------------+
| footer              |   <- ته پنجره
+---------------------+
```

## تمرین ۳ — کارت‌های هم‌قدِ خراب ⭐⭐⭐

**هدف:** الگوی «کارت‌های هم‌قد با دکمه ته کارت» را بدون ارتفاع ثابت درست پیاده کنید.

**صورت مسئله:**

برنامه‌نویس قبلی برای هم‌قد کردن کارت‌های تخفیف، به همه `height: 220px` داده.
حالا متن کارت بلند از کادر بیرون زده، کارت‌ها روی صفحه پهن خالی می‌مانند و دکمه‌ها هم‌خط نیستند.

**فایل شروع:** `starter/ex-3.html` و `starter/ex-3.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] `height` ثابت حذف شود و هیچ متنی از کارت بیرون نزند.
- [ ] کارت‌ها با `flex: 1 1 220px` ردیف را پر کنند.
- [ ] هر کارت فلکس ستونی باشد و دکمه با `margin-top: auto` ته کارت برود.
- [ ] در هر ردیف کارت‌ها هم‌قد و دکمه‌ها هم‌خط باشند.

**خروجی مورد انتظار:**

```
+---------+ +---------+ +---------+
| title   | | title   | | title   |
| text    | | long    | | text    |
|         | | long    | |         |
|         | | text    | |         |
| [ btn ] | | [ btn ] | | [ btn ] |
+---------+ +---------+ +---------+
```

---

## اشتباه‌های رایج این مبحث

- هم‌قد کردن کارت‌ها با `height` ثابت؛ متن بلند بیرون می‌زند. `stretch` خودش کارت‌ها را هم‌قد می‌کند.
- فراموش کردن `flex: none` روی عکس در شیء رسانه‌ای؛ عکس با متن بلند له می‌شود.
- نوشتن `height: 100vh` به‌جای `min-height`؛ آن وقت محتوای زیاد از صفحه بیرون می‌زند.
- صفر نکردن `margin` پیش‌فرض `body` در فوتر چسبان؛ صفحه اسکرول بی‌دلیل می‌خورد.
