# تمرین‌های مبحث «آشنایی با Flexbox»

درس مربوط: [آشنایی با Flexbox](../../../pages/01-intro.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — روزهای هفته در یک ردیف ⭐

**هدف:** فقط با `display: flex` روی ظرف، چند جعبه را کنار هم بنشانید.

**صورت مسئله:**

آموزشگاه می‌خواهد بالای صفحه برنامه کلاس‌ها، روزهای شنبه تا سه‌شنبه **کنار هم** دیده شوند،
ولی الان هر روز در یک خط جداست.

**الزامات:**

- [ ] یک ظرف با کلاس `days` و داخلش چهار `div` با کلاس `day` بسازید.
- [ ] روزها فقط با `display: flex` روی **ظرف** کنار هم بیایند (بدون `float` و `inline-block`).
- [ ] «شنبه» سمت راست باشد؛ چون صفحه `dir="rtl"` است، لازم نیست کار اضافه‌ای بکنید.
- [ ] بین جعبه‌ها با `margin` فاصله بگذارید (`gap` را در درس ۷ یاد می‌گیریم).

**خروجی مورد انتظار:**

```
+--------------------------------------------+
|                    [ 4 ] [ 3 ] [ 2 ] [ 1 ] |
+--------------------------------------------+
```
جعبه ۱ = شنبه (سمت راست)، جعبه ۴ = سه‌شنبه. ظرف تمام‌عرض است و جعبه‌ها از راست شروع می‌شوند.

---

## تمرین ۲ — منوی خراب: flex روی عنصر اشتباه ⭐⭐

**هدف:** تشخیص بدهید `display: flex` باید روی ظرف نوشته شود، نه روی آیتم‌ها.

**صورت مسئله:**

یک هنرجو سربرگ سایت «کتاب‌خانه من» را ساخته. قرار بود لوگو و منو در **یک ردیف** باشند
و سه لینک منو هم کنار هم؛ ولی همه‌چیز زیر هم افتاده است.

**فایل شروع:** `starter/ex-2.html` و `starter/ex-2.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] لوگو و `nav` در یک ردیف کنار هم باشند.
- [ ] سه لینک منو کنار هم باشند.
- [ ] `display: flex` فقط روی ظرف‌ها (`.topbar` و `.links`) باشد و از روی `a` پاک شود.
- [ ] HTML تغییر نکند.

**خروجی مورد انتظار:**

```
+------------------------------------------------+
|      [link3] [link2] [link1]   [ LOGO ]        |
+------------------------------------------------+
```
لوگو سمت راست، کنارش سه لینک. پس‌زمینه سربرگ تیره است.

## تمرین ۳ — دو لایه فلکس: ردیف کارت‌ها و سرِ کارت ⭐⭐⭐

**هدف:** یک ظرف فلکسی داخل یک آیتم فلکسی دیگر بسازید و بدانید هر عنصر ظرف است یا آیتم.

**صورت مسئله:**

صفحه «خدمات ما» سه کارت دارد. کارت‌ها باید کنار هم باشند و **داخل هر کارت** هم
آیکون گرد و تیتر کنار هم بیایند. متن توضیح زیر آن‌ها می‌ماند.

**الزامات:**

- [ ] ظرف `.cards` سه کارت را کنار هم بچیند.
- [ ] داخل هر کارت، `.card-head` آیکون و تیتر را کنار هم بچیند.
- [ ] پاراگراف توضیح زیر `.card-head` بماند (پس خود `.card` فلکس نیست).
- [ ] بالای فایل CSS در یک کامنت بنویسید کدام عنصرها «ظرف» و کدام‌ها «آیتم» هستند.

**خروجی مورد انتظار:**

```
+-------------+ +-------------+ +-------------+
| (3) title   | | (2) title   | | (1) title   |
| text...     | | text...     | | text...     |
+-------------+ +-------------+ +-------------+
```
کارت اول (طراحی سایت) سمت راست است. دایره سبز = آیکون.

---

## اشتباه‌های رایج این مبحث

- نوشتن `display: flex` روی آیتم‌ها به‌جای ظرف؛ فقط **فرزندهای مستقیم** ظرف کنار هم می‌روند.
- انتظار اینکه نوه‌ها هم کنار هم بیایند؛ برای هر لایه یک ظرف فلکسی جدا لازم است.
- فراموش کردن اینکه در صفحه راست‌چین، شروع محور اصلی سمت **راست** است.
- استفاده از `float` یا `inline-block` همراه Flexbox؛ لازم نیست و فقط گیج‌کننده است.
