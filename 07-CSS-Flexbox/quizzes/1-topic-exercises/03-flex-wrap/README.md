# تمرین‌های مبحث «شکستن خط (flex-wrap)»

درس مربوط: [شکستن خط (flex-wrap)](../../../pages/03-flex-wrap.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — برچسب‌های وبلاگ ⭐

**هدف:** با `flex-wrap: wrap` آیتم‌هایی را که جا نمی‌شوند به خط بعد بفرستید.

**صورت مسئله:**

زیر یک مطلب وبلاگ ده برچسب هست. کادر برچسب‌ها حداکثر ۴۰۰ پیکسل عرض دارد و
برچسب‌ها نباید له شوند یا بیرون بزنند؛ باید به خط بعد بروند.

**الزامات:**

- [ ] ظرف `.tags` با `max-width: 400px` و ده `span` با کلاس `tag`.
- [ ] ظرف فلکس باشد و با `flex-wrap: wrap` چندخطی شود.
- [ ] هر برچسب پس‌زمینه رنگی، `padding` و گوشه گرد داشته باشد.

**خروجی مورد انتظار:**

```
+---------------------------------+
|  [tag] [tag] [tag] [tag] [tag]  |
|  [tag] [tag] [tag] [tag]        |
|  [tag]                          |
+---------------------------------+
```

---

## تمرین ۲ — کارت‌های محصولِ له‌شده ⭐⭐

**هدف:** بفهمید بدون `wrap` آیتم‌ها جمع می‌شوند و با `flex-flow` مشکل را حل کنید.

**صورت مسئله:**

در صفحه محصولات، شش کارت ۲۰۰ پیکسلی داریم. در صفحه باریک کارت‌ها به‌جای رفتن به ردیف بعد
**باریک و له** شده‌اند. مدیر سایت می‌خواهد هر کارت همان ۲۰۰ پیکسل بماند و بقیه به ردیف بعد بروند.

**فایل شروع:** `starter/ex-2.html` و `starter/ex-2.css` را در پوشه خودتان کپی کنید. HTML را تغییر ندهید؛ فقط CSS را درست کنید.

**الزامات:**

- [ ] کارت‌ها در صفحه باریک به ردیف بعد بروند و عرضشان ۲۰۰ پیکسل بماند.
- [ ] به‌جای دو خاصیت جدا، از میان‌بُر `flex-flow: row wrap` استفاده کنید.
- [ ] صفحه در عرض گوشی اسکرول افقی نخورد.

**خروجی مورد انتظار:**

```
پهن:   [ 3 ] [ 2 ] [ 1 ]  ... تا جایی که جا شود
باریک: [ 2 ] [ 1 ]
       [ 4 ] [ 3 ]
       [ 6 ] [ 5 ]
```

## تمرین ۳ — فهرست شهرها در چند ستون ⭐⭐⭐

**هدف:** با `flex-flow: column wrap` و یک ارتفاع ثابت، فهرست را ستون‌به‌ستون بچینید.

**صورت مسئله:**

یک شرکت پست می‌خواهد فهرست دوازده شهری را که پوشش می‌دهد مثل روزنامه **ستونی** نشان دهد:
شهرها از بالا به پایین پر شوند و وقتی ستون پر شد، ستون بعدی (سمت چپ) شروع شود.

**الزامات:**

- [ ] شهرها داخل `ul` با کلاس `cities` و دوازده `li` باشند.
- [ ] از `flex-flow: column wrap` استفاده کنید.
- [ ] ظرف ارتفاع ثابت ۱۶۰ پیکسل داشته باشد (بدون ارتفاع، ستون هیچ‌وقت پر نمی‌شود).
- [ ] علامت‌های پیش‌فرض و `padding` لیست حذف شود.

**خروجی مورد انتظار:**

```
| 9  | 5  | 1  |
| 10 | 6  | 2  |
| 11 | 7  | 3  |
| 12 | 8  | 4  |
```
شهر ۱ بالای ستون راست است؛ هر ستون چهار شهر دارد.

---

## اشتباه‌های رایج این مبحث

- فراموش کردن `flex-wrap`؛ پیش‌فرض `nowrap` است و آیتم‌ها به‌جای رفتن به خط بعد له می‌شوند.
- استفاده از `column wrap` بدون ارتفاع مشخص برای ظرف؛ ستون هیچ‌وقت پر نمی‌شود.
- ترتیب در `flex-flow` مهم نیست، ولی هر دو مقدار باید درست باشند: `flex-flow: row wrap`.
- دادن عرض خیلی بزرگ به ظرف (مثلاً `width: 900px`)؛ آن وقت در گوشی هیچ‌وقت wrap اتفاق نمی‌افتد.
