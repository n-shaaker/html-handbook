# تمرین‌های مبحث «align-self و ترفند margin خودکار»

درس مربوط: [align-self و ترفند margin خودکار](../../../pages/11-align-self-margin-auto.html) · [بازگشت به فهرست تمرین‌ها](../../README.md)

- هر تمرین را در دو فایل جدا بسازید (مثلاً `ex-1.html` و `ex-1.css`).
- فقط از همین درس و درس‌های **قبلی** استفاده کنید.
- اول خودتان حل کنید، بعد با پوشه `solution` مقایسه کنید.

---

## تمرین ۱ — دکمه ورود در انتهای منو ⭐

**هدف:** با `margin-inline-start: auto` یک آیتم را به انتهای خط هل بدهید.

**صورت مسئله:**

منوی یک سایت آموزشی: لوگو، سه لینک، و دکمه «ورود» که باید کاملاً **سمت چپ** منو بچسبد،
در حالی که لوگو و لینک‌ها سمت راست کنار هم می‌مانند.

**الزامات:**

- [ ] ظرف `nav` فلکس، با `align-items: center` و `gap`.
- [ ] دکمه ورود کلاس `login` بگیرد و با `margin-inline-start: auto` به انتها برود.
- [ ] از `justify-content: space-between` استفاده نکنید (لینک‌ها نباید پخش شوند).

**خروجی مورد انتظار:**

```
+----------------------------------------------------+
| [login]                       [c] [b] [a]  LOGO    |
+----------------------------------------------------+
```

## تمرین ۲ — دکمه همیشه ته کارت ⭐⭐

**هدف:** در کارت ستونی، با `margin-top: auto` دکمه را به پایین کارت بچسبانید.

**صورت مسئله:**

سه کارت دوره آموزشی کنار هم هستند و متن‌هایشان طول متفاوت دارد. کارت‌ها هم‌قدند،
ولی دکمه «ثبت‌نام» هر کارت یک جای متفاوت افتاده. همه دکمه‌ها باید در یک خط، **ته کارت** باشند.

**الزامات:**

- [ ] ظرف `.cards` فلکس با `gap` (کارت‌ها خودبه‌خود هم‌قدند).
- [ ] هر `.card` فلکس ستونی باشد.
- [ ] دکمه با `margin-top: auto` به پایین کارت برود.
- [ ] به کارت‌ها `height` ثابت ندهید.

**خروجی مورد انتظار:**

```
+--------+ +--------+ +--------+
| title  | | title  | | title  |
| text   | | text   | | text   |
|        | | text   | |        |
|        | | text   | |        |
| [btn]  | | [btn]  | | [btn]  |   <- هم‌خط
+--------+ +--------+ +--------+
```

## تمرین ۳ — حباب‌های گفتگو ⭐⭐⭐

**هدف:** با `align-self`، هر آیتم را جدا از بقیه در محور فرعی تراز کنید.

**صورت مسئله:**

صفحه پشتیبانی یک فروشگاه گفتگوی کاربر و پشتیبان را نشان می‌دهد. پیام‌های کاربر سمت **راست**،
پیام‌های پشتیبان سمت **چپ** و پیام سیستمی («گفتگو شروع شد») **وسط** باشد.

**الزامات:**

- [ ] ظرف `.chat` فلکس ستونی با `gap: 8px` و `max-width: 450px`.
- [ ] هر پیام `max-width: 70%` داشته باشد.
- [ ] پیام‌های `.me` با `align-self: flex-start` و پیام‌های `.them` با `align-self: flex-end`.
- [ ] پیام `.system` با `align-self: center`.
- [ ] در یک کامنت بنویسید چرا در این ظرف ستونی `flex-start` یعنی سمت راست.

**خروجی مورد انتظار:**

```
+----------------------------+
|        (system)            |
|              [ me ....... ]|
|[ them ...... ]             |
|              [ me ... ]    |
+----------------------------+
```

## اشتباه‌های رایج این مبحث

- نوشتن `margin-inline-start: auto` روی آیتمی که فرزند مستقیم همان ظرف فلکسی نیست؛ اثری ندارد.
- استفاده از `align-self` برای جابه‌جایی در محور **اصلی**؛ `align-self` فقط محور فرعی را تغییر می‌دهد.
- فراموش کردن `flex-direction: column` روی کارت؛ بدون آن `margin-top: auto` دکمه را پایین نمی‌برد.
- قاطی کردن `margin-left` و `margin-inline-start`؛ در صفحه راست‌چین «شروع خط» سمت راست است.
