# پروژه ۴: پنل پیام‌رسان

- **سطح:** ⭐⭐⭐
- **زمان پیشنهادی:** ۹۰ دقیقه
- **هدف پروژه:** ظاهر یک پیام‌رسان تمام‌صفحه را بسازید: ستون مخاطبان با عرض ثابت، و ستون گفتگو که نوار بالا، پیام‌های دو طرفه و نوار نوشتن پیام دارد؛ همه فقط با Flexbox.
- **مباحث ترکیب‌شده (بخش ۱):** [۰۲ flex-direction](../../1-topic-exercises/02-flex-direction/README.md) · [۰۵ align-items](../../1-topic-exercises/05-align-items/README.md) · [۰۷ gap](../../1-topic-exercises/07-gap/README.md) · [۱۰ میان‌بُر flex](../../1-topic-exercises/10-flex-shorthand/README.md) · [۱۱ align-self و margin خودکار](../../1-topic-exercises/11-align-self-margin-auto/README.md) · [۱۲ الگوهای پرکاربرد](../../1-topic-exercises/12-patterns/README.md) · [۱۳ Flexbox واکنش‌گرا](../../1-topic-exercises/13-responsive/README.md)
- **فایل شروع:** `starter/index.html` (HTML کامل و آماده) و `starter/style.css` (خالی). HTML را تغییر ندهید.

## صورت مسئله

آموزشگاه برای هنرجوها یک پیام‌رسان داخلی ساخته و برنامه‌نویس‌ها فقط ظاهرش را کم دارند.
طرح طراح این است:

```
+--------------------------------------+---------------+
| [call]                   name   (M)  |  Contacts     |
+--------------------------------------+  (M) name [2] |
|                (today)               |  (H) name     |
|                       [ me ...... ]  |  (G) name [15]|
| [ them ...... ]                      |               |
|                       [ me ... ]     |               |
+--------------------------------------+               |
| [send] [__________________________]  |               |
+--------------------------------------+---------------+
```

## الزامات

1. `.app` فلکس با ارتفاع `100vh`؛ ستون مخاطبان `flex: 0 0 260px` و ستون گفتگو `flex: 1`.
2. هر مخاطب یک شیء رسانه‌ای است: دایره `.avatar` با `flex: none`، اطلاعات با `flex: 1` (نام بالای آخرین پیام)، و `.badge` اندازه خودش.
3. ستون گفتگو فلکس ستونی است: نوار بالا و نوار نوشتن اندازه محتوا، و `.messages` با `flex: 1` بقیه ارتفاع را بگیرد و اگر پیام زیاد شد، **خودش** اسکرول بخورد (`overflow-y: auto`).
4. دکمه «تماس» با `margin-inline-start: auto` به انتهای نوار بالا برود.
5. پیام‌های `.me` سمت راست، `.them` سمت چپ و `.system` وسط؛ فقط با `align-self`. هر پیام حداکثر ۷۰٪ عرض.
6. در نوار نوشتن، `input` بقیه عرض را بگیرد و دکمه اندازه خودش بماند.
7. با **یک** media query (کمتر از ۷۰۰ پیکسل): مخاطبان بالای گفتگو بیایند و حداکثر ۱۸۰ پیکسل ارتفاع داشته باشند.

## محدودیت‌ها

- فقط Flexbox؛ بدون Grid، `float` و `position`.
- برای جای پیام‌ها از `margin-left`/`margin-right` استفاده نکنید؛ فقط `align-self`.
- بدون `style` درون‌خطی، JavaScript و `!important`.
- حداکثر یک media query.

## امتیازی (تا ۲ نمره)

- مخاطب فعال (`.active`) و حالت `:hover`/`:focus-visible` مخاطبان رنگ متفاوت داشته باشند.
- گوشه حباب پیام‌ها طوری گرد شود که «دم» پیام سمت فرستنده باشد (مثلاً `border-radius` متفاوت برای هر گوشه).

## نکته استاد

- اگر کل صفحه به‌جای بخش پیام‌ها اسکرول می‌خورد، یکی از ظرف‌های بالاتر ارتفاع مشخص ندارد؛ زنجیره `100vh` → `flex: 1` را از بالا دنبال کنید.
- در ستون راست‌چین، `flex-start` یعنی **راست**. اگر پیام‌ها برعکس افتادند، محور را دوباره در DevTools نگاه کنید.
- برای اینکه دایره‌ها بیضی نشوند، هم `width`/`height` ثابت و هم `flex: none` لازم است.
