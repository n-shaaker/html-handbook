# پروژه ۳: صفحه فروشگاه کوچک «برگ سبز»

- **سطح:** ⭐⭐
- **زمان پیشنهادی:** ۶۰ دقیقه
- **هدف پروژه:** یک صفحه کامل فروشگاه بسازید که سربرگش منو و سبد خرید دارد، کارت‌های محصولش هم‌قد با دکمه ته کارت هستند و فوترش همیشه پایین صفحه می‌ماند.
- **مباحث ترکیب‌شده (بخش ۱):** [۰۵ align-items](../../1-topic-exercises/05-align-items/README.md) · [۰۷ gap](../../1-topic-exercises/07-gap/README.md) · [۱۰ میان‌بُر flex](../../1-topic-exercises/10-flex-shorthand/README.md) · [۱۱ align-self و margin خودکار](../../1-topic-exercises/11-align-self-margin-auto/README.md) · [۱۲ الگوهای پرکاربرد](../../1-topic-exercises/12-patterns/README.md) · [۱۳ Flexbox واکنش‌گرا](../../1-topic-exercises/13-responsive/README.md)
- **فایل شروع:** `starter/index.html` (HTML کامل و آماده) و `starter/style.css` (خالی). HTML را تغییر ندهید؛ فقط CSS بنویسید.

## صورت مسئله

فروشگاه آنلاین چای «برگ سبز» از لاهیجان، صفحه اول سایتش را می‌خواهد. صاحب فروشگاه گفته:
«سبد خرید باید همیشه گوشه سربرگ دیده شود. کارت‌ها هم‌قد باشند و قیمت و دکمه "افزودن" ته همه کارت‌ها
در یک خط باشد. حتی اگر محصول کم بود، فوتر نباید وسط صفحه بیاید.»

## الزامات

1. `body` فلکس ستونی با `min-height: 100vh`؛ `main` با `flex: 1` تا فوتر ته پنجره بماند.
2. سربرگ: لوگو، منو و سبد خرید در یک ردیف و عمودی وسط؛ فاصله‌ها فقط با `gap`.
3. سبد خرید با `margin-inline-start: auto` به انتهای سربرگ (سمت چپ) برود.
4. کارت‌ها با `flex-wrap` و `flex: 1 1 200px` در هر عرضی ردیف را پر کنند.
5. هر کارت فلکس ستونی؛ ردیف «قیمت + دکمه» با `margin-top: auto` ته کارت، و داخلش قیمت و دکمه با `space-between` دو سر.
6. نوشته داخل هر `.thumb` افقی و عمودی وسط باشد.
7. با **یک** media query (کمتر از ۶۰۰ پیکسل): سربرگ ستونی شود و سبد خرید تمام‌عرض.

## محدودیت‌ها

- فقط Flexbox؛ بدون Grid، `float` و `position`.
- بدون `height` ثابت برای کارت‌ها و سربرگ.
- بدون `style` درون‌خطی، JavaScript و `!important`.
- حداکثر یک media query.

## امتیازی (تا ۲ نمره)

- دکمه‌ها و لینک‌ها حالت `:hover` و `:focus-visible` واضح داشته باشند.
- محصول «دمنوش به‌لیمو» را با `order` اول ردیف بیاورید و یک برچسب «پرفروش» کنارش بگذارید.

## نکته استاد

- اول فقط فوتر چسبان را درست کنید و صفحه را با محتوای کم ببینید؛ بعد سراغ سربرگ و کارت‌ها بروید.
- اگر ردیف قیمت ته کارت نمی‌رود، ببینید خود `.product` را ستونی کرده‌اید یا نه.
- در گوشی، `margin-inline-start: auto` را صفر کنید؛ وگرنه سبد خرید در حالت ستونی به چپ هل داده می‌شود.
