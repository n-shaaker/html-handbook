آموزش Flexbox — چیدمان انعطاف‌پذیر

مثال به مثال، با جعبه‌های رنگی شماره‌دار؛ از اولین display: flex تا ساخت منو، کارت و چیدمان واکنش‌گرا

پیش‌نیاز: تا درس «فرم‌ها» در CSS میانی را تمام کنید، بعد همین Flexbox را بخوانید. بعد از Flexbox بروید به CSS Grid، سپس چیدمان سایت و Media Queries در CSS میانی.

  1. آشنایی با Flexbox

  5. تراز در محور فرعی (align-items)

  7. فاصله بین آیتم‌ها (gap)
  8. ترتیب نمایش (order)
  9. رشد، جمع شدن و اندازه پایه
  10. میان‌بُر flex
  11. align-self و ترفند margin خودکار
  12. الگوهای پرکاربرد
  13. Flexbox واکنش‌گرا
  14. جمع‌بندی و تمرین

Flexbox برای چیدمان در یک جهت (یک ردیف یا یک ستون) عالی است. وقتی چیدمان دوبعدی لازم دارید (ردیف و ستون با هم، مثل جدول کارت‌ها یا اسکلت کل صفحه)، سراغ دوره آموزش Grid بروید.

بعد از درس‌ها، خودتان را با کوییزهای عملی Flexbox محک بزنید.
