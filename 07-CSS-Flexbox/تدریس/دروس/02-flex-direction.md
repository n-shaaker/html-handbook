## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«navbar افقی می‌خواهیم ولی در موبایل منو **ستونی** شود — هنوز property نمی‌گوییم: فقط HTML یکسان و دو حالت بصری را ببینید.»


اول با **مسئله** شروع کن — نه با لیست property.

«flex-direction روی پدر نوشته می‌شود و می‌گوید محور اصلی به کدام سمت باشد؛ یعنی آیتم‌ها در یک ردیف کنار هم بیایند یا در یک ستون زیر هم، و از کدام سر شروع شوند. چهار مقدار دارد.»

«مقدار row پیش‌فرض است، حتی اگر آن را ننویسید. محور اصلی افقی می‌ماند و آیتم‌ها از شروع خط چیده می‌شوند. در این صفحه که dir="rtl" است، شروع خط سمت راست است، پس جعبهٔ ۱ سمت راست می‌نشیند و بقیه به سمت چپ دنبالش می‌آیند.»

«row-reverse همان ردیف افقی را نگه می‌دارد، اما شروع و پایان محور اصلی را جابه‌جا می‌کند. ترتیب نمایش برعکس HTML می‌شود. در صفحهٔ فارسی جعبهٔ ۱ که در نشانه‌گذاری اول است به سمت چپ می‌رود، چون پایان خط در راست‌چین سمت چپ است.»

«محور اصلی عمودی می‌شود و آیتم‌ها از بالا به پایین زیر هم می‌آیند. حالا محور فرعی افقی است و آیتم‌ها در عرض کش می‌آیند:»

**روی جزوه این عناوین را دنبال کنید:** *۲) جهت چیدمان (flex-direction)* · *مثال ۱: row (پیش‌فرض)* · *مثال ۲: row-reverse* · *مثال ۳: column*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  flex-direction: row;   /* اگر ننویسید هم همین است */
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  flex-direction: row-reverse;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  flex-direction: column;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«شاید بپرسید «div‌ها خودشان هم زیر هم می‌آمدند، پس column به چه درد می‌خورد؟» جوابش این است که حالا همه ابزارهای Flexbox (مثل gap ، وسط‌چینی عمودی و flex: 1 ) روی ستون هم کار می‌کنند. در درس ۱۲ با همین ترفند یک فوتر چسبان می‌سازیم.»

«column-reverse محور اصلی را عمودی نگه می‌دارد، اما جهت آن را برمی‌گرداند: شروع محور پایین ظرف است و پایانش بالا. برای همین جعبهٔ ۱، که در HTML اول آمده، پایین می‌نشیند و بقیه بالای آن چیده می‌شوند. ترتیب خواندن صفحه‌خوان همچنان ترتیب HTML است؛ فقط نمایش برعکس شده است.»

«Flexbox را می‌شود تو در تو به کار برد. هر ظرف فقط فرزندان مستقیم خودش را می‌چیند. اینجا خود کارت‌ها با flex-direction: row کنار هم نشسته‌اند، و داخل هر کارت یک ظرف دیگر با column عکس، نام و قیمت را از بالا به پایین چیده است.»

«اشتباه رایج: برای عوض کردن ترتیب نمایش در صفحه از row-reverse استفاده می‌کنیم، ولی ترتیب در HTML همان قبلی است. کاربری که با کیبورد (Tab) یا صفحه‌خوان کار می‌کند، همان ترتیب HTML را می‌شنود. اگر ترتیب معنی دارد (مثل مراحل خرید)، خود HTML را مرتب کنید.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
