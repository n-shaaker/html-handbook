## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«در DOM لوگو آخر است ولی در موبایل باید **بالا** باشد — بدون جابجایی HTML در markup تولید.»


اول با **مسئله** شروع کن — نه با لیست property.

«این اولین ویژگی است که روی آیتم (فرزند) نوشته می‌شود، نه پدر. order یک عدد صحیح است و می‌گوید آیتم در صف چندم نمایش داده شود، بدون اینکه HTML را تغییر دهیم. مقدار پیش‌فرض همه آیتم‌ها 0 است؛ آیتم با عدد کوچک‌تر جلوتر (نزدیک شروع خط) می‌آید.»

«همه order: 0 دارند، جعبه ۱ عدد بزرگ‌تری گرفته و به پایان صف رفته:»

«عدد منفی هم مجاز است. جعبه ۴ با order: -1 از همه جلوتر می‌آید:»

«آیتم‌هایی که order برابر دارند، به همان ترتیب HTML می‌آیند:»

**روی جزوه این عناوین را دنبال کنید:** *۸) ترتیب نمایش (order)* · *مثال ۱: یک آیتم را آخر بفرستیم* · *مثال ۲: یک آیتم را اول بیاوریم* · *مثال ۳: چیدن کامل با عدد*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.first-box {
  order: 1;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.last-box {
  order: -1;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.box-1 { order: 3; }
.box-2 { order: 1; }
.box-3 { order: 2; }
.box-4 { order: 1; }
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«در فهرست غذاهای یک کافه، «پیشنهاد امروز» در HTML جای خودش است ولی در نمایش اول می‌آید:»

«اشتباه رایج: با order ترتیب «معنایی» صفحه را عوض می‌کنیم. order فقط ظاهر را عوض می‌کند؛ صفحه‌خوان‌ها و کلید Tab همان ترتیب HTML را دنبال می‌کنند و کاربر کیبورد گیج می‌شود (فوکوس یک‌دفعه از این سر به آن سر می‌پرد). order را برای جابه‌جایی‌های تزئینی و کوچک نگه دارید.»

«اشتباه رایج: order را روی پدر می‌نویسیم، یا روی عنصری که آیتم فلکس نیست (پدرش display: flex ندارد). در هر دو حالت بی‌اثر است.»

«تمرین: فهرست پنج محصول یک فروشگاه را بسازید. محصول «پرفروش‌ترین» را که در HTML چهارمی است، با order اول نمایش دهید و محصول «ناموجود» را آخر. سپس صفحه را با کلید Tab پیمایش کنید و ببینید ترتیب فوکوس چطور است.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
