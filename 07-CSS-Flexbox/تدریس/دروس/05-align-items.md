## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«دو کارت pricing: یکی عنوان بلند، یکی کوتاه — دکمه «خرید» یکی بالا یکی پایین. کاربر می‌گوید «نامرتب».»


اول با **مسئله** شروع کن — نه با لیست property.

«justify-content آیتم‌ها را در محور اصلی جابه‌جا می‌کرد؛ align-items (روی پدر) همین کار را در محور فرعی انجام می‌دهد. در حالت row محور فرعی عمودی است، پس align-items می‌گوید آیتم‌ها بالا باشند، پایین، وسط یا تمام ارتفاع را بگیرند. برای اینکه تفاوت دیده شود، ظرف‌ها ارتفاع ۱۲۰ پیکسل دارند و جعبه‌ها متن‌های با طول متفاوت.»

«آیتم‌هایی که ارتفاع ثابت ندارند، کش می‌آیند تا تمام ارتفاع ظرف را بگیرند. راز «ستون‌های هم‌قد» در Flexbox همین است:»

«آیتم‌ها به بالای ظرف (شروع محور فرعی) می‌چسبند و فقط به اندازه محتوایشان بلند هستند:»

«align-items: center آیتم‌ها را در محور فرعی وسط ظرف می‌گذارد. در حالت row این محور عمودی است، پس آیتم‌ها وسط ارتفاع می‌ایستند و دیگر تا بالا و پایین ظرف کش نمی‌آیند. این همان وسط‌چین عمودی است که قبلاً با ترفندهای ارتفاع و حاشیه‌گذاری ساخته می‌شد.»

**روی جزوه این عناوین را دنبال کنید:** *۵) تراز در محور فرعی (align-items)* · *مثال ۱: stretch (پیش‌فرض)* · *مثال ۲: flex-start* · *مثال ۳: flex-end*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  align-items: stretch;
  height: 120px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  align-items: flex-start;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  align-items: flex-end;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.
