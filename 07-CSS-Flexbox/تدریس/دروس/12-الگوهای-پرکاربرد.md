## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«سه تمرین: navbar، pricing، sticky footer — هر کدام با Flex حل می‌شود.»


اول با **مسئله** شروع کن — نه با لیست property.

«حالا که همه ویژگی‌ها را می‌شناسیم، وقت ساختن چیزهای واقعی است. این شش الگو را تقریباً در هر سایتی می‌بینید؛ هر کدام فقط چند خط CSS است. خوب نگاهشان کنید، چون در کوییزها به کارشان می‌برید.»

«وقتی هم محور اصلی و هم محور فرعی باید یک عنصر را وسط ظرف بگذارند، روی پدر justify-content: center و align-items: center را با هم می‌نویسند. ظرف باید در محوری که وسط‌چین می‌شود فضای اضافه داشته باشد؛ برای همین اینجا min-height ارتفاع را از محتوای کارت بلندتر می‌کند. این الگو برای پیام «سبد خرید خالی است» یا حالت خالی یک بخش به کار می‌رود.»

«نوار منو دو گروه دارد که باید دو سر خط بروند: لوگو در شروع و لینک‌ها در پایان. justify-content: space-between همین کار را می‌کند و align-items: center همه را در ارتفاع نوار وسط می‌گذارد. flex-wrap: wrap باعث می‌شود اگر عرض صفحه به لینک‌ها نرسد، به‌جای بیرون زدن از صفحه به خط بعد بروند.»

«کارت‌ها با flex: 1 هم‌عرض و با stretch پیش‌فرض هم‌قد می‌شوند. داخل هر کارت هم column است و دکمه با margin-top: auto به ته کارت می‌چسبد، حتی اگر متن کارت‌ها کوتاه و بلند باشد:»

**روی جزوه این عناوین را دنبال کنید:** *۱۲) الگوهای پرکاربرد* · *مثال ۱: وسط‌چین کامل* · *مثال ۲: نوار منو* · *مثال ۳: ردیف کارت‌های هم‌قد*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.empty-cart {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 180px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.navbar {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  gap: 10px;
}

.navbar ul {
  display: flex;
  gap: 16px;
  list-style: none;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.cards { display: flex; gap: 12px; }

.card {
  flex: 1;
  display: flex;
  flex-direction: column;
}

.card .btn {
  margin-top: auto;   /* دکمه همیشه پایین کارت */
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

### متوسط
3. یک variation کوچک روی مثال کلاس (مقدار دیگر، یک selector دیگر، یک عنصر DOM دیگر).

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«رنگ، فونت، چیدمان با Flexbox و Grid و ساخت چند صفحه واقعی برای نمونه‌کار.»

«تعامل با کاربر و ساخت صفحه‌های پویا.»

«الگوی «عکس یک طرف، متن طرف دیگر»؛ در نظرات کاربران، پیام‌ها و فهرست خبرها همه‌جا هست. عکس با flex: none اندازه‌اش را حفظ می‌کند و متن بقیه جا را می‌گیرد:»

«قهوه‌اش عالی بود و فضای کافه خیلی آرام. فقط کاش صبح‌ها زودتر باز می‌کرد تا قبل از کار سر بزنم. حتماً دوباره می‌آیم!»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
