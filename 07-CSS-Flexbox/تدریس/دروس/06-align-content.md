## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«chipها wrap شده‌اند و **دو ردیف** داریم؛ کل بلوک بالای container مانده. فاصله **بین ردیف‌ها** کجا تنظیم می‌شود؟»


اول با **مسئله** شروع کن — نه با لیست property.

«وقتی با flex-wrap: wrap آیتم‌ها در چند خط چیده می‌شوند و ظرف ارتفاع اضافه دارد، سؤال پیش می‌آید: خود خط‌ها کجای ظرف باشند؟ align-content (روی پدر) جواب این سؤال است. مقدارهایش شبیه justify-content است، ولی خط‌ها را در محور فرعی جابه‌جا می‌کند.»

«مهم: align-content فقط وقتی اثر دارد که flex-wrap: wrap باشد و آیتم‌ها واقعاً بیشتر از یک خط شوند. در ظرف تک‌خطی هیچ کاری نمی‌کند.»

«در همه مثال‌ها ظرف ۲۰۰ پیکسل ارتفاع دارد، پهنایش ۴۰۰ پیکسل است و هفت جعبه ۱۰۰ پیکسلی در سه خط چیده شده‌اند.»

«فضای اضافه بین خط‌ها تقسیم می‌شود و هر خط کش می‌آید (برای همین بین خط‌ها فاصله افتاده):»

**روی جزوه این عناوین را دنبال کنید:** *۶) تراز خط‌ها (align-content)* · *مثال ۱: stretch (پیش‌فرض)* · *مثال ۲: flex-start و center* · *مثال ۳: space-between*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  flex-wrap: wrap;
  align-content: stretch;
  height: 200px;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css

.middle { align-content: center; }
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css

  align-content: space-between;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

## ۵) سؤال کلاسی

- «`align-content` vs `align-items` — کدام روی خطوط، کدام روی item در یک خط؟»  
  **پاسخ:** **align-content** بین **flex lines**؛ **align-items** itemها داخل **یک** line.
- «در Grid هم align-content داریم؟»  
  **پاسخ:** بله، مفهوم مشابه ولی context **track**های grid است نه flex lines.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«همه خط‌ها به بالای ظرف می‌چسبند، یا همه با هم وسط ظرف می‌روند:»

«خط اول بالا، خط آخر پایین و فضای خالی بین خط‌ها:»

«align-items: center آیتم‌ها را داخل خط خودشان وسط می‌کند؛ خط‌ها هنوز کل ارتفاع را بین خودشان تقسیم کرده‌اند. align-content: center کل خط‌ها را با هم وسط ظرف جمع می‌کند:»

«جعبه‌ها هنوز کل ارتفاع را گرفته‌اند (کار align-items: stretch ) و به پایین نرفته‌اند. اینجا باید از align-items: flex-end استفاده کرد.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.
