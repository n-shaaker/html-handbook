## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«در پروژه همه جا `flex: 1` کپی شده — امروز shorthand را **می‌فهمد** نه حفظ.»


اول با **مسئله** شروع کن — نه با لیست property.

«در عمل کمتر پیش می‌آید سه ویژگی درس قبل را جدا بنویسند. ویژگی flex روی آیتم، هر سه را در یک اعلان جمع می‌کند. ترتیب مقدارها ثابت است: اول flex-grow ، بعد flex-shrink ، و آخر flex-basis . اگر عددی تنها بنویسید، مشخصات CSS آن را رشد حساب می‌کند، جمع شدن را 1 می‌گذارد و پایه را 0% می‌گیرد. برای همین flex: 1 برابر است با 1 1 0% ، نه با «یک واحد از عرض محتوا».»

«چهار میانبر اسم‌دار آن‌قدر تکرار می‌شوند که بهتر است رفتارشان را، نه فقط اسمشان را، به خاطر بسپارید:»

«flex: 1 در مشخصات CSS برابر است با 1 1 0% . چون اندازهٔ پایه صفر است، عرض محتوا در تقسیم اولیه حساب نمی‌شود و کل عرض ظرف به‌عنوان فضای اضافه، به سهم برابر، بین آیتم‌ها تقسیم می‌شود. برای همین همهٔ آیتم‌ها دقیقاً هم‌عرض می‌شوند، حتی اگر متن یکی کوتاه و متن دیگری بلند باشد:»

«flex: auto یعنی 1 1 auto . اول هر آیتم به اندازه محتوایش جا می‌گیرد، بعد فضای باقی‌مانده تقسیم می‌شود؛ پس آیتمی که متن بیشتری دارد، پهن‌تر می‌ماند. با مثال ۱ مقایسه کنید:»

**روی جزوه این عناوین را دنبال کنید:** *۱۰) میان‌بُر flex* · *مثال ۱: flex: 1 — همه هم‌اندازه* · *مثال ۲: flex: auto — بزرگ شو، ولی به اندازه محتوایت* · *مثال ۳: flex: none — دست به من نزن!*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```html
flex: grow shrink basis;

/* مثال: */
flex: 1 1 200px;   /* grow: 1 ، shrink: 1 ، basis: 200px */
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.box {
  flex: 1;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.box {
  flex: auto;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## ۵) سؤال کلاسی

- «چرا `flex: 0` با `flex: 0 1 auto` فرق دارد؟»  
  **پاسخ:** `flex: 0` shorthand یک‌مقداری → **`0 1 0%`**؛ basis صفر و رفتار shrink متفاوت از `0 0 auto`.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«flex: none یعنی 0 0 auto : نه بزرگ می‌شود، نه کوچک. جعبه ۱ اینجا همیشه اندازه خودش را دارد و بقیه با flex: 1 فضا را تقسیم می‌کنند:»

«ستونی که همیشه دقیقاً ۲۰۰ پیکسل است؛ مثل ستون کناری (سایدبار) یک پنل مدیریت. ستون دیگر با flex: 1 بقیه را پر می‌کند:»

«این ستون هر چقدر پنجره پهن یا باریک شود، فضای باقی‌مانده را می‌گیرد؛ ولی ستون کناری همیشه ۲۰۰ پیکسل است.»

«چون flex: 2 برابر 2 1 0% است، پایهٔ همه صفر می‌ماند و فقط نسبت رشد فرق می‌کند. اینجا ستون وسط دو سهم می‌گیرد و هر ستون کناری یک سهم:»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
