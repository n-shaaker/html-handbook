## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«عرض ۳۲۰px: کارت‌ها ستون؛ ۹۶۰px: سه ستون — همان HTML.»


اول با **مسئله** شروع کن — نه با لیست property.

«صفحه‌ای که در لپ‌تاپ قشنگ است، در گوشی هم باید خوانا باشد. خبر خوب اینکه Flexbox خودش تا حد زیادی «انعطاف‌پذیر» است: با ترکیب flex-wrap و flex-basis کارت‌ها بدون هیچ media query خودشان را با عرض صفحه تطبیق می‌دهند. هر جا هم لازم شد، یک media query ساده کار را تمام می‌کند. در این درس پنجره مرورگر را باریک و پهن کنید تا تغییرها را ببینید.»

«چهار کارت با flex: 1 و بدون wrap ؛ در صفحه باریک هر کارت خیلی باریک و متنش ناخوانا می‌شود:»

«به هر کارت می‌گوییم «حداقل حدود ۱۸۰ پیکسل جا بگیر و اگر جا ماند بزرگ شو» ( flex: 1 1 180px ). هر وقت چهار کارت ۱۸۰ پیکسلی جا نشوند، آخری به خط بعد می‌رود و در گوشی همه زیر هم می‌آیند. بدون media query!»

«همان ترفند با کارت‌های واقعی‌تر. چون پنج کارت داریم، در بعضی عرض‌ها کارت آخر تنها در یک خط می‌ماند و پهن می‌شود؛ این رفتار طبیعی flex-grow است:»

**روی جزوه این عناوین را دنبال کنید:** *۱۳) Flexbox واکنش‌گرا (Responsive)* · *مثال ۱: مشکل — کارت‌ها در گوشی له می‌شوند* · *مثال ۲: راه‌حل — flex-wrap + flex-basis* · *مثال ۳: کارت‌های محصول فروشگاه*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.cards {
  display: flex;
  gap: 10px;
}

.card {
  flex: 1;
}
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.card {
  flex: 1 1 180px;   /* بزرگ شو، کوچک شو، از ۱۸۰ پیکسل شروع کن */
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.products {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.product {
  flex: 1 1 200px;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«اگر می‌خواهید کارت آخر پهن نشود و همه کارت‌ها دقیقاً هم‌اندازه بمانند، Grid انتخاب بهتری است؛ در دوره آموزش Grid این را می‌بینید.»

«چیدمان «محتوا + ستون کناری» در دسکتاپ کنار هم است. وقتی عرض صفحه از ۶۰۰ پیکسل کمتر شد، با یک media query جهت را column می‌کنیم تا زیر هم بیایند:»

«معرفی دوره‌های تابستانی آموزشگاه: برنامه‌نویسی وب، طراحی گرافیک و زبان انگلیسی. ثبت‌نام از اول تیر شروع می‌شود.»

«کلاس‌ها حضوری و آنلاین برگزار می‌شوند.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
