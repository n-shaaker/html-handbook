## ۱) شروع کلاس؛ مسئله قبل از تعریف

### مسئله کلاس (اول بگو)

«سه item وسط‌اند ولی دکمه «تنظیمات» باید **ته ردیف** برود — بدون spacer خالی در HTML.»


اول با **مسئله** شروع کن — نه با لیست property.

«align-items روی پدر، همه آیتم‌ها را با هم تراز می‌کرد. گاهی فقط یک آیتم باید رفتار متفاوتی داشته باشد. در این درس دو ابزار برای جابه‌جا کردن یک آیتم تنها یاد می‌گیریم: align-self برای محور فرعی و margin: auto برای محور اصلی.»

«align-self را روی خود آیتم می‌نویسند، نه روی پدر. مقدارهایش همان مقدارهای align-items است ( stretch ، flex-start ، center ، flex-end و baseline )، اما فقط همان یک آیتم را در محور فرعی جابه‌جا می‌کند و تراز بقیه را عوض نمی‌کند. اگر پدر align-items: flex-start داشته باشد و یک فرزند align-self: center ، فقط همان فرزند وسط ارتفاع می‌ایستد.»

«در درس‌های قبل دیدیم margin: auto فقط افقی وسط می‌کرد. داخل ظرف فلکس، margin خودکار همه فضای خالی آن سمت را می‌بلعد. پس یک جعبه با margin: auto در هر دو جهت دقیقاً وسط می‌نشیند:»

«margin-inline-start یعنی «margin سمت شروع ». در صفحه فارسی شروع سمت راست است، پس margin-inline-start: auto کل فضای خالی را سمت راست آیتم می‌گذارد و آن را (و هر چیزی بعد از آن) به سمت چپ هل می‌دهد:»

**روی جزوه این عناوین را دنبال کنید:** *۱۱) align-self و ترفند margin خودکار* · *مثال ۱: align-self — استثنا در محور فرعی* · *مثال ۲: margin: auto در Flexbox* · *مثال ۳: هل دادن یک آیتم به پایان خط*

**چرخه این بخش:** نشان بده → دانشجو حدس بزند → یک خط کد → refresh.

## ۳) Live Coding — مرحله‌به‌مرحله

«فایل live جدا می‌سازم تا index پروژه قاطی نشود — مثلاً `تدریس/live/` در همین ماژول.»

**مرحله 1 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  align-items: flex-start;   /* همه بالا */
  height: 140px;
}

.box-2 { align-self: center; }
.box-3 { align-self: flex-end; }
.box-4 { align-self: stretch; }
```

**مرحله 2 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.parent {
  display: flex;
  height: 140px;
}

.box {
  margin: auto;
}
```

**مرحله 3 — روی صفحه بگو:** «الان این قطعه را اضافه می‌کنم و نتیجه را با هم می‌بینیم.»

```css
.box-4 {
  margin-inline-start: auto;
}
```


**در حین تایپ بگو:** «الان فقط یک تغییر — save — refresh — چه فرقی دیدید؟»

**اشتباه عمدی (یک بار):** یک selector اشتباه یا property روی فرزند نادرست — خطا را با کلاس debug کنید.

## پیوست: نکات تکمیلی از جزوه (برای مدرس)

«چرا margin-inline-start و نه margin-right ؟ چون اگر روزی همین صفحه انگلیسی ( ltr ) شود، «شروع» خودکار سمت چپ می‌شود و ترفند باز هم درست کار می‌کند. در صفحه فارسی margin-right: auto هم همین نتیجه را می‌دهد.»

«لوگو و لینک‌ها از شروع خط (راست) می‌آیند و دکمه «ورود» با margin-inline-start: auto به انتهای خط (چپ) می‌رود. بدون حساب عرض و بدون space-between :»

«این بار margin خودکار را روی اولین لینک بعد از لوگو می‌گذاریم؛ لوگو راست می‌ماند و همه لینک‌ها با هم به چپ می‌روند:»

«اشتباه رایج: برای اینکه دکمه «ورود» به سمت چپ برود، float: left یا position: absolute می‌نویسیم. داخل ظرف فلکس float اصلاً کار نمی‌کند و absolute آیتم را از چیدمان بیرون می‌برد و ممکن است روی لینک‌ها بیفتد. راه درست همان margin-inline-start: auto است.»


**نکته مدرس:** بعد از هر save یک ثانیه مکث کنید تا کلاس خروجی را ببیند.

**نکته مدرس:** یک بار property را عمداً غلط بگذارید و با DevTools پیدا کنید.

**نکته مدرس:** از دانشجو بخواهید قبل از refresh پیش‌بینی بگوید.

**نکته مدرس:** DevTools → Elements → راست‌کلیک → Scroll into view برای آیتم‌های off-screen.

**نکته مدرس:** در RTL جهت main axis را با overlay Flex روی صفحه نشان دهید.
