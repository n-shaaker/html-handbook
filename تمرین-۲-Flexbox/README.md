# تمرین ۲ — Flexbox

دموی الگوهای رایج Flex: نوار منو، کارت‌ها، قیمت‌گذاری، چت.

## پیش‌نیاز

- **[12 CSS Flexbox](../12-CSS-Flexbox/)** را کامل بخوانید (نه فقط این دمو).

## معیار موفقیت

1. یک navbar افقی با `display: flex` و `gap`
2. ردیف کارت‌ها که با `flex-wrap` در عرض کم بشکند
3. حداقل یک الگوی `justify-content` / `align-items` درست
4. بدون `float` برای چیدمان اصلی

## کار شما

1. دمو را بررسی کنید و کامنت‌های CSS را بخوانید.
2. همان الگوها را در یک صفحه «قیمت‌گذاری سه پلن» از صفر پیاده کنید.
3. کوییزهای [12-CSS-Flexbox/quizzes](../12-CSS-Flexbox/quizzes/) را هم انجام دهید.
