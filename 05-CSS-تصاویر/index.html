قبل از شروع: دو جعبه ابزار

روش چه زمانی؟ مثال واقعی
تگ <img> تصویر محتوا است و باید دیده/خوانده شود عکس غذا، پروفایل، محصول، گالری
background-image تصویر فقط برای دکوراسیون است پس‌زمینه هیرو، پترن، بنر تزئینی

اگر کاربر باید عکس را ببیند، ذخیره کند، یا برای سئو/دسترسی‌پذیری مهم است → img. اگر فقط فضا را زیبا می‌کند و بدون آن هم معنی صفحه کامل است → background-image.
