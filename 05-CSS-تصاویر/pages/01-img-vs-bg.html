۱) تگ img یا background-image؟

هر تصویری که در صفحه می‌بینید از یکی از این دو راه آمده است: یا یک عنصر img داخل HTML است، یا با background-image پشت یک جعبه کشیده شده است. این انتخاب اولین تصمیم واقعی هنگام گذاشتن عکس در پروژه است، چون این دو راه از نظر معنا، دسترسی‌پذیری و سئو یکی نیستند. اگر عکس خودش بخشی از محتواست، باید در HTML باشد تا صفحه‌خوان و موتور جستجو آن را ببینند. اگر فقط فضا را زیبا می‌کند و حذفش به معنی صفحه آسیب نمی‌زند، پس‌زمینهٔ CSS مناسب‌تر است.

انتخاب اشتباه معمولاً ظاهر را همان لحظه خراب نمی‌کند، اما بعداً خودش را نشان می‌دهد: عکس محصولی که فقط پس‌زمینه باشد alt ندارد، در نتایج جستجو به‌عنوان تصویر ایندکس نمی‌شود، و اگر CSS لود نشود اصلاً دیده نمی‌شود.

محتوا → img

<img src="../images/food-1.jpg"
     alt="چلو کباب کوبیده">

دکوراسیون → background

/* css/demos/compare.css */
.decor-bg {
  min-height: 160px;
  background-image: url("../../images/hero.jpg");
  background-size: cover;
  background-position: center;
}
متن روی پس‌زمینه

در دنیای واقعی: فروشگاه اینترنتی برای عکس محصول حتماً img می‌گذارد (سئو + alt). بنر تمام‌صفحه اول سایت معمولاً background-image یا ترکیب تصویر + لایه تیره است.

سؤال اگر بله
آیا عکس خودش بخشی از معنی صفحه است، مثل عکس غذا یا محصول؟ از img استفاده کنید تا عکس در محتوا بماند و alt داشته باشد.
آیا اگر عکس را بردارید، خواننده اطلاعات مهمی را از دست می‌دهد؟ باز هم img درست است، چون پس‌زمینه برای صفحه‌خوان نامرئی است.
آیا عکس فقط فضا را زیبا می‌کند و متنِ کنارش همان معنی را می‌رساند؟ background-image مناسب است و نباید با img بدون alt شلوغش کنید.
آیا متن باید روی تصویر بنشیند، مثل بنر اول صفحه؟ معمولاً تصویر را پس‌زمینه می‌گذارند و یک لایهٔ تیرهٔ نیمه‌شفاف زیر متن می‌گذارند تا نوشته خوانا بماند.

اشتباه رایج: گذاشتن عکس محصول فقط با background-image. موتور جستجو آن را به‌عنوان محتوای تصویری صفحه نمی‌بیند، صفحه‌خوان چیزی برای خواندن ندارد، و تصویر پس‌زمینه اصلاً alt نمی‌گیرد. اگر عکس باید توضیح داشته باشد، جایش در img است.

به مسیرها دقت کنید: در img مسیر نسبت به فایل HTML (pages/) حساب می‌شود، پس ../images/ کافی است؛ اما url() داخل فایل CSS نسبت به خود فایل CSS (css/demos/) حساب می‌شود و دو بار ../ لازم دارد. درس بعد همین را کامل توضیح می‌دهد.

تمرین: برای صفحه معرفی شخصی، عکس پروفایل را با img بگذارید و پس‌زمینه هدر را با background-image.
