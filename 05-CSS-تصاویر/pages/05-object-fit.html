۵) object-fit — ناجی کارت‌های محصول

object-fit مشخص می‌کند محتوای یک عنصر جایگزین‌شونده، مثل img یا video، چطور داخل قابی جا بگیرد که خودتان عرض و ارتفاعش را تعیین کرده‌اید. عکس‌های واقعی نسبت‌های متفاوتی دارند. اگر همه را در قابی هم‌اندازه بگذارید و object-fit ننویسید، مقدار پیش‌فرض fill است: مرورگر عکس را در هر دو جهت آن‌قدر می‌کشد یا جمع می‌کند که دقیقاً به اندازهٔ قاب شود، حتی اگر چهره یا غذا تغییر شکل بدهد.

این ویژگی فقط وقتی اثر دارد که هر دو بعد قاب مشخص باشد. اگر ارتفاع auto بماند، قاب همان نسبت خود عکس را می‌گیرد و دیگر چیزی برای بریدن یا جا دادن اضافه وجود ندارد. سه مقدار پرکاربرد را در مثال زیر با یک عکس عمودی، داخل قاب افقی ۱۵۰ پیکسلی، کنار هم می‌بینید. 

.demo-fit-card img {
  width: 100%;
  height: 150px;       /* هر دو بعد مشخص → حالا object-fit معنی دارد */
  display: block;
}

.demo-fit-card .fill    { object-fit: fill; }     /* پیش‌فرض */
.demo-fit-card .cover   { object-fit: cover; }    /* پرکاربردترین */
.demo-fit-card .contain { object-fit: contain; }

هر سه کارت زیر یک عکس عمودی را در قابی افقی به ارتفاع ۱۵۰ پیکسل نشان می‌دهند. عرض و ارتفاع قاب در هر سه یکی است؛ تنها تفاوت، مقدار object-fit است. در fill عکس له می‌شود تا قاب پر شود، در cover قاب پر می‌شود ولی بالا و پایین عکس بریده می‌شود، و در contain همهٔ عکس دیده می‌شود و دو طرف قاب خالی می‌ماند.

fill — کش می‌آید (بد)

cover — قاب را پر می‌کند (عالی)

contain — کل عکس دیده می‌شود

مقدار رفتار کی استفاده شود؟
cover قاب را پر می‌کند؛ ممکن است لبه‌ها بریده شوند کارت محصول، گالری، تامبنیل، آواتار
contain کل عکس دیده می‌شود؛ ممکن است فضای خالی بماند لوگو، عکس فنی که نباید بریده شود
fill (پیش‌فرض) کش می‌آید تا دقیقاً اندازه قاب شود تقریباً هرگز در UI واقعی
none اندازه اصلی عکس، بدون تغییر؛ اضافه‌اش بریده می‌شود به‌ندرت؛ مثلاً نمایش بخشی از عکس بزرگ
scale-down کوچک‌ترِ none و contain؛ هرگز عکس را بزرگ‌تر نمی‌کند آیکون یا لوگوی کوچکی که نباید تار شود

در دنیای واقعی: تامبنیل فروشگاه، کارت غذا و تصویر شبکه‌ای گالری تقریباً همیشه object-fit: cover دارند. هدف این است که همهٔ قاب‌ها هم‌اندازه بمانند و هیچ نوار خالی بین عکس‌ها نیفتد، حتی اگر عکس اصلی مربعی، افقی یا عمودی باشد. بهای این یکدستی این است که لبه‌های عکس ممکن است دیده نشوند؛ اگر بریده شدن قابل قبول نیست، contain انتخاب درست‌تری است.

object-fit روی عناصری مثل img و video کار می‌کند، نه روی div. برای background از background-size: cover استفاده کنید — مفهومش شبیه است. با object-position (مثلاً object-position: top;) تعیین می‌کنید با cover کدام بخش عکس بماند؛ شبیه background-position.

اشتباه رایج: نوشتن object-fit: cover بدون تعیین هر دو بعد. اگر height مقدار auto باشد، قاب دقیقاً هم‌نسبت عکس است و object-fit هیچ اثری نمی‌گذارد.

تمرین: سه عکس با ارتفاع ثابت ۱۴۰ پیکسل و object-fit: cover در یک ردیف بچینید.
