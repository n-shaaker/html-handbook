۹) چک‌لیست قبل از تحویل پروژه

این صفحه درس تازه نیست؛ جمع‌بندی همان تصمیم‌هایی است که در درس‌های قبل گرفتید. قبل از نشان دادن صفحه، هر تصویر را با این سؤال‌ها چک کنید: آیا محتواست یا تزئین، مسیرش از فایل درست حساب شده، قابش در موبایل بیرون می‌زند یا نه، و اگر متن روی عکس است آیا کنتراست کافی دارد. جدول زیر هر مورد را به دلیلش وصل می‌کند تا فقط فهرست حفظ نکنید.

چک چرا مهم است؟
محتوا با img، دکوراسیون با background عکس محتوا باید در HTML بماند تا ایندکس و خوانده شود؛ تزئین را پس‌زمینه بگذارید تا بدون alt الکی در محتوا نیاید.
همه imgها alt معنادار دارند (و عکس‌های صرفاً تزئینی alt="") صفحه‌خوان برای عکس محتوا توضیح لازم دارد و برای عکس تزئینی باید سکوت کند. alt خالی با ننوشتن alt یکی نیست.
width و height واقعی عکس در HTML نوشته شده مرورگر قبل از دانلود، نسبت تصویر را می‌داند و جایش را خالی نگه می‌دارد؛ صفحه هنگام لود به پایین نمی‌پرد.
مسیر فایل درست است (HTML نسبت به HTML، CSS نسبت به CSS) مسیر غلط یعنی فایل پیدا نمی‌شود. در img آیکون شکسته می‌بینید و در پس‌زمینه فقط جای خالی می‌ماند.
هیرو: cover + لایه تیره + متن خوانا اولین بخش صفحه است. اگر متن روی قسمت روشن عکس بنشیند، کاربر تیتر را نمی‌خواند.
آواتار: عرض و ارتفاع برابر + border-radius: 50% + object-fit: cover بدون برابر بودن دو بعد، شکل بیضی می‌شود و بدون cover چهره کش می‌آید.
کارت‌ها: aspect-ratio یا ارتفاع ثابت + object-fit: cover قاب‌ها هم‌اندازه می‌مانند و تفاوت نسبت عکس‌ها ردیف را نامرتب نمی‌کند.
max-width: 100% و height: auto روی تصاویر داخل متن عکس از عرض والد بزرگ‌تر نمی‌شود و در موبایل اسکرول افقی نمی‌سازد.
نام فایل انگلیسی، بدون فاصله، و با حروف کوچک بعضی سرورها Hero.jpg را با hero.jpg یکی نمی‌دانند و فاصله در آدرس دردسر می‌سازد.
حجم عکس متناسب با اندازهٔ نمایش است فایل چندمگابایتی برای یک کارت کوچک، زمان لود صفحه را بالا می‌برد بدون اینکه کیفیت دیده‌شده بهتر شود.
عکس‌های پایین صفحه loading="lazy" دارند و عکس بالای صفحه ندارد مرورگر عکس‌های پایین را تا نزدیک شدن کاربر دانلود نمی‌کند. روی هیرو این ویژگی را نگذارید، چون همان عکس باید فوراً دیده شود.

الگوهای آماده برای کپی در پروژه

۱) تصویر معمولی داخل متن

img {
  max-width: 100%;
  height: auto;
  display: block;
  border-radius: 8px;
}

۲) هیرو

/* فایل css/style.css → یک پله تا ریشه پروژه */
.hero {
  min-height: 60vh;
  background-color: #222;   /* اگر عکس لود نشد */
  background-image:
    linear-gradient(rgba(0, 0, 0, 0.45), rgba(0, 0, 0, 0.45)),
    url("../images/hero.jpg");
  background-size: cover;
  background-position: center;
  color: #fff;
}

.hero-content {
  padding: 48px 24px;
}

۳) آواتار

.avatar {
  width: 96px;
  height: 96px;
  border-radius: 50%;
  object-fit: cover;
}

۴) تامبنیل کارت

.card-thumb {
  aspect-ratio: 4 / 3;
  overflow: hidden;
}

.card-thumb img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

جمع‌بندی: اگر چهار تصمیم را درست بگیرید، بیشتر کارهای تصویری پروژه‌های مبتدی تا متوسط پوشش داده می‌شود. اول مشخص کنید عکس محتواست (img) یا تزئین (پس‌زمینه). بعد مسیر را از همان فایلی حساب کنید که آدرس در آن نوشته شده. برای بنر، cover را با لایه‌ای بگذارید که متن را خوانا کند. برای قاب‌های هم‌اندازه، مثل آواتار و کارت، object-fit: cover را همراه با عرض و ارتفاع یا aspect-ratio مشخص به کار ببرید.

پروژه کوچک: یک صفحه «منوی سه آیتمی» بسازید با هیرو، سه کارت غذا، و یک آواتار سرآشپز در فوتر درباره ما.
