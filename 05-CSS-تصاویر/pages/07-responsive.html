۷) تصویر واکنش‌گرا — موبایل نشکند

تصویری که عرض ثابتی بزرگ‌تر از صفحه داشته باشد، در گوشی از ظرف خودش بیرون می‌زند و اسکرول افقی می‌سازد. واکنش‌گرا بودن عکس یعنی عرضش از عرض والد بیشتر نشود و نسبت طول به عرضش حفظ شود. قاعده‌ای که تقریباً برای هر تصویر داخل متن لازم است این است: max-width: 100% اجازه می‌دهد عکس کوچک بماند اگر فایلش کوچک است، اما نمی‌گذارد از عرض والد بزرگ‌تر شود؛ height: auto هم ارتفاع را با همان نسبت حساب می‌کند تا تصویر له نشود.

این قانون با کارت فرق دارد. در کارت، قاب ارتفاع مشخص دارد و object-fit تصمیم می‌گیرد چه بخشی از عکس دیده شود. برای عکسی که آزاد داخل متن نشسته، نباید ارتفاع را پیکسلی قفل کنید؛ وگرنه با کم شدن عرض، نسبت تصویر به‌هم می‌ریزد. 

img {
  max-width: 100%;
  height: auto;
  display: block; /* فاصله خالی زیر عکس (جای حروف پایین‌رونده خط) را حذف می‌کند */
}

اشتباه: عرض ثابت خیلی بزرگ

.demo-resp .broken {
  width: 900px;        /* عرض ثابت */
  max-width: none;
}

در موبایل باید افقی اسکرول کنید — تجربه بد.

درست: عرض سیال

.demo-resp .fluid {
  max-width: 100%;
  height: auto;
  display: block;
}

در دنیای واقعی: خیلی از فریم‌ورک‌ها همین قانون را پیش‌فرض دارند. علاوه بر CSS، برای سرعت از loading="lazy" روی عکس‌های پایین صفحه استفاده می‌کنند: 

<img src="../images/food-2.jpg" alt="زرشک‌پلو با مرغ"
     width="960" height="720" loading="lazy">

و برای اینکه گوشی عکس خیلی بزرگ دسکتاپ را دانلود نکند، چند اندازه از یک عکس می‌سازند و با srcset و sizes به مرورگر می‌دهند تا خودش مناسب‌ترین را انتخاب کند: 

<img src="hero-1024.jpg"
     srcset="hero-480.jpg 480w, hero-1024.jpg 1024w, hero-1920.jpg 1920w"
     sizes="100vw"
     alt="سالن رستوران" width="1024" height="768">
ویژگی / صفت کاربرد واقعی
max-width: 100% عکس از عرض والد بزرگ‌تر نشود
height: auto نسبت تصویر حفظ شود
loading="lazy" عکس‌های پایین صفحه دیرتر لود شوند (روی عکس هیرو و بالای صفحه نگذارید؛ دیرتر دیده می‌شود)
srcset و sizes مرورگر با توجه به عرض صفحه، فایل کوچک‌تر یا بزرگ‌تر را دانلود کند
width و height در HTML مرورگر قبل از دانلود عکس، نسبت آن را می‌داند و جایش را رزرو می‌کند؛ پس صفحه هنگام لود نمی‌پرد (CLS). با height: auto در CSS، عکس همچنان واکنش‌گرا می‌ماند.

این قانون برای عکسی است که آزاد داخل متن نشسته. داخل کارت، قاب معمولاً ارتفاع یا aspect-ratio مشخص دارد؛ آنجا width: 100% و height: 100% را با object-fit: cover می‌نویسند تا عکس قاب را پر کند و نسبت خودش را با بریدن لبه‌ها حفظ کند، نه با کش آمدن.

اشتباه رایج: فقط width: 100% بدون کنترل ارتفاع در کارت‌ها → ارتفاع‌ها ناهماهنگ می‌شوند. آنجا از aspect-ratio یا ارتفاع ثابت + object-fit استفاده کنید.

تمرین: پنجره مرورگر را خیلی باریک کنید و ببینید کدام عکس از صفحه بیرون می‌زند.
