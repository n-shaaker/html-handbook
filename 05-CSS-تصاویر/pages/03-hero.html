۳) هیرو واقعی سایت

هیرو همان بخش بزرگ اول صفحه است: یک تصویر پهن، یک تیتر، معمولاً یک جملهٔ کوتاه و یک دکمه. تقریباً هر صفحهٔ معرفی، رستوران یا فروشگاه چنین بلوکی دارد. عکس این بخش اغلب تزئینی است و متنِ روی آن معنی اصلی را می‌رساند، برای همین معمولاً با background-image ساخته می‌شود نه با img.

اگر فقط عکس را پس‌زمینه بگذارید و متن سفید را روی آن بنویسید، در قسمت‌های روشن عکس نوشته گم می‌شود. فرمولی که در پروژه‌های واقعی جواب می‌دهد این چهار بخش را با هم دارد:

  1. background-size: cover جعبه را کامل با عکس پر می‌کند. اگر نسبت عکس با جعبه یکی نباشد، لبه‌های اضافه بریده می‌شوند و ناحیهٔ خالی نمی‌ماند.
  2. background-position: center مشخص می‌کند کدام نقطهٔ عکس در وسط قاب بماند. اگر آن را ننویسید، مقدار اولیه 0% 0% است و گوشهٔ بالای چپ عکس با گوشهٔ بالای چپ جعبه میزان می‌شود؛ در هیرو معمولاً سوژه را از قاب بیرون می‌اندازد.
  3. یک لایهٔ تیرهٔ نیمه‌شفاف بین عکس و متن قرار می‌گیرد تا نوشته، مستقل از روشنی عکس، خوانا بماند.
  4. تیتر، یک جمله و دکمهٔ اقدام باید متن واقعی HTML باشند، نه بخشی از فایل عکس، تا هم خوانا باشند و هم بزرگ و کوچک شدن صفحه آن‌ها را خراب نکند.
<div class="demo-hero">
  <div class="demo-hero-inner">
    <h3>طعم خانه، سرویس سریع</h3>
    <p>منوی امروز را ببینید و آنلاین سفارش دهید.</p>
    <a class="demo-hero-btn" href="06-cards.html">مشاهده منو</a>
  </div>
</div>
/* css/demos/hero.css */
.demo-hero {
  min-height: 280px;
  border-radius: 10px;
  /* دو لایه با کاما: اولی (گرادیان تیره) روی دومی (عکس) می‌آید */
  background-image:
    linear-gradient(rgba(10, 20, 30, 0.35), rgba(10, 20, 30, 0.85)),
    url("../../images/hero.jpg");
  background-size: cover;
  background-position: center;
  color: white;
}

.demo-hero-inner {
  padding: 40px 24px;
  max-width: 480px;
}

طعم خانه، سرویس سریع

منوی امروز را ببینید و آنلاین سفارش دهید.

مشاهده منو

دکمه «مشاهده منو» به صفحه دیگری می‌رود، پس باید لینک (a با href واقعی) باشد. اگر کاری داخل همین صفحه انجام می‌داد (مثلاً باز کردن پنجره سفارش)، <button type="button"> درست بود.

اگر لایه تیره نگذارید چه می‌شود؟

متن سفید روی عکس روشن — سخت خوانده می‌شود

در دنیای واقعی: طراحان معمولاً روی هیرو گرادیان یا rgba می‌گذارند، نه فقط color: white. بدون کنتراست، حتی بهترین عکس هم صفحه را خراب می‌کند.

برای ارتفاع هیرو min-height مناسب‌تر از height ثابت است. min-height یک کف می‌گذارد تا بخش خالی به نظر نرسد، اما اگر تیتر یا دکمه در صفحهٔ باریک به خط‌های بیشتری بشکند، جعبه می‌تواند بلندتر شود و متن بریده نمی‌شود.

تصویر پس‌زمینه alt ندارد و صفحه‌خوان آن را نمی‌خواند. پس هر اطلاعات مهمی (نام رستوران، پیشنهاد ویژه) باید به‌صورت متن واقعی داخل هیرو نوشته شود، نه داخل خود عکس.

اشتباه رایج: گذاشتن عکس هیروی خیلی سنگین (چند مگابایت). در پروژه واقعی عکس را فشرده کنید (مثلاً WebP یا JPG با کیفیت ۷۰ تا ۸۰ درصد) و عرضش را بیشتر از نیاز (حدود ۱۹۲۰ پیکسل برای تمام‌عرض) نگذارید.

تمرین: برای صفحه معرفی‌تان یک هیرو بسازید با نام شما، یک جمله کوتاه و دکمه «تماس با من».
