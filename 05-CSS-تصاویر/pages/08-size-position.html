۸) اندازه و موقعیت پس‌زمینه

background-image فقط فایل عکس را به جعبه وصل می‌کند. اینکه عکس چقدر از جعبه را بپوشاند، تکرار شود یا نه، و کدام نقطه‌اش در قاب بماند، کار ویژگی‌های دیگری است. دو تای پرکاربرد background-size و background-position هستند. background-size اندازهٔ نقاشی‌شدهٔ عکس را نسبت به جعبه تعیین می‌کند و background-position می‌گوید آن عکسِ اندازه‌گرفته کجای جعبه قرار بگیرد.

اگر اندازه را ننویسید، مقدار اولیه auto است: عکس با اندازهٔ ذاتی خودش رسم می‌شود و اگر از جعبه کوچک‌تر باشد، بسته به background-repeat تکرار می‌شود. برای هیرو و بنر معمولاً هر دو ویژگی را با هم می‌نویسند تا نتیجه به ابعاد فایل عکس وابسته نماند.

cover در برابر contain

.demo-size .box {
  height: 160px;
  background-image: url("../../images/food-1.jpg");
  background-repeat: no-repeat;   /* بدون این، contain عکس را تکرار می‌کند */
}

.demo-size .cover {
  background-size: cover;     /* کل جعبه را پر می‌کند */
  background-position: center;
}

.demo-size .contain {
  background-size: contain;   /* کل عکس دیده می‌شود */
  background-position: center;
  background-color: #1a3a5c;  /* فضای خالی را پر کنید */
}
cover — برای هیرو و بنر
contain — برای لوگو/عکس کامل

قانون سرانگشتی: وقتی جعبه باید کاملاً پر شود و بریده شدن لبه‌ها مهم نیست، مثل هیرو، بنر و کارت تزئینی، از cover استفاده کنید. وقتی تمام عکس باید دیده شود، مثل لوگو یا نمودار، از contain استفاده کنید و برای نوار خالی کنار عکس یک background-color بگذارید. contain به‌تنهایی فضای خالی را رنگ نمی‌کند؛ اگر background-repeat هم no-repeat نباشد، مرورگر عکس را در آن فضای خالی تکرار می‌کند.

فوکوس چهره با position

cover جعبه را پر می‌کند و هر بخشی از عکس را که در قاب جا نشود می‌بُرد. اگر سوژه، مثلاً صورت، نزدیک بالای عکس باشد، مقدار center ممکن است پیشانی را بیرون بیندازد. background-position نقطهٔ تراز را عوض می‌کند: top center لبهٔ بالای عکس را به لبهٔ بالای جعبه می‌چسباند و برش را به پایین عکس منتقل می‌کند. 

.demo-pos .face {
  height: 140px;
  background-image: url("../../images/profile.jpg");
  background-size: cover;
  background-repeat: no-repeat;
}

.demo-pos .top    { background-position: top center; }
.demo-pos .center { background-position: center; }
position: top
position: center

اگر عکس عنصر img باشد نه پس‌زمینه، همان کار را object-fit: cover همراه با object-position انجام می‌دهد. مثلاً object-position: top center لبهٔ بالای عکس را به لبهٔ بالای قاب می‌چسباند، درست مثل background-position: top center برای تصویر پس‌زمینه.

تکرار پترن (کم‌کاربردتر ولی مفید)

.pattern {
  background-image: url("../../images/pattern.jpg");
  background-size: 80px;
  background-repeat: repeat;
}

در سایت‌های قدیمی‌تر برای بافت کاغذ/پارچه استفاده می‌شد. امروز بیشتر برای پترن‌های SVG کوچک یا نقطه‌ای دیده می‌شود، نه عکس سنگین.

خلاصه یک‌خطی (Shorthand)

.hero {
  background: #333 url("../../images/hero.jpg") no-repeat center / cover;
}

ترتیب رایج shorthand: رنگ، تصویر، تکرار، موقعیت، اندازه. ترتیب بیشتر بخش‌ها آزاد است، اما اندازه باید بلافاصله بعد از موقعیت و با / بیاید (center / cover)؛ اندازه بدون موقعیت مجاز نیست.

اشتباه رایج: نوشتن background: #333; بعد از background-image. shorthand همه زیرویژگی‌هایی را که ننوشته‌اید به مقدار اولیه برمی‌گرداند؛ پس تصویر پاک می‌شود. برای تغییر فقط رنگ، از background-color استفاده کنید.

تمرین: یک بنر بسازید که با cover پر شود و با background-position: right center فوکوس به سمت راست برود.
