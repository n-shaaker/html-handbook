## ۱) شروع — مسئله اول (دیالوگ)

«بچه‌ها، grid فروشگاه — هر کارت: عکس، نام، قیمت، دکمه.

درس قبل `height: 150px` روی img دادیم. حالا designer می‌گوید: *«نسبت ۴:۳ ثابت — اگر عکس portrait crop شود OK.»*

راه: wrapper `.thumb` با **`aspect-ratio: 4 / 3`** + img **`object-fit: cover`** + **`height: 100%`** — مطابق [`cards.css`](../../css/demos/cards.css).»

## ۲) Live Coding مرحله ۱ — HTML

```html
<article class="product-card">
  <div class="thumb">
    <img src="../images/food-1.jpg" alt="چلو کباب">
  </div>
  <div class="body">
    <h3>چلو کباب</h3>
    <p class="price">۲۴۰٬۰۰۰ تومان</p>
    <a class="btn" href="#">افزودن</a>
  </div>
</article>
```

«`alt` معنادار — نه "image1".»

---

## ۳) Live Coding مرحله ۲ — card shell

```css
.product-card {
  background: white;
  border: 1px solid #d9e2ec;
  border-radius: 10px;
  overflow: hidden;
  box-shadow: 0 2px 8px rgba(26, 58, 92, 0.06);
}
```

«`overflow: hidden` — zoom img از گوشه نزند بیرون.»

---

## ۴) Live Coding مرحله ۳ — thumb

```css
.product-card .thumb {
  aspect-ratio: 4 / 3;
  overflow: hidden;
  background-color: #eef1f5;
}
.product-card .thumb img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
```

**در مرورگر:** portrait و landscape — **قاب یکسان**.

### سؤال کلاسی

«چرا img هم width هم height 100%?»  
**پاسخ:** پر کردن کامل `.thumb` — object-fit cover روی آن crop می‌کند.

## ۶) Live Coding مرحله ۵ — hover zoom

```css
.product-card .thumb img {
  transition: transform 0.25s ease;
}
.product-card:hover .thumb img {
  transform: scale(1.05);
}
```

«transition preview — درس میانی. **`prefers-reduced-motion`** در media query اختیاری.»

**در مرورگر:** hover روی card — zoom نرم.

```css
}
@media (max-width: 800px) {
  .demo-cards {

  }
}
```

## ۸) اشتباهات رایج

- aspect-ratio روی img مستقیم بدون wrapper — کنترل سخت‌تر.  
- scale hover بدون overflow hidden on thumb.  
- price فقط در `::after content`.  
- cover بدون height 100% در ratio box.
