## ۱) شروع — دیالوگ

«بچه‌ها، فرض کنید کارت کاربر:

```html
<img src="profile.jpg" alt="عکس سارا">
```

CSS:

```css
img { width: 96px; height: 96px; border-radius: 50%; }
```

عکس **افقی** بود — در دایره **له** شده. مشتری می‌گوید «صورت squashed».

سؤال: `border-radius` مشکل است یا **نحوهٔ fit** تصویر در جعبه 96×96؟

امروز `.demo-avatar` good vs `.demo-avatar-bad` جزوه.»

---

## ۲) Live — HTML

```html
<div class="demo-avatar">
  <img class="profile" src="../images/profile.jpg" alt="عکس پروفایل">
  <div class="meta">
    <strong>سارا احمدی</strong>
    <span>طراح UI</span>
  </div>
</div>
```

«**محتوا** → img + alt describing person.»

---

## ۳) Live CSS — درست

```css
.demo-avatar {
  display: flex;
  align-items: center;
  gap: 14px;
  flex-wrap: wrap;
}

.demo-avatar img.profile {
  width: 96px;
  height: 96px;
  object-fit: cover;
  border-radius: 50%;
  border: 3px solid #1a3a5c;
  display: block;
}
```

**در حین `object-fit: cover`:**

«جعبه 96×96 ثابت — تصویر **برش** می‌خورد تا پر کند، **بدون** deform.»

**در مرورگر:** دایره تمیز.

---

## ۴) demo بد — عمدی

```css
.demo-avatar-bad img {
  width: 96px;
  height: 96px;
  border-radius: 50%;
  border: 3px solid #c92a2a;
}
```

**compare side by side** — کشیدگی.

### سؤال کلاسی

«فقط `height: auto` با width 96?»  
**پاسخ:** دایره کامل نیست — aspect حفظ ولی box مربع نیست.
