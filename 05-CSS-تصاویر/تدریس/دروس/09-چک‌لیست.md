## ۱) شروع — مسئله (دیالوگ)

«سایت آماده deploy — روی موبایل real device:

- یک img **404** (مسیر اشتباه درس ۲)  
- hero **horizontal scroll**  
- آواتار **کش‌آمده** (بدون object-fit)  
- decorative image با `alt` طولانی spam

امروز **چک‌لیست** — نه درس جدید syntax.»

---

## ۲) img محتوایی vs پس‌زمینه تزئینی

| | `<img>` | `background-image` |
|---|---------|---------------------|
| محتوا | بله — alt لازم | decor — alt در CSS نیست |
| SEO / RSS | بله | ضعیف‌تر |
| object-fit | بله | background-size |
| responsive | max-width 100% | size on box |

**پاسخ کلاسی:** لوگو با نام سایت — معمولاً **img** + alt نام برند.

---

## ۳) چک‌لیست accessibility

- [ ] هر img محتوایی **`alt` معنادار** (خالی فقط decor)  
- [ ] figure + figcaption برای caption بلند  
- [ ] contrast متن روی hero (overlay تیره اگر لازم)  
- [ ] focus روی linked images (border/outline)

---

## ۴) چک‌لیست layout

- [ ] `max-width: 100%; height: auto` برای inline content imgs  
- [ ] thumbs: **aspect-ratio** یا fixed height + **object-fit: cover**  
- [ ] `display: block` روی img در card — gap inline حذف  
- [ ] بدون overflow افقی — DevTools 320px

---

## ۵) مسیر و performance (intro)

- [ ] مسیر نسبی درست از CSS/HTML (`../images/`)  
- [ ] width/height attribute یا aspect-ratio — **CLS** کمتر  
- [ ] فرمت مناسب (webp در پروژه پیشرفته)  
- [ ] srcset برای hero بزرگ (درس ۷)
