## ۱) شروع — مسئله (دیالوگ)

«عکس 4000px را `<img src="hero.jpg">` گذاشتید — موبایل **scroll افقی**. HTML width attribute قدیمی کافی نیست — **CSS**:

```css
img {
  max-width: 100%;
  height: auto;
}
```

تصویر **هرگز از container پهن‌تر** نمی‌شود؛ ratio حفظ.»

---

## ۲) Live — داخل `.content`

```css
.content {
  max-width: 40rem;
  margin-inline: auto;
  padding: 1rem;
}
.content img {
  max-width: 100%;
  height: auto;
  display: block;
}
```

**در مرورگر:** resize — img shrink.

### سؤال کلاسی

«`width: 100%` vs `max-width: 100%`?»  
**پاسخ:** width همیشه کش؛ max-width فقط سقف — برای img معمولاً max-width + auto height.

---

## ۳) figure

```html
<figure>
  <img src="..." alt="...">
  <figcaption>توضیح عکس</figcaption>
</figure>
```

```css
figure {
  margin: 1rem 0;
}
figcaption {
  font-size: 0.875rem;
  color: #64748b;
  margin-block-start: 0.5rem;
}
```

---

## ۴) srcset (آگاهی)

```html
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 40rem"
  alt="...">
```

«مرورگر فایل مناسب bandwidth — جزوه [`07-responsive.html`](../../pages/07-responsive.html).»
