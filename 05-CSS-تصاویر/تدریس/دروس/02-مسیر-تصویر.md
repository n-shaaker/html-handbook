## ۲) قانون طلایی (tip جزوه)

1. **HTML:** مسیر نسبت به **فایل HTML باز شده**.  
2. **CSS:** مسیر در `url()` نسبت به **فایل CSS** — نه HTML.

«اگر این را قاطی کنیم، ۹۰٪ broken image از همین است — نه typo نام فایل.»

---

## ۳) Live — ساختار این دوره

درخت جزوه (خلاصه):

```
project/
├── pages/02-paths.html   ← HTML اینجا
├── css/demos/hero.css    ← CSS یک پوشه عمیق‌تر
└── images/profile.jpg    ← مقصد
```

**از HTML در `pages/`:**

```html
<img src="../images/profile.jpg" alt="پروفایل">
```

«یک `../` = برو بالا به `project/`، بعد وارد `images/`.»

**از CSS در `css/demos/`:**

```css
background-image: url("../../images/hero.jpg");
```

«دو `../` = از demos به css، از css به project — بعد images.»

### Live Coding

فایل `تدریس/live/05-paths.html` در **pages/** بساز یا از student بخواه مسیر را بنویسد — **قبل** reveal جواب.

**در مرورگر:** Network → 404 را برای مسیر wrong نشان بده.

### سؤال کلاسی

«چرا `../../` در CSS و `../` در HTML برای همان image folder؟»  
**پاسخ:** depth فایل CSS بیشتر است — یک سطح `demos` اضافه.

## ۴) معنی `../` و `./` (جدول جزوه)

| نوشتن | معنی |
|--------|------|
| `file.jpg` | هم‌پوشه با فایل مرجع |
| `./file.jpg` | صریح هم‌پوشه |
| `../file.jpg` | یک پوشه بالا |
| `../../images/x.jpg` | دو بالا، بعد images |

«Absolute URL (`https://...`) مستقل از location فایل است — CDN.»

---

## ۵) مشاهده مرورگر

1. DevTools → Network → Img filter.  
2. URL درخواست شده را بخوان — relative resolve شده.  
3. 404 → path wrong؛ 200 → OK.

«نام فایل case-sensitive روی Linux server — `Hero.jpg` ≠ `hero.jpg`.»
