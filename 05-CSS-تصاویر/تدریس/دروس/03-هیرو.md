## ۱) شروع — دیالوگ

«بچه‌ها، فرض کنید hero اول landing page:

```css
background-image: url("../../images/hero.jpg");
background-size: cover;
color: white;
```

عکس غذای روشن است — **تیتر سفید** روی آن **ناخوانا**.

طراح می‌گوید: «سایه متن بده.»  
dev می‌گوید: «لایه تیره روی عکس.»

کدام با CSS تمیزتر است؟ آیا `<img>` جدا + overlay div لازم است یا **چند background** کافی است؟

امروز [`demo-hero`](../../css/demos/hero.css) — همان جزوه.»

---

## ۲) Live — skeleton HTML

```html
<section class="demo-hero">
  <div class="demo-hero-inner">
    <h3>رستوران سنتی</h3>
    <p>طعم اصیل، سرو تازه هر روز</p>
    <a class="demo-hero-btn" href="#">مشاهده منو</a>
  </div>
</section>
```

«متن **HTML** است — SEO و screen reader؛ عکس **decorative/supporting** در background.»

---

## ۳) Live CSS — لایه‌ها

مرحله ۱ — ابعاد و رنگ متن:

```css
.demo-hero {
  min-height: 280px;
  border-radius: 10px;
  color: white;
}
```

مرحله ۲ — **دو لایه** (اولین listed = **روی** لایه بعد — top):

```css
.demo-hero {
  background-image:
    linear-gradient(rgba(10, 20, 30, 0.35), rgba(10, 20, 30, 0.85)),
    url("../../images/hero.jpg");
  background-size: cover;
  background-position: center;
}
```

در حین تایپ:

«gradient پایین تیره‌تر — متن پایین hero readable می‌شود. عکس لایه دوم.»

**در مرورگر:** resize width — cover crop می‌کند.

### inner + button

```css
.demo-hero-inner {
  padding: 40px 24px;
  max-width: 480px;
}

.demo-hero-inner h3 {
  margin: 0 0 8px;
  font-size: 1.6rem;
  color: white;
}

.demo-hero-btn {
  display: inline-block;
  background-color: #0b6e4f;
  color: white;
  text-decoration: none;
  padding: 10px 18px;
  border-radius: 6px;
}
```

(hover states در css جزوه — optional live)

## ۴) مشاهده

- contrast تیتر روی gradient.  
- `min-height` بدون content — box still tall.  
- disable images in DevTools — gradient ممکن است بماند — بحث fallback.

### سؤال کلاسی

«چرا img+overlay div هم valid است؟»  
**پاسخ:** control بیشتر؛ hero decorative often background stack کافی.

## ۵) اشتباهات

| غلط | درست |
|-----|------|
| cover بدون min-height | جعبه صفر |
| متن سفید بدون darkening | gradient/layer |
