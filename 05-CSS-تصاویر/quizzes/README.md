# تمرین‌ها و پروژه‌های عملی — تصاویر در CSS

تمرین‌های این دوره دو بخش دارند:

1. **بخش ۱ — تمرین‌های مبحثی** (`1-topic-exercises`): برای هر درس یک پوشه با **سه تمرین کوتاه** (⭐ ← ⭐⭐ ← ⭐⭐⭐). هر تمرین فقط همان مبحث و درس‌های قبل از آن را لازم دارد و ۱۰ تا ۲۵ دقیقه وقت می‌گیرد.
2. **بخش ۲ — پروژه‌های ترکیبی** (`2-combined-projects`): هر پروژه چند مبحث بخش ۱ را **هدفمند** کنار هم می‌گذارد تا یک صفحه واقعی ساخته شود.

همه عکس‌های لازم در پوشه `images` همین دوره هست (`food-1.jpg`، `food-2.jpg`، `food-3.jpg`، `hero.jpg`، `pattern.jpg`، `profile.jpg`، `path-diagram.jpg`)؛ عکس جدید لازم نیست.

## روش کار

**برای هنرجو:**

1. بعد از هر درس، پوشه همان مبحث را در بخش ۱ باز کنید و سه تمرینش را **به ترتیب** حل کنید.
2. وقتی همه مباحثی که یک پروژه لازم دارد (ستون «مباحث ترکیب‌شده» در جدول بخش ۲) تمام شد، آن پروژه را انجام دهید. پروژه‌ها از آسان به سخت مرتب شده‌اند.
3. کارتان را در پوشه‌ای **هم‌عمق با `solution`** بسازید (مثلاً `1-topic-exercises/04-avatar/my-work/`). آن‌وقت مسیر عکس‌ها از HTML و از CSS کنار آن می‌شود `../../../../images/...` (درست مثل پاسخ‌ها). اگر CSS را در زیرپوشه `css/` بگذارید، مسیر CSS یک `../` بیشتر می‌خواهد (مبحث ۲).
4. اگر تمرین پوشه `starter` دارد، فایل‌هایش را کپی کنید و از روی آن شروع کنید.
5. قبل از نگاه کردن به `solution`، صفحه را در عرض گوشی (حدود ۳۷۵ پیکسل) و دسکتاپ امتحان کنید و در DevTools ← Network مطمئن شوید هیچ عکسی 404 نشده.

**برای استاد:**

- پاسخ‌ها عمداً ساده و کوتاه نوشته شده‌اند (سطح یک هنرجوی مرتب، نه یک برنامه‌نویس حرفه‌ای). هر راه‌حلی که الزامات را برآورده کند قبول است.
- فایل‌های `starter` در مبحث ۲ (تمرین ۳) و مبحث ۹ **عمداً** اشکال دارند (مسیر خراب، alt غلط، عکس کش‌آمده)؛ این اشکال‌ها جزو صورت مسئله‌اند.
- در پروژه ۲ و تمرین ۲ مبحث ۲، فایل CSS عمداً در زیرپوشه `css/` است تا محاسبه مسیر تمرین شود.

## نکات نمره‌دهی

- تمرین‌های بخش ۱ نمره جدا ندارند؛ معیار قبولی برآورده شدن همه «الزامات» آن تمرین است.
- بارم هر پروژه بخش ۲ از **۲۰** است و جدولش در برگه همان پروژه آمده.
- `img` بدون `alt` یا با alt بی‌معنی («عکس»، «image») هر مورد **۰٫۵ نمره** کسر دارد. برای عکس تزئینی `alt=""` درست است.
- عکسی که کش آمده یا فشرده شده (نسبتش به‌هم خورده) **۱ نمره** کسر دارد.
- مسیر شکسته عکس (404) **۱ نمره** کسر دارد.
- استفاده از `style` درون‌خطی، JavaScript یا `!important` (مگر برگه اجازه داده باشد) از هر مورد **۲ نمره** کم می‌کند.
- بخش «امتیازی» تا **۲ نمره** اضافه دارد، ولی جمع نمره از ۲۰ بیشتر نمی‌شود.
