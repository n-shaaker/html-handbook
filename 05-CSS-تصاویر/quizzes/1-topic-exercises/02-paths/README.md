# مبحث ۲ — مسیر فایل تصویر

📖 درس مرتبط: [۲) مسیر فایل تصویر](../../../pages/02-paths.html)

ساختار پوشه‌ها در این دوره این‌طور است:

```
05-CSS-تصاویر/
├── images/                 ← همه عکس‌ها اینجا
└── quizzes/
    └── 1-topic-exercises/
        └── 02-paths/
            ├── starter/
            └── solution/
                ├── ex-1.html
                ├── ex-2.html
                └── css/ex-2.css
```

یادآوری: مسیر داخل HTML از جای **فایل HTML** حساب می‌شود و مسیر داخل `url()` در CSS از جای **فایل CSS**.

---

## تمرین ۱ — مسیر از فایل HTML ⭐

**هدف:** نوشتن مسیر نسبی درست با `../` از یک فایل HTML تا پوشه `images`.

**صورت مسئله:** صفحه «غذای روز» رستوران در پوشه `solution` قرار دارد و باید دو عکس `food-2.jpg` و `food-3.jpg` را از پوشه `images` دوره نشان دهد.

**الزامات:**
- فایل `ex-1.html` در پوشه هم‌عمق `solution` باشد.
- دو عکس با تگ `img` و مسیر نسبی (نه مسیر کامل `C:/...`).
- بالای صفحه در یک پاراگراف بنویسید مسیر از کدام پوشه‌ها بالا می‌رود (مثلاً «solution ← 02-paths ← ...»).
- `alt` معنادار و `width`/`height` درست برای هر دو عکس.

**خروجی مورد انتظار:** هر دو عکس بدون علامت «عکس شکسته» دیده می‌شوند.

---

## تمرین ۲ — مسیر از فایل CSS داخل پوشه css ⭐⭐

**هدف:** فهمیدن اینکه وقتی CSS در یک زیرپوشه است، `url()` یک `../` بیشتر لازم دارد.

**صورت مسئله:** همکارتان فایل CSS را به یک زیرپوشه `css/` منتقل کرده و حالا عکس پس‌زمینه بنر (`hero.jpg`) دیگر نمایش داده نمی‌شود، با اینکه عکس در HTML هنوز درست است.

**الزامات:**
- `ex-2.html` در `solution` و فایل CSS در `solution/css/ex-2.css` باشد.
- لینک CSS در HTML مسیر درست `css/ex-2.css` داشته باشد.
- بنر با `background-image` و `hero.jpg`؛ مسیر را از جای فایل CSS حساب کنید.
- یک عکس `img` هم (`food-1.jpg`) در همان صفحه باشد تا مسیر HTML و CSS را مقایسه کنید.
- در کامنت CSS بنویسید چرا مسیر CSS یک `../` بیشتر از مسیر HTML دارد.

**خروجی مورد انتظار:** هم بنر پس‌زمینه‌دار و هم عکس کباب درست نمایش داده می‌شوند.

---

## تمرین ۳ — پیدا کردن مسیرهای خراب ⭐⭐⭐

**فایل آماده:** `starter/ex-3.html` و `starter/ex-3.css`

**هدف:** تشخیص و اصلاح خطاهای رایج مسیر (پوشه جاافتاده، بک‌اسلش، حروف بزرگ/کوچک، مسیر کامل کامپیوتر خودتان).

**صورت مسئله:** یک کارآموز صفحه «گالری رستوران» را روی کامپیوتر خودش ساخته و همه‌چیز درست بوده. وقتی صفحه روی سرور رفت، هیچ عکسی نمایش داده نشد! پنج مسیر در این دو فایل خراب‌اند.

**الزامات:**
- فایل‌های `starter` را کپی کنید و هر پنج مسیر خراب را درست کنید.
- مسیرها نسبی باشند و فقط از `/` استفاده کنید.
- نام فایل دقیقاً با نام واقعی (حروف کوچک) یکی باشد.
- کنار هر اصلاح در یک کامنت HTML یا CSS بنویسید خطا چه بود.
- با DevTools (تب Network یا Console) مطمئن شوید هیچ خطای 404 نمانده.

**خروجی مورد انتظار:** هر چهار عکس گالری و پس‌زمینه سربرگ نمایش داده می‌شوند و هیچ خطای 404 در DevTools نیست.

---

## اشتباه‌های رایج این مبحث

- مسیر کامل کامپیوتر خود (`C:/Users/...`) را می‌نویسند؛ روی سرور یا کامپیوتر دیگر کار نمی‌کند.
- از `\` (بک‌اسلش ویندوز) استفاده می‌کنند؛ در وب فقط `/` درست است.
- `Food-1.jpg` و `food-1.jpg` را یکی می‌دانند؛ روی بیشتر سرورها فرق دارند.
- مسیر داخل CSS را از جای HTML حساب می‌کنند، نه از جای خود فایل CSS.
