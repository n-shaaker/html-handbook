## صورت مسئله

شبکه اجتماعی آشپزی «دستپخت» برای هر کاربر یک صفحه پروفایل دارد. صفحه کاربر «سارا رحیمی» باید این بخش‌ها را داشته باشد:

- بالای صفحه یک **عکس کاور** پهن که با عکس `pattern.jpg` پر شده (تزئینی است).
- یک **آواتار** دایره‌ای بزرگ از `profile.jpg` که نصفش روی کاور و نصفش پایین کاور است (مثل شبکه‌های اجتماعی).
- نام، یک خط معرفی و سه عدد آمار: «۳۴ دستور پخت»، «۱۲۰۰ دنبال‌کننده»، «۸۰ دنبال‌شونده».
- بخش «دستورهای اخیر» با سه عکس کوچک هم‌اندازه از `food-1.jpg`، `food-2.jpg`، `food-3.jpg` و نام غذا زیر هر کدام.

مدیر فنی سایت گفته: «فایل CSS حتماً در پوشه `css/` کنار `index.html` باشد، چون همه صفحه‌های سایت همین ساختار را دارند.»

```
پوشه-کار-شما/
├── index.html
└── css/
    └── style.css
```

پوشه کارتان را **هم‌عمق `solution`** (مثلاً `project-02-user-profile/my-work/`) بسازید.

## الزامات

1. ساختار پوشه دقیقاً مثل بالا باشد و `index.html` فایل `css/style.css` را لینک کند.
2. کاور با `background-image` (نه `img`) و ارتفاع `200px`؛ پترن با `background-size` دلخواه (مثلاً `300px auto`) و `background-repeat: repeat` تکرار شود. مسیر `url()` را از جای فایل CSS حساب کنید.
3. آواتار با تگ `img` و `alt` شامل نام کاربر؛ `140px` در `140px`، `border-radius: 50%`، `object-fit: cover` و حاشیه سفید ضخیم.
4. آواتار نصفه روی کاور بیاید (با `margin-top` منفی یا `position`) و وسط صفحه باشد.
5. سه آمار کنار هم و وسط‌چین باشند (با `inline-block` یا Flexbox ساده).
6. سه عکس «دستورهای اخیر» دقیقاً هم‌اندازه (مثلاً `aspect-ratio: 1 / 1` یا ارتفاع ثابت) با `object-fit: cover`؛ عکس عمودی چای با `object-position` استکان را نشان دهد.
7. همه `img`ها `width` و `height` واقعی در HTML داشته باشند؛ عکس‌های «دستورهای اخیر» `loading="lazy"` بگیرند ولی آواتار نه.
8. هیچ مسیری مطلق (`C:/...`) یا با `\` نباشد و هیچ 404 در DevTools دیده نشود.

## محدودیت‌ها

- عکس کاور فقط در CSS؛ آواتار و عکس غذاها فقط با `img`.
- بدون JavaScript، بدون `style` درون‌خطی، بدون `!important`.
- هیچ عکسی کش نیاید.
- حداکثر یک media query.

## امتیازی (تا ۲ نمره)

- روی آواتار یک نقطه سبز «آنلاین» با `position: absolute` (مثل تمرین ۳ مبحث ۴).
- عکس‌های «دستورهای اخیر» با hover کمی بزرگ شوند، بدون بیرون زدن از قاب.

## نکته استاد

- قبل از نوشتن `url()`، روی کاغذ از `css/style.css` پله‌پله بالا بروید تا به پوشه دوره برسید؛ یک پله بیشتر از مسیر HTML است.
- اگر کاور دیده نمی‌شود، اول DevTools ← Network را نگاه کنید؛ شاید عکس 404 شده و مشکل از CSS نیست.
- آواتار روی کاور: اگر `margin-top` منفی می‌دهید، آواتار باید `display: block` یا `inline-block` باشد.
